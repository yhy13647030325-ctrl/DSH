# 第 12 章：项目造型

## Core Idea
本章是全书方法的**演练合集**：5 个真实项目（水壶、摩托车头盔、锤子、咖啡机、剃须刀）按"轮廓 → 比例 → 形状 → 姿态 → 线条 → 体积 → 表面 → 从平面到立体"的顺序走完整流程。

## Frameworks Introduced

- **标准造型流程（案例中共通的步骤序列）**：
  **基准图 → 轮廓 → 比例 → 形状 → 姿态/体积 → 线条 → 表面 → 3D 绘图 → 3D 渲染效果图**
  - 不同案例会按需要取用其中若干步（如剃须刀案例用"轮廓 → 比例 → 线条 → 形状 → 体积 → 表面 → 3D 绘图"）。
  - When to use：任何产品造型项目的全流程骨架。

- **各步骤在本章的具体做法（作者在案例中给出）**：

  **比例**
  - "该水壶的整体比例与基准水壶保持一致。"  
  - 技法：因为"主要视觉特征很少，只有水位指示窗、壶盖和底座，所以设计师把重点放在了右图的**轮廓比例排列**上"。
  - **对齐原则**："它的设计使大多数视觉点与红色的相邻点**在同一水平线或垂直线上**，让设计显得更加平衡。"（例：壶嘴的尖端与把手的内弧线端点水平对齐；水位指示窗与壶身的后下部主体平行。）
  - 熟练后可"本能地做到这一点，而不必再加上网格线"。
  - 关键判据：**"如果一个产品看起来不太对劲，通常是由比例上的不完美导致的，所以需要花时间把这个阶段的设计做好。"**

  **形状**
  - 只改该改的："本案例中唯一需要修改的形状是水位指示窗，它看起来不太合适。它的位置被重新调整为与壶体的上半部平行。"

  **姿态**
  - "左图中的水壶设计有着坚实的、静止的姿态。如果想要姿态设计得更具动感，可以**简单地将设计进行倾斜**。重心已经转移到了前面，设计师也开始尝试修改底座和把手的形状。"

  **线条**
  - 问题起点："左图看起来很凌乱，因为设计师一直在尝试不同的线条和形状。"
  - 手法：把**重要的视觉特征（水位指示窗）延伸到壶身的侧面**，从而**与把手、轮廓产生联系**。
  - 另一个手法：**把把手重新融入壶身**而不是将末端暴露在外，形成中空形状，并经调整使其与周围线条整齐交汇；"不连接把手的概念可以很容易地设计成替代方案"。
  - 定稿："完成后的侧面轮廓已经通过**叠加原图来重新绘制**，使其更有表现力。设计师**加深了轮廓线**，让它更加突出。"

  **体积**
  - 案例做法：水位指示窗以一定角度横跨水壶主体、从把手向下延伸至正面；"这个特征还有一个意义上的功能，即**增加了视觉趣味，分割了水壶的主体，以减少产品视觉上的笨重感**"。
  - 对照方案："第二种设计没有这种分割，看起来比较简洁，但由于壶身明显增大，看起来比较沉重。这个壶身的**不规则轮廓增加了视觉冲击力，减少了方正感**。"
  - 结论：**体积划分会影响视觉重量**。

  **表面**
  - 描述：形态"是上部为轻微拉伸的银色圆柱体，深灰色的底部是锥形"；"银色的表面在从壶盖延伸到把手时具有**张力**，增加了视觉冲击力"；"底部更具几何感的圆锥形表面为水壶提供了坚实的底板，同时保证了水壶能容纳足够多的水"。

  **从平面到立体**
  - 目的："在这一阶段，你的目的是将产品进行**立体可视化**，因为还没有确定产品形式，所以通常需要**发挥艺术想象**来达到最佳效果。"
  - 迭代："一旦你画出了基本的外形，就需要对它进行**细微调整**，以改善整个产品的**线条流动和关系**"；"特别是对于比较复杂的产品，你可能会发现**需要多次绘制三维视图**，才能达到准确的效果。"
  - 细节示例：壶盖设计包含一个用于打开壶盖的**指孔**；在渲染图中该指孔被**简化**，以表达更为简洁的产品表面细节。
  - 交互点标注：**主要的用户交互点（壶盖、水位指示窗、把手）用蓝色突出显示**；铝制壶身上部与深灰色下半部分"都展示了一种高科技的感觉"。

- **五个案例的造型主题（同一流程的不同取向）**：
  | 案例 | 主题 | 关键手法 |
  |---|---|---|
  | 水壶 | （比例/线条/体积综合示范） | 视觉点对齐、指示窗延伸、把手融入壶身、分割主体减轻笨重感 |
  | 摩托车头盔（马克·德特雷） | **坚固和激进** | 摒弃传统遮阳板形状，改用更激进的面部形状；"眼睛"比例逐渐拉长以提高可见度；两眼间的"眉头"被镜面化，从而影响"鼻子"通气口的位置使外观和谐；下巴部位通过**表面折痕**分割出来，形成的**凹面用来捕捉光线** |
  | 锤子（托罗斯·詹加尔） | **动感和冒险** | 锤头最初简化，后加入更"激进"的形状（钟乳石与地面轮廓）变得更复杂；**锤头向下倾斜**使姿态更具动感，也让把手更符合人体工学；**锤子颈部的空洞形状**使其外观看起来更加轻盈 |
  | 咖啡机（伊恩·哈德洛） | **简洁明快** | 略呈圆锥形的新外观营造**更稳定、坚固的姿态**；滤网与咖啡壶形状在基准图上**简化**并增加**跑道形状的细节**；底座边缘角度调整使外观更轻盈；**咖啡壶的凹面模仿把手的形状**，为使用者手指留出空间 |
  | 剃须刀（汤姆·麦克道尔） | **柔性和友好** | 轮廓采取**符合人体工学**的方法，造型紧凑而圆润；在外形上修改线条之前，**先确定上半圆的形状**；随最终线条确定，对手柄和产品表面进行优化，以保证**手持舒适度** |

## Key Concepts

- **基准图**：流程起点（等同第 2 章的设计指南底图）。
- **轮廓比例排列**：把视觉点对齐到同一水平线/垂直线。
- **重心转移**：倾斜造型以获得动感。
- **线条的关联性**：把视觉特征延伸，使其与把手、轮廓产生联系。
- **视觉特征分割体积**：以功能特征顺带分割主体，减轻视觉笨重感。
- **表面张力**：表面在延伸过程中产生的紧张感（银色圆柱→把手）。
- **凹面捕捉光线**：用凹面制造光影变化（头盔下巴）。
- **空洞减轻视觉重量**：以镂空使外观更轻盈（锤颈）。
- **指孔简化**：为表达更简洁的表面细节而简化交互细节。
- **交互点标注**：用颜色（蓝色）标出主要用户交互点。

## Mental Models

- **Use 视觉点对齐 when 造型显得不平衡**：让多数视觉点落在同一水平线或垂直线。
- **Use「看起来不对劲」as 比例警报**：优先怀疑比例不完美，而不是继续改别的。
- **Use 倾斜 when 需要动感**（姿态）；**用分割 when 显得笨重**（体积）。
- **Use 延伸视觉特征 when 线条杂乱**：让线条有明确的关联对象。
- **Use 不规则轮廓 when 要减少方正感**。
- **Use 凹面 when 需要在暗部制造光**（头盔下巴"凹面用来捕捉光线"）。
- **Use 镂空/空洞 when 想显轻**（锤颈）。
- **Use 简化 when 需要"简洁明快"**（咖啡机、渲染图中的指孔）。
- **Use 交互点标注 when 汇报或评审**：用颜色圈出用户实际接触的部位。

## Anti-patterns

- **在造型"看起来不对劲"时去改形状或颜色**：先查比例。
- **让线条找不到关联对象**：会显得"很凌乱"。
- **把功能特征暴露在外却不加整合**：把手末端暴露不如融入壶身来得整洁。
- **用增大壶身来简化**：会明显变重（对照方案）。
- **一次就画出准确的三维视图**：复杂产品通常需要多次绘制。
- **为了造型牺牲人体工学**：锤子、剃须刀案例都把"姿态倾斜/轮廓圆润"与人机舒适度绑定。

## Worked Example

**水壶造型：从基准图到 3D 渲染的完整链路**

1. **基准图**：选定基准水壶，整体比例保持一致。
2. **轮廓**：确认视觉特征很少——仅**水位指示窗、壶盖、底座**。
3. **比例**：做**轮廓比例排列**，让大多数视觉点与相邻点**处于同一水平线或垂直线**上；例如壶嘴尖端与把手内弧线端点水平对齐、水位指示窗与壶身后下部主体平行 → 设计显得更平衡。
4. **形状**：只改不合适的一处——把水位指示窗的位置**调整为与壶体上半部平行**。
5. **姿态**：原设计姿态坚实静止；若要更动感，**简单地把设计倾斜**，重心前移，并相应修改底座和把手形状。
6. **线条**：解决"凌乱"——把水位指示窗**延伸到壶身侧面**，与把手、轮廓产生联系；把**把手重新融入壶身**形成中空形状，使其与周围线条整齐交汇；通过**叠加原图重新绘制**侧面轮廓并**加深轮廓线**使其更突出。
7. **体积**：让水位指示窗以一定角度横跨主体，**分割水壶主体以减少视觉笨重感**；对照方案（不分割）虽然简洁但**壶身增大显得沉重**；用**不规则轮廓增加视觉冲击力、减少方正感**。
8. **表面**：上部为轻微拉伸的**银色圆柱体**（从壶盖延伸到把手时具有**张力**），底部为**深灰色锥形**（提供坚实底板，同时保证容量）。
9. **从平面到立体**：进入**立体可视化**，发挥艺术想象；画出基本外形后做**细微调整**以改善线条流动和关系；复杂产品需**多次绘制三维视图**；**简化壶盖指孔**以表达更简洁的表面细节；用**蓝色标出主要用户交互点**（壶盖、水位指示窗、把手）。
10. **渲染**：输出 3D 绘图与渲染效果图。

## Key Takeaways

1. 本章是全书方法的**整合演示**：基准图 → 轮廓 → 比例 → 形状 → 姿态 → 线条 → 体积 → 表面 → 3D。
2. **比例优先**："如果一个产品看起来不太对劲，通常是由比例上的不完美导致的。"
3. **视觉点对齐**（同一水平线/垂直线）是获得平衡感的具体手段。
4. **倾斜**给姿态以动感，**分割**给体积以轻感，**不规则轮廓**削减方正感。
5. **线条必须有明确关联对象**（延伸到把手与轮廓；把手融入壶身）。
6. **凹面可用来捕捉光线**（头盔下巴），**镂空可显轻**（锤颈）。
7. **立体阶段需要多次绘制**并发挥艺术想象，还要简化不必要的细节（指孔）。
8. 五个案例示范了同一流程服务于不同主题：**坚固激进 / 动感冒险 / 简洁明快 / 柔性友好**。
