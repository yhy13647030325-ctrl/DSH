# 第 11 章：材料与质感

## Core Idea
材质在造型上承担两件事：**用光泽与抛光制造吸引力**，以及**用"跨界材料"让产品出类拔萃**；而选择材料必须经过四个自问来检验。

## Frameworks Introduced

- **表面抛光（光泽的吸引力）**：
  - 心理事实：**"人们总是容易被闪亮的物体所吸引。"**
  - 行业例证：大多数手机"在外观上看起来很普通，它们的卖点几乎都是**高品质的材料、高分辨率的屏幕图像和直观的用户交互**"。
  - 具体判据："智能手机最吸引人的地方之一是**宝石般的玻璃显示屏**。这也是客户最喜爱的部分，即使在不使用手机时，也**经常会看到人们对屏幕进行擦拭以保持光亮**。"
  - When to use：当产品的吸引力需要落在"质感与光泽"上而非造型新奇上时。

- **新颖材料选择（本章的核心增益点）**：
  - 结论：**"新颖的材料选择可以使产品出类拔萃。"**
  - 手法：**"通过采用与特定产品类别无关的材料，可以设计出新颖、独特的外观。"**
  - 案例：Meze 11 Deco 木质耳机（2013）——"有一个新颖的木质外壳，可以展现**温暖、环保**的理念，并帮助产品在竞争中脱颖而出。"
  - 机制：材质本身携带语义（温暖 / 环保 / 高科技），跨品类使用会带来陌生感与记忆点。

- **材料选择的四个自问（章节回顾给出的检查清单）**：
  1. **所选材料是否能够满足产品的功能需求？**（如坚固、保温等）
  2. **什么材料可以让目标客户产生积极联想？**
  3. **所选材料是否增强了产品造型或者并无帮助？这样的触感增强了用户体验吗？**
  4. **不常用于某种产品类别的材料是否有助于该产品脱颖而出？**
  - When to use：任何材质决策的收口检查；四问分别覆盖**功能、客户联想、造型增益/触感体验、差异化**。

## Key Concepts

- **表面抛光**：通过光泽提升吸引力。
- **宝石般的玻璃显示屏**：手机类产品的高价值材质语汇，用户会主动维护其光亮。
- **跨界材料**：与产品类别无关的材料 → 新颖独特的外观。
- **材质语义**：木质→温暖、环保；金属/玻璃→科技、精密、高级。
- **触感（tactility）**：材料对用户体验的直接影响维度。

## Mental Models

- **Use 抛光/光泽 when 造型本身已趋同**：手机卖点即"高品质材料 + 屏幕图像 + 交互"。
- **Use 跨界材料 when 想在竞争中脱颖而出**：故意选"与特定产品类别无关的材料"。
- **Use 四自问 when 收口任何材质决策**：功能 / 客户联想 / 造型增益与触感 / 差异化。
- **Think of 材料 as 语义载体**：木质=温暖环保，玻璃金属=精密高级，选材等于选词。
- **Remember 触感也是用户体验**：材料不止影响看，还影响摸。

## Anti-patterns

- **只追求闪亮而不顾功能**：四问第一条即"是否满足功能需求"。
- **选了客户无感甚至反感的材质**：必须问"什么材料可以让目标客户产生积极联想"。
- **材质与造型无关地堆砌**：要问"所选材料是否增强了产品造型或者并无帮助"。
- **忽略触感**："这样的触感增强了用户体验吗？"
- **始终使用品类常规材料**：会失去"脱颖而出的"机会。

## Worked Example

**给一副耳机选外壳材料**

1. **明确功能需求**（四问之一）：外壳是否需要坚固、隔音、轻量、耐用？
2. **列出候选语义**：木质→温暖、环保；金属→精密、高级；塑料→常规、廉价；玻璃→通透、科技。
3. **跨界尝试**（四问之四）：选择**与耳机品类不常关联的材料**，例如 Meze 11 Deco 的**木质外壳**，以呈现温暖、环保的理念。
4. **验证客户联想**（四问之二）：目标客户是否会因此产生积极联想？
5. **验证造型增益与触感**（四问之三）：该材料是否让造型更好？触感（贴耳、温度感）是否改善体验？
6. **对照光泽路线**：若走"闪亮吸引力"路线，则提升抛光与光泽度，类比智能手机"宝石般的玻璃显示屏"之吸引力。
7. **收口**：确保最终选择**至少在一个维度上制造了差异**（功能、语义、触感或辨识度），而不是平庸的品类常规用料。

## Key Takeaways

1. **人们总是容易被闪亮的物体所吸引**；抛光与光泽本身就是吸引力来源。
2. 手机一类产品的卖点已从造型转向**高品质材料、高分辨率屏幕、直观交互**；玻璃显示屏的价值高到用户会主动擦拭维护。
3. **新颖的材料选择可以使产品出类拔萃**：关键是**采用与特定产品类别无关的材料**。
4. 材料携带语义：木质外壳可展现**温暖、环保**的理念。
5. 材质决策收口用**四自问**：功能需求 / 客户积极联想 / 造型增益与触感体验 / 差异化潜力。
6. **触感是用户体验的一部分**，不是附属项。
