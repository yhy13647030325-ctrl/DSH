# 第 4 章：形状

## Core Idea
形状与轮廓相似，但**联想和象征意义在形状中更重要**（因为它更明显）；新形状的正确做法是：**取一个有意义的原形 → 抽象化 → 简化**，让客户感受到特性却看不出原形来源。

## Frameworks Introduced

- **形状的定位与约束**：
  - 与轮廓的关系：形状的造型和轮廓类似，但"**联想和象征意义在形状中的作用更为重要，因为它们更为明显**"。
  - 首要约束：**"形状应该始终受到功能的影响。"**
  - 与人体交互的部分要更细心：有棱角的产品在概念草图中可行，但**在设计与人互动的部分时要更加细心**，避免用户长时间使用时感到不适（如无线鼠标需要手掌舒适贴合，"如果一个产品要由用户来抓握或操作，那么它需要有很好的手感"）。
  - 修改策略：先确保功能形状可以在不影响使用和人体工学的前提下修改；也可以在设计中加入合适的符号形状与难点相匹配。

- **形状的表达功能（本章的语义维度）**：
  - **性别属性**："柔和的形状可以体现出更为女性化的产品，而更有棱角的形状通常与更男性化的产品相关"——**但也会因产品和产品类别的不同而变化**。
  - 象征与联想：表达意义或激发用户情感，**用户更可能在潜意识中与这些形状建立关联**。
  - 创新形状"也可以创造出更为独特或现代的外观"。

- **形状的一致性与连贯性**：
  - 要求："重要的是创设与整体产品形式语言相关联的连贯形状，从而达到更加和谐的效果。"
  - 常见做法："产品设计中最常见的二维形状通常都基于简单的几何形，如**圆形和椭圆形**。"
  - 有效形状：**"如同水滴一样的流线型，也被证明在突显产品性能方面是很有效的。"**

- **设计新形状的四步法（本章最有操作性的流程）**：
  1. **确保功能形状可以在不影响产品使用和人体工学的前提下进行修改**。
  2. **选择一个合适的与其既定主题相关的形状**。
  3. **对这个形状进行抽象处理并简化其形式**。
  4. 目的判据：**"让客户感受到原有形状的特性，但是不能太明显地看出原有形状的来源。"**
  - 示例：从**白头鹰的头部**开始，创作出能让人联想到**速度与敏捷**的形状，再对轮廓进行抽象以达成最终的形状特征。

## Key Concepts

- **形状（shape）**：比轮廓更具联想与象征含义的二维/三维形式要素。
- **功能形状**：受功能约束的部分，修改前必须确认不影响使用与人体工学。
- **流线型（水滴状）**：被证明能有效突显产品性能的形状语言。
- **简单几何形**：圆形、椭圆形——二维形状的基础语汇。
- **形状的性别联想**：柔和↔女性化，棱角↔男性化（随品类而变化）。
- **抽象化**：把取自原型（如鹰头）的形状简化，保留联想、隐去出处。
- **皇家橡树腕表案例**：贯穿其设计的**多边形**（八角形表盘、六角形螺钉和表栓）在当时是新颖形式；据说受 20 世纪 70 年代**深海潜水头盔**启发——虽然头盔并非多边形，但**观察窗周围的铆钉**显然提供了灵感。

## Mental Models

- **Use 四步法（可改性→选原形→抽象化→隐藏出处）when 需要原创形状**。
- **Use「感受得到特性、看不出出处」as 抽象化的合格线**：太像=抄袭，太不像=意义丢失。
- **Use 功能 when 决定形状能否被改动**：形状服从功能，先确认不破坏使用与人体工学。
- **Use 简单几何形与流线型 when 需要稳妥的形状语言**：圆/椭圆是基础，水滴状流线型利于表现性能。
- **Treat 性别联想 as 品类相关变量**：柔和/棱角的含义会随产品类别变化，不能一概而论。
- **Use 象征符号 when 想让用户潜意识建立关联**：容易识别的符号是表达意义或激发情感的有效方法。

## Anti-patterns

- **为了造型而牺牲抓握与操作手感**：交互部位必须更细心处理，避免长时间使用不适。
- **直接挪用原型形状**：会"太明显地看出原有形状的来源"。
- **把形状抽象到无法识别**：客户感受不到原有特性，意义丢失。
- **忽视形状的连贯性**：形状必须与整体产品形式语言相关联才能达到和谐。
- **机械套用"柔和=女性、棱角=男性"**：该联想随产品类别变化。
- **扁平地看待二维形状**：形状设计要服务于功能与主题，而非单纯装饰。

## Worked Example

**用"白头鹰→速度与敏捷"走完形状四步法**

1. **可改性检查**：确认该功能形状可以在不影响产品使用与人体工学的前提下修改。
2. **选原形**：选一个与既定主题相关的形状——**白头鹰的头部**，因为它天然关联"速度与敏捷"。
3. **抽象化**：从鹰头提取可迁移的形式特征（前倾的轮廓、锐利的收束），**对轮廓进行抽象**。
4. **简化**：去掉可辨识的细节，只保留造成联想的形式结构。
5. **合格判据**：让客户**感受到速度与敏捷的特性，但看不出这是鹰头**。
6. **配套检查**：
   - 形状是否仍受**功能**约束？
   - 与人交互的部位是否**手感良好**？
   - 形状是否与整体产品**形式语言连贯**？
7. **对照历史案例**：皇家橡树腕表的**多边形**（八角形表盘、六角形螺钉）取自潜水头盔观察窗周围的**铆钉**——保留了"铆钉/工业感"的联想，却完全没有头盔的形象。

## Key Takeaways

1. 形状比轮廓更依赖**联想与象征**，因为形状更明显。
2. **形状应该始终受到功能的影响**；交互部位要特别注意手感。
3. 设计新形状的**四步**：可改性检查 → 选相关原形 → 抽象化 → 简化；合格线是"**感受得到特性、看不出出处**"。
4. 简单几何形（圆/椭圆）是二维形状的基本语汇；**水滴状流线型利于突显性能**。
5. 形状的**性别联想**（柔和/棱角）随产品类别变化，不可机械套用。
6. 形状必须与**整体产品形式语言连贯**才和谐。
7. 容易识别的符号能触发用户的潜意识联想，是有效的表意手段。
