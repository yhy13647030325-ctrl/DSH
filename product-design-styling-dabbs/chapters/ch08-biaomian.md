# 第 8 章：表面

## Core Idea
表面是造型的"光影层"：**凸面、凹面、平面**三种基本类型的组合，加上**光线与阴影**的方向性，决定产品看起来是膨胀、精确还是流动。

## Frameworks Introduced

- **表面的三种基本类型（本章的核心分类）**：
  - **凸面**：向外凸出。
  - **凹面**：向内凹陷。
  - **平面**：平坦的平面。
  - "也有将这三种类型结合在一起的造型。"
  - 案例：产品可以是**凸面和凹面的混合体**，"这也显示了表面设计的创新可以吸引消费者的注意"（陶瓷勺子）。
  - When to use：任何表面设计的第一步是识别当前区域属于哪一类，以及三者如何过渡。

- **光线与阴影（本章的物理机制）**：
  - 基本规律 1：**"当一个有光泽的表面向地面倾斜时，它将反射出地面的颜色（或阴影）。"**
  - 基本规律 2：**"如果表面向上倾斜，在日光或人造光下会显得更轻。"**
  - 基本规律 3：**"在产品上或表面褶皱时，就会变得非常闪亮。"**
  - 用途：用倾斜方向控制产品局部"显重"还是"显轻"，用褶皱制造高亮。
  - 建模提示："到了立体建模阶段，你的草图线条会变成**闭合线、边缘线、表面折痕，以及实心或空心的部件形状**。在造型时，想象一下每条线可能会变成什么样子，以便更好地理解立体形态，这是一种很好的练习方法。"

- **表面的复杂性与目标市场**：
  - 最复杂案例：**运动鞋**——"在所有产品中，运动鞋的表面设计是最复杂的，因为它们必须包裹人类脚部的复杂形态"；额外的表面细节增加了产品的特色。
  - 头盔案例（Giro Ember MIPS 女式骑行头盔，2018）：**下半部分**和周边环境有交互和流动感；**上半部分**有高亮的表面，**利用光影来分割动态的形状**；对比鲜明的材料处理**增加了视觉分离感**。
  - 重要限定：**"这种动感的表面设计从未让消费者失望过，但根据目标市场的不同，比之简单得多的表面设计仍是有需求的。"**
  - 简洁路线：柏莱士 BR 03-92 腕表（2018）"以简单的几何造型营造出一种**精确和坚固**的感觉，这也是某些产品的重要标准"；边缘经过**倒角处理**，以便在手腕移动时**反射光线**；这些小细节通常经过**抛光处理**，从而最大限度地提高其反射率，**凸显腕表的精确性**；其灵感来自**经典的飞机驾驶舱仪表**。

## Key Concepts

- **凸面 / 凹面 / 平面**：表面设计的三原语，可混合。
- **倾斜方向与明暗**：向下倾斜→反射地面色/阴影；向上倾斜→受光显得更轻。
- **褶皱与高亮**：褶皱处非常闪亮。
- **倒角与抛光**：小尺度的边缘处理，用来"捕捉并反射光线"，传达精确性。
- **视觉分离感**：通过对比鲜明的材料处理获得。
- **光影分割**：用高亮区域把动态形状切分出来。
- **建模转化**：线条 → 闭合线 / 边缘线 / 表面折痕 / 实心或空心的部件形状。

## Mental Models

- **Use 三类型识别 when 开始处理任何表面**：凸 / 凹 / 平面，再考虑混合。
- **Use 倾斜方向 when 想让局部显轻或显重**：向上倾斜受光显轻；向下倾斜反射地面色。
- **Use 倒角+抛光 when 需要传达精确与坚固**：靠反射光线的变化暗示品质（腕表案例）。
- **Use 光影高亮 when 需要分割动态形状**：让高亮区域承担"分界"作用。
- **Use 复杂度分级 when 匹配目标市场**：动感复杂表面稳妥，但简单表面仍有市场需求，按客户选择。
- **Remember 必须立体建模才能解决复杂表面**：纸上轮廓与渲染无法准确处理复杂产品的表面问题。

## Anti-patterns

- **只在纸上设计复杂表面**："产品表面可以在纸上使用轮廓线条或渲染来设计，但**只有在以数码或实体方式进行立体建模时，设计师才能准确地解决复杂产品的表面问题**。"
- **只从一个角度观察雕塑式表面**："**雕塑的表面总是需要从不同的角度进行观察**，以确保它们能与邻近的视觉特征和表面相融合。"
- **不注意凸面造型**："**如果不注意凸面的造型，产品会显得过于膨胀。**"
- **无差别地追求复杂表面**：需要根据目标市场判断，简单设计同样有需求。
- **忽略表面间的融合**：表面必须与邻近视觉特征和表面相融合。

## Worked Example

**设计一个"精确坚固"的腕表表面**

1. **选类型**：以**平面 + 倒角（微凸/微凹过渡）**为主，不用强烈的凹凸混合，以传达精确与坚固。
2. **用倾斜控制轻重**：让主体面朝上受光（"在日光或人造光下会显得更轻"），避免大面积向下倾斜把地面阴影反射上来。
3. **加倒角**：边缘做**倒角处理**，使手腕移动时能够**反射光线**，产生随动作变化的高光。
4. **抛光提反射率**：对倒角与小细节做**抛光**，"最大限度地提高其反射率"，从而**凸显精确性**。
5. **借文化原型**：造型灵感取自**经典的飞机驾驶舱仪表**，赋予怀旧感与专业联想。
6. **多角度验证**：以数码或实体方式**立体建模**，从不同角度检查各表面是否与邻近视觉特征相融合。
7. **对照另一端**：若目标市场要动感，则改为复杂表面（如头盔）：下半部做流动交互、上半部用高亮**光影分割动态形状**、以对比材料增加**视觉分离感**。

## Key Takeaways

1. 表面只有三种基本类型：**凸面、凹面、平面**，可自由组合。
2. **倾斜决定明暗**：向下倾斜反射地面色/阴影；向上倾斜在光下显得更轻；褶皱处非常闪亮。
3. **复杂表面的准确处理必须依赖立体建模**；纸上轮廓与渲染不够。
4. 雕塑式表面**必须从多角度观察**，确保与邻近特征融合；**凸面处理不当会显得膨胀**。
5. **倒角 + 抛光**是通过反射光线传达"精确、坚固"的低成本高效手段。
6. 表面复杂度应**匹配目标市场**：动感复杂表面稳妥，简单表面同样有需求。
7. 立体建模阶段，草图线条转化为**闭合线、边缘线、表面折痕、实心或空心部件形状**。
