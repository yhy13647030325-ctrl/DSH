# 第 6 章：线条

## Core Idea
线条有**方向性、能量与关联**三重作用：它既要在三维形态上连续流动，又要与相邻特征形成明确的起点—终点关系，同时用倾斜度调节产品是"静态"还是"有能量"。

## Frameworks Introduced

- **线条的三维流动（本章首个提醒）**：
  - 现象："**平面上勾勒的线条在一个方向或平面上流动时，有时线条会在多个平面上过渡到三维（3D）形态。**"
  - 判据："从侧面看，一条线可能看起来是直的，但从上面看，它可能会沿着三维形态走不同的路径。"（例：头盔顶部线条从侧面看有弧度，从上面看也在另一平面上有弧度，因为它们沿三维轮廓流动。）
  - When to use：任何曲面产品（头盔、鼠标、水壶）的线条检查必须**多视图交叉验证**。

- **视觉持续与关联（本章核心原则）**：
  - 原则："为了表现整个产品的视觉连贯性，**线条应与相邻的视觉特征或所选视图中的其他线条有所关联**。"
  - 合格判据："**如果线条的起点和终点都很明确，并且符合逻辑，那么设计将会更加和谐。**"
  - 案例：剃须刀表面折痕线，**起点是旋转按钮，终点是修剪梳**；这种线条有明确的方向性，**在开始时显得较重、结束时显得较轻**，从而增添视觉能量。
  - 实现手法："这种效果是通过**改变线条横截面的表面深度**，从而改变其下方**阴影的大小**来实现的。"

- **线条的倾斜度与气质**：
  - **倾斜的线条**："可以使产品显得不那么静态"，在增加视觉能量的同时也**增强了产品的姿态**。
  - **纯粹水平或垂直的线条**："可以给人以**力量和坚固**的印象"，这对**需要融入周边环境**的产品很重要。
  - 判断依据：产品定位是"要动感"还是"要稳健"。

- **线条起止的四种特征关系（作者给出的清单）**：
  - **共线、相切、过圆心、相交**。
  - 用途：判断线条之间如何交接才"符合逻辑"。
- **长线条技巧**："沿着产品的长度扫过的线可以让它看起来更长，这在处理相对较短的产品时是一个有用的技巧，这样会使它们看起来更长、更好。"
- **克制原则（本章的纪律要求）**："在选择线条时**必须要有一定的克制力**，因为**设计过度或造型烦琐可能会导致产品的吸引力下降**。"

## Key Concepts

- **视觉持续（visual continuity）**：线条与相邻特征/其他线条的关联性。
- **方向性**：线条从起点到终点的明确走向。
- **线条重量**：通过截面深度与阴影大小控制线条"开始时重、结束时轻"。
- **倾斜线条**：增强能量与姿态。
- **水平/垂直线条**：传达力量与坚固，利于融入环境。
- **共线 / 相切 / 过圆心 / 相交**：线条交接的四种合理关系。
- **长扫线**：使产品视觉上更长的技巧。

## Mental Models

- **Use 多视图交叉验证 when 检查曲面上的线条**：一侧看是直的，另一侧可能走完全不同的路径。
- **Use「起点终点明确且符合逻辑」when 判断线条是否合格**。
- **Use 倾斜 vs 水平/垂直 when 定产品气质**：要能量与姿态用倾斜；要力量与融入环境用正交。
- **Use 截面深度与阴影 when 想让线条"有重量变化"**。
- **Use 共线/相切/过圆心/相交 when 处理线条交接**。
- **Use 长扫线 when 产品偏短**：用一条沿长度扫过的线拉长视觉。
- **Remember 克制 when 面对"再加几条线会更好看"的冲动**：过度设计会降低吸引力。

## Anti-patterns

- **只在单一视图里检查线条**：会漏掉三维流动带来的偏差。
- **线条的起点终点随意**：不符合"明确且符合逻辑"，设计会显得不和谐。
- **在需要动感的产品上使用水平/垂直主线条**：会削弱能量与姿态。
- **需要融入环境的产品却倾斜线条过度**：失去力量与坚固的印象。
- **设计过度、造型烦琐**：直接导致吸引力下降。
- **忽视线条与相邻特征的关联**：破坏整个产品的视觉连贯性。

## Worked Example

**给一把剃须刀梳理表面折痕线**

1. **定关联对象**：折痕线的**起点定为旋转按钮，终点定为修剪梳**——两个都是用户会实际接触的功能特征。
2. **赋予方向性**：让线条从按钮出发、指向修剪梳，形成明确的走向，而不是两头都"没有交代"。
3. **制造重量变化**：让线条**开始时显得较重、结束时显得较轻**，以增添视觉能量。
4. **实现手法**：通过**改变线条横截面的表面深度**，从而改变其下方**阴影的大小**——重的一端阴影大，轻的一端阴影小。
5. **多视图验证**：从侧面、上面分别检查这条线的走向，确认它在三维形态上流动时仍然连贯（如头盔案例所示）。
6. **交接关系检查**：确认该线与相邻线条的交接属于**共线、相切、过圆心、相交**中的合理形式。
7. **克制复核**：确认这条线是必要的、不烦琐的；若只是"看起来更丰富"，应删掉。

## Key Takeaways

1. 线条在**多个平面上流动**，必须多视图交叉验证其连续性。
2. **线条应与相邻视觉特征或同视图其他线条有所关联**；**起点终点明确且符合逻辑**才和谐。
3. 线条可通过**截面深度→阴影大小**获得"开始重、结束轻"的重量变化，从而增添视觉能量。
4. **倾斜线条** = 更强能量与姿态；**水平/垂直线条** = 力量与坚固、利于融入环境。
5. 线条交接的四种合理关系：**共线、相切、过圆心、相交**。
6. **沿长度扫过的线**可使短产品看起来更长。
7. **克制**是线条设计的纪律：设计过度或造型烦琐会导致吸引力下降。
