# 第 2 章：轮廓

## Core Idea
**二维轮廓是造型过程的最佳起点**，因为它定义了产品的边界；轮廓不仅包裹内部组件，还预先传达功能、个性与人体工学信息。

## Frameworks Introduced

- **轮廓优先原则（本章的战略判断）**：
  - "**二维（2D）轮廓是开始造型过程的最佳起点，因为它定义了产品的边界。**"
  - 轮廓是"最外面的形状，通常包裹着机械或电子部件，或者内容物（人、动物或他们的一部分）"。
  - 价值："轮廓是我们在观察产品时**首先注意的方面之一**，它可以提供包括**功能和个性**在内的大量视觉信息。"
  - 人体工学信息：轮廓还可以呈现"用户应该如何使用产品"，**以改善首次使用时的体验**（例：飞利浦蒸汽压力电熨斗的把手形状"意味着这是抓握产品的最佳部位"）。
  - 竞争判据：**"如果产品仅凭其轮廓就能被认出来，那么它们就更有可能在竞争中胜出。"**
  - 轮廓由功能或法规塑造的例子：现代立式真空吸尘器的细长轮廓减少了使用者弯腰的次数，同时减少机体重心和占用空间；超级跑车侧面往往具有**低矮的楔形轮廓**，即使从远处看也比普通车抢眼。

- **配置图（Package Drawing）**：
  - 内容：**呈现内部部件的尺寸和位置**，以此设计两到三种不同的设计选项和人体工学方案。
  - 优点：**"可以让你调整定位或更换内部组件"**（如想移动手持设备中间的发动机，就可以对它进行调整和重新定位）。
  - 缺点：**"使用配置图是准确但耗时的"**。
  - 使用条件：如果产品定位为家用产品，说明书里也必须包含配置图。
  - When to use：需要改动内部组件或需要多种人体工学方案时。

- **设计指南（Design Guide）**：
  - 定义：**将现有产品的 2D 图像作为草图的基础**，帮助快速创建多个可行的概念。
  - 定位：**"它是配置图的快速替代方案，更适用于只需更新样式而非修改内部组件（外观）的产品。"**
  - 使用前必须理解："你要了解为什么现有轮廓的某些区域看起来是这样的，因为新设计可能也需要类似的特征。"
    - 例：熨斗需要**平坦的底板**，后部**支架允许其垂直放置**；新轮廓设计也必须包括这两个元素——**除非设计师能想出更好、更新颖的解决方案**。
    - 底线：**"如果不想改变内部组件位置就不要超出参考线。"**
  - 视角选择（关键判断）：评估哪种视角最适合所选产品——
    - 若不修改内部组件，可选**产品在大部分时间被看到和使用时的外观**；
    - 可通过呈现**视觉上最重要的角度**来吸引客户注意力；
    - 例：**数字收音机前视图很重要；手表则顶视图更有意义**。
  - 制作步骤：**比例打印出 2D 图像 → 在上面放一张坐标纸 → 使用线条较粗的深色描出轮廓和主要视觉特征**；描出的轮廓即可作为基础。

## Key Concepts

- **轮廓（silhouette）**：产品最外面的二维形状，定义边界并包裹内部内容。
- **配置图**：以内部部件尺寸位置为核心的技术性底图。
- **设计指南**：以现有产品 2D 图像为底图的快速草图基础，用于样式更新。
- **参考线**：设计指南中不可越界的边界；不改变内部组件位置就不要超出。
- **功能性轮廓**：不考虑风格、以实用和符合人体工学的方式简单包装产品的轮廓，**是设计新型产品时明智的起点**。
  - "在设计一种新型产品时，明智的做法是画一个纯粹的草图，要有功能性的轮廓，**因为这样可能已经足够独特了**。"
  - 例：像在矩形内部元件周围绘制矩形一样简单；跑鞋和手机这类产品必须具有与内部组件紧密呼应的功能性轮廓，以尽可能紧凑化。
  - 例外与调整空间：有些产品与内部组件之间的距离"可能会更大程度改善人体工程学、稳定性、安全性或风格"（如电视遥控器或电吉他）。
  - 修改许可："如果功能性轮廓不可取或者不适合目标顾客，你可以修改，**不破坏功能的区域**或注入原创人体工学的部分。"
- **草图深化技巧**：许多设计师"会尝试用**轻微的线条重复绘制**，直至找到最理想的方案"；此阶段不必太在意轮廓造型；**一旦做出决定，可以用较粗的笔或施加更大的力度来让线条变得更深更粗**。
- **必须保留的功能性细节**："确保重要的功能性细节设计（如按钮或手柄）针对目标……"

## Mental Models

- **Use 轮廓 when 开始一个造型任务**：先画 2D 轮廓，再考虑细节；轮廓决定边界、也决定客户的第一眼认知。
- **Use「凭轮廓能否被认出」when 评价设计竞争力**。
- **Use 功能性轮廓 when 设计全新产品**：先做"纯粹的功能包装草图"，它可能已经足够独特。
- **Use 视角选择 when 画设计指南**：问"用户大部分时间从哪个角度看它"（收音机→前视；手表→顶视）。
- **Use 配置图 vs 设计指南 when 决定底图方式**：要动内部→配置图（准但慢）；只改样式→设计指南（快）。
- **Think of 参考线 as 不可越界的物理现实**：除非你能提出更好的解决方案，否则保持在内部组件的边界之内。

## Anti-patterns

- **跳过轮廓直接做细节**：违背"轮廓是最佳起点"。
- **在不了解现有轮廓成因时就重画**：可能破坏必需的特征（如熨斗的平坦底板与直立支架）。
- **超出参考线却未改变内部组件位置**：内部件会与外壳冲突。
- **用错视角**：给手表看前视图、给收音机看顶视图，都不是用户最常使用的角度。
- **把功能性轮廓当成最终方案而不做调整**：功能性轮廓不可取时可以修改（不破坏功能的区域）。

## Worked Example

**为一把电熨斗重做轮廓：从设计指南到新轮廓**

1. **确定底图方式**：任务只需更新样式、不动内部组件 → 用**设计指南**而非配置图。
2. **选择视角**：熨斗在使用时主要从**侧视**被看到 → 选侧视图作为底图。
3. **制作底图**：按比例打印现有熨斗 2D 图像；铺上坐标纸；**用较粗深色描出轮廓和主要视觉特征**。
4. **追问轮廓成因**（关键一步）：为什么现有轮廓某些区域长这样？
   - 需要**平坦的底板**（熨烫面）；
   - 后部需要**支架**以允许其垂直放置。
   - 结论：新轮廓**也要包括这两个元素**——除非能想出更好、更新颖的解决方案。
5. **定边界**：既然不改变内部组件位置，新轮廓**不要超出参考线**。
6. **反复勾画**：用轻微的线条重复绘制，直到找到最理想的方案；此阶段不必太在意造型。
7. **定稿**：用较粗的笔或加大力度让线条更深更粗，确保按钮、手柄等**重要功能性细节**被明确画出。
8. **保留人体工学信息**：让轮廓本身表达"应抓握哪里"（如把手形状指示最佳抓握部位），以改善首次使用体验。

## Key Takeaways

1. **2D 轮廓是造型过程的最佳起点**，因为它定义边界并承载功能、个性与人体工学信息。
2. **仅凭轮廓就能被认出的产品更可能在竞争中胜出**。
3. **配置图**（呈现内部部件尺寸位置，准但慢）vs **设计指南**（基于现有 2D 图像，快，适合只改样式）。
4. 用设计指南时必须**先理解现有轮廓为什么长这样**，并保留必需特征（除非有更好的方案）。
5. **视角选择**取决于用户最常看到/使用的角度（收音机→前视；手表→顶视）。
6. **不改变内部组件位置就不要超出参考线**。
7. **功能性轮廓**（不考虑风格的实用包装）是设计新品时可能"已经足够独特"的起点。
8. 草图阶段可用轻微线条反复试探；定稿时加重线条，并确保重要功能细节清晰。
