# 第 9 章：从平面到立体

## Core Idea
把二维草图转成三维形态时，必须处理三类"立体专属"问题：**视角选择、立体比例校验（含比例错觉）、方正感削减**——很多在平面图上成立的设计到了三维会失衡。

## Frameworks Introduced

- **起点：从用户最常看到的视角开始**：
  - "**三维造型设计应从用户最常看到的视角开始。**"（例：产品后部的四分之三视图）
  - 训练法：为现有产品找到**比例相似的合适的三维设计指南**作为底图（这类图片很容易在网上找到）→ **描摹到图纸上** → **添加透视指引和虚化点** → **重复这个过程**，调整一些视觉特征的位置和造型。
  - 进阶：**"当你觉得很自信时，可以尝试在这个视图中重新创造属于自己的设计"**，同时参考已创建的平面设计图；"随着时间的推移和不断练习，你就可以不再需要这些设计指南"；"在有信心的时候，你可以开始在没有设计指南的情况下进行三维造型"。

- **三维造型的指导性原则**：
  1. **准确转移**："你应该将产品平面设计图**准确地转移到**三维草图或模型中去。"（不熟练时可能需要多次尝试）
  2. **尽早建模**："设计师经常在立体草图的早期阶段发挥艺术想象来改善整个产品的视觉流程，**这就是为什么一旦选定概念，就必须尽快进入实物或数字建模阶段**，这样你才能更好地理解和完善产品形态。"

- **立体比例（本章第一步的固定检查）**：
  - "当对一个三维草图进行风格评价时，**你的第一步应该是确保整体比例与最初在平面图上构建的一样**。"
  - 检查项：**宽度、长度和高度的关系**；"如果在包装和功能限制允许之内，则可以对比例进行相应调整"。
  - 关键提醒："还应该**检查和修改视觉特征之间的距离和比例**，因为它们在立体空间中可能会表现出不同的效果，比如**视错觉会造成，当物体与观看者的距离增加时它们会显得更小**。"
  - 工具提示：**Photoshop 是在检验草图比例时有用的工具**，因为可以借助"变换"工具快速进行比例调整。

- **比例错觉（本章最有操作性的技巧）**：
  - 前提：**"如果你的设计整体上需要调整比例，但总体尺寸无法改变"**。
  - 手法："那么可以通过**调整视觉特征来增大或减小产品比例**。"
  - 规律：**"较长的特征使产品看起来更长，而较短的特征则相反。"**
  - 效果："这也可以'**欺骗**'消费者，使其在视觉上看到一个更长或更短的**整体效果**，就能更接近设计师的意图，**但实际上它并没有改变**。"
  - 案例：汀普莱斯对流式电暖器（2008）——一台散热格栅较宽、一台较窄；"虽然从视觉上来看第一个设计看起来比较长，但是**两者其实长度一致**"。
  - 曲率手法："你也可以通过**增加或减小拐角处的曲率**来调整产品在立体空间的外观比例"；飞利浦 HD2636/20 烤面包机（2018）**减小左边曲率**的设计，可以使产品看上去更长。

- **减少方正感**：
  - 判据："当一个设计在三维空间中看起来有点**过于方正**时，可以在其平……"（针对平面/表面做处理，弱化箱形观感）。
  - 与第 7 章的分割、第 8 章的表面处理配合使用。

## Key Concepts

- **用户最常用视角**：三维建模的起点视角，决定呈现效果的第一印象。
- **三维设计指南**：比例相似的三维底图，用于描摹练习。
- **透视指引与虚化点**：描摹时补充的空间线索。
- **立体比例**：宽 / 长 / 高关系 + 视觉特征间距。
- **比例错觉**：通过改变视觉特征长度或拐角曲率，在不改总体尺寸的前提下改变"看起来的大小"。
- **方正感**：三维中显得过于箱形的观感缺陷。

## Mental Models

- **Use 用户最常用视角 when 开始三维建模**：不从不常用的角落视角起手。
- **Use 三维设计指南 + 描摹 + 透视指引 when 练习三维草图**；熟练后脱离指南。
- **Use 宽长高 + 特征间距 when 校验立体比例**：平面成立≠三维成立，尤其要防"距离远显得小"的视错觉。
- **Use 比例错觉 when 总体尺寸无法改变**：**加长视觉特征→显长；缩短→显短**；**减小拐角曲率→显长**。
- **Use Photoshop 变换工具 when 快速试比例**。
- **Use 减方正感处理 when 三维中显得箱形**。
- **Remember 尽早建模**：选定概念后立刻进入实物或数字建模。

## Anti-patterns

- **直接把平面图当成三维结果**：必须准确转移并重新校验比例。
- **只检查整体尺寸而不检查视觉特征间距**：立体空间会产生视错觉（距离增加显得更小）。
- **在总体尺寸不可变时放弃比例调整**：可以使用比例错觉手法"欺骗"视觉。
- **依赖设计指南而不加自己的设计**：应逐步过渡到独立三维造型。
- **让产品在三维中显得过于方正**。
- **概念定了迟迟不进建模**：会失去早期艺术想象改善视觉流程的机会。

## Worked Example

**把两台长度一样的电暖器做成"一长一短"**

1. **确认约束**：整体尺寸/长度**无法改变**。
2. **识别可调对象**：散热格栅属于**视觉特征**，其宽度可调。
3. **应用规律**：**较长的特征使产品看起来更长，较短的特征则相反**。
   - 甲方案：把**散热格栅做宽** → 视觉上显得产品更长。
   - 乙方案：把**散热格栅做窄** → 视觉上显得产品更短。
4. **结果**：两者**实际长度完全一致**，但观感长度不同（汀普莱斯对流式电暖器案例）。
5. **第二条手段（曲率）**：通过**减小某一端的拐角曲率**，也能让产品看起来更长（飞利浦烤面包机案例）。
6. **校验**：用 Photoshop"变换"工具快速试整体比例；检查宽/长/高关系与特征间距，防止因视错觉造成误判。
7. **建模**：一旦确定概念，**尽快进入实物或数字建模**，在立体阶段继续改善视觉流程。

## Key Takeaways

1. 三维造型**从用户最常看到的视角开始**；练习可用比例相似的**三维设计指南**描摹，并添加透视指引与虚化点。
2. **平面设计图必须被准确地转移到**三维草图或模型中；不熟练时需多次尝试。
3. 三维风格评价的**第一步是确保整体比例与平面图一致**，并检查**宽/长/高关系**与**视觉特征之间的距离和比例**。
4. 立体空间存在**视错觉**（物体距离观看者越远显得越小）。
5. **比例错觉技巧**：总体尺寸不变时，加长视觉特征→显长，缩短→显短；**减小拐角曲率**→显长。
6. 设计在三维中**过于方正**时需要专门处理以削减方正感。
7. **一旦选定概念，必须尽快进入实物或数字建模阶段**。
