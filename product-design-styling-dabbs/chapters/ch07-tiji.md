# 第 7 章：体积

## Core Idea
体积设计的任务是**减少大块体的呆板感**：通过分割、复刻、加点与调整，让笨重的整体产生**视觉分离度**而显得更轻、更有层次。

## Frameworks Introduced

- **体积评价的起点**：
  - "当评价一个产品的体积时，**首先要突出那些在视觉上可以改进的地方**。"
  - 问题诊断："图 7.4 左边的主机外观保守，看起来很普通，这是因为**缺乏视觉信息和箱形轮廓**。"

- **减少呆板的三种选择（作者给出的清单）**：
  1. **可以向内复刻原部件的形状**，创造一个与原体积和谐的小部件；
  2. **也可以添加新的细节**，如形状或线条，以增加**视觉分离度**；
  3. **还可以调整表面部件**以改善视觉分离度。
  - 三条路径的共同目标是：把"一整块"变成"看得出结构的多块"。

- **分割法（汽车尾部案例）**：
  - 观察：**"汽车的尾部在平面图里看起来通常是很大的"**。
  - 做法："设计师把它**分割成若干较小的部位**，以减少视觉上的笨重感，**增加趣味性**。"
  - 例：沃尔沃 XC coupé 概念车（2014）的尾部被分为**四个主要部分**；车灯、排气管、车牌和后导流板的形状"为汽车增添了个性，视觉层次更清晰"。
  - 反证："如果没有这些部件区分，车辆尾部看上去就会呆板、无趣。"
  - 行业语（米歇尔·帕加诺，汽车设计师）：**"建立各部件间的绝佳平衡，以确保所有部件都适得其所。"**

- **不对称的取舍**：
  - 案例：戴尔灵越 5680 游戏台式主机（2018）有着**沿对角线设计的散热格栅**，把外形不对称地分成两个部分。
  - 判据："**不对称的产品往往不如对称的好看**，但在本设计中，该设计比其他方案更引人注目，因为**我们的眼睛还没有习惯这种形式**。"
  - 结论："**不对称设计值得尝试，但也取决于目标客户群体的喜好。**"

- **有机部件的整合**：飞利浦 Saeco 咖啡机（2010）的设计者"增加了有机部件。这些都被转化为**流动部件以整合外形设计**，好用来模拟咖啡流动的样子。"

## Key Concepts

- **视觉分离度**：把整体划分出可辨识部件，从而降低视觉重量、增加层次的机制。
- **分割**：把大体块拆成若干较小部位。
- **内向复刻**：向内复制原型形状，做出与原体积和谐的**小部件**。
- **视觉信息**：让形体"有东西可看"的细节；缺乏视觉信息 = 看起来普通。
- **不对称分割**：以对角线等方式打破对称，靠"新鲜感"取胜。
- **体积与轻量错觉**：减去一部分并不总能实现，设计师"更倾向于增添实体部件来增加视觉分离"。

## Mental Models

- **Use 三手法清单（内向复刻 / 加细节 / 调表面）when 某个体块显得笨重**。
- **Use 分割 when 大面积平整区域**：分割出的部件本身就是"趣味点"。
- **Think of 缺乏视觉信息 as 普通感的根源**：箱形轮廓 + 无细节 = 保守。
- **Use 对角线不对称 when 想要比对称方案更醒目**：代价是牺牲"好看"的常规判断，需目标客户认可。
- **Use 流动部件 when 想把分散的形体整合起来**：用一个连续部件统一外形。

## Anti-patterns

- **任由大面积完整表面存在**：缺少视觉分离度，显得笨重。
- **为减重而强行剔料**："通过剔除一部分来减轻体积的视觉效果**并不总是可行的**"。可用"侧面下部向里削刻出较大的留白与主体相呼应"来缓解（婴儿座椅概念图，2008）。
- **无条件采用不对称**：不对称通常不如对称好看，只有"眼睛还没习惯"时才占优势，且取决于目标客户。
- **分割过多而无主次**：会失去"各部件适得其所"的平衡。
- **只加装饰细节而不建立分离度**：细节必须服务于"把体块区分开"这一目标。

## Worked Example

**把一台"又笨又普通"的机箱做轻**

1. **诊断**：左边主机外观保守、很普通——原因是**缺乏视觉信息和箱形轮廓**。
2. **选手法**：从三种中选择组合使用——内向复刻、添加形状/线条细节、调整表面部件。
3. **中间方案示范**：同样箱形轮廓，但用**银色有弧度的部分来修饰**，让人们的**视线从轮廓的直边上移开**（对应"调整表面部件/追加有弧度装饰"）。
4. **进阶方案**：在形状和细节上**增加主体的分离度**，使产品更具特色，并**在视觉上让产品变轻**。
5. **若采用不对称**：沿对角线设计散热格栅，把外形分成两个部分；确认"比其他方案更引人注目"，并核对目标客户群是否接受。
6. **若需整合**：加入**有机/流动部件**把外观统一起来（咖啡机案例）。
7. **收口判据**：检查各部件是否"**适得其所**"，整体是否从"一整块"变成"看得出结构的多块"。

## Key Takeaways

1. 体积设计的核心是**减少呆板、增加视觉分离度**。
2. 三种手法：**向内复刻出和谐小部件 / 添加形状与线条细节 / 调整表面部件**。
3. **分割**是应对大面积体块的主力手法（汽车尾部分成四个主要部分）。
4. 缺乏**视觉信息** + **箱形轮廓** = 普通、保守的观感。
5. **剔除材料来减重并不总是可行**；设计师更倾向**增添实体部件**来建立分离。
6. **不对称值得尝试**，因为"眼睛还没习惯"，但通常不如对称好看，且取决于目标客户。
7. 目标是"**各部件间的绝佳平衡，确保所有部件都适得其所**"。
