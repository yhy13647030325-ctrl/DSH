# 速查表（Cheatsheet）

## 决策规则

| 情形 | 决定 |
|---|---|
| 开始造型任务 | 从 **2D 轮廓**入手（它定义边界） |
| 需要动内部组件 | 用**配置图**（准确但耗时） |
| 只改样式 | 用**设计指南**（快）；先理解现有轮廓为何长这样 |
| 决定用哪个视角 | 选**用户大部分时间看到/使用**的角度（收音机→前视，手表→顶视） |
| 不知该不该超出参考线 | 不改变内部组件位置就**不要超出** |
| 造型构思卡壳 | 过一遍**奥斯本七动词**（替代/放大/适应/修改/改编/消除/组合） |
| 团队对方向有分歧 | 用 **SDS** 让客户标出"理想设计"位置；结果只作指导 |
| 需要主题灵感 | 抓**时代精神**（识别潮流后决定追随或避免） |
| 要把主题变语言 | 做**情绪板**，取元素时"**精妙地取舍**" |
| 做品牌系列 | 建立**品牌基因**（轮廓/线条/形状/表面/材料/颜色） |
| 担心第一稿太满意 | **必须**再做多个造型选项 |
| 造型别扭但说不清 | 先怀疑**比例**："如果一个产品看起来不太对劲，通常是由比例上的不完美导致的" |
| 想把产品做薄 | **从配置图入手找妥协**，尽早与工程团队谈比例 |
| 需要原创形状 | **形状四步**：可改性→选相关原形→抽象化→简化（感受得到特性、看不出出处） |
| 要动感姿态 | **倾斜**设计、重心前移；用动态三技巧（拉升一侧边缘/消灭垂直线/底部弧线） |
| 要稳重形态 | 稳定外形 + 重量**均衡分布在支撑点**上 |
| 要个性与辨识度 | 用**姿势形态**（借一个有姿态的形象） |
| 线条凌乱 | 让线条**与相邻特征建立关联**，起点终点明确且符合逻辑 |
| 线条缺能量 | 让它**开始重、结束轻**（改截面深度→改阴影大小） |
| 要能量还是坚固 | 倾斜线条→能量与姿态；水平/垂直线条→力量与坚固、融入环境 |
| 产品显得太短 | 用**沿长度扫过的线** |
| 想继续加线条 | **克制**——设计过度会降低吸引力 |
| 体块呆板笨重 | 三手法：**内向复刻 / 加形状与线条细节 / 调表面部件** |
| 大面积体块（如车尾） | **分割**成若干较小部位，增加趣味与层次 |
| 想用不对称 | 可试，但通常不如对称好看；确认目标客户接受 |
| 形体散 | 用**流动部件**整合外形 |
| 表面设计 | 识别**凸/凹/平面**并组合；凸面不当会显膨胀 |
| 想控制局部轻重 | 表面**向下倾斜**→反射地面色；**向上倾斜**→显得更轻；褶皱→闪亮 |
| 要传达精确坚固 | 边缘**倒角 + 抛光**提高反射率，借经典原型（驾驶舱仪表） |
| 总体尺寸不能改但比例不佳 | 用**比例错觉**：加长视觉特征→显长；缩短→显短；减小拐角曲率→显长 |
| 三维中显得方正 | 做**减方正感**处理 |
| 立体比例评价第一步 | 确保**整体比例与平面图一致**，并查**宽/长/高 + 特征间距** |
| 部件过大不协调 | **分成多个部分并使其颜色变深**（主色非黑/深色时才有效） |
| 某部位应退后 | 用**深色基调**弱化（如汽车深色立柱） |
| 要强调重要功能 | 用**金属色/金属材料**（镀铬条），但需谨慎 |
| 医疗产品选色 | 用**平静柔和的色彩**（考虑患者精神状况与环境） |
| 想让产品"多彩" | **零星色彩的点缀**优于整体上色 |
| 选色前 | **了解目标客户群的好恶**；不要只靠颜色吸引特定性别 |
| 选材料 | 过**四自问**：功能 / 客户积极联想 / 造型增益与触感 / 差异化 |
| 想让产品出类拔萃 | 用**与品类无关的材料**（如木质外壳耳机） |
| 概念已定 | **尽快进入实物或数字建模**；复杂产品需多次绘制三维视图 |
| 汇报/评审 | 用颜色**标注主要用户交互点** |

## 决策树

```
造型做完仍"看起来不对劲"？
├─ 比例问题 → 视觉点对齐（同水平线/垂直线）→ 仍不行则用比例错觉
├─ 姿态问题 → 要动感：倾斜 + 消灭垂直线 + 底部弧线
├─ 体积问题 → 三手法（内向复刻/加细节/调表面）；大面积则分割
├─ 线条问题 → 建立关联对象（延伸到把手与轮廓），去掉无来由的线
└─ 表面问题 → 凸/凹/平面组合；倾斜控光；倒角抛光

产品显得重 / 笨？
├─ 体块完整无分割 → 用视觉特征（指示窗/格栅/车灯）分割主体
├─ 大面积平整 → 增加视觉分离度（细节/表面部件调整）
├─ 想显轻 → 向上倾斜表面；镂空（锤颈）；不规则轮廓减方正感
└─ 材质反差过大 → 用深色弱化不吸引人的部分

要在竞争中脱颖而出？
├─ 造型层面 → 形状四步（抽象化 + 隐藏出处）
├─ 材质层面 → 跨界材料（四自问校验）
├─ 颜色层面 → 色彩对比分区 / 金属强调 / 零星点缀
└─ 主题层面 → 时代精神 + 情绪板 + 品牌基因
```

## 阈值与默认值

| 项 | 值／判据 |
|---|---|
| 配置图方案数 | **2~3 种**设计选项 |
| 造型选项数 | 多个（**无论第一张多好都要做多个**） |
| 表面基本类型 | **3 类**：凸面、凹面、平面 |
| 线条起止的合理关系 | **4 种**：共线、相切、过圆心、相交 |
| 奥斯本动词 | **7 个**：替代/放大/适应/修改/改编/消除/组合 |
| 比例的判断依据 | 长与高关系 + 视觉特征匹配关系 |
| 概念到建模 | **选定概念后尽快**进入实物或数字建模 |
| 三维视图的常规次数 | 复杂产品需**多次**绘制 |
| 材料检验 | **4 个**自问 |
| 单椅身的标准流程 | 基准图→轮廓→比例→形状→姿态/体积→线条→表面→3D→渲染 |

## 识别信号

- 两个视觉点**不在同一水平线或垂直线**上 → 设计显得不平衡。
- 产品"看起来不对劲"却找不到原因 → **比例**不完美。
- 设计"缺乏视觉信息 + 箱形轮廓" → 观感普通、保守。
- 大面积表面**没有任何分割或细节** → 笨重、呆板。
- 设计师"一直在尝试不同的线条和形状" → 线条缺乏关联对象，画面凌乱。
- 某特征**以角度横跨主体** → 正在承担"分割体积、减轻视觉笨重感"的功能。
- 表面**向下倾斜** → 会反射地面颜色/阴影（显重）。
- 表面**向上倾斜** → 在光下显得更轻。
- 产品**过于方正** → 需要专门削减方正感。
- 主色是**黑色或深色** → "加深分区"的对比手法**失效**。
- 组成部件**尺寸很大** → 用色彩分成多部分并加深。
- 用户**主动擦拭屏幕** → 光泽是真实的高价值属性。
- 使用**与品类无关的材料** → 正在走"出类拔萃"路线。
- 造型一切正常但**迟迟不建模** → 正在错过改善视觉流程的窗口。
