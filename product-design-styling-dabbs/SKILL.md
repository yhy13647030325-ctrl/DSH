## 核心框架与思维模型

### 1. 全书主线：一条可复用的造型流程
**视觉主题 → 轮廓 → 比例 → 形状 → 形态（姿态）→ 线条 → 体积 → 表面 → 从平面到立体 → 色彩 → 材料与质感 → 项目演练**

每一章的造型抓手都是独立可控的变量，评审时先定位"问题出在哪一环"。

### 2. 视觉主题三工具（第 1 章）
- **奥斯本清单（7 动词）**：替代 / 放大 / 适应 / 修改 / 改编 / 消除 / 组合。
- **SDS（语义差异量表）**：让客户在对立属性上标出"**理想设计**"的位置；结果**只能作为指导**（"人们并不总是与先进的设计和造型合拍"）。
- **时代精神（Zeitgeist）**：识别当下文化潮流后**追随或避免**（尾翼时代→易用美学→环保高效/蜂巢六边形）。
- **情绪板 → 精妙的选取**：不可复制，也不可模糊；"**你与目标客户的联系越紧密，视觉设计就会越成功**"。
- **品牌基因**：以匹配的**轮廓、线条、形状、表面、材料或颜色**把产品线联结为一个家族。

### 3. 轮廓是起点（第 2 章）
**2D 轮廓是造型过程的最佳起点**，因为它定义边界。**仅凭轮廓就能被认出的产品更可能在竞争中胜出。**
- **配置图**（呈现内部部件尺寸位置，准确但耗时）vs **设计指南**（基于现有 2D 图，快，适合只改样式）。
- 视角选择：**用户大部分时间看到的角度**（收音机→前视；手表→顶视）。
- 底线：**不改变内部组件位置就不要超出参考线**。

### 4. 比例与比例错觉（第 3、9 章）
- 比例 = **长与高的关系 + 视觉特征之间的匹配关系**；"**比例可以区分毛驴和赛马**"。
- 比例受**功能、人体工学、内部工艺、环境、法规、成本**六因素影响；**纤薄**是长期有效的信号，但需**内部重构**支撑。
- **比例错觉**（总体尺寸不可变时用）：加长视觉特征→显长；缩短→显短；**减小拐角曲率**→显长。

### 5. 形状的抽象化四步（第 4 章）
①确认功能形状可改 → ②选一个与主题相关的原形 → ③**抽象化并简化** → ④让客户**感受得到特性、看不出出处**（如从鹰头提炼速度与敏捷）。

### 6. 形态（姿态）三分法（第 5 章）
- **动态形态** = 重心偏移 → 制造"即将倾倒"的错觉。三技巧：**拉升一侧边缘 / 消灭垂直线条 / 底部做弧线**。
- **静态形态** = **重量均衡分布在支撑点**（如吐司机的四脚）。
- **姿势形态** = 借一个有姿态的形象（"弯腰的人"）赋予个性。

### 7. 线条三条规律（第 6 章）
- **关联**：线条应与相邻视觉特征或同视图其他线条有关联；**起点终点明确且符合逻辑**。
- **重量**：通过**改变线条横截面的表面深度**改变阴影大小，实现"**开始重、结束轻**"。
- **倾斜度**：**倾斜线条** = 能量与姿态；**水平/垂直线条** = 力量与坚固、利于融入环境。
- 纪律：**必须要有一定的克制力**——设计过度会降低吸引力。

### 8. 体积：把"一整块"变成"看得出结构的多块"（第 7 章）
三手法：**内向复刻**出和谐小部件 / **添加形状与线条细节** / **调整表面部件** → 增加**视觉分离度**。
- 大面积（如汽车尾部）→ **分割成若干较小部位**。
- **不对称**值得尝试（"眼睛还没习惯"），但通常不如对称好看。
- 目标：**"各部件间的绝佳平衡，确保所有部件都适得其所。"**

### 9. 表面：三种类型 + 光影（第 8 章）
**凸面 / 凹面 / 平面**的组合；**向下倾斜反射地面色（显重）、向上倾斜显得更轻、褶皱处非常闪亮**。
**倒角 + 抛光**用来反射光线、传达"精确与坚固"。
**复杂表面的准确处理必须依赖立体建模**，并**从多角度观察**；**凸面处理不当会显得膨胀**。

### 10. 从平面到立体（第 9 章）
- 从**用户最常看到的视角**开始；用**三维设计指南**描摹并添加**透视指引与虚化点**。
- 立体评价第一步：**确保整体比例与平面图一致**，检查宽/长/高关系与**视觉特征间距**（立体空间有视错觉）。
- **一旦选定概念，必须尽快进入实物或数字建模阶段**；复杂产品需多次绘制三维视图。

### 11. 色彩：最强的作用是增强对比度（第 10 章）
- **把主体分成多个部分并使其颜色变深** → 弱化过大的部件；**主色为黑/深色时该手法失效**。
- **深色基调弱化**不吸引人的部分（汽车深色立柱）；**金属色/金属材料强调**重要功能（镀铬条）。
- 语义：红色→应急/关键操作；柔和→医疗；白色→清洁/中性。
- **零星色彩的点缀比整体上色更"多彩"**（拉姆斯）；**不要只靠颜色吸引特定性别客户**。

### 12. 材料与质感的四自问（第 11 章）
①是否满足**功能需求**？②什么材料让**目标客户产生积极联想**？③是否**增强造型**、触感是否改善体验？④**不常用于该品类的材料**是否有助于脱颖而出？
**"新颖的材料选择可以使产品出类拔萃。"**（如木质外壳耳机传达温暖、环保）

### 13. 项目造型：全流程演练（第 12 章）
**基准图 → 轮廓 → 比例 → 形状 → 姿态/体积 → 线条 → 表面 → 3D 绘图 → 3D 渲染**
- 比例阶段：让**大多数视觉点与相邻点处于同一水平线或垂直线上**。
- **"如果一个产品看起来不太对劲，通常是由比例上的不完美导致的。"**
- 五个案例主题：坚固激进（头盔）/ 动感冒险（锤子）/ 简洁明快（咖啡机）/ 柔性友好（剃须刀）/ 综合示范（水壶）。
