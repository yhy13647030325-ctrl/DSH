# 判据与参数速查（Cheatsheet）

> 全部出自《SOLIDWORKS® 高级曲面教程（2017 版）》。页码为 PDF 页。

## 一、核心判据（三句话）

| # | 判据 | 页码 |
|---|---|---|
| 1 | **实体的任意一条边线同时属于且只属于两个面；曲面的边线可只属于一个面** | p14 |
| 2 | **除了 A 级曲面以外，相切连续（C1）可以被广泛接受** | p25 |
| 3 | **曲面通常只是通往实体的中间步骤** | p24 |

## 二、连续性三级

| 级别 | 名称 | 判据 | 用途 |
|---|---|---|---|
| C0 | 位置连续 | 接触，有可见夹角 | 不够 |
| **C1** | 相切连续 | 相切，但曲率半径可变 | **除 A 级外通用** |
| **C2** | 曲率连续 | 相接处**曲率半径相同** | A 级曲面 |

- 满足 C2 必满足 C0 与 C1
- C1 不够的原因：**曲率半径骤变**（例：曲面 65mm 接平面无穷大）
- **验证**：【误差分析】→ **0° = 相切；90° = 垂直**

## 三、四类曲面

| 类型 | 判据 | 归属 |
|---|---|---|
| 代数曲面 | 简单代数公式；U-V 是直线/圆弧 | 解析曲面 |
| 直纹曲面 | **每点都有直线穿过且在面上** | 解析曲面 |
| 可展曲面 | **直纹子集，未拉伸状态可展开** | 解析曲面 |
| NURBS | U-V 都是样条，样条间插值 | **数值曲面** |

**可展曲面 = 钣金展开的基础。**

## 四、U-V 参数

| 项 | 值 |
|---|---|
| 参数取值 | **0 ～ 1** |
| 参数中心 | **U0.5 V0.5** |
| 查看命令 | **【面部曲线】** |
| 能网格预览的特征 | 圆顶、变形、填充曲面、边界曲面、自由形、放样曲面 |

**非 4 边曲面的两个成因**：
1. **退化曲面**：边长为零、曲线交于一点（**奇点**）；主因 **圆角、抽壳、等距**
2. 4 边曲面剪裁后抽壳 —— 一般不出问题（系统先等距再剪裁）

## 五、检查曲面闭合三法

1. **加厚**——只有全封闭时【从闭合的体积生成实体】才可用
2. **【检查实体】**——高亮开环边线
3. **看边线颜色**是否符合【系统选项】>【颜色】>【曲面，开环边线】

**前置**：【显示/选择】勾**【以不同的颜色显示曲面的开环边线】**。

| 边界 | 边界曲面 |

## 八、转换工具对照

| 方向 | 工具 |
|---|---|
| 实体 → 曲面 | 【删除面】+【删除并修补】 |
| 实体面 → 复制为曲面 | **【等距曲面】**（距离 0） |
| 曲面 → 实体 | 【加厚】、【缝合曲面】+【创建实体】 |
| 曲面合并 | 【缝合曲面】 |
| **（无）** | **没有"反缝合"命令** |

## 九、混合建模四种手段

| 目的 | 工具 |
|---|---|
| 用曲面编辑实体 | 替换面、使用曲面切除、成形到一面/实体、到离指定面指定距离、曲面圆角 |
| 实体↔曲面转换 | 删除面、加厚、缝合、等距曲面 |
| 曲面作构造几何 | 交叉曲线、曲面剪裁、**直纹曲面定拔模**、曲面圆角作相切参考 |
| 由曲面直接建实体 | 加厚（可对**开环曲面**） |

## 十、导入格式优先级

| 序 | 格式 | 说明 |
|---|---|---|
| 1 | **Parasolid** | **SOLIDWORKS 建模内核，可直接读取不需转换** |
| 2 | ACIS | 不易出错 |
| 3 | STEP | 不易出错 |
| 4 | **IGES** | **最易出错，尽量不用** |

**注意**：所有中性格式**都不含创建历史**（只定义面/边/顶点）。

## 十一、修补七法（按成本）

| 序 | 方法 |
|---|---|
| 1 | 改变输入类型（换格式） |
| 2 | **改变精度（降低默认精度可让模型自动缝合）** |
| 3 | 输入为曲面（修补→缝合→加厚） |
| 4 | 延伸曲面 |
| 5 | 剪裁曲面 |
| 6 | 删除曲面 + 替代 |
| 7 | 填充曲面 |

## 十二、输入诊断的两个限制

| 限制 | 说明 |
|---|---|
| **仅当输入特征是零件的唯一特征时可用** | 加了别的特征就用不了 → 先诊断再建模 |
| "以后不要再问"关掉后 | 在【系统选项】>【高级】中恢复 |

## 十三、FeatureWorks 成功率

| 零件类型 | 成功率 |
|---|---|
| **棱柱状零件** | **较高** |
| **自由形态消费品零件** | **较低** |

## 十四、主模型技术对照

| 技术 | 类型 | 曲面可用 | 父零件生成特征 |
|---|---|---|---|
| 【插入】>【零件】 | 推动 | **可用** | **否** |
| 插入到新零件 | **牵引** | **可用** | 否 |
| 分割 | 推动 | **不可用** | 是 |
| 保存实体 | 推动 | **不可用** | 是 |

- **推动仅对实体模型起作用**
- **曲线实体不能被转移** → 用 3D 草图 + 转换实体引用 + 解除吸收的草图绕过

## 十五、质量检查三件套

| 手段 | 作用 |
|---|---|
| **高反射材质** | 让缺陷显形；理想状态是接缝处看不出缝 |
| **图像品质设高** | 品质低会掩盖裂缝，甚至制造假裂缝 |
| **强光源**（无 RealView 时） | 补充反射观察条件 |

## 十六、五个"必须记住"的隐性事实

| # | 事实 | 出处 |
|---|---|---|
| 1 | 实体建模**后台就是曲面建模**（先建面再缝） | ch01 |
| 2 | 曲面**不能做布尔操作**，必须手工剪裁或缝合 | ch01 |
| 3 | 拔模**在建模初期用直纹曲面定**，不是事后加 | ch05 |
| 4 | 复杂接合**不能用圆角**，要剪裁+放样+填充 | ch06 |
| 5 | 剪裁轮廓在曲面建模里**常常故意不完全定义** | ch06 |
