# 可复用套路（Patterns）

> 从 7 章归纳的可操作系统。标 **（提炼）** 处为归纳。

## 模式一：判断"该用曲面还是实体"

**何时用**：开始一个新零件，不确定用哪套方法。

```
① 实体命令能不能一次做出这个形？
     ├ 能 → 用实体（更快、更稳、有自动检查）
     └ 不能 → ②
② 是否因为"一条边线同时属于 4 个面"而做不出？
     ├ 是 → 必须用曲面
     └ 否 → ③
③ 是否需要"一次只做一个面"、每个面用不同技术？
     ├ 是 → 用曲面
     └ 否 → 用实体
④ 只是需要"参考面"来定终止/拔模/切割？
     └ 做一个局部曲面当构造几何体，主体仍用实体（混合建模）
```

**判据来源**：第 1 章 1.1.1（边线归属）、1.3（四条理由）、1.3.1（两条不该用）。

**陷阱**：**默认"曲面更高级"**。原书明确"假如经过相同数量的操作步骤便可以得到所需的实体，那么用户就应该选用实体建模"。

## 模式二：曲面建模七步流程

**何时用**：任何自由曲面零件。

```
① 插图片    —— 一开始就插，草图要改名
② 规划草图  —— 关键特征、总体尺寸、驱动轮廓
③ 找对称/边线 —— 中心到原点；投影曲线 / 3D 样条 / 轮廓边线
④ 定功能面  —— 有功能面的从它开始（瓶颈要圆、要有平基座）
⑤ 频繁检查  —— 每完成重要步骤就【检查】+【重建验证】
⑥ 建文件夹  —— 特征可能数百个，按区域归类
⑦ 最后清除  —— 【删除实体】清掉中间产物
```

**来源**：第 1 章 1.5。

## 模式三：C1 还是 C2 的决策

**何时用**：任何曲面相接处。

```
这个面会被看到/摸到吗？
├ 不会（内部结构）→ C0 即可
└ 会 → 是 A 级曲面（外观主面、高光反射件）吗？
      ├ 是 → 必须 C2（曲率连续）
      └ 否 → C1（相切连续）可被广泛接受
```

**判据**：「除了 A 级曲面以外，相切连续可以被广泛接受。」
**验证法**：【误差分析】→ **0° = 相切，90° = 垂直**。
**视觉验证**：高反射材质 + 高图像品质 + 强光源，看接缝处有没有缝。

## 模式四：拔模前置（本章最有价值的一条）

**何时用**：任何需要拔模的自由曲面塑件。

```
① 先画分型线（草图 + 套合样条曲线，保证 C2 光滑）
② 【直纹曲面】类型 = 【锥削到向量】
     距离 = 12mm（够大即可，不重要）
     参考向量 = 与拔模方向垂直的基准面 + 【反向】
     角度 = 需要的拔模角（如 3°）
     边线 = 分型线
     检查锥形"向外"，不对就点【交替边】
③ 后续放样/扫描的轮廓，与直纹曲面边线加【相切】
     → 曲面自然带该角度拔模
```

**为什么不能事后加拔模**（原文）："一般来说用户不会在本地特征创建完毕后再来插入拔模特征。"
**来源**：第 5 章步骤 17 + 步骤 20-2。

## 模式五：接合四步（复杂相接处）

**何时用**：两根以上的管子/臂要接成整体（T/X/K/Y 形）。

```
① 剪裁定过渡区
     太短 → 褶皱
     太长 → 要加更多面块
② 剪裁出"分割边界"（不是完整轮廓）
     理由：一个特征接不了所有实体，必须分段
③ 分段放样
     轮廓 = 相邻管件的边界
     约束 = 曲率（做不到时退到相切）
     接头错位就拖接头；【应用到所有】可清除以单独控制
④ 填充修补
     边线设定优先【曲率】，不行用【相切】+ 误差分析验证
⑤ 缝合（缝隙控制）→ 高反射检查
```

**来源**：第 6 章 6.1.1 + 6.2。

## 模式六：破面修补七法（按成本排序）

**何时用**：导入的模型是坏的。

| 序 | 方法 | 成本 | 说明 |
|---|---|---|---|
| 1 | 换格式 | 最低 | Parasolid > ACIS > STEP > IGES |
| 2 | 调精度 | 低 | **降低**缝合精度能让模型自动缝上 |
| 3 | 输入为曲面 | 中 | 不做实体，改为曲面后修 |
| 4 | 延伸曲面 | 中 | 面太短接不上 |
| 5 | 剪裁曲面 | 中 | 面超出 |
| 6 | 删除+替换面 | 高 | 修不好的面直接换 |
| 7 | 填充曲面 | 高 | 补最后缺口 |

**预防优于修补**：让对方**导出时调精度**。

## 模式七：四种达到同一结果的做法（选哪个）

**何时用**：要用曲面去修饰实体。

原书给的四种（电吉他案例）：
1. 拉伸 + 【成形到一面】/【成形到实体】
2. 拉伸切除 + 【成形到一面】/【成形到实体】
3. 【使用曲面切除】
4. 【替换面】

**判据（原文）**：「至于哪种方法更佳，针对不同的案例，**答案也是不一样的**。」

**选择提示（提炼）**：

| 情境 | 倾向 |
|---|---|
| 只需切掉一半 | 使用曲面切除 |
| 要用曲面定义新表面 | 替换面 |
| 拉伸时就该停在曲面上 | 成形到一面/实体 |
| 曲面是开放的、只作边界 | 成形到一面 |

## 模式八：主模型分件

**何时用**：一个外形要拆成多个零件。

```
需要联动吗？
├ 需要 → 主模型
│    ├ 曲面主模型 → 【插入】>【零件】/ 插入到新零件
│    └ 实体主模型 → 分割 / 保存实体（或上面两种）
└ 不需要 → 普通建模，各自独立

选推动还是牵引？
├ 父改要推给子 → 推动（分割/保存实体，仅实体）
└ 子要取父的东西 → 牵引（插入到新零件）
```

**两条限制**：**曲面不能被分割/保存实体；曲线实体不能被转移。**

## 反模式清单

| 反模式 | 表现 | 后果 |
|---|---|---|
| **默认用曲面** | 简单棱柱件也用曲面做 | 慢、脆、难改 |
| **留开放的曲面** | 项目做完还是开放曲面 | 原书：曲面只是通往实体的中间步骤 |
| **拔模事后加** | 特征做完再加拔模 | 曲面变形/失败 |
| **用圆角做复杂接合** | 相贯处直接倒圆 | 做不出受控过渡 |
| **过渡区随便定** | 不做剪裁规划 | 短了褶皱、长了多块 |
| **不做接缝检查** | 只用默认显示 | 图像品质会掩盖裂缝 |
| **接合想一步到位** | 一个放样接所有管 | 原文：不可能 |
| **修补从填充开始** | 破面直接填充 | 成本最高；应先换格式/调精度 |
| **直线圆弧拼轮廓** | 不用套合样条 | 狭长面、短边、圆角抽壳不稳 |
| **不组织特征树** | 几百个特征平铺 | 无法维护 |
