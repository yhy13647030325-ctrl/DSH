> **★★★ 判据：CMF 不是"选颜色 + 选材料"，是三个维度的组合决策。**
> 同一材料 + 不同表面 = 完全不同的产品（不锈钢：镜面 >95% vs 喷砂 1–10%）。

### 1. 材料的五个维度（p71）
**engineering（技术）→ product use（使用）→ environment（环境）→ aesthetics（美学）→ emotion（情感）**
原文措辞极精确：美学是**第四个**，情感是**第五个**。前三个给阈值，后两个给方向。

### 2. 属性的四层递进（p44–45）
**① 美学属性**（直接作用于感官：含 form, color, texture）→ **② 联想属性**（时间/地点/事件/人/文化）→ **③ 感知属性**（反应：精致/现代/幽默）→ **④ 情感属性**（它让你感觉如何）。
> **★★★ CMF 能"定"的只有第 ① 层；②③④ 只能押注 + 验证。**

### 4. 材料指数（p226–p227，表 7A.3 全表）

| Function | 场景 | **Minimize** |
|---|---|---|
| Tie，最小重量，刚定 | 轻量拉索 | **ρ/E** |
| Beam，最小重量，刚定 | 飞机翼梁、球杆 | **ρ/E^½** |
| Beam，最小重量，强度定 | 汽车悬臂 | **ρ/σ_y^(2/3)** |
| Panel，最小重量，刚定 | 车门板 | **ρ/E^(1/3)** |
| Panel，最小重量，强度定 | 桌面 | **ρ/σ_y^(1/2)** |
| Column，最小重量，屈曲定 | 液压推杆 | **ρ/E^½** |
| Spring，最小重量，储能定 | 航天回位弹簧 | **E·ρ/σ_y²** |
| **Natural hinge**，最大变形不断 | **廉价活铰** | **E/σ_y** |

> **★★★ 判据：材料指数是"功能 + 目标 + 约束"三元组的函数，不是属性本身。**
> 同一材料，梁是 ρ/E^½，板是 ρ/E^(1/3)，活铰是 E/σ_y。**说"这个材料好不好"没有意义。**

### 5. Ashby 选材四步（p141，**原文措辞**）

> **重要**：本书原文四步是 **`Translation → Analysis → Identification → Screening + Ranking`**。
> **流行简写 `translate → screen → rank → document` 在本书中不存在**（`document` 全库 0 命中）。本技能以原文为准。

1. **Translation** — 把非技术表述翻译成目标与约束
2. **Analysis** — 分析构件，识别性能指标并写成方程
3. **Identification** — 从方程中识别决定性能的材料属性
4. **Screening + Ranking** — 筛除不满足约束者，再按性能指标潜力排序

> **★★★ 判据：约束写"能/不能"（二值），目标写"求最小值"（连续）。**
> 图 7.4 的形态就是：**三行约束做筛，一行目标做排。**

### 6. 光泽六级（p82，图 4.13，**F 层唯一公共标尺**）
测量条件：**入射 60°，观测 120°**
**Dead matte <1% ｜ Matte 1–10% ｜ Eggshell 15–20% ｜ Semi-gloss 40–50% ｜ Full gloss >80% ｜ Mirror >95%**

### 7. 表面工艺的量化五列（p360–p383）
`Surface hardness (Vickers) / Coating thickness (μm) / Curved surface coverage / Processing temp. (°C)` + 工艺族
> **硬度分水岭：印刷 5–10 HV ｜ 涂装 10–16 HV ｜ 阳极氧化 600–1000 ｜ 化学镀 600–1100 ｜ 搪瓷 7k–10k**

### 8. 感知层四条公式（p221–p222，全在附录）

| 感知 | 公式 | 判定 |
|---|---|---|
| **软/硬** | **S = E·H** | S 小 = 软，S 大 = 硬 |
| **冷/暖** | **Q = √(ρ·λ·c_p)** | Q 小 = 暖，Q 大 = 冷 |
| **音高** | **P = √(E/ρ)** | P 小 = 低音 |
| **声亮度** | **L = 1/η** | L 小 = 闷，L 大 = 响 |

> **★★★ "软"与"硬"不是一根轴的两端** —— 硬靠 H（硬度），软靠 E（模量）。**这就是双材质设计的物理根据。**

### 9. 感知词表（p99，图 4.26，20 对）
Aggressive/Passive · Cheap/Expensive · Classic/Trendy · Clinical/Friendly · Clever/Silly · Common/Exclusive · Decorated/Plain · Delicate/Rugged · Disposable/Lasting · Dull/Sexy · Elegant/Clumsy · Extravagant/Restrained · Feminine/Masculine · Formal/Informal · Hand-made/Mass-produced · Honest/Deceptive · Humorous/Serious · Irritating/Loveable · Mature/Youthful · Nostalgic/Futuristic
> **★ 组内一致性约 80%（p98），但条件苛刻：同一社会文化群体 + 受试者能"拿在手上"。**

### 10. 四材料人格与老化三类型（p96–p97）

| 材料 | 人格关键词 | **老化方式** |
|---|---|---|
| **木材** | 自然、手工、传统 | **越旧越贵**（acquiring additional character） |
| **金属** | 冷、洁净、精确、工程化 | **越旧越美**（patina） |
| **陶瓷/玻璃** | 传统 + 高技术、不朽 | **几乎不变**（threatened only by brittleness） |
| **聚合物** | 温、可塑、变色龙 | **越旧越差**（gloss scratched, colors fade） |

### 11. CMF 完整流程（p138、p141–p146，本技能 ch07 §7.10）
**意向 → 拆约束/目标 → 读感知 → 分析法 → 合成法 →（相似法/灵感法）→ 交叉验证 → C 定案 → F 定案 → 风险清单 → 三级验证 → 记录成档**（+1 个标记的"混沌位"）

### 12. 三级验证（p49、p98、p155）
① **材料级**：拿"将来真要用的那批料"实测关键属性
② **零件级**：全尺寸原型，测技术期望 + 美学期望
③ **感知级**：让目标用户在**能拿在手上**的实物上贴图 4.26 的词
