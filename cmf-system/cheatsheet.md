## 二、必须记住的 12 组数字

### C 层
| 项 | 值 | 出处 |
|---|---|---|
| **光泽六级**（入射 60°/观测 120°） | Dead matte **<1%** ｜ Matte **1–10%** ｜ Eggshell **15–20%** ｜ Semi-gloss **40–50%** ｜ Full gloss **>80%** ｜ Mirror **>95%** | p82 |
| **透明四词** | opaque / translucent / transparent / water-clear | p93 |
| 最便宜的光学透明聚合物 | **PET / PS / PMMA** | p93 |
| 色谱边界（硬约束） | **酚醛（Phenolic）只能黑或棕** | p248 |

### M 层
| 项 | 值 | 出处 |
|---|---|---|
| **8 个材料指数** | 拉杆 ρ/E ｜ 梁刚 ρ/E^½ ｜ 梁强 ρ/σ_y^(2/3) ｜ 板刚 ρ/E^(1/3) ｜ 板强 ρ/σ_y^(1/2) ｜ 柱 ρ/E^½ ｜ 弹簧 Eρ/σ_y² ｜ **活铰 E/σ_y** | p227 |
| 陶瓷"强度"的特殊定义 | **抗压碎强度 ≈ 抗拉强度的 15 倍** | p205 |
| 韧性 | **K_IC**，单位 **MPa·m^½**；用于 CD 盒的指标是 **K_IC/E** | p207 / p151 |
| 密度 vs 模量的跨度 | 原子间距差 3 倍以内；**密度差得多** | p203 |

### F 层
| 项 | 值 | 出处 |
|---|---|---|
| **表面硬度分水岭** | 印刷 **5–10 HV** ｜ 涂装 **10–16 HV** ｜ **阳极氧化 600–1000** ｜ **化学镀 600–1100** ｜ **搪瓷 7k–10k** | p360–p383 |
| **阳极氧化三种膜** | 弱溶解（硼酸）**0.1–1 μm 非孔** ｜ 中溶解（铬酸 3–10%/硫酸 20%/草酸 5%）**双层** ｜ 强溶解（磷酸） | p372 |
| **抛光精度阶梯** | 机械 **<0.1 μm**（曲面 Poor）｜ 电解 **0.4 μm 经济 / 0.05 μm 高成本**（曲面 Average）｜ 化学（曲面 Good） | p373–p375 |
| **涂装三方权衡** | 溶剂型：**最好看 + 最脏** ｜ 水性：合规但**质量更差更慢** ｜ 粉末：**50–2000 μm，利用率 99%** | p376–p379 |

### 感知层
| 公式 | 判定 | 出处 |
|---|---|---|
| **软硬 S = E·H** | S 小 = 软 | p221 |
| **冷暖 Q = √(ρ·λ·c_p)** | Q 小 = 暖 | p221 |
| **音高 P = √(E/ρ)** | P 小 = 低音 | p222 |
| **声亮度 L = 1/η** | L 小 = 闷 | p222 |

## 三、CMF 12 步流程（ch07 §7.10）

```
0  定意向（Market / Economics / Sustainable / Performance）        [强制]
1  拆约束（二值）与目标（求最小）                                  [强制]
2  读感知（图 4.26 选 3–5 对词）                                   [强制]
3  分析法（属性图 + 材料指数）                                     [强制]
4  合成法（按意向/感知找产品案例）                                 [强制]
5  相似法（capture → edit → search）                              [视需要]
6  灵感法（almost at random）                                     [视需要]
7  交叉验证（读 Chart 3 排韧性风险）                               [强制]
8  C 定案（色号 + 光泽级 + 分区）                                  [强制]
9  F 定案（七行规格）                                             [强制]
10 风险清单（F 层 16 条 + 指向注塑缺陷技能）                       [强制]
11 三级验证（材料级 / 零件级 / 感知级）                            [强制]
12 记录成档（六表 + 被否决项及理由）                               [强制]
-- 留一个"混沌位"（直觉选择，必须标记）                            [开放]
```

> **结构与混沌的比例：12 : 1**（p200「Without structured methods, material selection gets nowhere. But without a little craziness and chaos, the really novel solutions may be missed.」）

## 九、CMF 决策 → 工艺风险速查（完整 12 行见 patterns.md P-13）

> **两条页码口径不要混**：`pN` = Ashby 原书 PDF 索引；`走 A–G / 案例 N` = `product-injection-defects` 的章节路径与案例号。

| CMF 决策 | 放大什么风险 | 跳到哪 |
|---|---|---|
| **镜面/高光（>95%）** | 流痕、气纹、熔接痕**全暴露** | 走 A、走 C；案例 2 / 4 / 36 / 7 |
| **水白透明** | 透明不良、银纹、气泡 | ch01 §1.14.15 / .7 / .11；案例 28 / 31 |
| **骨位有火花纹未省光** | **粘后模 → 顶出变形** | **案例 56** |
| **薄壁求纤细** | 缺胶、填充不满 | §1.14.2；案例 23 |
| **哑光/细咬花** | **无风险，反而藏缺陷** | 预防项（p383） |
| **整体着色/涂装** | 色差、混色、变色、斑点 | §1.14.8 / .17；案例 99 |
| **深色 + 高光** | 浅色能盖的色差/流痕，深色盖不住 | 走 G |
| **双材质/包胶** | 夹线、包胶不牢、缩水 | §1.14.4；案例 7 / 13 / 85 / 52 |
| **塑料电镀** | 涂层开裂/剥落 | p368 原文风险 |
| **IMD** | 图案变形；**PE 不能做** | p366 原文 |
| **透明件 + 卡扣/活铰** | 顶白、断裂、拉翻 | §1.14.5；案例 34 / 66 / 67 / 100 / 50 |
| **高硬度表面（阳极/搪瓷）** | 不引缺陷，但放大基材微变形 | 基材先喷砂再阳极 |

> **★★★★★ 判据：同一个"表面"变量，做纹理藏缺陷（p383），做镜面放大缺陷（p82）。**
> **★★★★ 最坏组合：高光泽 + 透明 + 薄壁，三者叠加良率断崖。**
