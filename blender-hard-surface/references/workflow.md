# 建模工作流（可照做）

> 出自《Blender 3D Incredible Models》ch01 p5–6。**三个项目都按这四步走**。

## 四步总览

```
① 收集参考  →  ② 拆分部件  →  ③ 建块面  →  ④ 加细节
   (找图)        (拆件)         (父件起)      (90% 工作在这)
```

---

## ① 收集参考（Gathering references）

### 找什么

| 物体复杂度 | 参考类型 |
|---|---|
| **简单物体** | **一张照片够** |
| **复杂物体（载具等）** | **最好找蓝图（blueprint）** |

**原文判据**：
> 「**蓝图通常高度精确，帮我们做出真实比例**；但**实景照片能帮我们理解一些在 2D 蓝图里难看清的形状**。」

### 要找几个视图

> 「**最好总是有侧视、顶视、前/后视三组参考**。这能让我们**不受透视畸变**地看清每一面。」

**如果没有蓝图怎么办**：
> 「找一份高质量蓝图可能很难，但**任何看起来是正交投影（orthographic projection）的物体图像都够用**。」

**正交投影的通俗定义（原文）**：
> 「简言之，就是**从正面、顶面或侧面直接绘制**一个 3D 物体所得的 2D 表示。」

### 搜索技巧（原文 TIP）

> 在 Google 搜索里**加 `side`、`top`、`blueprint` 等关键词**很有用。
> 网上还有**大量免费供个人使用的蓝图站点**。

## ② 拆分部件（Separating the parts）

### 为什么要拆

> 「**把物体拆成独立组件，因为这让我们能一步步做。**
> **这很重要，因为处理复杂物体时，很容易被"从哪开始"压垮。**」

### 拆到什么粒度

**判据**：拆到**每个部件都值得单独建**的粒度，但**不必过细**。

| 项目 | 拆成几个部件 |
|---|---|
| **FN SCAR** | **5 个**：机身、枪托、握把、弹匣、枪管（**瞄具并入枪管**，因为位置与细节等级相近） |
| **T-72 坦克** | **3 个大件**：车体、炮塔、履带/轮子 |

> **原文对步枪的补充说明**：
> 「在别的例子里，我们也会把**瞄具、榴弹发射器当作独立组件**，但这里不做。」

---

## ③ 建块面模型（Creating the block-out model）★ 最关键

### 核心判据：先找"父件"

> 「**我们总是想找到"其他所有东西都附着于它"的那个部件。**
> **它将充当参照系（frame of reference），建好它之后，我们就可以不断往它上面加东西。**」

| 项目 | 父件 | 理由 |
|---|---|---|
| **T-72 坦克** | **车体（hull）** | **其他一切都附着于它** |
| **FN SCAR** | **机身（body）** | 枪托/握把/弹匣/枪管都接在它上面 |

### 块面的标准

> 建**一个非常简单的所有主要部件的版本**。
> **块面 = 只有轮廓与体积，没有小细节。**

### 操作要点（提炼自 ch02 实操）

| 步 | 操作 | 快捷键/路径 |
|---|---|---|
| 1 | 进侧视 | **Numpad 1** |
| 2 | 加参考图 | **Shift+A → Image** |
| 3 | 让参考图半透明 | 选中图 →**右侧 Image Properties 标签**→勾 **Opacity**→拖滑杆 |
| 4 | 从最大部件开始 | 加立方体，**`S` 缩放**→单击确认→**`G` 移动**→单击确认 |
| 5 | 对齐参考 | **在侧视里把边线对到蓝图的线** |

## ④ 增加细节（Increasing detail）

> 「一旦有了粗略形状的轮廓，就可以开始做**更小更精细的部件**：舱盖、螺钉、装甲板之类。
> **这使模型看起来更复杂完整。大部分工作量在这一步。**」

### 细节的四类（提炼自三个项目）

| 类型 | 例子 | 常用手段 |
|---|---|---|
| **重复件** | 螺钉、格栅、履带片、导轨齿 | **Array 修改器** |
| **挖孔/开槽** | 散热孔、凹槽 | **Boolean 修改器** |
| **薄板件** | 装甲板、面板 | **Solidify 修改器** |
| **对称件** | 左右两侧 | **Mirror 修改器**（只做一半） |

---

## 三条贯穿全书的实操原则

### 原则 1：用 3D 游标精确定位

> 「**每次添加物体，它都恰好加在 3D 游标（3D Cursor）上。**」
> 所以：**把游标精确放到想要的位置，再新建物体**。

**把游标吸附到选中面**：
```
选面 → Shift+S → Cursor to Selected
```

### 原则 2：松散部件用 L 键整体选中

**问题**：只选一个面去移动，**会拖着相连的面一起动，把网格弄变形**。

**解法**：
```
Edit Mode → 鼠标悬停在部件上 → 按 L   （L = Linked）
```

### 原则 3：先做一半，再镜像

> ch02 原文用 **Mirror 修改器**完成对称（步枪左右两侧）。

**流程**：
```
① 只建左侧（或一半）
② 加 Mirror modifier，镜像轴选 X
③ 勾 Clipping 防止中线裂开
④ 所有细节都在这一半上做，另一侧自动跟随
```

## 项目开工清单

```markdown
□ 1. 参考图找齐了吗？（至少侧视）
      - 简单件：一张照片
      - 复杂件：蓝图（正交投影）
□ 2. 拆成几个部件？写下来。
      例：机身/枪托/握把/弹匣/枪管（5 件）
□ 3. 父件是哪个？（其他一切附着于它的那个）
□ 4. 块面阶段只做轮廓，不碰小细节。
□ 5. 细节阶段按四类填：
      - 重复件 → Array
      - 挖孔   → Boolean
      - 薄板   → Solidify
      - 对称   → Mirror（只做一半）
□ 6. 随时按 L 检查：我选的是不是整个松散部件？
```

## 中模 vs 高模的取舍（ch05 原文）

赛博飞船用的是**中模（medium-poly）**，原文解释了为什么：

> 「这个模型会用于第 6 章演示**能模拟更高细节等级的技术**。
> 到本章结束时，我们会得到一个**中细节等级**的模型，**这使它适合用于游戏和动画**。
> **这很重要，因为高度细节的模型往往不适合这类用途，必须被替换成不那么复杂的模型。**」

> **★ 判据**：
> - **影视/静帧** → 高模可以
> - **游戏/动画** → 中模 + **法线贴图伪造细节**（ch06 就是干这个）
