# 失败模式总表（带编号可回查）

> 编号格式 **`F-B<章>-<序>`**（B = Blender）。共 **12 章、96 条**。
> 每条含现象/根因/处置，全部来自各章正文。

## 第 1 章：硬表面基础（8 条）

| 编号 | 现象 | 根因 | 处置 |
|---|---|---|---|
| F-B1-01 | 移动一个面整个模型变形 | 没用 L 键 | 悬停按 **L** 选整个松散部件 |
| F-B1-02 | 不知从哪下手 | 没拆件 | 拆成 3–5 个部件 |
| F-B1-03 | 不知先建哪个 | 没找父件 | 找"其他一切附着于它"的部件 |
| F-B1-04 | 比例全错 | 凭记忆没参考 | 找参考图/蓝图 |
| F-B1-05 | 参考图有透视对不上 | 用了透视图 | 找**正交投影**图 |
| F-B1-06 | 硬表面做出来像有机 | 没倒角、loop 太连续 | **Ctrl+B** 倒角 + 加支撑边 |
| F-B1-07 | 做不出尖/鼓的地方 | 只用硬表面工具 | **Proportional Editing** |
| F-B1-08 | 面数爆炸卡顿 | 倒角太多 | 倒角**烘成法线贴图** |

## 按根因归类（最高频的五类）

| 根因 | 涉及编号 | 一句话 |
|---|---|---|
| **法线/UV 没处理好** | F-B3-01、F-B6-01、F-B6-12 | 布尔前修法线；烘焙前 UV 展开 |
| **参数值没按原文设** | F-B4-03、F-B8-05、F-B11-04、F-B6-05 | Samples 10/Radius 0.07、Offset ±2.000、X Max 1°、Hex 8080FF |
| **没应用修改器就继续** | F-B9-03、F-B10-05 | 先 Apply 再操作 |
| **选择/命名没做对** | F-B9-01、F-B11-01、F-B11-07、F-B2-03 | 先重命名；Ctrl+P 先子后父 |
| **用错工具** | F-B5-02（S vs Alt+S）、F-B11-09（骨骼 vs 约束）、F-B8-04（G vs G×2） | 三组易混工具 |

## 六组最容易记错的对比

| 对比 | 正解 |
|---|---|
| **S** vs **Alt+S** | Alt+S 沿法线，每条边距离相等 |
| **Shift+W** | **弯曲工具**（5.1.2 实测），不是合并顶点 |
| **Shift+N** vs **Shift+N** | 旧版 vs **新版重算法线（用这个）** |
| **G** vs **G 两次** | 自由移动 vs 顶点滑移 |
| **Ctrl+J** vs **Shift+J** | 合并物体 vs 合并圆 |
| **Bake Emit** vs **Bake Normal** | 边缘/发光 vs 法线 |
