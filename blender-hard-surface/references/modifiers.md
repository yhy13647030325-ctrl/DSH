# 修改器参数与用法（8 个）

> 出自《Blender 3D Incredible Models》。参数值全部**核对原文**，标注章节与图号。
> **修改器是什么（原文 ch02）**：
> 「**修改器是 Blender 对物体执行的操作，用来非破坏性地操作它的几何**。也就是说，Blender 会按你创建的修改器以某种方式改变物体，**而不真正改动原始几何**。」

**添加路径（通用）**：右侧 **Modifier Properties 标签**（扳手图标）→ **Add Modifier** → 选类别与修改器。

---

## 1. Mirror（镜像）— ch02、ch05、ch07

**用途**：**只做一半，另一半自动生成**。硬表面建模最省力的手段。

**书里的用法**（ch02「Mirroring an object with a Mirror modifier」）：
> 建好步枪的一半 → 加 Mirror 修改器 → 另一侧自动出现。

**参数**：

| 参数 | 说明 | 书里取值 |
|---|---|---|
| **Axis（镜像轴）** | X / Y / Z | **X**（左右对称） |
| **Clipping（裁剪）** | 防止顶点越过镜像面 | **建议勾选** |
| **Merge（合并）** | 合并中线上的顶点 | 勾选 |
| **Mirror Object** | 用另一个物体作镜像面 | 一般不填（用自身原点） |

**判据**：
- **对称的机械件（步枪、坦克车体、飞船）** → 先做一半 + Mirror
- **不对称件（握把、弹匣）** → 不做 Mirror

> **★ 顺序提醒**：Mirror 通常**放在修改器栈的最前面**（先镜像再倒角/细分），否则镜像出来的另一半不会带上后续修改器的效果。

## 2. Array（阵列）— ch03、ch05、ch06、ch07、ch10、ch11

**用途**：**把一个细节重复成 N 个**。硬表面做"密集重复细节"的主力。

**书里的四个实例**：

| 章 | 做什么 | 原文 |
|---|---|---|
| **ch03** | **导轨的齿** | 「先把**导轨的一级台阶**做出来，然后用 **Array 修改器**把它复制很多次」 |
| **ch08** | **排气格栅** | 「用**阵列**做排气格栅」 |
| **ch10** | **履带片** | 「把履带片阵列成一圈」 |
| **ch11** | 履带绑定后仍用阵列 | — |

**参数**：

| 参数 | 说明 | 常见取值 |
|---|---|---|
| **Fit Type** | 如何决定数量 | **Fixed Count**（定量）或 **Fit Curve / Fit Length**（沿曲线/按长度铺满） |
| **Count** | 实例数 | 按需 |
| **Relative Offset** | 按物体自身尺寸的倍数偏移 | 常用 |
| **Constant Offset** | 按绝对距离偏移 | 精确间距时用 |
| **Object Offset** | 用另一个物体的变换做偏移（可做**旋转阵列**） | 履带/齿轮时用 |
| **Merge** | 合并相邻实例的顶点 | 按需 |

> **★ Array 的两种"铺满"方式**：
> - **Fit Length / Fit Curve**：给一个总长或一条曲线，**自动算需要几个** → 适合履带、格栅
> - **Fixed Count + Offset**：**自己数几个** → 适合导轨齿、螺钉

## 3. Boolean（布尔）— ch03、ch08

**用途**：**用另一个物体在目标上切出形状**（挖孔、开槽）。

**书里的用法（ch03，原文完整流程）**：

| 步 | 操作 | 原文 |
|---|---|---|
| 1 | 建一个**用来切孔的物体**（形状=想要的孔） | — |
| 2 | **给物体命名** | 「给它重命名，因为它会出现在一个列表顶部」 |
| 3 | 选中**要切孔的物体**（步枪），**加 Boolean 修改器** | 「用这个修改器在物体上**切出一个洞**，形状就是刚创建并重命名的那个物体」 |
| 4 | **Object 列表里找到那个物体** | 「在 Object 列表里找到名为 **a** 的物体」 |
| 5 | **Operation 设为 Difference** | 「**确保 Boolean 设成 Difference**」 |
| 6 | **应用修改器，然后删掉切孔用的物体** | 「应用修改器并删掉物体后，我们就得到一个矩形孔」 |

**参数**：

| 参数 | 取值 | 说明 |
|---|---|---|
| **Operation** | **Difference**（差集） | **挖孔用这个** |
| | Union / Intersect | 合并 / 相交 |
| **Object** | 切孔用的物体 | **必须选对** |
| **Solver** | Exact / Fast | Exact 更准，Fast 更快 |

**★ 三条关键判据（原文 p 图 3.23 附近）**：

> ① **切孔物体的法线必须正确**：
> 「**应用 Boolean 修改器时，你有时会发现没切出孔来。这可能是因为用来切孔的物体的法线有问题。
> 一定要修法线：Edit Mode 下选中整个物体按 `Shift + N`。**」

> ② **切完要删掉工具物体**：
> 「应用修改器并删掉物体后，就得到一个矩形孔。」

> ③ **平滑着色设置**（原文同段）：
> 「（Auto Smooth 的）**大多数情况下 45 度是最好的角度**（most of the time, 45 degrees is the best angle），但你可以随意调这个数字找最佳结果。」

> **⚠ 顺序**：**先命名工具物体**，否则 Object 列表里全是 `Cube.001` 之类，选不对。

## 4. Solidify（加厚）— ch03、ch05、ch08

**用途**：**把一张单层面片变成有厚度的实体板**。

**书里的用法（ch03）**：
> 「给上部枪托加一个 **Solidify 修改器**。」
> 「**Solidify 修改器给表面增加厚度**，如图 3.51。
> **厚度在整个物体上并不总是恒定的，所以务必勾选 Even Thickness（均匀厚度）。**」

**参数**：

| 参数 | 说明 | **书里取值** |
|---|---|---|
| **Thickness（厚度）** | 加多厚 | 按需 |
| **Offset（偏移）** | 厚度往哪边长（-1/0/1） | 0（两侧均分）常合适 |
| **Even Thickness（均匀厚度）** | 拐角处保持厚度一致 | **★ 务必勾选**（原文明确） |
| **Rim（边缘填充）** | 是否给开口加边 | 勾选 |
| **Only Rim** | 只加边框不加厚 | 不用 |

> **★ 用途场景**：装甲板、面板、护板——**先做一张面，再 Solidify**，比直接挤出一个厚块好改。

## 5. Subdivision Surface（细分曲面）— ch03、ch07、ch08、ch09

**用途**：**让物体变得平滑圆润**。

**书里的用法（ch03，握把）**：
> 「加一个 **Subdivision Surface 修改器**。」
> 「Subdivision Surface 修改器会**让物体平滑圆润很多，但看起来不好看**。
> **我们还得再加点东西才算完成**。」

**参数**：

| 参数 | 说明 | 取值 |
|---|---|---|
| **Levels Viewport** | 视口细分级别 | 1–2（视口轻） |
| **Render** | 渲染细分级别 | 2–3 |
| **Type** | Catmull-Clark（默认）/ Simple | 默认 |

> **★ 原文的关键提醒**：
> **光加细分"看起来不好看"**——因为细分会把硬边也一起抹圆。
> **解法**（原文后续步骤）：
> 「**给平面加倒角**」+ **加环切（Ctrl+R）收紧边**，让细分后**边仍然硬**。
>
> **这就是硬表面的核心技术：`细分 + 支撑边（support loops）`**。
> 想保住哪里硬，就在**离边很近的地方加一圈环切**。

## 6. Curve（曲线变形）— ch08、ch10

**用途**：**让一个已有的物体（或其阵列）沿一条曲线弯曲**。履带绕轮、线缆走线都靠它。

**书里的用法（ch08，线缆）**：

| 步 | 原文 |
|---|---|
| 1 | 建一个圆柱，**圆柱直径 = 线缆宽度**；**删掉圆柱的顶面和底面** |
| 2 | **给圆柱阵列加 Curve 修改器** |
| 3 | **在 Curve Object 字段里选刚创建的曲线** |
| 4 | **可能需要调整 Deform Axis 因子直到贴合正确** |
| 5 | **之后应用（Apply）Curve 修改器** |

**参数**：

| 参数 | 说明 | 书里取值 |
|---|---|---|
| **Curve Object** | 用哪条曲线 | 填曲线物体名 |
| **Deform Axis** | 沿哪个轴变形 | **需试，直到贴合**（原文：may need to adjust） |

> **★ 两个操作要点**：
> ① **先做 Array 再套 Curve** —— 阵列铺满后，曲线把它弯成形
> ② **Deform Axis 要试** —— 不对就换轴，原文明确说"可能需要调整"

## 7. Shrinkwrap（收缩包裹）— ch09

**用途**：**把物体贴合到另一个物体的表面上**。

**书里的用法（ch09，炮塔细节）**：

| 步 | 原文 |
|---|---|
| 1 | 加一个**空心圆**（empty circle） |
| 2 | **给这个空心圆加 Shrinkwrap 修改器** |
| 3 | **在 Shrinkwrap 里把 Wrap Method 设为 `Target Normal Project`** |
| 4 | **把 Target object 设为炮塔（Turret）** |
| 5 | **应用修改器，再向上挤出这个圆** |

**参数**：

| 参数 | 说明 | **书里取值** |
|---|---|---|
| **Wrap Method** | 包裹方式 | **Target Normal Project** |
| **Target** | 贴到哪个物体 | **Turret（炮塔）** |
| **Offset** | 离表面的距离 | 按需 |

> **★ 价值**：在**曲面上做细节**（舱盖、凸起）时，**先用平面物体 + Shrinkwrap 吸附**，得到贴合曲面的轮廓，再挤出。

## 8. Edge Split（分离边）— ch08、ch10

**用途**：**控制平滑着色**——让某些边看起来是硬的。

**书里的用法（ch08，挡泥板）**：

| 步 | 原文 |
|---|---|
| 1 | 先手动标记锐边：**选锐边 → `Ctrl + E` → Mark Sharp** |
| 2 | **加 EdgeSplit 修改器** |
| 3 | **在修改器里取消勾选 `Edge Angle`，勾选 `Sharp Edges`** |

**参数**：

| 参数 | 说明 | **书里取值** |
|---|---|---|
| **Edge Angle** | 按角度自动分离 | **取消勾选** |
| **Sharp Edges** | 只分离手动标记为 Sharp 的边 | **勾选** |
| **Split Angle** | 角度阈值（Edge Angle 开启时生效） | 不用 |

> **★ 为什么这样设**：**手动标记 + 只认标记**，比按角度自动判断更可控（不会把想保平滑的地方也切开）。

**★ 复制修改器到多个物体（ch10，省时技巧）**：
> 「**选所有轮子和悬挂，最后选前面那个**，然后**按 `Ctrl + L` 再选 `Copy Modifiers`**。
> 这会把 **Edge Split 修改器复制到其他所有物体**上，产生更好的着色。」

## 修改器顺序（提炼，全书的实际栈序）

> 书里没有专门讲"栈顺序"，但从各章操作可归纳出通用栈序：

```
① Mirror        （先镜像，后面都作用在完整物体上）
② Subdivision   （细分）
③ 支撑边/环切   （用 Ctrl+R + 移动，收硬边）—— 这是建模操作，不是修改器
④ Bevel         （倒角）
⑤ Solidify      （加厚）
⑥ Array         （最后阵列，避免阵列后再改原始体）
⑦ Curve         （弯曲阵列结果）
⑧ Edge Split    （最后处理着色）
```

> **★ 核心原则**：**越"改变整体形态"的越靠前；越"处理表面效果"的越靠后。**
