# 新项目开工清单（Blender 硬表面）

> 用法：拿到"做一个类似的机械/载具/装甲"任务时，按此清单逐项填。
> 判据来自《Blender 3D Incredible Models》四步工作流与各项目实践。

---

## 一、定风格（决定工具与工作流）

| 项 | 填答 |
|---|---|
| 这个物体是**硬表面**吗？（机器/载具/武器/装甲/无生命硬物） | ☐ 是 ☐ 否 |
| 判据自检：**有锐边？有平面？多松散部件？loop 短而断？** | ☐ 都符合 |
| 如果主体是硬表面但有**曲面**（像坦克炮塔） | ☐ 需要用有机工具（比例编辑/细分） |

> 不是硬表面 → **本技能不适用**（角色/生物/布料走雕刻路线）。

---

## 二、定目标面数

| 用途 | 面数定位 | 细节怎么办 |
|---|---|---|
| **影视/静帧/渲染图** | **高模** | 全部用真几何（倒角、螺钉、面板） |
| **游戏/实时/动画** | **中模** | **法线贴图伪造**（ch06 技术） |
| 需要能动（履带/轮子） | 中高模 | 加**约束绑定**（ch11） |

> **判据**：原文「高度细节的模型往往**不适合游戏和动画**，必须替换成不那么复杂的模型。」

---

## 三、四步工作流

### ① 收集参考

| 项 | 填答 |
|---|---|
| 需要几张参考？ | ☐ 1 张（简单件） ☐ 侧+顶+前/后（复杂件） |
| 有蓝图吗？ | ☐ 有（优先，正交精确） ☐ 没有（找正交投影图） |
| 尺寸有严格要求吗？ | ☐ 有 → **开 Edge Length**（坦克类） ☐ 无（凭比例感） |

### ② 拆分部件

**拆成几件？**（写下清单）

```
1. ______________（父件）
2. ______________
3. ______________
4. ______________
5. ______________
```

**判据**：
- 拆到"每件都值得单独建"
- **位置与细节等级相近的可合并**（例：瞄具并入枪管）
- **必须有一个父件**（其他一切附着于它）

### ③ 建块面

| 项 | 检查 |
|---|---|
| **父件先建了吗？** | ☐ |
| 父件是：______________（步枪=机身 / 飞船=驾驶舱 / 坦克=车体） | ☐ |
| 只做**轮廓与体积**，没碰小细节 | ☐ |
| 对称件：**只做一半 + Mirror** | ☐ |
| 参考图已对齐（半透明 Opacity 调低） | ☐ |

### ④ 加细节（90% 工作量）

**按四类填**：

| 类型 | 我要加什么 | 用什么 |
|---|---|---|
| **重复件**（螺钉/格栅/履带/导轨齿） | ______________ | **做一级 + Array** |
| **挖孔/开槽** | ______________ | **Boolean（Difference）** |
| **薄板件**（装甲/面板/护板） | ______________ | **Solidify（勾 Even Thickness）** |
| **曲面上的细节** | ______________ | **Shrinkwrap（Target Normal Project）** |

## 四、开工前必开的三个显示/辅助

| 项 | 路径 | 为什么 |
|---|---|---|
| **Cavity 着色** | Viewport Shading → 勾 **Cavity** → Type **Both** → 滑杆拉满 | 看清网格凹凸 |
| **Edge Length**（需精确尺寸时） | Viewport Overlays → Measurement → 勾 **Edge Length** | 按图纸数值缩放 |
| **MatCap 预览**（看成品感） | Viewport Shading → **Lighting = MatCap** → Color = Single | 不用材质就能看效果 |

---

## 五、建模过程中随时自检

| 检查项 | 方法 |
|---|---|
| **我选的是整个部件吗？** | 悬停按 **L** |
| **法线朝外吗？** | Edit Mode 全选 → **Shift + N** |
| **硬边在细分后还硬吗？** | 加 **Ctrl+R 支撑边** + **Ctrl+B 倒角** |
| **该硬的边在平滑着色后硬吗？** | **Ctrl+E → Mark Sharp** + **EdgeSplit（勾 Sharp Edges）** |
| **加厚的厚度均匀吗？** | Solidify 勾 **Even Thickness** |
| **3D 游标位置对吗？**（新物体加在游标处） | **Shift+S → Cursor to Selected** |

---

## 六、贴图阶段决策

| 我要… | 方法 | 章 |
|---|---|---|
| 金属**边缘磨损** | Edge Mask（Cycles+Bevel+Geometry+Dot Product+Invert）→ 烘焙 **Emit** → **Mix RGB** | ch04 |
| **表面凹凸**但不加几何 | 烘焙 **Normal** 贴图 | ch06 |
| **倒角**但不加几何 | 烘 **Bevel 法线贴图**（高模→低模） | ch06 |
| **舱盖/标识**等细节 | **画法线贴花**（基底 Hex **8080FF**） | ch06 |
| 手绘彩色涂装 | Texture Paint（**Shift+7 → Numpad 5** 正面对齐） | ch06 |
| 程序化材质 | 节点（Noise 等）+ Principled BSDF | ch12 |

## 七、交付前检查

| 项 | 检查 |
|---|---|
| 面数符合目标（游戏/影视） | ☐ |
| 法线全部朝外（Shift+N） | ☐ |
| UV 展开完成（若需贴图/烘焙） | ☐ |
| 修改器已应用或**有意保留**（保留便于改） | ☐ |
| 松散部件已命名（便于后期） | ☐ |
| 若有绑定：转控制物体，履带/轮子联动正常 | ☐ |
| 材质在 **Cycles 与 Eevee** 下都检查过 | ☐ |

---

## 八、按产品类型的快速配方

| 产品 | 父件 | 拆分 | 关键手法 | 参考章 |
|---|---|---|---|---|
| **枪械** | 机身 | 机身/枪托/握把/弹匣/枪管 | 布尔开孔、Array 导轨、边缘磨损 | ch02–ch04 |
| **载具/飞船** | 驾驶舱或底盘 | 主体/机翼/引擎/装甲 | 装甲板 + 法线贴图伪造 | ch05–ch06 |
| **坦克/履带车** | 车体 | 车体/炮塔/轮子/履带 | Edge Length、EdgeSplit、Array+Curve、约束绑定 | ch07–ch12 |
| **机械装置**（任意重复细节多） | 主体框架 | 框架/运动件/紧固件 | **做一级 + Array** | ch03、ch08 |
| **面板类外壳** | 主壳 | 壳体/面板/饰条 | **Plane + Solidify + 倒角** | ch03、ch08 |

---

## 九、三条最容易忘的

1. **新物体加在 3D 游标处** —— 开建前先 `Shift+S → Cursor to Selected`。
2. **烘焙前挪开遮挡部件** —— 否则 edge map / normal map 在遮挡处出错。
3. **`Ctrl+P` 先选子级再选父级** —— 反了层级就错。
