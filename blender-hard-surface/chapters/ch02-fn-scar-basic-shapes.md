# 第 2 章：FN SCAR 基础形体

> 原书 Chapter 2: Creating Basic Shapes for an FN SCAR。
> 本章对应**四步工作流的第 1–3 步**（参考图 → 拆件 → 块面）。

## 本章解决什么

**第一个实操项目**，学 Blender 最核心的那批建模操作，并用它们把一把 FN SCAR 步枪的**块面**搭出来。

> 原文：「到本章结束，我们会得到 FN SCAR 突击步枪的**简单版本**，并**掌握一些核心建模工具与技术**。」

**九个主题（原文）**：
1. Preparing references
2. Modeling the lower receiver
3. Modeling the upper receiver
4. Creating the stock
5. Adding a handgrip shape
6. Creating attachment rails
7. Shaping the barrel
8. **Mirroring an object with a Mirror modifier**
9. Adding a simple magazine

## 2.1 设置参考图（三步，原文 p9）

> 「为简单起见，这个项目**只用一张参考图**。把图像设为 Blender 里的参考，**要三步**」：

| 步 | 操作 | 快捷键/路径 |
|---|---|---|
| **1** | **进入侧视图** | **Numpad 1** |
| **2** | **从 Add 菜单的 Image 区添加参考** | **Shift + A → Image** |
| **3** | **浏览到下载图片的文件夹并打开** | — |

### 参考图太亮刺眼？调透明度（原文）

> 「有时 Blender 里的参考图**太亮或刺眼**。我们可以**把图调得稍微透明**来修正。」
> 「**选中参考图 → 右侧 Image Properties 标签 → 勾 `Opacity` → 把滑杆往下拖**。」

### 视图快捷键（原文 TIP，务必记住）

> 「**Numpad 数字 1、3、7 用于在前视、右视、顶视的正交视图间切换。
> 9 切到当前视图的反面。
> 按 1、3、7 时按住 Ctrl 会分别切到后视、左视、底视。**」

### 参考图要找几张（原文判据）

> 「**最好总是有侧视、顶视、前/后视三组参考**，这样不受透视畸变地看清每一面。**但不是必须的。**
> 本例中**多面背景参考不必要，侧视图是最重要的参考**。」

## 2.2 拆分部件（原文 p9）

> 「设计里有很多不同组件，但我们可以**简化成五个主要部件：机身（body）、枪托（stock）、握把（handgrip）、弹匣（magazine）、枪管（barrel）**。
> **我们也可以把瞄具（sights）并入枪管**，因为**它们的位置与细节等级相近**。」

> **★ 附加规则（原文）**：
> 「在别的例子里，我们也会把**瞄具、榴弹发射器当作独立组件**，但这里不做。」
> **即：拆件粒度按"位置与细节等级是否相近"合并。**

## 2.3 建下机匣（lower receiver）— 五步（原文 p10）

**为什么要从机身开始**：
> 「按照上一章的工作流模型，**我们先建物体最大的部件，也就是枪的机身**。
> 它由**护木、下机匣、上机匣**组成。让我们用**五步**开始建机匣的下半部分。」

| 步 | 操作 | 快捷键 | 原文细节 |
|---|---|---|---|
| **1** | **从 Add 菜单加一个立方体**，与视图对齐 | **Shift+A → Mesh → Cube** | 「用它来塑造下机匣」 |
| **2** | **用 `S` 缩小立方体**；单击左键确认；**再按 `G` 拖动**到角落，单击确认 | **S** / **G** | 「**放在机匣后部，这样我们可以从那里开始**」 |
| **3** | **选中物体按 `Tab` 进入 Edit Mode** | **Tab** | 「要启用多边形建模（**手动操作顶点、边、面**），必须进 Edit Mode」 |
| **4** | **按 `2` 切到边选择（Edge Select）** | **2** | 「这让你**选中单条边**，而不是顶点或面。**顶点选择和面选择分别用 1 和 3**」 |
| **5** | **选右边的面并沿 X 轴挤出** | **E** 然后 **X** | 「按 **E 挤出**，按 **X 把挤出限制在 X 轴**。**把边推到机匣前部**，单击左键确认位置」 |

> **步骤 5 的后续**：
> 「这样做后**底部会得到一条新边，我们把它沿 Z 轴向下挤出**。
> 做法：**选那条边，按 `E` 和 `Z`，单击左键应用挤出**。」

## 2.4 环切（Loop Cut）— 原文专门开一节讲

**定义与快捷键（原文 p10）**：
> 「环切用于**创建一条新的边循环**。它创建一组新多边形供建模用。**激活 Loop Cut 工具的快捷键是 `Ctrl + R`。**」
> 「工具激活后，**把光标悬停在你想加环切的那条边上**。**可以用鼠标滚轮上下来控制环切数量**。」

**★ 完整操作四拍（原文）**：
```
① Ctrl + R
② 单击左键（创建环切）
③ 移动鼠标滑杆（沿边滑动环切位置）
④ 再单击左键（应用环切）
```

**在步枪上的应用**：

| 步 | 原文 |
|---|---|
| **1** | 「**按 `Ctrl + R` 创建环切并悬停鼠标在网格上**。本例中，**一条竖直环切把两个侧面分成四块**。我们可以**用底部的一个面把弹匣座向下挤出**」 |
| **2** | 「**在顶点选择模式下逐个移动顶点**（**按 `3` 启用**，原文此处应理解为切换选择模式）。**这让我们做出弹匣座的斜底和右侧突出的小形状**」 |

> **⚠ 原文小瑕疵**：第 2 步原文写「**在顶点选择模式下……按 3 启用**」，但 **`3` 是面选择**。
> **按前文 p10 明确「顶点和面分别用 1 和 3」，顶点选择应为 `1`。** 此处疑为原文笔误，**照做时用 `1`**。

## 2.5 视口着色（Shading the viewport）— 让网格好看点

> 「在继续建模前，**让我教你一个让网格在工作时更好看的办法**。」

| 步 | 操作 |
|---|---|
| **1** | 屏幕**右上角**有个 **Viewport Shading** 菜单 |
| **2** | 菜单**底部勾 `Cavity`** |
| **3** | 展开后，打开 **`Type` 框选 `Both`** |
| **4** | **把所有滑杆拉到最大值** |

> **原文评价**：「这些着色设置**只是个花招（gimmick）**，但**让建模过程更有意思**。」
> 「Viewport Shading 菜单里还有别的设置，随便探索。」

## 2.6 建上机匣（upper receiver）— 引入 3D 游标

**为什么要用 3D 游标（原文 p11）**：
> 「**我们需要在我们刚做的网格顶部放一个立方体，但放的位置必须相当精确，所以用 3D 游标。**」
> 「**3D 游标是操纵 3D 空间中物体的强大工具，后面会大量使用。
> 每次我们添加物体，它都恰好加在 3D 游标上。**」

| 步 | 操作 | 快捷键 | 原文 |
|---|---|---|---|
| **1** | **把 3D 游标吸附到下机匣背面的那个面** | **Shift + S → Cursor to Selected** | 「选那个面，**用 Shift+S 打开 Snap 菜单**，选 **Cursor to Selected**。顾名思义，这会把 3D 游标吸附到选中的多边形上」 |
| **2** | **加立方体并移到表面上方** | Shift+A → Cube | 「用这个立方体做上机匣和护木」 |
| **3** | **在侧视里把立方体的边对齐参考图的线** | Numpad 1 | 「先把立方体的高度对齐蓝图（图 2.17）的那部分。**再把立方体侧面往右推，使其匹配机身的长度**」 |
| **4** | **加两条环切，并在 Y 轴上放大** | **Ctrl+R** 然后 **S → Y** | 「按 **S 缩放**、**Y 只在 Y 轴上缩放**」 |
| **5** | **挤出两条环切之间顶部的面**；**只挤出一点点，再重复一次做出第二个台阶** | **E** | 「现在**每侧应该有三个台阶**」 |

> **步骤 3 的关键判断（原文）**：
> 「这个物体的**顶部和底部宽度会变化**，所以那些部分我们**用不同的技术来建模**。」

### 枪托的一个具体操作（原文 p12，可验证）

**问题**：挤出后面**没有厚度**。
**解法（原文）**：
> 「**因为没有厚度，我们用 `Alt + S` 快捷键并把鼠标向上移动，给选中的边循环加厚度。
> 这会把挤出的面循环向外扩张**。」

> **★ 这条是 `Alt+S` 的**主要用法**：挤出后沿法线加厚。全书出现 14 次。**

## 2.8 Mirror 修改器（本章正式引入）

**修改器是什么（原文 p12）**：
> 「**修改器是 Blender 对物体执行的操作，用来非破坏性地操作几何**。
> 也就是说，Blender 会按你创建的修改器以某种方式改变物体，**而不真正改动原始几何**。」

**用法**：步枪是左右对称的 → **只建一半 → 加 Mirror → 另一半自动生成**。

**参数与判据**：详见 [references/modifiers.md § Mirror](../references/modifiers.md)。

> **★ 本章的收尾（原文）**：
> 「我们只需要再做**一个简单的弹匣**，FN SCAR 就可以进入细节阶段了。」

## 失败模式（F-B2）

| 编号 | 现象 | 根因 | 处置 |
|---|---|---|---|
| **F-B2-01** | 参考图太亮，看不清模型 | 没调透明度 | Image Properties → 勾 **Opacity** → 拖低 |
| **F-B2-02** | 视图转来转去对不准 | 用了透视视图 | **Numpad 1/3/7** 切正交视图；**Ctrl+Numpad** 切反面对应视图 |
| **F-B2-03** | 新加的物体跑到奇怪的位置 | **加了别的物体，3D 游标在别处** | 原文：「**每次添加物体，它都恰好加在 3D 游标上**」→ 先 **Shift+S → Cursor to Selected** 把游标归位 |
| **F-B2-04** | 环切位置不对/数量不对 | 没走完四拍 | **Ctrl+R → 单击 → 滚轮调数量 → 滑动定位 → 单击** |
| **F-B2-05** | 挤出的面是"纸片"，没有厚度 | 只挤出没加厚 | **Alt + S** 沿法线加厚 |
| **F-B2-06** | 移动一个面把网格拉坏 | 没用 L 键 | 悬停按 **L** 选整个松散部件 |
| **F-B2-07** | 想缩放单轴却整体缩了 | 没按轴 | **S 后按 X/Y/Z**；**Shift+Y/X 是"除该轴外"** |
| **F-B2-08** | 镜像后中间有裂缝 | Mirror 没勾 Clipping / Merge | 勾 **Clipping** + **Merge** |
| **F-B2-09** | 建了一半不知怎么接下半 | 没想好拆件 | 按五件拆分：机身/枪托/握把/弹匣/枪管 |
| **F-B2-10** | 建模界面看着平淡、看不清凹凸 | 没开 Cavity | 右上 **Viewport Shading** → 勾 **Cavity** → Type **Both** → 滑杆拉满 |
