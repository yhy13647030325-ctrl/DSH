## 8.1 侧装甲（Modeling the side armor）★ 含 Edge Split 的完整用法

**本节范围（原文）**：
> 「我们现在创建侧装甲和油箱。**这里重点做挡泥板（mudguards）、侧装甲（也叫裙板 skirt）、以及一些尾部细节。**」

### 挡泥板：倒角 + Solidify + Edge Split（原文 4 步）

| 步 | 操作 | 快捷键 | 原文 |
|---|---|---|---|
| **1** | **给挡泥板的边倒角，并用 Solidify 修改器加厚表面** | **Ctrl+B** + Solidify | — |
| **2** | **选锐边按 `Ctrl + E`，菜单里选 `Mark Sharp`** | **Ctrl+E** | 见下方★ |
| **3** | **加 EdgeSplit 修改器**；修改器里**取消勾选 `Edge Angle`、勾选 `Sharp Edges`** | EdgeSplit | — |
| **4** | **给挡泥板加更多细节**：倒角、铰链等 | **Ctrl+B** | — |

**★ 步骤 2–3 的判据（原文）**：
> 「**给物体应用平滑着色时，我们可以手动标记想让哪些边显得锐利。
> 然后可以用一个修改器告诉 Blender 如何着色这个物体。**」

> **★ 这就是"手动控制平滑组"的完整链条**：
> ```
> ① 选边 → Ctrl+E → Mark Sharp        （标记）
> ② 加 EdgeSplit → 取消 Edge Angle     （不按角度自动判断）
> ③              勾 Sharp Edges        （只认手动标记）
> ```
> **好处**：比"按角度自动"更可控，**不会把想保平滑的地方也切开**。

### 侧裙箱体：双击 G 滑移（原文 4 步）

| 步 | 操作 | 快捷键 |
|---|---|---|
| **5** | **建一个压扁的立方体，倒角** | **Ctrl+B** |
| **6** | **加一条环切，用"双击 `G`"把前面的顶点滑移**，让那部分倒角更宽 | **Ctrl+R** → **`G` 按两次** |
| **7** | **在形状上再加更多环切**（用于挤出成形） | **Ctrl+R** |
| **8** | **塑形并在端部挤出一个孔** | **E** |

> **★ 步骤 6 的 `G` 按两次 = Vertex Slide（顶点滑移）**，不是自由移动。
> **区别**：自由移动会脱离原边；**滑移只能沿原边方向滑动**，不破坏拓扑。

## 8.2 排气格栅用阵列做（Creating exhaust grills with arrays）★ Array 参数最具体的实例

**原文**：「我们到车体后部。**下面几步用阵列创建排气格栅**。」

| 步 | 操作 | 关键参数 |
|---|---|---|
| **1** | **在坦克最末端建一个简单框架并加细节** | — |
| **2** | **加一些基础形状（重塑的立方体）在框架内形成若干横条** | — |
| **3** | **在框架里建一个细长形状，加 Array 创建格栅。** **把 `Relative Offset` 因子设为 `2.000`（或 `-2.000`，视方向而定）** | **Relative Offset = ±2.000** |
| **4** | **在另一个方向重复，形成网格图案** | — |
| **5** | **用同样技术在车体上做更大的排气口** | — |

> **★ `Relative Offset = 2.000` 是什么（原文给的唯一精确值）**：
> **偏移量 = 物体自身尺寸的 2 倍** → **即：相邻两个实例之间留出一个同样大小的空隙**。
> **这就是"格栅"的成因**：实体与空隙交替。

> **★ 单向 Array 做栅条，再叠加另一方向 Array 做网格** —— **两轴阵列出格栅**。

### 后续几个面板的做法（原文步骤 6–9）

| 步 | 操作 | 原文 |
|---|---|---|
| **6** | 在大格栅前**加一个带倒角的薄板** | — |
| **7** | **再加一个面板盖住前一个** | — |
| **8** | **在面板上做一个轮廓（outline）** | 「**可以用平面创建形状、内插面（inset faces）、再删掉内部面来做**」 |
| **9** | **给边循环倒角** | **Ctrl+B** |

> **★ 步骤 8 的技法值得记住**：**平面 → `I` 内插面 → 删内部面 = 得到一个"框/轮廓"**。

## 本章操作速查

| 我要… | 操作 |
|---|---|
| 控制哪些边看起来是硬的 | 选边 → **Ctrl+E → Mark Sharp** → 加 **EdgeSplit** → 取消 **Edge Angle**、勾 **Sharp Edges** |
| 把单层板加厚 | **Solidify** → 勾 **Even Thickness** |
| 顶点沿边滑移（不破坏拓扑） | **Ctrl+R** 加环切 → 选中 → **`G` 按两次** |
| 做格栅（栅条） | 做一根 → **Array** → **Relative Offset = ±2.000** |
| 做网格（十字格栅） | 第一方向 Array → 再叠第二方向 Array |
| 做"框/轮廓" | **平面 → `I` 内插面 → 删内部面** |
| 倒角 | **Ctrl+B** |
| 挤出孔 | **E** |

## 失败模式（F-B8）

| 编号 | 现象 | 根因 | 处置 |
|---|---|---|---|
| **F-B8-01** | 平滑着色后该硬的地方变圆 | 没标锐边 | **Ctrl+E → Mark Sharp** + **EdgeSplit（勾 Sharp Edges）** |
| **F-B8-02** | EdgeSplit 把不该切的也切了 | 勾了 **Edge Angle** | **取消勾选 Edge Angle**，只勾 **Sharp Edges** |
| **F-B8-03** | 加厚后拐角厚薄不均 | 没勾 Even Thickness | Solidify → **勾 Even Thickness** |
| **F-B8-04** | 移动顶点把形状弄歪 | 用了自由移动 | 用 **`G` 按两次**（顶点滑移，只在原边上滑） |
| **F-B8-05** | 格栅间距不对、连成一片 | Relative Offset 不对 | 设 **±2.000**（偏移 = 自身尺寸 2 倍，留出一个空隙） |
| **F-B8-06** | 格栅只有一个方向 | 没叠第二方向 | 另一方向**再加一个 Array** |
| **F-B8-07** | 做不出"框" | 直接删面 | **平面 → `I` 内插面 → 删内部面** |
| **F-B8-08** | 面板重叠穿插 | 没留缝 | 不同面板错开位置 |
| **F-B8-09** | 车体细节越做越乱 | 忘了父件是车体 | 所有细节都**加到车体上**，保持层级 |
