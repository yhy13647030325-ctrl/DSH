## 3.1 3D 游标（3D Cursor）

ch02 已用过，本章正式讲。

**核心事实（ch02 已说，本章深化）**：
> 「**每次添加物体，它都恰好加在 3D 游标上。**」

**把游标精确放到某处**：
```
选目标几何（面/边/顶点） → Shift + S → Cursor to Selected
```

**用游标做镜像中心（本章 TIP）**：
> 「**你可以按 `S`、输入 `-1`、回车，让物体绕 3D 游标镜像。**
> **也可以试试先设定一个轴，再输入数值。**」

> **★ 这是 `S -1` 技巧**：**缩放比例填 -1 = 镜像翻转**，轴心由**枢轴点**决定。
> 所以配合**枢轴点设成 3D Cursor**，就能绕游标镜像。

## 3.2 握把（handgrip）：细分 + 支撑边 ★ 最重要的技术组合

**这是全书讲"如何用细分做出硬边"最集中的地方。**

**原文流程**：

| 步 | 操作 | 说明 |
|---|---|---|
| 1 | 从立方体做出握把基本形状 | — |
| 2 | **溶解面（Dissolve Faces）**，用 **`J`** 连顶点成边 | 「取两个角顶点用 **`J`** 连成一条边」（图 3.8） |
| 3 | **加 Subdivision Surface 修改器** | 「它会**让物体平滑圆润很多，但看起来不好看**」 |
| 4 | **给平面加倒角** | 「我们得再加点东西才算完成」 |

**★ 核心判据（原文的因果）**：
> 问题：**细分会把本该硬的边也抹圆。**
> 解法：**在硬边附近加支撑边（support loops）+ 倒角**，把细分"顶住"。

**具体手法**：
| 手段 | 快捷键 | 作用 |
|---|---|---|
| **环切加支撑边** | **Ctrl + R** | 在离边很近处加一圈线，**收紧细分** |
| **倒角** | **Ctrl + B** | 让边在细分后仍显硬朗 |
| **顶点滑移** | **`G` 按两次** | 微调支撑边位置 |

**倒角的两个进阶操作（本章 TIP）**：
> ① 「**创建倒角时按 `C` 可以切换 Clamping。** 这**允许或阻止倒角切穿多边形**。」
> ② 「**倒角也可以加在单个顶点上。选中一个顶点用 `Shift + B` 发起倒角**，单击左键应用。会弹出 Bevel 菜单。」（此句出自 ch05，同法通用）

## 3.3 机匣细节（detailing the receiver）：Boolean 挖孔 + 圆要 12 边

### Boolean 的完整流程（原文 p 图 3.18–3.20）

| 步 | 原文 |
|---|---|
| 1 | 建一个**用来切孔的物体**（形状 = 想要的孔） |
| 2 | **给它重命名** ——「因为它会出现在一个列表顶部」 |
| 3 | **选步枪，加 Boolean 修改器** ——「用它**在物体上切出一个洞**，形状是刚创建并重命名的那个物体」 |
| 4 | **在 Object 列表里找到那个物体**（图 3.19） |
| 5 | **确保 Boolean 设成 `Difference`**（图 3.20） |
| 6 | **应用修改器，然后删掉工具物体** ——「就得到一个矩形孔」 |

### ★ 三条必须记住的判据

**① 切孔物体法线必须正确**（原文 p 图 3.23 附近）
> 「**应用 Boolean 修改器时，你有时会注意到没有孔被创建出来。
> 这可能是因为用来切孔的物体的法线有问题。
> 一定要修正法线：在 Edit Mode 下选中整个物体，按 `Shift + N`。**」

**② 圆用 12 个顶点**（本章 TIP）
> 「**添加圆时，屏幕左下角会出现 Add Circle 菜单。菜单里有 `Vertices` 条，控制圆的顶点数。
> 用圆来切孔时，把它设成 12。**」

**③ Auto Smooth 的角度**（原文）
> 「（Auto Smooth 的）**大多数情况下 45 度是最好的角度**（most of the time, 45 degrees is the best angle），可以随意调这个数字找最佳结果。」

## 3.4 螺钉（modeling screws）

**流程要点**：

| 步 | 操作 | 快捷键 |
|---|---|---|
| 1 | 建圆（**12 顶点**） | Shift+A → Circle |
| 2 | 若做成两个独立圆，**合并** | **Shift + J**（原文：「若你把圆做成独立物体，可选中两者按 Shift+J 合并」） |
| 3 | **桥接边循环，再挤出**，做出螺钉厚度 | **E** |
| 4 | **复制螺钉到下一个孔** | **Shift + D** |
| 5 | **把新螺钉移到 3D 游标** | Snap 菜单里 **Selection to Cursor** |

> **原文完整链路**：
> 「**把 3D 游标吸附到另一个孔的底部圆**。用 **Shift+D 复制螺钉**，用 snap 菜单里的 **Selection to Cursor** 按钮把新螺钉移到 3D 游标。」

> **★ 这个"游标 + Shift+D + Selection to Cursor"的组合是复制重复件的标准动作。**

**缝合被撕开的边（本章 TIP）**：
> 「你可以**按距离合并顶点把撕开的边缝回去**，这会把同位置的顶点合成一个，关掉它们之间看不见的缝。」
> **⚠ 5.1.2 实测纠正**：合并顶点**没有直接快捷键**，走 **`M` 菜单 → By Distance**。
> **`Shift-W` 在 5.1.2 里是 `transform.bend`（弯曲工具）**，不是合并。

## 3.5 用 Array 做导轨（本章核心修改器案例）

**思路（原文）**：
> 「我们现在要把**导轨的简单形状**变成**精细成品导轨**。
> **首先做导轨的一级台阶，然后用 Array 修改器把它复制很多次。**」

**流程**：

| 步 | 操作 |
|---|---|
| 1 | 做**一级台阶**（一个齿） |
| 2 | 给它加倒角（`Ctrl + B`） |
| 3 | **加 Array 修改器** |
| 4 | 设 **Count**（数量）与 **Offset**（偏移） |

**参数详见** [references/modifiers.md § Array](../references/modifiers.md)。

> **★ 这是"重复件"的通用解法**：导轨齿、螺钉排、格栅、履带片——**都是"做一级 + Array"**。

## 3.6 枪托（finishing the stock）：Solidify 加厚

**问题**：枪托上部的面片**没有厚度**。

**原文流程**：

| 步 | 原文 |
|---|---|
| 1 | 「**把上部枪托沿 X 轴缩小**，让**枪托和枪身之间留一点缝**」 |
| 2 | 「**给上部枪托加一个 Solidify 修改器**」 |
| 3 | 「Solidify 修改器**给表面增加厚度**。**厚度在整个物体上并不总是恒定的，所以务必勾选 `Even Thickness`**」 |
| 4 | 「加一些其他细节」 |

> **★ `Even Thickness` 是必勾项**，原文明确。

| 我要… | 操作 |
|---|---|
| 绕游标镜像 | 枢轴点设 **3D Cursor** → **S → -1 → Enter** |

## 失败模式（F-B3）

| 编号 | 现象 | 根因 | 处置 |
|---|---|---|---|
| **F-B3-01** | **Boolean 加了但没切出孔** | **切孔物体的法线反了** | Edit Mode 全选工具物体 → **Shift + N** 修法线 |
| **F-B3-02** | Boolean 列表里找不到切孔物体 | **没给工具物体命名** | 原文：**先重命名**，否则列表里全是 Cube.001 |
| **F-B3-03** | Boolean 切出来是"加料"不是"挖孔" | Operation 选错 | 改 **Difference** |
| **F-B3-04** | 布尔后工具物体还在场景里 | 忘了删 | 原文：**应用修改器并删掉物体** |
| **F-B3-05** | 圆切出来的孔太"方" | 圆顶点数太少/太多 | Add Circle → **Vertices = 12**（原文推荐） |
| **F-B3-06** | **细分后硬边全变圆了** | **没加支撑边/倒角** | **Ctrl+R 在边附近加环切** + **Ctrl+B 倒角** |
| **F-B3-07** | 倒角切穿了多边形 | Clamping 没开 | 倒角时按 **C** 切换 **Clamping** |
| **F-B3-08** | 想镜像但位置不对 | 枢轴点不是游标 | 枢轴点设 **3D Cursor** 再 **S -1** |
| **F-B3-09** | 撕开的边有缝 | 有重叠顶点没合并 | **M 菜单 → By Distance**（`Shift-W` 是弯曲，不合并） |
| **F-B3-10** | 复制螺钉位置总偏 | 手动拖 | 游标吸到目标 → **Shift+D** → **Selection to Cursor** |
| **F-B3-11** | 导轨齿一个一个摆太慢 | 手工复制 | **做一级 + Array 修改器** |
| **F-B3-12** | 加厚后拐角处厚薄不均 | 没勾 Even Thickness | **Solidify → 勾 Even Thickness** |
| **F-B3-13** | 平滑着色出现难看渐变 | Auto Smooth 角度不对 | 设 **45°**（原文取值） |
| **F-B3-14** | 瞄具装了但"瞄不准" | 没做功能验证 | 原文：**假装瞄准看对齐** |
