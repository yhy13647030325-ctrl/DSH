# 第 6 章：飞船纹理绘制

> 原书 Chapter 6: Texture Painting the Sci-Fi Race Ship。
> **本章是全书的核心方法论**：如何用贴图让**低面数模型看起来像高模**。

## 本章解决什么

> 原文总结：「我们学会了**用倒角法线贴图和纹理绘制来提高模型的表观细节等级**。
> 我们学会了**为三个目的烘焙法线贴图**：
> **① 模拟凹凸表面 ② 在低模上放置倒角这类细节 ③ 在表面绘制贴花以创造更多细节**。」

> **★ 这三个目的是全书最重要的方法论**——**因为倒角在几何上太贵**（ch01 已说），所以：
> - **凹凸** → 法线贴图伪造
> - **倒角** → 烘焙成法线贴图（几何上不加）
> - **贴花/舱盖** → 画上去（连模型都不加）

**原书对效果的验证**：
> 「画完法线贴花后，**看起来就像我们在装甲上真的建模出了一个舱盖**。
> **这是在不新增任何物体、不增加模型面数的前提下创造大量细节的好办法。**」

**六节结构（原文）**：
1. **Baking a normal map**
2. **UV unwrapping**
3. **Baking a bevel map**
4. Texture painting the armor panels
5. Painting decals
6. **Painting normal decals**

---

## 6.1 三个烘焙目的（本章总纲）

| # | 目的 | 解决什么问题 | 对应小节 |
|---|---|---|---|
| **1** | **模拟凹凸表面（bumpy surfaces）** | 中模表面太平滑 | Baking a normal map |
| **2** | **在低模上放置倒角（bevels）** | ch01 说倒角太贵，几何上不加 | **Baking a bevel map** |
| **3** | **绘制贴花（decals）增细节** | 想加舱盖/标识但不想建模 | **Painting normal decals** |

---

## 6.2 UV 展开（UV unwrapping）★ 烘焙的前提

**为什么必须先做**：
> 烘焙是**把 3D 表面的信息"摊"到 2D 图**上，所以模型**必须先有 UV**。

**操作（与 ch04 同）**：

| 步 | 操作 |
|---|---|
| 1 | **Edit Mode 全选**（`A`） |
| 2 | 按 **`U`** 打开 UV 映射菜单 |
| 3 | 选 **Smart UV Project** |

> **★ 顺序**：**先修法线（Shift+N）→ 再 UV 展开 → 再烘焙**。
> ch04 原文也强调过：「**展开前先修法线**，确保整把枪是一个物体」。

---

## 6.3 烘焙法线贴图（Baking a normal map）

**流程（与 ch04 烘焙 edge map 同构）**：

| 步 | 操作 | 要点 |
|---|---|---|
| 1 | 进 **Cycles** 渲染引擎 | 烘焙需要 Cycles |
| 2 | 在 Image Editor **新建图像** | 尺寸 **2048**、勾 **32-bit Float** |
| 3 | 材质里加 **Image Texture 节点**，载入这张新图 | — |
| 4 | 选中物体 → Render Properties → **Bake 菜单** | — |
| 5 | **Bake Type 设为 `Normal`** | （ch04 烘 edge map 用的是 **Emit**） |
| 6 | 点 **Bake** | 等几分钟 |

> **⚠ 差异提醒**：
> | 烘什么 | Bake Type |
> |---|---|
> | **边缘遮罩（ch04）** | **Emit** |
> | **法线贴图（ch06）** | **Normal** |

**★ 烘焙前必须做的事（ch04 已证）**：
> **把重叠/遮挡的部件挪开**，否则烘焙结果在遮挡处出错。

---

## 6.4 烘焙倒角贴图（Baking a bevel map）★ 第 2 个用途

**这一步在解决 ch01 提出的问题**：
> ch01：「**倒角常被避开，因为它们给模型增加大量多边形**……**因为代价高，倒角常被烘焙成法线贴图**，这样**在表面上看得见，但不是 3D 模型的一部分**。」

**做法（提炼，本章配图为主）**：

| 步 | 操作 |
|---|---|
| 1 | 复制一份模型，在复制体上加**真实倒角**（Ctrl+B） |
| 2 | 给复制体做 UV |
| 3 | **用复制体烘法线贴图**（高模 → 低模烘焙） |
| 4 | 把烘好的法线贴图**应用到原始低模** |
| 5 | 低模上**看起来有倒角，几何上却没有** |

> **（书中未给出逐步编号）**——本节以图 6.x 推进，**没有列出每步的编号清单**。
> 上述四步是**根据原文"烘焙倒角贴图"的标题与 ch01 的动机**归纳的**（提炼）**。

---

## 6.5 纹理绘制装甲板（Texture painting the armor panels）

**这一步给装甲板上色**。

**关键工具与操作**：

| 项 | 说明 |
|---|---|
| **绘制模式** | Texture Paint 模式 |
| **画笔选择（本章 TIP）** | 「**按 `C` 激活画笔选择（brush selection），然后点击拖动左键选择。滚动鼠标滚轮调整笔刷大小。**」 |
| **对着面正视图（本章 TIP）** | 「**用 `Shift + 7` 把视图与选中面对齐，再按 `Numpad 5` 进入正交视图。这会在纹理绘制时给你更好的角度。**」 |
| **同材质批量选面（ch06 前文）** | 「选一个面按 **`Shift + G`** → **Select Similar** 菜单 → 点 **Material**，选中所有同材质的面」 |

> **★ `Shift + 7` + `Numpad 5` 是纹理绘制的标准视角操作**：
> **`Shift + 7`** 把视图转到与选中面正对，**`Numpad 5`** 切正交，**避免透视扭曲**。

---

## 6.6 绘制贴花（Painting decals）

**贴花 = 画上去的图案**（标识、编号、磨损）。

**Stencil（模板）机制**：

| 步 | 操作 |
|---|---|
| 1 | 在 Texture Properties 标签**载入贴花图** |
| 2 | **在 Texture 菜单里载入图像**；可能需要**修正图像长宽比**，也可**改角度旋转模板** |
| 3 | **把模板放到船上，在上面涂画** → 产生贴花 |
| 4 | **右键点击拖动可以移动模板** |

---

## 6.7 绘制法线贴花（Painting normal decals）★ 最惊艳的技巧

**这是把"舱盖"画上去的方法**。

**完整流程（原文 p 图 6.57–6.62）**：

| 步 | 操作 | 关键参数 |
|---|---|---|
| **1** | 重新打开赛博飞船的 `.blend`，**在 Armor 材质里新建图像** | 「这次**不把图像设成全黑，而是把 Hex 码设为 `8080FF`**。这给我们**一个可以在上面画法线凹凸的基底**」 |
| **2** | **在 Texture Properties 标签载入刚烘好的法线贴图** | — |
| **3** | **在 Texture 菜单里载入图像**；**可能需要修正图像长宽比**，**也可改角度旋转模板** | — |
| **4** | **把模板放到船上任意位置，在上面涂画**，产生法线贴花 | 「**右键点击拖动可以移动模板**」 |
| **5** | **把图像在 Y 轴缩放到 -1.00 来翻转**，画到船的另一侧 | 「**和在建模时翻转物体是同一手法**」 |
| 6 | 用本章技术尽可能多细节 | — |

### ★ 为什么基底是 `8080FF`（原理）

> 法线贴图的 RGB 表示**法线方向**。
> **`80 80 FF`** = 法线朝正上方（切线空间的标准"平面"色）。
> **即：`8080FF` 是一张"完全平坦、无凹凸"的法线贴图基底。**
> 在这个基底上画东西，**画出来的就是凹凸**。

> **（书中未解释为什么用 8080FF，以上为原理补充，标 提炼）**

### ★ 效果验证（原文）

> 「画完法线贴花后，**看起来就像我们真的在装甲上建模出了舱盖**。
> **这是在不新增任何物体、不增加面数的前提下创造大量细节的好办法。**」

## 6.8 本章方法论总结（最该带走的部分）

**★ 一句话**：
> **低模 + 法线贴图 = 视觉上的高模。**

**三条路径**：

| 想加什么 | 用 | 代价 |
|---|---|---|
| **表面凹凸** | 烘 **Normal** 贴图 | 只增贴图，不增面 |
| **倒角** | 烘 **Bevel 法线贴图**（高模→低模） | 只增贴图，不增面 |
| **舱盖/标识/细节** | **画法线贴花**（`8080FF` 基底） | **连模型都不加** |

**这也解释了全书的整体策略**：
```
ch02–ch04  FN SCAR   → 高模（可以随便加倒角）
ch05–ch06  赛博飞船  → 中模 + 法线贴图伪造细节（游戏适用）
ch07–ch12  T-72 坦克 → 高模 + 细节（加上前面所有技术）
```

## 失败模式（F-B6）

| 编号 | 现象 | 根因 | 处置 |
|---|---|---|---|
| **F-B6-01** | 烘焙出来一片黑/乱码 | **没做 UV 展开** | Edit Mode 全选 → **U → Smart UV Project** |
| **F-B6-02** | 烘焙文件是纯黑 | **Bake Type 选错** | 法线用 **Normal**；边缘/发光用 **Emit** |
| **F-B6-03** | 烘焙在遮挡处出错 | **部件重叠** | 原文：**先把遮挡的部件挪开**（只挪复制体） |
| **F-B6-04** | 法线贴图效果不明显 | 没用 **32-bit Float** 或分辨率太低 | 新建图设 **2048**、勾 **32-bit Float** |
| **F-B6-05** | 法线贴花画出来一片紫/怪色 | **基底不是 `8080FF`** | 新建图时 **Hex 设 `8080FF`**（平坦基底） |
| **F-B6-06** | 纹理绘制时笔刷抓不到面 | 没进 Texture Paint 模式 / 没选对画笔 | 按 **C** 选画笔 → 拖动左键 → 滚轮调大小 |
| **F-B6-07** | 在透视视图里画，图案被拉伸 | 没切正交 | **Shift+7** 对齐面 → **Numpad 5** 正交 |
| **F-B6-08** | 只给一个面上了色，其他漏了 | 手工逐个选 | 选一个 → **Shift+G → Material** 选所有同材质面 |
| **F-B6-09** | 模板位置不好调 | 不会移动 | **右键点击拖动**移动模板 |
| **F-B6-10** | 贴花在另一侧是反的 | 没翻转 | 图像 **Y 轴缩放 -1.00** |
| **F-B6-11** | 模型面数越来越高，跑不动 | 什么都用真几何做 | 原文：**用贴图伪造细节，不新增物体、不增面数** |
| **F-B6-12** | 倒角贴图烘了但对不上 | 高低模的 UV 不一致 | 高模与低模需**同一个 UV 布局**，或用同一套 UV 烘 |
