## 7.1 ★★★★★ 建车体（Modeling a hull）

> **原文**：
> 「**本节我们创建车体。我们会把这部分作为基础，把所有其他基础形体加到它上面。**
> 以下步骤中，我们会用之前学过的工具和技术，把默认立方体变成坦克车体。**」

### 7.1.1 ★★★★★ 第一步：打开 Edge Length（本章第一个新操作）

> **原文**：
> 「**在 Viewport Overlays 菜单的 Measurement 区域勾选 Edge Length。
> 这会在 Edit Mode 里显示所选边的长度。**」

**★★★★★ 这是本章最重要的"基础设置"**：

| 项 | 内容 |
|---|---|
| **位置** | **★ Viewport Overlays → Measurement → Edge Length** |
| **作用** | **★ 在 Edit Mode 显示选中边的**实际长度** |

> **★★★ 判据：要做"尺寸精确"的模型，第一步是开 Edge Length** ——
> **★ 否则你永远不知道"这条边有多长"，只能靠目测。**

**★★★★ 为什么这一章特别需要它**：
> **原文（总结）**：
> 「**我们用边的测量值来正确设定比例，这样后面就不用担心尺度问题。**」

> **★★★ 判据：坦克有"真实尺寸"（车长 6.9m、宽 3.6m），必须按实测尺寸建。**
> **★ 而飞船是原创的，尺寸随意 → 所以 ch05 不需要 Edge Length。**

## 7.2 ★★★★★ 建侧裙（Creating a skirt）

> **原文**：
> 「**本节我们用简单形状创建侧装甲与履带罩（track covers）的轮廓。**
> 接下来几步，我们再次添加形状并用基本工具与技术修改它们，来创建坦克这部分。**」

### 7.2.1 ★★★★★ 步骤 1：在同一物体里"加平面再分离"（本节最巧的一步）

> **原文**：
> 「**在 Edit Mode 里给车体加一个新平面，并按 Selection 分离它。
> ★ 这个平面会有和车体相同的原点与修改器，
> 因为它是作为同一个物体的一部分创建的。**」

**★★★★★ 这是"继承修改器"的技巧**：

```
在车体（已加 Mirror 修改器）内部
   ↓ Edit Mode → 加平面
   ↓ P → Separate by Selection
   ↓
★ 新平面自动继承：相同的原点 + 相同的 Mirror 修改器
```

| 继承什么 | 好处 |
|---|---|
| **★ 原点** | **★ 位置自动对准** |
| **★ 修改器（Mirror）** | **★ 不用重新加** |

> **★★★ 判据：想让新部件"自动带上父物体的修改器"→ 在同一物体内部建，再 `P` 分离。**
> **★ 这比"新建物体 + 重新加 Mirror + 对齐原点"快得多。**

**★★★★ 原文的放置参考**：
> **「图 7.16 是从顶视图和侧视图正确放置这个平面的参考。」**
> **★★ 侧裙的平面位置在这两个视图里都看得见，所以给双视图参考。**

### 7.2.2 ★★★★★ 步骤 2–8：侧裙的造型（含一个"用三角化导引"的技巧）

| 步 | 原文操作 | 关键 |
|---|---|---|
| **2** | **挤出前面的边 → 下移到与车体首部同高** | — |
| **3** | **`Ctrl+B` 把锐边变圆** | — |
| **4** | **★ 复制一个角顶点 → 下移 → `F` 填充侧面 → `Ctrl+T` 三角化** | **★ 本节最巧** |
| **5** | **`Ctrl+B` 倒角 → 稍微外扩** | — |
| **6** | **在内边做两条边的小倒角 → 内边下滑** | **★ 三角化的边起"导引"作用** |
| **7** | **★ 删掉三角化的面 → 在内侧重做步骤 4–5** | **★ 临时结构** |
| **8** | **`Shift+D` 复制后面的边 → 向后挤出 → 加环切 → 再挤一个形状** | — |

**★★★★★ 步骤 4–7 的"临时三角化导引"（本节最有价值的技术）**：

> **原文（步骤 4）**：
> 「**从形状的一角复制单个顶点，并把它下移。
> 下移后按 `F` 填充侧面，再用 `Ctrl+T` 把填充的面三角化。**」
> **原文（步骤 6）**：
> 「**在内边再做一个小型两边倒角，并把倒角内边向下滑。
> ★ 这里，三角化产生的边会帮助引导这些边。**」
> **原文（步骤 7）**：
> 「**删掉三角化的面，在形状内侧重做步骤 4 和 5。**」

**★★★★★ 完整理解这个技巧**：

```
① 复制一个顶点 → 下移（★ 造出"尖"）
   ↓
② F 填充侧面 → Ctrl+T 三角化
   ↓ ★ 三角化产生"放射状的边"
③ 用这些边做倒角/滑动 ★ 它们充当"导引线"
   ↓
④ 删掉三角化的面（★ 临时结构用完就删）
```

| 要点 | 说明 |
|---|---|
| **★ 三角化是"临时的"** | **★ 用完就删** |
| **★ 作用是"产生放射状边"** | **★ 给倒角/滑动提供方向** |
| **★ 不是最终拓扑** | **★ 最终要删掉** |

> **★★★ 判据：需要"从一个点放射出多条导引边"时，临时三角化再用。**
> **★ `Ctrl+T` = Triangulate（三角化）。**

**★★★★ 步骤 8 的"复制边再挤出"**：
> **原文**：「**按 `Shift+D` 复制形状后面的边，并向后挤出。
> 然后加一个环切，在后面挤出另一个形状。**」

> **★★ 判据：`Shift+D` 在 Edit Mode 里可以复制"边"（不只是面）** ——
> **★ 复制边 = 造一条"新的边循环"。**

### 7.2.3 ★★★★ 步骤 9–10：立方体做斜面与盒子

> **原文**：
> 「**加一个立方体，用它做出薄的形状。确保边跟随一个斜面（slope）。**」
> 「**用立方体在坦克侧面做更多盒子。
> 确保塑造它们，让它们绕着车体的形状走。**」

**★★★★ 两条判据**：

| # | 判据 |
|---|---|
| **1** | **★ 薄的形状要"边跟随斜面"**（不是平的） |
| **2** | **★ 侧面的盒子要"绕着车体形状走"**（不是整齐排列） |

> **★★ 判据：坦克的附加件不是"贴上去的方盒子"，而是"顺着车体曲面的形状"** ——
> **★ 这是坦克与"方块感"的区别。**

## 7.3 ★★★★★ 建炮塔（Adding a simple turret）

> **原文**：
> 「**本节我们创建一个简单的炮塔形状。
> ★ 炮塔可以说是坦克最难建模的部分，
> 所以目前我们只创建一个物体，后面再修改它来加更多细节。**」

**★★★★★ 一条"难度自觉"的判据**：
> **★★ 原文直接承认：「炮塔可以说是坦克最难建模的部分。」**
> **★ 所以本章"只做一个物体"，是主动取舍。**

### 7.3.1 ★★★★★ 四步（本节）

| 步 | 原文操作 | 关键 |
|---|---|---|
| **1** | **车体顶部加一个圆 → 作为炮塔环（turret ring）** | — |
| **2** | **炮塔环上加立方体 → ★ 删掉底面 → 加 Subdivision Surface** | **★ 两个关键** |
| **3** | **缩放使网格略大于炮塔环 → ★ 调整形状让前低后高** | **★ 炮塔的楔形** |
| **4** | **（原文：这是唯一能算"基础形体"的炮塔形状，先到这）** | — |

**★★★★★ 步骤 2 的两个关键**：

**① 必须删掉底面**
> **★★ 因为炮塔是"坐在车体上"的罩子，底面不可见** ——
> **★ 留着会增加无用面，且细分后底部会"鼓出来"。**

**② 加 Subdivision Surface 但 ★ 不 Apply**
> **原文**：「**给立方体加 Subdivision Surface 修改器让它变圆，★ 但不要应用这个修改器。**」

**★★★★★ 「不 Apply」是本节的隐含判据**：

| 做法 | 后果 |
|---|---|
| **Apply 修改器** | **★ 网格被"固化"成细分后的样子，改不动了** |
| **★ 不 Apply（保持修改器）** | **★ 随时能改基础形，细分自动跟着变** |

> **★★★ 判据：还要继续修改的物体，Subdivision 不要 Apply。**
> **★ 这样"改低模 → 高模自动更新"，是可迭代的做法。**
> **★ 这与 ch03「Subdivision + 支撑边」是同一体系：支撑边加在低模上。**

**★★★★ 步骤 3 的"前低后高"**：
> **原文**：「**缩放物体，让网格略大于炮塔环，并调整形状让前部比后部低。**」

> **★★ 判据：T-72 炮塔是"卵形 + 前倾"** ——
> **★ 前低后高是这个型号的特征（不是通用坦克造型）。**

## 7.4 ★★★★★ 加负重轮（Adding wheels）—— 本章技术最密集的一节

> **原文**：
> 「**现在我们给坦克加一些轮子。
> 以下步骤中，我们创建简单圆柱并排列它们，这样就知道轮子会坐在哪。**」

### 7.4.1 ★★★★★ 步骤 1–2：圆柱 + Array（六轮）

| 步 | 原文操作 | 参数 |
|---|---|---|
| **1** | **坦克侧面加圆柱** | — |
| **2** | **加 Array → ★ Count = 6、Constant Offset Y = 1.41 m** | **★ 原文给定精确值** |

**★★★★★ 两个精确参数（原文明确给出）**：

| 参数 | 值 | 意义 |
|---|---|---|
| **★ Count** | **★ 6** | **★ T-72 单侧 6 个负重轮** |
| **★ Constant Offset Y** | **★ 1.41 m** | **★ 轮距 1.41 米** |

> **★★★ 判据：`1.41m` 是 T-72 的真实轮距** ——
> **★ 这说明"按真实尺寸建模"不是口号，是每个参数都对。**

**★★★★ 与"Relative Offset"的对照**：
> **★★ ch05 的碳纤维用 Constant Offset（绝对距离），ch06 的飞船格栅也是。**
> **★ 判据：要"精确间距"用 Constant Offset；要"按物体尺寸"用 Relative Offset。**

### 7.4.2 ★★★★★ 步骤 3–4：主动轮（Sprockets）

> **原文**：
> 「**在前部和后部加两个更小的圆柱。这些将是驱动履带的主动轮（sprockets）。**」
> **「对轮子应用（Apply）Array 修改器。」**

**★★★★ 步骤 4 的「Apply Array」很关键**：
> **★★ 因为下一步要 `P` 分离成独立部件，修改器必须先 Apply** ——
> **★ 否则分离后每段都带着"从头再阵列一次"的修改器，会爆炸。**

| 步 | 为什么 |
|---|---|
| **★ 先 Apply Array** | **★ 让 6 轮变成"真实几何"** |
| **★ 再 `P` 分离** | **★ 分离后每个轮是独立物体** |

### 7.4.3 ★★★★★ 步骤 5–8：分离、Origin to Geometry、Link Object Data

**这一步是本章最有价值的技术组合**：

> **原文（步骤 5）**：「**在 Edit Mode 里选中所有轮子，按 `P` 分离成 Loose Parts（松散部件）。**」
> **原文（步骤 7）**：「**在左上角 Object 菜单里打开 Set Origin 子菜单，选 Origin to Geometry。
> 这会把每个轮子的原点放在物体中心。**」
> **原文（步骤 8）**：「**选中所有轮子按 `Ctrl + L`。
> 在 Link/Transfer Data 菜单里选 Link Object Data。
> 这会让物体共享数据，所以当一个物体被改变时，所有其他链接物体也会变。**」

**★★★★★ 三件套的完整逻辑**：

```
① P → Separate by Loose Parts
   ↓ ★ 把 6 个轮子拆成 6 个独立物体
② Object → Set Origin → Origin to Geometry
   ↓ ★ 每个轮子的原点回到"自身中心"
③ Ctrl + L → Link Object Data
   ↓ ★ 6 个轮子共享同一份网格数据
```

| 步骤 | 作用 |
|---|---|
| **① 分离** | **★ 每个轮能单独定位** |
| **② Origin to Geometry** | **★ 保证"绕自身转"而不是"绕世界原点转"** |
| **③ Link Object Data** | **★ 改一个 = 改全部** |

**★★★★★ 第 ③ 步的价值（原文点明）**：
> **原文**：
> 「**例如，改变一个轮子的网格（如图 7.36），会自动改变所有其他轮子的形状。
> 这能节省大量时间，因为你只需要处理一个轮子，因为它们都是完全相同的。**」

> **★★★ 判据：一组"完全相同"的物体，用 Link Object Data 共享网格** ——
> **★ 改一个全变，这是"实例化"（instancing）的思路。**
> **★ 与"复制物体"的区别：复制会各存一份数据，链接是共用一份。**

**★★★★ `P` 的两个模式（本节的隐含知识）**：

| 菜单项 | 结果 |
|---|---|
| **Separate by Selection** | **★ 按当前选择分成一个新物体** |
| **★ Separate by Loose Parts** | **★ 按"松散部件"拆成多个物体（一次拆完）** |

> **★★ 判据：要"一次拆成 N 个独立件"用 **Loose Parts**；只拆"选中的那块"用 Selection。**
> **★ ch03 的机翼是 Selection，本章的 6 轮是 Loose Parts。**

### 7.4.4 ★★★★★ 步骤 9：镜像到另一侧（含法线修正）

> **原文**：
> 「**复制所有轮子，在 3D 游标位于世界原点时，在 X 轴上缩放到 -1，把它们复制到坦克另一侧。**
> **记得在 Edit Mode 里按 `Shift + N` 修正翻转后的轮子的法线。**」

**★★★★★ 三个要点**：

| 要点 | 说明 |
|---|---|
| **★ 游标必须在世界原点** | **★ 否则镜像位置偏** |
| **★ `S` `X` `-1` 镜像** | **★ ch03 讲过的"缩放负值"** |
| **★ 必须 `Shift+N` 修法线** | **★ 翻转会反法线** |

> **★★★ 判据：`S` 缩放 -1 之后，法线一定反了，必须 `Shift+N`。**
> **★ 这是 ch03 "S → -1 镜像" 的必然后果（那里就说过"会真翻转，法线也翻"）。**
