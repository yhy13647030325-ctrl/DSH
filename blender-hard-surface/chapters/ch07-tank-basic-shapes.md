# 第 7 章：T-72 坦克基础形体

> 原书 Chapter 7: Modeling the T-72 Tank: Basic Shapes。
> **第三个、也是最高级的项目**开始。对应四步工作流的**第 3 步（块面）**。

## 本章解决什么

> 原文：「最后一个项目是**高细节的 T-72 坦克**。这里会用到**目前学过的所有工具与技术**，以及**其他新技术**，来达到最高的细节等级。
> 本节还**引入基础的约束绑定（constraint rigging）技术**，让**坦克履带能动起来**。」

**五个主题（原文）**：
1. **Modeling a hull**（车体）
2. **Creating a skirt**（裙板）
3. **Adding a simple turret**（简化炮塔）
4. **Adding wheels**（负重轮）

> **拆件（ch01 已说）**：坦克 = **车体（父件）+ 炮塔 + 履带/轮子**。

## 7.1 车体（hull）★ 父件

**原文的定位**：
> 「本节我们创建车体。**我们会用这个部件作为基础，把所有其他基础形体都加到它上面。**」

> 「下面几步，我们**用已学过的工具与技术把默认立方体变成坦克车体**。」

### 完整步骤（原文 p 图 7.1–7.12）

| 步 | 操作 | 快捷键/路径 | 原文细节 |
|---|---|---|---|
| **1** | **打开 Viewport Overlays 菜单的 Measurement 区，勾 `Edge Length`** | Viewport Overlays | 「这会在 Edit Mode 下**显示选中边的长度**」 |
| **2** | **把默认立方体缩放到图 7.2 的尺寸** | **S** | 尺寸**需对照原书图 7.2** |
| **3** | **按 `Ctrl + R` 加两条环切** | **Ctrl + R** | 得到图 7.3 的形状 |
| **4** | **在内部视图里移动边，做出尖的船头** | **G**（在内部视角） | 「Inside view」= **透视看内部** |
| **5** | **在物体中部再加两条环切**；**把后面的面略微降低** | **Ctrl + R** / **G** | 图 7.5 |
| **6** | **移动后部的边，塑造车体尾部** | **G** | 图 7.6 |
| **7** | **再加三条环切** | **Ctrl + R** | 图 7.7 |
| **8** | **删除车体左侧所有的面** | **X** | 「为 Mirror 做准备」 |
| **9** | **给物体加 Mirror 修改器** | Mirror modifier | 图 7.9 |
| **10** | **按 `E` 挤出车体侧面的一个面** | **E** | 图 7.10 |
| **11** | **移动边，让挤出的面比它的基底小** | **G** | 「做出斜侧面」 |

### ★ 三条关键手法（本章的方法论）

**① `Edge Length` 是精确建模的前提**
> 「这会在 Edit Mode 下**显示选中边的长度**。」

> **★ 意义**：坦克有**真实尺寸**要求（车体长宽高），**开着 Edge Length 才能按图纸数值缩放**。
> 对比：**步枪/飞船凭比例感，坦克要按真实尺寸**。

**② 删一半 + Mirror —— 全书第三次用**
| 项目 | 用 Mirror 的位置 |
|---|---|
| FN SCAR（ch02） | 枪身左右 |
| 赛博飞船（ch05） | 侧面形状 |
| **T-72 坦克（ch07）** | **车体左右（删左半边 → Mirror）** |

**③ 内部视角（Inside view）移动顶点**
> 步骤 4、6 都需要「在内部视图里移动边/顶点」——**从外面看不到内部的边，必须进模型内部**。

## 失败模式（F-B7）

| 编号 | 现象 | 根因 | 处置 |
|---|---|---|---|
| **F-B7-01** | 车体尺寸和真车对不上 | 没开 Edge Length 凭感觉缩 | **Viewport Overlays → Edge Length**，按图 7.2 数值 |
| **F-B7-02** | 车头做不出尖 | 只在外部视角动 | 进**内部视角**移动顶点（步骤 4） |
| **F-B7-03** | 镜像后车体中间有缝 | 没勾 Clipping/Merge | Mirror 勾 **Clipping** + **Merge** |
| **F-B7-04** | 忘了删一半就加 Mirror，模型重叠 | 顺序错 | **先删左半面（步骤 8）→ 再加 Mirror（步骤 9）** |
| **F-B7-05** | 想一次做完炮塔和轮子 | 违反工作流 | **ch07 只做块面**，细节留 ch09/ch10 |
| **F-B7-06** | 挤出的侧面是垂直的，不是斜的 | 没缩挤出的面 | 步骤 11：**让挤出的面比基底小** |

## 与其他部分的关系

- **车体是父件 → ch08 在它上面加所有细节**
- **Mirror 第三次用**（步枪/飞船/坦克）
- **简单炮塔 → ch09 高模炮塔**
- **基础轮子 → ch10 详细轮子**
- **Edge Length 是坦克项目的独特要求**（步枪/飞船不需要精确尺寸）

### 轮子的精确参数（已核对原文）

| 项 | 值 | 原文 |
|---|---|---|
| **轮子 Array Count** | **6** | 「给圆柱加 Array 修改器来复制轮子。**把 Count 值设为 6**」 |
| **轮子 Array Constant Offset Y** | **1.41 m** | 「**Constant Offset 的 Y 因子设为 1.41 m**」 |
| **轮子基础形体缩放** | **0.2**（ch10） | 「**把枢轴点设为 Individual Origins**，**把所有形状缩放到 0.2 倍**」 |
