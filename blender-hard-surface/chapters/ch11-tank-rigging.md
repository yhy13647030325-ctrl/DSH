# 第 11 章：履带绑定（约束）

> 原书 Chapter 11: Rigging Tank Tracks。

**让履带能动**：转一个空物体，履带就跟着"走"。

> 原文：「本节我们**用空物体（empty objects）和约束（constraints）来绑定履带和轮子**。
> **下面几步把履带的运动绑定到一个空球的旋转上**。」

**四个小节（原文）**：
1. **Adjusting the tracks**（调整履带）
2. **Rigging with constraints**（约束绑定）★
3. **Rigging the wheels and sprockets**（绑定轮子与主动轮）
4. **Parenting the tracks**（履带父子关系）

## 11.1 空物体是什么（原文 p 图 11.7）

> 「**空物体（empty object）是一个存在但在渲染中不可见的物体。**
> **它常用作占位符（placeholder）、参考（reference）或绑定用的物体（rigging object）。**」

**创建**：
```
Shift + A → Empty → Sphere
```

> **注意**：不在 Mesh 菜单下，而在 **Empty** 菜单下。

**重命名（必做）**：
```
选中 → F2 → 输入 Sphere
```

## 11.2 用 Transformation 约束绑定履带 ★ 本章核心

**原文完整 9 步（p 图 11.9–11.14）**：

| 步 | 操作 | 路径 | 关键参数 |
|---|---|---|---|
| **1** | **创建一个空球** | **Shift+A → Empty → Sphere** | — |
| **2** | **按 `F2` 把物体重命名成 `Sphere`** | **F2** | 名字要可识别 |
| **3** | **选中履带，找到 `Object Constraint Properties` 标签，打开 `Add Object Constraint` 菜单** | 右侧标签栏 | — |
| **4** | **加一个 `Transformation` 约束** | Add Object Constraint → Transformation | 「这会**在 Object Constraints 标签里创建一个菜单，很像修改器**」 |
| **5** | **勾选 `Extrapolate` 复选框；把 `Owner` 设为 `Local Space`** | — | **Extrapolate ✓ / Owner = Local Space** |
| **6** | **在 `Target` 菜单里找到那个叫 `Sphere` 的空球** | — | — |
| **7** | **展开 `Map From` 和 `Map To` 菜单；前者选 `Rotation`，后者选 `Location`** | — | **Map From = Rotation / Map To = Location** |
| **8** | **在 `Map From` 里把 `X Max` 设为 `1 degree`；在 `Map To` 里把 `Y Source Axis` 设为 `X`** | — | **X Max = 1° / Y Source Axis = X** |
| **9** | （在 `Map To` 里继续设目标轴幅度） | — | — |

### ★ 步骤 7 的原理（原文说得很清楚）

> 「**这样做，我们就把球的旋转翻译成了履带的移动。**
> **换句话说，当球旋转时，履带就移动。**」

**即**：
```
空球旋转（Rotation） ──映射──▶ 履带位移（Location）
```

> **★ 为什么用"空物体旋转 → 履带位移"而不是直接转轮子**：
> **履带是平的（一块块片），不会自己"转"**。
> 它的运动本质是**沿路径平移**，所以要用**位移**驱动；
> 而**手感上我们希望"转一圈 = 走多远"**，所以用**旋转**作输入。

### `X Max = 1 degree` 是什么意思（原文取值）

> 「在 Map From 里把 **X Max 设为 1 degree**」

> **即：映射的输入范围以 1 度为基准**——**空球每转 1°，履带移动设定的距离**。
> **这决定了履带"转速"的灵敏度。**

> **（书中未继续解释 X Max 的更多含义，以上为语义解释，标 提炼）**

## 11.3 绑定轮子与主动轮（Rigging the wheels and sprockets）

**思路**：
- **主动轮/负重轮**：**用 Rotate 驱动**（它们真的在转）
- **履带**：**用 Location 驱动**（它在平移）

**做法（提炼）**：
| 步 | 操作 |
|---|---|
| 1 | 给轮子加约束（Copy Rotation 或 Transformation），目标指向同一个空球 |
| 2 | 设定旋转方向与比例（左右履带方向相反） |
| 3 | 隐藏空物体（`H`），避免误选 |

## 11.5 本项目的绑定性质

| 项 | 说明 |
|---|---|
| **绑定内容** | 履带、轮子、主动轮 |
| **绑定手段** | **空物体 + Transformation 约束** |
| **不涉及** | **骨骼（armature）**、权重绘制、IK |
| **为什么不用骨骼** | 履带是**刚性块的链条**，不是要变形的肉体；**约束更合适** |

> **★ 这是"硬表面绑定"与"角色绑定"的分野**：
> - **角色** → 骨骼 + 权重 + IK
> - **机械** → **空物体 + 约束**（本章）
> **本书只讲后者。**

## 失败模式（F-B11）

| 编号 | 现象 | 根因 | 处置 |
|---|---|---|---|
| **F-B11-01** | 约束的 Target 下拉里找不到空物体 | **没重命名** | 先 **F2** 给空物体命名 |
| **F-B11-02** | 转空球履带不动 | **Map From / Map To 设错** | **Map From = Rotation**、**Map To = Location** |
| **F-B11-03** | 履带运动方向反了 | Source Axis 不对 | 改 **Y Source Axis**，或改 X Max 正负 |
| **F-B11-04** | 转一点点履带就飞出去 | **X Max 太大** | 原文取 **1 degree** |
| **F-B11-05** | 转超过一定角度履带不动了 | 没勾 Extrapolate | **勾 `Extrapolate`** |
| **F-B11-06** | 约束表现和预期不符（跟着视图变） | Owner 空间不对 | **Owner 设 `Local Space`** |
| **F-B11-07** | 设了父子但反了 | Ctrl+P 选择顺序错 | **先选子级，再选父级** |
| **F-B11-08** | 空物体挡住选模型 | 空物体可见 | 按 **H** 隐藏（空物体本来不渲染，但视口可见） |
| **F-B11-09** | 想用骨骼绑履带 | 手段选错 | 机械件用**空物体 + 约束**，不用骨骼 |

### 主动轮的约束比例（已核对原文）

| 项 | 设置 | 原文 |
|---|---|---|
| **主动轮约束比例** | **每 1° 球旋转 → 主动轮转 100°** | 「**空球每转一度，主动轮就会转 100 度**」 |
