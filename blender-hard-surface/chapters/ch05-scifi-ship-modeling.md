| **面数** | **高模（high-poly）** | **★ 中模（medium-poly）** |

## 5.1 ★★★★★ 建基础形体（Modeling basic shapes）

> **原文**：
> 「**本节我们要为飞船创建基础形体。我们将从座舱（cockpit）开始，
> 因为它是飞船的中心部分。
> 其他一切——包括机翼、引擎、装甲——都会附着到座舱上。**」

**★★★★★ 一条关键的建模顺序判据**：

> **★★★ 「从座舱开始，因为它是中心，其他一切附着到它上面。」**
> **★ 这与 ch02 的"先建最大件"是同一原则** ——
> **但这里的理由更明确：座舱是"装配基准"。**
> **★ 判据：先建"其他件要围绕它放"的那个件。**

### 5.1.1 ★★★★ 步骤 1–5：座舱（五步）

| 步 | 原文操作 | 关键 |
|---|---|---|
| **1** | **加立方体 → 移动边做成机头** | **★ 纯移动边，不挤出** |
| **2** | **`E` 挤出机头后部几次 + `S` 缩放各段** | **★ 挤出 + 缩放交替** |
| **3** | **侧面加立方体 → 重塑 →（用 Mirror 复制到另一侧）** | **★ Mirror 首次在此出现** |
| **4** | **侧面再挤出 → 加两个环切 → `P` 分离中间段 → `Alt+S` 收窄** | **★ `P` + `Alt+S` 组合** |
| **5** | **`Ctrl+J` 合并回来 → `F` 填充面** | **★ 合并 + 填充** |

**★★★★★ `Alt + S` 的第二次精确定义（ch02 已讲，这里更清楚）**：
> **原文**：
> 「**用 `Alt + S` 会把这个面推向它朝向的方向。**
> **这会缩小形状，同时确保每条边到起始点的距离相等。**」

> **★★★ 判据：`Alt+S` 是"等距内缩/外扩"，`S` 是"按轴向缩放"** ——
> **★ 前者沿法向，后者沿物体轴。**

**★★★★ `P` + `Ctrl+J` + `F` 的三件套**：

| 键 | 功能 | 用途 |
|---|---|---|
| **`P`** | **★ 分离（Separate）** | **把一段面单独拿出来处理** |
| **`Ctrl+J`** | **★ 合并物体（Join）** | **处理完再合回去** |
| **`F`** | **★ 填充面（Fill）** | **补上分离留下的洞** |

> **★★ 判据：需要"临时把一段面单独改形"时，`P` → 改 → `Ctrl+J` 合回** ——
> **★ 这样不会牵连周围的面。**

### 5.1.2 ★★★★★ 步骤 6：推进系统（"平滑 + 挖孔"）

> **原文**：
> 「**用 `Ctrl+B` 给底部形状的侧面加倒角，然后在后面加一个圆柱。
> 借助更多倒角和挤出，把形状做平滑并在后面挖一个孔。
> 这个形状将是推进系统。**」

**★★★★ 推进系统的三步**：

| 步 | 操作 |
|---|---|
| **1** | **`Ctrl+B` 给侧面加倒角** |
| **2** | **加圆柱到后方** |
| **3** | **更多倒角 + 挤出 → 平滑 → 后方挖孔** |

> **★★ 判据：喷口造型 = "圆柱 + 倒角 + 挖孔"** ——
> **★ 不需要特殊工具，就是基本操作的组合。**

### 5.1.3 ★★★★★ 步骤 7–12：引擎、机翼、风挡（六个件）

| 步 | 原文操作 | 关键 |
|---|---|---|
| **7** | **机身后面加立方体做引擎座** | — |
| **8** | **再加立方体 → 向前延伸做机翼 → 旋转对齐已有形状** | **★ 旋转对齐** |
| **9** | **`Shift+D` 复制前面的面 → 前移 → 挤出** | **★ 复制面再挤出** |
| **10** | **重复做出约两倍长的形状 → `Ctrl+R` 中间加环切 → `Alt+S` 推向船中央** | **★ 环切 + Alt+S** |
| **11** | **把整个机翼向外推，做出机翼间距** | — |
| **12** | **座舱后部的面 `E` 向上挤出 → 前缘拉得比后缘高** | **★ 拉出坡度** |

**★★★★★ 三个"造形"技巧（本节的核心）**：

**① `Shift+D` 复制面（不是复制物体）**
> **★★ 判据：`Shift+D` 在 Edit Mode 里复制的是"选中的面"，在 Object Mode 里复制的是"整个物体"。**
> **★ 这是一个容易混淆的点。**

**② 重复 + 加环切 + `Alt+S` = 机翼分段的通用做法**
> **★★ 原文**：「重复做出约两倍长的形状……用 `Ctrl+R` 在中间加一个环切……
> 用 `Alt+S`，面会沿它朝向的方向被推出，推向船的中央。」

**③ "前缘高于后缘" = 坡度**
> **★★ 原文**：「把座舱形状后面的面用 `E` 向上挤出，**把前缘拉得比后缘高。**」
> **★ 这样机翼就有了"上扬"的造型。**

## 5.2 ★★★★★ 加细节（Adding details，十二步）

> **原文**：
> 「**我们做了足够的基础形体来构成飞船。
> 现在继续增加飞船上的细节程度，并给已有形状添加更多物体。
> 这里我们会改善飞船外观，但不会做得太复杂。**」

**★★★★★ 本节的最重要产出：三个"进气口"做法**：

### 5.2.1 ★★★★★ 机头罩 + 风挡框（步骤 1–4）

| 步 | 原文操作 | 关键 |
|---|---|---|
| **1** | **`Shift+D` 复制机头顶部的面 → 上移** | — |
| **2** | **`E` 向下挤出 → 后面加环切 → ★ `Shift+N` 修法线** | **★ 挤出后必须修法线** |
| **3** | **挤出刚做的环切底部面 → 做成风挡框（四步挤出）** | — |
| **4** | **可能需要把风挡做得更宽/更大来适配框** | — |

**★★★★★ 一条"挤出后必须修法线"的判据**：
> **原文**：「**挤出后记得用 `Shift + N` 修正法线。**」

> **★★★ 判据：每次挤出/加面之后，法线可能反向** ——
> **★ 尤其在"复制面 → 挤出 → 缩放"这类操作后。**
> **★ `Shift+N`（或 `Ctrl+N`）是修复手段。**

**★★★★ 步骤 5 的倒角**：
> **原文**：「用 `Ctrl+B` 给机头罩、风挡、风挡框后面的一些边加倒角。
> **这会让形状流动得更好。**」

> **★★ 判据：倒角的作用之一是"让形状流动"（flow better）** ——
> **★ 不只是"做圆边"，还是"让面的走向更顺"。**

### 5.2.2 ★★★★★ 进气口（Air intake）的三种做法（本节技术核心）

**做法一：Insert + Extrude（步骤 6–7）**

> **原文**：
> 「**把边向机翼方向移回，做出形状上的一个角度。
> 选中面按 `I` 插入新面，然后按 `E` 挤出，把面向内移到所需深度，做出进气口。**」

```
选面 → I（内插）→ E（挤出）→ 向内推 → ★ 进气口
```

**做法二：复制底面 + `Alt+S` + 挤出（步骤 8）**

> **原文**：
> 「**复制进气口底部的两个面并下移。
> 可以用 `Alt + S` 按它们朝向的方向移动。向下挤出做出类似的形状。**」

**做法三：再次 Insert 做第二个进气口（步骤 9）**

> **原文**：「**再次插入面来做另一个进气口。**」

**★★★★★ 三种做法的选择判据**：

| 做法 | 用什么 | 适合 |
|---|---|---|
| **① 内插 + 挤出** | **`I` → `E` → 向内推** | **★ "凹进去的洞"（真正的进气口）** |
| **② 复制面 + `Alt+S`** | **`Shift+D` → `Alt+S` → `E`** | **★ "凸出来的唇"** |
| **③ 重复做法 ①** | — | **★ 同一部件上的第二个进气口** |

> **★★★ 判据：进气口 = "内插 + 向内挤出"，唇口 = "复制 + 外推"。**
> **★ 一个是"凹"，一个是"凸"，用同一套工具的两种方向。**

### 5.2.3 ★★★★★ 机头凹陷（Nose dent，步骤 10–12）

> **原文**：
> 「**1. 给座舱顶部和底部的边加倒角。顶部只倒前面的边，
> 然后双击 `G` 向上滑动顶点。**
> **2. 选中机头顶部的面并挤出，然后按右键把它们弹回原位。**
> **3. 把 3D 游标放在前缘，在 Z 轴上把面缩放为 0 以压平它们。**
> **4. 单独缩小各条边，让凹陷在后面变窄。**」

**★★★★★ 一个"挤出 0 距离"的技巧（步骤 2）**：
> **原文**：「**选中机头顶部的面并挤出，然后按右键把它们弹回原位。**」

> **★★★ 判据：`E` 后立刻按右键 = "挤出但停在原地"（零距离挤出）** ——
> **★ 这会创建"新的面/边但位置不变"，用于"复制拓扑而不移动"。**
> **★ ch02 的枪托橡胶垫也用了这招（`E` + 右键 → `Alt+S` 加厚）。**

**★★★★ 步骤 3 的"游标 + Z 轴归零压平"**：
> **★★ 把游标放到前缘 → 枢轴设 3D Cursor → `S` `Z` `0` → 面沿"前缘所在平面"压平。**

**★★★★ 步骤 4 的"逐边缩小"**：
> **原文**：「**单独缩小各条边，让凹陷在后面变窄。**」

> **★★ 判据：让凹陷"呈楔形"= 后面的边缩得比前面多。**

### 5.2.4 ★★★★★ 炮形部件 + Shear 工具（步骤 13–14）

> **原文**：
> 「**用同样的技术，在座舱侧面加一个类似的物体。**
> **在物体前面再加两个形状，让它看起来像一把枪。**」
> 「**选中枪末端的圆，激活屏幕左侧的 Shear（错切）工具。
> 把顶部滑块向后拖以错切表面。拖动滑块后，可以在 Shear 菜单里手动调整偏移值。**」

**★★★★★ Shear 是本章唯一的新工具**：

| 项 | 内容 |
|---|---|
| **激活** | **屏幕左侧工具栏的 Shear** |
| **操作** | **拖顶部滑块向后** |
| **★ 精调** | **★ 拖动后在左下角 Shear 菜单里改偏移值** |

> **★★ 判据：Shear = "错切"，让平面上的顶点平行移动** ——
> **★ 用于"把圆形截面切成斜口"这类需求（炮弹尖、斜切管口）。**

## 5.3 ★★★★★ 装甲板（Modeling armor panels）—— 本章最重要的技术

> **原文**：
> 「**现在我们学习如何创建装甲板来覆盖飞船外表。
> 我们会用一个新物体并给它加修改器，从而塑造装甲板。
> 这能改善飞船外观。**」

### 5.3.1 ★★★★★ 装甲板的四步（本节核心）

> **原文**：
> 「**1. 复制座舱后部的顶面并分离成新物体。
> 我们这里要用 Mirror 修改器，所以删掉面的一半。**
> **2. 加一个 Solidify 修改器和一个 Mirror 修改器。
> 在 Solidify 里把厚度设为 0.1m，并勾选 Even Thickness。**
> **3. 从侧面挤出一条边并向下拉，形成装甲板。记得可以双击 `G` 滑动顶点。**
> **4. 给这个形状加几个环切，把后边向内推。**」

**★★★★★ 装甲板 = "平面 + Solidify + Mirror"（本节的方法论）**：

```
从一个"面"开始（★ 不是立方体！）
   ↓
加 Solidify（★ 厚度 0.1m + Even Thickness）
   ↓ ★ 平面变成"有厚度的板"
加 Mirror（★ 复制到另一侧）
   ↓
挤出边 → 塑造外形
```

**★★★★★ 三个关键参数**：

| 参数 | 值 | 为什么 |
|---|---|---|
| **★ Solidify 厚度** | **★ 0.1m** | **★ 装甲板的实际厚度** |
| **★ Even Thickness** | **★ 必勾** | **★ 否则斜面厚度不均（ch03 已讲）** |
| **★ Mirror** | **★ 删一半再加** | **★ 保证对称** |

> **★★★ 判据：装甲板从"一个面"开始，不是从"立方体"开始。**
> **★ 因为装甲板本质是"薄壳"，Solidify 正好把它变厚。**
> **★ 从立方体开始反而要"抽壳"，麻烦得多。**

**★★★★ 步骤 1 的一个细节**：
> **原文**：「**我们这里要用 Mirror 修改器，所以删掉面的一半。**」

> **★★ 判据：用 Mirror 前必须"只留一半"** ——
> **★ 否则镜像后会重叠（两面在中间重合）。**

### 5.3.2 ★★★★ 排气管（Rear exhaust，步骤 5–6）

> **原文**：
> 「**在引擎上方放一个立方体，塑形使其契合我们从装甲板切出的形状。
> 用 `Ctrl+B` 给边加倒角，然后在后面 `I` 插入并 `E` 挤出一个面。这将成为排气管。**」
> 「**重复这个过程，做出另外两根管子从这个形状伸出。**」

| 步 | 操作 |
|---|---|
| **1** | **引擎上方放立方体 → 塑形契合切口** |
| **2** | **`Ctrl+B` 倒角** |
| **3** | **后面 `I` 插入 → `E` 挤出 → 排气管** |
| **4** | **重复做出另两根** |

> **★★ 判据：排气管 = "立方体 + 倒角 + 内插挤出"** ——
> **★ 与进气口用的是同一套技术，只是"向内"变"向外"。**

### 5.3.3 ★★★★★ 一条"对齐角度"的判据（本节最实用）

> **原文**：
> 「**当挤出装甲板的新部件时，
> 你可以通过"先挤出边，然后用 3D 游标向外缩放"来确保它们与另一个面有相同的角度。**」

**★★★★★ 这是"复制一个面角度"的方法**：

```
要"新部件与已有面同角度"
   ↓ 直接挤出面 → ★ 角度是随机的
   ↓
"先挤出边 → 用 3D 游标做枢轴 → 向外缩放"
   ↓ ★ 新部件与参考面共面/同角
```

> **★★★ 判据：想让新部件"与某面同角度"→ 用"边挤出 + 游标缩放"，不要直接挤出面。**

**★★★★ 机翼装甲（步骤 7）**：
> **原文**：「**在机翼起始处加另一个装甲板。**」
> **★ 用的是"同一物体"** —— **因为装甲板的修改器（Solidify + Mirror）可以复用。**

## 5.4 ★★★★★ 加更多部件（Adding more parts）

> **原文**：
> 「**本节我们继续给飞船添加更多部件细节，把剩下的基础形体替换为更精致的。
> 我们会完成机翼、座舱和飞船后部，并添加其他细节。**」

### 5.4.1 ★★★★★ 机翼中段的"细化链"（步骤 1–9）

| 步 | 原文操作 | 关键 |
|---|---|---|
| **1** | **机翼侧面加形状 → 前面加平面 → 旋转到与已有形状同角度** | **★ 旋转对齐** |
| **2** | **用环切把平面分成两个 → 向前挤出 → 各加两个环切** | — |
| **3** | **`Alt+S` 把外面向外推（保证方向对）→ 另一侧同样做** | **★ `Alt+S` 保方向** |
| **4** | **加立方体 → `S` 做长而薄** | — |
| **5** | **两个环切 → 后边向前推** | — |
| **6** | **再加环切 → 挤出 → 边再前推** | — |
| **7** | **薄长面继续挤出 → 边再前推** | — |
| **8** | **前面再加立方体 → 后边前推 → 环切 → 挤出 → 边并拢** | — |
| **9** | **机翼外侧加立方体 → Y 轴放大到与机翼同长 → 倒角外边** | **★ Y 轴对齐长度** |

**★★★★★ "重复同一动作"是机翼的做法**：
> **★★ 步骤 4–8 全是"加立方体 → 环切 → 推边 → 挤出 → 推边"** ——
> **★ 同一模式重复 4 次，做出"层叠的机翼片"。**

> **★★★ 判据：复杂机翼不需要新工具，而是"基本动作的重复组合"。**

### 5.4.2 ★★★★★ Array 做格栅（步骤 10–12）

> **原文**：
> 「**给这个形状的侧面加一个更小的立方体，同样倒角。
> 按 `P` 把它分离成新物体。**」
> 「**在修改器属性标签里，加一个 Array 修改器来多次复制这个形状，沿着机翼排列。**」
> **原文（连接件）**：
> 「**加一个小立方体连接机翼的两个部分。
> 把顶面移到侧面，让形状有角度。**」
> 「**给这个形状加 Array 修改器。**」
> 「**复制这个阵列并移到第一个下面，让形状看起来更复杂。**」
