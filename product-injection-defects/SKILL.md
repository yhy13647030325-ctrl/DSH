## 全书最核心的一条方法：多级注射四段法

**100 个案例中 49 例把"多级注射及位置切换"作为第一条对策**（位置切换 47 次、保压 44 次）。这是本书的骨干方法。

### 标准四段（原文模板，案例 2）

| 段 | 动作 | 目的 |
|---|---|---|
| **第一段** | 用相对快的速度**刚刚充满流道至进胶口**，并**找出相应的切换位置** | 快速通过流道，减少压力损失与冷却 |
| **第二段** | 用**慢速及很小的位置充过进胶口附近** | 慢速通过浇口，抑制高剪切与喷射 |
| **第三段** | 用快速充满模腔的 **90%**，以免高温熔融胶料冷却 | 中段必须快，否则前沿冷却形成波浪纹 |
| **第四段** | 用**慢速充满模腔**，使模腔内空气**完全排出** | 慢速排气，避免困气与烧焦 |
| **转换** | 最后转换到**保压切换位置** | 补缩 |

### 参数规律（从 100 例统计）

| 项 | 分布 | 说明 |
|---|---|---|
| 第一段速度 | **"相对快的速度" 26 例**（"中等速度" 8 例） | 默认取相对快 |
| 第三段速度 | **"快速" 16 例**（"中等速度"/"中速" 8 例，"慢速" 8 例） | 通常快；薄壁/熔接处用中速 |
| 第三段充满比例 | **90% 16 例**（95% 3 例，85% 2 例，97%、70% 各 1） | **默认 90%**，薄壁处可提到 95–97%，熔接处降到 70% |
| 含"保压"对策 | 43 例 | 保压是第二高频手段 |
| 含"模温"对策 | 20 例 | 第三高频 |

> **注意：四段不是教条。** 案例 7（融合线在肉薄处）第三段用**中速充满模腔的 70%**，"以便胶流冲过产品肉薄处，避免熔融胶料在肉薄处合流"；案例 16（末端烧焦）第一段用**中速**（不是"相对快"），第三段**中速充满模腔的 97%**，第四段慢速排气。**参数要按缺陷位置与结构改。**

## 第 1 部分的五个工艺参数（理解缺陷的前提）

原书把注塑工艺参数分五类调：

| 参数 | 影响什么 | 典型缺陷 |
|---|---|---|
| **压力**（注射压力） | 能否充满、密度 | 缺胶、披锋 |
| **流量/速度** | 剪切热、喷射 | 气纹、流痕、烧焦 |
| **温度**（料温/模温） | 流动性、冷却 | 熔接痕、变形、色差 |
| **时间**（注射/保压/冷却） | 补缩、定型 | 缩水、变形 |
| **位置**（切换位置） | 各段的分界 | 几乎所有缺陷 |

> **"位置"被单列为一个参数**，这是本书的特别之处：**切换位置定错了，后面所有段都白调。**

## 缺陷归因的两条主路径

### 路径 A：工艺参数（调机能解决）

```
温度不够/速度过快 → 高剪切 → 熔料分解 → 气纹、烧焦、流痕
速度/位置不当     → 料流前沿冷却 → 波浪纹、缺胶
保压不足/时间短   → 补缩不够 → 缩水、凹点
模温不均          → 冷却不均 → 变形、翘曲
```

### 路径 B：模具与结构（要改模或改结构）

```
浇口太小/位置不当 → 高剪切、喷射 → 气纹、流痕、熔接痕
排气不良          → 气体排不出 → 困气、烧焦、气纹
拔模不足/表面粗糙 → 脱模阻力大 → 拉模、拖伤、擦烧
顶出面积不足      → 局部应力 → 顶白、顶针印、变形
壁厚不均          → 冷却快慢不一 → 缩水、变形
熔接位置在薄壁/受力处 → 强度不足 → 融合线、断裂
```

> **判别顺序**：先查工艺（便宜），改不动再查模具（贵），模具也改不动才改结构（最贵）。详见 [references/decision-tree.md](references/decision-tree.md)。

## 限制

- 书中案例为**2000 年代的实际生产案例**，材料牌号（如 ABS PA757、PMMA、PCEXL1414）与设备参数以当时为准，**实际调机需按当前材料与设备重新验证**。
- 扫描件 OCR，个别术语与数字可能识别有误（如"肉薄"=薄壁"、"水口"=浇口、"行位"=滑块），已按行业惯例校正；不确定处标 **（OCR 存疑）**。
- 书中**不给完整的材料物性表与 Moldflow 仿真流程**（书中未展开）。
- "多级注射四段法"是书中的通用模板，但每个案例的参数都不同，**不可照抄参数，只能照抄思路**。
