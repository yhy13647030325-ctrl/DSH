# 注塑成型工艺表怎么读

> 每个案例末尾都附一张"注塑成型工艺表"。这张表是**可复制的调机记录**，但 OCR 后表格散乱，本页说明它有哪些字段、怎么对应用。

## 一、表格的字段（从案例 7 与其他案例归纳）

### 1. 温度类

| 字段 | 含义 |
|---|---|
| **料筒温度** | 分段：一段（近喷嘴）→ 末段（近料斗），案例中出现 2200 / 230℃ / 235℃ / 240℃ 等 |
| **模具温度** | 前模 / 后模 分开记 |
| **干燥温度** | 如 85℃ |
| **干燥时间** | 如 2.5h |
| **干燥方式** | 抽湿干燥机 / 除湿机 |

### 2. 压力类

| 字段 | 含义 |
|---|---|
| **射出压力** | 分段压力 |
| **保压压力** | 通常低于射出压力 |
| **背压** | 塑化时螺杆后退阻力 |
| **锁模力** | 案例中也记（如 100t、160T、2200） |

### 3. 速度类

| 字段 | 含义 |
|---|---|
| **射出速度** | 分段速度（对应多级注射四段） |
| **射速位置** | **各段的切换位置**（关键！） |
| **回缩速度** | 抽胶/松退速度 |
| **回转速度** | 螺杆转速 |

### 4. 位置类

| 字段 | 含义 |
|---|---|
| **射胶时间** | 如 3.06 / 0.06 |
| **射胶量** | 如 250g |
| **射胶残量** | 余料 |
| **料量位置** | 计量位置 |
| **保压位置** | 保压切换点 |
| **回缩位置** | 松退位置 |
| **回转位置** | — |
| **顶出长度** | 如 2.5 |
| **顶出次数** | — |

### 5. 时间类

| 字段 | 含义 |
|---|---|
| **冷却时间** | — |
| **保压时间** | — |
| **全程时间** | 周期 |
| **合模保护时间** | — |
| **加料监督时间** | — |
| **吹气时间 / 吹气延时** | 若有气辅 |

### 6. 其他

| 字段 | 含义 |
|---|---|
| **原料** | 牌号 |
| **颜色** | — |
| **再生料使用** | 比例 |
| **成品重 / 水口重** | 单件与流道 |
| **浇口入胶方式** | 点浇口 / 潜水等 |
| **注塑机** | 如海天 160T |
| **模具模出数** | 1×2 |
| **模具运水图** | 冷却水路布置 |
| **恒温机** | 是否用 |

## 二、读表的三个重点

### 重点 1：射速位置 = 多级注射的分界

**这是整张表最有价值的一栏。** 它记录了四段法每段在哪里切换。

> 案例里的"位置切换过早/过晚"就是指这一栏设错。

### 重点 2：料筒温度是分段的

不要只看一个数。**近喷嘴段温度最高，逐段降低**（案例 7 里出现 2200（OCR 存疑，疑为 220℃）/230℃/235℃/240℃ 的组合）。

> 分段控温的目的：**保证喷嘴端流动性最好，料斗端不提前塑化结块。**

### 重点 3：前后模温分开

案例 31 的核心对策就是**前后模设温差**（前 110℃ / 后 70℃）。表里"前模/后模"两栏就是为此。

## 三、OCR 表格的已知问题

扫描件表格经 OCR 后是**按行散落的文字**，顺序错乱。例如案例 7 的表格被识别成：

```
射出压力 / 射出速度 / 射速位置 / 射胶时间 / 实际 83℃ / 回缩位置 / 吹气时间 ...
```

**数值与字段名已经错位，不可直接引用。**

> **本技能的处理方式**：只提取了**案例正文里的工艺参数**（那些在"对策"里明确写出的，如"第一段快速""第三段 90%""保压 0.5s"），**不搬运表格里的数字**，因为无法保证对应关系正确。

## 四、如果你要看原表的数字

请直接翻原书对应页（见 [case-index.md](case-index.md) 的页码），**不要用本技能的 OCR 数字**。

## 五、工艺表能教给你的方法（这部分可靠）

虽然数字不可靠，但**表的字段结构本身**教了三件事：

1. **注塑参数必须分段记录**（分段压力、分段速度、分段位置）——单一数值不够
2. **温度要分料筒段 + 前后模**——不是一个"模温"
3. **时间要分开记**（射胶/保压/冷却/全程）——因为它们影响不同的缺陷

> 这三条与 [chapters/ch00-overview.md](../chapters/ch00-overview.md) 的五参数分类一致，互为印证。
