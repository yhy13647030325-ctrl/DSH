# 缺陷诊断决策树

> 用途：手上有个缺陷，先走这张树决定"改工艺还是改模具/结构"。这是成本从低到高的顺序。

## 第 0 步：先记录六个信息（缺一个就别往下走）

| 信息 | 为什么必须 |
|---|---|
| **什么缺陷**（现象） | 决定查哪一类 |
| **在哪个位置**（进胶口附近 / 末端 / 骨位 / 转角 / 顶出位） | **位置几乎决定成因** |
| **什么材料**（PMMA / ABS / PC / PP…） | 流动性不同，对策不同 |
| **是否透明件** | 透明件对外观缺陷极其敏感 |
| **入胶方式**（扇形 / 搭阶 / 潜水 / 点浇口…） | 剪切与喷射的主因 |
| **模温 / 料温 / 当前分段参数** | 判断是参数还是结构 |

> 书里每个案例都强制记录这组信息（案例开头的"注塑机特征/模具特征/产品特征"），**这不是格式，是诊断所需**。

## 第 1 步：按位置分叉

**位置是本书最强的诊断线索。**

```
缺陷在哪个位置？
├─ 进胶口附近 ──────────────→ 走 A（剪切/喷射问题）
├─ 料流末端 / 最后充填处 ────→ 走 B（排气/困气问题）
├─ 两股料流汇合处 ──────────→ 走 C（熔接问题）
├─ 骨位/柱位/厚薄交界 ──────→ 走 D（补缩/冷却问题）
├─ 顶出位置 ────────────────→ 走 E（顶出问题）
├─ 侧壁/滑块/深腔 ──────────→ 走 F（脱模问题）
└─ 整件都有 / 随机分布 ─────→ 走 G（材料/设备/环境）
```

## 走 A：进胶口附近的缺陷（气纹、流痕、烘印）

**机理**：浇口截面突然变小 → 熔料通过时高剪切 → 瞬间升温 → 分解产气。

**处置顺序（成本从低到高）**：

| 序 | 动作 | 判据 | 对应案例 |
|---|---|---|---|
| A1 | **改多级注射，浇口段慢速** | 第一段快速充满流道到浇口，**第二段慢速+很小位置**通过浇口 | 2、4、5 等（49 例共用） |
| A2 | **调位置切换点** | 切换早了/晚了都不行 | 2（过早）、16（过晚） |
| A3 | **提高模温** | 模温高 → 熔料流动性好 → 剪切小 | 4 |
| A4 | **加大进胶截面** | 截面大 → 剪切小 | 4 |
| A5 | **浇口附近加开排气** | 气体要有去处 | 4 |
| A6 | 改浇口形式/位置（改模） | 潜水/搭阶改扇形等 | （书中未系统展开） |

> **先做 A1–A2**，这两条不用改任何硬件。A3–A5 要调设备/改模，A6 改模最贵。

## 走 B：末端的缺陷（烧焦、困气、缺胶）

**机理**：气体排不出，被压缩升温 → 焦化；或气堵住料流 → 缺胶。

| 序 | 动作 | 判据 | 案例 |
|---|---|---|---|
| B1 | **最后一段慢速充满** | 使模腔空气完全排出 | 全模板 |
| B2 | **降末端速度 + 降料温** | 减少分解 | 16、55、63 |
| B3 | **加排气**（模具） | 排气槽/镶件间隙/顶针排气 | 26、30、47 |
| B4 | 调整浇口位置使料流平衡 | 改模 | 20、27 |
| B5 | 加大末端截面 | 改模 | （书中未展开） |

> **B3 是分水岭**：调参数只能缓解，**排气不良必须改模**。判断方法——参数调到极限仍困气，就是排气问题。

## 走 C：熔接/夹线的缺陷（融合线、夹水线、夹线）

**机理**：两股料流分开后汇合，界面未充分熔合。

| 序 | 动作 | 判据 | 案例 |
|---|---|---|---|
| C1 | **提高料温 / 模温** | 界面温度高才能熔合 | 7、20 |
| C2 | **调整速度让汇合点在有利位置** | 案例 7 用**中速充满 70%**，"以便胶流冲过产品肉薄处，避免熔融胶料在肉薄处合流" | 7 |
| C3 | **降低速度 + 低模温**（反例） | 案例 20 用**慢速 + 低模温**"改变熔接痕位置" | 20 |
| C4 | 改浇口位置（让熔接线避开受力/外观面） | 改模 | 20、27 |
| C5 | 汇合处加排气 | 改模 | — |

> **注意 C2 与 C3 方向相反**：案例 7 要"冲过薄壁"，案例 20 要"慢速走胶改变位置"。**同样是熔接痕，对策取决于你想让汇合点移到哪。** 这是本节最容易照抄错的地方。

## 走 D：骨位/柱位/厚薄交界的缺陷（缩水、凹点、光影）

**机理**：厚处冷却慢，收缩时补缩不足。

| 序 | 动作 | 判据 | 案例 |
|---|---|---|---|
| D1 | **加保压压力 / 延长保压时间** | 补缩 | 52（扣位缩水） |
| D2 | **降低模温（局部）** | 快冷减少收缩差 | 6、11 |
| D3 | **减薄厚处**（改结构） | 壁厚均匀 | 见结构技能 |
| D4 | 加筋/掏空（改结构） | 消除厚大区域 | 见结构技能 |

> **D3/D4 是根治**，但要在开模前做。已开模的只能 D1/D2 缓解。

## 走 E：顶出位置的缺陷（顶白、顶针印、顶出变形）

**机理**：顶出时局部应力超过材料屈服。

| 序 | 动作 | 判据 | 案例 |
|---|---|---|---|
| E1 | **增加顶出面积**（顶块代替顶针） | 减小单位面积应力 | 66、67 |
| E2 | **提高模温** | 材料软一点不易白化 | 66 |
| E3 | **缩短冷却时间/延长**（找对方向） | 案例 98 是两侧面顶出变形 | 98 |
| E4 | 降低保压/降低顶出速度 | 减少内应力 | 25 |
| E5 | 加脱模斜度（改模） | 减小脱模阻力 | 见结构技能 |

> **顶白和拉白的区别**：顶白在顶出位置且**呈局部块状**；拉白在侧壁且**沿脱模方向呈条纹**。前者是顶出问题（E），后者是脱模问题（F）。

## 走 F：侧壁/滑块/深腔的缺陷（拉模、拖伤、擦烧）

**机理**：脱模阻力 > 材料强度，或侧向摩擦生热。

| 序 | 动作 | 判据 | 案例 |
|---|---|---|---|
| F1 | **抛光模具表面** | 减小摩擦 | 9、94、95 |
| F2 | **加/加大脱模斜度**（改模） | 根本对策 | 9、32 |
| F3 | **提高模温** | 材料软化 | 9 |
| F4 | 检查滑块/斜顶配合与润滑 | 行位拖模 | 82 |
| F5 | 减小保压（减少过填） | 过填增大脱模阻力 | 88 |

> **"擦烧"是摩擦热导致局部熔融**——不只是划伤。所以要同时降速与润滑。

## 走 G：整件/随机分布（尺寸偏差、色差、脏污、混色）

| 序 | 动作 | 判据 | 案例 |
|---|---|---|---|
| G1 | 检查原料干燥 | 水汽→银纹/发雾 | 12 |
| G2 | 检查料筒/螺杆清洁度 | 黑点、脏污 | 62、84 |
| G3 | 检查色母分散与混料 | 色差 | 99 |
| G4 | 检查模温均匀性与冷却水路 | 尺寸不一 | 83 |
| G5 | 检查保压与计量位置稳定性 | 尺寸波动 | 28、38、83 |

## 第 2 步：工艺 or 模具？（分水岭判断）

调完工艺仍存在 → 改模具。**三条硬判据**：

| 判据 | 结论 |
|---|---|
| 参数已到工艺窗口边界（再调就出别的缺陷） | **改模** |
| 同一模具不同腔表现不同 | **模具流道平衡问题**，改模 |
| 同一模具换个材料就好 | 工艺或材料问题，先调工艺 |

## 第 3 步：仍不行 → 改结构

改模也解决不了（如壁厚不均、熔接在受力处），要回到结构设计。此时调用 `product-structure-liubaoshun` 第一章 1.5 的注塑三要点。

## 一张速查：缺陷 → 首选动作

| 缺陷 | 首选 | 类型 |
|---|---|---|
| 气纹/流痕/烘印 | 多级注射（浇口段慢速）+ 调切换位置 | 工艺 |
| 烧焦/困气 | 最后段慢速 + 加排气 | 工艺→模具 |
| 融合线/夹水线 | 提料温模温 + 调汇合位置 | 工艺 |
| 缩水/凹点/光影 | 加保压/延长保压 | 工艺 |
| 变形/翘曲 | 调前后模温差 + 保压曲线 | 工艺 |
| 顶白/顶针印 | 增加顶出面积 + 提模温 | 模具 |
| 拉模/拖伤/擦烧 | 抛光 + 加脱模斜度 | 模具 |
| 披锋/毛边 | 降压力/提锁模力 | 工艺 |
| 粘模 | 抛光 + 加斜度 + 降保压 | 模具 |
| 缺胶/填充不满 | 提压力速度料温 | 工艺 |
| 尺寸偏差 | 查保压/计量/模温均匀性 | 工艺 |
| 色差/脏污 | 查原料/清洁/色母 | 材料设备 |

## 本书不给的答案（诚实边界）

- **不给材料物性表与推荐工艺窗口**：案例给的是"这一台机、这一套模、这一种料"的参数。
- **不给模流分析（Moldflow）流程**。
- **不给成本估算**。
- 案例多为 2000 年代设备与材料，**参数需按当前条件重验**。
