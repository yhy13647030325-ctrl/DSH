# 第 0 章：概述——工艺参数与缺陷成因

> 对应书中第 1 部分（书内 p2–11 / PDF p28–37 之前）。这是理解 100 个案例的前提。

## 核心要点

原书先把注塑工艺参数分成**五类**，再把缺陷成因分到这几类上。**记住这个分法，后面 100 个案例都能归位。**

## 一、五个工艺参数

### 1.1 注射成型压力参数

压力决定**能不能充满**、**充得多密**。

| 影响 | 压力不足 | 压力过高 |
|---|---|---|
| 填充 | **缺胶、填充不满** | 披锋、飞边 |
| 内应力 | — | 内应力大、变形 |
| 模具 | — | 易损 |

### 1.2 注射成型流量（速度）参数

**这是本书最核心的参数**——100 个案例里，"速度快"是最常见的致因词。

> 原书反复出现的一句机理：
> **"速度快会产生融料加剧剪切产生高温易分解"**

| 影响 | 速度过快的后果 |
|---|---|
| 剪切 | 熔料在浇口处受**高剪切** → 瞬间升温 → **分解** → 产生气体 |
| 表现 | **气纹、流痕、烧焦、烘印** |
| 速度过慢的后果 | 料流前沿冷却 → **波浪纹、缺胶、熔接痕明显** |

> **速度是双刃**：快了剪切分解，慢了前沿冷却。所以才有"多级注射"——**分段用不同速度**。

### 1.3 注射成型温度参数

包括**料筒温度**与**模具温度**两个不同的东西：

| 温度 | 影响 | 过高 | 过低 |
|---|---|---|---|
| **料温（料筒）** | 流动性、分解 | 分解→气纹、烧焦、色差 | 流动性差→缺胶、熔接痕 |
| **模温** | 冷却速度、表面质量、变形 | 冷却慢→缩水、变形、周期长 | 冷却快→熔接痕明显、内应力、变形 |

> **模温常被当成一个参数，实际要分前后模**。案例 31（镜片变形）的对策就是"**使用两台模温机，前后模温设温差，前模 110℃，后模 70℃**"。

### 1.4 注射成型时间参数

| 时间项 | 影响 | 不足 | 过长 |
|---|---|---|---|
| **注射时间** | 充填 | 缺胶 | — |
| **保压时间** | 补缩、定型 | **缩水、凹点** | 内应力、变形、周期长 |
| **冷却时间** | 定型 | **变形、顶白** | 周期长 |

> 案例 31 的对策里有"**增加保压时间 0.5s，防止产品变形**"——保压时间不只是补缩，也影响变形。
> 同例还演示了**二次保压**："先下降到一次保压，再上升到二次保压"，且第三段用**快速充满 95%**（不是默认的 90%）。**说明"90%"只是最常用的经验值，不是唯一解。**

### 1.5 注射成型位置参数

**位置 = 各段的分界点，也就是"切换位置"。** 这是本书特别强调的参数：

- 案例 2：致因里有"**位置切换过早**"
- 案例 16：致因里有"**位置切换过晚**"

> 同一个参数，早了晚了都出错。**切换位置定错，后面所有段的参数都白调。** 这是"多级注射四段法"里第一段的任务："充满流道至进胶口并**找出相应的切换位置**"。

## 二、缺陷成因的两大类

原书把成因归结到两个方面（这也是我们诊断的分叉点）：

### A 类：工艺参数（调机可解决）

```
温度不够 / 速度过快 → 高剪切 → 熔料分解 → 气纹、烧焦、流痕
速度 / 位置不当    → 料流前沿冷却 → 波浪纹、缺胶
保压不足 / 时间短  → 补缩不够 → 缩水、凹点
模温不均           → 冷却不均 → 变形、翘曲
```

### B 类：模具与结构（要改模或改结构）

```
浇口太小 / 位置不当 → 高剪切、喷射 → 气纹、流痕、熔接痕
排气不良            → 气体排不出 → 困气、烧焦、气纹
拔模不足 / 表面粗糙 → 脱模阻力大 → 拉模、拖伤、擦烧
顶出面积不足        → 局部应力 → 顶白、顶针印、变形
壁厚不均            → 冷却快慢不一 → 缩水、变形
熔接位置在薄壁/受力处 → 强度不足 → 融合线、断裂
```

## 三、注塑机的三个部分（案例里的"注塑机特征"）

案例中每例都给出：

| 项 | 意义 |
|---|---|
| **牌号** | 如 DEMAG、HT86T（宁波）、德玛格（江苏） |
| **锁模力** | 如 50t、86t、100t —— 决定能开多大模、能否压住 |
| **塑化能力** | 如 80g、119g、94g —— 决定单次最大注射量 |

> **为什么记录这三个**：同一种缺陷，在不同锁模力/塑化能力的机器上对策可能不同（如塑化能力不足会表现为缺胶，而非工艺参数问题）。

## 四、模具的四个特征（案例里的"模具特征"）

| 项 | 意义 | 与缺陷的关系 |
|---|---|---|
| **模出数** | 如 1×2（一模两腔） | 影响流程平衡 |
| **入胶方式** | 扇形浇口、搭阶浇口、潜水进胶、点浇口、小水口转大水口 | **决定剪切与喷射**（气纹、流痕的主因） |
| **顶出方式** | 顶针顶出、顶块顶出、顶针及斜顶 | **决定顶白、顶针印、变形** |
| **模具温度** | 如 90℃、100℃、119℃（恒温机） | 决定冷却与变形 |

## 五、产品特征（案例里的"产品特征"）

| 项 | 意义 |
|---|---|
| **材料** | PMMA、ABS PA757、PCEXL1414 等 —— 流动性差异直接影响对策 |
| **颜色** | 透明件对气纹/流痕特别敏感（案例 2、31 都是透明镜片） |
| **产品重（单件）** | 与射胶量匹配 |
| **水口重** | 流道占比，越大越浪费也越影响压力损失 |

> **透明件要特别小心**：案例 2（流痕）、31（变形）都是透明镜片。透明件会把内部应力、流痕全部暴露出来，**外观要求放大了工艺缺陷**。

## 六、常见缺陷与解决办法的对应表（书中 p11 区域）

原书在第 1 部分末尾给了"注塑成型常见制品缺陷及解决方法"，是 100 个案例之前的**速查版**。核心对应关系：

| 缺陷 | 首查参数 | 次查 |
|---|---|---|
| 缺胶/填充不满 | 压力、速度、料温 | 浇口尺寸、排气 |
| 气纹/流痕 | **速度**（过快）、**位置切换** | 浇口、排气、料温 |
| 烧焦/困气 | **排气**、速度 | 料温、模具排气槽 |
| 缩水/凹点 | **保压**、保压时间 | 壁厚、模温 |
| 变形/翘曲 | **模温均匀性**、保压 | 壁厚、冷却时间、顶出 |
| 熔接痕/融合线 | 料温、模温、速度 | 浇口位置、排气 |
| 披锋 | 压力过高、锁模力不足 | 分型面 |
| 拉模/拖伤 | **拔模**、表面粗糙度 | 模温、顶出 |
| 顶白/顶针印 | **顶出面积**、模温 | 保压、冷却时间 |
| 发白 | 内应力（脱模/顶出） | 料温、模温、拔模 |

## 七、一条贯穿全书的判据

> **"速度快会产生融料加剧剪切产生高温易分解"**

这句话在 100 个案例里反复出现，至少覆盖了气纹、流痕、烧焦、烘印四大类。**它的物理链条是**：

```
速度过快
  → 浇口处截面突然变小
  → 熔料通过时受高剪切
  → 剪切生热（不是料筒给的熱）
  → 局部瞬间升温超过材料分解温度
  → 分解产生气体
  → 气体排不出就困在制品里
  → 表现为气纹 / 烧焦 / 烘印 / 流痕
```

> **所以对策的第一步永远是"多级注射"**——把速度分段，让通过浇口那一段慢下来。这就是为什么 49 个案例的第一条对策都是"运用多级注射及位置切换"。
