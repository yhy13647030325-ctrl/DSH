## 核心思想（速记）

1. **设计本质**：不是造物，而是谋事——设计的是生活方式，不是产品本身
2. **事理学核心**：实事求是——先研究"事"（外因），再组织"物"（内因）
3. **内外因分析**：外因（人、环境、时间、条件）决定"应该怎样"；内因（材料、结构、工艺、形态）决定"可以怎样"
4. **目标系统**：回归本源——"初心要做什么？走什么路？再去选择工具和技术"
5. **设计思维六步**：观察→分析→归纳→联想→创造→评价
6. **两大原则**：有限理性原则、适应性原则
7. **全生命周期**：作品→产品→商品→用品→废品，设计是系统性干预
8. **提倡使用，不鼓励占有**：设计的责任是定义需求、引领需求、创造需求

## 使用方式

- 用户问设计方法论/事理学 → 读取 ch03-methodology.md
- 用户问如何做设计分析/用户研究 → 读取 patterns.md 中的内外因分析框架，并给 templates/external-internal-factors.md 供其填写
- 用户问设计思维步骤 → 读取 cheatsheet.md 中的六步法，并给 templates/six-step-worksheet.md 供其填写
- 用户问项目怎么定方向/目标 → 读取 ch02-epistemology.md 目标系统部分，并给 templates/goal-system.md 供其填写
- 用户问具体设计案例 → 读取 ch04-cases.md
- 用户问术语定义 → 读取 glossary.md
- 用户问"某个术语在哪一章" → 查本文件"主题索引"节
- 用户问"这样做对不对/踩了什么坑" → 读取 cheatsheet.md 第十二节"失败模式速查"，或 patterns.md 的"反模式清单"

## 限制

本技能基于柳冠中《设计方法论》及相关公开演讲、访谈内容整理，用于设计思维与方法论指导。具体设计项目需结合实际场景和用户需求。

本技能不含原书电子版；知识库内容以现有文件为边界。文件中标注"（现有材料未展开）"的位置表示现有材料不足以展开，未作任何事实性补充；标注"（应用模板，非原书内容）"的位置为引申的操作化内容，不应被引用为原书观点。

## 相关技能

本技能可与下列技能配合使用（**不修改这两个技能目录中的任何文件**，此处仅为引用与配合说明）：

- **[world-modern-design-history](../world-modern-design-history/SKILL.md)** —— 《世界现代设计史》（王受之）知识库：查设计运动、流派、人物与年代脉络。
  - **配合场景一**：讨论"设计的源与流／变与不变"（本技能 ch01）时，用该技能核查具体运动、风格与年代的先后与因果，避免把形式流变误当作需求本源。
  - **配合场景二**：讨论"传统是创造出来的，绝对不是继承出来的"（本技能 ch01）时，用该技能确认某一风格或流派的创造脉络。
  - **配合场景三**：讨论"中国设计的出路／设计立国"（本技能 ch04）时，用该技能补齐现代设计史的背景参照（"不能总是跟着西方走"这一判断的历史语境）。
  - **分工**：该技能回答"历史上发生了什么、谁在何时做了什么"，本技能回答"面对设计任务应当怎样思考与推进"。
- **[book-to-skill](../book-to-skill/SKILL.md)** —— 把书和文档拆成结构化技能的方法论。
  - **配合场景一**：想把本技能的知识库结构（SKILL.md＋references/chapters＋glossary＋patterns＋cheatsheet＋templates）套用到另一本书时，用该技能执行抽取与组织流程。
  - **配合场景二**：需要诊断本技能"哪些框架提取不足／哪些章节缺少失败模式"时，用该技能的抽取标准做对照复核。
  - **注意**：用该技能重建或扩展任何知识库时，同样受"不得添加原书之外新事实"的边界约束。
