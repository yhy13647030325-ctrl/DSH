# 书籍技能章节的统一格式规范

> **适用范围**：本项目所有"从书蒸馏"的技能章节（共 13 个技能 / 约 4000 页）。
> **制定依据**：`solidworks-practice` 13 章重做的实践（54,307 → 271,420 字符，+400%）。
>
> **核心原则**：**统一"接口"，不统一"骨架"** ——
> 操作手册与理论著作的内容组织方式不同，但**检索接口必须一致**。

---

## 一、章节文件的标准结构（6 段）

每一章按以下顺序组织，**不可增减顺序**：

```
① 章节头（元信息）
② 总纲/概述
③ 按原书小节逐节展开
④ 核心内容表（按书类型二选一）
⑤ 本章空白（诚实边界）
⑥ 与其他章的连接
```

---

## 二、① 章节头：四行元信息

### 格式

```markdown
# 第 N 章：章节标题

> **原书 PageRange（N 页）**｜**本版逐页读完全部 N 页**
> 页码口径：**PDF 索引** / **书内印刷页** / **EPUB 章节+段落**（三选一）
>
> **读法说明**：按原书 `X.1 → X.N` 逐节展开，不跳节。
> 每节含【原文摘录】+【图注还原】+【判据提炼】。
```

### 硬要求

| # | 要求 |
|---|---|
| 1 | **必须写明原书页码范围**（如 `p49–p94`） |
| 2 | **必须写明实读页数**（如"全 46 页"） |
| 3 | **必须声明页码口径**（三者选一） |
| 4 | **必须写明读法**（逐节 or 按主题重组） |

### 页码口径三选一

| 类型 | 口径 | 声明写法 |
|---|---|---|
| **PDF 索引** | 从 1 开始数 PDF 页 | `页码口径：**PDF 索引**` |
| **书内印刷页** | 页脚数字（需实测偏移） | `页码口径：**书内印刷页**（实测 PDF索引 = 书内页 + N）` |
| **EPUB** | 无固定页码 | `页码口径：**章节号 + 段落号**（形如 ch05 §3 ¶2）` |

> **★ 页脚为空或不可提取时，一律用 PDF 索引** ——
> **这是唯一"任何人都能复核"的锚点。**

## 三、② 总纲 + ③ 逐节展开

### 引文格式（硬要求）

> **原文（p123）**：
> 「**逐字摘录的内容**，关键处可用**加粗**标出。」

**四条规则**：

| # | 规则 |
|---|---|
| 1 | **用 `「」` 包裹原文**（不用 `""` 或 `>>`） |
| 2 | **页码紧跟引文**，形如 `（p123）` |
| 3 | **不许改写原文**（可删节用 `…`，不可换词） |
| 4 | **加粗只能加在原文已有的关键词上**，不能自己"强调" |

### 图注还原

原书的图注（件号、尺寸、标注）**必须文字化**：

```markdown
**图 2-41 滚动轴承内圈常见固定形式（9 种）**
```

| 项 | 要求 |
|---|---|
| **图号** | 照原文写（如图 2-41） |
| **图名** | 照原文写 |
| **件号/尺寸** | **凡能读出的，全部列出** |
| **读不出的** | 写 `（图不清，未录）` —— **不许猜** |

### 提炼格式

```markdown
> **★ 判据（或"论点"）：一句话结论**
> 展开说明……
```

**★ 号数量表示重要度**：
| 记号 | 含义 |
|---|---|
| **★** | 有用 |
| **★★** | 重要 |
| **★★★** | 关键判据/核心论点 |
| **★★★★** | 全书级判据（跨章通用） |

## 四、④ 核心内容表：按书类型二选一

### 类型 A：操作/技术类 → **判据表**

**适用**：solidworks-*、blender-*、product-injection-defects

**格式**：

```markdown
## N.x 本章判据总表（共 M 条）

| # | 判据 | 出处 |
|---|---|---|
| 1 | **一句话可执行规则** | p123 |
| 2 | 另一条 | p124 |
```

**判据的判定标准**（必须满足其一）：

| 条件 | 例 |
|---|---|
| **可执行**（照着做） | "网格尺寸 ≤ 圆角半径一半" |
| **可选择**（二选一的依据） | "精确定位用紧配，常拆用间隙配" |
| **可验证**（对错有标准） | "应力变化 < 5% 即收敛" |

> **★ 纯描述性的事实（如"这个按钮在这里"）不算判据** ——
> **那是操作步骤，写进正文即可。**

### 类型 B：理论/方法类 → **概念-论点表**

**适用**：world-modern-design-history、design-psychology-norman、
ergonomics-ding-yulan、design-elements-hannah、product-design-styling-dabbs、
visual-dynamics-industrial-design

**格式**：

```markdown
## N.x 本章概念-论点表（共 M 条）

| # | 概念 | 原文主张 | 支撑案例 | 我的提炼 | 出处 |
|---|---|---|---|---|---|
| 1 | **预设用途** | 「……」 | 门把手 | 看见就知道怎么用 | p12 |
```

**五列的填写要求**：

| 列 | 要求 |
|---|---|
| **概念** | **书中的术语**（用原词） |
| **★ 原文主张** | **作者的核心判断**（尽量逐字，带引号） |
| **支撑案例** | 书中用来论证的具体例子 |
| **★ 我的提炼** | **可迁移的认知**（不是复述） |
| **出处** | 页码 |

> **★★ "我的提炼"列是理论类书的价值所在** ——
> **原文是"作者的观点"，提炼是"读者能用的东西"。**
> **两者必须分开写，不能混为一谈。**

---

## 五、⑤ 本章空白（诚实边界）

**每章必须有**，格式：

```markdown
## N.x 本章的空白

| 缺什么 | 书中情况 | 该去哪查 |
|---|---|---|
| 具体数值表 | 只有定性描述 | 手册/标准 |
| XXX 的操作 | 只提名字，未展开 | 其他章/官方文档 |
```

**三条填写规则**：

| # | 规则 |
|---|---|
| 1 | **不许写"无"**（任何书都有空白） |
| 2 | **必须区分"未展开"与"未读到"** |
| 3 | **"未读到"要明说**（如"本章 p50–p60 未逐页读"） |

---

## 六、⑥ 与其他章的连接

```markdown
## N.x 与其他章的连接

| 本章内容 | 关联章 | 关系 |
|---|---|---|
| 判据 X | ch03 §3.4 | 同一机制 |
| 概念 Y | 另一本书 §2.1 | 同源 |
```

> **★ 跨书关联要写书名**，不能只写 "ch03"（会混淆是哪本书的 ch03）。

## 七、技能级索引（SKILL.md）的统一格式

### 章节索引表

```markdown
| 章节 | 主题 | 内容要点 |
|---|---|---|
| [ch01](chapters/ch01-xxx.md) | 主题（**p1–p14 全 14 页**） | **2.0 万**：要点1、要点2、**N 条判据** |
```

**三列硬要求**：
| 列 | 必须含 |
|---|---|
| **章节** | 链接 |
| **主题** | **页码范围 + 实读页数** |
| **内容要点** | **字数 + 3~5 个关键词 + 判据/论点数** |

### 主题索引

```markdown
- **构念名（术语）** → ch05
- **具体操作** → ch03、ch07
```

## 八、校验脚本的对接

每本书需有 `references/page-manifest.json`：

```json
{
  "book": "《书名》作者，出版社，年份",
  "page_type": "PDF 索引",
  "page_range": [1, 209],
  "read": [1, 2, 3, "...实读的全部页"],
  "note": "页脚为空，统一用 PDF 索引"
}
```

**校验命令**：
```powershell
python validate-page-citations.py --all
```

**检查三项**：页码越界 / 格式混用 / 未实读引用。

## 九、抽查清单（每章完成后自查）

| # | 检查项 | 通过标准 |
|---|---|---|
| 1 | 章节头四行齐全 | 页码 + 实读数 + 口径 + 读法 |
| 2 | 原文引用有页码 | 100% |
| 3 | 图注已文字化 | 能读出的都录了 |
| 4 | 核心表存在 | 判据表 or 概念-论点表 |
| 5 | 空白清单存在 | 至少 3 项 |
| 6 | 无页码越界 | `validate-page-citations.py` 通过 |
| 7 | 无断链 | 链接全部可达 |

## 十、两类的差异对照（速查）

| 项 | 操作/技术类 | 理论/方法类 |
|---|---|---|
| **章节头** | 相同 | 相同 |
| **引文格式** | 相同 | 相同 |
| **★ 核心表** | **判据表**（3 列） | **概念-论点表**（5 列） |
| **★ 表的目的** | **"照着做"** | **"理解并迁移"** |
| **图注** | 重要（件号/尺寸） | 次要（多为案例照片） |
| **空白** | 缺数值/缺操作 | 缺论证/缺反例 |
| **典型章字数** | 1.5~3.7 万 | 1.0~2.0 万 |

> **★ 为什么理论类字数要求更低**：
> **理论书原文本身密度高，可"逐字引用"的比例大** ——
> **不需要像操作手册那样"把一句说明展开成一段"。**
