## 四、全书的"八条主线"（history 蒸馏的产出的最高层结论）

### 主线 1：设计的定义与限度（ch01）
- **★ 限度管理（迪诺·迪尼 2005）**：不可协商（硬约束）vs 可协商（软约束）；多个硬约束矛盾时"重新设定限度"
- **★ 艺术与设计的分界**：不在作品本身，在**"是否被赋予传达功能"**

### 主线 2：从"为权贵"到"为大众"（ch02 → ch05）
- **★ Royal Patrons 体制**（ch02）：定制 + 皇家控制 + 不进市场
- **★ 拉斯金"为大众"**（ch03）："不要再为取悦公爵夫人而生产纺织品"
- **★ 现代主义"两个问题"**（ch05）：设计范畴变了 + 设计为谁服务

### 主线 3：技术决定论与其反叛（ch03/ch04/ch06/ch09）
- **★ `xylography` vs `typography`**：只有活字才带动批量出版
- **★ 美国的批量能力"是从军工标准化转来的"**
- **★ `design` vs `styling`**（ch06/ch09）：前者"解决问题+创造形式"，后者"仅提供不同形式"

### 主线 4：理想主义与现实（ch05/ch07/ch08）
- **★ "新精英主义"悖论**（ch05）：不为精英服务，但强调精英领导
- **★ 乌尔姆偏技术、包豪斯偏艺术**：两次都栽在"一个维度压倒另一个"
- **★ 后现代"死于商业化模仿"**（ch08）

### 主线 5：民族性与全球化（ch10/ch11）
- **★ `国际主义风格`（1960s，一种风格）≠ `国际化同质化`（2000s，一种结构性现实）**
- **★ 意大利"现代设计 = 过去的延续"；日本"传统→现代是延展"**
- **★ 北欧"既是国际的，同时又是民族的"（"很少国家能达到这一水平"）**

### 主线 6：设计与制造的关系（ch10）
- **★ 设计与制造"必须在一起"** —— 美国制造业外流 → 设计部门随迁 → "工业设计逐年衰退"
- **★ "没有设计，还可以有制造；但没有制造，设计就完全是别的东西"**（彼得·多默）

### 主线 7：需求层次的教训（ch07）
- **★ 彗星客机**：方形窗口 → 应力集中 → 金属疲劳 → 1953–54 两次全机解体
- **★ 判据："心理需求压倒物理需求"，把需求关系本末倒置**

### 主线 8：否定之否定的螺旋（ch10）
```
现代主义 → 法西斯封杀 → 迁美 → 国际主义 → 后现代
   → 1990s 衰退 → 现代主义"另一波兴起"（苹果极简）
   → "否定之否定"，走上更高级阶段
```
