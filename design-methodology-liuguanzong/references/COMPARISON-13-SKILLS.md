**★★★★★ 核心判据：**
- **★ `Ergonomics` 词源**：ergon（工作）+ nomoi（规律）= "**人的劳动规律**"
- **★ 起源总括**："**起源于欧洲，形成于美国**"
- **★ 两类尺寸**：构造尺寸（静态）/ 功能尺寸（动态）
- **★ GB 3975 立姿八要点 / 坐姿六要点**（眼耳平面、腓骨头高度、膝角直角）
- **★ 三种骨杠杆**：平衡/省力/**速度**（"速度杠杆在人体中较为普遍"）
- **★ 核心矛盾**："**最大的力量和最大的运动范围是相矛盾的**"
- **★ 人的模型**："**单通道的有限输送容量的信息处理系统**"
- **★ 三通道分工**：视觉 8 类 / 听觉 4 类 / 触觉 3 类信息；"负荷过重/环境不适合"是换通道信号
- **★ 四个阈值**：**15cm / 4.5kg / 41cm / 每分钟 2 次**
- **★ 2.5 百分位女性**（可达性设计）；"死角部分不能配置仪表"
- **★ 干涉点公式**：**h = (D·k + d·H) / (D + d)**
- **★ 环境四分区**：最舒适 / 舒适 / 不舒适 / 不能忍受
- **★ 三个退让层级**：允许环境 → 安全环境 → 个体防护
- **★ 气湿阈值**：**高气湿 80%+ / 低气湿 <30%**
- **★ 失误"永远是交互的"**；两个主因：**设计不良 + 操作不当**
- **★ 五个总体目标**：**安全 / 高效 / 舒适 / 健康 / 经济**（要求"总体优化"）
- **★ 五个目标会冲突** → "总体优化"= 权衡后的最优
- **★ "静态紧张最伤"**（不是"用力太累"）
- **★ 综合集成法四基础**：思维科学 / 系统数学 / 计算机 / 实践论认识论
- **★ 七个"结合"**（方法论自检清单）
- **★ 专家 vs 机器的分界是"能否言传"**

| ch06 设计中的挑战 | 9,451 | 7,456 | 30 | 4.02 |
| ch07 以用户为中心 | 8,688 | 8,616 | 34 | 3.95 |
| **合计** | **58,911** | **59,454** | **238** | **4.00** |

**★★★★★ 核心判据：**
- **★ 两条原则**：**概念模型 + 可视性**
- **★ "给我几个小时，我可以搞清楚"——这本身就是失败**
- **★ `如果某种错误有可能发生，就一定会有人犯这样的错误`**
- **★ Return/Enter 案例**：设计缺陷 → 自责 → 不汇报 → "你是唯一抱怨的人" → 缺陷长期存在
- **★ "没有人抱怨" ≠ "没有问题"**
- **★ 两条鸿沟**：**执行鸿沟**（不知道怎么做）/ **评估鸿沟**（不知道做成了没有）
- **★ 知识的三个来源**：头脑 / 外部提示 / 限制因素
- **★ 四条理由**：信息储存于外部 / 无须高度精确 / 自然限制 / 文化限制
- **★ `行为 = 头脑知识 + 外部信息 + 限制因素`**
- **★ 四类限制因素**：**物理结构 / 语意 / 文化 / 逻辑**
- **★ 完整公式**：预设用途（展开范围）→ 限制因素（缩小范围）
- **★ 六类失误**：撷取性/描述性/数据干扰/联想/忘记目的/功能状态
- **★ 反直觉**："**失误经常出现在已习以为常的行为中**，学习时反而很少"
- **★ 七原则**（全书方法论总表）

**★★★★★ 核心判据：**

- **★ 非对称的教学方针**：**"任何舞者用双脚都能够直立，但富有动感的一腿腾空就困难了"**
- **★ 训练目的**："学会做最困难的事情，从而加强设计能力"
- **★★★★★ 三维草模三条"不"**：不反映细节 / 不表现材料 / 不是成品

- **★ `方向力` = "所有运动力量的总和"**
- **★ 三级元素**：主导（**帮助构成表达含义**）/ 次要（**补充主导**）/ 从属
- **★ 主导不是"体积最大"，是"最能表达含义"**
- **★ `控制模型`**（保持原状，作为审视进程的依据）
- **★ 成功最硬判据**："**设计模型中的凹空间将看上去比控制模型大**"
