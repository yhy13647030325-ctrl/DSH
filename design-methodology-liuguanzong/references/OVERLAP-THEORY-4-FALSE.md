## 五、四本的真正组织逻辑（答案）

| 书 | 组织逻辑 | 独有方法论 | 不可替代 |
|---|---|---|---|
| **造型** | **十阶段流程**（轮廓→比例→…→材料） | **每阶段验收清单** | **唯一有"完整造型流程"** |
| **元素** | **教学课题制**（课题一/二/三 + 学生作品） | **三维草模法 / 比例平衡草图 / 空间草模** | **唯一有"动手找形"方法** |
| **心理** | **认知机制递进**（七阶段→失误→七原则） | **失误六类 / 行动七阶段 / 化简七原则** | **唯一有"失误分类学"** |
| **视觉动力** | **物理受力类比**（F 定义→三图示→生长约束） | **拉扯拉断涂抹三图示 / 竹竿生长 / 法向 F** | **唯一有"形态物理学"** |

```
【造型】    做什么 → 按什么顺序做（流程型）
【元素】    怎么教 → 怎么用手找形（教学型）
【心理】    人怎么想 → 为什么会错（认知型）
【视觉动力】 为什么好看 → 力怎么算（物理型）
```

> **★★★★★ 判据：四本对应"四个不同的问题"，不是"同一问题的四个版本"。**
> **★ 所以 `Jaccard 0.92` 是"词汇重合"，`0 条相同行` 才是"内容不重复"。**

## 七、结论与建议

### 7.1 三条结论

**① 四本理论书之间**：**六组配对全部"误判重叠"**（相同行 0 条）

**② 四本的分工极清晰**：**39 章中 33 章（85%）为独有章节**

**③ 四本无真空、无独占**：26 主题全部有 ≥2 本覆盖 —— **互补性最好的组合**

### 7.2 不建议合并

| 理由 | 说明 |
|---|---|
| **组织逻辑不同** | 流程型 / 教学型 / 认知型 / 物理型 |
| **独有章节 85%** | 合并等于重写 |
| **无内容重复** | 0 条相同行 |

> **★ 强行合并没有任何收益（本来就没重复），只会有损失（失去四种视角）。**
