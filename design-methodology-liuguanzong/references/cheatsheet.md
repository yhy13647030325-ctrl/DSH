# 设计方法论速查表（Cheatsheet）

> 用法：本页是"现场速查"，只给判据与对照，不展开论证；需要依据时按各节标注的章节文件回查。
> 边界：标注"（现有材料未展开）"处表示知识库现有材料不足以展开、未作推测；标注"（应用模板，非原书内容）"处为引申的操作化内容。

## 一、核心思想速查

| 概念 | 核心含义 | 一句话记忆 | 出处 |
|------|---------|-----------|------|
| 事理学 | 研究"事"来设计"物"的方法论 | 先谋事，后造物 | [ch03](chapters/ch03-methodology.md) |
| 实事求是 | 先研究外因（事），再组织内因（物） | 实事→求是 | [ch03](chapters/ch03-methodology.md) |
| 从造物到谋事 | 设计本质是安排人的行为，不是制造产品 | 设计的是生活方式 | [ch03](chapters/ch03-methodology.md) |
| 目标系统 | 先明确目标，再选路径，最后选工具 | 初心→道路→工具 | [ch02](chapters/ch02-epistemology.md) |
| 全生命周期 | 作品→产品→商品→用品→废品 | 五品统一 | [ch01](chapters/ch01-ontology.md) |
| 共生美学 | 打破艺术与科学对立，多元共生 | 和而不同 | [ch02](chapters/ch02-epistemology.md) |

**常见误用**：把六条当口号背，却不落到"先事后物"的顺序上——判断是否真的在用，只看一条：内因是不是在外因之后才定的。

## 二、设计思维六步法

```
1. 基于观察 → 发现真实问题
2. 重在分析 → 深入理解原因
3. 精于归纳 → 提炼共性规律
4. 善于联想 → 跨领域激发创意
5. 意在创造 → 形成设计方案
6. 勤于评价 → 持续优化迭代
```

**各步输出物**：①观察记录、问题清单 ②需求分析报告 ③设计原则、用户画像 ④创意概念草图 ⑤设计方案、原型 ⑥评估报告、迭代方案。（[ch02](chapters/ch02-epistemology.md)、[patterns 模式三](patterns.md)）

**与事理学的对应**：1–3 步＝实事（研究外因）；4–5 步＝求是（组织内因）；第 6 步以"合理"为标准。

**常见误用**（应用推演，非原书内容）：跳过归纳（第 3 步）直接联想 → 创意无依据；只观察不分析 → 停在现象层；跳过评价（第 6 步）→ 方案一次成型。可填写版见 [templates/six-step-worksheet.md](../templates/six-step-worksheet.md)。

## 三、内外因分析框架

```
外因（事）——决定"应该怎样"
├── 人：谁在使用？什么状态？
├── 环境：在哪使用？
├── 时间：什么时候使用？
├── 条件：经济、文化、技术条件
└── 目的：要做什么事？

内因（物）——决定"可以怎样"
├── 原理：用什么技术原理？
├── 材料：用什么材料？
├── 结构：采用什么结构？
├── 工艺：如何制造？
├── 形态：什么形状？
└── 色彩：什么颜色？
```

**顺序铁律**：先研究外因，再组织内因；内因的每一项都应能回指某条外因。

**常见误用**：跳过外因直接讨论材料、结构、造型——原文以"像医院一样先诊断，诊断完了再去配药、抓药、治疗"点破这一反面；以及不区分"工作餐／会议餐／婚礼宴请／国宴"的目的与方式就设计餐具。（[ch02](chapters/ch02-epistemology.md)、[ch03](chapters/ch03-methodology.md)）

可填写版见 [templates/external-internal-factors.md](../templates/external-internal-factors.md)。

## 四、事理学应用步骤

```
Step 1：抽象目标
  把具体需求抽象为本质目标
  例："设计杯子" → "设计饮水方式"

Step 2：研究外因
  分析人、环境、时间、条件等外部因素
  例：谁喝？在哪喝？喝多少？什么温度？

Step 3：构建目标系统
  把外因整理成完整的目标系统描述

Step 4：组织内因
  根据目标系统选择、组织、创造内因
  例：选择材料、结构、工艺、形态

Step 5：评价优化
  评估方案是否合情合理，持续迭代
```

**逐步判据**（应用模板，非原书内容）：

| 步骤 | 通过判据 |
|------|---------|
| 1 抽象目标 | 目标表述里不出现具体器形、材料或技术名词 |
| 2 研究外因 | 人／环境／时间／条件／目的五类都有填写 |
| 3 构建目标系统 | 内外因权重与关联关系已标出 |
| 4 组织内因 | 每条内因都能回指某条外因 |
| 5 评价优化 | 以"合情合理"（情＋理）为标准给出结论 |

**常见误用**：从 Step 4 开始（先选材料再找理由），或把 Step 1 的目标写成"设计一个更好的 X"。

## 五、设计两大原则

| 原则 | 含义 | 应用 | 常见误用 |
|------|------|------|---------|
| 有限理性原则 | 人的理性有限，寻求满意解而非最优解 | 不追求完美，在约束下找最佳 | 在有限信息下无限优化、迟迟不决策 |
| 适应性原则 | 设计应适应环境变化 | 设计要有弹性和可演化性 | 停留于被动适应，未上升到主动创新 |

出处：[ch02](chapters/ch02-epistemology.md) 第五节；适应性原则的案例见 [ch04 生土建筑](chapters/ch04-cases.md)。

## 六、设计两大观念

| 观念 | 核心 | 实践 | 常见误用 |
|------|------|------|---------|
| 生态观 | 人与自然和谐共生 | 可持续设计、绿色设计、循环设计 | 刺激过度消费（"双十一就是犯罪"，[ch04](chapters/ch04-cases.md)） |
| 共生美学观 | 多元因素和谐共生 | 不追求单一美学，包容多样性 | 把艺术与科学摆成对立两端 |

**自检句**："广厦万间，夜眠七尺；良田千顷，日仅三餐。"

## 七、经典案例：坐与座

```
问题：设计一把椅子？

事理学思路：
1. 抽象目标：不是设计"座"（物），而是研究"坐"（事）
2. 研究外因：
   - 谁坐？（老人/小孩/上班族/孕妇）
   - 在哪坐？（办公室/餐厅/公园/车上）
   - 坐多久？（几分钟/几小时/一整天）
   - 做什么？（吃饭/工作/休息/等待）
3. 发现：不同的"坐"需要不同的"座"
   - 工作坐→需要支撑和调节
   - 休息坐→需要舒适和放松
   - 等待坐→需要耐用和易清洁
4. 组织内因：根据不同场景选择材料、结构、形态
```

**原文给出的场景—内因对照**（[ch04](chapters/ch04-cases.md)）：

| 场景 | 关键外因 | 内因选择 |
|------|---------|---------|
| 办公室工作 | 上班族／伏案／每天6-8小时／保持专注和健康 | 可调节高度、腰部支撑、透气材料、人体工学；网布+金属+机械调节结构 |
| 餐厅用餐 | 就餐者／配餐桌／30分钟-1小时／舒适但不过于放松 | 适中高度、易清洁、耐用、与餐桌匹配；木材/塑料+简洁结构 |
| 公园休息 | 路人／户外风吹日晒／5-30分钟／休息观景社交 | 耐候材料、易维护、可多人、与环境协调；防腐木/金属+坚固结构 |
| 交通工具上 | 乘客／移动空间有限／几十分钟到几小时／安全 | 安全带接口、折叠收纳、轻量化、防撞；塑料+金属+折叠结构 |

**常见误用**：跳过第 3 步直接进第 4 步（未得出"没有万能的椅子"就开始选材料），等于又回到找万能方案。

## 八、设计本质判断清单

```
问自己：
□ 我是在设计"物"还是设计"事"？
□ 我是从需求出发还是从技术出发？
□ 我考虑了全生命周期吗？
□ 我是在鼓励占有还是提倡使用？
□ 我的设计是在跟随市场还是引领需求？
□ 我考虑了不同人的不同需求吗？
□ 我的设计合情合理吗？
```

**加两条**（应用模板，非原书内容）：
- □ 我的技术选择发生在"初心→路径"之后吗？
- □ 我的方案有随环境变化演化的余地吗？

## 九、柳冠中金句速查

```
1. "我设计的不是杯子，而是饮水解渴的方式。"
2. "不是设计车，而是设计出行方案。"
3. "设计看起来是在造物，其实是在讲理，在抒情。"
4. "物是做事的，杀鸡焉用宰牛刀。"
5. "传统是创造出来的，绝对不是继承出来的。"
6. "广厦万间，夜眠七尺；良田千顷，日仅三餐。"
7. "设计是引导人们行为的，是一种事前干预。"
8. "过程远重于结果。"
9. "提倡使用，不鼓励占有。"
10. "设计不能只跟着市场走，满足欲望，更要关注真正的需求。"
```

## 十、设计方法论 vs 设计方法

```
设计方法：具体的设计技巧和工具
  例：头脑风暴、用户访谈、原型制作

设计方法论：选择设计方法的方法
  目的：
  - 寻路：引领我们认识事物的观念、方法
  - 入门：如何构建新事物的概念、方法
  - 脉络：与其他知识形成体系框架
```

**常见误用**：把"方法"当"方法论"——方法很多而方向不明；反之只谈原则不落技巧，同样空转。（后者现有材料未展开）

出处：[ch03 第一节](chapters/ch03-methodology.md)、[ch01 元设计](chapters/ch01-ontology.md)。

## 十一、从物到事的思维转换

| 传统思维（造物） | 事理学思维（谋事） |
|-----------------|-------------------|
| 设计一个杯子 | 设计饮水方式 |
| 设计一把椅子 | 设计坐的行为 |
| 设计一辆车 | 设计出行方案 |
| 设计一个产品 | 设计一种生活方式 |
| 关注产品功能 | 关注用户行为 |
| 从技术出发 | 从需求出发 |
| 鼓励占有 | 提倡使用 |
| 单一环节优化 | 全生命周期系统设计 |

**改写动作**：把左栏的话改写成右栏，再要求自己列出至少两条实现路径，之后才允许出现材料与技术名词。
