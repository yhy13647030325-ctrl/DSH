# 页码口径总表（Page Citation Convention）

> **本文件是所有「逐章重读」产出物的页码基准。**
> 任何章节文件里出现 `（pXXX）`，都必须按本表的口径解释。
>
> 制定日期：2026-11-14
> 用途：解决"同一本书不同来源页码对不上"的问题——这是本项目反复踩坑的地方。

---

## 一、为什么需要这张表

以往出现过三种页码错乱：

| 错乱类型 | 实例 | 后果 |
|---|---|---|
| **PDF 索引 ≠ 印刷页码** | 刘宝顺 b041.png 实际是书 p042 | 14 处引用错位 |
| **不同书页码混用** | ch08 跨书专题里的 p864 被当成刘宝顺的页 | 36 个假 ERROR |
| **EPUB 无固定页码** | 王受之设计史 | 无法标页码 |

**本表逐本固定口径，后续引用一律照此执行。**

## 二、逐本口径（10 本 PDF）

### 判定方法说明

对每本书执行了两项探测：

1. **文字层探测**：抽 5 页看 `get_text()` 字符数
   - 抽样全部接近 0 → **扫描版**（必须读图）
   - 抽样大多 > 80 → **文字版**（可提取）
2. **页码探测**：分别取页面**顶部 10%** 与**底部 10%** 的文本块
   - 找到数字/全角数字 → 记录偏移
   - 都为空或只有内容行 → 页码是图形，**不可自动提取**

## 三、写作规范（所有章节文件必须遵守）

### 3.1 页码标记格式

**统一用三位数字，带书名代号**：

```
（刘 p045）        ← 刘宝顺，书内印刷页 45
（战 p104）        ← SolidWorks 实战，PDF 索引 104
（2025 p864）      ← SOLIDWORKS 2025，PDF 索引 864
（曲 p199）        ← 高级曲面，PDF 索引 199
（注 p029）        ← 注塑缺陷，PDF 索引 29
（诺 p112）        ← 诺曼设计心理学，PDF 索引 112
（人机 p036）      ← 丁玉兰，书内印刷页 36
（造型 p051）      ← 戴布斯，PDF 索引 51
（动力 p088）      ← 李想视觉动力，PDF 索引 88
（元素 p024）      ← 汉娜设计元素，PDF 索引 24
（设计史 ch05 §3 ¶2）  ← EPUB，章节+段落
（Blender ch02 §2.3）  ← EPUB，章节+小节
```

### 3.2 三条硬规则

| # | 规则 | 原因 |
|---|---|---|
| 1 | **不许写"约在 pXX"** | 要么查到确切页，要么标注"书中未展开" |
| 2 | **扫描版的页码必须实测确认** | 不能凭 PDF 索引推算（刘宝顺踩过坑） |
| 3 | **一本书的页码不许混进另一本书的章节** | 跨书专题用 ch08，普通章节只引本书 |

### 3.3 原文摘录规范

**凡是打引号的原文，必须是逐字摘录**，并附页码。

```
> 「**多数设计缺陷均出现在工艺性方面。**」（刘 p017）
```

- 用 `「」` 包裹原文
- 页码紧跟在引文后
- 长引文可分多行，但**不能改写**

### 3.4 未读到/未展开的处理

| 情况 | 写法 |
|---|---|
| 书中确实没有 | `（书中未展开）` |
| 我读到但没读懂/图不清楚 | `（需对照原书图 N）` |
| 页码不确定 | **不写页码，标注"待核"**，绝不猜 |

### 刘宝顺（已完成，128/128 页）

| 项目 | 值 |
|---|---|
| 校正方法 | 抽读页脚，逐页确认 |
| 实测关系 | **PDF 索引 10 = 书内 p009**，即 `书内 = PDF − 1` |
| 转图规则 | `bNNN.png` = 书内 `p(NNN+1)` |
| 覆盖 | 128/128 页全部实读，0 处未实读引用 |

> **现口径以实测为准**：`b011.png` 显示页脚 `012`，即 `b011 = p012`。

## 五、给后续工作的检查清单

开始某一本书的逐章重读前，先过一遍：

- [ ] 确认这本书在本文档的口径行
- [ ] 若是扫描版，**抽读 3 页页脚**确认偏移是否与记录一致
- [ ] 若是 EPUB，确认章节号编法
- [ ] 读完后用 `validate-page-citations.py` 校验
- [ ] 在该书的 `page-manifest.json` 里登记 `read` 页

## 六、与已有校验脚本的关系

| 脚本 | 用途 |
|---|---|
| `validate-page-citations.py` | 查页码越界、格式混用、未实读引用 |
| `page-manifest.json` | 每本书的实读页声明 |

**本表是 manifest 的上游依据**——
manifest 的 `page_range` 和 `read` 都按本表口径填写。

## 附：为什么不用"统一换算成书内页"

有人会想"全部换算成印刷页码更专业"。**不这么做，理由有三**：

1. **扫描版换算不可靠**——页码是图形，OCR 可能错
2. **EPUB 根本没有页码**——强行造一套只有我更懂，读者查不到
3. **PDF 索引是唯一可共同验证的锚点**——任何人拿到同一个 PDF 都能翻到

> **原则：可复核 > 好看。**
