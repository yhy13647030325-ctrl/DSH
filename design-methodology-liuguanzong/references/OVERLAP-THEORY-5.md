**但看骨架就知道组织逻辑完全不同**：

| 书 | 组织逻辑 | 典型章节 |

| **设计元素** | **教学课题制** | 课题一"三个直棱体的组合" / 空间草模 / 联想法 |

| **造型** | **十阶段流程** | 轮廓→比例→形状→形态→线条→体积→表面→立体→颜色→材料 |

> **★★★ 判据：五本的交集是"词汇"，不是"内容"。**

## 五、五本的真正分工（核心结论）

### 5.1 一句话定位

| 书 | 一句话 | 它的不可替代性 |
|---|---|---|
| **设计元素** | **"怎么教造型 / 怎么用草模找形"** | **三维草模法 / 比例平衡草图 / 空间草模 —— 唯一有"动手找形"方法的** |
| **设计心理** | **"人为什么会用错 / 怎么设计才不出错"** | **七阶段 / 六类失误 / 七原则 —— 唯一有"失误分类学"的** |
| **视觉动力** | **"形态的力从哪来 / 怎么算"** | **F 的定义 / 三图示 / 施力受力 / 生长约束 —— 唯一有"形态物理"的** |
| **人机工程** | **"尺寸该多少 / 环境该怎样"** | **百分位 / 硬数值 / 标准 —— 唯一有"具体数字"的** |
| **造型** | **"按什么顺序做造型"** | **十阶段 + 每阶段验收清单 —— 唯一有"完整流程"的** |

### 5.2 七个"路由规则"（可直接用）

| 你的问题 | 查哪本 | 依据（实测词频） |
|---|---|---|
| **"这个形态的力感对不对 / 为什么别扭"** | **视觉动力** | 动态与力感 **476 次**（占 65%） |
| **"用户会不会用错 / 这个操作能懂吗"** | **设计心理** | 失误与错误 **191 次**（占 80%） |
| **"尺寸该多少 / 百分位怎么选"** | **人机工程** | 人体尺寸 **209 次**（**唯一**） |
| **"怎么按流程做造型"** | **造型** | 比例 390 / 材质 483（均为最高） |
| **"怎么教 / 怎么用草模找形"** | **设计元素** | 三维草模法（唯一） |
| **"这个比例看着舒服吗"** | **造型**（有 390 次）→ 补 **设计元素**（比例平衡法） | 造型给判据，元素给方法 |
| **"环境/照明/噪声怎么定"** | **人机工程** | 环境因素 **223 次**（占 78%） |

### 5.3 五个"必配组合"

| 场景 | 组合 | 为什么 |
|---|---|---|
| **"这个造型为什么别扭"** | **视觉动力（判力感）→ 设计元素（查比例构成）** | 前者给物理解释，后者给构成检查 |
| **"设计一个好用的东西"** | **设计心理（认知）→ 人机工程（尺寸）** | 前者判"懂不懂"，后者判"够不够大" |
| **"从 0 开始做产品造型"** | **造型（十阶段）→ 视觉动力（诊断）→ 设计元素（找形）** | 流程 → 诊断 → 突破 |
| **"给客户解释设计理由"** | **视觉动力（有物理依据）+ 人机工程（有数值）** | 这两本最有"可验证的证据" |
| **"教学 / 带新人"** | **设计元素（课题制）→ 造型（流程）** | 前者给练习，后者给步骤 |
