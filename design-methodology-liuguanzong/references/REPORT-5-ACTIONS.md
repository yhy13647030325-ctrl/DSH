## 五、跨技能接口（真接口，不是"详见"）

本项目确立的接口标准：**找到同一物理变量在两个领域里的相反作用 + 最坏组合**，才算接口；"详见 X 技能"只是索引。

| 接口 | 相反作用 / 最坏组合 | 出处 |
|---|---|---|
| CMF ↔ 注塑 | **同一个"表面"变量**：做纹理藏缺陷（p383）／做镜面放大缺陷（p82 Mirror >95%）；**最坏组合 = 高光泽+透明+薄壁，良率断崖** | cmf `patterns.md` P-13 |
| CMF ↔ 注塑（失效链） | 咬花在骨位顶出段未省光 → **粘后模 + 顶出变形**（外观决策变成结构失效） | cmf P-13 第 3 行，实读 injection `ch04:910` |
| 用户研究 ↔ 人机 | 抽样停止条件必须从"主题饱和"**升级为覆盖 P5/P95 端点**，否则系统性丢掉两端人群 | ursk `patterns.md` P13 |
| 用户研究 ↔ 造型 | 造型"用户画像五问"的第 03/04 问（收入/爱好/孩子）**属人口统计，不能当画像骨架**（会犯"市场细分当 persona"） | ursk `SKILL.md` §5.1 |
| 可用性测试 ↔ 设计心理 | 七原则产物是**预期缺陷清单，必须由测试检验后才能进报告**（防两技能串味） | ut `ch05 §5.10` |
| 无障碍 ↔ 人机 | 人机算满足度（P5–P95 默认排除 10%）→ 无障碍给超界人群命名、分轴、换算人数 | iad `SKILL.md`（只写章名不写页） |
| 无障碍 ↔ 可用性测试 | 招募 boundary users 判据：能力分数 ≈ 产品需求分数；1.5–2h 含休息；问"哪里难用"不问"你能做到吗" | iad `patterns.md` P8 |

**一个结构发现**：`product-injection-defects` 现在是 **CMF / 结构 / 建模三个设计端技能的共同下游** —— 从任何一端进来，最后都要过"能不能造/会不会有缺陷"这一关。路由表已把它画成方法层与工具层之间的汇合节点。

## 六、四条引证纪律（本轮沉淀，已写进 design-router §七）

1. **页码口径不混**：PDF 索引 / 书内印刷页 / EPUB 段落号，混写 = 假页码。跨技能指路一律写"详见 <技能名> 的 <章名>"，不带页。
2. **冲突并列**：两本书对同一件事说法不同时，两边都写、标明差异，不挑一个。实例：被试数、严重度方向、extreme users 界定、resilience 三定义、Bakelite 色域。
3. **空白写成坐标**：不确定的地方写"原书未给 / 去查 X"，不填看起来合理的值。实例：形状因子 0 命中、HADRIAN 0 命中、30 个方法无样本量。
4. **反例不复现错误链**：写"不要写 X"时，若 X 本身会触发校验或被误抄，改成只描述不复现。（路由专家第一版把 `translate→screen→rank→document` 当反例原样写出，结果反例本身违反了硬要求。）

### 9.4 OCR 错字的处理原则（重要）

**OCR 错字一律照录，不许"顺手修正"。** 已记录 30+ 处，例如：

| 页 | OCR 原样 | 应为 |
|---|---|---|
| p100 | `ARIArole` | ARIA role |
| p244 | `交叉引I用` | 交叉引用 |
| p198 | `圣奥东尼奥` | 圣安东尼奥 / San Antonio |
| p35 | `IEDO` | IDEO |
| p137 | `数以干计` | 数以千计 |
| p153 | `一相情愿` | 一厢情愿 |
| p218 | `Konwbility` / `Knowbility` 同段不一致 | Knowbility |

**理由**：引文的全部价值在于"可以回源逐字核对"。改一个字，引文就变成了伪造。
全量清单见该技能 `glossary.md` §6。

另有一条 OCR **版式特征**必须知道：跨页或遇图注时，OCR 会把图注/侧栏/图内英文**串进正文中间**。原书是通顺一段，交错是 OCR 产物。该技能按语义拼接后引用，并在 SKILL.md ①-b 明写"回源核对前请先做版式剥离"。
