## 四、四个新技能的实际能力边界（诚实版）

### 4.1 `inclusive-accessibility-design`（9 章）

**有**：能力谱三轴（感官/认知/机动）、排除率量化四步、7-Level 知识回路、极端用户法、模拟工具标定、评估方法库。

**没有（原文 0 命中，已写进⑤）**：
- **HADRIAN**：Clarkson 611 页 + Coleman 267 页全 0 命中
- **ITK**：书里 `Toolkit` 只是节名；Coleman 的 `Inclusive Design Toolkit` 是 **BT 公司网站**，非方法名
- **capability spectrum**：原书叫 `capability loss as a continuum`
- **"包容性设计三原则"**：`three principles` 0 命中；唯一命中是 Vodafone Simply 项目三原则（不是通行教义）
- **时效止于 2007 年**：WCAG 2.1/2.2、EN 17161、EN 301 549、ISO 21542 **一概不含**

### 4.2 `user-research-methods`（10 章）

**有**：五维方法谱系、30+ 方法四问（何时用/不能用/最少样本量/产出物）、样本量双源总账、亲和图/KJ/内容分析、persona/旅程图/任务分析/认知走查、木马/RITE/并行原型。

**没有**：**30 个方法两书都没给样本量**（已逐条列清）。Goodman DOC 20/21/23/24/26–29 未读（已在⑤标明"未读"而非"没有"）。

**关键判据**：**"5 个用户够"是覆盖率下限，不是停止条件** —— 两书都只给覆盖率，未给停止判据。

### 4.3 `usability-testing`（8 章）

**有**：完整链路（测前/测中/测后）、招募筛选、任务场景写法、主持禁语、逐级提示四档、严重度评级、四维分类（形成性/总结性、实验室/远程、有主持/无主持、探索/评估/验证/比较）。

**两处硬冲突已并列**：
- **"几个被试够"**：Rubin 4–5 人/格子（主张尽量 8 人）vs Barnum 3–5 人（"第 5 个停"）；**下限与停止规则都不同**
- **严重度方向相反**：Rubin 4=最重 vs Barnum 1=最重 → 给出统一书写约定 `严重（Rubin 4 分 / Barnum Level 2）`

### 4.4 `cmf-system`（7 章）

**有**：C 色彩（发色机理、透明四级、光泽六级）/ M 材料（六张属性图读法、材料指数八项、选材四步）/ F 表面（15 种工艺量化表、阳极氧化、IMD）/ 感知层（软=E·H、冷=√(ρλc_p)、音高 P=√(E/ρ)、亮度 L=1/η）。

**色彩是最大短板**：全书讨论色彩只有 **p93 共 45 个词**（"色彩靠 Pantone 编号"）。色相/明度/纯度、配色法则、ΔE 色差、NCS/Munsell/RAL、色彩心理 —— **全部零覆盖**，已写进 ch03 §3.7 共 10 项空白，指向 `product-design-styling-dabbs` 与 `visual-dynamics`。

**有出处支撑的强项**：发色机理（酚醛只能黑/棕 p248、玻璃金属氧化物配方 p254、铝阳极氧化看合金 p372）。

## 五、跨技能接口（真接口，不是"详见"）

本项目确立的接口标准：**找到同一物理变量在两个领域里的相反作用 + 最坏组合**，才算接口；"详见 X 技能"只是索引。

| 接口 | 相反作用 / 最坏组合 | 出处 |
|---|---|---|
| CMF ↔ 注塑 | **同一个"表面"变量**：做纹理藏缺陷（p383）／做镜面放大缺陷（p82 Mirror >95%）；**最坏组合 = 高光泽+透明+薄壁，良率断崖** | cmf `patterns.md` P-13 |
| CMF ↔ 注塑（失效链） | 咬花在骨位顶出段未省光 → **粘后模 + 顶出变形**（外观决策变成结构失效） | cmf P-13 第 3 行，实读 injection `ch04:910` |
| 用户研究 ↔ 人机 | 抽样停止条件必须从"主题饱和"**升级为覆盖 P5/P95 端点**，否则系统性丢掉两端人群 | ursk `patterns.md` P13 |
| 用户研究 ↔ 造型 | 造型"用户画像五问"的第 03/04 问（收入/爱好/孩子）**属人口统计，不能当画像骨架**（会犯"市场细分当 persona"） | ursk `SKILL.md` §5.1 |
| 可用性测试 ↔ 设计心理 | 七原则产物是**预期缺陷清单，必须由测试检验后才能进报告**（防两技能串味） | ut `ch05 §5.10` |
| 无障碍 ↔ 人机 | 人机算满足度（P5–P95 默认排除 10%）→ 无障碍给超界人群命名、分轴、换算人数 | iad `SKILL.md`（只写章名不写页） |
| 无障碍 ↔ 可用性测试 | 招募 boundary users 判据：能力分数 ≈ 产品需求分数；1.5–2h 含休息；问"哪里难用"不问"你能做到吗" | iad `patterns.md` P8 |

**一个结构发现**：`product-injection-defects` 现在是 **CMF / 结构 / 建模三个设计端技能的共同下游** —— 从任何一端进来，最后都要过"能不能造/会不会有缺陷"这一关。路由表已把它画成方法层与工具层之间的汇合节点。

## 六、四条引证纪律（本轮沉淀，已写进 design-router §七）

1. **页码口径不混**：PDF 索引 / 书内印刷页 / EPUB 段落号，混写 = 假页码。跨技能指路一律写"详见 <技能名> 的 <章名>"，不带页。
2. **冲突并列**：两本书对同一件事说法不同时，两边都写、标明差异，不挑一个。实例：被试数、严重度方向、extreme users 界定、resilience 三定义、Bakelite 色域。
3. **空白写成坐标**：不确定的地方写"原书未给 / 去查 X"，不填看起来合理的值。实例：形状因子 0 命中、HADRIAN 0 命中、30 个方法无样本量。
4. **反例不复现错误链**：写"不要写 X"时，若 X 本身会触发校验或被误抄，改成只描述不复现。（路由专家第一版把 `translate→screen→rank→document` 当反例原样写出，结果反例本身违反了硬要求。）
