# 第 7 章：动力分析 + 形态修改

## Core Idea
当设计**没有先天形态缺陷**可依循时（如汽车前脸），工作从"修约束"转为"调关系"：先把动力分析**简化为编号箭头**，再按**势力阵营**调整位置、轮廓与方向，在"势能"上做文章。

## Frameworks Introduced

- **两种对抗强度（本章的类型学）**：
  - **激烈型（电动工具）**："它们的图形对抗形式是比较激烈的，这里所说的激烈，正如下图中左边的**橄榄球队员**一样，**发生接触与碰撞**。"
  - **对峙型（汽车前脸）**："这方面的特征与电动工具不同，它的图形之间的关系**很少发生接触与碰撞，大多是处于远距离对峙，两军对垒，有种剑拔弩张的态势**。"（如橄榄球比赛**准备发球之前**，双方队员的架势）
  - When to use：先判断手上产品属于哪一种对抗形态，决定处理手法。

- **自由度差异与难点转移**：
  - "与电动工具设计步骤一样，选取一款汽车之后，先要对它的前脸做一个**动力分析**，不同的是，汽车前脸的设计**相对自由度很大**，所以**没有先天形态缺陷和先天视觉动力**。"
  - 分析容易："通过图形轮廓得出视觉动力分析是比较容易的。"
  - **难点在于**："知道了它的动力分析之后，**该如何修改**。不同于前一章，设计时明确的目标就是约束形态生长，增强工作方向的动力，而**本章却没有了这些目标**。"

- **动力分析简化法（本章的核心操作）**：
  - 做法：**"一个图形或者曲线只用一个动力箭头表示，并把每一个箭头进行编号"**，"这样就有了 5 个确定的角色，然后调整它们之间的关系。"
  - 判读主线（瑞虎 1.6DVVT 案例）："整个画面的主要情节是由以**曲线 1 和图形 2 为代表的从上向下的势力**，和以**图形 3 为代表的从下向上的势力**组成。"
  - 约束条件（现实约束）："为了保证**尽可能小的修改**（实际案例中，汽车款式短阶段修改前脸的设计，不会大动干戈），我们就以原设计中的**上下冲突**为主题来进行优化。"
  - 阵营划分：**"先把图形元素按照势力划分"**——蓝色代表向下的势力，红色代表向上的势力；"这样每一个图形就有了目标，方便修改。"

- **势能（气势）管理（本章的判断依据）**：
  - "虽然说汽车前脸的图形元素不发生直接冲突，但**这种情况下比的就是气势或者叫势能**。"
  - 橄榄球类比："双方势力越强，比赛就越精彩，但**并不是气氛越紧张越好**——**如果比赛还没开始，就发生了冲突，这样的效果并不好**。"
  - 目标：**"所以我们需要把控这种气氛，以增强对立感。"**

- **四类修改动作（本章的具体手法）**：
  1. **去掉重复动力**：去掉曲线 1——"因为它与图形 2 是**同一个方向的重复**。当曲线 1 和图形 2 组合在一起的时候，反而形成了一个**左右拉扯的图示**，所以去掉曲线 1，只保留图形 2。"
  2. **调整空隙以调气氛**："为了避免气氛过于紧张，把**图形 3 向下移动一点点**，也就是**留大了它与图形 2 之间的空隙**，这样可以**适度降低紧张感**。"
  3. **增强轮廓的指向性与势能**（图形 5 = 车大灯）："它被划分在向下势力中，它的位置本来就在左右两侧，**离冲突中心比较远**，而原设计中的轮廓**不够尖锐，指向性弱**。所以我们对它的轮廓进行修改，**使它具有更强的冲突势能，并明确指向，怒视冲突中心**。"
  4. **调整动力方向**（图形 4）："它与图形 5 的情况一样。不过在原设计中，它的动力方向是**朝向外侧**的。所以，我们不仅要修改它的轮廓，并且要**调整它的动力方向**，**让它成为向上的势力，并发挥出势能**。"
  - 收口："就这样，做好大方向上的调整之后，**再增加一些设计细节**，就完成了修改。"

## Key Concepts

- **对峙型对抗**：不发生接触，靠势能对抗（汽车前脸）。
- **动力分析简化**：一图形/曲线 → 一箭头 → 编号 → 调关系。
- **势力阵营**：按方向把图形分组（向上的势力 / 向下的势力）。
- **势能（气势）**：不接触情况下决定胜负的量。
- **紧张感调节**：通过调整两阵营之间的**空隙**来增减。
- **指向性**：轮廓是否明确指向冲突中心。
- **动力方向调整**：把某个图形的力从"朝外"改为"成为向上/向下的势力"。
- **最小修改原则**：汽车短周期改款不会大动干戈。

## Mental Models

- **Use 两种强度判别 when 拿到一个产品**：接触碰撞（电动工具）还是远距离对峙（汽车前脸）？
- **Use 一图形一箭头 when 动力分析太复杂**：先做减法再做关系调整。
- **Use 阵营划分 when 决定"每个元素该干什么"**：给每个图形一个方向目标。
- **Use 空隙 when 调节紧张感**：留大空隙 → 降低紧张；缩小空隙 → 增强对立。
- **Use 指向性强化 when 元素离冲突中心太远**：修改轮廓使其尖锐、明确指向中心（"怒视"）。
- **Use 动力方向翻转 when 元素的力朝向错误**：把它收编到正确的势力中。
- **Use 最小修改 when 面对改款约束**：在主线上优化，而非重构。

## Anti-patterns

- **保留同方向的重复动力**（如曲线 1 与图形 2）：两者组合反而形成**左右拉扯图示**，破坏主题。
- **让气氛过度紧张**："并不是气氛越紧张越好"——比赛还没开始就打起来效果不好。
- **让元素方向朝外而不管**（图形 4 原状）：无法为阵营贡献势能。
- **把设计目标照搬电动工具那套**（约束形态生长、增强工作方向动力）：汽车前脸**没有这类目标**。
- **忽略现实中"不大动干戈"的约束**：应以原设计的主要冲突为主题做优化。
- **只调大方向而不加细节**（或反之）：作者要求大方向先定，**再增加设计细节**。

## Worked Example

**瑞虎 1.6DVVT 前脸修改：五角色、两阵营、四动作**

**阶段一：动力分析**
1. 对汽车前脸做动力分析 → 得出各图形轮廓的视觉动力。
2. **简化**：一个图形/曲线只用一个**动力箭头**表示，逐一**编号** → 得到 **5 个确定的角色**。
3. 读主线：**曲线 1 + 图形 2 = 从上向下的势力**；**图形 3 = 从下向上的势力**。
4. 设定约束：按"**尽可能小的修改**"原则，以原设计的**上下冲突**为主题优化。
5. **划分阵营**：蓝色 = 向下势力；红色 = 向上势力。

**阶段二：四步修改**
6. **去掉重复**：删除曲线 1——它与图形 2 同方向重复，且两者组合会形成**左右拉扯图示**；只保留图形 2。
7. **调空隙**：把图形 3 **向下移动一点点**，**留大它与图形 2 之间的空隙**，**适度降低紧张感**（避免"比赛还没开始就冲突"）。
8. **强化指向（图形 5 = 车大灯）**：原轮廓**不够尖锐、指向性弱**且**离冲突中心远** → 修改轮廓，**增强冲突势能、明确指向、怒视冲突中心**。
9. **翻转方向（图形 4）**：原动力**朝向外侧** → 修改轮廓并把方向**调整为向上的势力**，发挥势能。

**阶段三：收口**
10. **大方向既定后，再增加设计细节**；与原始图片对比，体会修改前后的差别。
11. **换车型重复流程**：对下一款车同样"先做动力分析，再修改"。

## Key Takeaways

1. 图形对抗有两种强度：**激烈型**（接触碰撞，如电动工具）与**对峙型**（远距离对峙，如汽车前脸）。
2. 汽车前脸**自由度大、没有先天形态缺陷与先天视觉动力**，因此难点从"如何分析"转为"**如何修改**"。
3. **动力分析简化法**：一图形/曲线 → 一箭头 → 编号 → 得到确定的角色数量。
4. 用**势力阵营**（向上/向下）给每个图形分配目标。
5. 不接触的对抗比的是**气势/势能**；**不是气氛越紧张越好**，需要把控。
6. 四类修改动作：**去重复、调空隙、强化轮廓指向与势能、调整动力方向**。
7. 遵循**最小修改**原则（短周期改款不会大动干戈）。
8. 流程收口顺序：**先大方向、后细节**。
