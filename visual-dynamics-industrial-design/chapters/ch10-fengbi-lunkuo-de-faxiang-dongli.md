# 第 10 章：封闭轮廓的法向动力

## Core Idea
**法向动力不专属圆形——一切封闭轮廓都有**，且都由"垂直平面的第三维度的力量"形成；决定性变量是**圆角大小**（越接近圆形，法向动力越大）。

## Frameworks Introduced

- **从圆形到一切封闭轮廓（本章的推广）**：
  - "也许你已经想到了，**法向视觉动力，不是只有圆形才有，其实所有的封闭轮廓图形都有**。"
  - 语言类证："就像平时语言上说的'**洞**'，比如，衣服破了个洞。"——"我们在讲圆形法向动力的时候，所说的'**纸面上有一个黑洞**'这个比方，**适用于所有封闭图形**（如下图的穿墙效果）。"
  - 成因："所以，只要是封闭轮廓图形，**都有法向视觉动力，且都是由垂直所在平面的第三维度的力量形成的**。"
  - 推论："如果理解了这一点，**法向动力的图形对象就一下子被扩展了**。"

- **圆角大小决定法向动力（本章的核心判据）**：
  - "它们之间的区别只是**动力的大小不同**……但它们**都有法向动力**。"
  - 规律一：**"图形越接近于圆形，法向动力就越大。"**
  - 规律二（圆形的特例）："（圆形的法向动力是**最大**的，因为它带有**旋转特征**。此内容会在后面的'13 流动的形态'中展开）"
  - 操作性结论：**"所以对于一个封闭的几何图形来说，圆角大小就决定了它的法向动力的大小。"**
  - 应用一（App 图标）："这个方面在 App 图标的设计上就有体现。看看下面的这些图标，左右两种，哪个法向动力更强呢？"
  - 应用二（手机）："还有就是我们每人都有的智能手机产品。无论你用的是哪款手机，**你是否注意过它的圆角大小**，以及它**放在桌面上的时候呈现的法向动力效果**呢？"
  - 普遍性："至此，一切封闭轮廓开始引起我们的注意，它们的法向视觉动力似乎无处不在。"——"当我们看到产品的同时，**视觉动力会从第三个维度上展现出来**。"

- **封闭轮廓法向动力的削弱（本章的两种方法）**：
  - 方法一：**打破轮廓**（= 圆形的"破坏边缘"）：
    - "它与圆形的削弱方式其实是一回事。第一种就是**破坏边缘**，它的另一种说法则更接近本质，就是**打破轮廓**。**当图形不再是完整的封闭轮廓时，法向动力自然就削弱了。**"
    - 印章案例（起源故事）："在篆刻中的**印章**有一个外轮廓，而篆刻者经常在这个外轮廓边缘上**刻出一个缺口**。这个缺口就起到了**削弱印章法向动力**的效果。**据说第一次出现轮廓缺口是因为不小心把印章摔在地上造成的，却发现这样看上去效果更好，于是之后就有意刻出一个缺口。**"
  - 方法二：**封闭轮廓连通（一石二鸟）**：
    - "直接切断轮廓是一种方式，还有一种常用的方式就是，**把一个封闭轮廓和另一个封闭轮廓打通并连接起来**。"
    - **效力**："这样可以**一举两得地同时削弱两个封闭图形的法向动力**。"
    - 验证方式："如下图所示，**比较一下原图和恢复轮廓以后的样子**。"

## Key Concepts

- **一切封闭轮廓都有法向动力**（不只是圆形）。
- **第三维度力量**：法向动力的来源。
- **圆角大小 → 法向动力大小**：越接近圆形越大。
- **圆形的旋转特征**：使它具有最大的法向动力（详见第 13 章）。
- **打破轮廓**：让图形不再是完整封闭轮廓，法向动力自然削弱。
- **轮廓缺口**：最小尺度的"打破轮廓"（印章案例）。
- **轮廓连通**：两个封闭轮廓打通连接，一举削弱两者。
- **穿透感**：封闭轮廓使人感到"有一个洞/穿墙"。

## Mental Models

- **Use 封闭轮廓识别 when 扫描一个产品**：所有闭合的圈（按钮、开孔、格栅、屏幕圆角）都在产生法向动力。
- **Use 圆角大小 when 调节封闭图形的法向动力强度**：要强 → 加大圆角接近圆形；要弱 → 减小圆角或做锐角。
- **Use 打破轮廓 when 需要削弱某个封闭形状**：留一个缺口即可（印章的启发）。
- **Use 轮廓连通 when 需要同时削弱两个形状**：把它们打通连接，"一举两得"。
- **Remember 手机圆角与 App 图标 when 说明该规律的实用价值**。
- **Remember 旋转特征 when 解释"为什么圆形最强"**。

## Anti-patterns

- **以为法向动力只属于圆形**：所有封闭轮廓都有，只是大小不同。
- **在需要强法向动力时使用锐角封闭形状**：圆角太小会削弱效果。
- **在需要弱法向动力时保留完整的大圆角轮廓**：应打破轮廓或连通。
- **忘记检查"随处可见的封闭轮廓"**：手机的圆角、App 图标、产品的开孔都在起作用。
- **把"缺口"当成缺陷**：它恰恰是有效的削弱手段（印章的例子）。

## Worked Example

**判断两个 App 图标哪个法向动力更强（并据此调节）**

1. **识别对象**：两个图标都是**封闭轮廓**图形 → 都具备法向视觉动力。
2. **比较变量**：唯一的关键差别是**圆角大小**。
3. **套用规律**：**"图形越接近于圆形，法向动力就越大"** → **圆角更大、更接近圆形的那一个，法向动力更强**。
4. **理解极值**：**圆形**的法向动力**最大**，因为它带有**旋转特征**（第 13 章展开）。
5. **迁移到手机**：观察自己手机的**圆角大小**，以及它**放在桌面上时呈现的法向动力效果**。
6. **若需削弱**：
   - **打破轮廓**：在轮廓边缘留出一个**缺口**（印章案例——缺口让它"看上去效果更好"）；
   - **轮廓连通**：把它与另一个封闭轮廓**打通并连接**，**一举两得**地削弱两者。
7. **验收**：**比较原图与"恢复轮廓以后"的样子**，确认削弱是否到位。

## Key Takeaways

1. **法向视觉动力不专属圆形——一切封闭轮廓都有**，皆由**垂直所在平面的第三维度的力量**形成。
2. 封闭轮廓使人产生"**洞 / 穿墙**"的立体感（"纸面上有一个黑洞"的比方对所有封闭图形成立）。
3. **图形越接近于圆形，法向动力就越大**；**圆形的法向动力最大**（因为它带有**旋转特征**）。
4. **封闭几何图形的圆角大小就决定了它法向动力的大小**（App 图标、手机圆角）。
5. 削弱方法一：**打破轮廓**——图形不再是完整封闭轮廓时，法向动力自然削弱（印章的轮廓缺口）。
6. 削弱方法二：**把一个封闭轮廓与另一个封闭轮廓打通并连接**，可**一举两得**削弱两者。
7. 验收方式：**比较原图与恢复轮廓后的样子**。
