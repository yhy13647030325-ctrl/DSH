# 第 13 章：流动的形态

## Core Idea
矢量（视觉动力）解释不了有机形态，于是引入**流体**：关键是**流速与轨迹**——必须先在视觉上**制造连贯流道**（闭环或消失在边缘），再通过**障碍物**与**弯道**控制流速，并让多条轨迹**趋势一致**。

## Frameworks Introduced

- **为什么引入流体（本章的动机）**：
  - 局限："引入的原因是，**视觉动力这个概念的运用遇到了局限，因为矢量并没有办法解释视觉领域的所有内容**，所以需要借用其他概念。"
  - 界定："这里所说的**流体并不是流体力学**，那个还需要微积分数学基础。……这里讲的**流体不过是流动的液体**而已。"
  - 具体困境："对于下图中的**有机形态**，视觉动力的方法就没有很好的方式来表达。不得不用**很多个很小的箭头排着队**来表示形态的生长力。这样表示就变得**烦琐、累赘，不容易有结论**。但是，这些箭头的排列却在视觉上有了一种有趣的**流动效果**。"
  - When to use：形态复杂、箭头式分析失效时。

- **动态与静态的错觉（本章的知觉基础）**：
  - 静态错觉（倒蜂蜜）："在倒蜂蜜或者橄榄油的时候，知道液体在流动，但某一瞬间看上去像是静止的一样。"——**"视觉判断物体的动态主要依靠光影的变化"**；"这种**质地均匀、清澈透明的液体，很容易给我们造成一种静止的错觉**。"
  - 动态错觉（静止图像）："如果反过来，**静止的图像也会给我们造成动态的错觉**。"
  - 生理依据："只要我们睁开眼睛，**眼球就一直处于高频的轻微颤动状态**。因为视网膜需要**有光线照射才能发出电信号**，而且需要**不断变换的光线**照射，才能持续发出电信号传递到大脑。如果视网膜上的一个细胞一直被一样波长的光线照射，它很快就会因为感觉不到变化而失去敏感性。"（**雪盲**即此理）
  - 操作结论："所以**你用动态的方式来描述静态的画面和物体是有生理依据的**……只不过那些静态的图片引起的动态效果往往是不能被察觉出来的，需要**通过提示和标注来识别它们**。"
  - 用法："我们不再用之前视觉动力的方式来描述生长形态，而是**用连续小箭头作为引导**，能让我们用流动的视角来看待一个静态的形态，就好**像亲眼看到它长出来的过程**似的。"

- **流速：制造连贯流道（本章的第一关键）**：
  - 总纲："不像视觉动力强调的是方向、大小、增强、削弱。**在流体概念中，关键的就是流速和轨迹。**"
  - 活水与死水："一般**无头无尾的是活水**，一个你眼睛都能看到头和尾的，那一般不是河流，而是**死水**。"
  - **首要条件**："产生流动性和流速的首要条件是**在视觉上制造出流动的可能性，也就是制造出连贯的流道**。"
  - **两种做法**："要么**在可视范围内制造闭环流道**，要么**让流道消失在产品的边缘**——当然，这其实依然是一个**闭环流道**，只不过**流道是立体环绕产品形体**的。"
  - 效果："这样就可以保证流动的可能性，使产品外观具备**流体动感**。"
  - 例：FLIR 设备；打印机（设计局限性大，外形不能有太大变化）——"无论是使用**宽窄变化的河道面**，还是使用**宽度一致的河道面**，它们都在试图制造产品形体上的**视觉流动性**"。

- **障碍物：控制流速（本章的第二关键）**：
  - **改道而非堵死**："**流体一旦流动起来，要使它变化，只能改道而不能堵死**，这也是符合客观世界的规律的。……当流道中出现障碍物，且其可能直接把流道堵死的时候，那**流体一定会改道，绕过障碍**。"
  - **减速机制**："视觉上，**流体为了减速正好也是通过在河道中放置一些障碍物来实现的**。"
  - **医疗仪器案例（本章最完整的实战）**：
    - 布局："它有一个屏幕，**屏幕周围是一圈的按键**，按键所处的区域是一个**灰色的围绕屏幕一周的流道**。"
    - 宽度变化："这个灰色流道的**宽度在遇到按键和 Logo 的时候就会有所变化**，目的就是**保障流速**。"
    - 细小障碍："在产品的左上角有两个绿色的按键，按键边上还有图标，它们就是产品白色外壳区域这个流道中的**细小障碍**。"
    - **排列原则**："两个按键的轮廓和图标的排布一定是**按照流体的流向安排**的，如同它们是**在一条河流中沉睡了上百年的石头，被冲刷成与河流方向一致的样子**。"
    - **弯道与障碍同处**："**障碍物往往放在拐角处**，这是因为**在转弯时必然减速，这是常识**，而障碍物也是让流体减速的因素。所以**弯道和障碍物两个减速要素放置在同一处**，可以使流体在视觉上有明确的减速效果，**离开减速区域后，流体又开始在直道无障碍加速**。"
    - **反例（分开放置的恶果）**："如果分开放置，就会使流体可能在弯道减速，通过弯道准备加速时，又遇到直道中的障碍物，不得不再次减速，则会产生**停滞的效果**。"
    - 结论："所以在以流体元素为主的产品外形设计上，**利用流体原则可以指导我们对按键和图标这类小元素进行合理的运用**。"
  - **优先级说明**："在有些产品上，**流体特性会主导产品的外观，而法向视觉动力和凹凸关系，则会退居次要**。"

- **轨迹：多条流道的协同（本章的第三关键）**：
  - 单条轨迹："如果一个产品外形上**只有一条流道轨迹**，这个轨迹自然是可以很自由地设定，在这种情况下，**轨迹关系并不重要**。"
  - 多条轨迹："但如果在**流道数量很多**的情况，它们之间就会**相互影响**，流道轨迹之间的关系就变得**十分重要**。这种情况经常出现在**强调动感的产品类型**中。"
  - **协同原则**："流道的轨迹之间是有一定的**相互约束**的，**不能自顾自地乱流**。它们都**统一朝向一个目标**，即便轨迹不同，但**趋势一致**。如同**游蛇们集体出动，盯住同一个猎物**。"
  - 案例：某汽车的流体处理"非常的混乱"——"稍加修改，**控制、调和各个流道轨迹之间的关系**，就可以有所改善"。
  - 交汇处理："两个流道交汇却又互不影响"在物理世界是"像德国的**马格德堡水桥**一样上下错开的"；"不过在产品上它们其实是**互相交错**的，所以我们需要做一些视觉上的处理，**用粗细或颜色加以区分**，否则流体的效果会受到影响。"

- **用流体回看视觉动力（本章的理论统合）**：
  - 拉扯图示："这些拉扯图示，其实也是由于**流体流速的剧烈变化**导致的视觉效果，与之前讲过的图形的剧烈形变所体现的视觉动力类似。"
  - **圆形 = 台风**："我们可以把圆形的内部看作是**拥有流体物质并旋绕着圆心高速旋转，就类似于台风的样子**。"
  - **圆心遮蔽的流体解释**："在圆形的这个流体闭环内，**边界的入侵就是一种对内部流动性的巨大阻碍**。**直到覆盖圆心，闭环内的所有旋转流动都被停止了。**这也对应我们之前讲过的法向视觉动力的约束方式。"
  - **流体的独到价值**："不过之前内容的局限性就体现在此处，**有一种情况只能用流体概念来解释，那就是当所有抑制法向视觉动力的方法都不能用的时候**。"
  - **极端情况的解法**："面对极端情况，我们就采用**往流道里放置障碍物**的方法来抑制流体的流速，从而可以抑制圆形流体闭环的法向视觉动力。**放得越多，流速越慢，法向动力就越弱。**"
  - 案例（单反相机镜头）："左边的镜头上**有文字印刻**，右边的镜头没有。两边的法向视觉动力大小不同。左边的圆形闭环流体，由于**流道内障碍物的大量出现，导致流速降低**。而右边在没有障碍物的情况下，**流速可以达到非常高**，再加上**同心圆嵌套**的形式，**法向动力就会非常刺眼**。"

## Key Concepts

- **流体（本章义）**：流动的液体，非流体力学。
- **矢量局限**：有机形态用箭头排布表达会"烦琐、累赘"。
- **动态/静态错觉**：视觉判断动态主要依靠**光影变化**；视网膜需要**不断变换的光线**（雪盲）。
- **流速与轨迹**：流体概念的两个关键。
- **连贯流道**：闭环流道，或流道消失在产品边缘（实为立体环绕的闭环）。
- **活水 / 死水**：无头无尾 = 活水；看得到头尾 = 死水。
- **障碍物**：既造成改道，也是减速手段。
- **弯道**：必然减速；应与障碍物放在同一处。
- **停滞**：弯道与障碍分离导致的负效果。
- **轨迹协同**：多流道统一朝向一个目标，趋势一致（游蛇喻）。
- **流道交汇**：用粗细或颜色区分。
- **圆形 = 旋绕圆心的流体闭环**（台风喻）。

## Mental Models

- **Use 流体 when 形态是有机的、箭头分析失效**。
- **Use 连贯流道 when 要为产品建立流动感**：闭环，或让流道消失在产品边缘。
- **Use 障碍物 when 需要减速**；**Use 弯道 when 需要减速**；**把两者放在同一处**以获得明确减速，之后在直道加速。
- **Avoid 把弯道与障碍分开**：会产生**停滞**。
- **Use 按流向排布 when 处理按键、图标等小元素**：像被河流冲刷百年的石头。
- **Use 统一趋势 when 流道很多**：各轨迹不必相同，但**朝向同一目标**。
- **Use 粗细或颜色区分 when 流道交汇**。
- **Use 往流道加障碍物 when 所有法向削弱方法都不可用**：放得越多，流速越慢，法向动力越弱。

## Anti-patterns

- **用矢量方式硬解有机形态**：会"烦琐、累赘，不容易有结论"。
- **让流道有头有尾**：那是"死水"，不具备流动感。
- **让障碍物直接堵死流道**："只能改道而不能堵死"。
- **把弯道减速与障碍物减速分开放置**：会产生停滞效果。
- **让多条流道"自顾自地乱流"**：轨迹必须趋势一致。
- **让流道交汇却不做区分**：流体效果会受影响（需用粗细或颜色区分）。
- **在法向削弱方法都可用时先想到流体**：流体是"极端情况"的专用解释力。

## Worked Example

**用流体原则改造一台医疗仪器的按键布局**

**第 1 步：制造连贯流道**
- 以**屏幕周围一圈按键所在的灰色区域**作为**围绕屏幕一周的流道**。
- 目的：让产品外观具备**流体动感**（可视范围内的闭环流道）。

**第 2 步：用宽度变化保障流速**
- 让灰色流道的**宽度在遇到按键和 Logo 时发生变化**——"目的就是**保障流速**"。

**第 3 步：把按键作为"细小障碍"**
- 左上角两个绿色按键及其图标，是白色外壳区域流道中的**细小障碍**。
- **按流向排布**："如同它们是在一条河流中沉睡了上百年的石头，被冲刷成与河流方向一致的样子。"

**第 4 步：把弯道与障碍放在同一处**
- 常识：**转弯时必然减速**；**障碍物也是减速因素**。
- 因此**障碍物往往放在拐角处**：两个减速要素同处 → 明确的减速效果；**离开减速区域后在直道无障碍加速**。

**第 5 步：避免"停滞"**
- 若分开放置：弯道减速 → 出弯准备加速 → 又遇直道障碍 → 再次减速 → **停滞**。

**第 6 步：若流道很多，做轨迹协同**
- 让各流道**统一朝向一个目标**，"即便轨迹不同，但**趋势一致**"，如同**游蛇集体出动盯住同一个猎物**。
- 流道交汇处，用**粗细或颜色**加以区分。

**第 7 步：极端情况（法向动力无法用其他方法削弱时）**
- 采用**往流道里放置障碍物**的方式抑制流速 → 抑制圆形流体闭环的法向动力；**放得越多，流速越慢，法向动力越弱**。
- 案例：**单反相机镜头**——左侧镜头因**文字印刻**（大量障碍物）使流速降低、法向动力减弱；右侧镜头无障碍物、加上**同心圆嵌套**，流速极高，**法向动力非常刺眼**。

## Key Takeaways

1. 引入流体是因为**矢量（视觉动力）无法解释所有视觉内容**，尤其是有机形态。
2. **视觉判断动态主要依靠光影变化**（倒蜂蜜的静止错觉）；反之，**静止图像也会造成动态错觉**（生理依据：眼球频颤 + 视网膜需要变化的光线，雪盲即例）。
3. 流体的两个关键是**流速**与**轨迹**。
4. **流动性前提**：制造**连贯流道**——**闭环流道**，或**让流道消失在产品边缘**（实为立体环绕的闭环）。
5. **活水无头无尾**；能看到头尾的是**死水**。
6. **流体只能改道，不能堵死**；**障碍物同时也是减速手段**。
7. **弯道必然减速**，因此**弯道与障碍物应放在同一处**，否则会产生**停滞**。
8. 小元素（按键、图标）应**按流向排布**，像被河水冲刷百年的石头。
9. 多流道必须**趋势一致、统一朝向一个目标**（游蛇喻）；交汇处**用粗细或颜色区分**。
10. **圆形 = 旋绕圆心的流体闭环**（台风喻）；**覆盖圆心则旋转流动全部停止**，与法向动力的约束方式对应。
11. **流体概念的独到价值**：当**所有抑制法向动力的方法都不能用**时，可用**在流道中放置障碍物**来削弱（**放得越多，流速越慢，法向动力越弱**，如单反相机镜头）。
