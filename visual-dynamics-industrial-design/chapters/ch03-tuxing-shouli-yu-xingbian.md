# 第 3 章：图形受力与形变

## Core Idea
图形受力会形变，而**不同受力方式对应一组可复用的"图示"**：左右拉扯、拉断、局部涂抹；把这些图示有意地"找出来"或"添加进去"，就能掌控产品的动力效果。

## Frameworks Introduced

- **拉扯图示（左右拉扯）**：
  - 物理原型："拿一款橡皮泥，捏住它的两端，然后慢慢拉扯。它会被**越拉越长，中间部分会越来越细**，而被手捏住的地方则没有太大的粗细变化。"
  - 图形抽象："图形受到两个方向相反的拉力，越拉越长，**中间部分变细变窄**。"
  - 应用："这种图示在**汽车前脸**的设计中有不少运用……它们虽然乍看之下非常不同，但其实**都是同一个形式的视觉动力表现**而已。有的拉得比较长，比较细；有的拉得不太多，不太用力。"
  - 双向操作："通过观察，我们可以**找到这种拉扯图示的运用**，同时也可以**尝试在没有运用的地方有意添加这种图示**，来增加动力效果。"
  - 变体（柔软的拉扯）："拉扯图示不一定要抽象成硬朗的，也可以处理成**柔软的轮廓**，和真实的橡皮泥的样子非常接近"（例：FLIR 双目红外望远镜头部）。
  - 迭代形态："拉扯后形变"可用于更复杂的图形（如**回字形**的左右拉扯）。

- **拉断图示（一直拉会断）**：
  - 原型："橡皮泥如果一直被拉扯，是会被拉断的，所以同样可以抽象出一个**刚刚被拉断的橡皮泥的轮廓图形**。"
  - 应用：汽车尾灯的设计（如英菲尼迪）；仔细看会发现"它**下部的排气管**的形态是一个拉扯图示"。
  - **强度对比（本章的重要结论）**：**"拉扯图示和拉断图示哪个视觉动力效果更强？答案是拉扯图示更强，因为拉断的那个瞬间，拉力的反作用力就消失了，物体已经断裂，也就不需要拉力了。"**
  - 方法论价值："只要借助熟悉的**物理概念**，就能想明白不同图示之间的区别了。"

- **局部涂抹图示（压扁 + 涂抹）**：
  - 原型："把它**压扁在桌面上**，然后用一根手指在它的下半部分从左到右地涂抹过去，使它的下半部分发生**巨大的形变**，在桌面上留下**长长的拖曳痕迹**。"
  - 抽象结果："可以得到一个**局部受力发生剧烈形变**的视觉动力图示。"
  - 应用：汽车车灯设计（如全新迈腾）。
  - 与弯曲曲线的关系（重要辨析）："这个涂抹图示和那个曲线图示动力效果非常接近。只不过**一个是曲线，另一个是图形**——**曲线只有弯曲形变，而图形还有粗细变化**。它们其实是**同一类受力变形的样式，只是受力的对象不同**。"

- **组合运用（本章的实战建议）**：
  - "汽车前脸的设计中，有的**同时使用了左右拉扯和局部涂抹**。**多种方式组合使用是比较多见的。**"

## Key Concepts

- **受力图示**：拉扯 / 拉断 / 局部涂抹，三种可复用的形态语汇。
- **拉扯图示**：越长越细，中段变窄。
- **拉断图示**：断裂瞬间的轮廓。
- **局部涂抹图示**：局部剧烈形变 + 拖曳痕迹。
- **曲线 vs 图形**：曲线只有弯曲形变；图形还有粗细变化。
- **同形不同源**：不同产品外观可能来自同一形式的动力表现。
- **有意添加**：不仅是"读出"图示，还可以在空缺处**主动添加**以增强动力。

## Mental Models

- **Use 拉扯图示 when 需要一个"有张力"的方向感**（中段变细是标志）。
- **Use 拉断图示 when 需要更克制、更"事件化"的形态**：强度弱于拉扯，"因为拉断的那个瞬间，拉力的反作用力就消失了"。
- **Use 局部涂抹图示 when 需要局部剧烈形变 + 拖曳感**。
- **Use 曲线/图形的选择 when 决定要不要"粗细变化"**：要粗细变化则必须用图形，而非曲线。
- **Use 组合 when 单一图示动力不足**：拉扯 + 涂抹是常见搭配。
- **Use 两种读图方向 when 做设计评审**：先"找出"已有的图示，再考虑"添加"新的。

## Anti-patterns

- **以为拉扯图示必须是硬朗的**：也可做成**柔软的轮廓**（贴近真实橡皮泥）。
- **简单地认为拉断图示 = 拉扯图示（甚至更强）**：事实上**拉扯图示更强**。
- **把曲线与图形的形变混为一谈**：区别在于图形带有**粗细变化**。
- **只使用单一受力图示**：会失去组合增益。
- **只在已有的图示上分析，忽略"主动添加"**：作者明确鼓励在没有运用的地方有意添加。

## Worked Example

**从橡皮泥到汽车前脸：三次受力实验对应三种图示**

**实验一：拉扯（横向）**
- 操作：捏住橡皮泥两端慢慢拉扯。
- 结果：**越拉越长，中间部分越来越细**，手捏处粗细不变。
- 抽象：两个方向相反的拉力 → 中间变细变窄的图示。
- 用在哪里：汽车前脸设计（现代领动、Polo GTI、Huracan、Kia 等）。
- 变体：也可做成**柔软轮廓**（FLIR 双目红外望远镜头部）。

**实验二：一直拉会断（拉断）**
- 操作：持续拉扯，直到断裂。
- 结果：得到"刚刚被拉断的橡皮泥轮廓"。
- 用在哪里：汽车尾灯轮廓（英菲尼迪）、下部排气管。
- 强度判断：**弱于拉扯图示**——"拉断的那个瞬间，拉力的反作用力就消失了"。

**实验三：压扁 + 涂抹（局部涂抹）**
- 操作：压扁在桌面 → 一根手指在下半部分从左到右涂抹 → 留下长长的拖曳痕迹。
- 结果：**局部受力发生剧烈形变**的图示。
- 用在哪里：汽车车灯（全新迈腾）。
- 与曲线的关系：**同一类受力变形，只是对象不同**——曲线只有弯曲形变，图形还有粗细变化。

**收口**：在前脸设计中把**拉扯 + 涂抹组合使用**，是"比较多见"的做法。

## Key Takeaways

1. **拉扯图示**：两个相反拉力 → 越拉越长、中间变细变窄；广泛用于汽车前脸；也可柔化处理。
2. **拉断图示**：断裂瞬间的轮廓（汽车尾灯）。
3. **拉扯图示的视觉动力强于拉断图示**——因为拉断瞬间反作用力消失。
4. **局部涂抹图示**：压扁后局部涂抹形成"局部剧烈形变 + 拖曳痕迹"（汽车车灯）。
5. **曲线只有弯曲形变，图形还有粗细变化**；二者是同一类受力变形的不同对象。
6. 设计时既**"找出"**已有图示，也可在空缺处**有意添加**。
7. **多种方式组合使用**（拉扯 + 涂抹）比较常见。
8. 借助熟悉的**物理概念**，可以判断不同图示的强度差别。
