# 速查表（Cheatsheet）

## 决策规则

| 情形 | 决定 |
|---|---|
| 想"读出"轮廓有没有动力 | 与**几何基准线**（水平/竖直）对比，找**偏离趋势** = F |
| 分析复杂形态的动力 | 用**倒叙**：找"比它更简洁的参照图形"作对比基准 |
| 单条线动力不够 | **多条约斜线叠加**；或**加大曲线扭曲度** |
| 单类动力不够强 | **形变动力 + 倾斜动力组合**使用 |
| 画面因倾倒感不稳 | 补一个**支撑要素**（视觉平衡） |
| 判断某产品用了哪种受力图示 | 看特征：**中段变细**=拉扯；**断裂轮廓**=拉断；**拖曳痕迹**=局部涂抹 |
| 在拉扯与拉断之间选 | 要更强 → **拉扯**（拉断时反作用力已消失，更弱） |
| 想要更强烈的受力效果 | **拉扯 + 局部涂抹组合** |
| 受力图示太硬朗 | 处理成**柔软轮廓**（贴近真实橡皮泥） |
| 两个图形有压迫关系 | 用**施力者/受力者**：拆分角色 → 筛出冲突对 → 判角色 |
| 想增强冲突动力 | **求合力**——合力的视觉动力效果更强烈 |
| 想更丰富 | 扩角色数（双施力者 + 单受力者；多施力者 + 多受力者，**无数量上限**） |
| 动力分析太复杂 | **一图形/曲线只用一个箭头**，逐一编号 |
| 不知道每个元素该干什么 | **按势力划分阵营**（向上势力 / 向下势力） |
| 图形不接触怎么比 | 比**气势/势能**；**不是越紧张越好**，要增强对立感 |
| 气氛过于紧张 | 把一方**移动一点点、留大空隙** |
| 发现同方向重复动力 | **去掉重复的一个**（否则会形成左右拉扯图示，破坏主题） |
| 某元素离冲突中心太远 | 修改轮廓，**增强势能、明确指向、怒视冲突中心** |
| 某元素的力朝向错误 | **修改轮廓 + 调整动力方向**，收编到正确势力 |
| 想让形态有生命 | 用**竹笋范式**：向上生长力 + 向内挤压 → 外轮廓逐步减弱、向内倾斜分割 |
| 生长遇到阻力 | **绕开阻力继续向上**（分叉），不要停止、不要穿透 |
| 要不要劈断 | **千万不能劈断**——生长力必须 > 阻力，但只以**微弱优势** |
| 产品某端天然变细 | **顺应末端自然约束**，不做过多处理，把发挥放在另一端 |
| 开始一个产品的外观设计 | 做**先天形态分析**：轮廓拆成 **3 个基础图形**（标准：可提炼单一准确动力） |
| 不知道重点处理哪里 | 找**细节分布区**（Logo、散热孔） |
| 产品要"力量感/坚固/可靠" | 用**战争模型**：双方劈砍式，入侵者先攻三次劈砍 + 拉扯加强，生长方同样反击 |
| 产品要柔和（如吹风机） | 用**生长形态末端的分割处理方式** |
| 要约束向上生长的形体 | 选**方向相对**（同轴线正面攻击）或**方向垂直**（侧面入侵） |
| 约束要多狠 | **边缘轻微内缩**（一般够用）／**垂直方向形体攻击（打穿顶部）**（最强）／多数产品**几种全用** |
| 需要可分析的简洁形体 | 用**封闭轮廓垂直拉伸**的实体（可简化为单一视觉动力） |
| 正方体动力数量爆炸 | **倒角**（增强截面法向动力）或**轴向拉长** |
| 多形体拼接动力混乱 | 用"**一端 + 埋入**"：形体 2、3 都在形体 1 一端且一端埋入，互相制造阻碍 → 单向 |
| 组合多个形体 | **主要（最大/动力最大）→ 次要（适中/略小）→ 附加（最小/最小动力）** |
| 一个图形有多个动力 | **只标出自己需要的那部分动力**（承认标注的主观性） |
| 出现纯凹陷或纯凸起 | 补另一种：**纯凸加凹陷补偿，纯凹加凸起补偿**（形态补偿） |
| 需要流动感 | 制造**连贯流道**：闭环流道，或让流道**消失在产品边缘** |
| 流道流速过快 | **在河道中放置障碍物**（放得越多，流速越慢）；**只能改道不能堵死** |
| 在某处需要明确减速 | 把**障碍物放在拐角处**（弯道 + 障碍两个减速要素同处） |
| 处理按键、图标等小元素 | 让它们**按流体流向排布**（如被冲刷百年的石头） |
| 流道数量很多 | 让轨迹**统一朝向一个目标、趋势一致**（游蛇喻）；交汇处**用粗细或颜色区分** |
| 所有法向削弱方法都不能用 | **往流道里放障碍物**削弱流速 → 削弱法向动力 |
| 想彻底削弱圆形 | **遮挡圆心**（最强，但"失去大部分生命力"，不主流） |
| 想精细调节削弱程度 | **不遮圆心，破坏边缘轮廓**并按面积调节；**不要越过圆心**（越过 = 死亡状态） |
| 圆形轮廓不能破坏 | **内部切割**（切比萨；或轻微重复切割如金属网） |
| 轮廓与内部都不能动 | **外部干扰**（圆周外围布置图形；最弱但可能性最多，摄像头/排气管常用） |
| 任何封闭图形要削弱 | **打破轮廓**（不再是完整封闭轮廓即减弱）；两个都要削弱则**连通为一体** |
| 调封闭图形的法向动力 | 调**圆角大小**——越接近圆形越大 |
| 设计 App 图标 / 手机 | 留意**圆角大小**及产品**放在桌面上的法向动力效果** |
| 需要节奏感（静态画面） | 按**压制与释放**构造：先试探 → 逐步释放 → 达到最大 → 结尾峰值后迅速平息 |
| 静态对比怎么做才算到位 | 同时做**明暗 + 细节密度 + 色彩**多维反差，并设定两者的**对比、比例、位置** |

## 决策树

```
看到一个形态，怎么分析？
├─ 是单一图形/曲线
│   ├─ 平面内 → 与几何基准线对比 → 得 F；或倒叙（与更简洁参照图形比较）
│   ├─ 封闭轮廓 → 还有法向动力（垂直平面的第三维），圆角越大越强
│   └─ 实体（三维）→ 形体视觉动力；封闭轮廓垂直拉伸可简化为单一动力
├─ 是两个及以上图形
│   ├─ 发生接触碰撞 → 施力者/受力者冲突 → 求合力
│   └─ 远距离对峙 → 势力阵营 + 势能；调空隙、强化指向、翻转方向
└─ 是有机/复杂形态
    └─ 用流体：先造连贯流道，再用障碍与弯道调流速，再协同轨迹

形态看起来"不自然"，问题在哪？
├─ 纯凹陷/纯凸起 → 形态补偿（凹凸并存原理）
├─ 末端是平的/圆柱状 → 缺末端自然约束（竹笋必尖）
├─ 被劈断了 → 违反微弱优势原则（变成两个独立形体）
├─ 圆形动力太刺眼 → 按限制条件选：遮圆心/破坏边缘/内部切割/外部干扰
├─ 流道停滞 → 弯道与障碍分开放置了，应同处
└─ 画面无节奏 → 缺压强与释放的转换，或只在单一维度做对比

多形体组合怎样才不乱？
├─ 分主次附加（形体大→动力大；形体小→动力小）
├─ 每个形体只保留单向动力（用"一端+埋入"制造一端的阻碍）
└─ 避免在中心位置互相穿插、避免三者体量接近
```

## 阈值与默认值

| 项 | 值／判据 |
|---|---|
| 圆形在平面内的合力 | **0**（唯一起点图形） |
| 三维起点图形 | **球体**（星球、种子、胚胎） |
| 正方体完整动力数 | 6 个法向 + 8 个尖角动力（**无实用价值**） |
| 先天形态分析拆解数 | **3 个基础图形** |
| 约束强度分级 | 边缘轻微内缩 → 垂直方向形体攻击（打穿顶部） |
| 三维末端对抗方向 | 2 种：方向相对（同轴线）/ 方向垂直（侧面） |
| 多形体角色 | 3 种：主要 / 次要 / 附加（体量与动力双重递减） |
| 视觉通道承载节奏 | 仅**视觉与听觉**（味觉、嗅觉无节奏） |
| 通感发生位置 | **大脑皮层内部** |
| 视觉波长范围 | 400~760 纳米（4 种视觉细胞） |
| 听觉频率范围 | 20~20000 赫兹（50000 毛细胞） |
| 嗅觉气味种类 | 1 万多种（300~400 受体细胞） |
| 静态节奏的维度 | 3 类：明暗 / 细节密度 / 色彩 |
| 影视节奏的速度维度 | 3 个：镜头时间（慢→正常）、主体速度、镜头切换速度 |

## 识别信号

- 某处轮廓**偏离水平线或竖直线** → 存在视觉动力 F。
- 图形**中段变细** → 拉扯图示在起作用。
- 图形有**断裂般的轮廓** → 拉断图示（比拉扯弱）。
- 局部有**拖曳痕迹** → 局部涂抹图示。
- 两个图形一方**被逼入角落、剧烈形变** → 施力者／受力者冲突。
- 图形**互不接触但气氛紧张** → 对峙型，比的是势能。
- 出现**同方向重复的动力** → 应删掉一个。
- 形态末端**呈尖形/逐步收窄** → 符合生长与约束规律。
- 形态**被劈成两段** → 违反微弱优势，生长感已消失。
- 某端**天然变细**（如手电钻头部） → 末端自然约束，不宜多动。
- 产品上**存在 Logo、散热孔** → 该图形是处理重点（细节分布区）。
- 圆形**看起来很刺眼** → 法向动力过强，或障碍物太少（如无文字印刻的镜头）。
- 圆形**被遮住圆心** → 已接近"死亡状态、无生命迹象"。
- **圆角很大** → 法向动力强（手机、App 图标）。
- 两个封闭轮廓**被打通连接** → 一举两得削弱两者法向动力。
- 印章外轮廓**有缺口** → 打破轮廓以削弱法向动力。
- 流道**有头有尾** → 死水，无流动感。
- 流道**在拐角处放置了障碍** → 有效的减速设计；若两者分开 → 会产生**停滞**。
- 多条流道**趋势一致** → 轨迹协同得当；若"自顾自地乱流" → 混乱。
- 画面**一部分高密度聚集、其余稀疏清淡** → 静态节奏（对比）成立。
- 画面**只在单一维度做对比** → 节奏单薄。
- 颜色、冷暖、明度纯度**看似讲究实则无序** → 缺的是**节奏的把控、抑制与释放**。
