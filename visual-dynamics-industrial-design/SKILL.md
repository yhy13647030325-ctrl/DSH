## 核心框架与思维模型

### 1. 视觉动力 F 是一个假设（ch01 + ch02）
**"视觉动力是指用来描述视觉感受的一种概念工具，并不真实存在。"** 同"1+1=2""人是自私的"一样是基础假设。
读法：把轮廓与**几何基准线**（水平/竖直线）对比，找**偏离趋势** = F；**倾斜的线条形成推力**。增强：**多条斜线叠加**、**加大扭曲度**、**形变 + 倾斜组合**。
前提：美感是**进化的额外视觉快感奖励**（与性选择相关），**底层审美判断始终激活**——故外观关乎根本。

### 2. 三种受力图示（ch03）
**拉扯**（相反拉力 → 越长越细、**中间变窄**）／**拉断**（刚断裂的轮廓，**强度弱于拉扯**：断裂瞬间反作用力已消失）／**局部涂抹**（压扁后涂抹 → **局部剧烈形变 + 拖曳痕迹**）。
辨析：**曲线只有弯曲形变，图形还有粗细变化**。用法：既**"找出"**已有图示，也可**有意添加**；**组合使用**（拉扯+涂抹）常见。

### 3. 施力者与受力者（ch04）
两图以上发生"攻击—被攻击"时判角色：**施力者**（把人逼入墙角者）、**受力者**（剧烈形变者）。
**可像做物理题一样求合力，合力的视觉动力效果更加强烈**；**角色数量无限制**。

### 4. 生长与约束（ch05 + ch06）
- **一切动力都有阻力，一切生长都有障碍**；**视觉舒适 = 符合客观规律**。
- **圆形 = 平面内合力 0 = 一切图形的起点**（如一粒种子）；分析是**倒叙**的——**与更简洁的参照图形比较**得动力矢量。
- **竹笋范式**：向上生长力 + 向内挤压 → 外轮廓**逐步减弱** → **外表面向内的倾斜和分割**（末端必尖）。
- **分叉**：生长力**绕开阻力继续向上**，反复即成树枝结构。
- **微弱优势原则**：生长力必须 > 阻力但只微超——**千万不能劈断**，一断即变成两个独立形体。
- **先天形态**：由功能决定、同类共享（电动工具与吹风机都有手柄）；有的产品有（单反相机），有的没有（音箱）。做法：轮廓拆成 **3 个基础图形**（可提炼单一准确动力），重点处理**细节分布区**（Logo、散热孔）；**末端自然约束**（手电钻头部）顺应，发挥集中在另一端。
- **战争模型**："**我们的工作就是在制造生长势力与约束势力的冲突**"——双方劈砍式，入侵者先攻三次劈砍 + 拉扯加强，生长方同样劈砍反击并插入内部。

### 5. 动力分析与形态修改（ch07）
两种强度：**激烈型**（接触碰撞，电动工具）／**对峙型**（远距离对峙，汽车前脸——**没有先天形态缺陷**，难点是"**如何修改**"）。
**简化法**：**一图形/曲线只用一个箭头**、逐一编号 → 划分**势力阵营**。不接触时比**气势/势能**，**不是越紧张越好**。
四类修改：**去重复动力 / 调空隙降紧张 / 强化轮廓指向与势能（"怒视"冲突中心）/ 翻转动力方向**；先定大方向，**再增加细节**。

### 6. 法向视觉动力及其控制（ch08 + ch09 + ch10）
- **定义**：**"把一个通过圆心、方向垂直于圆形所在平面的动力，称为法向视觉动力。"** 成因是**强制图底分离**（"不能同时看到两个图案"；人脸—花瓶图），这也解释了"文字浮在纸面上"。
- **推广**：**一切封闭轮廓都有法向动力**（垂直平面的第三维力量）。**核心判据：圆角大小决定大小**——**越接近圆形越大**，**圆形最大**（因带**旋转特征**）。应用：App 图标、手机圆角。
- **可控性**："**削弱与增强的关系是视觉动力的关键**"，依据**动力源在圆心**按限制条件选法：
  ①**遮挡圆心**（最强，但"以致失去了大部分生命力"，不主流）；②**不遮圆心、破坏边缘轮廓**（**主力手法**，按面积调节；标尺见**眼睛表情**：冷漠→微笑→恐惧→翻白眼，遮挡越多越温和，**含圆心 = 死亡状态**）；③**内部切割**（切比萨／金属网）；④**外部干扰**（最弱但可能性最多）；⑤**打破轮廓**（印章缺口）；⑥**轮廓连通**（打通两个封闭轮廓，**一举两得**）。

### 7. 形体视觉动力（ch11）
- **形体视觉动力 = 实体形态形变带来的视觉动力**（书是实体，书页画面不是）。
- 表达难度：**平面 → 法向 → 三维形体**；人类认知次序相反（**先接触真实三维**）。
- **雕塑学习的重要性远超过手绘和建模**——"会用 Word 软件不代表能写出好文章"。
- 二维起点是**圆形**，三维起点是**球体**（实际不用球体起手）。正方体完整分析（6 法向 + 8 尖角）**无实用价值**；简化法：**倒角**或**轴向拉长**。
- **法向动力与形体动力等效**；**以封闭轮廓做垂直拉伸**的形体可简化为**单一视觉动力**；**三维形体特征** = 二维图上无法展现的动力冲突形式。
- 末端对抗：**方向相对**（同轴线正面攻击）／**方向垂直**（侧面入侵）。强度：**边缘轻微内缩** → **打穿顶部**；多数产品**几种全用**。
- 多形体拼接须有序：**主要（最大/动力最大）→ 次要（适中/略小）→ 附加（最小/最小）**；用"**一端 + 埋入**"让每个单元的力变**单向**（互相制造一端的阻碍）。动力标注有**主观性**——**只需标出自己需要的那部分动力**。

### 8. 凹与凸的平衡（ch12）
- **凹 = 物质缺失**；**凸 = 物质增多**（含只是"看起来增多"）。
- **物质不增不减时，凹陷与凸起必然并存**：陨石坑看起来与火山口差不多；脚印亦然。机制：**凹陷部分的物质被挤压移动，成为周围凸起部分的物质**。
- 视觉舒适度**基本上处于普通物理范围内**：受**时间维度**限制（水滴石穿）、不能识别**化学过程**。
- **形态补偿**：**单纯凸起加凹陷补偿；单纯凹陷加凸起补偿。**（三维中是二维"生长力/阻碍力搭配"的表述升级）

### 9. 流动的形态（ch13）
矢量无法解释一切，故引入**流体**；关键是**流速**与**轨迹**：
- **制造连贯流道**：**闭环流道**，或**让流道消失在产品边缘**（实为立体环绕的闭环）。**有头有尾 = 死水。**
- **流体只能改道，不能堵死**；**障碍物同时是减速手段**。
- **弯道必然减速**，故**障碍物应放在拐角处**（两减速要素同处）；**分开放置会产生"停滞"**。
- 小元素（按键、图标）**按流向排布**；多流道须**趋势一致、统一朝向一个目标**（游蛇喻），交汇处**用粗细或颜色区分**。
- **圆形 = 旋绕圆心的流体闭环**（台风喻）；**覆盖圆心则旋转流动全部停止**。
- **流体的独到价值**：当**所有抑制法向动力的方法都不能用**时，**往流道里放障碍物**——**放得越多，流速越慢，法向动力越弱**。

### 10. 视觉节奏（ch14）
- **节奏就是压制与释放的组合搭配**——平静与激烈、沉默与呐喊，两个极端之间的转换。
- 源自**恐吓**：**先试探 → 逐步释放 → 强度达到最大**；结尾指标达峰值后**迅速平息**。
- **节奏只出现在视觉与听觉**（大脑对这两类信息处理能力更复杂）。
- **静态画面中的节奏就是"对比"**——**密度的高度差异**；须细化为多维度：**明暗**（黑白比例 + 交织/纯色对比）、**细节密度**（高密度聚集 vs 大量空白）、**色彩**（暖色高纯度聚集 vs 冷色低纯度蔓延、变化频率不均）。
- 最终提炼：**颜色、冷暖、明度纯度都不重要，关键是节奏的把控、抑制与释放**——掌握**高／低密度、高／低压力、高／低频率**两区之间的**对比、比例、位置**。

本技能只覆盖《工业产品设计中的视觉动力（第 2 版）》（李想 编著，人民邮电出版社）一书的内容。

**生成说明**：原 PDF 为**无文本层扫描件**（194 页，仅 869 个字符且无汉字），正文全部经 **RapidOCR（PP-OCRv6）** 逐页识别。本书是**高度依赖插图**的方法论著作——"视觉动力"的判读需要通过作者标注箭头的示例图来体会，而这些图及其标注**无法通过 OCR 获取**。因此本技能覆盖其**文字论述与方法框架**，但**图示中箭头的具体指向、位置与强度**需对照原书查看。OCR 对书内小字标注（图中箭头旁的 F 标记等）识别率低，引用精确原文时请以纸质书复核。

**方法边界（书中明确陈述）**：视觉动力的舒适度"基本上处于**普通物理范围**内"，不包括长时间过程（水滴石穿）与化学过程（腐蚀、体积剧增反应）。作者亦说明"视觉动力"本身是一种**假设**。

**练习依赖**：作者多次强调需要**大量观察练习**才能获得"不经过思考就能看出视觉动力"的敏感度，并主张**学习雕塑**的重要性远超过手绘与建模。本技能提供判断标准与分析路径，不能代替观察训练与动手实践。
