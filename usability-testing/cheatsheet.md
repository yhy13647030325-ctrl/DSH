## 测前（计划 / 人 / 任务 / 试点）

| 动作 | 照做 | 出处 |
|---|---|---|
| **先问该不该测** | 五种伪理由全部否掉：能改善体验／别人都做／会议室正好空／某人刚在会上学了新招／想验证市场有没有需求 | p106 |
| **定测试类型** | 只问三件：要回答什么？产品多完整？还有多少时间可改？ | p65 |
| **写计划九节** | Purpose → Research questions → 被试特征 → Method → 任务清单 → 环境设备 → 主持人角色 → 数据与度量 → 报告内容 | p105 |
| **设两个冻结日** | 计划冻结（问什么不再变）＋ 产品冻结（测什么不再变） | p103 |
| **写研究问题** | 必须**可观察**。"测试是否易用"× → "旅客如何开始预订？卡在哪一步？"✓ | p107、p110 |
| **画像第一稿** | 写叙述句"看见一个人"，不写条件表；区分付钱的/用的/读文档的 | p154 |
| **操作化定义** | 用「任务 × 频次」矩阵打分，**不用自评**。反例：60 小时/周仍可能不会用浏览器 | p157–p158 |
| **定 Requirements / Classifiers** | Requirements = 门槛（否则 Terminate）；Classifiers = 格子（记录+配额） | p159 |
| **矩阵设计** | 两轴用**领域知识 × 工具知识**；每格 ≥4 人；填不满则向"最像主流用户"偏 | p163–p164 |
| **定样本量** | 见下「关键数字」 | p110/p164；B p38–p40/p213 |
| **写筛问卷七步** | 回画像 → 抓产品特有属性 → 成题 → **最易淘汰的靠前** → 简化流向 → **自己测一遍** → 做答案表 | p165 |
| **筛问卷结构** | 每题 = 问题 + 选项 + `[Terminate]/[Continue]` + **招募员注记**；不朗读选项；聚焦行为不聚焦人口统计 | p168–p169 |
| **必招 LCU** | 每个样本 ≥1 个「最不熟练用户」（时间不敢卡在最底、但多数维度在底） | p184 |
| **控明星被试** | 最多 1–2 个；**3–4 个就毁掉结果**；登记招募来源 | p185–p186 |
| **留招募时间** | **2 周**；确认做 3 次（确认信 → 前一天提醒 → **前夜电话，尽量找到人**） | p187 |
| **任务清单（给团队）** | 四部分：描述／材料与机器状态／**SCC**／计时基准 | p117–p118 |
| **算计时基准** | 6 人估算（3 工程师+3 技术写作）取均值 **× 2.5** | p120 |
| **写任务场景（给被试）** | 一个场景包住多条任务；给目标+动机+真实数据；**不提按钮名/菜单项/屏幕标题** | p220–p223 |
| **试点** | ≥1 人，**下限能力者优先**，走完全流程。不跑试点=前 1–2 个真被试变成试点 | p253 |
| **冻结产品** | 测试期停开发；"冻结"的实质是把 bug 变成已知量 | p254 |

## 测中（脚本 / 话术 / 记录 / 伦理）

| 动作 | 照做 | 出处 |
|---|---|---|
| **选形态** | 定性 → sit-by；定量 → 主试离场（在场会把点击数/耗时拉到 **2 倍**） | p92；B p246 |
| **观察者六条** | 开场前到／全程不离开／关手机／**不笑不出声不做表情**／只问开放式且不提设计替代／保密 | p193 |
| **逐字念脚本** | 不背不即兴。作用是**抗情绪污染**（前几场失败会污染下一场） | p195–p196 |
| **脚本长度** | 几段；含任务时不超过 **2 页** | p194 |
| **脚本三禁区** | 不说"这很简单"／"大多数人觉得很容易"／"你肯定没问题" | p198 |
| **说什么** | "不是在测你"要说，但**重复 ≤3 次**；靠行为兑现（被试自责=没兑现） | p199、p265 |
| **不主动说什么** | 不主动说"在场有人做过这个产品"；**问则答真话** | p197 |
| **必须说什么** | 被观察与被录像**必须主动告知**，不得为此撒谎；报酬**绝不与表现挂钩**（玩笑也不行） | p198 |
| **出声思维** | 三选一：同步 / 回溯 / 协同发现（见下"三变体"） | p242–p244、p92–p93、p306–p307 |
| **沉默** | 被试停下时**数 20–30 秒**再介入 | p210、p244 |
| **中性问法** | "What are you thinking right now?"／"How close was that to what you expected?"；**问 what/how，不问 why** | p246；B p233 |
| **把责任揽过来** | "I missed what just happened. Could you tell me?" | p245 |
| **帮忙时机** | **该项已判定失败之后**再帮（越过基准时间），不影响计分 | p211 |
| **帮忙要记账** | "帮过"与"没帮就成"**必须分开统计**，绝不合并 | p211 |
| **提示分四档** | ①重试鼓励 ②方向（right place / different area）③一般方法 ④具体步骤；**记档位并计数** | p305 |
| **不归咎被试** | "mistakes are always the fault of the product" | p211 |
| **不救** | 迷失后怎么恢复是唯一证据；彻底卡死才介入 | p209 |
| **出错继续** | 泄漏了信息就继续，最多作废一小部分 | p210 |
| **记录分工** | 主持人**不自己计时**；用代码化（A/B/C/D + 时间戳）保住观察注意力 | p112–p113、p95 |
| **同意书四项** | 研究目的／录像去向与用途／被试如何标识／**可随时退出与撤回**；未成年需监护人签 | B p170–p171 |
| **代号** | 报告与文件名**只用 P1/U1**（不比 Barnum 的"可报名字"更宽） | p189 |
| **不可逆操作** | 做假环境（文件不真删、可恢复） | p246 |

## 测后（汇总 / 严重度 / 报告 / 复测）

| 动作 | 照做 | 出处 |
|---|---|---|
| **当天汇总** | 每天收工前 30 分钟；记忆是某些事件的唯一载体 | p285 |
| **报三个成功率** | 含协助 / 纯成功 / **基准内成功**——只报一个会隐藏两类问题 | p288 |
| **小样本写法** | "**10 of 12**"而非"83%"；先分数后百分比 | p296 |
| **计时统计** | 有离群值时用**中位数**不用均值 | p289 |
| **定性计数** | 文本进表格 → 查找替换+变色 → 得到主题频次（可复核） | p286 |
| **发现会** | 一句话发现／便签带**被试编号**／回指时间戳；预期四阶段（overwhelmed→groove→frustrated→magic） | B p269 |
| **发现 ≠ 结果** | 结果是可数的；发现必须**可被反驳** | p307–p308 |
| **一级标题** | 用**研究问题**分组（可自检是否答全） | p308 |
| **排序** | 至少按「影响」与「频次」各排一次 | p309 |
| **严重度** | 见下「严重度」 | p300–p301；B p284–p287/p323 |
| **全局/局部先判** | 三个高发全局类型：信息架构/导航、一致性/术语、反馈 | B p284–p286 |
| **报告五节** | 摘要（**1 页**，研究问题→答案两列）／Method（可粘贴计划+**写明偏离**）／Results（不放原始数据，注明保管人）／发现与建议／后续研究 | p311–p315 |
| **篇幅** | 正式报告 **20–25 页**；验证/总结性可套 **ISO 25062 CIF** | p311 |
| **必写正面发现** | 否则负面发现触发防御、建议不被采纳 | p315 |
| **建议两段** | 短期（不滑期）／长期（真正需要）；初稿不管政治（"reality bats last"），但**拍板权归主持人** | p315–p318 |
| **复测三验** | ①老问题修好 ②**没引入新问题** ③修复有效 | p73、p321–p322 |
| **复测节奏** | **每 2–6 周**一轮 | p319 |

## 否决项（出现任一条，先停下来修）

| # | 否决项 | 为什么 |
|---|---|---|
| **D1** | 报告里只给一个成功率 | 隐藏"靠帮忙才过"与"过了但超时" |
| **D2** | 严重度只写数字不写口径 | Rubin 4 最重 / Barnum 1 最重，**方向相反**，会读反 |
| **D3** | 严重度表没有"受影响人数" | 读者无法判断该不该修 |
| **D4** | 任务文本里出现界面字面（按钮名/菜单名） | 直接泄题，测的是"照着找"不是"会不会" |
| **D5** | 用"5 个就够"当停止理由 | 两书都只给覆盖率，**未给停止判据** |
| **D6** | 让被试边出声边给任务计时 | 出声会拉长时长且**减少错误** |
| **D7** | 帮忙后仍把该任务算作"独立完成" | 数据失真；必须分列 |
| **D8** | 自测且无补偿措施 | 自测几乎不可能客观（"像让父母评价自己的孩子"） |
| **D9** | 报告里出现被试姓名 | 应只用 P1/U1 代号 |
| **D10** | 录像用途超出同意书范围 | 伦理 + 合规；同意书须写明用途 |
| **D11** | 被试全是"明星"（3–4 个） | 结果系统性偏好，团队还愿意相信 |
| **D12** | 样本里 0 个 LCU | 失去上界验证与"心智模型最干净"的视角 |
| **D13** | 现场才告知要录像/被观察 | 同意无效；必须电话阶段就说明 |
| **D14** | 报酬与表现挂钩（含玩笑） | 被试本来就在担心这件事，提一句就坐实 |
| **D15** | 没跑试点 | 前 1–2 个真被试会变成试点，成本以样本形式还回去 |
| **D16** | 测试期改产品代码且无 QA 窗口 | 原文实例：产品 5 分钟崩溃一次，测试取消 |
| **D17** | 只在测完才汇总 | 只存在于记忆里的细节永久丢失 |
| **D18** | 复测只看"老问题修好没" | 漏掉"有没有引入新问题"——迭代的常见副作用 |

## 出声思维三变体（速选）

| | 同步出声 | 回溯复盘 | 协同发现 |
|---|---|---|---|
| 人数 | 1 | 1 | 2 |
| 适用 | 探索期、要"为什么" | **边说边做困难者**（幼儿/高龄/认知障碍） | 真实场景本就两人共用 |
| 代价 | **减少错误** → 不能测真实错误率 | 耗时翻倍 + 事后合理化 | 制造不存在的双人情境 |
| 不能用于 | 计时任务、极短任务 | 长会话 | 单人使用的产品 |

## 四种分类维度（速选）

| 维度 | 选 A | 选 B |
|---|---|---|
| **形成性 / 总结性** | 要改设计 → formative | 要验达标 → summative |
| **实验室 / 现场** | 要控制与围观 → 实验室 | 要真实环境 → 现场（"follow me home"） |
| **有主持 / 无主持** | 要"为什么" → 有主持 | 要"多少人" → 无主持（量大但问不了原因） |
| **探索 / 评估 / 验证 / 比较** | 概念未定 → 探索 | 设计已定 → 评估；临发布 → 验证；选方案 → 比较 |

> **无主持/自动化的两个硬伤**：① 不能追问 → 得不出"为什么" ② **没有情绪信息** → 难以判断严重度（p349）。

## 严重度（两书方向相反，务必标口径）

**Rubin（4 = 最重）**
| 分 | 级别 | 一句话 |
|---|---|---|
| 4 | Unusable | 不能**或不愿**用 |
| 3 | Severe | 会用但严重受限、极难绕过 |
| 2 | Moderate | 能用，需中等努力绕过 |
| 1 | Irritant | 偶发／易绕过／装饰性 |

**频率**：≥90%=4｜51–89%=3｜11–50%=2｜≤10%=1
**关键度 = 严重度 + 频率**（2–8）。**8 分唯一组合 = 4+4（所有人用不了）**。
> 反直觉：**"对所有人致命"(4+1=5) 与 "对所有人小烦"(1+4=5) 同分**——看总损害，不看严重度。

**Barnum（1 = 最重）**
- 3 点：Catastrophe / Serious / Cosmetic
- 4 点：catastrophe / major / minor / cosmetic
- 实操 4 级：L1 阻断完成｜L2 挫败+显著延迟｜L3 轻微｜L4 无影响但有偏好/建议
- **Catastrophe 含"需要协助"**（业务目标是自助时）
- 三维度：频率 / 影响 / **持久性**（能学会就不再犯——Rubin 无此维）

**统一写法**：`严重（Rubin 4 分 / Barnum Level 2）`——正文写文字级别 + 括注书与分值。
