## 二、WCAG 2.0 四级口径（A / AA / AAA / 指南级）

> **依据**：本书**附录 B 的快速参考表**（p254–p256，「B.10 总结：按顺序排列的WCAG 要求」）。
> **这是本书唯一成体系的级别清单，共 61 条**（A 25 条 / AA 13 条 / AAA 23 条）+ **8 条指南级**。

### 2.1 四级的定义（本书 p245 原文）

> **原文（p245）**：
> 「你的项目可能会选择在某个层面(A级、AA级和AAA级)去符合WCAG2.0的要求，
> **A的数量越多即意味着级别越高，对于可访问性的要求也越高。**」

| 级别 | 本书含义 | 本技能的用法 |
|---|---|---|
| **指南级**（原文作"指南级"，如 p248「2.1 键盘可访问性…（指南级）」、p249「2.2 足够的时间」） | **原则层的准则**，下面再分 A/AA/AAA 具体条目 | 用于**定位**（找条目），不用于验收 |
| **A** | **最低门槛**（原文：「A级」） | **能不能完成** |
| **AA** | 中等（原文：「AA级」） | **完成得顺不顺** |
| **AAA** | 最高（原文：「AAA级」） | **完成得放不放心** |

> **★ 本技能的分级心智模型（跨 ch05/ch07/ch08/ch09 四章验证得出）**：
> **A 管"能不能完成"，AA 管"顺不顺"，AAA 管"放不放心"。**
> **且规律：越底层/结构化的要求越落在 A 级；越内容质量/增强的要求越落在 AAA 级。**

> **★ 用法一（验收）**：先定目标级别（A / AA / AAA），再按级别筛条目。
> **级别越高覆盖越全，但成本也越高；A 级是"不可省"的底线。**
>

## 四、易混淆词组（**成对辨析**）

| 对 | 区别 | 出处 |
|---|---|---|
| **普适设计（universal design）** vs **普适可用性（universal usability）** | 前者 **Ron Mace / 1996 / 建筑与产品设计 / 七原则**；后者 **Ben Shneiderman / 2000 / 人机交互 / 多层式界面** | p34 vs p212–p213 |
| **普适设计** vs **包容性设计** | **本书把两者视为同一目标**（p31）；⚠ `inclusive-accessibility-design` 把那四词**分开辨析** | p31 |
| **可访问性（accessibility）** vs **可用性（usability）** | 本书认为两者"类似"且"密不可分"（p30、p225），**未给严格分界**；Cliff Tyllick 的括注承认"如果产品对用户没有可用性，那么产品也不会具有可访问性（也许不是完全正确，但是基本就是这样）" | p30、p234 |
| **字幕（caption）** vs **对白字幕（subtitle）** vs **描述（description）** | **字幕**=同语言文字（含非对白音）；**对白字幕**=翻成其他语言；**描述**=补视觉信息（给看不见的人） | p185 表 9-2 |
| **开放式字幕** vs **隐藏式字幕** | 前者强制显示；后者可开关 | p185 |
| **替代文字（alt）** vs **等价性文本（equivalent text）** | 本书基本混用；"等价性"更强调信息量等价 | p181、p224 |
| **用户角色（persona）** vs **人物快照** | 角色是"虚拟人物"；快照是该角色的**四层档案卡**（本书自造排版用语） | p40、p46 等 |
| **导航** vs **定位** | **导航**=怎么走（操作路径）；**定位**=我在哪（当前位置）。**缺一不可** | p116–p117 |
| **A 级 / AA 级 / AAA 级** vs **指南级** | 前三级是**可验收的具体条目**；"指南级"是**原则层准则**（如 2.1 键盘可访问性、2.2 足够的时间） | p245、附录 B |
| **过程标准** vs **结果标准** | **BS 8878** = 过程（流程中是否纳入）；**WCAG 2.0** = 结果（成品是否达标）。⚠ 与"以产品为基础 vs 以特点为基础"（p91）**是另一个维度**，不要混 | p223 vs p91 |
| **坡道口（p77）** vs **坡道口（p239）** | 同一比喻，**两种用途**：p77 讲"结构质量"；p239 讲"主流红利" | p77、p239 |
| **"以产品为基础"** vs **"以特点为基础"** | 标准按"某类产品"写 → 换品类失效；按"某种特性"写 → 跨平台跨品类通用 | p91（Mike Paciello） |
