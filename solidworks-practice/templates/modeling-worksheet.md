## 二、分析模型（原书要求的两步）

### 步骤 1：模型摆放

| 问题 | 答案 |
|---|---|
| 这个零件的主视图应表现哪一面？（最佳轮廓面） | |
| 因此**第一个草图应画在哪个基准面**？ | 前视 / 上视 / 右视 / 自建基准面 |
| 装配时它的哪个面是配合基准？ | |
| 出图时需要哪些视图（主/俯/左/剖/局部）？ | |

### 步骤 2：最佳轮廓选择

| 问题 | 答案 |
|---|---|
| 用哪个轮廓做主草图能让特征最少？ | |

| 该轮廓是否需要后续改型（尺寸驱动）？ | |
| 是否需要拔模 / 拔模方向是什么？ | |
