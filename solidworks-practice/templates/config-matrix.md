# 配置矩阵模板（Configuration Matrix）

> 用途：一个模型要做多规格时，先把矩阵填出来，再决定用手动配置还是系列零件设计表（第 8 章）。

## 一、先判断用哪种做法

| 条件 | 选手动配置 | 选系列零件设计表 |
|---|---|---|
| 配置数 ≤ 3 | ✔ | |
| 配置数 ≥ 4 | | ✔ |
| 受控尺寸 ≤ 4 | ✔ | |
| 受控尺寸 ≥ 5 | | ✔ |
| 本机没装 Excel | ✔ | ✘ |
| 需要给别人批量维护 | | ✔ |

## 二、前置动作（两种都需要）

```
□ 【视图】>【尺寸名称】显示尺寸名（格式 Dx@草图n）
□ 开 Instant3D
□ 设计树右击【注解】→【显示特征尺寸】
```

## 三、配置矩阵

| 配置名 | 尺寸①<br>`D_@草图_` | 尺寸②<br>`D_@草图_` | 尺寸③<br>`D_@特征_` | 尺寸④ | 尺寸⑤ | 材料 | 备注 |
|---|---|---|---|---|---|---|---|
| A（默认） | | | | | | | |
| B | | | | | | | |
| C | | | | | | | |
| D | | | | | | | |

**填写规则**：
- 配置名尽量用 A/B/C/D 或规格代号，便于识别
- 每个尺寸列都要写出**它属于哪个草图/特征**（`D1@草图1` 这种）
- 未受控的尺寸不列（所有配置共用同一值）

## 四、手动配置步骤（对应 8.2.1）

```
1. ConfigurationManager → 右击默认配置 →【属性】→ 改名 A
2. 右击某个尺寸 →【配置尺寸】→ 在"修改配置"对话框双击"生成新配置"输 B → 回车
3. 重复输入 C、D
4. 双击其余受控尺寸，逐个加入对话框
5. 按矩阵填每个配置的数值
6. 【输入名称】填表格名（如"规格"）→【保存】→【确定】
7. CommandManager【配置】按钮预览 → 双击切换验证
```

## 五、系列零件设计表步骤（对应 8.2.2）

```
1.【插入】>【表格】>【设计表】→ 默认设置
2. 弹【尺寸】对话框 → 按住 Ctrl 多选受控尺寸 → 确定
3. 点空白处退出表格编辑
4. 右击【系列零件设计表】→【在单独窗口中编辑表格】→ 确定
5. 右击 Excel 左上角单元格 →【设置单元格格式】→【常规】  ← 关键！
6. 填配置行与数值
7. 若发现漏尺寸：选中空白单元格 → 在图形区双击该尺寸，自动补入
8. 保存关闭 → 提示"已添加配置"
9. ConfigurationManager 双击各配置验证
```

## 六、验证清单

- [ ] 每个配置双击后模型确实变化
- [ ] 每个配置的质量属性符合预期（差异来自受控尺寸）
- [ ] 表格名在 ConfigurationManager 中可见
- [ ] 装配体中的该零件配置切换后位置/配合未失效
- [ ] 若用于工程图：交替位置视图/爆炸视图引用的配置仍然有效

## 七、常见坑对照

| 坑 | 原因 | 处理 |
|---|---|---|
| 表里尺寸变成文字 | Excel 单元格格式是"文本" | 左上角单元格改【常规】 |
| 某尺寸没进表 | 建表时漏选 | 选中空白单元格 → 图形区双击该尺寸 |
| 改了数值模型不变 | 配置未激活 | 双击配置名 |
| 装配体配置没简化 | 没压缩零部件 | 装配体配置靠压缩实现简化 |
| 尺寸名找不到 | 未显示特征尺寸 | 设计树【注解】→【显示特征尺寸】 |
