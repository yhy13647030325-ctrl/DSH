# 出图自检清单（Drawing Checklist）

> 用途：工程图保存前逐项过一遍。对应第 6 章。

## 一、开始之前

- [ ] 模型的**第一个草图基准面**选对了（决定主视图方向）
- [ ] 零件已指定材料
- [ ] 零件自定义属性已填（零件号、设计、材质等）——明细表会读这些
- [ ] 装配体已建好所需配置（如"关闭/打开"用于交替位置视图）
- [ ] 装配体已建好爆炸视图（若工程图要出爆炸图）

## 二、模板与图纸

- [ ] 选对模板（国标 A3 = `gb_a3`；零件/装配体模板图标不同）
- [ ] 图纸属性：图纸名称 / 全局比例 / 投影类型（第一角 or 第三角）
- [ ] 图纸格式：图框、标题栏齐全
- [ ] 需要多张图纸时已规划（如 Sheet1 视图 + BOM 页）

## 三、视图

- [ ] 主视图是**最佳轮廓面**（能表现产品主要外形）
- [ ] 标准三视图齐全（主/俯/左），或按需用模型视图单独放
- [ ] 内部结构已用**剖视图 / 断开的剖视图**表达
- [ ] 局部细节已用**局部视图**放大
- [ ] 过长件已用**断裂视图**
- [ ] 斜面上的特征已用**辅助视图**
- [ ] 视图比例合适（默认可能太小需改 1:1 或其他）
- [ ] 视图对齐关系正确（投影子视图继承父视图样式与比例）

**视图禁忌核对**：
- [ ] 没有在局部/剖面/交替位置视图上建断开的剖视图
- [ ] 剪裁视图的定义区域是封闭草图
- [ ] 若在爆炸视图上做了断开的剖视图 → 已确认该爆炸视图不再需要解除爆炸

## 四、尺寸

- [ ] 已用【模型项目】导入模型尺寸（【整个模型】+【将项目输入到所有视图】）
- [ ] 尺寸已【对齐】>【自动排列】，少数手工微调
- [ ] 冗余尺寸已删（如统一圆角 R2 可只在技术要求说明）
- [ ] 倒角等不符合标准的显示已删并用手工【智能尺寸】重标（注意：**手标是参考尺寸，不驱动模型**）
- [ ] 关键配合尺寸已加**公差**（如 φ15 +0.03/-0.00）
- [ ] 螺纹孔已用正确写法（如 `5×M8-6H⤳S`），引线用直径标注
- [ ] 对称、中心距等按**设计意图**标注（不是随手标）

## 五、注解

- [ ] 中心线 / 中心符号线齐全
- [ ] 表面粗糙度符号齐全（含"其余"整体要求）
- [ ] 基准特征符号齐全
- [ ] 形位公差（几何公差）齐全
- [ ] 技术要求文本（例：无铸造缺陷 / 去锐边去毛刺 / 未注圆角 R2 / 未注公差）
- [ ] 焊接符号（若适用）

## 六、装配体工程图专有项

- [ ] 【系统选项】>【工程图】勾了【生成视图时自动隐藏零部件】
- [ ] 断开的剖视图已用【不包括零部件/筋特征】排除标准件（螺栓、丝杠等不该被剖）
- [ ] 交替位置视图已设【自由拖动】+【物理动力学】+ 明确检查范围
- [ ] 爆炸视图已勾【在爆炸状态中显示】
- [ ] 零件序号已添加（【自动零件序号】后手工排）
- [ ] 材料明细表已插入，列属性已按需改为自定义属性（如"材质"）
- [ ] 明细表项目数与实际零部件数一致（含虚拟零部件）

## 七、保存与交付

- [ ] 已保存 `*.slddrw`
- [ ] 需要给别人看时考虑另存 eDrawings（`*.edrw`）
- [ ] 若要对方测量：eDrawings 保存时勾【确定可测量此 eDrawings 文件】
- [ ] 打印预览已检查图幅内不溢出

## 八、常见退回原因（提前避开）

| 退回意见 | 根因 |
|---|---|
| "主视图不是最佳轮廓" | 建模第一个草图基准面选错 |
| "剖视里螺栓被剖了" | 未用【不包括零部件/筋特征】 |
| "尺寸与模型不一致" | 有人手改了图纸参考尺寸 |
| "改模型后图纸没更新" | 尺寸是手标参考尺寸，不是模型项目导入 |
| "缺材质列" | 明细表列属性未改为自定义属性"材质" |
| "圆角标注太乱" | 未把统一圆角写进技术要求 |
