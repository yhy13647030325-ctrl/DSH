## 四、拉伸终止条件（六种 + 两开始条件）

| 终止条件 | 用于 |
|---|---|
| 给定深度 | 最常用 |
| 两侧对称 | 以草图面居中 |
| 成形到下一面 | 切到最近实体面 |
| 成形到一顶点 | 切到指定顶点 |
| 完全贯穿 | 穿透全部 |
| 到离指定面指定的距离 | 从某面偏移一段后停止 |

| 开始条件 | 用于 |
|---|---|
| 等距 | 从离草图面一段距离开始（做悬空结构） |

## 五、拉伸的三种变体

| 变体 | 关键设置 |
|---|---|
| 拉伸-拔模 | 【拔模角度】，可配合【所选轮廓】一次拉多个封闭轮廓 |
| 拉伸-薄壁 | 薄壁特征：单向 / 两侧对称 + 厚度（开口壳件首选） |
| 拉伸-指定方向 | 【拉伸方向】由模型边线或辅助草图直线驱动（做斜面过渡） |

## 六、阵列七型

| 类型 | 参考输入 |
|---|---|
| 线性 | 方向1/方向2 的边线 + 间距 + 实例数（含源） |
| 圆周 | 阵列轴 + 角度 + 实例数 + 【等间距】 |
| 镜像 | 镜像基准面 + 要镜像的实体/特征/面 |
| 表格驱动 | 坐标系 + 表格 |
| 草图驱动 | 参考草图（点）+ 参考点（可选**重心**） |
| 曲线驱动 | 曲线路径（可投影曲线） |
| 填充 | 同一面的实例/特征 |

三个通用开关：**【只阵列源】**（勾了只复制原始，不传播）、**【可跳过的实例】**（点中心粉红点挖掉）、**【几何体阵列】**（快，但失去特征参数关联）。

## 七、剪裁五法

| 方式 | 一句话 |
|---|---|
| 强劲剪裁 | 划过即删，且能延伸（最常用） |
| 边角 | 两实体延伸/剪裁到边角相交 |
| 在内剪除 | 剪边界内都相交或全不相交的实体 |
| 在外剪除 | 剪边界外打开的实体，同时延伸边界内打开的 |
| 剪裁到最近端 | 单击即删至最近交点；点端点可延伸（最常用） |

## 八、配合类型与自由度

| 配合 | 吃掉 |
|---|---|
| 重合（面-面） | 1 平移 |
| 重合（基准面-基准面） | 1 平移 + 1 旋转 |
| 同轴心 | 2 平移 + 2 旋转 |
| 平行 | 1 旋转 |
| 垂直 | 1 旋转 |
| 相切 | 1 平移 |
| 距离 / 角度 | 1 自由度（可驱动限位） |
| **宽度** | 2 平移 + 1 旋转（对称居中） |

**铁律**：刚体 6 自由度（3 平移 + 3 旋转）；第一个零件固定；子装配体默认刚性，需动改【柔性】。

## 九、派生视图 9 类

投影 / 辅助 / 局部 / 剪裁 / 断开的剖视（局部剖）/ 断裂 / 剖面 / 旋转剖 / 交替位置。

**禁忌速记**：
- 断开的剖视图 **不能**建于 局部/剖面/交替位置视图 上
- 在爆炸视图上建断开的剖视图 → 该爆炸视图**不可解除爆炸**
- 剪裁视图 / 断开的剖视图 → 定义区域**必须封闭草图**
- 剪裁视图 不能裁 局部视图

## 十、尺寸的两类身份

| 【模型项目】导入 | **驱动尺寸** | 改模型 |

## 十一、渲染层级优先级

拖外观时的应用范围：**面 > 特征 > 实体 > 零件 > 部件**（面/曲面优先级最高）。

- 装配体里**只能给零部件贴图**；给"面"贴图必须进零件编辑状态
- 点光源要【在 PhotoView 中打开】才参与最终渲染
- 最终渲染历史保留 **0~9 共 10 个**结果

## 十四、分析关键数值

| 项 | 值 / 判据 |
|---|---|
| 静态假设 | 载荷缓慢加载至全值后**保持不变**，忽略惯性与阻尼 |
| 线性假设 | 载荷-反应线性 / 虎克定律 / 小位移 / 边界不变 |
| 网格收敛判据 | 加密一档后应力变化 **< 5%** 即停 |
| 圆角处网格尺寸 | ≈ **圆角半径的一半** |
| 变形显示比例 | 最大变形缩放到**模型边界框对角的 10%**（视觉放大，非真实值） |
| 安全系数图解标尺 | 【安全系数以下的区域】默认输入 **1** |
| 优化算例 | 一个算例只能**一个目标**；变量数相乘 = 状况数 |
| 报表输出 | 自动生成 Microsoft **Word** 文档 |
| 探测结果导出 | **CSV**（Excel 可开） |
