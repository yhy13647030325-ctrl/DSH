# 可复用套路（Patterns）

> 标 **（提炼）** 的是从书中多个实例归纳出的通用做法，不是原书原句；其余均直接对应书中步骤。

## 模式一：零件建模七步法（原书每道例题的标准骨架）

**何时用**：任何零件建模任务的起点。

**怎么走**：
1. **分析模型** —— ① 模型摆放（决定后二维视图方向）② 最佳轮廓选择（决定效率与后续改型难度）
2. 新建零件（模板 `gb_part`）
3. 环境设置（MMGS + 小数位 2，**在画草图之前**设）
4. 绘制草图并**完全定义**（轮廓 → 几何关系 → 尺寸）
5. 创建特征
6. 编辑材料
7. 保存并关闭（按给定名称）

**陷阱**：跳过第 1 步直接开画，结果草图基准面选错，出图时主视图不是最佳轮廓，只能返工；跳过第 3 步，后面所有尺寸都要重标。

## 模式二：草图三段法（原书判据）

**何时用**：每画一个草图。

**怎么走**：
1. **先画近似轮廓** —— 尺寸驱动软件，不必画准，只需拓扑正确
2. **再加几何关系** —— 水平/竖直/相切/相等/对称/重合，决定"什么跟着什么变"
3. **最后标尺寸** —— 决定性尺寸，尽量少（多余即过定义）

**通过判据**：所有线条变**黑**（完全定义）。
**陷阱**：绘制时捕捉了过多自动几何关系 → 后续定义时过定义（原书示例 3 明确点名）。

## 模式三：装配约束链（自底向上）

**何时用**：把已有零件拼成装配体。

**怎么走**（以"三配合定一个零件"为例）：
1. 插入第一个零件并**直接确认**（让零件原点与装配原点重合，此后固定）
2. 插入后续零件，先拖到大致位置
3. 加 **【重合】**（贴合面）
4. 加 **【同轴心】**（孔与轴）
5. 加 **【重合】**（基准面，限制转角）
→ 6 自由度收完

**变体**：
- 铰接结构：三个【同轴心】即可留 1 个旋转自由度（原书装载机的动臂/摇臂/油缸）
- 对称居中：【宽度】配合（两组对称面）
- 大装配简化：子装配体默认刚性，需要动改【柔性】

**判据**：设计树右侧显示的自由度符号消失到预期数量。
**陷阱**：不先摆位置就加配合，会遇到"零件飞出去"；配合顺序错了会得到反向姿态，需删掉重加。

## 模式四：出图流水线（两种入口）

**何时用**：从模型生成工程图。

**A. 模型视图法**（零件，精度高）
```
选模板(gb_a3) → 模型视图(选方向+比例) → 投影视图 → 剖面视图替换
→ 中心线 → 模型项目导入尺寸 → 自动排列 + 手调
→ 删冗余尺寸(如R2) → 手标参考尺寸(倒角) → 加公差/粗糙度/基准
→ 技术要求文本 → 保存
```

**B. 视图调色板法**（装配体，快）
```
系统选项勾"生成视图时自动隐藏零部件" → 从装配体制作工程图
→ 视图调色板拖主视 → 投影视图
→ 断开的剖视图(排除标准件) → 交替位置视图(物理动力学)
→ 爆炸状态视图 → 自动零件序号 → 材料明细表 → 改列属性 → 保存
```

**关键区分**：`模型项目`导出的是**驱动尺寸**（改它改模型）；`智能尺寸`手标的是**参考尺寸**（不改模型）。

## 模式五：渲染六步

**何时用**：要出产品效果图。

**怎么走**：
1. 开 PhotoView360 插件
2. **先清掉默认外观**（右击 →【移除外观】）
3. 拖外观（注意关联工具栏的层级：面/特征/实体/零件/部件；**面级优先于零件级**）
4. 加贴图（装配体只能贴零部件；贴"面"必须进零件编辑状态 + 【映射】里勾套合）
5. 选布景 + 补光源（点光源需【在 PhotoView 中打开】）
6. **用独立【预览窗口】**调，满意后【最终渲染】→ 保存图像

**陷阱**：用"整合渲染"在图形区预览，很卡；最终渲染前忘清默认白色外观，白做一遍。

## 模式六：配置矩阵（参数化的两种写法）

**何时用**：一个模型要多个规格。

**写法 A：手动配置（配置尺寸）**
```
显示尺寸名称/特征尺寸 → 右击某尺寸【配置尺寸】→ 输新配置名
→ 逐个尺寸加进对话框 → 填各配置值 → 保存表格并命名
```

**写法 B：系列零件设计表（Excel）**
```
【插入】>【表格】>【设计表】→ Ctrl 多选尺寸 → 确定
→ 在单独窗口编辑 → 左上角单元格【设置单元格格式】=常规
→ 填配置行 → 保存关闭
```

**判据**：`ConfigurationManager` 里双击配置名，模型应即时变化。
**陷阱**：Excel 单元格格式是文本 → 整表当成文字，全部失效；漏了尺寸 → 选中空白单元格后在图形区双击该尺寸补入。

## 模式七：分析闭环（静力 + 优化）

**何时用**：要验证强度或减重。

**怎么走**：
1. 确认假设（静态：载荷缓慢加载后不变；线性：虎克定律 + 小位移 + 边界不变）
2. 新算例（静态）
3. 材料（与设计树材料是两套，需统一时两边都改）
4. 夹具（约束足够，防刚体位移）
5. 载荷（压力/力，注意方向与单位）
6. 网格（**圆角处网格 ≈ 圆角半径一半**）
7. 运行 → 看应力/位移/应变/安全系数
8. **收敛判据：加密一档后应力变化 < 5% 即停**
9. 按结果改模型（加大圆角、改壁厚）→ 重算
10. 【设计洞察图解】找可简化区域 → 切除 → 重算
11. 需要自动寻优时：设计算例（变量 + 约束 + 单一目标）→ 勾【优化】运行

**陷阱**：拿放大后的变形比例当真实位移；只看颜色不看数值；变量选了不敏感尺寸（原书实例的结论就是"筋厚度影响不如圆角显著"）。

## 模式八：焊件分组（3D 草图 + 结构构件）

**何时用**：管路、框架、桁架类结构。

**怎么走**：
1. 3D 草图，**按 Tab 切基准面**逐段画线（沿 X/Y/Z）
2. 全部尺寸标完，末点与原点重合 → 完全定义
3. 直角处加过渡圆角（管路）
4. 【结构构件】→ 选标准/类型/大小
5. **按"平行线一组、圆弧单独成组"分组**
6. 补端部封板（草图 + 拉伸）
7. 隐藏 3D 草图

**判据**：接头处型材自然对接，无穿模、无错位。
**陷阱**：直线与圆弧混在一组 → 接头按直线逻辑处理，圆弧处错乱。

## 反模式清单

| 反模式 | 表现 | 后果 |
|---|---|---|
| **跳过分析模型** | 拿起来就画 | 基准面错、主视图错、后期改不动 |
| **画准再标尺寸** | 手工调形状到"看起来对" | 尺寸驱动失效，改一个尺寸全乱 |
| **草图留蓝** | 欠定义就去做特征 | 后续特征飘移，装配对不上 |
| **草图变黄硬撑** | 过定义不处理 | 草图驱动模型失效 |
| **重复造标准件** | 手画螺栓螺母 | 浪费工时且规格不符 |
| **装配不先定位** | 直接加配合 | 零件飞出、姿态反向 |
| **工程图手标所有尺寸** | 不用模型项目 | 与模型脱钩，改模型图不变 |
| **改外观在三文档层** | 装配体里改文档层外观 | 无效（第 7、10 章都点名） |
| **网格一刀切** | 全程默认网格看圆角应力 | 应力严重偏小 |
| **无限加密网格** | 一直加密求"更准" | 时间爆炸，且 5% 判据早已满足 |
| **优化加不敏感变量** | 变量列表塞一堆 | 算得慢还得不到改善 |
