# 术语表（Glossary）

> 按拼音排序。括号内为出处章节。

## B

- **拔模分析** — 检查拔模应用到零件上的情况：核实拔模角度、检查面内角度变化、找出分型面/浇注面/出坯面（ch03）
- **板厚/薄壁特征** — 拉伸时直接生成开口壳体，可选单向或两侧对称 + 厚度（ch03）
- **包容（包覆）** — 把草图文字或轮廓贴合到面上，用于 Logo/文字（ch08）
- **爆炸直线草图** — 用 3D 草图的【步路线】连接各零件，显示爆炸装配的对应关系（ch04）
- **爆炸视图** — 沿移动操作杆手柄/三重轴移开零部件，每次方向 + 距离存为一个步骤（ch04）
- **闭合组** — 扫描时把多个封闭轮廓选成一组作为轮廓（ch03）
- **步路线** — 爆炸直线草图的命令，在【要连接的项目】中选顶点/边线/面（ch04）
- **布局设计** — 装配体四种设计方案之一，原书未展开（ch04）

## C

- **材料明细表（BOM）** — 装配体工程图中的表格，可换列类型为自定义属性（如"材质"）（ch06）
- **参考几何体** — 基准面、基准轴等辅助几何（ch03）
- **草图图片** — 把图片插入草图作描摹参照，设高度后按草图直线定位（ch03）
- **草图驱动阵列** — 按参考草图的点阵列表实例，可选参考点为"重心"（ch03）
- **插入横断面** — eDrawings 中按参考面/实体面剖切模型查看（ch11）
- **尺寸驱动** — SOLIDWORKS 是尺寸驱动软件，几何大小由尺寸控制，故画草图只需近似形状（ch02）
- **从动尺寸** — 不驱动模型的尺寸（工程图手标 / 过定义时把多余尺寸指定为从动）（ch02、ch06）
- **重设** — 系统选项中恢复出厂设置；网格属性中恢复默认密度（ch01、ch12）

## D

- **大图标** — eDrawings【视图】>【工具栏】中开启，方便查看工具条（ch11）
- **动态干涉检查** — 拖动零部件过程中做碰撞检测（ch04）
- **动态镜像** — 先选镜像点再绘制，画一侧自动生成对称（ch02）
- **断开的剖视图（局部剖）** — 在标准视图上剖切某局部显示内部结构（ch06）
- **断裂视图** — 把过长/过宽的视图按比例截断显示在小图纸上（ch06）
- **等距实体** — 沿法向偏移草图实体，含 6 个选项（ch02）
- **顶层层叠 / 底层层叠** — 智能扣件自动加垫圈/螺母（ch05）

## F

- **放样** — 多个轮廓之间过渡成形，靠"接头"对齐（ch03）
- **非刚性（柔性）** — 子装配体可动状态的属性（ch04）
- **辅助视图** — 垂直于现有视图中参考边线的展开视图（ch06）
- **附加特征（应用特征）** — 直接建在实体上的特征，如圆角、倒角（ch03）

## G

- **干涉检查** — 静态：算当前位置是否重叠；动态：拖动过程中是否碰撞（ch04）
- **刚度变化** — 线性假设要求可忽略（小位移）（ch12）
- **关键帧 / 键码** — 动画中记录状态的时间点；马达起止靠键码控制（ch10）
- **关联工具栏** — 选中对象时自动弹出的快捷工具栏（ch01）
- **光滑曲线套合（套合样条曲线）** — 把多段 3D 草图线拟合成一条光顺样条，供扫描作路径（ch09）
- **规范（图纸格式）** — 图框 + 标题栏 + 必要文字（ch06）
- **滚轮缩放 / 中键旋转** — 见"鼠标三键"（ch01）

## H

- **宏（未展开）** — 原书未涉及
- **虎克定律** — 线性假设的核心，应力与应变成正比（ch12）
- **环境封闭** — 球形光源方法，通过控制封闭区域的环境光衰减使模型更逼真（ch07）
- **焊缝 / 焊接符号** — 工程图注解（ch06）；焊件见 ch09

## J

- **基准面 / 基准轴** — 见 ch03 两张创建方法表
- **几何公差（形位公差）** — 工程图注解；书中说明"为与软件一致，形位公差指几何公差"（前言、ch06）
- **基本运动** — 动画三类算例之一，考虑质量，可模拟马达/弹簧/接触/引力（ch10）
- **假想/虚拟零部件** — 保存在装配体内部的零部件（ch04、ch05）
- **剪裁视图** — 隐藏定义区域外内容，聚焦某部分（ch06）
- **接触** — 基本运动中定义零件间碰撞关系；筛选球体实例得到 105 组（ch10）
- **结构构件** — 焊件命令，按标准/类型/大小生成型材，按"组"组织（ch09）
- **截面/剖面视图** — 用剖切线分割父视图生成单独视图（ch06）
- **旧版兼容（版本选择）** — 3DContentCentral 下载时须选与本地软件兼容的版本（ch05）
- **绝对坐标（空间控标）** — 3D 草图的方向辅助工具（ch09）

## K

- **可跳过的实例** — 阵列中挖掉个别实例（ch03）
- **空间控标** — 3D 草图中帮助保持方向的图形辅助工具（ch09）
- **快速栏（S 工具栏）** — 按 S 键按环境弹出常用命令（ch01）
- **扩展名** — `.sldprt/.sldasm/.slddrw`；模板 `.prtdot/.asmdot/.drwdot`（ch01）

## L

- **拉伸（凸台/基体）** — 草图沿方向成形；六种终止条件 + 拔模/薄壁/方向三种变体（ch03）
- **临时轴** — 前导视图工具栏【隐藏/显示项目】>【观阅临时轴】显示，可作阵列轴（ch03）
- **零件、装配体、工程图** — 三种文档类型（ch01）
- **逻辑（物理动力学）** — 交替位置视图中让零件相撞自动停止（ch06）
- **录制（走查）** — 走查过程可录成视频（ch10）

## M

- **马达** — 线性/旋转驱动器；运动可设距离、等速等（ch10）
- **毛坯（型材大小）** — 结构构件的"大小"参数，如 1.5sch40、30×30×2.6（ch09）
- **模板** — 含图纸格式 + 全局设定（ch06）
- **命名（模型命名）** — 例题一律按给定名称保存（ch03 等）
- **模拟算例（算例）** — 分析任务的容器（ch12）

## N

- **内切圆直径** — 多边形定位尺寸的标法（ch08 五边形 15mm）
- **逆选择（逆转选择）** — 按住 Ctrl 多选后右击，选中之外的全部（ch04）
- **拟合成形（放样）** — 见"放样"

## P

- **配合** — 零部件表面/边与基准面/其他表面/边的约束关系（ch04）
- **配置（Configuration）** — 单一文件中的多个设计变化（ch08）
- **配置尺寸** — 手动添加配置时把尺寸加入"修改配置"对话框（ch08）

## Q

- **欠定义 / 完全定义 / 过定义** — 草图三态：蓝 / 黑 / 黄（ch02）
- **强劲剪裁** — 划过即删，兼具延伸功能（ch02）
- **曲率（接头）** — 放样中拖动接头调整外形（ch03）
- **驱动尺寸** — 从模型项目导入的、与模型双向关联的尺寸（ch06）

## R

- **热力 / 疲劳 / 非线性 / 线性动态** — Simulation 的分析类型（ch12）
- **柔性** — 子装配体可动（ch04）
- **柔性与刚性图标** — 设计树中可区分（ch04）

## S

- **三重轴** — 爆炸视图中移动零部件的坐标手柄（ch04）
- **扫描** — 轮廓沿路径成形；可加引导线、可沿路径扭转（ch03）
- **设计表 / 系列零件设计表** — 用 Excel 表格驱动多配置（ch08）
- **设计洞察图解** — 分析结果中显示承载区域，透明区可简化（ch12）
- **升水器械** — 不属于本书内容
- **实体文件夹** — 设计树中管理多实体的容器（ch03）
- **收敛判据** — 网格加密后应力变化 < 5%（ch12）
- **属性框（PropertyManager）** — 与设计树同位置的命令界面（ch01）
- **数值链接（链接数值）** — 把尺寸绑定到全局变量（附录）
- **鼠标三键** — 左选、中旋、右菜单（ch01）
- **速率（等速马达）** — 线性马达可设 mm/s（ch10）
- **随路径和第一引导线变化** — 扫描的方向/扭转控制选项（ch03）

## T

- **碳钢 / 延性铁 / 合金钢** — 书中用到的材料（ch03、ch12）
- **特性（特征）** — 模型的组成单元；分草图特征与应用特征（ch03）
- **填充阵列** — 基于同一面的实例/特征阵列（ch03）
- **投影视图** — 基于已有视图八方向投影（ch06）
- **图纸 / 图纸格式 / 图纸属性** — 三个术语（ch06）
- **图表驱动阵列（表格驱动）** — 按坐标系 XY 表格阵列（ch03）

## W

- **完全贯穿** — 拉伸切除终止条件（ch03）
- **网络（网格）** — 有限元划分；可加"网格控制"局部加密（ch12）
- **文档属性** — 仅当前文档的设置，随文件保存（ch01）
- **蜗杆（未展开）** — 原书未涉及
- **物理动力学** — 见"逻辑（物理动力学）"

## X

- **系统选项** — 影响本机所有文档的设置（ch01）
- **系列零件** — 同文件内多种规格（ch08）
- **相切（圆弧与直线相同）** — 认证题常见附加条件（附录）
- **向内/向外剪除** — 见"剪裁五法"（ch02）
- **消除隐藏线** — 动画中零部件显示状态之一（ch10）
- **旋转（凸台/基体）** — 绕轴回转成形（ch03）
- **旋转剖视图** — 剖面线转折的剖视图（ch06）
- **选择其他** — 选到被遮挡的面（ch04）
- **选择管理器（SelectionManager）** — 空白处右击可打开，用于选轮廓/路径/引导线/组（ch03）
- **循环引用（外部参考）** — 自顶向下建模的关联特征，需要时可断开（ch04）

## Y

- **压缩（特征/零部件）** — 让特征暂时不参与重建；认证题换型常用（ch08、附录）
- **压强（压力）** — 分析载荷，单位 N/mm²(MPa)（ch12）
- **颜色设定** — 拔模分析中改面分类显示色（ch03）
- **一致性（1:1 比例）** — 工程图默认比例可能偏小，需手动改（ch06）
- **引线（直径标注）** — 尺寸【引线】选项卡中选直径标注法（ch06）
- **应力（von Mises）/ 位移（合位移）/ 应变（对等）** — 三类结果图解（ch12）
- **用户库** — 3DContentCentral 中 28 万以上注册用户提供的模型（ch05）
- **约束（设计算例）** — 应力/挠度/频率的合理变化范围（ch12）
- **预览窗口** — PhotoView360 的独立渲染预览，省资源（ch07）

## Z

- **载荷（外部载荷）** — 压力/力，注意方向与单位（ch12）
- **增强（筋）** — 加在开敞件上的加强结构，可带拔模（ch03）
- **粘贴工程图** — 自顶向下建模时把工程图复制粘贴到新零件草图作参照（ch04）
- **折叠（压缩）** — 见"压缩"
- **阵列（源与实例）** — 源是被阵列的几何，实例是由源派生的复制品（ch03）
- **支撑（夹具）** — 分析中的边界约束（ch12）
- **直槽口 / 中心点直槽口 / 三点圆弧槽口 / 中心点圆弧槽口** — 四类槽口（ch02）
- **指引线（步路线）** — 见"步路线"
- **质量属性** — 读质量、体积、质心（附录）
- **中心线 / 构造线** — 草图辅助线，可作旋转轴/镜像点（ch02）
- **轴测（等轴测）** — Ctrl+7（ch01）
- **转换实体引用** — 把已有几何投影到当前草图（ch03、ch04）
- **装配体特征** — 在装配环境中创建、可传播到零件的特征（ch05）
- **子装配体** — 插入装配体中的装配体，系统当作一个零部件（ch04）
- **自动键码** — 动画中自动记录关键帧的开关（ch10）
- **自顶向下 / 自底向上** — 装配体两种建模策略（ch04）
- **自由拖动** — 交替位置视图中手动拖到极限（ch06）
- **走查** — 在 3D 场景中漫游并可录制（ch10）
- **最小化（优化目标）** — 质量/体积最小（ch12）
