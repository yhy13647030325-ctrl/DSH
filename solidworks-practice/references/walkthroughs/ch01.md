## S01–S06　启动与退出

| 步 | 操作 | 路径 |
|---|---|---|
| **S01** | 启动 SolidWorks | **【开始】/【所有程序】/【SolidWorks<版本号>】/【SolidWorks<版本号>】**；或双击桌面快捷方式 |
| **S02** | 退出 SolidWorks | **【文件】/【退出】**；或点主界面右上角关闭按钮 |
| **S03** | 打开现有文件（方式一） | **双击**现有的 SolidWorks 文件——**若程序未运行会自动启动再打开** |
| **S04** | 打开现有文件（方式二） | **【文件】/【打开】** → 输入文件名或浏览；**SolidWorks 会列出最近打开过的文件** |
| **S05** | 保存 | 菜单栏**【保存】** 按钮（**Ctrl+S**） |
| **S06** | 复制（另存副本） | **【文件】/【另存为】** → 以**新的文件名**保存为副本 |

**三种文件后缀（原文）**：零件 `*.sldprt`、装配体 `*.sldasm`、工程图 `*.slddrw`。

## S07–S12　新建文件与三种设计模式

| 步 | 操作 | 路径 / 选项 |

| **S07** | 进入新建 | 进入 SolidWorks 后，可通过**【新建】**和**【打开】**两种选择 |

## S13–S18　菜单栏的四种行为（原文逐条）

| 步 | 操作 | 说明（原文） |
|---|---|---|
| **S13** | 展开主菜单 | **SolidWorks 隐藏了主菜单**。**将鼠标移动到左上角**使主菜单展开 |
| **S14** | **固定主菜单** | 单击**最后的图钉按钮** → **保持主菜单显示**，工具栏向右平移 |
| **S15** | 识别子菜单 | 菜单选项带**向右小箭头** → 有子菜单；**鼠标移上去小箭头变白，子菜单展开** |
| **S16** | 识别对话框命令 | 菜单选项后带**三个小点（…）** → 单击会**打开对话框**。例：【工具】/【测量】 |
| **S17** | 自定义菜单 | 选 **【自定义菜单】** → **每个命令前出现复选框** → 勾选/去除可增删命令 |
| **S18** | 定位自定义入口 | 如【插入】菜单下的【自定义菜单】 |

> **★ 这是本章最实用的四条**：**图钉固定**、**小箭头=子菜单**、**…=对话框**、**自定义菜单可增删**。

## 失败模式（F-01）

| 编号 | 现象 | 根因 | 处置（含路径） | 页 |
|---|---|---|---|---|
| F-01-01 | 找不到主菜单 | **主菜单默认隐藏** | **鼠标移到左上角**展开；点**图钉**固定 | p13 |
| F-01-02 | 点了菜单没反应 | 该命令带 **…**，要开对话框 | 点 **…** 项打开对话框（如【工具】/【测量】） | p13 |
| F-01-03 | 想找的命令在菜单里没有 | 被**自定义菜单**移除了 | 选 **【自定义菜单】** → **勾回复选框** | p13 |
| F-01-04 | 工具栏少了常用按钮 | 默认未显示 | **右击工具栏 →【自定义】/【命令】** → 拖拽添加 | p13 |
| F-01-05 | 不知道某个功能叫什么 | 不记得命令名 | 用**搜索工具**：选**【搜索命令】** → 输入关键字（如"圆"） | p13 |
| F-01-06 | 新建时找不到自己的模板 | 只用了标准三模式 | 在【新建】对话框点**左下角【高级】** 选自定义模板 | p12 |
| F-01-07 | 想另存副本却覆盖了原文件 | 用了【保存】 | 用 **【文件】/【另存为】** 并改文件名 | p11 |
