## 核心要点

**eDrawings 是什么**：把 SolidWorks 模型/工程图**打包成可发给别人看的文件**，对方**不需要 SolidWorks**。

**可以保存的格式（原文）**：

| 类别 | 格式 |
|---|---|
| **零件** | `*.eprt`、`*.zip`、`*.htm`、`*.exe`、`*.bmp`、`*.tif`、`*.jpg`、`*.png`、`*.gif` |
| **装配体** | `*.eprt`、`*.zip`、`*.htm`、`*.exe`、`*.bmp`、`*.tif`、`*.jpg`、`*.png`、`*.gif` |
| **工程图** | 同上 |

> **注意**：装配体/工程图也列出 `*.eprt`，**实际常用 `*.easm` / `*.edrw`**（原文保存对话框里写的是 `*.eprt, *.easm, *.edrw`）。

## 11.2.3 如何保存 eDrawings 文件（两条路径）

| 路径 | 操作 |
|---|---|
| **路径一** | **【文件】/【另存为】** → 下拉列表选 **eDrawings（`*.eprt`、`*.easm`、`*.edrw`）** → 保存 |
| **路径二** | 直接单击**【保存】按钮右边的下拉箭头** → 选 **【出版 eDrawings 文件】** → **自动打开 eDrawings 浏览器** → 保存 |

> **★ 多配置必读**：「如果**有多配置的零部件，还要选定要输出的配置**。」

**保存时可设两项**：**【选项】** 和 **【密码】**。

## 11.4 阅览批注 3D 模型（S01–S12）

**素材**：装配体 **"机械手"**（**运动设置和爆炸视图已完成**）

### S01–S03　保存为 eDrawings ★ 两个必勾项

| 步 | 操作 | 路径 / 参数 |
|---|---|---|
| **S01** | 打开文件 | **【文件】/【打开】** → **"机械手"** 装配体 |
| **S02** | 选择保存类型 | **切到【运动算例1】标签**（运动设置和爆炸已完成）→ 单击**【另存为】** → **保存类型下拉选【eDrawings（*.easm）】** |
| **S03** | **设置保存选项** | 单击**【选项】** → 打开**【输出】选项卡** → 见下方 |

**【输出】选项卡（S03）**：

| 选项 | 默认值 | **本书取值** |
|---|---|---|
| **【确定可测量此 eDrawings 文件】** | **不勾** | **勾选** |
| **【将运动算例保存到 eDrawings 文件中】** | **不勾** | **勾选** |

> **★ 这两个勾是全章的关键**：
> - 不勾【确定可测量】→ **对方打不开测量功能**
> - 不勾【将运动算例保存】→ **动画丢了**

### S04–S06　在 eDrawings 里查看

| 步 | 操作 | 按钮 / 路径 |
|---|---|---|
| **S04** | 打开文件 | 打开 **SolidWorks eDrawings** 程序 → 单击**【打开】** → 选刚保存的文件 |
| **S05** | 查看零部件树 | 在**【零部件】** 标签中看装配体层结构 → 单击**【移动零部件】** 可任意拖拽 → 单击**【显示爆炸】** 显示爆炸视图 |
| | 附加 | **右击模型树中的零部件可隐藏或透明显示** |
| **S06** | 动画重新排序 | 单击**【连续播放】** 看动画切换视图；用**【将动画重新排序】** 里的**【上移】/【下移】** 改顺序 |

### S07–S10　四个标签页的功能

| 步 | 标签 | 能做什么 |
|---|---|---|
| **S07** | **【配置】** | 看不同配置以及不同显示状态；**图形窗口里也能切换** |
| **S08** | **【标注】** | **标注尺寸、插入图片、添加注释、绘制几何图形** |
| **S09** | **【测量】** | 单击**【激活测量】** → 在图形区选几何图形 |
| **S10** | **【横断面】** | 单击**【插入横断面】** → 选参考面或实体面 |

### S11–S12　播放动画与戳记

| 步 | 操作 | 路径 / 注意 |
|---|---|---|
| **S11** | 播放运动算例 | 在**【动画】** 标签中播放 **SolidWorks Motion 创建的动画** |
| **S12** | 添加戳记 | 在**【戳记】** 标签中加 **【批注】【机密】【草稿】** 等 |

> **★★ 一条严重后果（原文）**：「**保存 eDrawings 文件后，戳记会永久保留，不可删除。**」
> **加戳记前必须确认——这是不可逆操作。**

## 命令路径速查（本章全部命令）

| 命令 | 菜单路径 | 默认值/关键选项 |
|---|---|---|
| 开插件 | **【工具】/【插件】** | 勾 **PhotoView360**（渲染用） |
| 另存为 eDrawings | **【文件】/【另存为】** → 类型 **eDrawings（*.eprt/*.easm/*.edrw）** | **多配置需选定输出配置** |
| 出版 eDrawings | **【保存】按钮右侧下拉箭头 →【出版 eDrawings 文件】** | 自动打开浏览器 |
| **输出选项** | 保存时**【选项】→【输出】选项卡** | 勾**【确定可测量】** + **【将运动算例保存】**（**默认都不勾**） |
| 密码 | 保存时**【密码】** | 默认无 |
| 存为 exe | eDrawings →**【文件】/【另存为】→ *.exe** | 自带播放器，体积大 |
| 保存批注 | eDrawings**【文件】/【保存批注】** | 多人各自独立 |
| 大图标 | eDrawings**【视图】/【工具栏】→【大图标】** | 图标下显示注释 |
| 上色/线框 | eDrawings**【视图】/【上色】**、**【上色时显示边线】** | 默认上色 |
| 移动零部件 | eDrawings**【零部件】标签 →【移动零部件】** | — |
| 显示爆炸 | eDrawings**【显示爆炸】** | 需源文件有爆炸视图 |
| 连续播放 | eDrawings**【连续播放】** | — |
| 动画重排序 | eDrawings**【将动画重新排序】→【上移】/【下移】** | — |
| 激活测量 | eDrawings**【测量】标签 →【激活测量】** | 需保存时勾了可测量 |
| 插入横断面 | eDrawings**【横断面】标签 →【插入横断面】** | 选参考面/实体面 |
| 添加戳记 | eDrawings**【戳记】标签** | **保存后永久保留，不可删除** |

## 失败模式（F-11）

| 编号 | 现象 | 根因 | 处置（含路径） | 页 |
|---|---|---|---|---|
| F-11-01 | **对方打不开测量功能** | 保存时**没勾【确定可测量此 eDrawings 文件】** | 重新另存 → 【选项】/【输出】→ 勾选该项 | p223 |
| F-11-02 | **动画丢了** | 没勾**【将运动算例保存到 eDrawings 文件中】** | 同上，勾选该项 | p223 |
| F-11-03 | 多配置零件只输出了一个配置 | 没选定输出配置 | 另存时**选定要输出的配置** | p222 |
| F-11-04 | **戳记加错了想删掉** | **保存后戳记永久保留、不可删除** | **加之前确认**；错了只能重存一份 | p226 |
| F-11-05 | eDrawings 里没有爆炸视图 | 源装配体没做过爆炸视图 | 先在 SolidWorks 里建**【插入】/【爆炸视图】** | p224 |
| F-11-06 | 对方电脑打不开文件 | 只给了 eDrawings 文件但没装查看器 | 存成 **`*.exe`**（**自带播放器**） | p222 |
| F-11-07 | 想隐藏某个零件看内部 | 只会旋转 | **右击模型树零部件 → 隐藏/透明** | p224 |
| F-11-08 | 图标看不清含义 | 图标太小 | **【视图】/【工具栏】→【大图标】**；或悬停看提示 | p222 |
| F-11-09 | 保存后没自动打开浏览器 | 用了路径一（另存为） | 改用**【出版 eDrawings 文件】** 会自动打开 | p222 |
