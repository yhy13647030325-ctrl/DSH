# 附录逐步清单：CSWA / CSWP 样题（可照做版）

> PDF p245–280（书内 p236–271）。
> **操作约定**：命令写全菜单路径；对话框列默认值；以图给值处标 **（需对照原书图 N）**。
> 本附录的核心是**一套套路**，题为"质量-体积练习 1-1 至 2-x"。

## ★ 核心套路：为什么这些题都用"全局变量 + 链接数值"

**这类题的共同结构**：

```
第 1 题：从零建模，尺寸用字母 A/B/C/D/E 表示（设为全局变量）
第 2 题起：改全局变量的值 → 重建 → 读质量
```

> **★ 判据**：**只要把尺寸链接到全局变量，后续每题改一次变量即可**——不用重新建模。
> 这就是 CSWA 系列题"同一模型反复变形"的解法。

### 三件必做的事（原文反复出现）

| # | 操作 | 路径 |
|---|---|---|
| 1 | **设单位** | **【工具】/【选项】/【文档属性】/【单位】** → **MMGS**、小数位 **2** |
| 2 | **建全局变量** | **【工具】/【方程式】** |
| 3 | **把尺寸链接到变量** | **右击尺寸 →【链接数值】** → 选对应变量 |

## 附录 A：CSWA 质量-体积练习

### 练习 1-1（25 分）：从零建模（15 步）

**已知**：MMGS、小数位 2、原点任意、材料 **红铜**（密度 **0.0089 g/mm³**）、
**A=58°、B=60、C=135、D=20**、**抽壳厚度 3mm**。
**问：零件质量为多少克？**

| 步 | 操作 | 路径 / 参数 |
|---|---|---|
| **S01** | 新建零件 | **【文件】/【新建】/【零件】**（图 A-2） |
| **S02** | 设置环境 | **【工具】/【选项】/【文档属性】/【单位】** → MMGS、小数位 2 → 确定 |
| **S03** | 打开方程式管理器 | **【工具】/【方程式】** |
| **S04** | **创建全局变量** | 在管理器中创建图 A-5 所示变量（A/B/C/D）→ 确定 |
| **S05** | 指定材料 | 设计树**右击【材料】→【编辑材料】** → 选 **"铜"** → **【应用】** → **【关闭】** |
| **S06** | 绘制草图 | 选**前视基准面** → 画图 A-6 草图 |
| **S07** | 拉伸-薄壁1 | **【插入】/【凸台/基体】/【拉伸】** → 勾**【薄壁特征】**（图 A-7） |
| **S08** | **显示特征尺寸** | 设计树**右击【注解】→【显示特征尺寸】** → 全部尺寸显示 |
| **S09** | **链接数值** | 见下方明细 |
| **S10** | **完整圆角** | 按图 A-10 创建（**【插入】/【特征】/【圆角】→ 类型选【完整圆角】**） |
| **S11** | 绘制草图 | 选图 A-11 平面 → 画**与完整圆角同心、φ20** 的圆 |
| **S12** | 切除-拉伸1 | **【插入】/【切除】/【拉伸】** → 用 S11 草图 |
| **S13** | **抽壳** | **【插入】/【特征】/【抽壳】**（图 A-13）→ **【厚度】3mm** |
| **S14** | **查看质量** | **【工具】/【评估】/【质量属性】** |
| **S15** | 保存 | 命名 **"Structure"** |

**【S09】链接数值的完整操作**：

| 步 | 操作 |
|---|---|
| 1 | 在图形界面**右击尺寸 "135mm" →【链接数值】** |
| 2 | 在弹出的列表中选择变量 **C** |
| 3 | 同样方法把 **58 → A**、**60 → B**、**20 → D** |

> **★ 顺序无所谓，但四个都要连**；漏一个，后续改变量时该尺寸不动。

**【全局变量】的填法（S04）**：

| 变量名 | 值 | 说明 |
|---|---|---|
| **A** | **58** | 角度（°) |
| **B** | **60** | 长度 |
| **C** | **135** | 长度 |
| **D** | **20** | 长度 |

### 练习 1-2（10 分）：改变量（5 步）

**新值**：**A=60°、B=70、C=130、D=17**；材料仍 **红铜 0.0089 g/mm³**。

| 步 | 操作 | 路径 |
|---|---|---|
| **S01** | 打开零件 | **【文件】/【打开】** → "Structure" |
| **S02** | 改变量 | **【工具】/【方程式】** → 改 A/B/C/D（图 A-16） |
| **S03** | **重建模型** | 退出管理器 → **Ctrl+B**（或 **Ctrl+Q**） |
| **S04** | 查看质量 | **【工具】/【评估】/【质量属性】** |
| **S05** | 保存退出 | — |

> **★ S03 不能省**：退出方程式后**模型不会自动更新**，必须重建。

## 失败模式（F-99）

| 编号 | 现象 | 根因 | 处置（含路径） | 页 |
|---|---|---|---|---|
| F-99-01 | **改了全局变量，模型没变** | **没重建** | 退出方程式后 **Ctrl+B 或 Ctrl+Q** | p250 |
| F-99-02 | **点不到尺寸，无法链接数值** | **特征尺寸被隐藏** | **右击【注解】→【显示特征尺寸】** | p248 |
| F-99-03 | 链接数值后改变量还是不动 | 该尺寸**没链接上** | 逐个检查：右击尺寸看【链接数值】是否已指向变量 | p248 |
| F-99-04 | **质量差 1000 倍** | **单位系统混用**（MMGS vs IPS） | MMGS 用 **g/mm³**；IPS 用 **lb/in³** | p245、p255 |
| F-99-05 | 质量算出来差 4~5% | **材料换错了密度** | 红铜 **0.0089**、黄铜 **0.0085** | p254 |
| F-99-06 | 该题不该有的特征还在 | 只删了没压缩 | **右击 →【压缩】**（可恢复） | p252 |
| F-99-07 | 孔位置定不住 | 没完全定义 | 用**【同心】配合**把孔位置完全定义 | p252 |
| F-99-08 | 加变量 E 后报错 | 变量名重复或语法错 | 在方程式管理器里检查变量名唯一 | p251 |
| F-99-09 | 材料加了但质量还是空 | 只看【应用】没【关闭】 | **【应用】→【关闭】** 两步都要点 | p246 |
| F-99-10 | 重建后仍显示旧值 | 用了 Ctrl+B 但特征有错 | 改用 **Ctrl+Q**（强制重建），会有提示 | p248 |
