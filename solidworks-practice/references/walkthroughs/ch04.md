# 第 4 章逐步清单（可照做版）

> PDF p104–134（书内 p95–125）。
> **操作约定**：命令写全菜单路径；对话框列**选项/默认值/本书取值**；原书简写补全标 **（补全）**；以图给值处标 **（需对照原书图 N）**。

## 核心要点

装配体 = 零件 + 配合，本质是**用约束吃掉自由度**。文件扩展名 `*.sldasm`。

**两个基础概念（原文 p104）**：
- **配合关系**：零部件的表面或边与基准面、其他表面或边的**约束关系**
- **自由度**：空间中未受约束的刚性实体具有**六个自由度**——三个平移 + 三个旋转

**四种设计方案（p104）**：自底向上、自顶向下、布局设计、智能零部件设计（本章只讲前两种）。

## 4.3.1 自底向上：六步流程（原文）

| # | 步骤 | 原文要点 |
|---|---|---|
| 1 | **创建新装配体** | 方法与创建零件相同 |
| 2 | **添加第一个零部件** | 可从打开的零件窗口或 Windows 资源管理器**拖放** |
| 3 | **放置第一个零部件** | **自动设为固定状态**，其他零部件加入后再定位 |
| 4 | 读设计树符号 | 设计树含大量**符号、前缀和后缀** |
| 5 | **零部件间配合** | 配合**限制了零部件的自由度** |
| 6 | 子装配体 | 可新建或插入；**系统把子装配体当作一个零部件处理** |

## E01　自底向上：装载机（p105–113）

**素材**：`装载机` 文件夹（后体、前体、差动、车轮组、装载组、螺钉）。

### 阶段 A：起手（S01–S08）

| 步 | 操作 | 路径 / 参数 |
|---|---|---|
| **S01** | 创建装配体 | **【文件】/【新建】** → 选 **装配体** 模板 |
| **S02** | 插入第一个零部件"后体" | 设计树**【开始装配体】** 属性框 → 单击**【浏览】** → 弹出**【开始装配体】** 对话框 → 选 **"装载机"文件夹中的"后体"** → **勾选"图形预览"** → 单击放置按钮 |
| **S03** | **不要点界面空白处** | 原文：**单击界面任何一处即可将模型放置到装配体中，这里请勿进行此操作** |
| **S04** | 直接确认放置 | 目的：**零件坐标系与装配体坐标系重合** |
| **S05** | 理解第一个零件为何固定 | 第一个插入件**自动加【固定】配合**，自由度全被固定 |
| **S06** | 解除固定的方法 | **右击 →【浮动】** |
| **S07** | 插入"前体" | **【插入】/【零部件】/【现有零件/装配体】**（或工具栏【装配体】/【插入零部件】） |
| **S08** | 放置"前体" | 在图形界面**任意处单击** |

> **★ S03/S04 的因果**：点空白处 = 随机位置放置；直接确认 = **原点对齐**。前者会导致后续所有配合都要先"把零件挪回来"。

| **S13** | 加**【重合】** | **【插入】/【配合】** → 选"前体"和"后体"各一个**面** → 软件默认**【重合】** |

## 各命令的完整对话框选项（补齐版）

> 上文例题只列了"本例改了哪几项"。这里把**每个对话框的完整选项**列出，含**默认值**。

### 【配合】PropertyManager（本章最核心）

**【配合选择】**：两个选择框，选面/孔面/基准面/边线。

**【标准配合】七种**：

| 配合 | 约束掉什么 | 典型用法 |
|---|---|---|
| **【重合】** | 1 个平移 | 面贴面、点线重合 |
| **【平行】** | 1 个转动 | 两面平行 |
| **【垂直】** | 1 个转动 | 两面成 90° |
| **【相切】** | 1 个平移+1 转动 | 面与圆柱相切 |
| **【同轴心】** | 2 个平移+2 转动 | 孔与轴 |
| **【距离】** | 1 个平移（定值） | 保持间隔 |
| **【角度】** | 1 个转动（定值） | 保持夹角 |

**【高级配合】六种**：

| 类型 | 作用 | 本例用在哪 |
|---|---|---|
| **【宽度】** | 让一个件在另一个件的两对称面间居中 | **E01 S30（装载组）** |
| 【轮廓中心】 | 按轮廓中心对齐 | — |
| 【对称】 | 两件关于一个面对称 | — |
| **【凸轮】** | 凸轮与从动件 | — |
| **【齿轮】** | 齿轮传动（需填比率） | 第 10 章练习 |
| **【齿条】** | 齿轮齿条 | — |

**【机械配合】五种**：凸轮 / 齿轮 / 齿条 / 螺旋 / 万向节。

**【选项】组**：

| 选项 | 默认值 | 作用 |
|---|---|---|
| **【添加到新文件夹】** | 不勾 | 把该配合归入新文件夹 |
| 【显示弹出式工具栏】 | 勾选 | 加完自动弹关联工具栏 |
| **【只显示未使用的配合】** | 不勾 | 过滤列表 |

> **★ 配合的本质是"吃掉自由度"**：一个件 6 自由度；**面-面重合 + 孔-孔同轴心 + 基准面重合**这套三件套正好收掉 6 个。

## 与其他部分的关系

- **与 `solidworks-2025-mechanical` ch06 的差异**：那本额外讲**机械配合（齿轮/凸轮/齿条）与高级配合**；本文件讲基础配合与完整装配流程。
