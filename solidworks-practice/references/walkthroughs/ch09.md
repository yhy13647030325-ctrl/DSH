# 第 9 章逐步清单（可照做版）

> PDF p187–205（书内 p178–196）。
> **操作约定**：命令写全菜单路径；对话框列选项/默认值/本书取值；以图给值处标 **（需对照原书图 N）**。
> 本章两个实例：**3D 管道 16 步 + 篮球架焊件 28 步**，全部来自原文。

## 核心要点：3D 草图的唯一方向基准是 **Tab 键**

> **按 `<Tab>` 键切换草图平面，直到光标显示为对应平面符号**（如 ZX、XY、YZ），**再画线**。

**本例反复出现的三种光标**：沿 **Z 轴 / X 轴 / Y 轴** 方向绘制。

## 9.3.1 实例 1：3D 管道（16 步）

**已知**：材料 **1060 铝合金**、密度 **2700 kg/m³**、单位 **MMGS**、小数位 **2**。

| 步 | 操作 | 路径 / 参数 |
|---|---|---|
| **S01** | 新建文件 | 模板 **"gd_part"** → 单位系统 **【MMGS】** |
| **S02** | 激活 3D 草图 | **【插入】/【3D 草图】**（特征工具栏【3D 草图】按钮） |
| **S03** | 绘制直线组 1 | **【工具】/【草图实体】/【直线】** → **按 <Tab> 直到光标显示平面符号** → 从原点**沿 Z 轴约 9mm** → **沿 X 轴约 5.5mm** → **分别标注 9mm 和 5.50mm** |
| **S04** | 绘制直线组 2 | 从 5.5mm 直线端点 → **沿 Y 轴约 9mm** → **沿 X 轴约 9mm** → 分别标尺寸 |
| **S05** | 绘制直线组 3 | **沿 Y 轴约 5.5mm** → **沿 Z 轴约 9mm** → **沿 Y 轴约 9mm** → **沿 Z 轴约 5.5mm** → 分别标尺寸 |
| **S06** | 绘制直线组 4 | **沿 X 轴约 9mm** → **沿 Z 轴约 9mm** → **沿 X 轴约 5.5mm** → 分别标尺寸 |
| **S07** | 绘制直线组 5 | **沿 Y 轴约 9mm** → **沿 X 轴约 9mm** → **沿 Y 轴约 5.5mm** → 分别标尺寸 |
| **S08** | 绘制直线组 6 | **沿 Y 轴约 9mm** → **沿 Z 轴约 9mm** → **沿 Y 轴约 5.5mm** → 分别标尺寸 |
| **S09** | 绘制最后一条 | 使**它的端点和图纸原点重合** → **草图完全定义**，**所有线段显示为黑色** |
| **S10** | 添加圆角 | **【工具】/【草图工具】/【圆角】** → **所有直角加 R1.5mm** → **保存并退出 3D 草图** |
| **S11** | 新 3D 草图 + 转换 | **【插入】/【3D 草图】** → **【工具】/【草图工具】/【转换实体引用】** → **【要转换的实体】选【3D草图1】** |
| **S12** | 套合样条曲线 | **【工具】/【样条曲线工具】/【套合样条曲线】** → **框选 3D 草图** → 确认 → **保存并退出** |
| **S13** | 绘制扫描轮廓 | **隐藏【3D草图1】** → **前视基准面** 画 **φ2 的圆** → **圆心与套合样条曲线加【穿透】** |
| **S14** | 创建扫描 | **【插入】/【凸台/基体】/【扫描】** → 【轮廓】= **步骤 13 的圆**；【路径】= **套合样条曲线** |
| **S15** | 编辑材料 | **1060 铝合金** |
| **S16** | 保存 | 命名 **"3D管道"** |

### ★ 3D 管道的三个隐性要点

| # | 要点 | 原因 |
|---|---|---|
| 1 | **每组直线的方向顺序固定** | 方向错一根，整条管道走向就变；**每组内部按 Z→X、Y→X 等固定序** |
| 2 | **S09 必须"闭合到原点"** | 使草图**完全定义**（全黑），否则后续套合/扫描不稳 |
| 3 | **S12 先套合再当路径** | 3D 草图里有大量 R1.5 圆角与直线段，**套合成单一 C2 样条**才能扫出光滑管道 |

> **S12 的意义**：不套合直接扫，**会在每个圆角处出现接缝/退化**（对照 `solidworks-surface-advanced` ch02 的"套合样条曲线三条好处"）。

## 9.3.2 实例 2：篮球架焊件（28 步）

**核心概念（原文）**：
> **焊件是由多个焊接在一起的零件组成的，应该把焊件作为多实体进行建模，一个特殊的焊件特征会指明这个多实体零件为焊件。**

### 阶段 A：3D 骨架（S01–S10）

| 步 | 操作 | 路径 / 参数 |
|---|---|---|
| **S01** | 新建文件 | 模板 **"gd_part"** → **MMGS** |
| **S02** | 激活 3D 草图 | **【插入】/【3D 草图】** |
| **S03** | 绘制中心线 | 见下方明细 |
| **S04** | 转换中心线 | 见下方明细 |
| **S05** | 继续画骨架直段 | **【直线】** → **按 Tab 切平面** → 沿各轴延伸（图 9-34） |
| **S06** | 加第二条中心线 | 同 S03 方法，**按 Tab 到目标平面**（**需对照原书图 N**） |
| **S07** | 补齐横向连接 | 沿 X/Z 轴连接两立柱（**需对照原书图 N**） |
| **S08** | 标尺寸 | **【智能尺寸】** 标各段长度（**需对照原书图 N**） |
| **S09** | 检查完全定义 | 草图**全黑**即完全定义；蓝色表示还缺约束 |
| **S10** | 退出 3D 草图 | 点**【退出草图】/【确认角】** |

**【S03】中心线绘制（原文完整）**：

| 步 | 操作 |
|---|---|
| 1 | **打开【直线】的下拉菜单 → 单击【中心线】** |
| 2 | **按 <Tab> 键切换草图平面，直到光标显示为【ZX】** |
| 3 | 从原点**沿 X 轴约 1200mm**，并使该线**在模型空间中与 X 轴重合** |
| 4 | 继续**沿 Z 轴约 1500mm** |
| 5 | 继续**沿 X 轴约 1200mm** |
| 6 | 绘制第四条使其**与原点重合**，并给该线**【沿 Z 轴】几何关系** |
| 7 | 分别标注尺寸 **1200mm 和 1500mm** |

**【S04】构造线转实体线（原文完整）**：

| 步 | 操作 |
|---|---|
| 1 | **按住 <Ctrl> 选中两条沿 Z 轴、长 1500mm 的中心线** |
| 2 | 在**属性框**中将 **【作为构造线】选项取消勾选** |
| 3 | 确认 |

> **★ S04 的价值**：中心线默认是**构造线（不参与建模）**；焊件结构构件要的是**实体路径**，所以要把其中几条"转正"。

### 阶段 B：焊件与结构构件（S11–S20）

| 步 | 操作 | 路径 / 参数 |
|---|---|---|
| **S11** | 激活焊件 | 第一个**结构构件**生成后，**【焊件】按钮才会出现在设计树** |
| **S12** | 结构构件 1 | **【插入】/【焊件】/【结构构件】** → 见对话框 |
| **S13** | **分组** | **平行线成一组、圆弧单独成组** |
| **S14** | 剪裁/延伸 | **【插入】/【焊件】/【剪裁/延伸】** → 见对话框 |
| **S15** | 顶端盖 | **【插入】/【焊件】/【顶端盖】** |
| **S16** | 角撑板 | **【插入】/【焊件】/【角撑板】** |
| **S17** | 圆角焊缝 | **【插入】/【焊件】/【圆角焊缝】** |
| **S18** | 检查切割清单 | 展开设计树**【切割清单】文件夹** |
| **S19** | 材料 | **1060 铝合金** |
| **S20** | 保存 | 命名 **"篮球架"** |

**【结构构件】属性管理器（S12）**：

| 选项组 | 选项 | 默认值 | **本书取值** |
|---|---|---|---|
| **【标准】** | 下拉 | **ansi 英寸** | **需对照原书图**（国标用 iso/gb） |
| **【Type: Configured Profile】** | 下拉 | — | 按需选 |
| **【大小】** | 下拉 | — | 按需选 |
| **【组】** | 文本框 | 空 | **在绘图区选一组草图实体作为路径线段** |

**【剪裁/延伸】四种边角类型（S14）**：

| 类型 | 可剪几个实体 |
|---|---|
| **【终端剪裁】** | **一个或多个** |
| **【终端斜接】** | 一个 |
| **【终端对接1】** | 一个 |
| **【终端对接2】** | 一个 |

**【剪裁边界】**：可选**【面/平面】**。

> **★ 分组规律（本章最重要的一条实操经验）**：
> **平行线归为一组，圆弧单独成组**——因为**圆弧处的接头处理与直段不同**，混在一组会导致接头错乱。

## 失败模式（F-09）

| 编号 | 现象 | 根因 | 处置（含路径） | 页 |
|---|---|---|---|---|
| F-09-01 | 3D 草图里画的线方向乱跑 | **没按 Tab 切平面** | **按 <Tab> 直到光标显示目标平面符号**（ZX/XY/YZ）再画 | p188 |
| F-09-02 | 3D 管道扫出来一段一段、有接缝 | 没用套合样条 | **【套合样条曲线】** 框选整个 3D 草图再当路径 | p193 |
| F-09-03 | 3D 管道草图无法完全定义 | **最后一条线没回到原点** | 让**端点与原点重合** → 全黑即完全定义 | p191 |
| F-09-04 | 扫描找不到路径 | 隐藏了 3D 草图 | 显示后再选；或用**套合后的草图** | p193 |
| F-09-05 | 扫描轮廓与路径不相交 | 缺【穿透】 | 圆心与路径加**【穿透】** 几何关系 | p193 |
| F-09-06 | 中心线画了但结构构件选不到 | **中心线是构造线** | **取消勾选【作为构造线】**，转成实体线 | p195 |
| F-09-07 | 结构构件接头错乱 | **分组不对** | **平行线一组、圆弧单独成组** | p196 |
| F-09-08 | 想剪多根型材剪不了 | 选错边角类型 | **只有【终端剪裁】能剪多个** | p197 |
| F-09-09 | 设计树里没有【焊件】按钮 | **还没有第一个结构构件** | 先做第一个结构构件，焊件特征会自动出现 | p194 |
| F-09-10 | 找不到切割清单 | 未展开 | 展开**【切割清单】文件夹** | p196 |
| F-09-11 | 画 3D 草图时视图转得头晕 | 一直用鼠标转 | **用 <Tab> 切平面**比转视图可靠 | p188 |
| F-09-12 | 圆角加在 3D 草图后扫描失败 | 圆角半径过大或顺序错 | 用 **R1.5**（本例），且**先圆角后套合** | p191 |

## 与其他部分的关系

- **与 `solidworks-2025-mechanical` ch09 的差异**：那本给**焊件七属性、剪裁四类型、切割清单层级**；本文件给**3D 管道 16 步 + 篮球架骨架**，含 **Tab 切平面、构造线转实体、分组规律**。
- **套合样条曲线 → `solidworks-surface-advanced` ch02**（同一工具的曲面用法）。
- **焊缝位置四原则 → `product-structure-liubaoshun` 1.3**（软件不判断焊缝是否放错）。
