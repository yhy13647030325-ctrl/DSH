## 核心要点（先记三条）

### ① 尺寸驱动，先画形状后标尺寸

> 「SolidWorks 是一款**尺寸驱动**的软件，几何体的大小是通过为其标注的尺寸来控制的。
> 因此，**绘制草图过程中只需绘制近似的大小和形状即可**。」（p047）

### ② 推理线自动捕捉几何关系

> 「绘制直线时可以**最大范围地利用推理线**，推理线可以**自动捕捉一些几何关系**。」（p046）

### ③ 画直线的两种操作法（原文 p47）

| 方法 | 操作 |
|---|---|
| **单击—单击** | 起点单击一次 → 移到终点（**图形区已预览**）→ 再单击一次 |
| **单击—拖动** | 起点单击并**按住左键不放** → 移到终点 → **松开左键** |

### ★ 直线↔切线弧的两种切换（原文 p52）

> **不必另外选【切线弧】命令**，画直线时可以直接转换：

| 方法 | 操作 | 限制 |
|---|---|---|
| **① 移开再返回** | 画好第一段直线后，**把光标移到绘图区任意地方再返回端点** | **同一步骤内只能直线→切线弧，不能再转回直线** |
| **② 按 A 键** | 画好第一段直线后**按一下 <A>** → 转切线弧；**再按 <A>** → 转回直线 | **可反复切换** |

> **★ 切线弧的智能性（原文）**：绘制切线弧时，SolidWorks 会**根据光标的移动位置在四个目标区域内智能分析出八种可能性**（图 2-94）。

> **★ 一条重要警告（原文 p51）**：
> 「图是由**单独的直线命令**绘制而成，在绘图时**只需要捕捉图 2-93 中的几何关系**，
> **过多捕捉几何关系会使以后定义几何关系时造成过定义状态**。」
> **即：捕捉不是越多越好。**

## 2.5.4 示例 4（10 步）★ 全章最复杂

| 步 | 操作 | 路径 / 参数 |
|---|---|---|
| **S01** | 绘制中心线 | **【工具】/【草图实体】/【中心线】** → 两条经过原点，**【水平】【竖直】** |
| **S02** | 绘制圆并标注 | **【工具】/【草图实体】/【圆】** → **φ48、φ8、φ3.50、φ3.50**，标注使其完全定义 |
| **S03** | 绘制另一条中心线 | **【中心线】** → 画 **120° 夹角**，且**夹角中心线与竖直中心线有对称几何关系** |
| **S04** | 中心点圆弧槽口 | **【工具】/【草图实体】/【中心点圆弧槽口】** → **以原点为中心点**、**与两条 120° 夹角中心线相交** → 标尺寸 |
| **S05** | 绘制五角星 | 创建 **5 条相等长度线段**，**每条都与 φ3.5 的圆相切**，加必要约束 → **完全定义** |
| **S06** | 剪裁草图 | **【工具】/【草图工具】/【剪裁】** → 剪掉五角星**中心多余部分直线**，**保持各线段与圆相切且相等** |
| **S07** | 镜像实体 | **【工具】/【草图工具】/【镜像】** → 镜像步骤 6 中**已完全定义**的草图 |
| **S08** | 等距圆 | **【工具】/【草图工具】/【等距实体】** → **【等距距离】3.00mm** + **勾选【反向】** → 等距 **φ48 的圆** |
| **S09** | 等距槽口 | 同上 → **3mm** + **取消勾选【反向】** → 等距**槽口** |
| **S10** | 剪裁完成 | **【工具】/【草图工具】/【剪裁】→【强劲剪裁】** → 剪裁得到**完全定义草图** |

### ★ 示例 4 的三处隐性要点

| # | 要点 | 说明 |
|---|---|---|
| 1 | **S03 的对称关系** | 120° 夹角中心线**必须与竖直中心线对称**，否则后续槽口定位不上 |
| 2 | **S05 的"与圆相切"** | 5 条线段**既要相等、又要与 φ3.5 圆相切**——两个条件叠加才能完全定义 |
| 3 | **S08 vs S09 的【反向】** | **等距圆时勾选反向、等距槽口时取消**——同一命令两个方向，**勾错就跑到另一侧** |

## 失败模式（F-02）

| 编号 | 现象 | 根因 | 处置（含路径） | 页 |
|---|---|---|---|---|
| F-02-01 | 草图一直是蓝色（欠定义） | 尺寸没标全或几何关系不足 | 补 **【智能尺寸】** 或**【添加几何关系】** | p45 |
| F-02-02 | 草图变黄（过定义） | **捕捉了过多几何关系** | 删多余关系（原文明确警告） | p51 |
| F-02-03 | 阵列后草图变蓝 | 阵列结果**仍需定位** | 用**边角点与圆加【重合】** 收掉自由度（示例2 S05） | p50 |
| F-02-04 | 画完直线想接切线弧，找不到命令 | 不知道可直接切换 | **按 A 键**切换；或光标**移开再返回端点** | p52 |
| F-02-05 | 切线弧转不回直线 | 用了"移开再返回"法 | **改用 A 键**（A 键可反复切换） | p52 |
| F-02-06 | 等距跑到图形另一侧 | **【反向】** 勾选状态错 | 勾选/取消【反向】试一次 | p54 |
| F-02-07 | 等距出来的是双线 | 勾了**【双向】** | 取消【双向】 | p47 |
| F-02-08 | 五角星剪裁后约束全丢 | 剪裁顺序错 | **先加相等+相切约束，再剪中心多余线**（示例4 S05→S06） | p53 |
| F-02-09 | 中心点圆弧槽口定位不上 | 两条 120° 中心线**未与竖直中心线对称** | 补**【对称】** 几何关系（示例4 S03） | p52 |
| F-02-10 | 想找两线交点当约束点 | 没有交点实体 | **按住 Ctrl 选两条角度线 + 单击【点】** | p52 |
| F-02-11 | 草图基准面选错、后面全歪 | 随手点了某个面 | 激活后**旋转到与屏幕平行（【正视于】）**，**原点符号变红**才是正确激活 | p46 |
| F-02-12 | 画直线第一点就定位错 | 没利用推理线 | **把光标靠近已知尺寸位置**（如"竖直中心线接近 25mm 处"） | p46 |
| F-02-13 | 图中灰色尺寸改不了 | 那是**从动尺寸** | 从动尺寸不驱动几何，属正常（示例3 说明） | p53 |
| F-02-14 | 阵列角度不对，实例重叠 | 【等间距】与【标注角间距】互斥 | 只能用其一；【等间距】默认勾 | p47 |

## 与其他部分的关系

- **与 `solidworks-2025-mechanical` ch02 的差异**：那本给 **2025 版命令路径清单**；本文件给 **4 个示例 29 步的完整拆解**（含 A 键切换、等距反向、从动尺寸）。
