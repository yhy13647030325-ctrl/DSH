# 第 7 章逐步清单（可照做版·子操作级）

> PDF p164–172（书内 p155–163）。
> **操作约定**：命令写全菜单路径；对话框列**选项/默认值/本书取值**；以图给值处标 **（需对照原书图 N）**。
> **本章按"子操作级"拆解**：原文 8 个步骤展开为 **32 步**，每步只做一件事。

## 核心要点：渲染的六步流程（原文 p164）

> **PhotoView360 操作流程**：
> 1）**打开 PhotoView360 插件**
> 2）**开启预览或者打开预览窗口查看效果**
> 3）**编辑外观、布景以及贴图**
> 4）**编辑光源**
> 5）**编辑 PhotoView 选项**
> 6）**最终渲染，保存图像**

## ★ 两个前提工具（p164，原文先说这两样）

### ① RealView 与环境封闭

> 如果图形显卡支持，软件会**自动添加 RealView 开关**，即所谓"**小金球**"，并**默认打开此功能**，
> 能**在不需要渲染的情况下**，为模型提供**逼真而又动态的展现**。

> **环境封闭**是一种**球形光源方法**，通过**控制由于封闭区域导致的环境光衰减**，使模型更加逼真。

| 项 | 说明 |
|---|---|
| RealView | **依赖显卡**；有则自动出现"小金球"，**默认开** |
| 环境封闭 | 球形光源法；**在视图环境里就生效**（无需渲染） |

### ② PhotoView360 是什么

> 更加逼真的显示和输出需要插件 **PhotoView360**，通过它可以**添加不同的布景、光源、外观贴图、相机视角**等。

**★ 关联工具栏的层级顺序（原文，极重要）**：
> 「第二个图标会**根据用户拖拽到的目标特征不同而不同**；**选项依次为：面、特征、实体、零件、部件**。

| 序号 | 层级 | 作用范围 |
|---|---|---|
| 1 | **面** | 只作用于选中的面 |
| 2 | **特征** | 作用于该特征 |
| 3 | **实体** | 作用于该实体 |
| 4 | **零件** | 作用于整个零件 |
| 5 | **部件** | 作用于子装配体 |

> **记忆**：**序号越大范围越大；"部件"和"曲面"优先级最高。**

## 阶段 F：点光源（S29–S32）★ 步骤最密

**原理（原文）**：
> 查看光源文件夹，**布景照明度和环境光源是布景提供的逼真光源，该光源通常足够进行渲染**。
> 这里需要**添加一个点光源来实现灯泡的发光效果**。

| 步 | 操作 | 路径 / 参数 |
|---|---|---|
| **S34** | 开剖面 | **前导视图工具栏 →【剖面视图】** → 选**前视图** → 确定 |
| **S35** | 调前视图 | **Ctrl+1** → 前视图 |
| **S36** | **加点光源** | **右击光源文件夹 →【添加点光源】**（图 7-26） |
| **S37** | 拖红点定位 | **用鼠标拖动图形区中的红点**到**灯泡中心位置**（图 7-27） |
| **S38** | 换上视图 | **Ctrl+5** → 上视图 |
| **S39** | **改坐标** | 在点光源设定中，把**"光源位置"的 X 和 Z 坐标改为 0**（图 7-28） |
| **S40** | 退出剖面 | 确定 → 单击按钮**退出剖视图显示** |
| **S41** | **★ 在 PhotoView 中打开** | **右击 DisplayManager 中刚建的点光源 →【在 PhotoView 中打开】** → **确保点光源前面显示对应标记** |

**【点光源】属性**：

| 选项 | 默认值 | **本书取值** |
|---|---|---|
| 【光源位置】X | 拖拽决定 | **0** |
| 【光源位置】Y | 拖拽决定 | 保持（灯泡高度） |
| 【光源位置】Z | 拖拽决定 | **0** |
| 【在 PhotoView 中打开】 | 关闭 | **打开** |

> **★ S36 是全章最易漏的**：**不点【在 PhotoView 中打开】，这个点光源在最终渲染里根本不参与。**

## 阶段 G：预览与最终渲染（S37–S40）

**原文推荐的两种方式对比**：

| 方式 | 说明 | 推荐度 |
|---|---|---|
| **整合渲染** | 在**图形区域直接渲染** | — |
| **预览窗口** | 在**独立窗口渲染** | **★ 推荐（更为节省资源，方便修改操作）** |

| 步 | 操作 | 路径 / 参数 |
|---|---|---|
| **S42** | 缩放 | 缩放图形窗口模型到**合适大小** |
| **S43** | 预览 | 单击**【预览窗口】** 按钮进行渲染 → 观察结果 |
| **S44** | 调整迭代 | 按喜好在**外观、贴图、布景、光源**等方面调整，满意后即为最终渲染 |
| **S45** | 最终渲染 | **【渲染工具】/【最终渲染】** → 等一段时间后图像区显示最终效果 |
| **S46** | 看历史 | **可在 0～9 中切换，查看渲染完成的最后 10 个历史结果** |
| **S47** | 保存 | 单击**【保存图像】** → 输出所需图形格式 |

## 与其他部分的关系

- **本章是 practice 独有**（2025 与 surface 都不讲渲染）。
- **外观 ↔ 材料**：外观只影响显示；**材料（密度）才影响质量属性**（ch06 S01、ch12 仿真都依赖材料）。
- **渲染 ↔ 动画**：动画可选用 PhotoView 渲染器（见 `ch10.md` 保存动画）。
- **RealView/环境封闭 ↔ 曲面检查**：`solidworks-surface-advanced` ch06 用高反射材质查接缝，原理同源。
