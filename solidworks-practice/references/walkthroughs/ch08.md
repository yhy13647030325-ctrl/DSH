# 第 8 章逐步清单（可照做版）

> PDF p173–186（书内 p164–177）。
> **操作约定**：命令写全菜单路径；对话框列选项/默认值/本书取值；以图给值处标 **（需对照原书图 N）**。
> 本章两个实例：**手动配置 27 步 + 系列零件设计表 16 步**，全部来自原文。

## 核心要点：两种做配置的方法

| 方法 | 命令 | 特点 |
|---|---|---|
| **手动配置** | **右击尺寸 →【配置尺寸】** | 直接在模型上点，**不用 Excel** |
| **系列零件设计表** | **【插入】/【表格】/【设计表】** | 用 **Excel 表格**批量管，**需要 Microsoft Excel 支持** |

| **S04** | 拉伸凸台 | **【插入】/【凸台/基体】/【拉伸】** |

| **S06** | 拉伸凸台 | 同上 |

> **S01–S12 的尺寸需对照原书图 8-1 至 8-12**（本章以图给值）。

### 阶段 B：进配置环境（S13–S16）★ 三个前置开关

| 步 | 操作 | 路径 / 参数 |
|---|---|---|
| **S13** | 激活 ConfigurationManager | **【ConfigurationManager】和【FeatureManager】在同一个工具栏** → 单击命令管理工具栏的按钮切换 → 出现带默认配置列表的树 |
| **S14** | 修改默认配置属性 | **右击【默认[套筒扳手]】→【属性】** → 把**【配置名称】和【说明】改成大写英文字母 A** → 确认 |
| **S15** | **显示尺寸名称** | **【视图】/【尺寸名称】** → 显示；**再次单击可隐藏** |
| **S16** | **显示特征尺寸** | **打开【Instant3D】命令** → **设计树右击【注解】文件夹 →【显示特征尺寸】** → 尺寸在模型界面显示 |

**★ 尺寸名称格式（原文）**：
> 「每个草图尺寸都有一个**独立无二的名称，其名称格式为"Dx@草图 n"**。**默认设置下尺寸名称是被隐藏的**。」

**S13–S16 的三个前置开关缺一不可**：

| # | 开关 | 不开会怎样 |
|---|---|---|
| 1 | **切到 ConfigurationManager** | 看不到配置列表 |
| 2 | **【Instant3D】** 打开 | **【显示特征尺寸】选了也不显示** |
| 3 | **【显示特征尺寸】** | **模型上看不到尺寸，无法右击** |

### 阶段 C：建配置（S17–S23）★ 本章核心

| 步 | 操作 | 路径 / 参数 |
|---|---|---|
| **S17** | 添加新配置 | **右击"草图1"中的尺寸 φ24 →【配置尺寸】** → 弹出**【修改配置】对话框** → **双击文字"生成新配置"** → 输入 **B** → **Enter** → 重复输入 **C、D、E** |
| **S18** | 添加"草图4"尺寸 | **双击"草图4"中的"D1"尺寸** → 自动加入对话框 |
| **S19** | 添加"圆角1"尺寸 | **双击"圆角1"中的"D1"尺寸** → 加入 |
| **S20** | 添加"草图3"尺寸 | **双击"草图3"中的"D1"尺寸** → 加入 |
| **S21** | 添加"切除-拉伸1"尺寸 | **双击"切除-拉伸1"中的"D1"尺寸** → 加入 |
| **S22** | 修改尺寸 | 按图 8-26 对表格内尺寸**逐配置改值**（**需对照原书图 8-26**） |
| **S23** | 保存表格 | 在**【输入名称】** 输入 **"规格"** → 单击**【保存】** → **【确定】** 退出修改配置 |

**【修改配置】对话框（S17–S23）**：

| 区域 | 内容 |
|---|---|
| 行 | **每个配置一行**（A/B/C/D/E） |
| 列 | **每个尺寸一列**（双击尺寸即加入） |
| 底部"生成新配置" | **双击该文字 → 输入新配置名 → Enter** 即新增一行 |
| **【输入名称】** | 表格名称，本例 **"规格"** |
| 按钮 | **【保存】/【确定】** |

> **★ S17 的"双击'生成新配置'"是唯一入口**——不是点按钮，是**双击那行文字**。

### 阶段 D：验证与收尾（S24–S27）

| 步 | 操作 | 路径 / 判据 |
|---|---|---|
| **S24** | 查看配置 | 命令管理工具栏→**【配置】** 按钮 → 预览已添加的配置 → **双击可激活查看某一配置** |

| **S26** | 编辑材料 | **右击【材质】→【编辑材料】** → **1060 铝合金** |
| **S27** | 保存 | 命名 **"套筒扳手"** |

## 8.2.2 系列零件设计表：Wrench（16 步）

**已知**：A=80、B=12、C=10、D=8、**E=10（半径）**、**F=9（半径）**、G=5、**未注圆角 R1、未注倒角 C1**。
材料 **1060 铝合金**（2700 kg/m³）、**MMGS**、小数位 **2**。

> **★ 原文明确前提**：「**此章需要 Microsoft Excel 软件支持。**」

| 步 | 操作 | 路径 / 参数 |
|---|---|---|
| **S01** | 拉伸1 | **【插入】/【凸台/基体】/【拉伸】**，**上视基准面**画草图 → **【终止条件】两侧对称、【深度】5mm** |
| **S02** | **倒角1** | **【插入】/【特征】/【倒角】** → **选所有正六边形边线（共 24 根）** → **【距离】1.00mm、【角度】45.00°** |
| **S03** | **圆角1（专家法）** | **【插入】/【特征】/【圆角】** → 选 **【FilletXpert】** → **选一条模型边线后不要移动光标** → 关联工具栏点**【相连，11 边线】** → **半径 1mm** |
| **S04** | 草图2 + 文字 | 上视基准面新建草图 → 画**两根构造线** → **【工具】/【草图实体】/【文字】** → 输入 **"SolidWorks"** → 见下方 |
| **S05** | **包覆1** | **【插入】/【特征】/【包覆】**（按图 8-37 设参数） |
| **S06** | **插入设计表** | **【插入】/【表格】/【设计表】** → **选择默认设置**（图 8-38）→ 确定 |
| **S07** | 添加尺寸 | 弹出**【尺寸】对话框** → **按住 <Ctrl> 同时选图 8-39 所示 6 个尺寸** → 确定 |
| **S08** | 退出表格编辑 | 确定后**弹出表格**（含刚才添加的尺寸参数）→ **在图形界面任意空白处单击**退出 |
| **S09** | 打开表格 | 命令管理工具栏中**右击【系列零件设计表】** → 编辑/打开 |
| **S10–S15** | 填表格 | 在 Excel 里填各配置的尺寸值（**需对照原书图 8-30**） |
| **S16** | 保存 | — |

## 失败模式（F-08）

| 编号 | 现象 | 根因 | 处置（含路径） | 页 |
|---|---|---|---|---|
| F-08-01 | 找不到配置列表 | **没切到 ConfigurationManager** | 命令管理工具栏点**【配置】** 按钮 | p177 |
| F-08-02 | **选【显示特征尺寸】没反应** | **没打开 Instant3D** | 先开**【Instant3D】**，再右击【注解】→【显示特征尺寸】 | p177 |
| F-08-03 | **设计表里尺寸名变成文本、整表失效** | **Excel 单元格格式是"文本"** | **右击左上角 →【设置单元格格式】→【常规】** | p181 |
| F-08-04 | 想加新配置找不到入口 | 找按钮找不到 | **在【修改配置】对话框里双击"生成新配置"文字** | p177 |
| F-08-05 | 尺寸加不进配置对话框 | 没双击 | **双击模型上的"D1"尺寸**即自动加入 | p178 |
| F-08-06 | **改了配置尺寸模型没变** | **没激活对应配置** | **双击配置名**激活 | p180 |
| F-08-07 | 模型上看不到尺寸，无法右击 | 尺寸名/特征尺寸被隐藏 | **【视图】/【尺寸名称】** + **【显示特征尺寸】** | p177 |
| F-08-08 | 设计表打不开 | 没装 Excel | 原文：**需 Microsoft Excel 软件支持** | p180 |
| F-08-09 | 圆角要选 11 条边线点不完 | 不知道 FilletXpert | **选一条边线后不动光标** → 关联工具栏**【相连，N 边线】** | p182 |
| F-08-10 | 草图文字改不了字体 | 勾着【使用文档字体】 | **取消勾选**再点【字体】 | p182 |
| F-08-11 | 倒角选不全 24 根边线 | 手工点 | **先选一条 → 用选择工具或环选** | p181 |
| F-08-12 | 表格保存后找不到 | 没命名 | 【输入名称】填 **"规格"** 后【保存】 | p180 |
