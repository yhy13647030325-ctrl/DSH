# 第 6 章逐步清单（可照做版）

> PDF p146–163（书内 p137–154）。
> **操作约定**：命令写全菜单路径；对话框列**选项/默认值/本书取值**；以图给值处标 **（需对照原书图 N）**。
> 本章 **实例1（模型视图出图）16 步**，全部来自原文。

## 核心要点：工程图的四层命令

| 层 | 命令 | 作用 |
|---|---|---|
| **建图纸** | 模板 `gb_a3` | 定图纸大小与图框 |
| **建视图** | 模型视图 / 投影 / 剖面 / 局部 / 断开剖 | 表达形状 |
| **标尺寸** | 模型项目（导入）/ 智能尺寸（手标） | 两种尺寸性质不同 |
| **加注解** | 中心线 / 基准 / 粗糙度 / 形位公差 / 注释 | 完整表达 |

> **★ 尺寸的两种性质（全章最重要的判据）**：
> - **【模型项目】导入的 = 驱动尺寸** → **改它会改模型**（双向关联）
> - **手动标注的 = 参考尺寸** → **无驱动作用**

## 6.5.1 实例 1：皮带轮出图（16 步）

### 阶段 A：准备零件数据（S01–S02）

| 步 | 操作 | 路径 / 参数 |
|---|---|---|
| **S01** | 赋予材料 HT200 | 见下方明细 |
| **S02** | 补充零件属性 | **【文件】/【属性】** → 切到**【自定义】** 选项组 → **"零件号"改为 "PDL001"**、**"设计"赋值 "张三"** → 确定后保存 |

**【S01】自定义材料的完整操作**：

| 步 | 操作 | 路径 |
|---|---|---|
| 1 | 打开材料库 | 设计树**右击【材质】→【编辑材料】** |
| 2 | 新建类别 | 在【材料】对话框中**右击【自定义材料】→【新类别】** → 改名 **"铸铁"** |
| 3 | 新建材料 | **右击【铸铁】→ 新建材料 "HT200"** |
| 4 | 填属性 | 按图 6-17 填：**【名称】HT200**、**【质量密度】7280 kg/m³**；**其他参数用于分析，可以不填** |
| 5 | 应用 | 单击**【应用】** → 再单击**【关闭】** |

> **★ S01 的两个要点**：① **密度 7280 kg/m³ 必须填对**，否则后续质量属性全错 ② 别的参数不是必填

### 阶段 B：建图纸与视图（S03–S06）

| 步 | 操作 | 路径 / 参数 |
|---|---|---|
| **S03** | 创建工程图 | **【文件】/【新建】** → 选 **【gb_a3】** 模板 → **【确定】** |
| **S04** | 创建第一个视图 | 见下方明细 |
| **S05** | 创建投影视图 | **【插入】/【工程图视图】/【投影视图】** → **图纸只有一个视图时软件自动选父视图** → **把光标移到"左视图"的左侧** → **自动产生"主视图"** → 单击放置 |
| **S06** | 删除主视图换剖视图 | **右击主视图 →【删除】** → 确认 |

**【S04】模型视图的完整操作**：

| 步 | 操作 | 路径 / 参数 |
|---|---|---|
| 1 | 点命令 | **【插入】/【工程图视图】/【模型视图】**（视图布局工具栏【模型视图】）→ 出现**【模型视图】** 属性框 |
| 2 | 浏览文件 | 单击**【浏览】** 按钮 → 至"实例"中的 **"皮带轮"** 文件 |
| 3 | 下一步 | 单击**【下一步】** |
| 4 | 选方向 | 方向选 **左视**（图 6-20）→ 单击**【打开】** |
| 5 | 放置 | 在视图窗口图框**右侧**单击**【放置】** |
| 6 | **改比例** | **若默认比例较小** → 在图纸框空白区**右击 →【属性】** → **修改比例为 1:1** |

> **★ S04 第 6 步是必做**：默认比例常常偏小，**改成 1:1** 才符合国标出图习惯。

**【S06】剖面视图的完整操作**（本章最绕）：

| 步 | 操作 | 路径 / 参数 |
|---|---|---|
| 1 | 点命令 | **【插入】/【工程图视图】/【剖面视图】** |
| 2 | 设对齐 | **选"切割线"下的【对齐】**（图 6-22） |
| 3 | 第一点 | **视图中心线上方** |
| 4 | 第二点 | **中间圆的圆心** |
| 5 | 第三点 | **左下角圆的圆心** |
| 6 | 确定 | 单击**【确定】** → 放置剖面视图 |
| 7 | **改方向** | **若剖面方向与图 6-24 不同** → 单击剖面视图 → 在**属性管理器选【反转方向】** |

> **★ 三点定剖切线的规律**：**第一点在轮廓外（定视线方向），第二、三点落在要剖的圆心上**。
> **★ 7 的通用性**：原文明确「有关某一视图的设置，**都可以单击此视图，在左侧的属性管理器中进行修改**」。

### 阶段 C：中心线与尺寸（S07–S10）

| 步 | 操作 | 路径 / 参数 |
|---|---|---|
| **S07** | 添加中心线 | 见下方明细 |
| **S08** | 导入尺寸 | 见下方明细 |
| **S09** | 修整尺寸 | 见下方明细 |
| **S10** | 移动与改文字 | 见下方明细 |

**【S07】中心线两条路径**：

| 目的 | 操作 |
|---|---|
| 孔的轴线 | **【插入】/【注解】/【中心线】** → **依次单击左视图中的三个孔** → 得 3 条回转轴线 |
| 轮槽对称中线 | **依次单击左侧轮槽的两条对称齿面线** → 产生对称中线；右侧同法 |
| 调长度 | **单击各条点画线 → 拖拽线的两个端点** |
| 退出 | 退出中心线工具 |

**【S08】【模型项目】对话框（导入尺寸）**：

| 选项组 | 选项 | 默认值 | **本书取值** |
|---|---|---|---|
| **【来源/目标】** | 来源 | **所选特征** | **【整个模型】** |
| | **【将项目输入到所有视图】** | 不勾 | **勾选** |
| **【尺寸】** | 按钮 | — | 点**【为工程图标注】** |
| 其余（注解/参考几何体） | — | 不勾 | 本例只用尺寸 |

**S08 之后必做**：**框选所有尺寸 → 右击空白区 →【对齐】/【自动排列】** → 再手动微调少数。

> **★ 原文判据**：「添加的尺寸为**驱动尺寸**，意味着**对尺寸的修改会导致模型发生改变**。」

**【S09】修整三条规则**：

| 规则 | 操作 |
|---|---|
| **R2 圆角不标** | **删除图纸中所有 R2 尺寸**，改在技术条件里说明 |
| **倒角要手标** | **导入的倒角尺寸显示方式不符合标准** → **右击左视图的尺寸 1 和 0.50 →【删除】** |
| 重标倒角 | **【工具】/【尺寸】/【智能尺寸】→【倒角尺寸】** → 选夹角 45° 的两条边 → 加 **C1、C2** |

> **★ 原文判据**：「这种**手动添加的尺寸为参考尺寸，无驱动作用**。」

**【S10】移动与改螺纹标注**：

| 步 | 操作 | 参数 |
|---|---|---|
| 1 | 拖拽尺寸 | **按住 <Shift>** 单击主视图 M8 尺寸 → **拖到左视图** |
| 2 | 改文字 | 选 M8 尺寸 → 属性管理器**【数值】** 标签 → **【标注尺寸文字】** 改为 **`5×M<DIM>-6HEQS`** |
| 3 | 改引线 | 切到**【引线】** 选项卡 → 选**【直径】** 标注方法 |
| 4 | 加直径 | 添加 **φ48** 尺寸与标准 M8 孔的中心圆 |

### 阶段 D：注解与公差（S11–S16）

| 步 | 操作 | 路径 / 参数 |
|---|---|---|
| **S11** | 添加其他注解 | **【插入】/【注解】** 下加**基准**和**表面粗糙度** |
| **S12** | **加公差** | 单击 **φ15** 尺寸 → **【公差/精度】选【双边】** → **正值 0.03、负值 0.00** → 其他默认 |
| **S13** | 添加技术条件 | **【插入】/【注解】/【注释】** → 输入技术要求 |

**S13 技术条件原文内容**：
```

1.零件无铸造缺陷。
2.去锐边去毛刺，未注圆角为R2。
```

**【公差/精度】对话框（S12）**：

| 选项 | 默认值 | **本书取值** |
|---|---|---|
| 【公差类型】 | 无 | **【双边】** |
| 【最大偏差】 | — | **0.03** |
| 【最小偏差】 | — | **0.00** |
| 其他 | — | **默认** |

| 步 | 操作 |
|---|---|
| **S14** | 插入材料明细表（装配图时用）：**【插入】/【表格】/【材料明细表】** → 选一个视图 |
| **S15** | 自动零件序号：**【插入】/【注解】/【自动零件序号】** |
| **S16** | **【判定】** 保存并检查：**驱动尺寸（导入）与参考尺寸（手标）是否混淆** |

## 失败模式（F-06）

| 编号 | 现象 | 根因 | 处置（含路径） | 页 |
|---|---|---|---|---|
| F-06-01 | **改工程图尺寸，模型跟着变了** | 用的是【模型项目】导入的**驱动尺寸** | 需要说明性尺寸时改用**【智能尺寸】** 手标（参考尺寸） | p155 |
| F-06-02 | 视图太小、图面空一半 | 默认比例偏小 | **右击图纸空白 →【属性】** → 改 **1:1** | p152 |
| F-06-03 | 剖面方向反了 | 剖切线方向 | 单击剖面视图 → **属性管理器【反转方向】** | p154 |
| F-06-04 | 剖切线画不出来/位置不对 | 三点位置错 | **第一点在轮廓外，第二、三点落在要剖的圆心上** | p154 |
| F-06-05 | 导入的尺寸乱七八糟 | 没有自动排列 | **框选所有尺寸 → 右击 →【对齐】/【自动排列】** | p155 |
| F-06-06 | 导入的倒角尺寸不合标准 | 【模型项目】导入的显示方式不规范 | **删除后用【智能尺寸】/【倒角尺寸】** 手标 | p155 |
| F-06-07 | 满图都是 R2 尺寸 | 圆角太多 | **删掉所有 R2**，在**技术条件**里写"未注圆角 R2" | p155 |
| F-06-08 | 螺纹标注显示成 M8 单个 | 没改标注文字 | 【数值】→**【标注尺寸文字】** 改 **`5×M<DIM>-6HEQS`** | p156 |
| F-06-09 | 螺纹引线样式不对 | 没选直径 | **【引线】选项卡 →【直径】** | p156 |
| F-06-10 | 材料密度加成 7.28 之类 | 单位看错 | 填 **7280 kg/m³** | p151 |
| F-06-11 | 插入【模型项目】只导入了一个视图的尺寸 | 没勾【将项目输入到所有视图】 | 勾选该项，【来源】改**【整个模型】** | p155 |
| F-06-12 | 想在工程图改某个视图的比例，改了图纸比例 | 改错层级 | **单击该视图**，在**左侧属性管理器**改视图比例 | p154 |
| F-06-13 | 找不到【模型视图】按钮 | 工具栏没显示 | **【视图】/【工具栏】/【视图布局】** 勾选 | p152 |
