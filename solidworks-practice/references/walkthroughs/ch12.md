# 第 12 章逐步清单（可照做版）

> PDF p231–244（书内 p222–235）。本章只讲 **SOLIDWORKS Simulation 静力分析**的常用功能。
> **操作约定**：命令写全菜单路径；对话框列选项/默认值/本书取值；原书简写补全标 **（补全）**。

## 核心要点：三组假设（必须先确认）

### 静态假设（原文 p232）

> 所有载荷被**缓慢且逐渐加载**，直到达到完全量值。达到后**载荷保持不变**（不随时间变化）。
> 由于加速度和速度很小可忽略，因此**允许忽略惯性和阻尼力**。
> 引起相当大的惯性和（或）阻尼力的随时间变化的载荷**可以使用动态分析**。

### 线性假设（四条，原文 p232）

| # | 内容 |
|---|---|
| 1 | **载荷和所引起的反应之间的关系是线性的** |
| 2 | **模型中的所有材料均符合虎克定律**（应力与应变成正比） |
| 3 | **负载所引起的位移足够小**，可忽略由加载所造成的刚度变化 |
| 4 | **在应用载荷的过程中，边界条件不会改变**——载荷的大小、方向和分布必须固定不变；当模型发生变形时不应改变 |

> **原书的处理办法**：「将实际工作的情况**简化为最危险时的最大静态力**，此时的计算结果**偏于安全**，且符合静态假设。」

## 三类分析工具（p231）

| 工具 | 能力（原文） |
|---|---|
| **SOLIDWORKS Simulation** | 静力、频率、屈曲、热力、跌落测试、压力容器、疲劳、非线性、线性动态 |
| **SOLIDWORKS Flow Simulation** | 流场分析，含**电子散热**与**通风采暖**模块 |
| **SOLIDWORKS Plastics** | **模流分析** |

## E03　设计改进（p236–240，16 步）★ 含网格精度判据

> **★ S07 网格收敛判据（原文 p238）**：
> 「原理上**网格越小，精度越高，但计算时间会越长**。
> **如果提高一次网格数量，相应的应力值变化在 5% 范围内，一般就可以接受了，不必再次提高网格数量。**」
> **这是"何时停止加密网格"的客观标准，不是凭感觉。**

> **★ S06 的半半径规则**：网格尺寸取**圆角半径的一半**——原文用实例示范的做法。

> **★ S08 的目标值**：原文明确"目标控制应力 **≤ 350 MPa**"。

## E04　设计优化（p240–243，11 步）

| 步 | 操作 | 路径 / 参数 |
|---|---|---|
| **S01** | 生成设计算例 | **【算例】标签右击 →【生成新设计算例】** → 出现"设计算例1" |
| **S02** | 理解三要素 | **变量**：可改尺寸（壁厚、孔径、圆角半径）；**约束**：应力/挠度/频率的合理范围；**目标**：优化最终目的（最小质量/体积/频率，或最大频率/扭曲）——**一个优化算例只能设一个目标** |
| **S03** | 设目标 | **右击【目标】→【添加】** → **【传感器类型】=【质量属性】** → 确定 → 目标：**零件质量最小化** |
| **S04** | 加变量"筋厚度" | **【变量】下拉 →【添加参数】** → **图形视图里所有尺寸自动显示** → 选 **8mm** → 填名称"筋厚度" |
| **S05** | 加变量"间距1" | 同法选 **15mm** → 名称"间距1" |
| **S06** | 加变量"圆角" | 同法选 **3mm** → 名称"圆角" |
| **S07** | 设参数范围 | "筋厚度"最小 **8mm**、最大 **10mm**、每次递增 **1mm** → **共 3 种**；3 个变量状况数相乘 **共 24 种** |
| **S08** | **删变量以减算量** | **右击"间距1"→【删除】**。原文括注：**可以根据电脑性能和时间安排添加或减少变量** |
| **S09** | **加约束传感器** | **【约束】下拉 →【添加传感器】** → 见对话框 |
| **S10** | 设约束范围 | 选 **"应力1"为基础算例** → 下拉选**【小于】** → 输入 **350 N/mm² (MPa)** 作为【最大】 |
| **S11** | 运行 | **勾【优化】→【运行】** → 计算 **12 个活动状况 + 当前、初始两个 = 14 个算例** → **整个计算时间会比较长** |
| **S12** | 读结果 | 完成后**单击【优化（10）】，模型会自动更改为优化后的尺寸** |

**【添加传感器】对话框（S09）**：

| 选项组 | 选项 | **本书取值** |
|---|---|---|
| **【传感器类型】** | 下拉 | **【Simulation 数据】** |
| **【数据量】** | 下拉 | **【应力】** + **【VON: von Mises 应力】** |
| **【属性】** 单位 | — | **N/mm²(MPa)** |
| **【准则】** | 下拉 | **【模型最大值】** |
| **【步长准则】** | 下拉 | **【通过所有步长】** |

> **★ S12 后面的关键结论（原文 p243）**：
> 「对比最后的结果可以看到，**实际上筋厚度没有圆角对最大应力的影响显著**，
> 然而**这两个变量又对最终目标"零件质量"影响不是很大**。
> 有兴趣和时间的同学可以**去掉"筋厚度"变量，添加拉伸切除特征的几个尺寸作为变量**，以达到最终缩减产品质量的目的。」

> **这条是全书唯一"优化结果不符合预期并解释为什么"的段落**：
> **变量选不对，优化跑得再久也没意义。判据是"变量对该目标是否敏感"。**
