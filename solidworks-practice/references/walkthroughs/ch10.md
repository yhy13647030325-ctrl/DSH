## 核心要点：三类算例（p206）

| 类型 | 能力（原文） |
|---|---|
| **动画** | 包括①**通过关键帧之间的插值**模拟动画 ②**用马达驱动**装配体生成动画 |
| **基本运动** | 在装配体上模仿**马达、弹簧、接触以及引力**，**并考虑质量** |
| **Motion 分析** | 精确模拟分析运动单元效果（**力、弹簧、阻尼、摩擦**），考虑**材料属性、质量及惯性**，还可生成**运动、动力图表、轨迹** |

**打开方式（p206）**：
> 打开装配体后在界面**左下角**看到 **"动画1"** 标签，单击进入动画编辑。
> 如果看不到，**在菜单【视图】中勾选【MotionManager】**。

## 动画中可控制项（p208）

> 除**马达、力、弹簧、接触、引力**外，以下都可作为控制项：
> 零部件的**显示、隐藏**与否，**装配体配合关系、光源、视图及相机视图**，零部件的**移动、爆炸、外观**，**装配体特征**等。

### 五种插值模式（p210 原文全量）

| 模式 | 行为 |
|---|---|
| **【线性】** | 零部件以**匀速**从位置 A 移到位置 B |
| **【捕捉】** | 零部件从位置 A **突变**到位置 B |
| **【渐入】** | **开始匀速移动，但随后会朝着位置 B 方向加速** |
| **【渐出】** | **一开始加速移动，但当快接近位置 B 时减速** |
| **【渐入/渐出】** | 结合【渐入】和【渐出】两种模式 |

### 保存动画的参数（p211 原文）

| 参数 | 关键值（原文） |
|---|---|
| **渲染器** | PhotoView360 打开时可选用 **PhotoView 渲染器**（逼真但**耗费时间会比较长**） |
| **图像大小** | 可自定义分辨率，也可选软件提供的**常用高宽比** |
| **每秒的画面（帧率）** | **人眼所能分辨的帧数为 24 帧**，过大无实际意义；**最小的帧数为 8 帧**，低于此值动画不够平滑连贯 |
| **时间范围** | 默认渲染到总时长，也可**自定义** |

## E04　动态剖切（p215–218，10 步）★ 最绕的一个

| **S03** | 选草图平面 | 图形区**单击曲面实体** → **【草图绘制】** |
| **S04** | 转换实体引用 | 进"编辑草图"状态 → **【工具】/【草图工具】/【转换实体引用】** → **选高亮边线** |

| **S07** | 5 秒处拖近 | 切**【动画】** 标签 → 时间滑条 **5 秒** → 把控制零件**拖到离装配体比较近** → 自动加关键帧 |
| **S08** | 10 秒处拖远 | 滑条 **10 秒** → 拖**比较远** → 自动加关键帧 |
