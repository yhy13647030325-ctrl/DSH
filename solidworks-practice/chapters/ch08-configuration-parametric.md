# 第 8 章：参数化设计基础

> 对应原书第 8 章（正文 p164–177）。

## 核心要点

**参数化设计 = 把模型中的定量信息变量化**，成为可任意调整的参数；给不同数值就得到不同大小和形状的零件。**配置（Configuration）** 是在单一文件里生成多个设计变化的机制。

> 原书提示：第 8.2.2 的系列零件设计表**需要 Microsoft Excel 支持**。

## 配置能做什么（三种文档中的用途）

| 文档 | 配置的作用 |
|---|---|
| 零件 | 生成具有不同尺寸、特征、属性（含自定义属性）的**系列零件** |
| 装配体 | 通过**压缩零部件**生成简化设计 |
| 装配体 | 用不同零部件配置、不同装配体特征参数、不同尺寸，配置出特定自定义属性的装配体系列 |

## 8.2.1 手动添加零件配置（实例：套筒扳手）

已知 A=24 B=16.7 C=3.65（圆角）D=11 E=7，未注倒角 C0.5，1060 铝。

### 建模骨架（13 步）

1. 用 **gb_part** 模板新建，单位 MMGS
2. 前视基准面草图1：原点为中心、φ24 圆
3. 拉伸凸台：给定深度 15
4. 草图2：同一平面 φ16.7 圆
5. 拉伸凸台：给定深度 10，**勾【合并结果】**
6. **圆角1**：手工 / 等半径 / R3.65
7. 草图3：中心在原点、边长 11 的正六边形，一条边加【水平】
8. 拉伸切除：给定深度 7
9. 草图4：中心在原点五边形，智能尺寸标**内切圆直径 15**，一条边加【水平】
10. 拉伸切除：给定深度 12
11. **倒角1**：角度距离 / 距离 0.5 / 角度 45° / 选 3 条边线
12. 编辑材料 1060 铝
13. 保存

### 配置操作（14 步关键部分）

| 步骤 | 动作 | 要点 |
|---|---|---|
| 13 | 激活 **ConfigurationManager** | 与 FeatureManager 在同一工具栏，点按钮切换 |
| 14 | 右击【默认[套筒扳手]】→【属性】 | 把【配置名称】和【说明】改成大写 **A** |
| 15 | 显示尺寸名称 | 【视图】>【尺寸名称】。**格式固定为 `Dx@草图n`** |
| 16 | 显示特征尺寸 | 开 **Instant3D**，设计树右击【注解】→【显示特征尺寸】 |
| 17 | 添加新配置 | 右击草图1 的 "φ24" 尺寸 →【配置尺寸】→ 在【修改配置】对话框双击"生成新配置"输入 **B**，回车；再依次输 C、D、E |
| 18–21 | 往对话框添加其它尺寸 | 双击草图4 的 D1、圆角1 的 D1、草图3 的 D1、切除-拉伸1 的 D1，逐个加入对话框 |
| 22 | 修改各配置尺寸值 | 按书中表格填 |
| 23 | 保存表格 | 【输入名称】输"**规格**" →【保存】→【确定】 |
| 24 | 查看配置 | CommandManager 点【配置】按钮预览，**双击激活查看** |
| 25 | 显示表格 | 右击【规格】表格 →【显示表格】→ 可整体改所有配置尺寸 |

> **本质：把尺寸从"一个值"变成"一张表的一列"**。手工方式就是逐个尺寸调出【配置尺寸】对话框，把配置名当作新行。

## 8.2.2 自动添加零件配置：系列零件设计表（实例：Wrench）

已知 A=80 B=12 C=10 D=8 E=10（半径）F=9（半径）G=5，未注圆角 R1、未注倒角 C1，1060 铝。

### 建模骨架

| 步骤 | 动作 | 要点 |
|---|---|---|
| 1 | 凸台-拉伸1 | 上视基准面草图，**两侧对称**，深度 5 |
| 2 | 倒角1 | 选**所有正六边形边线（共 24 根）**，距离 1，角度 45° |
| 3 | 圆角1 | **FilletXpert** → 选一条边线后**不要移动光标** → 关联工具栏【相连，11 边线】→ R1 |
| 4 | 草图2 | 上视基准面，画两根**构造线** → 【文字】工具输入 "SolidWorks" → 取消勾【使用文档字体】→ 字体设"汉仪长仿宋体、常规、四号"，间距 1.50mm |
| 5 | **包覆1** | 【插入】>【特征】>【包覆】 |
| 6 | 插入设计表 | 【插入】>【表格】>【设计表】，选默认设置 |
| 7 | 添加尺寸 | 弹【尺寸】对话框 → **按住 Ctrl 选 6 个尺寸** → 确定 |
| 8 | 退出表格编辑 | 点空白处 |
| 9 | 单独窗口编辑 | 右击【系列零件设计表】→【在单独窗口中编辑表格】→【添加行和列】点确定 → 出现 Excel 表格 |
| 10 | 修正文字显示 | **右击最左上角单元格 →【设置单元格格式】→【常规】**，所有尺寸文字变回数字 |
| 11 | 补加漏掉的尺寸 G | 先开 Instant3D → 选中 Excel 的 **H2** 单元格 → 点设计树【凸台-拉伸1】→ 在图形界面**双击尺寸 G**，即写入 H2 |
| 12 | 添加更多配置 | 再次【在单独窗口中编辑表格】填内容 → 保存关闭 |
| 13–14 | 完成 | 关闭后提示已添加配置；ConfigurationManager 中双击或【显示配置】查看 |
| 15–16 | 材料 + 保存 | — |

### 三个"只有踩过才知道"的细节

1. **单元格格式必须是"常规"**，否则 Excel 把尺寸名当文本，整表失效
2. **漏尺寸的补法**：选中目标单元格 → 在图形区双击该尺寸，一步到位（不必重新插表）
3. **圆角专家 + 包覆**是这题的两个关键工具，前面章节都出现过

## 配置的两种做法对比

| | 手动添加（配置尺寸） | 系列零件设计表（Excel） |
|---|---|---|
| 入口 | 右击尺寸 →【配置尺寸】 | 【插入】>【表格】>【设计表】 |
| 适用规模 | 少量配置、少量尺寸 | 多配置、多尺寸、需要批量维护 |
| 依赖 | 无 | **需要 Excel** |
| 优点 | 直观、不用 Excel | 一表看全、易批量改、可外部维护 |
| 缺点 | 尺寸多了要一个个加 | 有 Excel 格式坑 |
| 共同前提 | **先显示尺寸名称/特征尺寸** | 同左 |

## 高频失败模式与对策

| 现象 | 原因 | 对策 |
|---|---|---|
| 【配置尺寸】找不到 | 尺寸名称没显示 | 【视图】>【尺寸名称】；或开 Instant3D 显示特征尺寸 |
| 新配置加进去尺寸没变 | 只加了行没填值 | 在【修改配置】对话框逐列填 |
| Excel 表里全是文字不是数字 | 单元格格式为文本 | 左上角单元格→【设置单元格格式】→【常规】 |
| 设计表里缺某个尺寸 | 建表时没选全 | 选中空白单元格 → 图形区双击该尺寸补入 |
| 切换配置模型不变 | 当前配置没激活 | 双击配置名，或右击【显示配置】 |
| 装配体配置起不到简化作用 | 没压缩零部件 | 装配体配置靠**压缩零部件**实现简化 |
