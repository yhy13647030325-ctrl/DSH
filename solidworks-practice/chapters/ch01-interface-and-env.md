## 1.1 ★★★ 步骤组 A：确认软件版本与三大技术基础（p001–p002）

**★★★★★ 为什么先做这一步**：知道软件"基于什么内核"，才能理解它"为什么这样操作"。

> **原文（p001）**：
> 「**SolidWorks 基于 Parasolid 内核、Windows 平台、特征建模**。」

### 步骤 A1：核对软件版本

1. 启动 SolidWorks。
2. 点击 **【帮助】→【关于 SolidWorks】**。
3. 记录**主版本号**（如 2023 / 2024 / 2025）——**后续所有菜单路径与此有关**。

> **★★ 判据**：版本不同 → 菜单位置可能不同。**照抄别人的步骤前，先确认版本一致。**

### 步骤 A2：理解三大技术基础（不用操作，读一遍）

> **原文（p001）的三大基础**：

| # | 基础 | 含义 |
|---|---|---|
| **★ 1** | **★ Parasolid 内核** | **实体建模的数学内核**（与 NX、Solid Edge 同源） |
| **★ 2** | **★ Windows 平台** | **界面是原生 Windows**（所以菜单/对话框符合 Windows 习惯） |
| **★ 3** | **★ 特征建模** | **模型由"特征"按历史顺序堆叠**（所以有 FeatureManager 设计树） |

> **★★★ 判据**：**这三条解释了后面所有操作** ——
> **① 内核统一 → 曲面与实体可互转**（见曲面技能）；
> **② Windows 原生 → 右键菜单/拖拽都通用**；
> **③ 特征建模 → 改前面的特征会影响后面的特征**（所以有"回退控制条"）。

## 1.2 ★★★★ 步骤组 B：新建文件并认识三种文档（p002）

**★★★★★ 为什么**：三种文档（零件/装配体/工程图）的界面与权限完全不同，**建错类型要重来**。

### 步骤 B1：新建零件

1. 点击 **【文件】→【新建】**（或 **`Ctrl+N`**）。
2. 在弹出的对话框中选 **【零件】**。
3. 点击 **【确定】**。
4. **确认单位**（见步骤 C2）——**每次新建零件都要确认**。

> **★★★ 判据**：**单位是"文档属性"** → **不随系统设置，随文件走**。
> **所以新建后不确认单位，尺寸可能全错。**

### 步骤 B2：认识三种文档的差别

> **原文（p002–p008）**：

| 文档类型 | 扩展名 | 主要用途 | 关键界面 |
|---|---|---|---|
| **★ 零件** | **`.SLDPRT`** | **单个零件建模** | **FeatureManager 设计树 + 3 个基准面** |
| **★ 装配体** | **`.SLDASM`** | **多个零件组合** | **设计树 + 配合文件夹** |
| **★ 工程图** | **`.SLDDRW`** | **出二维图纸** | **图纸 + 视图调色板** |

> **★★ 判据**：**三种文档的"设计树根节点"不同** ——
> **零件是"零件名"，装配体是"装配体名"，工程图是"图纸名"。**
> **看错根节点 = 在建错的文件里操作。**

### 步骤 B3：认识 13 个界面部件（p002–p008）

> **原文列举的 13 个部件**（按屏幕位置）：

| # | 部件 | 位置 | 作用 |
|---|---|---|---|
| **★ 1** | **菜单栏** | 顶部 | 全部命令 |
| **★ 2** | **CommandManager** | 顶部（工具栏区） | **按情境切换的标签工具栏** |
| **★ 3** | **前导视图工具栏** | 绘图区上方 | **视图操作**（缩放/剖面/显示样式） |
| **★ 4** | **FeatureManager 设计树** | 左侧 | **特征历史顺序** |
| **★ 5** | **PropertyManager** | 左侧（与设计树同区） | **当前命令的参数面板** |
| **★ 6** | **ConfigurationManager** | 左侧标签 | 配置管理 |
| **★ 7** | **图形区域** | 中央 | 建模区 |
| **★ 8** | **任务窗格** | 右侧 | 设计库/资源 |
| **★ 9** | **状态栏** | 底部 | 提示与坐标 |
| **★ 10** | **Heads-up 视图工具栏** | 绘图区（浮动） | 视图快捷按钮 |
| **★ 11** | **快捷菜单** | 右键弹出 | 情境命令 |
| **★ 12** | **确认角** | 左上角 | **打勾确认 / 打叉取消** |
| **★ 13** | **参考三重轴** | 左下角 | 显示当前朝向 |

> **★★★ 判据：第 12 项"确认角"最容易被忽略** ——
> **它决定"命令是执行了还是取消了"。**
> **草图/特征做到一半，眼睛要习惯看一眼左上角。**

## 1.3 ★★★★★ 步骤组 C：设定基本环境（p009–p013，本章最重要）

**★★★★★ 为什么最重要**：**环境设错，后面所有文件都受影响**（且不自知）。

### 步骤 C1：打开环境设置对话框

1. 点击 **【工具】→【选项】**（部分版本为【工具】→【系统选项】）。
2. 弹出 **【系统选项 - 普通】** 对话框。
3. 左侧是**页签列表**（10 个），右侧是**当前页签的选项**。

> **原文（p009）**：
> 「在【工具】菜单中，**【系统选项（S）-普通】对话框允许用户自定义 SolidWorks 的基本环境**，
> 例如**绘图标准、个人习惯**等。」

### 步骤 C2：★ 判断"这个选项该不该改"（核心决策）

> **原文（p009）的三条硬规则**：

| # | 规则 | 含义 |
|---|---|---|
| **★ ①** | **影响所有文档** | **改一次，这台机器上所有文件都变** |
| **★ ②** | **换台电脑就不同** | **不随文件走** |
| **★ ③** | **建议默认值不要改** | **默认值经过验证** |

**★★★★★ 判据：先问一句话再动手** ——
> **"这个改动是'我在这台机器上的习惯'，还是'这个文件的标准'？"**
> **★ 前者 → 系统选项；后者 → 文档属性。**
> **★ 都不是 → 不改。**

### 步骤 C3：认识 10 个系统选项页签（按需修改）

> **原文（p010–p012）的 10 个页签**：

| # | 页签 | 关键作用 | 什么时候要动 |
|---|---|---|---|
| **★ 1** | **普通** | **绘图标准、个人习惯** | 少动 |
| **★ 2** | **草图** | 草图默认行为 | 改"过定义时提示"等 |
| **★ 3** | **几何关系/捕捉** | **自动捕捉开关** | **画草图不顺手时查这里** |
| **★ 4** | **显示/选择** | 颜色、选择方式 | 少动 |
| **★ 5** | **性能** | **大模型流畅度** | **模型卡顿时调这里** |
| **★ 6** | **装配体** | 装配默认行为 | 少动 |
| **★ 7** | **外部参考引用** | 关联设计的加载方式 | **做自顶向下设计时必查** |
| **★ 8** | **默认模板** | **新建时用哪个模板** | **新建报错时第一个查这里** |
| **★ 9** | **文件位置** | 模板/设计库路径 | 迁移电脑时查 |
| **★ 10** | **异型孔向导/Toolbox** | **标准件库路径** | **螺钉找不到时查这里** |

> **★★★ 判据：两个"最常出问题"的页签** ——
> **★ 第 8（默认模板）：模板丢了 → 新建文件报错。**
> **★ 第 10（Toolbox 路径）：路径丢了 → 标准件（螺钉）找不到**（详见 ch05）。

### 步骤 C4：★ 区分"系统选项"与"文档属性"（最容易搞混）

> **原文（p012）**：
> 「**文档属性中的设置可以应用到每一个文档中。**
> 例如**【绘图标准】、【单位】等一些设置可以随文档一起保存，
> 不会因为文档在不同的系统环境下打开而发生更改**。」

**★★★★★ 对照表（背下来）**：

| 项 | **系统选项** | **文档属性** |
|---|---|---|
| **★ 影响范围** | **所有文档** | **当前文档** |
| **★ 是否随文件走** | **不随**（存本机） | **随文件走** |
| **★ 典型内容** | 背景色、显示、性能 | **绘图标准、单位** |
| **★ 企业做法** | 各人自定 | **统一模板，不改** |

> **★★★ 判据：一句话记住** ——
> **"换个电脑"看系统选项，"换个文件"看文档属性。**
>
> **★ 单位的坑**：**单位是文档属性** →
> **同一个零件在别人机器上量出来数值一样**（好）；
> **但显示的颜色可能不一样**（系统选项）。

**步骤 C4a：设置单位（每次新建零件都要做）**
1. 新建或打开零件。
2. 点击 **【工具】→【选项】→【文档属性】** 标签。
3. 选择 **【单位】**。
4. 选 **【MMGS】**（毫米、克、秒）——**本书所有示例都用 MMGS**。
5. 点击 **【确定】**。

**步骤 C4b：设置图像品质（影响性能与外观）**
1. **【工具】→【选项】→【文档属性】→【图像品质】**。
2. 拖动**滑块**：向左（低）→ 流畅但粗糙；向右（高）→ 精细但卡顿。
3. 一般默认位置即可；**大模型卡顿时向左调**。

> **★ 企业实践（原文 p012）**：
> 「一般在企业中，**文档属性的一些选项都已定义好，所有员工使用统一的模板，不需要修改**，
> 而且**企业的设计文件标准统一，便于管理**。」

### 步骤 C5：★ 恢复出厂设置（改坏了怎么办）

> **原文（p009）**：
> 「修改之后如果想恢复，可以在【系统选项】中选择**【重设】，恢复 SolidWorks 出厂设置。**」

1. **【工具】→【选项】→【系统选项】**。
2. 点击左下角 **【重设】**。
3. 确认后 → **所有系统选项回到出厂值**（文档属性不受影响）。

> **★★★ 判据**：**"重设"只影响系统选项，不动文件本身** ——
> **所以文件里的单位、绘图标准不会丢。**

## 1.4 ★★★★★ 步骤组 D：鼠标三键与视图操作（p013）

**★★★★★ 为什么**：**后面 90% 的操作都靠"看模型"**，而看模型全靠中键。

> **原文（p013）**：
> 「在 SolidWorks 中，**鼠标的左、中、右键有着完全不同的意义。**
> **左键：用于选择对象**，如几何体、菜单按钮和 FeatureManager 设计树中的内容。
> **中键：用于动态地旋转、平移和缩放**零件或装配体，平移工程图。
> **右键：用于激活关联的快捷键菜单。**」

### 步骤 D1：三键分工（先记住）

| 键 | 作用 |
|---|---|
| **★ 左键** | **选择对象** |
| **★ 中键** | **旋转/平移/缩放（视图操作）** |
| **★ 右键** | **关联快捷菜单** |

### 步骤 D2：★ 四种视图操作（表 1-1 完整）

| # | 操作 | 按键方法 |
|---|---|---|
| **★ 1** | **旋转视图** | **按住中键，拖动** |
| **★ 2** | **平移视图** | **`Ctrl` + 中键，拖动** |
| **★ 3** | **缩放视图（连续）** | **`Shift` + 中键，前拖放大 / 后拖缩小** |
| **★ 4** | **缩放视图（分步）** | **旋转滚轮**（前滚放大、后滚缩小） |

**★★★★★ 记忆法（四句口诀）** ：
```
中键单独   → 转（旋转）
Ctrl+中键  → 移（平移）
Shift+中键 → 缩（缩放，连续）
滚轮       → 缩（缩放，分步）
```

> **★★ 判据**：**"缩放"有两种方式** ——
> **`Shift`+中键是"连续拖"（适合精细调整），滚轮是"分步跳"（适合快速接近）。**

### 步骤 D3：练习（建议 3 分钟）

1. 新建零件 → 画一个矩形 → 拉伸成方块。
2. 用**中键拖动**转一圈。
3. 用 **`Ctrl`+中键**平移到屏幕角落。
4. 用 **`Shift`+中键**前拖放大。
5. 用**滚轮**后滚缩小。
6. **目标：不看键盘就能完成"转-移-缩"。**

> **★★★ 判据**：**这一步没过，后面所有章都会卡**（因为建模=反复看不同角度）。

## 1.5 ★★★★★ 步骤组 E：快捷键速查（p014）

**★★★★★ 为什么**：**视图切换用快捷键比点图标快 3–5 倍**。

> **原文（p014）**：「常用快捷键见表 1-2。」

### 步骤 E1：文件与编辑（3 个）

| 快捷键 | 功能 |
|---|---|
| **`Ctrl+O`** | 打开文件 |
| **`Ctrl+S`** | 保存文件 |
| **`Ctrl+Z`** | 撤销 |

### 步骤 E2：★ 视图旋转（四种"方向键+"）

| 快捷键 | 功能 |
|---|---|
| **方向键** | 旋转视图 |
| **`Shift`+方向键** | 旋转视图 |
| **★ `Alt`+方向键** | **绕垂直于屏幕的轴线旋转视图** |
| **`Ctrl`+方向键** | 移动视图 |

**★★★★★ 判据：`Alt`+方向键最特殊** ——
> **它是"绕屏幕法线转"（相当于在屏幕平面内旋转）。**
> **其他三种都是"绕模型轴转"。**

### 步骤 E3：★ 标准视图（`Ctrl+1`~`8`，八个方向）

**★★★★★ 这八个键最值得背** ——

| 快捷键 | 视图 |
|---|---|
| **`Ctrl+1`** | **前视** |
| **`Ctrl+2`** | **后视** |
| **`Ctrl+3`** | **左视** |
| **`Ctrl+4`** | **右视** |
| **`Ctrl+5`** | **上视** |
| **`Ctrl+6`** | **下视** |
| **`Ctrl+7`** | **等轴测** |
| **`Ctrl+8`** | **正视于**（把选中面转正） |

> **★★★ 判据：`Ctrl+8` 是建模中使用频率最高的一个** ——
> **因为"在某个面上画草图"必须先"正视于"该面。**
> **★ 记忆**：`Ctrl+8` = "面对它"（正面朝向）。

### 步骤 E4：练习（建议 2 分钟）

1. 用 `Ctrl+1`~`6` 依次切换六个标准视图。
2. 用 `Ctrl+7` 回到等轴测。
3. 选中一个面 → 按 `Ctrl+8` → **确认该面正对屏幕**。
