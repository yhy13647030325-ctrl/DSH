# 第 1 章：软件介绍与基本环境

> 对应原书第 1 章（正文 p1–14）。

## 核心要点

SOLIDWORKS 是**基于特征 + 参数化**的三维 CAD，界面是标准 Windows 程序。真正要好用的是三处结构：**FeatureManager 设计树**（自动记录建模顺序，可回改、可调顺序）、**PropertyManager 属性框**（与设计树同位置，激活时自动替换）、**CommandManager 命令管理器**（按任务分选项卡）。

## 界面构成（13 个部件）

| 部件 | 位置 / 触发 | 作用 |
|---|---|---|
| 菜单栏 | 鼠标移到左上角展开；末尾图钉可固定 | 几乎所有命令。带 ▸ 有子菜单，带 … 会弹对话框 |
| 前导视图工具栏 | 绘图窗口顶部居中 | 整屏显示全图、局部放大、剖面视图等；可右击【自定义】拖拽增减命令 |
| 搜索工具 | 工具栏 | 搜命令、帮助，也能搜本机/局域网/互联网文件 |
| 帮助与弹出式工具栏 | 按钮旁向下箭头 | 下拉式一组工具 |
| 任务窗格 | 界面右侧，可移动/调整/关闭/图钉固定 | SolidWorks 资源、设计库、文件探索器、视图调色板、外观、布景和贴图、自定义属性 |
| 状态栏 | 窗口最下面 | 提示当前操作状态与步骤（例："草图已完全定义"） |
| 快捷栏（S 工具栏） | 按 **S** 键 | 按当前环境（零件/装配/工程图/草图）弹出不同命令 |
| 文件窗口与图形区域 | — | 多窗口，可同时开多个文件 |
| 左侧区域 | 文件窗口左侧 | FeatureManager、PropertyManager、ConfigurationManager、DimXpertManager、插件管理器，顶部按钮切换 |
| 关联工具栏 | 选中对象时自动弹出，移开自动隐藏 | 针对所选对象的快捷操作 |
| CommandManager | 工具栏区 | 按选项卡分组（草图、特征等）；右击任一选项卡可增删 |

## 系统选项 vs 文档属性（最容易搞混的一对）

| | 系统选项 | 文档属性 |
|---|---|---|
| 影响范围 | **本机所有文档**（包括别人发来的文件） | **仅当前文档**，随文件保存 |
| 典型内容 | 背景颜色、显示/选择、性能、装配体、外部参考引用、默认模板、文件位置 | 绘图标准、单位、图像品质 |
| 换机器会变吗 | **会**（同文件在不同电脑显示不同） | 不会 |
| 建议 | **默认值不要改**；改了可【重设】恢复出厂 | 企业里统一由模板定义，员工不改 |

> 原书提醒：企业一般把文档属性写进统一模板，保证文件标准统一、便于管理。

## 鼠标三键（含义完全不同）

| 键 | 用途 |
|---|---|
| 左键 | 选择对象：几何体、菜单按钮、设计树内容 |
| 中键 | **旋转**：按住拖动即自由旋转 |
| 中键 + Ctrl | **平移** |
| 中键 + Shift | **缩放**（前后拖动）；或滚轮前后滚动 |
| 右键 | 激活关联快捷菜单 |

## 文件操作与三种文档类型

- 启动 / 退出：开始菜单或桌面快捷方式；【文件】>【退出】
- 打开：双击文件（未启动时会自动启动再打开）；或【文件】>【打开】，并列出最近文件
- 新建：【文件】>【新建】，三种设计模式——**零件 / 装配体 / 工程图**；左下角【高级】可选自定义模板
- 另存副本：【文件】>【另存为】

| 类型 | 扩展名 | 模板扩展名 |
|---|---|---|
| 零件 | `*.sldprt` | `*.prtdot` |
| 装配体 | `*.sldasm` | `*.asmdot` |
| 工程图 | `*.slddrw` | `*.drwdot` |

## 设计树可见性三档

【工具】>【选项】>【系统选项】>【FeatureManager】：

- **自动**：项目存在就显示，否则隐藏
- **显示**：始终显示
- **隐藏**：始终隐藏

默认只有【注解】文件夹一直显示。

## 应用提示（提炼）

1. **改设置要分清层**：影响全机的去系统选项，跟文件走的进文档属性；团队协作只改模板不改系统选项。
2. **S 键是效率核心**：不用找工具栏，按环境弹出最常用命令。
3. **设计树是唯一真相**：模型出问题先看特征顺序和父子关系，不要在图形区瞎点。
4. **Ctrl+1..8 背下来**：出图、看内部结构、判断朝向全靠这八个视角。
