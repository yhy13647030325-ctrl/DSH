# 第 5 章：标准件库

> 对应原书第 5 章（正文 p126–136）。

## 核心要点

标准件库分两条路：**【Toolbox】= 本地资源**，**【3DContentCentral】= 在线资源**。装螺栓螺帽不要自己画，走 Toolbox；找不到的供应商件去 3DContentCentral 下载。

## 设计库 vs 标准件库

- **设计库**：设计中可重复使用单元的信息总和。特点是**通过标准化、系列化建立可重复使用单元，并对零部件分类、建立检索机制**。内容含常用注释、特征库、零件库、基础件库、标准件库。
- **标准件库**：为 CAD 软件提供标准件模型的插件，帮助快速创建标准件模型。按国家标准分 **GB / DIN / Ansi** 等，按种类分螺母、铆钉、焊钉等。

## 5.4 Toolbox

### 启动方式

【工具】>【插件】→ 勾选 **SolidWorks Toolbox** 与 **SolidWorks ToolboxBrowser**。

### 智能扣件（Smart Fasteners）

**前提**：装配体中包含特定规格的孔、孔系列或孔阵列。

**原理**：用 Toolbox 标准件库自动给装配体中所有可用孔特征添加扣件（螺栓/螺钉）；这些孔可以是**装配体特征**，也可以是**零件中的特征**。添加新扣件时，**扣件默认长度根据装配体中的孔而定**。

**要点**：
- 用**异型孔向导**建孔，能最大限度发挥智能扣件优势——向导给的标准尺寸与螺钉螺栓匹配
- 其他类型孔（凸台内部轮廓、拉伸切除、旋转切除）：智能扣件**根据孔的物理尺寸选一个合理直径**
- 添加扣件时**自动与孔建立重合和同轴心配合**

### 异型孔向导 / Toolbox 配置

路径：【工具】>【选项】>【系统选项】>【异型孔向导/Toolbox】→ 单击【配置】。

用来设智能扣件的**默认扣件**和**自动扣件更改**。孔若由异型孔向导或孔系列创建，扣件类型由孔标准/类型/扣件决定。

### 实例：Electricmotor 加智能扣件（18 步）

| 步骤 | 动作 | 要点 |
|---|---|---|
| 1 | 打开已配好配合的装配体 | — |
| 2 | 【装配体特征】→【异型孔向导】 | — |
| 3 | 设【孔类型】参数 | **【特征范围】选【所选零部件】** → 选零部件 → **勾【将特征传播到零件】** |
| 4 | 设孔位置 | 单击【位置】→ 选平面画草图（**不需要点【3D 草图】按钮**）→ 完全定义 |
| 5 | 单击【智能扣件】 | 没开 Toolbox 插件会弹提示 |
| 6 | 加载 Toolbox | 任务窗格【设计库】→【Toolbox】；未开启时提示框里点"现在插入" |
| 7 | 再次【智能扣件】→ 确定 | — |
| 8 | 属性框单击**【增添所有】** | 【结果】看型号；【系列零部件】可设是否自动调整到孔直径/长度、是否加【顶部层叠】【底部层叠】；【属性】可改大小、长度、显示、备注 |
| 9 | 查看结果 | 设计树出现步骤名 |
| 10–12 | 打开零件"Central" | 可见**柱形沉头孔已被添加到零件模型中**（因为第 3 步勾了传播） |
| 13–17 | 手动加螺母 | Toolbox → Gb/螺母/六角螺母 → 拖【1型六角螺母】到螺钉柱形面上，出现光标后松开，**自动建立配合**；属性框【选项】勾【将大小自动调整到配合的几何体】；重复放置其余 3 个 |
| 18 | 保存 | 因含虚拟零部件，弹【另存为】→【内部保存】 |

> **手动拖拽也自动加配合**，配合文件夹里带**黄色五角星**标记的就是这样自动生成的。
> **【顶部层叠】/【底部层叠】** = 自动加垫圈/螺母。原书实例改用手动加螺母，是为了演示拖拽方式。

## 5.5 3DContentCentral

**是什么**：免费在线资源，可查找、配置、下载已被标准零部件制造商认可的数百万种标准零部件的 **3D 模型和 2D 工程图**。除供应商目录，还有 **28 万以上注册用户**提供的用户库；找不到时可去用户库搜；也可上传自己的模型。

### 实例：下载齿轮并装入（17 步）

| 步骤 | 动作 | 要点 |
|---|---|---|
| 2 | 任务窗格【设计库】→【3DContentCentral】 | 下分【供应商内容】【用户库】 |
| 3 | 展开【供应商内容】 | 弹使用条款 → 【接受】→ 加载【所有供应商】【所有类别】 |
| 4 | 选【所有类别】 | 点【Click here for all categories】打开网页 |
| 5 | 网页底部切【简体中文】 | — |
| 6 | 登录/注册 | 网页左上 |
| 7–8 | 搜索 | 输 "LKA-F3" → 搜索；也可用【高级搜索】 |
| 9 | 配置 | 【配置及下载】→【配置】下拉选 **LKA-F3-30** |
| 10 | 预览 | 【更新预览】→ 预览窗口点【预览 3D】 |
| 11 | 下载格式 | 【下载】→【格式】=3D → **SolidWorks Part/Assembly (*.sldpart)**；【版本】=2013 |
| 12–13 | 下载 → 解压 | 放入装配体所在文件夹 |
| 14–16 | 插入 → 加【同轴心】+【重合】 | — |
| 17 | 保存 | 【内部保存】 |

> 下载时**必须选与当前 SOLIDWORKS 版本兼容的版本号**，高版本文件低版本打不开。

## APl 课后练习（原书 5.7）

装配体 "Fan"，异型孔参数：**柱形沉头孔 / ANSI Metric / 六角螺钉 / M2 / 正常配合**；孔位置与零部件 "Stand" 的圆角边线【同轴心】；螺母 = **1 型六角螺母 GB/T 6170—2000**。

## 高频失败模式与对策

| 现象 | 原因 | 对策 |
|---|---|---|
| 【智能扣件】点了没反应 | Toolbox 插件没开 | 【工具】>【插件】勾选两个 Toolbox；或在设计库里点"现在插入" |
| 智能扣件加的螺钉长度不对 | 孔不是异型孔向导建的 | 用异型孔向导重建孔，或手动改【属性】里的长度 |
| 孔只出现在装配体里，零件里没有 | 没勾【将特征传播到零件】 | 【特征范围】→【所选零部件】时勾选 |
| 手动拖螺母不自动配合 | 拖放位置不是扣件/孔面 | 拖到螺钉柱形面或孔上，等出现配合光标再松 |
| 下载的齿轮打不开 | 版本选高了 | 重新下载并选低版本 |
| 3DContentCentral 打不开 | 需接受使用条款/登录 | 完成条款与登录 |
