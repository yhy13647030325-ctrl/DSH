# 第 12 章：分析工具

> 对应原书第 12 章（正文 p222–235）。本章只讲 SOLIDWORKS Simulation 静力分析的常用功能。

## 核心要点

早年设计靠经验简化，再用力平衡和几何关系列方程，受计算能力与理论模型限制，**简化结果和实际工况差异大**，导致产品不合理、成本与安全可靠性难兼顾。有限元技术解决了"能否改进、是否安全、可否减重、材料是否合适经济"这些问题。

## 三类分析工具（对应不同物理场）

| 工具 | 用途 |
|---|---|
| **SOLIDWORKS Simulation** | 实体分析：**静力、频率、屈曲、热力、跌落测试、压力容器、疲劳、非线性、线性动态** |
| **SOLIDWORKS Flow Simulation** | 流体/流场分析，含**电子散热**与**通风采暖**模块 |
| **SOLIDWORKS Plastics** | 面向塑件与模具设计工程师的**模流分析** |

打开方式：【工具】>【插件】→ 勾选 SolidWorks Simulation。

## 静力分析的两组假设（必须能背）

### 静态假设

所有载荷**被缓慢且逐渐加载**，直到达到完全量值；达到后**载荷保持不变**（不随时间变化）。因为加速度和速度很小可忽略，所以**允许忽略惯性和阻尼力**。

> 随时间变化、会引起相当大惯性/阻尼力的载荷，应改用**动态分析**。

### 线性假设（四条）

1. 载荷与反应之间的关系是**线性**的
2. 所有材料均符合**虎克定律**（应力与应变成正比）
3. 载荷引起的**位移足够小**，可忽略加载造成的刚度变化
4. 应用载荷过程中**边界条件不改变**——载荷的大小、方向、分布必须固定不变，模型变形时不应改变

> 原书的处理办法：把实际工况简化为**最危险时的最大静态力**，此时结果偏于安全，且符合静态假设。

## 实例：托架分析（完整流程）

已知：合金钢，两个孔固定，承载 **7 MPa** 压力。

| 步骤 | 动作 | 要点 |
|---|---|---|
| 1 | 打开"托架.SLDPRT" | — |
| 2 | 确认假设 | 见上两组假设 |
| 3 | **创建算例** | Simulation 标签 →【新算例】→ 类型【静态】，默认名"算例1"；可用算例标签切换 |
| 4 | **指定材料** | 建模时选过会自动导入。也可在 Simulation 中另设（**不影响设计树中的材料设定**）：右击实体 →【应用】/【编辑材料】→ 钢 →【合金钢】 |
| 5 | **固定夹具** | 右击【夹具】→【固定夹具】→ 选两个相同大小的孔 |
| 6 | **设置压力** | 右击【外部载荷】→【压力】；**单位 N/mm²(MPa)**，值 7；注意力的方向 |
| 7 | **设置网格** | 右击【网格】→【生成网格】；配置不高就用默认密度（【重设】恢复默认，取消勾【网格参数】） |
| 8 | 预览网格 | 划分完成后网格化模型显示在图形区 |
| 9 | 运行 | 【运行】或右击分析树顶端【运行】；完成后结果显示在【结果】中；把【夹具】和【外部载荷】右键【全部隐藏】 |

材料设定完成后实体上会出现一个**图标**表示已设定。

## 结果查看（6 步）

| 步骤 | 图解 | 要点 |
|---|---|---|
| 1 | **应力（von Mises）** | 应力图解附加在变形形状上；为展示变形，软件**把最大变形缩放到模型边界框对角的 10%**（本例变形比例约 **11.6**） |
| 2 | **位移（合位移）** | — |
| 3 | 保存动画 | 右击【位移】→【动画】→ 勾【保存为 AVI 文件】 |
| 4 | **应变（对等）** | — |
| 5 | **安全系数图解** | 右击【结果】→【定义安全系数图解】→ 步骤1 准则【最大 von Mises 应力】→ 步骤2【屈服力】→ 步骤3【安全系数以下的区域】，输入 1 → 红色=不安全，蓝色=安全 |
| 6 | **生成报表** | 【报表】→ 选内容、填标题、设位置 → 出版，自动生成 **Microsoft Word** 文档 |

> **变形比例 11.6 不是真实变形**，是为了看得见而放大的。读图时不要拿它换算真实位移。

## 设计改进（15 步，含网格精度判断）

前提：前面为展示安全系数故意夸大了工况；现改为**承载 3000 N** 的力重算。

| 步骤 | 动作 | 关键判据 |
|---|---|---|
| 1 | 删除"压力-1" | — |
| 2 | 设【力/扭矩】 | 右击【外部载荷】→【力】→ 选圆柱端面 |
| 3 | 改应力图解单位 | 右击【应力】→【编辑定义】→ 单位 MPa |
| 4 | 查看应力 | 应力集中最高 **477.4 MPa**，未超屈服极限；圆角半径 2mm，此处需要更小网格 |
| 5 | **应用网格控制** | 右击【网格】→【应用网格控制】→ 选四个圆角面 → **网格大小 = 圆角半径的一半 = 1.00mm** |
| 6 | 判断精度是否够 | **原理：网格越小精度越高，但计算越慢。判据：提高一档网格后应力变化在 5% 以内，即可接受，不必再加** |
| 7 | 改模型 | 目标控制应力 ≤ **350 MPa** → 圆角从 2mm 改 **3mm** → Ctrl+Q 更新 |
| 8 | 重算 | 模型变了网格要重划；局部应力**降了 100 多 MPa**——圆角对应力集中影响很大 |
| 9 | **设计洞察图解** | 右击【结果】→【定义设计洞察图解】→ 右拖"等值"滑条 → 蓝色承载区域变化 → **透明区域可简化掉** |
| 10 | 按洞察切除 | 建拉伸切除特征 |
| 11 | 加圆角 | 勾**【多半径圆角】**给不同边线不同半径过渡 |
| 12 | 重算 | 应力最大值有所提升 |
| 13 | **探测** | 右击【应力】→【探测】→ 【在位置】点应力集中区读具体值 |
| 14 | 边线探测 | 【在所选实体上】选孔上边线 → 更新 → 列出边线所有节点应力值 |
| 15 | 保存结果 | 【报告选项】里可存为**传感器**（供优化用）；【保存】存 **CSV**（Excel 可开）；【图解】看分布 |

## 设计优化（11 步）

思路：让软件自动算，而不是凭经验改敏感尺寸一次次试。

| 步骤 | 动作 | 说明 |
|---|---|---|
| 1 | 【算例】标签右击 →【生成新设计算例】 | 出现"设计算例1" |
| 2 | 认识三个概念 | **变量**：可改的尺寸（壁厚、孔径、圆角半径）；**约束**：应力/挠度/频率的合理范围（限最小/最大值）；**目标**：优化最终目的（最小质量/体积/频率，或最大频率/扭曲）——**一个优化算例只能设一个目标** |
| 3 | 设目标 | 右击【目标】→【添加】→【传感器类型】=质量属性 → 目标：**质量最小化** |
| 4 | 加变量"筋厚度" | 【变量】→【添加参数】→ 图形区所有尺寸自动显示 → 选 8mm，命名"筋厚度" |
| 5 | 加"间距1" | 选 15mm |
| 6 | 加"圆角" | 选 3mm |
| 7 | 设参数范围 | 筋厚度 8→10mm，步长 1mm，共 3 种；3 个变量相乘共 **24 种**状况 |
| 8 | 删变量 | 右击"间距1"→【删除】（按电脑性能与时间增减变量） |
| 9 | 加约束传感器 | 【约束】→【添加传感器】→【传感器类型】=Simulation 数据 → 【数据量】=应力、VON: von Mises 应力 → 单位 MPa，【准则】=模型最大值，【步长准则】=通过所有步长 |
| 10 | 设约束范围 | 选"应力1"为基础算例 →【小于】→ 输 **350 MPa**（保证任何地方 von Mises 应力不超 350） |
| 11 | 运行 | 勾【优化】→【运行】，计算 12 个活动状况 + 初始/当前共 **14 个**算例 → 完成后【优化(10)】自动应用最优尺寸 |

**本例结论（原书给出）**：**筋厚度对最大应力的影响不如圆角显著**，但这两个变量对最终目标"零件质量"影响都不大。建议去掉"筋厚度"，改加拉伸切除特征的几个尺寸作变量，才能真正减重。

2. 在练习 1 基础上：显示 **Y 方向最大位移**；以**直径 260mm** 为变量、**步长 5mm**、**质量最小化**为目标，**高亮点 Y 向位移 ≤ 1mm** 且**应力 ≤ 180 MPa** 为约束，优化设计

## 高频失败模式与对策

| 现象 | 原因 | 对策 |
|---|---|---|
| 应力值明显偏小 | 网格尺寸大于圆角半径 | 【应用网格控制】，尺寸取圆角半径一半 |
| 反复加网格但结果一直变 | 没看收敛判据 | 加密一档后变化 **<5%** 即停 |
| 结果蓝色一片、找不到危险区 | 安全系数图解未设阈值 | 设【安全系数以下的区域】=1 |
| 变形看起来夸张 | 变形比例被放大 | 知道是视觉效果即可；真实值看位移图解 |
| 夹具不够导致刚体位移 | 约束不足 | 至少约束 6 自由度（本例两个孔固定） |
| 优化跑很久 | 变量多、每次都要重划网格 | 减少变量；节点数按时间预算取舍 |
| 优化后尺寸无意义 | 变量对目标不敏感 | 先看单变量影响，只保留敏感变量 |
| Simulation 里改了材料，模型树没变 | 设计树材料与算例材料是两套 | 需要统一时两边都改 |
