# 第 2 章：草图

> 对应原书第 2 章（正文 p15–48）。草图是三维造型的基础，是创建零件的第一步。

## 核心要点

草图 = **轮廓 + 几何关系 + 尺寸**。SOLIDWORKS 是尺寸驱动软件，所以画的时候**只需近似大小和形状**，精确值靠尺寸给。草图状态用颜色说话：**蓝 = 欠定义，黑 = 完全定义，黄 = 过定义**。原书明确建议：**每个草图都应做到完全定义**。

## 三种草图状态

| 状态 | 颜色（默认） | 含义 | 能不能用 |
|---|---|---|---|
| 欠定义 | 蓝色（选中为淡蓝） | 定义不充分，可拖动改形状/位置 | 可用，但驱动模型不可靠 |
| 完全定义 | 黑色 | 信息完整 | **推荐**。零件设计成熟、开始加工时每个元素都该如此 |
| 过定义 | 黄色 | 有重复尺寸或冲突几何关系 | **危险**：会导致草图驱动模型失效 |

**过定义的处置**：插入尺寸时若有两个尺寸驱动同一几何体，会提示是否把多余尺寸指定为**从动**。指定为从动 → 视图仍完全定义；指定为驱动 → 视图过定义。

**典型完全定义过程**（原书示例）：给矩形顶部和右侧加尺寸，左侧与下方由原点固定其关系，插入尺寸时由水平/垂直推算出相对两边相等，所有实体变黑。

## 草图工具（改已有几何，不是画）

### 绘制圆角 / 绘制倒角

- **圆角**：两实体交叉处剪掉角部并生成切线弧。可【保持拐角处约束条件】。选择方式：选两条边，或直接选中两条直线的**交点**。
- **倒角**三型：
  - 【角度距离】：输入距离 + 角度，先选的边为长度距离
  - 【距离-距离】：输入两个距离，先选的边为第一个距离
  - 【相等距离】：距离-距离 + 勾选【相等距离】，只输一个距离

### 剪裁五法（表 2-17）

| 方式 | 行为 | 常用度 |
|---|---|---|
| **强劲剪裁** | 按住左键划过要删的线段即删；**同时具备延伸功能** | ★★★ 最常用 |
| 边角 | 延伸或剪裁两实体直到在边角相交；十字交叉时第二实体选保留部分 | ★★ |
| 在内剪除 | 剪除位于两边界实体内都相交或全不相交的实体；仅一边相交的剪不掉 | ★ |
| 在外剪除 | 剪裁两边界实体外打开的实体，**同时能延伸**边界内打开的实体 | ★ |
| **剪裁到最近端** | 单击实体即删至最近交点；单击端点后移动鼠标可延伸 | ★★★ 最常用 |

### 等距实体

沿法向偏移一段距离。六个选项：

| 选项 | 作用 |
|---|---|
| 添加尺寸 | 是否标注等距距离 |
| 反向 | 偏移方向 |
| 选择链 | 等距单一元素 vs 整体相连元素 |
| 双向 | 是否两侧同时等距 |
| 制作基体结构 | 把源元素变成构造线 |
| 顶端加盖 | **仅当【双向】激活且轮廓不闭合**时可用，可选圆弧或直线封口 |

### 镜像 / 动态镜像

- **镜像**：先画好实体，再镜像。SOLIDWORKS 会**自动在每对对应草图点之间施加【对称关系】**；改源，镜像跟着改。【镜像点】可选中心线、直线、模型线性边线、工程图线性边线。勾选【复制】→ 结果含源+镜像；不勾 → 只有镜像。
- **动态镜像**：先选镜像点，再画。中心线上下出现「=」号，画一侧自动生成对称图形。

### 线性阵列 / 圆周阵列（草图内）

**线性阵列**
- 方向 1 / 方向 2（两者设置完全相同）
- 【反向】调方向；【间距】距离；【实例数】**含阵列元素本身**；【角度】按角度阵列
- 【要阵列的实体】：已选元素列在框中，可直接在其中删除
- 【可跳过的实例】：单击实例中心圆点跳过；在框中删掉该条可恢复

**圆周阵列**
- 【反向】+ 可选参考中心点；或用【中心点 X】/【中心点 Y】坐标定位
- 【间距】：不勾【等间距】时 = 相邻元素夹角；勾【等间距】时 = 首末元素夹角
- **【等间距】与【标注角间距】不能同时勾选**
- 【标注半径】【标注角间距】可自动加标注

## 草图定义三途径 + 尺寸

原书 2.4 明确：草图定义方式体现**设计意图**，设计者**必须在建模之前考虑好设计意图**。

1. **自动几何关系**：按绘制方式自动加平行/垂直/水平/竖直
2. **方程式**：创建尺寸之间的代数关系，提供**强制修改模型的外部方法**
3. **手动约束关系**：同心、相切、重合、共线等
4. **尺寸**：标注方式本身反映设计者打算如何修改尺寸

### 智能尺寸六类

| 类型 | 操作要点 |
|---|---|
| 线性尺寸 | 自动按鼠标位置在水平/竖直/平行间切换 |
| 角度尺寸 | 两直线间角度；或直线与点（顺序：直线一端点 → 另一端点 → 点） |
| 圆弧尺寸 | 半径（直接点圆弧）／弧长（先选两端点再选圆弧）／弦长（选两端点后拖） |
| 圆的标注 | 同线性 |
| 中心距 | 依次点两个圆后拖出 |
| 同心圆 | 点第一圆再点第二圆；右击可锁定尺寸线方向 |

**改尺寸**：双击尺寸 → 【修改】对话框 → 输入值 → 确认。
**改尺寸属性**：选中尺寸 → 左侧【尺寸】属性框。

### 尺寸标注如何体现设计意图（原书三个对照）

1. 无论矩形尺寸怎么变，**两个孔始终与边界保持相应距离** → 标到边界
2. 两孔**以矩形左侧为基准**标注 → 孔位置不受整体宽度影响
3. 标**两孔中心距** → 保证孔心之间距离

> 同一组孔，三种标法 → 三种改型行为。这就是"尺寸即设计意图"。

## 四个示例（原书 2.5，全部要以 MMGS 完全定义）

**示例 1：带阵列与等距的对称图形**
1. 新建零件，单位 MMGS
2. 打开草图，出现三个默认基准面
3. 选前视基准面，用【正视于】转到平行屏幕，原点符号变红=已激活
4. 画两条过原点、带水平/竖直关系的中心线
5. 画直线（利用推理线自动捕捉几何关系），只需近似尺寸
6. 智能尺寸标注至完全定义
7. 圆周阵列已完全定义部分
8. 等距实体
9. 保存关闭

**示例 2：圆 + 圆弧 + 阵列 + 重合**
画中心线 → 画 φ130 与 φ30 圆 → 画两条 R60 三点圆弧并加几何关系 → 圆周阵列 → 为两个边角点和 φ130 圆加【重合】使完全定义。

**示例 3：直线+切线弧，注意别过度捕捉**
- 画大体轮廓时**只捕捉必要几何关系**——"过多捕捉几何关系会使以后定义几何关系时造成过定义状态"
- **直线↔切线弧转换两种办法**：①画完第一段直线后，光标移开再回到端点；②按 **A** 键切换（可来回切）
- 切线弧时 SOLIDWORKS 按光标位置在**四个目标区域智能分析出八种可能性**
- 交点获取：按住 Ctrl 选两条角度线 → 单击【点】命令
- 最后加圆角（圆内灰色尺寸为从动尺寸）

**示例 4：五角星（综合）**
中心线 → 画 φ48/φ8/2×φ3.5 圆并标尺寸 → 画 120° 夹角中心线（与竖直中心线对称）→ 中心点圆弧槽口 → 画 5 条等长线段且都与 φ3.5 圆相切 → 剪裁五角星中心多余部分（保持各线段相切且相等）→ 镜像 → 等距 φ48 圆（3mm + 反向）→ 等距槽口（3mm + 不反向）→ 强劲剪裁完成。

> 示例 4 的关键顺序：**先把约束关系想全（相切+相等），再剪裁**。反了就得反复补关系。

## 高频失败模式与对策

| 现象 | 原因 | 对策 |
|---|---|---|
| 草图变黄、模型改不动 | 过定义 | 多余尺寸改**从动**；删冲突关系；避免重复驱动同一几何 |
| 草图变蓝、后面特征乱飘 | 欠定义 | 补尺寸或几何关系直至全黑 |
| 加关系时提示冲突 | 已有关系覆盖同一自由度 | 先删旧关系再加 |
| 示例 3 类轮廓反复过定义 | 绘制时捕捉了过多自动几何关系 | 只捕捉必要关系，其余靠尺寸 |
| 剪裁后轮廓不闭合 | 剪掉了需要的段 | 用【强劲剪裁】配合【剪裁到最近端】精修 |
| 圆周阵列角度不对 | 等间距勾选状态理解反 | 勾选=首末夹角，不勾=相邻夹角 |
| 等距顶端加盖不可用 | 未勾双向或轮廓已闭合 | 先勾双向；确保轮廓不闭合 |
