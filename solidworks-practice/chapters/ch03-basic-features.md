# 第 3 章：基本特征

> 对应原书第 3 章（正文 p49–94）。全章 11 个小节、9 个完整实例 + 8 道练习。

## 核心要点

模型由**特征**堆成。特征分两类：**草图特征**（基于二维草图，经拉伸/旋转/扫描/放样变实体）与**应用特征**（直接建在实体上，如圆角、倒角）。

每个例题都以同样两步开头，原书反复强调：

> **分析模型** = ①模型的摆放（关系到二维图的视图方向）②最佳轮廓的选择（更快更高效，且方便后期更改和管理）

## 3.2 拉伸

### 3.2.1 拉伸-拔模（实例：拉伸-五角星）

已知 A=100，拔模 50°，材料 1060 铝合金，MMGS，小数位 2。

步骤骨架：新建 → 环境设置 → 草图1（前视基准面，五条直线加【相等】+尺寸）→ 凸台-拉伸1（**两侧对称 / 深度 50 / 拔模 50° / 所选轮廓选六个封闭轮廓**）→ 编辑材料（设计树右击【材质<未指定>】→【编辑材料】→ 1060 合金 → 应用）→ 保存。

> **"所选轮廓"是拉伸的隐藏能力**：一个草图里有多个封闭轮廓时，可以只拉其中几个，一次成型多实体。

### 3.2.2 拉伸-薄壁特征（实例：薄壁特征-铸件）

已知 A=38 B=10 C=32 D=15，1060 铝合金。

关键动作：
- 拉伸1：【给定深度】26 + 方向反向 + **薄壁特征 单向 / 反向 / 厚度 6**
- 圆角1
- 切除-拉伸1：选面做草图 → 捕捉圆弧圆心画同心圆 φ13 → **【成形到下一面】**
- 切除-拉伸2：两个圆【相等】+ 圆心间【水平】→ 【成形到下一面】
- 凸台-拉伸1：给定深度 6

> **薄壁特征 = 拉伸时就把壳做出来**，不必事后抽壳。适合开口件。

### 3.2.3 拉伸-方向（实例：拉伸-铸件）

已知 A=40 B=11 C=28。

关键动作：
- 草图1 → 拉伸1 给定深度 40
- 草图2（右击面 →【草图绘制】）→ 拉伸2：**【成形到一顶点】+【拉伸方向】指定斜边线**
- 倒角1
- 草图3（可加【对称】关系或镜像）→ **切除-拉伸1 【完全贯穿】**

> **【拉伸方向】可由模型边线驱动，也可由辅助草图直线驱动**——这是做斜面/拔模类过渡的关键手段。

## 3.3 参考几何体

### 3.3.1 基准面创建方法（表 3-1 全量）

| 分类 | 操作方法 |
|---|---|
| 偏移距离 | 选现有基准面或模型表面，输入距离 |
| 与面角度 | 选一个表面 + 一条边或轴，输入角度 |
| 三点重合 | 分别选三个点 |
| 单个边线和点重合 | 选一条边线 + 一个点 |
| 与面平行且与点重合 | 选一个平面 + 一个点 |
| 两侧对称 | 选两个要与之对称的平面 |
| 垂直于在线点 | 选一条螺旋线 + 其一个端点 |
| 两面相切 | 选两个圆柱面，可反转调整方向 |
| 相切与曲面且与点重合 | 选一个曲面 + 一个预先画好的草图点 |

> 所选条件不能构成有效基准面时会给出提示信息，不要硬撑，换组合。

### 3.3.2 基准轴创建方法（表 3-2）

- 将临时轴转换成基准轴
- 选择两相交的基准面或两平面
- 选择两个草图点或两个模型顶点
- 选择一个圆柱面或圆锥面
- 选择一个点 + 一个基准面（生成轴穿过点并垂直于基准面）

基准轴可在设计树上重命名、选取、调整大小。

## 3.4 阵列

**基本概念**：
- **源**：被阵列的几何体，可以是一个或多个特征、实体、面
- **实例**：源通过阵列创建的复制品，**由源派生并随源变化**

### 阵列类型全表（表 3-3）

| 类型 | 典型应用 |
|---|---|
| 线性 | 单向等距、双向等距、只阵列源的双向、去除一些实例 |
| 圆周 | 关于中心等间距、去除实例或 <360° 范围阵列 |
| 镜像 | 按指定平面镜像 |
| 表格驱动 | 基于坐标系 XY 方向的表格阵列 |
| 草图驱动 | 基于草图点阵列 |
| 曲线驱动 | 基于曲线几何路径 / 完全圆周路径 / 投影曲线路径 |
| 填充 | 基于同一面的实例阵列、基于同一面其他特征阵列 |

### 3.4.1 线性阵列（实例：阵列-计算器）

材料 ABS，密度 1020。

骨架：草图1 → 拉伸1（两侧对称 160）→ 草图2（每线距外边 10，圆角 R10）→ 切除-拉伸1（给定深度 2，拉伸方向为斜边线）→ 草图3 → 拉伸2（2.5）→ **线性阵列1**（方向一：边线1，间距 20，实例数 5；方向二：边线2，间距 30，实例数 5；**不勾【只阵列源】**）→ **去除阵列实例**（打开【可跳过的实例】，单击实例中心粉红点）→ 草图4 → 拉伸3（2.5）→ 材料 ABS。

> **【只阵列源】勾选与否结果完全不同**——勾了只复制原始那个，不勾会把"源 + 之前已阵列出来的"一起传播。

### 3.4.2 圆周阵列（实例：阵列-五角星）

骨架：上视基准面草图1 → 拉伸1（10）→ **基准面1（三点）** → 草图2（尺寸不定，足够大）→ 切除-拉伸1（完全贯穿）→ 镜像1（右视基准面，镜像整个零件）→ **圆周阵列1**（阵列轴=边线1，实例数 5，角度 360，勾【等间距】，阵列整个零件）→ 镜像2（选五个面中任一个，镜像实体文件夹下所有实体）。

> 这套"先切一个角 → 镜像 → 圆周阵列 → 再镜像"的组合，是做对称多瓣体的通用套路。

### 3.4.3 草图驱动阵列（实例：阵列-铸件）

骨架：草图1 → 拉伸1（两侧对称 10）→ 草图2（圆与边线【重合】）→ 切除-拉伸1（**【到离指定面指定的距离】**，等距 5）→ 草图3（四个点，均与边线【重合】）→ **草图驱动的阵列**（参考草图=草图3，参考点=**重心**，要阵列的特征=切除-拉伸1）→ 编辑特征勾选**【几何体阵列】**对比结果。

> 【几何体阵列】只复制几何形状不复制特征定义，能显著降低重建负担，但失去参数关联。这是速度与可改性之间的取舍。

## 3.5 旋转（实例：台灯）

这是全书唯一演示"**草图图片描摹**"的地方：

1. 前视基准面草图，先画一条竖直直线 + 一条水平直线作 X/Y 轴定位图片
2. 【工具】>【草图工具】>【草图图片】，插入图片，设高度 500，按草图直线放置（底边与水平线重合，以竖直线为轴左右对称）
3. 用直线、样条曲线描摹外形轮廓，形成封闭区域
4. **隐藏草图图片**：右击设计树该草图名选【隐藏】，或右击草图图片选【压缩】
5. 旋转1：竖直线为轴，给定深度 360°
6. 草图2 → 旋转2（360°）
7. 草图3（圆）→ 拉伸1（4mm，注意方向）
8. 草图4 → **旋转-薄壁1**（两侧对称，厚度 4）
9. 隐藏实体：实体文件夹右击【旋转-薄壁】→【隐藏】
10. 拉伸2（**【开始条件】等距 20 + 【成形到下一面】+ 勾【合并结果】**）
11. **圆周阵列1**（阵列轴选**临时轴**：前导视图工具栏【隐藏/显示项目】→【观阅临时轴】；实例数 4，等间距）

> **【开始条件】=等距** 让拉伸从离基准面一段距离处开始，是做悬空结构的常用手法。

## 3.6 扫描

### 3.6.1 扫描-回形针（基础型）

已知 A=32 B=10，材料延性铁（7100）。
上视基准面草图1 = 路径轮廓；右视基准面草图2 = 截面轮廓；扫描：轮廓=草图2，路径=草图1。

### 3.6.2 扫描-引导线（进阶型，最容易翻车）

骨架：上视草图1 → 拉伸1（15）→ 前视草图2（圆）→ 拉伸2（两侧对称 60）→ **路径**（前视草图3）→ **引导线**（前视草图4）→ **轮廓**（模型表面草图5，基于构造线对称）→ 加**两个【穿透】**关系 → 扫描1（轮廓=草图5，路径=草图3，引导线=草图4，**【方向/扭转控制】=随路径和第一引导线变化**）。

**两个【穿透】的加法定点**：
- 第一个：当前草图构造线一端的"点" + 路径草图（草图3）连接轮廓处的"圆弧"
- 第二个：构造线另一端的"点" + 引导线草图（草图4）连接轮廓处的"圆弧"

> **本书明确的关键警告**：使用【引导线】时，**随引导线变化的轮廓定型尺寸，在添加【穿透】前不可将其完全定义，否则轮廓不能随引导线变化。**
> 即：想让它变的那一维，先留活口。

**SelectionManager**：选轮廓/路径/引导线时在界面空白处右击可打开，能选择封闭区域、开环或组。

### 3.6.3 扫描-不规则弹簧（扭转控制）

已知 A=60，B=35（半径），材料铸造碳钢（7800）。
路径 = 前视草图1；轮廓 = 前视草图2；扫描：轮廓=**闭合组<1>**，路径=草图1，**【方向/扭转控制】=沿路径扭转**，【定义方式】=旋转，【圈数】=20。

> 弹簧类直接用"沿路径扭转 + 圈数"，不要手工画 20 圈。

## 3.7 拔模与拔模分析

**为什么**：铸造成形和注射成形零件都需要拔模，使其容易脱模。
**拔模分析工具**：检查拔模应用到零件上的情况，核实拔模角度、检查面内角度变化、找出**分型面、浇注面和出坯面**。

### 实例（手机壳）

1. **拔模分析**：拔模方向=前视基准面（方向指向模型），拔模角度=3°，勾【面分类】；可用【颜色设定】改色、按钮显隐面
2. **读结果**：相对于前视基准面共 **156 个正拔模 / 8 个需要拔模 / 35 个负拔模**
3. **加拔模特征**：【手工】+【中性面】+ 3° + 中性面=前视基准面 + 拔模面选那 8 个面（默认黄色）
4. **复核**：8 个面已符合边界设定，再单击【拔模分析】关闭分析

> 判据：**"需要拔模"的面数就是这一步的工作量**。分析 → 按数量点选 → 复验归零。

## 3.8 抽壳与筋（实例：冰块盒）

材料 ABS。

1. 上视草图1（矩形）→ 拉伸1（20）
2. **抽壳1**：厚度 2.5，移除面1；【多厚度设定】厚度 3.0，移除相对的面2
3. 草图2（一条竖直线+一条水平线）→ 用草图【线性阵列】阵列竖直线（实例数 9，间隙 10）
4. **筋1**：【类型】两侧，厚度 2.0，【在草图基准面处】，调拉伸方向，加【拔模】3° 并勾【向外拔模】
5. **圆角1**：用 **FilletXpert** → 【添加】→ 选一条凹陷边线后**不要移动鼠标** → 关联工具栏出现【所有凹陷，143 边线】→ 一性次加完 → 半径 1.0 → 【应用】（不选【完整预览】可少等）
6. **抽壳2**：厚度 1.0，移除面选"除第一次抽壳选的面以外的其余 5 个面"

> 两个"效率爆点"：**FilletXpert 的"所有凹陷/所有凸起"**一次性选几百条边线；**多厚度抽壳**让一次抽壳出两种壁厚。

## 高频失败模式与对策

| 现象 | 原因 | 对策 |
|---|---|---|
| 拉伸出的形状不是想要的 | 草图含多个封闭轮廓，默认全选了 | 用【所选轮廓】只点要的那个 |
| 扫描报错"轮廓与路径不相交" | 轮廓平面与路径没有穿透关系 | 让轮廓草图与路径相交，或加【穿透】 |
| 扫描带引导线后外形不变 | 轮廓定型尺寸已完全定义 | 变化维先不定，加完【穿透】再定 |
| 放样扭曲 / 失败 | 轮廓接头不对齐 | 在图形界面对应选轮廓；手动拖接头 |
| 弹簧圈数不够/方向反 | 【沿路径扭转】圈数或旋转方向 | 调【圈数】与【定义方式】 |
| 拔模后仍有黄面 | 漏选"需要拔模"的面 | 以拔模分析的黄色面数量为准逐一点选 |
| 抽壳失败 | 壁厚大于局部圆角/最小特征 | 减小厚度，或多厚度设定单独调 |
| 圆角一次只能选几条边 | 手工逐个点 | 用 FilletXpert【所有凹陷/所有凸起】 |
| 阵列后多余实例 | 方形/圆周阵列必然多出 | 用【可跳过的实例】挖掉 |
| 阵列后重建卡顿 | 每实例都完整重建 | 勾【几何体阵列】（牺牲可改性换速度） |
| 基准面建不出来 | 所选几何不构成有效平面 | 换组合（三点/面+角度/两侧对称） |
