# 第 7 章：渲染

> 对应原书第 7 章（正文 p155–163）。

## 核心要点

两条路：**RealView**（实时，不需渲染就有逼真动态效果）→ 用于日常看模型；**PhotoView360**（插件，真渲染）→ 用于出效果图。渲染流程六步：开插件 → 预览 → 编辑外观/布景/贴图 → 编辑光源 → 编辑选项 → 最终渲染并保存。

## 7.2 两个工具

### RealView 与环境封闭

- **RealView**：显卡支持时自动出现开关（"小金球"），默认打开，**不需要渲染**就能给模型逼真又动态的展现。
- **环境封闭**：一种**球形光源方法**，通过控制封闭区域导致的环境光衰减，使模型更逼真。

### PhotoView360

更逼真的显示与输出靠这个插件，可加不同布景、光源、外观贴图、相机视角。

**对话框构成**：工具条 + DisplayManager + 前导视图工具栏 + 外观/布景/贴图任务窗格 + 关联命令 + 显示窗格。

### 操作流程

1. 打开 PhotoView360 插件
2. 开启预览或打开预览窗口
3. 编辑外观、布景、贴图
4. 编辑光源
5. 编辑 PhotoView 选项
6. 最终渲染，保存图像

## 实例：渲染台灯（8 步）

| 步骤 | 动作 | 关键细节 |
|---|---|---|
| 1 | 打开"台灯"装配体 | 导入文件默认白色，自建零部件灰色 |
| 2 | 查看并清理默认外观 | 打开 DisplayManager → 查看外观 → 右击几种白色外观 →【移除外观】；试切换软件自带布景（默认"三点渐褪"），观察 DisplayManager 中布景/光源/相机变化 |
| 3 | 编辑添加外观 | 走任务窗格：【外观】>【石材】>【粗陶瓷】→ 拖"瓷器"到瓶身 → **关联工具栏选第 4 个"零件级"** |
| 4 | 加贴图 | 装配体环境只能对**零部件**贴图；要对**面**贴图必须进零件编辑状态 → 任务窗格添加"台灯贴图"文件夹 →【将贴图添加到零件】→ 选中间曲面 → DisplayManager【映射】→ 勾【将宽度套合到选择】【将高度套合到选择】 |
| 5 | 设置布景 | 前导视图工具栏【布景】→ 选"背景-工作间" |
| 6 | 添加光源 | 布景照明度+环境光源通常够用；本例加**点光源**做灯泡发光：右击光源文件夹【添加点光源】→ 拖动红点到灯泡中心 → 切上视图把光源位置 X、Z 改为 0 → 退出剖视图 → 右击点光源【在 PhotoView 中打开】（确保前面显示） |
| 7 | 预览效果 | 两种：图形区直接"整合渲染"；或**独立"预览窗口"**——原书推荐第二种，**更省资源、方便修改** |
| 8 | 最终渲染并输出 | 点【最终渲染】→ 可在 **0~9** 切换查看最近 10 个历史结果 → 【保存图像】 |

### 拖拽外观时的"应用层级"（重要）

关联工具栏第二个图标会随拖拽目标不同而变化，选项依次为：**面、特征、实体、零件、部件**。

> **优先级：部件、曲面最高。** 所以想精确控制某一段曲面，必须显式选到"面"级。

### 本例的外观配置清单

| 目标 | 外观 | 层级 |
|---|---|---|
| 瓶体 | 石材/粗陶瓷 → 瓷器 | 零件级 |
| 支撑体 | 无光黄铜 | 设计树中的部件 |
| 遮罩上下两铜圈 | 无光黄铜 | 实体 |
| 瓶托上部 | 无光黄铜 | 面 |
| 灯泡固定 | 无光黄铜 | 零件 |
| 灯座 | 无光金 | 零件 |
| 瓶托四个外旋转面 | 无光金 | 面 |
| 瓶托三个较大外旋转面 | 塑料/高光泽 → 黑色高光泽塑料 | 面 |
| 灯泡体 | 玻璃/光泽 → 透明玻璃 | 零件 |

> **高级选项**里可调照明度、粗糙度等；不懂时可开【动态帮助】辅助选值。

### 探讨（原书 7.5 给出三个方向）

1. 减小环境亮度
2. 灯光改暖色调（昏黄）
3. 增加遮罩的透明度和粗糙度

## 三个课后练习（含原书给定的外观）

1. 风扇叶轮
2. 字体：字体用**"发光二极管"**，平台用**"黑色中等光泽塑料"**，红色字体做了**照明度调整**
3. 工具刀

## 高频失败模式与对策

| 现象 | 原因 | 对策 |
|---|---|---|
| 贴图加不上去 | 在装配体里想对"面"贴图 | 进零件编辑状态再贴 |
| 外观加错范围 | 拖拽时层级选错 | 注意关联工具栏第 2 图标；面级优先于零级 |
| 点光源渲染里没效果 | 未在 PhotoView 中打开 | 右击点光源【在 PhotoView 中打开】 |
| 灯丝不在正中 | 光源坐标偏 | 上视图把 X、Z 改 0 |
| 实时预览很卡 | 用了整合渲染 | 改用独立【预览窗口】 |
| 最终渲染前白忙 | 没清理默认白色外观 | 先把默认外观【移除外观】 |

## 命令路径速查（本章全部命令）

| 命令 | 菜单路径 | 默认值/关键选项 |
