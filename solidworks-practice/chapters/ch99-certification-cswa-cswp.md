# 附录：CSWA / CSWP 样题套路

> 对应原书附录 A（CSWA，正文 p236–254）与附录 B（CSWP，正文 p255–270）。

## 核心套路（两个附录完全相同）

认证样题 90% 是同一道题的变体，**核心不是建模技巧，而是"改参数 → 重建 → 读质量"的闭环**。标准打法八步：

```
① 新建零件 → ② 设置单位/小数位 → ③ 打开方程式管理器建全局变量
→ ④ 指定材料 → ⑤ 建模（草图+特征） → ⑥ 显示特征尺寸
→ ⑦ 用【链接数值】把尺寸绑到全局变量 → ⑧ 质量属性读结果
```

**换参数题**只需：改全局变量 → **Ctrl+B 或 Ctrl+Q 重建** → 再读质量属性。**不要重新建模**。

## 两个关键工具

### 全局变量（方程式管理器）

【工具】>【方程式】。把题目给的 A/B/C/D/E… 建成全局变量，注意：
- 变量名大小写、含义要与题目对应（如 A=角度、B/C=长度）
- 改值时**只改全局变量**，不碰草图尺寸

### 链接数值（Link Values）

右击图形区或设计树中的尺寸 →【链接数值】→ 在列表里选对应全局变量。
- 这是"尺寸 ↔ 变量"的绑定动作
- 附录 A 练习 1-1：把 135→C、58→A、60→B、20→D

> **必须先【显示特征尺寸】**（设计树右击【注解】→【显示特征尺寸】）才能点到那些尺寸。

## 附录 A：CSWA 样题（4 道，全部围绕 Structure/Casting）

### 练习 1-1（25 分）Structure

- 单位 MMGS，小数位 2，原点任意
- 材料 **红铜**，密度 **0.0089 g/mm³**
- **A=58°（角度），B=60，C=135，D=20**
- 问：零件质量为多少克？**抽壳厚度 3mm**

建模骨架：新建 → 设单位（【工具】>【选项】>【文档属性】>【单位】）→ 方程式管理器建全局变量 → 材料选"铜" → 前视基准面草图 → **拉伸-薄壁1** → 显示特征尺寸 → 链接数值（135→C、58→A、60→B、20→D）→ **完整圆角** → 画同心 φ20 圆 → 切除-拉伸1 → **抽壳** → 质量属性 → 保存为"Structure"。

> 注意：这题用的是**拉伸-薄壁**而不是"拉伸后抽壳"，两者壁厚语义相同但特征树不同；题目后面还另加了"抽壳"。

### 练习 1-2（10 分）同一个 Structure，换参数

- A=60°，B=70，C=130，D=17，仍红铜
- 做法：打开零件 → 方程式管理器改全局变量 → **Ctrl+B/Ctrl+Q 重建** → 质量属性

### 练习 1-3（25 分）再加特征

- A=60°，B=68，C=140，D=18，**E=25**（新增）
- 做法：加全局变量 E → 重建 → **压缩特征**（右击特征点压缩按钮）→ 用**异型孔向导**建孔（用【同心】配合定位孔）→ 前视草图 + 切除-拉伸 → 另一草图并**把 25mm 链接到 E** → 凸台-拉伸 → 再草图 + 切除-拉伸 → Ctrl+B → 质量属性

> "**压缩特征**"是换题型的标准动作：题目说不做抽壳，就压缩抽壳特征而不是删除。

### 练习 1-4（10 分）换材料

- A=65°，B=75，C=130，D=22，E=35；材料 **黄铜**，密度 **0.0085 g/mm³**
- 做法：改全局变量 → 重建 → 读质量

### 练习 2-1（25 分）Casting（**IPS 英制**）

- 材料铜，**单位 IPS**，密度 **0.321 磅/立方英寸**，小数位 **3**
- **A=4、B=3、C=2.85、D=0.26**
- 问：质量为多少**磅**？

骨架：新建 → 设 IPS → 全局变量 → 铜 → 前视草图 → **旋转1** → 链接数值 → 建基准面1（用草图几何）→ 草图 → 凸台-拉伸1 → 切除-拉伸5 → 前视草图 → 凸台-拉伸2 → 切除-拉伸1 → 切除-拉伸2 → **圆周阵列** → 草图 → 切除-拉伸3 → 切除-拉伸4 → 圆角 → Ctrl+B → 质量属性 → 保存为"Casting"。

> **单位切换 + 小数位 3** 是 IPS 题的唯一差别，别忘改密度。

### 练习 2-2（10 分）

- A=3.5、B=2.4、C=2.75、D=0.25；仍 IPS、铜、0.321 lb/in³、小数位 3
- 改全局变量 → 重建 → 读质量

## 附录 B：CSWP 样题（6 道，全部围绕 Casting）

### 练习 1-1（25 分）

- MMGS，小数位 2，原点任意
- 材料 **黄铜**，密度 **0.0085 g/mm³**
- **A=75，B=160，C=185**
- 附加条件：**抽壳厚度 2mm，底部开放，圆弧要求与直线相同**

骨架：新建 → 设单位 → 全局变量 → 黄铜 → **上视基准面**草图 → 凸台-拉伸 → 再凸台-拉伸 → 显示特征尺寸 → 链接数值 → **抽壳1（2.00mm）** → 质量属性。

> **"圆弧要求与直线相同"** = 这类题里圆弧要加【相切】约束，否则形状不符。

### 练习 1-2（10 分）

- A=80，B=165，C=190；黄铜 0.0085
- 条件：**圆弧保持相切**，含抽壳（厚度 2，底部开放）
- 改变量 → 重建 → 读质量

### 练习 1-3（10 分）

- A=68，B=155，C=186，**D=65**
- 条件：圆弧相切，**所有孔都完全贯穿并与圆角同心**，**压缩抽壳特征**
- 加全局变量 D → 重建 → **压缩"抽壳1"** → 草图（尺寸链接 C、D）→ 凸台-拉伸3 → 草图 → 凸台-拉伸4 → 圆角 → 草图 → 切除-拉伸 → 质量属性

### 练习 1-4（10 分）

- A=70，B=165，C=188，D=70；黄铜
- 改变量 → 重建 → 读质量（纯参数题）

### 练习 1-5（10 分，最复杂）

- A=70，B=155，C=185，**D=75，E=30，F=5**
- 附加：**加强筋位于拉伸凸台中心；φ5mm 半圆切除位于倒角中心；切槽圆周阵列等距且完全贯穿**
- 骨架：加变量 → 右视草图 → **筋1** → 草图 → 凸台-拉伸6 → **建基准面** → 草图（链接 E、F）→ **切除-旋转1** → 草图 → 切除-拉伸2 → 草图 → 切除-拉伸3 → Ctrl+B → 质量属性

> 三个附加条件分别对应：**筋居中**（对称约束）、**半圆切除对被倒角**（同心/定位）、**圆周阵列等距**（等间距勾选）。

### 练习 1-6（10 分）

- A=72，B=160，C=187，D=77，E=35，**F=10**；黄铜
- 改变量 → 重建 → 读质量

## 高频失败模式与对策

| 现象 | 原因 | 对策 |
|---|---|---|
| 改参数后模型没变 | 没重建 | **Ctrl+B**（重建）/ **Ctrl+Q**（强制重建） |
| 尺寸链接不上 | 未显示特征尺寸 | 设计树右击【注解】→【显示特征尺寸】 |
| 质量对不上 | 材料/密度未设或选错 | 检查材料是否真应用；密度数值是否抄错 |
| 单位错导致质量差 1000 倍 | IPS/MMGS 混用 | 显式设单位系统 + 小数位 |
| 该压缩的特征没压缩 | 直接删除导致后续特征失败 | **压缩**而不是删除 |
| 题目要求"圆弧与直线相同"没满足 | 缺相切约束 | 加【相切】几何关系 |
| 孔位置偏 | 用尺寸而非同心定位 | 用【同心】配合到圆角边线 |

## 与其他章的连接

- 方程式（第 2 章 2.4.2）→ 全局变量
- 显示特征尺寸、尺寸名称 `Dx@草图n` → 第 8 章配置
- 拉伸-薄壁、旋转、抽壳、筋、圆周阵列、多半径圆角 → 第 3 章
- 压缩特征 → 装配体配置（第 8 章）
- 质量属性/质心 → 第 3 章练习要求、第 6 章自定义属性

## 命令路径速查（附录全部命令）

| 命令 | 菜单路径 | 默认值/关键选项 |
|---|---|---|
| 设单位 | **【工具】/【选项】/【文档属性】/【单位】** | MMGS/IPS；小数位 2（IPS 用 3） |
| 方程式管理器 | **【工具】/【方程式】** | 建全局变量 |
| 显示特征尺寸 | **右击【注解】→【显示特征尺寸】** | 默认隐藏 |
| 链接数值 | **右击尺寸 →【链接数值】** | 选全局变量 |
| 重建 | **Ctrl+B** / **Ctrl+Q** | — |
| 编辑材料 | **右击【材料】→【编辑材料】** | **【应用】→【关闭】** |
| 压缩特征 | **右击特征 →【压缩】** | 换题型用压缩不用删除 |
| 质量属性 | **【工具】/【评估】/【质量属性】** | 读质量/体积/质心 |
| 异型孔向导 | **【插入】/【特征】/【孔】** | 柱形沉头孔/AnsiMetric/六角螺栓 |
