# 第 11 章：eDrawings

> 对应原书第 11 章（正文 p212–221）。

## 核心要点

跨企业、跨平台交流模型和工程图的"只读查看器"。把 SOLIDWORKS 模型/工程图转成 eDrawings 格式，别人**不用装 SOLIDWORKS** 就能无缝查看、批注、测量。

## 为什么需要它（原书给的三个痛点）

社会化大生产下企业分工不同，过去靠二维工程图 + 工程师描述交流，问题是：
1. **可能产生误解**
2. 对人员素质要求不低
3. **中间交流成本过高**

加上各企业用的三维软件可能不是同一平台，还有**图纸保密性**等安全要求——这些缺陷催生了 eDrawings。

> 本章只介绍针对 SOLIDWORKS 平台的发布/浏览/批注。其他软件的发布功能见官网 http://www.edrawingsviewer.com/

## 能直接打开的文件类型

| 类型 | 扩展名 |
|---|---|
| eDrawings | `*.eprt`、`*.easm`、`*.edrw` |
| SOLIDWORKS | `*.sldprt`、`*.sldasm`、`*.slddrw` |
| DXF/DWG | `*.dxf`、`*.dwg`（支持 2.5 到 2010 版本） |
| 3DXML | `*.3dxml` |
| CALS | `*.cal`、`*.ct1` |
| XML 纸张规格（XPS） | `*.edrwx`、`*.eprtx`、`*.easmx` |
| Pro/ENGINEER | `*.prt`、`*.prt.*`、`*.xpr`、`*.asm`、`*.asm.*`、`*.xas` |
| STL | `*.stl` |
| SOLIDWORKS 模板 | `*.prtdot`、`*.asmdot`、`*.drwdot` |

## 能保存的文件类型

零件、装配体、工程图都一样：`*.eprt`、`*.zip`、`*.htm`、`*.exe`、`*.bmp`、`*.tif`、`*.jpg`、`*.png`、`*.gif`。

## 如何保存

两种入口：
1. 【文件】>【另存为】→ 保存类型选 eDrawings（`*.eprt` / `*.easm` / `*.edrw`）
2. 单击【保存】按钮右边的下拉箭头 →【出版 eDrawings 文件】（会自动打开 eDrawings 浏览器）

**多配置零部件要选定要输出的配置。** 保存时可设【选项】和【密码】（可给打开文件设密码）。

## 实例 1：阅览批注 3D 模型（12 步）

| 步骤 | 动作 | 要点 |
|---|---|---|
| 1–2 | 打开"机械手"装配体 → 切【运动算例1】→【另存为】选 `*.easm` | 运动设置与爆炸视图已完成 |
| 3 | 【选项】→【输出】 | **勾【确定可测量此 eDrawings 文件】** + **【将运动算例保存到 eDrawings 文件中】** |
| 4–5 | 打开 eDrawings 程序 → 打开该文件 | 【零部件】标签看装配层结构；【移动零部件】可拖拽；【显示爆炸】显示爆炸视图；右击零部件可隐藏/透明 |
| 6 | 【连续播放】看动画 | 视图切换顺序可用【将动画重新排序】的【上移】/【下移】改 |
| 7 | 【配置】标签 | 看不同配置及显示状态，也可切换 |
| 8 | 【标注】标签 | 标尺寸、插图片、加注释、画几何图形 |
| 9 | 【测量】标签 | 点【激活测量】再选几何 |
| 10 | 【横断面】标签 | 【插入横断面】选参考面或实体面 |
| 11 | 【动画】标签 | 播放由 SOLIDWORKS Motion 创建的动画 |
| 12 | 【戳记】标签 | 加【批注】【机密】【草稿】等戳记 |

> **警告（原书明确）**：保存 eDrawings 文件后，**戳记会永久保留，不可删除**。加"机密"前想清楚。

## 查看与交流（11.5）

- 审阅者装 eDrawings 播放器即可打开
- **如果对方没装也不能上网下载播放器**：用 **eDrawings Professional** 保存为 `*.exe` 可执行文件，双击即可打开。代价是**文件里含播放器，体积会增大**
- `*.exe` 里也有【激活测量】选项
- **多人批注会混乱**：审阅者可【文件】>【保存批注】把自己的意见存成单独批注文件，各自独立查看

## 实例 2：阅览批注工程图（11.6）

| 步骤 | 动作 | 要点 |
|---|---|---|
| 1 | 打开 `*.edrw` | 界面与 3D 不同：**"零部件"标签变为"图纸标签"** |
| 2 | 切换图纸 | 例含 Sheet1 与 BOM 两张图纸，各含不同视图；双击放大；也可点下方图纸标签切换 |
| 3 | 快速切视图 | **双击视图标识**（剖切符号、视图标签等） |
| 4 | 查看视图的 3D 模型 | 单击某视图出现绿框 →【旋转】即见该视图 3D 状态，此时也可测量；【主页】回到工程图 |

## 模型显示方式（11.7）

| 操作 | 效果 |
|---|---|
| 【视图】>【上色】 | 上色显示 |
| 取消选择【上色】 | 线框 |
| 【上色时显示边线】 | 上色 + 边线 |

## 高频失败模式与对策

| 现象 | 原因 | 对策 |
|---|---|---|
| 发出后对方测不了尺寸 | 保存时未勾【确定可测量】 | 重新保存并勾选 |
| 对方打不开 | 未装播放器 | 存为 `*.exe` 自包含 |
| 动画丢了 | 未勾【将运动算例保存】 | 重新保存 |
| 想去掉戳记 | 戳记一旦保存永久保留 | 只能重新出一份文件 |
| 多人批注混在一起 | 都在同一文件上批注 | 各自【保存批注】成独立文件 |
| 多配置只出一个 | 未选定输出配置 | 保存时指定配置 |

## 命令路径速查（本章全部命令）

| 命令 | 菜单路径 | 默认值/关键选项 |
|---|---|---|
| 另存为 eDrawings | **【文件】/【另存为】** → 类型 **eDrawings（*.eprt/*.easm/*.edrw）** | 多配置需选定输出配置 |
| 出版 eDrawings | **【保存】旁下拉 →【出版 eDrawings 文件】** | — |
| 输出选项 | 保存时**【选项】→【输出】** | 勾**【确定可测量】** + **【将运动算例保存】** |
| 存为 exe | eDrawings Professional → **【文件】/【另存为】→ *.exe** | 自带播放器 |
| 保存批注 | eDrawings **【文件】/【保存批注】** | 多人独立 |
| 大图标 | eDrawings **【视图】/【工具栏】→【大图标】** | — |
| 上色/线框 | eDrawings **【视图】/【上色】** / **【上色时显示边线】** | 默认上色 |
