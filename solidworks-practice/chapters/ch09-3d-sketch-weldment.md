# 第 9 章：3D 草图与焊件

> 对应原书第 9 章（正文 p178–196）。

## 核心要点

2D 草图搞不定复杂空间模型时用 3D 草图。它的实体与 2D 不同，因此在**扫描、放样、焊件**中特别有用，但**绘制起来比较困难**。焊件按**多实体**建模，用一个特殊的焊件特征指明这是焊件。

## 9.2 使用 3D 草图

### 三个工具

| 工具 | 作用 |
|---|---|
| **基准面切换** | 在三维空间绘制，默认用模型默认坐标系；想切到另外两个默认基准面，**按住 Tab 键**（草图工具激活时会显示当前草图平面原点）；要切到标准基准面之外的参考基准面，**按住 Ctrl 再单击那参考基准面** |
| **草图实体与几何关系** | 3D 草图中可用实体和几何关系比 2D 少，但有些关系**只存在于 3D**：【平行 YZ】【平行 ZX】【沿 Z】 |
| **空间控标** | 在几个基准面上绘图时的方向辅助工具；定义直线或样条曲线的第一个点时出现，可选择用于绘图的轴线 |

## 9.3.1 实例 1：3D 管道（16 步）

已知长边 9、短边 5.5，所有圆角 R1.5，1060 铝。

| 步骤 | 动作 |
|---|---|
| 1 | 用 **gd_part** 模板新建，单位 MMGS |
| 2 | 特征工具栏【3D 草图】 |
| 3–8 | 分段画直线：**每一步按 Tab 键直到光标显示目标平面符号**，沿 Z / X / Y 方向依次绘制，每段标注尺寸；共 7 组直线 |
| 9 | 最后一条直线端点与原点重合，草图完全定义（全部线段变黑） |
| 10 | 为所有直角加 **R1.5** 过渡圆角，保存退出 |
| 11 | 再激活 3D 草图 → 【转换实体引用】→ 选【3D 草图1】 |
| 12 | 【工具】>【样条曲线工具】>【套合样条曲线】→ 框选 3D 草图 → 确定，保存退出 |
| 13 | 隐藏【3D 草图1】→ 前视基准面画 **φ2** 圆，圆心与套合样条曲线加**【穿透】** |
| 14 | 【扫描】：轮廓=φ2 圆，路径=套合样条曲线 |
| 15–16 | 材料 1060 铝，保存为"3D 管道" |

> **3D 管道的核心技巧**：先用 3D 草图 + 圆角画出折线骨架 →【套合样条曲线】把它变成光顺路径 → 再用扫描给截面。这样管路转弯处自然圆滑。

### Tab 键的意义

绘制时按 Tab 会在 **XY / YZ / ZX** 平面之间切换，光标显示当前平面符号。**这是 3D 草图的唯一方向基准**——不按 Tab 就是在默认平面上乱画。

## 9.3.2 实例 2：焊件（篮球架，27 步）

**焊件定义**：由多个焊接在一起的零件组成，应作为**多实体**建模，一个特殊的焊件特征指明这个多实体零件为焊件。

| 步骤 | 动作 | 要点 |
|---|---|---|
| 1 | gd_part 模板，MMGS | — |
| 2 | 激活 3D 草图 | — |
| 3 | 画中心线 | 按 Tab 切到 **ZX**；从原点沿 X 画 1200 → 沿 Z 画 1500 → 沿 X 画 1200 → 第四条与原点重合并加**【沿 Z 轴】**关系；标注 1200 与 1500 |
| 4 | **转换中心线为实体线** | 按住 Ctrl 选两条沿 Z 方向、长 1500 的中心线 → 属性框**取消勾【作为构造线】** |
| 5 | 直线1 | Tab 切 ZX，画两条与 1200 线平行（沿 X）的线段并标位置 |
| 6 | 直线2 | Tab 切 **YZ**，以交点为起点画两条直线并标尺寸；为长 500 的线加【沿 Z 轴】 |
| 7 | 直线3 | YZ 下继续，画沿 Y 方向、另一端与斜线相交的直线并标尺寸（此时斜线位置已定） |
| 8 | 圆角 | 【绘制圆角】**R500** |
| 9–13 | 直线4~7 + 圆角 | 在 YZ 下继续；加【沿 X 轴】、【相等】关系；再加 **R500** 圆角 |
| 14 | 直线8 | Tab 切 ZX，连接两端点画两条直线 |
| 15 | 直线9 | Tab 切 YZ，画两条直线并加几何关系 |
| 16 | 保存退出 3D 草图 | — |
| 17 | **结构构件 + 组1** | 【插入】>【焊件】>【结构构件】；【标准】=**ansi 英寸**，【类型】=**管道**，【大小】=**1.5sch40**；激活【组】列表框，选 4 条平行直线 → 自动创建组1 |
| 18 | 组2 | 点【新组】→ 选 6 条平行直线 |
| 19 | 组3 | 点【新组】→ 选 4 条平行直线 |
| 20 | 组4 | 点【新组】→ 选 2 条平行直线 |
| 21 | 组5 | 点【新组】→ 选 1 条**圆弧** |
| 22 | 组6 | 点【新组】→ 选另 1 条**圆弧** |
| 23 | 草图 | 选平面画轮廓并完全定义 |
| 24 | 凸台-拉伸 | 给定深度 5，**注意拉伸方向** |
| 25 | 隐藏 3D 草图1 | — |
| 26–27 | 材料 1060 铝，保存为"篮球架" | — |

> **结构构件按"组"组织**：同一组 = 同一根型材共用的连续路径。**平行线一组、圆弧单独成组**，因为圆弧处的接头处理方式与直段不同。这是焊件不出现接头错乱的关键。

## 两个课后练习

1. **3D 管路**：A=50，B=8（直径），1060 铝
2. **椅子**：A=1200 B=400 C=450 D=450；框架部分结构构件【标准】=ISO、【类型】=**方形管**、【大小】=**30×30×2.6**；其余横梁【标准】=ISO、【类型】=管道、【大小】=**33.7×4.0**；材料**柚木**，密度 630

> 练习 2 给定两套不同型材参数，正是练"焊件里混合多种结构构件"的标准题。

## 高频失败模式与对策

| 现象 | 原因 | 对策 |
|---|---|---|
| 3D 草图线画在错误平面 | 没按 Tab 切换 | 绘制时按 Tab 直到光标显示目标平面 |
| 3D 草图无法完全定义 | 缺【沿 X/Y/Z 轴】类关系 | 用 3D 专属几何关系收口 |
| 套合样条曲线后扫描报错 | 圆与样条未加【穿透】 | 让圆心与样条曲线【穿透】 |
| 焊件接头错乱 | 直线与圆弧混在同一组 | **圆弧单独成组**，直段与圆弧分开 |
| 结构构件方向反 | 轮廓基准方向问题 | 用属性框的方向切换按钮 |
| 3D 草图挡住后续操作 | 未隐藏 | 右击设计树【隐藏】 |
