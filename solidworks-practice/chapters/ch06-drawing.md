# 第 6 章：工程图

> 对应原书第 6 章（正文 p137–154）。

## 核心要点

工程图 = **一组视图 + 尺寸 + 技术要求 + 标题栏 + 明细表**，是加工制造的依据。三者**互相关联**：零件/装配体任何更改，工程图自动更新，反之亦然。

原书比喻：用 SOLIDWORKS 做工程图就像**用相机给模型各个方向拍照**，再按工程图要求处理。

## 三个术语（必须先分清）

| 术语 | 含义 |
|---|---|
| **图纸** | 一张实际的绘图用纸，用来放视图、尺寸、注解。一张工程图可用**多张图纸**描述产品 |
| **图纸格式** | 图框 + 标题栏 + 必要的文字 |
| **模板** | 含一个对应图纸格式 + 全局设定，保证所有图纸规范协调。可自定义 |

模板扩展名：`*.prtdot`（零件）、`*.asmdot`（装配体）、`*.drwdot`（工程图）。

## 七步操作流程

1. 新建工程图，选模板和关联零部件
2. 生成标准视图（模型视图 / 标准三视图）
3. 生成派生视图（局部/剖面/投影/断裂等）
4. 对齐和显示视图（操纵、隐藏/显示、显示状态）
5. 标注尺寸、注释、基准、形位公差（几何公差）和其他注解
6. 保存
7. 打印和发送

## 标准视图

**取决于模型在三维坐标系中的摆放**。原书的关键提醒：

> 在产品设计中，一般主视图放能表现产品主要外形的最佳轮廓，因此**在模型创建初期选择第一个草图基准面时，就要考虑主视图是哪一个基准面**。

这是第 2、3 章"分析模型→模型摆放"的真正原因。

- **标准三视图**：主视图 + 俯视图 + 左视图（主视图一般为"前视图"，据产品主要特征而定）
- **模型视图**：单一方向。预定义 7 个：主视图、仰视图、左视图、后视图、俯视图、右视图、等轴测图

## 派生视图 9 类

| 视图 | 定义 | 限制与要点 |
|---|---|---|
| **投影视图** | 基于已有视图做 8 方向投影 | 已有视图=父视图，新视图=子视图；**子视图继承父视图的显示样式、比例**；投影方向由图纸属性设定 |
| **辅助视图** | 垂直于现有视图中参考边线的展开视图 | 类似投影视图，但按斜边展开 |
| **局部视图** | 某部分的放大显示 | 可以是正交/等轴测/剖面/裁剪/爆炸/另一局部视图 |
| **剪裁视图** | 隐藏定义区域外内容，聚焦某部分 | 定义区域**必须为封闭轮廓草图**；不能剪裁局部视图或已用于生成局部视图的视图 |
| **断开的剖视图（局部剖）** | 在标准视图中剖切某部分显示内部结构 | **不能**在局部视图、剖面视图、交替位置视图上生成；在爆炸视图上生成后**该爆炸视图将不可解除爆炸**；剖面区域需封闭草图轮廓 |
| **断裂视图** | 把较大长度/宽度按比例显示在较小图纸上 | 长杆件必备 |
| **剖面视图** | 用剖切线分割父视图并生成单独视图 | 含阶梯剖、旋转剖 |
| **旋转剖视图** | 剖面线转折的剖切 | — |
| **交替位置视图** | 同一视图上叠显不同位置的装配体运动范围 | 用**细双点画线**在原有视图上层叠 |

## 尺寸与注解

- **智能尺寸**：自动或手动加尺寸与注解
- **模型项目**：把三维模型信息（如草图尺寸）导入工程图
- **注解工具集**（表 6-15）：螺纹线、表面粗糙度符号、基准特征符号、基准目标符号、销钉符号、多转折引线、零件序号、成组的零件序号、区域剖面线、焊接符号、形位公差、中心符号线、中心线、焊缝、修订符号、孔标注

## 图纸格式与图纸属性

- **图纸属性**：图纸名称、全局比例、当前图纸的投影类型
- **图纸格式**：标题栏、图框、注释、嵌入图像、自定义属性、图表定位点

二者都在工程图空白区域**右击**调出，一般保存在图纸模板里直接调用。

## 实例 1：模型视图出图（皮带轮，14 步）

| 步骤 | 动作 | 细节 |
|---|---|---|
| 1 | 赋予材料信息 | 右击【材质】→【编辑材料】→ 右击【自定义材料】→【新类别】改名"铸铁" → 右击"铸铁"新建材料 **HT200**；**质量密度 7280 kg/m³**；其他参数可空 |
| 2 | 补充零件信息 | 【文件】>【属性】→【自定义】：零件号=PDL001，设计=张三 |
| 3 | 创建图纸 | 【文件】>【新建】→ 选 **gb_a3** 模板 |
| 4 | 创建第一个视图 | 【视图布局】>【模型视图】→【浏览】选零件 →【下一步】→ 方向选**左视** → 放置；比例不对时右击空白→【属性】改 1:1 |
| 5 | 创建投影视图 | 【投影视图】→ 移到左视图左侧自动产生主视图 |
| 6 | 创建剖视图 | 删掉主视图 → 【剖面视图】→ 切割线【对齐】→ 三点定剖切位置 → 放置；方向反了用【反转方向】 |
| 7 | 加中心线 | 【注解】>【中心线】→ 点三个孔；再点轮槽对称齿面线；拖端点调长度 |
| 8 | 导入尺寸 | 【模型项目】→【来源/目标】选【整个模型】→ 勾【将项目输入到所有视图】→【尺寸】下选【为工程图标注】 |
| 9 | 修整标注 | 删所有 R2（改在技术要求里说明）；倒角尺寸手动用【智能尺寸】下的【倒角尺寸】重标（**手动标的是参考尺寸，无驱动作用**） |
| 10 | 移动/改显示 | 按住 **Shift** 可把尺寸从一个视图拖到另一个；M8 尺寸改文字为 `5×M<DIM>-6H⤳S`，【引线】选【直径】标注法 |
| 11 | 其他注解 | 基准、表面粗糙度 |
| 12 | 加公差 | 点 φ15 尺寸 →【公差/精度】→ 双边：+0.03 / -0.00 |
| 13 | 技术条件 | 【注释】输入："技术要求 1.零件无铸造缺陷。2.去锐边去毛刺，未注圆角为R2。" |
| 14 | 完成 | 加"其余"表面粗糙度符号 → 保存 |

**关键区分**：**从【模型项目】导入的尺寸是驱动尺寸**——改它会改模型（与草图/特征双向关联）；**手工用【智能尺寸】标的是参考尺寸**——不改模型。

**尺寸乱了怎么办**：框选所有尺寸 → 右击空白 →【对齐】>【自动排列】→ 再手工微调少数。

## 实例 2：视图调色板出图（台虎钳装配体，12 步）

比实例 1 更便捷直观。装配体工程图比零件图多了**爆炸视图 + 零件序号 + 材料明细表**。

| 步骤 | 动作 | 要点 |
|---|---|---|
| 1 | 预设 | 【工具】>【选项】>【系统选项】>【工程图】→ 勾【生成视图时自动隐藏零部件】 |
| 2 | 打开装配体 | 确保当前配置为"关闭" |
| 3 | 建工程图 | 【文件】>【从装配体制作工程图】→ 选 gb_a3 |
| 4 | 插入视图 | 任务选项卡【视图调色板】→ 拖"主视"到图纸 |
| 5 | 投影视图 | 用【投影视图】投影其余视图 |
| 6 | 断开的剖视图 | 在主视图上画封闭样条曲线 → 【不包括零部件/筋特征】选"圆螺丝钉""丝杠"（它们不被剖切）→ 剖切【深度】95 → 勾【自动加剖面线】【预览】 |
| 7 | 交替位置视图 | 选俯视图 → 新配置命名"打开" → 【移动】=【自由拖动】→【选项】=【物理动力学】→ 检查范围【这些零部件之间】→ 选"动掌"与"虎钳底座零件图" → 【恢复拖动】拖到末端，**两零件相撞自动停止** |
| 8 | 爆炸视图 | 右击"等轴测"视图→【属性】→ 勾【在爆炸状态中显示】，参考配置=默认 |
| 9 | 零件序号 | 选爆炸视图 → 【注解】>【自动零件序号】→ 手工拖排 |
| 10 | 材料明细表 | 【插入】>【表格】>【材料明细表】→ 选爆炸视图 → 设属性 → 拖到位置 |
| 11 | 改列属性 | 点"说明"列 → 【列属性】→ 【列类型】=自定义属性，【属性名称】=材质 |
| 12 | 保存 | — |

> **物理动力学 + 自动停止**是做行程极限视图的利器，不用手算极限位置。

## 高频失败模式与对策

| 现象 | 原因 | 对策 |
|---|---|---|
| 改工程图尺寸，模型也变了 | 从【模型项目】导入的是驱动尺寸 | 需要只读标注时手工【智能尺寸】标参考尺寸 |
| 剖视图里螺栓被剖开了 | 未指定排除 | 用【不包括零部件/筋特征】把标准件排除 |
| 断开的剖视图生成失败 | 在局部/剖面/交替位置视图上做 | 换到标准视图上做 |
| 爆炸视图的工程图无法解除爆炸 | 在该爆炸视图上生成过断开的剖视图 | 换视图做剖切 |
| 视图比例不对 | 默认比例小 | 右击空白→【属性】改比例 |
| 尺寸挤成一团 | 导入位置未排列 | 【对齐】>【自动排列】后再微调 |
| 装配体工程图里内部件透视 | 未设自动隐藏 | 【系统选项】>【工程图】勾【生成视图时自动隐藏零部件】 |
| 交替位置视图不动 | 【移动】/【选项】设错 | 【自由拖动】+【物理动力学】+ 明确检查范围 |
