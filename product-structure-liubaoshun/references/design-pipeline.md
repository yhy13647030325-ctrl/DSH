# 产品设计全流程：八个技能怎么串起来

> 这是本技能与已有设计技能的**总连接页**。做产品设计时按这张图调用，不要各自为政。


## 二、每个环节该问哪本书

| 你现在的处境 | 调用 | 问它什么 |
|---|---|---|
| "这个需求是真的吗？" | 柳冠中 | 内外因分析、目标系统（初心→路径→工具） |
| "用户会怎么用错？" | 诺曼 | 预设用途、反馈、四类限制、失误与错误 |
| "这个尺寸合适吗？" | 丁玉兰 | 百分位、人体尺寸、满足度 |
| "这个形怎么更统一？" | 汉娜 | 主导/次要/附属、比例、轴线 |
| "这个造型有动感吗？" | 李想 | 视觉动力、法向动力、凹与凸的平衡 |
| "这个形能不能做出来？" | **刘宝顺** | 壳体功能与准则、四大工艺工艺性 |
| "这个塑料件会不会缩水/变形？" | **李忠文** | 缺陷现象→原因→对策 |
| "怎么建模、出图、装配？" | SOLIDWORKS | 特征选型、草图、工程图 |

## 三、三层交接点（最容易掉东西的地方）

### 交接 1：造型 → 结构（第 4 层 → 第 5 层）

**问题**：造型给了曲面和比例，但那是"好看"的标准，不是"能做"的标准。

**交接清单**（用刘宝顺的判据校核造型）：

| 校核项 | 判据来源 | 造型端要准备什么 |
|---|---|---|
| 拔模斜度够不够？ | 注塑 15′/30′/筋 2°–5° | 侧壁是否为直壁、有无倒扣 |
| 壁厚均匀吗？ | 第一章"壁厚尽可能均匀" | 造型有无厚薄突变 |
| 过渡是圆角还是锐角？ | 第一章"避免锐角连接" | 所有转角 |
| 有没有表面凹陷？ | 第一章"尽量避免表面凹陷" | 装饰槽、logo 凹坑 |
| 分型面在哪？ | 第一章铸造/注塑工艺性 | 造型的分界线 |
| 要不要拆件？ | 第一章"便于拆装" | 开合线、锁扣位 |

> **顺序不能反**：先有造型再校核结构，不能边造型边改结构，否则造型会被工艺牵着走而失去一致性。**但校核要早**，越早发现越便宜。

### 交接 2：结构 → 注塑工艺（第 5 层 → 第 6 层）

**问题**：结构设计对了，注塑还是会出缺陷——因为缺陷还取决于**工艺参数**（射速、温度、保压）。

**交接判据表**：

| 结构特征 | 可能引发的缺陷 | 查缺陷技能的哪一类 |
|---|---|---|
| 壁厚不均 / 局部厚 | 缩水、凹点、光影 | 缩水/凹点类 |
| 转角为锐角 | 应力集中、开裂 | 断裂/破损类 |
| 排气不良（深腔、盲孔） | 困气、烧焦、气纹 | **烧焦/困气类（15 例）** |
| 拔模斜度不足 | 拉模、拖伤、擦烧 | 拉伤/拖伤类（10 例） |
| 浇口位置不当 | 气纹、流痕、喷射痕 | 气纹/流痕类（12 例） |
| 熔接位置在薄壁/受力处 | 融合线、强度不足 | 夹线/融合线类（13 例） |
| 顶出面积不足 | 顶白、顶针印、变形 | 发白/顶白类（7 例） |

> **判断责任边界**：**结构缺陷改结构，工艺缺陷调参数。** 但很多缺陷两者都能"救"——结构改不了时才调工艺。这个顺序见缺陷技能的决策树。

### 交接 3：结构 → 建模（第 5 层 → 第 7 层）

**问题**：结构方案是对的，但建模顺序不对，后面改不动。

**交接要点**：
- 结构方案里的**分件**决定建模的零件数
- **分型面**决定草图基准面的选择（回指 SOLIDWORKS 的"分析模型两步"）
- **拔模斜度**要么在草图里给，要么用拔模特征
- **壁厚**用抽壳还是拉伸薄壁，取决于第 5 层的结构形式

## 四、一个完整例子：做个带盖的塑料小盒

| 步骤 | 技能 | 产出 |
|---|---|---|
| 1 | 柳冠中 | 这个盒子是装什么的？谁在什么场景用？（外因） |
| 2 | 诺曼 | 开盖方式是否可被发现？盖回去有没有反馈？ |
| 3 | 丁玉兰 | 手握尺寸、开盖力矩是否在人能力范围内 |
| 4 | 汉娜 / 戴布斯 | 盒体与盖的比例、分型线的视觉处理 |
| 5 | **刘宝顺** | 壁厚均匀吗？拔模斜度？盖与盒用弹性锁扣还是螺纹？密封要不要 O 形圈？ |
| 6 | **李忠文** | 如果盖子是 PP、盒体是 ABS，熔接痕在哪？深腔排气够吗？ |
| 7 | SOLIDWORKS | 抽壳 2mm、拔模 1°、铰链位放哪、出图 |

## 五、什么时候**不要**串起来用

不是每个项目都要走完七层。原书自己就提醒过两处"不必"：

- **不必做完整计算**：刘宝顺明说刚度强度"通常需要结构工程师配合"，设计师知道有这四条即可
- **不必追求绝对密封**：密封"对很多产品也没有必要，而且还要考虑成本"

同理：
- 简单产品不必做完整的人机工程计算（丁玉兰的百分位方法用于有明确人机界面的产品）
- 一次性/不维修产品不必设计可拆结构（刘宝顺 p12 明确列为例外）

> **串技能是为了不漏，不是为了走流程。** 按产品复杂度裁剪。
