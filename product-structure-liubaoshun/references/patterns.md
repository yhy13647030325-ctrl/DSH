# 可复用判据（Patterns）

> 从刘宝顺《产品结构设计》六章归纳的可操作系统。标 **（提炼）** 处为归纳而非原句。

## 模式一：成型工艺选型（四选一）

**何时用**：造型已定，要决定用什么工艺做。

**决策顺序**（严格按此序，不要跳）：

```
① 材料是什么？
     ├ 塑料 → 注塑（批量大）或 其他
     └ 金属 → ②
② 批量多大？
     ├ 单件/小批 → 砂型铸造 / 焊接 / 手工
     └ 大批量 → ③
③ 结构复杂度？
     ├ 刚度强度要求高、内腔复杂 → 铸造（压铸/金属型/熔模）
     ├ 薄板外壳 → 冲压（一件一模，批量要大）
     └ 大件、板厚大 → 焊接
④ 精度要求？
     ├ 高 → 压铸 / 熔模 / 冷冲压
     └ 低 → 砂型铸造
```

**陷阱**：
- 注塑"不适于单件小批量"（模具成本高）
- 冲压"一件一模，局部更改也要换模"，小批量成本极高
- 熔模铸件"重量一般不超过 25kg"

## 模式二：工艺性自查七问（铸造/注塑通用）

**何时用**：任何铸件或注塑件的结构评审。

| # | 问 | 不合格的信号 |
|---|---|---|
| 1 | 有大面积封闭薄壁吗？ | 尤其当它水平放置（气孔夹渣） |
| 2 | 凹凸太多吗？ | 表面起伏频繁 |
| 3 | 拔模斜度够吗？ | 直壁、内凹、死角 |
| 4 | 活块能减少吗？ | 凸台离分型面远 |
| 5 | 砂型/模具够牢吗？ | 薄法兰、悬空结构 |
| 6 | 型芯能减少吗？ | 封闭内腔 |
| 7 | 壁厚均匀吗？ | 局部厚大 |

**判据**：原书明说"**多数设计缺陷均出现在工艺性方面**"——这七问比强度计算更常命中。

## 模式三：焊缝位置四原则

**何时用**：设计焊接结构。

1. 便于焊接操作（手工焊/点焊/缝焊要求不同）
2. **避开最大应力区与应力集中部位**——尤其壳体拐角
3. 避开或远离机械加工面（精度高→焊后加工；精度低→焊前加工但留距离）
4. 考虑焊接变形对内应力与尺寸的影响

**陷阱**：为了工艺在拐角处加焊缝，结果拐角本来应力集中，焊完更脆。

## 模式四：冲压件失效归因

**何时用**：冲压件开裂/起皱。

| 现象 | 位置 | 原因 | 对策 |
|---|---|---|---|
| **开裂** | 凸模四角 | 承受筒壁传递的拉应力，材料变薄 | 加大圆角、减小拉深深度、改善润滑 |
| **折皱** | 凸缘 | 圆周切线方向压应力过大 | 加压边圈、增加板厚、减小拉深深度 |
| **弯裂** | 折弯线 | **弯曲线平行于板料纤维方向** | 改变排样，让弯曲线垂直于纤维方向 |

**附带判据**：拉伸件应"尽可能简单、对称"，法兰边宽度"尽可能一致"。

## 模式五：连接方式选型（三条分流）

**何时用**：两个零件要连起来。

```
① 要相对运动吗？
     ├ 要 → 活动连接
     │      ├ 转动 → 轴 + 轴承（高速高精用滚动，低速用滑动）
     │      ├ 移动 → 设计"轨道"结构
     │      ├ 螺旋 → 螺旋面作空间轨道
     │      └ 多自由度 → 单自由度组合
     └ 不要 → ②
② 要拆吗？
     ├ 不拆 → 焊接 / 铆接 / 胶接
     │      ├ 要抗振耐冲击 → 铆接
     │      ├ 要密封绝缘减震 → 胶接
     │      └ 大件薄板 → 焊接
     └ 要拆 → ③
③ 拆的频率与精度？
     ├ 高精度可重复 → 螺纹（金属）/ 预埋金属螺纹件（塑料）
     ├ 频繁快速 → 弹性变形连接
     ├ 要密封又要拆 → 管箍（软管）
     └ 永久紧配 → 过盈（热装）
```

**两条易错点**：
- **塑料件直接攻螺纹会"易扣"** → 必须预埋金属螺纹件
- **自攻钉的预孔要略小于螺钉，材料越硬预孔越大**

## 模式六：自由度校验（机构设计自检）

**何时用**：设计任何运动机构后。

**三条硬判据**：
1. 机构自由度数 **> 0**（否则不成立）
2. **驱动构件数 = 机构自由度数**（否则运动不确定）
3. 机构运动简图**按比例绘制**（便于校核与沟通）

**陷阱**：两自由度机构只给一个电机 → 机构会"乱跑"（运动不确定）。

## 模式七：传动选型（旋转怎么传）

**何时用**：需要在两轴之间传递旋转。

| 需求 | 选 | 关键约束 |
|---|---|---|
| 准确、大功率、紧凑 | 齿轮 | 模数标准化；重载用非直齿 |
| 大传动比 + 省空间 | 周转（行星）轮系 | 可达几千 |
| 旋转↔直线 | 齿轮齿条 | — |
| 单向传动 | 蜗轮蜗杆 | 蜗杆只能主动；传动比大 |
| 中心距大、成本低、可打滑 | 带传动 | **必须张紧**（增加包角） |
| 准确、大扭矩、耐恶劣 | 链传动 | **转速比 ≤5～6**；链轮齿数取**奇数**；两轮回转面必须同平面 |

**材料配对通则（提炼）**：**磨损快的那个用更硬/更耐磨的材料**——齿轮里是小齿轮，蜗轮蜗杆里是蜗杆。

## 模式八：间歇/往复机构选型

**何时用**：需要"走走停停"或"来回动"。

```
先把工作分解工序 → 按时间与顺序排空间布置 → 再选机构
```

| 需求 | 选 | 判据 |
|---|---|---|
| 精确停在某位置 | 分度机构（圆柱分度凸轮/槽轮） | 高速灌装、贴标要求高 |
| 一般间歇 | 槽轮、棘轮、欠齿轮 | — |
| 往复直线 | 曲柄滑块 / 凸轮 | — |
| 往复摆动 | 曲柄摇杆 / 摆动凸轮 | — |
| 复杂时序多动作 | **多凸轮同轴** | 机械式程序控制 |
| 单一机构不够 | 基本机构的**变化形式**或**组合机构** | 换机架、换驱动件 |

**凸轮两条铁律**：
- 高速时**不能只靠弹簧**保持接触 → 用**确动凸轮**（开沟槽夹住从动件）
- 凸轮曲线**按运动规律反算**，不是先画曲线

## 模式九：密封选型（四级分流）

**何时用**：有密封要求。

```
① 密封放在设计的哪一步？→ 必须一开始就纳入（放最后会无法弥补）
② 结合面有相对运动吗？
     ├ 有 → 动密封
     │     ├ 旋转轴 + 油润滑 → 唇形圈（油封）
     │     ├ 液压/气缸活塞杆 → 成型圈
     │     ├ 低速不重要 → 毛毡（但高速不能用）
     │     └ 要无磨损 → 非接触（螺旋槽气膜）
     └ 没有 → 静密封
           ├ 低压法兰 → 非金属软垫片（预紧力要大）
           ├ 高压法兰 → 金属垫片
           ├ 螺纹接头 → 生料带（聚四氟乙烯）
           ├ 重要阀门 → 聚四氟乙烯成型件
           └ 高压容器 → 自紧密封（压力越高越紧，可达 200MPa）
③ 要求多高？
     ├ 靠封闭工作（液压/气动）→ 要求高
     └ 储存传输（瓶/管）→ 看泄漏影响
④ 要绝对不 leak 吗？→ 不必也做不到，按成本平衡
```

## 模式十：安全结构六原理选型

**何时用**：做安全设计。

| 危险特征 | 选原理 | 做法 |
|---|---|---|
| 可提前感知、需人反应 | **警示** | 定变量→定阈值→定警示方式→设计转换装置 |
| 危险可被自动检测并化解 | **转换** | 用危险状态的输入参量驱动装置输出保护动作（安全阀、过载保护） |
| 载荷可预估且能承受 | **安全存在** | 规定载荷时间内承受所有可能事件 |
| 无法承受但可牺牲局部 | **有限损坏** | **刻意设计薄弱环节并引导破坏方向**（保险丝、安全销、爆破膜） |
| 部分件靠自身能力保护 | **借助** | 安全带 |
| 不让接触 | **隔离** | 防护罩 |
| 必须多重保障 | **冗余** | 积极（不打折）/ 消极（打折能用）/ 原理（换原理） |

**三档诚实度**：提示警告（不确定）→ 有限保护（减损）→ 完全保护（无损）。**别把第一档当第三档宣传。**

## 反模式清单

| 反模式 | 表现 | 后果 |
|---|---|---|
| **密封最后才想** | 结构定型后才加密封 | 无法弥补的设计缺陷（原书明说） |
| **拔模靠感觉** | 不给斜度或给太小 | 拉模、拖伤、擦烧 |
| **壁厚随形** | 哪里有空间就加厚 | 缩水、凹点、内部气孔 |
| **塑料件直接攻丝** | 不预埋金属件 | "易扣"失效 |
| **高速凸轮只靠弹簧** | 不用确动凸轮 | 从动件飞脱 |
| **先画凸轮曲线** | 不定运动规律 | 曲线无法满足运动要求 |
| **链轮齿数取偶数** | 不按奇偶选 | 磨损不均 |
| **追求绝对密封** | 不计成本 | 成本失控，且做不到 |
| **把警示当保护** | 只做指示灯就认为安全 | 保护程度不确定 |
| **安全裕度靠"感觉"** | 不做安全存在校核 | 载荷超出即失效 |
