# 数值速查（Cheatsheet）

> 全部数值出自刘宝顺《产品结构设计》。工程应用需按当前材料手册与设备校核。

## 一、注塑件拔模斜度（p033）★ 最常用

| 部位 | 斜度 |
|---|---|
| 内表面 | **15′** |
| 外表面 | **30′** |
| 孔 | 与内表面相同 |
| 加强筋 | **2°～5°** |

## 二、各工艺的精度/能力边界

| 工艺 | 关键数值 | 出处 |
|---|---|---|
| 熔模铸造 | 可铸 **0.5mm 孔**；最小壁厚 **0.3mm**；重量**≤25kg** | p17 |
| 压力铸造 | 铝合金最小壁厚 **0.5mm**；最小孔径 **0.7mm**；抗拉强度比砂型**提高 25%～30%** | p18 |
| 砂型铸造 | 大批量大型箱体仍以砂型为主 | p19 |
| 冲压 | 板厚 **>8～10mm** 时用热冲压 | p24 |
| 埋弧自动焊 | 适用**中厚钢板 6～60mm** | p23 |

## 三、铸件内应力处理

| 方法 | 参数 | 耗时 |
|---|---|---|
| 自然时效 | 粗加工后放室外 | **一年以上** |
| 人工时效（热处理） | 缓热到 **500～600℃**，保温后缓冷 | 数小时～数天 |
| 振动时效 | 激振器共振，微观塑性变形 | 复杂件**几十分钟** |

**铸钢件**：复杂/性能高 → 正火+回火；简单 → 退火。

## 四、连接方式的默认配合与参数

| 项 | 值 | 出处 |
|---|---|---|
| 轴承内圈与轴 | **过盈配合** | p51 |
| 轴承外圈与结构孔 | **过渡配合** | p51 |
| 自攻钉预孔 | 略小于螺钉；**材料越硬预孔越大** | p39 |
| 塑料件螺纹 | 必须**预埋金属螺纹件** | p39 |
| 薄金属板螺纹 | 局部**焊接加强块** | p39 |

## 五、齿轮与传动

| 项 | 值/规则 | 出处 |
|---|---|---|
| 传动比 | = 从动轮齿数 ÷ 主动轮齿数 | p74 |
| 转速比 | 与传动比**成反比** | p74 |
| 扭矩比 | 与传动比**成正比** | p74 |
| 模数 | 国家标准标准化、系列化 | p74 |
| 重载 | 多用**非直齿**齿轮 | p74 |
| 配对材料 | 小齿轮（转速高磨损快）表面硬度**高于**大齿轮 | p74 |
| 蜗杆/蜗轮 | 蜗杆用**钢材**，蜗轮用**铸铁** | p75 |
| 周转轮系传动比 | 可达**几千** | p76 |

## 六、链传动与带传动

| 项 | 值/规则 | 出处 |
|---|---|---|
| 链传动转速比 | **不宜太大，通常 ≤5～6** | p80 |
| 链轮齿数 | 取**奇数**（磨损均匀） | p80 |
| 两链轮位置 | 回转平面**同一平面**，轴线平行 | p80 |
| 张紧轮位置 | 设在**松边**，直径**等于或略小于小链轮** | p80 |
| 带传动 | **必须设张紧**，增加包角与接触压力 | p79 |

## 九、六原理对照表

| 技术类别 | 原理 | 一句话 |
|---|---|---|
| **提示性** | 警示 | 提前说 |
| **间接** | 转换 | 自动让（安全阀） |
| 间接 | 借助 | 自己扛（安全带） |
| 间接 | 隔离 | 挡住（防护罩） |
| **直接** | 安全存在 | 算够了 |
| 直接 | 有限损坏 | 牺牲一个 |
| 直接 | 冗余 | 多备几个 |

## 十、常用材料速查

### 铸造

| 材料 | 一句话 |
|---|---|
| 灰铸铁 | 最常用机器结构铸件；铸造性优、便宜 |
| 球墨铸铁 | 接近碳钢；受力复杂、要求强度韧性 |
| 蠕墨铸铁 | 导热好耐热、热裂倾向小；复杂与薄壁件 |
| 可锻铸铁 | 形状复杂、承受冲击的薄壁小件 |
| 铸造碳钢 | 综合力学高、可焊；必须热处理 |
| 铝硅合金 | **应用最广**的铸造铝合金 |
| 铝铜合金 | 强度高耐热；铸造性差耐蚀差 |
| 铝镁合金 | 强度高密度小耐蚀；铸造性差 |
| 铝锌合金 | 便宜铸造性优；耐蚀差热裂大 |

### 齿轮

| 材料 | 用于 |
|---|---|
| 钢 | 机械设备、重要传动 |
| 黄铜 | 仪表钟表（扭矩小、摩擦小、易加工） |
| 尼龙 | 轻载高速：照相机、复印机、打印机 |
| 塑料 | 电动玩具等不重要场合 |

### 胶粘剂

| 胶 | 用于 | 弱点 |
|---|---|---|
| 酚醛树脂 | 金属非金属结构胶 | — |
| 环氧树脂 | 金属塑料陶瓷；使用温度 **－60～200℃**（原文全角减号） | **脆、耐热差** |
| 聚氨酯 | 不同材料与软材料 | **耐热差**，耐低温好 |

## 十一、五条最容易被忽略的硬约束

| # | 约束 | 出处 |
|---|---|---|
| 1 | 密封要**一开始就纳入**，放最后会无法弥补 | p118 |
| 2 | 塑料件**不能直接攻螺纹**，要预埋金属件 | p39 |
| 3 | 高速凸轮**不能只靠弹簧**，要确动凸轮 | p97 |
| 4 | 冲压弯曲线**平行纤维方向会裂** | p30 |
| 5 | 焊缝**不要放在拐角**（应力集中） | p26 |
