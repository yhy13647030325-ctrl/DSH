## A.0 三十秒上手：怎么用这三张表

```
已知：轴 φ50 h6，孔 φ50 H7
① 查 A.1：φ50 在 30–50 段 → IT6 = 16 μm, IT7 = 25 μm
② 查 A.2：轴 h 的基本偏差 es = 0 → ei = 0 − 16 = −16 μm
      即 φ50 h6 = φ50(0 / −0.016)
③ 查 A.3：孔 H 的基本偏差 EI = 0 → ES = 0 + 25 = +25 μm
      即 φ50 H7 = φ50(+0.025 / 0)
④ 判配合：孔最小 50.000 − 轴最大 50.000 = 0（不紧）
            孔最大 50.025 − 轴最小 49.984 = +0.041
      → 间隙 0 ~ +41 μm → **间隙配合**
```

> **★ 记住两个恒等式**（基孔制 / 基轴制）：
> - **孔 H**：EI = 0，ES = +IT
> - **轴 h**：es = 0，ei = −IT
>
> 这两个是所有配合的锚点——**H7/h6 都是从这里推出来的**。

## A.4 孔代号的异号规则（J/K/M/N/P/R/S…）

> 偏差表只给了孔 A~H，因为**基孔制**才是常用体系。
> 其余孔代号按 GB/T 1800.2 的**异号规则**从轴推导：

| 孔 | 从哪个轴代号推 | 规则 |
|---|---|---|
| **J / K / M / N** | j / k / m / n | **ES = −ei**（异号，且 Δ 修正） |
| **P ~ ZC** | p ~ zc | **ES = −ei**（异号，且 Δ 修正） |

> **Δ（Delta）**：IT ≤ IT8 且基本尺寸 > 3 mm 时，需加修正量
> `Δ = ITn − IT(n−1)`。具体取值查标准原文，**本表未收录**。

**实用简化（设计阶段够用）**：
```
过渡配合 K7/h6、N7/h6 → 直接查机械设计手册的"常用配合表"
过盈配合 P7/h6、S7/h6 → 同上
```
> **不建议自己用异号规则硬算** —— Δ 修正容易错，查现成的配合表更可靠。

> **四本书都没给这个对应关系**，以下是通用机械设计经验值，
> **不是标准强制规定**，仅供设计初稿估算。

| 配合类型 | 常用 Ra (μm) | 说明 |
|---|---|---|
| **IT5–IT6 级配合面** | **0.2–0.4** | 精密轴承位、量规 |
| **IT7 级配合面** | **0.4–0.8** | 一般轴承位、精密滑动 |
| **IT8–IT9 级配合面** | **0.8–1.6** | 一般配合面 |
| **IT10–IT11** | **1.6–3.2** | 非配合面、一般加工面 |
| **不配合的自由面** | **3.2–12.5** | 铸造/粗铣面 |

> **★ 与刘宝顺 p051 那张图的对照**：
> 图上标了 **Ra 1.6 / 3.2**，圆柱度 0.006、跳动 0.015。
> 按上表反推：**Ra1.6 → 约 IT8–IT9**，
> 而 0.006 的圆柱度**远高于**这个等级该有的形状精度。
> **说明那张图是"混合精度"的**——配合面精、其余面粗。**这是正常做法，不是矛盾。**
