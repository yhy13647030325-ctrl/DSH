# 成型工艺选型决策表（Process Selection）

> 用途：造型定稿后，决定用什么工艺做。对应刘宝顺第一章四大工艺。

## 一、先回答六个问题

| # | 问题 | 选项 | 你的答案 |
|---|---|---|---|
| 1 | 材料是？ | 塑料 / 金属板 / 金属铸件 / 其他 | |
| 2 | 批量是？ | 单件 / 小批（<1000）/ 中批 / 大批（>10万） | |
| 3 | 刚度强度要求？ | 高 / 中 / 低 | |
| 4 | 造型复杂度？ | 简单 / 中等 / 复杂曲面 / 复杂内腔 | |
| 5 | 精度要求？ | 高（免机加工）/ 中 / 低 | |
| 6 | 单件成本 vs 模具成本，哪个更敏感？ | 模具 / 单件 | |

## 二、主决策表

| 工艺 | 最适条件 | 硬限制 | 单件成本 | 模具成本 |
|---|---|---|---|---|
| **砂型铸造** | 大件、复杂内腔、刚度强度要求高、批量不限 | 精度低、表面粗糙 | 中 | 低 |
| **熔模铸造** | 精度高、难切削合金、形状复杂 | **重量 ≤25kg**；材料贵 | 高 | 中 |
| **金属型铸造** | 有色合金、大批量 | **透气性差无退让性**，易冷隔裂纹 | 中 | 高 |
| **压力铸造** | 中小型低熔点有色合金、大批量 | 设备与压型贵；高熔点合金压型寿命低 | 低 | 很高 |
| **离心铸造** | 中空筒/管类 | **内表面质量差、孔尺寸不易控制** | 低 | 中 |
| **焊接** | 金属薄板、大件、单件小批 | **造型能力差、精度低、有变形** | 中 | 极低 |
| **冲压** | 金属薄板、大批量、复杂曲面 | **一件一模**，改模即改成本 | 极低 | 高 |
| **注塑** | 塑料、大批量、造型能力强 | **模具成本高，不适单件小批** | 极低 | 高 |

## 三、按场景速查

| 场景 | 结论 | 依据 |
|---|---|---|
| 单件定制的金属外壳 | **焊接** 或 砂型铸造 | 模具成本不能摊薄 |
| 十万件塑料外壳 | **注塑** | 唯一经济选择 |
| 十万件金属薄板外壳 | **冲压** | 一件一模但量大可摊 |
| 汽车变速箱壳体 | **压铸（铝）** 或 铸造 | 刚度强度 + 复杂内腔 |
| 高压阀门壳体 | **铸造碳钢** + 热处理 | p15 |
| 精密小件（≤25kg，复杂） | **熔模铸造** | 可铸 0.5mm 孔、0.3mm 壁 |
| 铸铁管、缸套 | **离心铸造** | 中空件专长 |
| 水龙头、水暖件 | **砂型铸造**（内腔复杂不便机加工） | p14 |
| 飞机机身铝合金板 | **铆接**（配合冲压件） | p35 |
| 汽车车门 | **冲压 + 焊接组装** | p22、p24 |
| 大件机床床身 | **砂型铸造**（灰铸铁，减振） | p13–15 |

## 四、每类工艺的结构附加要求

选完工艺后，结构必须满足该工艺的工艺性，逐项过：

### 铸造（七问）
- ☐ 避免大面积封闭薄壁（尤其水平）
- ☐ 减少凹凸
- ☐ 加拔模斜度（含内腔）
- ☐ 减少活块
- ☐ 保证砂型牢固
- ☐ 减少型芯（内腔改开式、用对称结构）
- ☐ 壁厚均匀

### 注塑（三要点）
- ☐ 拔模：内 15′ / 外 30′ / 孔同内 / 筋 2°–5°
- ☐ 壁厚均匀
- ☐ 过渡用圆角
- ☐ 避免表面凹陷
- ☐ 螺纹预埋金属件

### 冲压
- ☐ 弯曲线垂直纤维方向
- ☐ 弯曲部位加加强筋
- ☐ 拉伸件简单对称
- ☐ 法兰边宽度一致

### 焊接
- ☐ 焊缝避开拐角
- ☐ 避开最大应力区
- ☐ 避开加工面
- ☐ 考虑焊后变形

## 五、材料速查（按工艺）

| 工艺 | 常用材料 |
|---|---|
| 铸造 | 灰铸铁（最常用）、球铁、蠕铁、可锻铸铁、铸造碳钢（需热处理）、铝硅/铝铜/铝镁/铝锌合金 |
| 焊接 | 钢板、有色金属及其合金 |
| 冲压 | 钢板、铝板、铜板（看延展性与拉伸能力） |
| 注塑 | 热塑性塑料（除氟塑料几乎都可用）；某些热固性也可 |

## 六、成本敏感时的替代思路

| 原方案 | 太贵时改成 | 代价 |
|---|---|---|
| 压铸 | 砂型铸造 + 机加工 | 精度下降、加工量增加 |
| 冲压 | 焊接（板件拼） | 造型能力下降、精度低 |
| 注塑 | 或改小批量工艺（真空浇注等，**书中未涉及**） | — |
| 熔模铸造 | 砂型 + 机加工 | 精度与表面下降 |
| 一件一模（冲压） | 改用**组合冲压**合理利用板材 | 需重新排样 |

> 最后一条出自 p24：冲压"可采用组合冲压等方法，合理利用板材，产生的废料少"。**这是不改工艺只改排样的降本手段。**
