## 5.1 概述（p116）

### ★ 一条项目管理层面的警告（p116）

> 「**产品的密封结构设计、尤其是较为重要的产品密封结构设计，
> 一般不是产品设计的最后一个环节，应在产品结构设计的前期就予以考虑并设计，
> 否则，可能造成无法弥补的缺陷。**」

> **★ 这是本章最重要的一句话**：
> **密封不是"最后贴个垫圈"**。它影响：
> - **分型面位置**（ch01 铸造/注塑的分离面）
> - **配合精度**（ch07 的公差）
> - **装配顺序**（先装密封还是先装件）
> **前期不考虑，后期改不动。**

### 密封的两种功能（p116）

| 功能 | 说明 |
|---|---|
| **防止内部介质泄漏** | 油、气、水不外漏 |
| **防止外部介质侵入** | 灰尘、水、气不进内 |

> **★ 两个方向都要考虑**：
> 只防内漏的是"密封"，**同时防外侵的才是"防护"**（如轴承的防尘+防油）。

### 密封的分类（p116）

```
密封
├─ 静密封（无相对运动）
│   ├─ 垫片密封
│   ├─ 填料密封
│   ├─ O 形圈密封
│   └─ 研合面密封 / 自紧密封
└─ 动密封（有相对运动）
    ├─ 接触式
    │   ├─ 毛毡密封
    │   ├─ 唇形圈密封
    │   └─ 成型圈密封（V/U/L/J）
    └─ 非接触式
        ├─ 离心密封
        ├─ 螺旋密封
        ├─ 干气密封
        └─ 铁磁流体密封
```

## 5.2 静密封结构（p117–p120）

### ★★ 5.1.2 密封材料怎么选（p117，完整清单）

**选择密封材料的主要考虑因素（p117 原文）**：

> 「**产品的特点**（如**工作温度、接触介质、运动状况**等），
> **密封的要求**（**可靠性、耐久性**等），
> **密封方式**，**维护维修**（**装拆方便性、互换性、频繁程度**），
> **加工、制造工艺性和成本因素**等。」

**六类常用材料（p117，完整）**：

| 材料 | 具体形式 | 用于 |
|---|---|---|
| **金属** | **铜片垫、钢片垫**（冲压成型）；**纯铜垫** | 钢片垫：**发动机缸体等密封**；纯铜垫：**液压系统的静密封** |
| **聚四氟乙烯** | **成型件**；**生料带** | 成型件：**重要的阀门**；生料带：**水暖管、燃气管道接头等螺纹密封** |
| **橡胶** | — | **水截门、低压无腐蚀管道对接头** |
| **密封圈** | **O 形圈、V 形圈、Y 形圈、唇形圈**，由**橡胶、聚氨酯**等制成，**标准化零件** | **液压、气动系统的动、静密封** |
| **毛毡** | — | **机械系统油封** |
| **密封胶** | **环氧树脂、酚醛树脂、氯丁胶**等 | **按连接材料和密封要求选用** |

> **★★ 三条实用判据**：
> ① **螺纹密封用生料带**（聚四氟乙烯）——这是最日常的
> ② **密封圈是标准件**——**不必自制，查手册选型**
> ③ **金属垫用于高温高压**（橡胶不行的地方）

### ★★ 5.2.1 垫片密封（p117）

**原理（p117 原文）**：
> 「在密封结合面间**夹入金属或非金属垫片**，实现密封。
> 垫片密封**需要一定的压力施加在垫片上，使垫片变形后充满间隙**。
> 垫片密封**通常用螺纹紧固件施加预紧力**，机械结构上**采用法兰形式较简单、有效**。」

> **★★ 核心机理：靠"变形填满间隙"，而变形靠"预紧力"**。
> 所以垫片密封的三个变量：
> | 变量 | 影响 |
> |---|---|
> | **垫片材料软硬** | 越软越易变形（但强度低） |
> | **预紧力大小** | 不足→漏；过大→压溃 |
> | **法兰刚度** | 不足→预紧力不均 |

**★ 五种法兰垫片结构（p117，图 5-1）**

| 图 | 结构 | 特点（原文） |
|---|---|---|
| **(a)** | **平垫**（非金属软垫片，光面法兰） | 「**垫片面积大，法兰受力均匀，但需螺栓预紧力大**」 |
| **(b)** | **凹凸面法兰**（垫片在凹槽内） | 定位好，垫片不易挤出 |
| **(c)** | **榫槽面法兰** | 密封性最好，加工复杂 |
| **(d)** | **梯形槽法兰** | 垫片受约束，抗压 |
| **(e)** | **锥形垫**（金属垫） | 「**主要用于压力管道连接接头**」 |

> **★★ 关键判据（p117 原文）**：
> 「图 5-1(a)～5-1(d) 的垫片**为非金属软垫片，适于设备和管道连接密封**，
> **垫片面积大，法兰受力均匀，但需螺栓预紧力大**。
> 图 5-1(e) **采用金属垫，主要用于压力管道连接接头**。」

> **★ 选型逻辑**：
> | 工况 | 选 |
> |---|---|
> | 低压、大口径、设备法兰 | **(a) 平垫**（便宜、受力均匀） |
> | 中压、需定位 | **(b)(c)(d) 带槽**（垫片不跑） |
> | **高压管道** | **(e) 锥形金属垫** |

**★ 螺纹连接的封塞/管接头也用垫片（p117）**
> 「机械设备、液压系统等使用**螺纹连接的封塞、管接头也使用垫片密封**，如图 5-2」

### ★★ 5.2.2 填料密封（p118）

> **组合式密封的典型**：填料（软材料）被压盖压紧，充满轴与壳体间的间隙。

**★ 图 5-3 ~ 5-6 的结构演进（p118）**：
从简单压盖，到**带隔环/带油环**，到**高压用多重填料**。

> **★ 填料密封的核心参数是"压盖压缩量"**：
> 太松→漏；太紧→摩擦大、发热、轴磨损。
> **所以需要"可调压盖"**（定期拧紧）。

### ★★ 5.2.3 O 形圈密封（p118–p119，图 5-7~5-9）

**七种安装形式（p119，图 5-7 ~ 5-9）**：

| 形式 | 结构 |
|---|---|
| **径向密封（轴用）** | O 圈在轴上，径向压缩 |
| **径向密封（孔用）** | O 圈在孔槽内 |
| **端面密封（平面）** | O 圈在两平面之间 |
| **角密封** | 在转角处 |
| **带挡圈的动密封** | 高压时加挡圈防挤出 |
| **带挡圈的静密封** | 同上 |
| **特殊截面** | 异形 |

> **★★ 两条关键判据**：
> ① **高压必须加挡圈**（否则 O 圈被挤入间隙而损坏）
> ② **动密封的压缩率小于静密封**（动密封要考虑摩擦与磨损）

### ★ 研合面密封与自紧密封（p120）

**研合面密封**：
> 两金属面**精密研磨后直接贴合**，靠分子间力 + 表面张力密封。
> **用于高真空、超高压**（无垫片可用时）。

**自紧密封（p120）**：
> **利用介质本身的压力使密封件压紧** → **压力越高，密封越紧**。
> **用于高压容器**（见 §5.4）。

> **★ 这是密封设计的"反向思维"**：
> 一般密封是"压力越大越难封"；
> **自紧密封把压力变成密封力的来源**（见 p127 的 200MPa 实例）。

### ★★ 5.3.1 毛毡密封（p121）

**特点（p121 原文）**：
> 「毛毡密封**结构简单，成本低，但容易脏污失效，不适于高速场合**。」

| 优点 | 缺点 | 不可用 |
|---|---|---|
| 结构简单、成本低 | **容易脏污失效** | **高速场合** |

**图 5-10 四种毛毡密封结构（用于轴承盖）**

> **★ 判据**：**毛毡 = 低速、清洁环境、低成本**。
> 一旦有粉尘或高速，就必须换唇形圈。

### ★★★ 5.3.2 唇形圈密封（p121–p122）

#### 自紧机理（p121，原文最完整的一段）

> 「唇形圈**因截面形状呈唇状而得名**。如图 5-11 所示，
> **一般唇形圈都带有金属骨架和螺旋弹簧，起自紧作用。**
> **在自由状态下，唇形圈内径比轴颈小**，
> **当安装到轴上以后，其唇口产生一定的弹性变形**，
> **加之其自紧弹簧的收缩力，唇形圈对密封轴产生一定的抱紧力**，
> **从而堵住间隙，防止泄漏，达到密封的目的。**」

**★ 三步自紧链**：
```
① 自由状态：内径 < 轴颈（过盈）
② 装入后：唇口弹性变形（径向压紧）
③ 自紧弹簧：持续收缩力（补偿磨损）
```

> **★★ 为什么带弹簧**：
> **橡胶会老化松弛，弹簧提供"永不衰减"的压紧力**。
> 这就是唇形圈寿命远长于纯橡胶圈的原因。

> 「唇形圈为**系列化产品**，有**各种截面和结构形式**，**尺寸系列可在设计手册中查到**。」

**★ 图 5-11 十二种唇形圈结构（p121）**：从单唇到双唇、带副唇（防尘）、带板片弹簧（耐腐蚀介质）

#### ★★ 应用与安装要求（p122）

> 「唇形圈**主要用于旋转轴的密封，特别是机械内采用液体油脂方式润滑的场合，
> 密封效果好，俗称油封。**」

**★★★ 图 5-12 的安装尺寸（p122，全书唯一的唇形圈安装参数）**

| 参数 | 值 | 含义 |
|---|---|---|
| **H₁ = H −（1~2）** | — | **唇形圈高度 = 座孔深度 −1~2mm**（留余量） |
| **φ3-6** | 3~6 mm | **拆卸孔直径**（便于取出） |
| **3-4 孔** | 3~4 个 | **拆卸孔数量** |
| **Ra 0.8（抛光）** | 0.8 μm | **与唇口接触的轴表面粗糙度** |
| **3.2** | 3.2 μm | **座孔内壁粗糙度** |
| **d（φ）** | — | **轴径** |
| **D（φ）** | — | **座孔直径** |

> **★★ 三条可直接照做的结论**：
> ① **轴表面必须 Ra0.8 抛光**（否则唇口磨损快）
> ② **座孔 3.2 即可**（不需抛光）
> ③ **座孔深度留 1~2mm 余量 + 设 3-4 个 φ3-6 拆卸孔**

**★ 三种使用型式（p122，图 5-13）**：

| 图 | 型式 | 作用 |

| **(a)** | **防漏油式** | 单唇朝内，只防内泄 |
| **(b)** | **防尘式** | 单唇朝外，只防外侵 |
| **(c)** | **防尘防漏油式** | **双唇**（主唇防油 + 副唇防尘） |

### ★★★ 5.3.3 成型圈密封（p122–p123）

**与唇形圈的区别（p122 原文）**：
> 「成型密封圈**外观上与唇形圈相似，但一般没有骨架且用途与唇形圈大不相同**。」
> 「一般成型密封圈**按其截面形状命名，如 V 形圈、Y 形圈、U 形圈、L 形圈等**。」

| | 唇形圈 | 成型圈 |
|---|---|---|
| **骨架** | **有金属骨架** | **一般没有** |
| **自紧弹簧** | **有** | 一般没有 |
| **用途** | **旋转轴**（油封） | **往复运动**（活塞/活塞杆） |
| **命名** | 按用途 | **按截面形状**（V/U/Y/L） |

**★ 材料（p122）**：
> 「成型密封圈常用材料为**合成橡胶、夹布橡胶、合成塑料**等，
> 也可用**皮革、铝、铜、不锈钢**制作，
> 一般采用**模压成型**，**塑料、金属制密封圈也可采用机加工成型**。」

**★★ 自紧密封机理（p123）**：
> 「成型密封圈**内、外径尺寸有一定余量，安装后产生一定的变形，
> 并可借助介质的压力形成自紧密封。**」

> **★ 注意"借助介质压力"**：
> **成型圈是"自紧"的**——压力越高，圈被压得越紧（与 §5.2 的自紧密封同原理）。
> **这是往复密封（液压缸/气缸）必需的**，因为压力波动大。

### ★★ 5.3.4 非接触密封（p124–p125）

> **原理**：**不靠接触，靠"间隙 + 流体阻力"或"离心力"阻止泄漏**。
> **优点：无磨损、寿命长、适合高速**；**缺点：有微量泄漏**。

**四类非接触密封（p124–p125）**：

#### ① 离心密封（p125，图 5-21）

| 图 | 结构 | 原理 |
|---|---|---|
| **(a)** | **背叶片** | 叶轮背面设叶片，**把泄漏液甩回** |
| **(b)** | **副叶轮** | 独立副叶轮产生反向压力 |
| **(c)** | **甩油环/甩水盘** | 旋转盘把液体甩向外周 |

> **★ 判据**：**离心密封 = 靠旋转产生的离心力**，**停机时失效**（转速低时无效）。

#### ② 螺旋密封（p124）

> 轴上或孔内加工**螺旋槽**，旋转时把介质**沿轴向"泵"回**。

#### ③ ★★★ 干气密封（p125，图 5-22，最有数值的一段）

> 「其端面**开设有深度 0.1mm 的螺旋槽**，如图 5-22(b)。
> 当**干燥空气被输送到密封面时**，由于**动环的转动螺旋槽将气体由动环外周送到螺旋槽根部，
> 并逐步提高气体压力**，**槽内压力造成贴合面形成 2.5～5μm 的间隙**，
> 故在**正常运转状态，贴合面处于非接触状态**。」

**★★ 三个关键数值**：
| 参数 | 值 |
|---|---|
| **螺旋槽深度** | **0.1 mm** |
| **运转时间隙** | **2.5 ~ 5 μm** |
| **介质** | **干燥空气** |

> **★★ 干气密封的原理是"用气体自己顶开"**：
> ```
> ① 旋转 → 螺旋槽泵气
> ② 气体压力升高 → 顶开贴合面
> ③ 形成 2.5~5μm 气膜 → 非接触
> ④ 停机 → 气膜消失 → 端面贴合（静止密封）
> ```
> **★ 这是"动时不接触、静时接触"的智能密封**——
> **既无磨损（运转），又不泄漏（停机）**。
> **用于压缩机、高速泵**等高端场合。

**★ 图 5-22 的九个件（p125）**：
1、6—**O 形圈**；2—**弹簧**；3—**静环**；4—**动环**；5—**传动销**；7—**轴套**；8—**轴**；9—**静环座**

> **★ 注意"静环 + 动环 + 弹簧 + O 圈"是机械密封的标准配置**：
> **弹簧提供初始压紧，O 圈做二次密封**。

## 5.4 特殊密封结构（p125–p128）

### ★ 概述（p125）

> 「产品的密封要求**服务于其功能需要**，**特殊用途的产品有特殊的密封要求**。」

### ★★ 5.4.1 铁磁流体密封（p126，图 5-23）

**定义（p126 原文）**：
> 「图 5-23 的结构称为**铁磁流体密封**。
> **铁磁性超细微粒在低挥发度的液体中构成稳定的胶体溶液，即铁磁流体。**
> **铁磁流体在密封间隙中受磁场作用，形成强韧的液体膜，阻止泄漏。**
> **铁磁流体为液体，对旋转轴无摩擦。**」

**图 5-23 五个件**：1—**永久磁铁**；2—**软铁极板**；3—**非导磁轴**；4—**铁磁流体**；5—**导磁轴**

> **★★ 核心优势：「铁磁流体为液体，对旋转轴无摩擦」**
> **这是唯一"零摩擦 + 零泄漏"的动密封方案。**

> 「铁磁流体密封**用于高速、高真空等密封场合**。」

| 优点 | 适用 |
|---|---|
| **无摩擦**（液体） | **高速** |
| **零泄漏** | **高真空** |

### ★★ 5.4.2 三种特殊管道密封（p126，图 5-24）

| 图 | 结构 | 特点（原文） |
|---|---|---|
| **(a)** | 1—壳体；2—**橡胶圈**；3—V 形槽；4—管子 | 「**结构简单、密封可靠，适用于快速装拆场合**」 |
| **(b)** | 1—接头体；2—**螺母**；3—压套；4—管子 | 「**通过螺母和锥面将连接管扩口连于锥面，适用于液压系统等薄壁金属管路连接**」 |
| **(c)** | 1—连接套；2—**球头**；3—管子 | 「**用球头管套实现管子连接，允许两管不同轴线的连接及连接位置相对偏移**」 |

> **★★ 三种的适用判据**：
> | 需求 | 选 |
> |---|---|
> | 快速装拆 | **(a) 橡胶圈 + V 形槽** |
> | 液压薄壁管 | **(b) 螺母锥面扩口** |
> | **允许轴线偏移/角度偏差** | **(c) 球头** |

> **★ (c) 球头密封是"用球面吸收装配误差"**——与 ch02 §2.3.4 柔性连轴器同思路。

### ★★★ 5.4.3 高压容器密封（p127，图 5-25，唯一的高压数值）

| 图 | 结构 | **使用压力** | 特点（原文） |
|---|---|---|---|
| **(a)** | **顶盖 + 平垫 + 螺栓** | **20～50 MPa** | 「**结构简单**」 |
| **(b)** | **软金属垫 + 双锥环 + 托圈** | **200 MPa** | 「**加工精度要求不高，预紧力小，具有自紧密封作用**」 |
| **(c)** | **卡箍 + C 形环** | — | 「**结构简单，有自紧密封作用，装拆方便**」 |

> **★★★ 这是全书唯一的压力等级数据**：
> **平垫 20~50 MPa；双锥环自紧 200 MPa（4~10 倍）。**

> **★ 为什么双锥环能到 200MPa**：
> **它是"自紧"的**——介质压力越高，锥环被压得越紧（§5.2 的自紧原理）。
> **所以高压容器不用"加厚螺栓"，而用"双锥环"。**

### ★★ 5.4.4 民用产品密封实例（p126–p128，图 5-26~5-28）

**① 冰箱门密封（p126）**
> 「**冰箱门密封严，冰箱的冷冻、冷藏效果好且节能，但需经常开启取放物品，因此设计上需兼顾。**
> 现代冰箱门的密封一般**采用镶磁性条的中空合成橡胶专用密封条**解决了上述需要矛盾。」
> 「一般而言，**工业机械设备的密封要求和复杂程度要比一般民用产品高得多**，
> 这也是我们在本章**主要围绕机械设备密封问题讨论**的原因。
> **在普通产品上借用这些方法，设计处理起来往往显得非常简单、容易。**」

> **★★ 这段话点明了本章的定位**：
> **本章讲的是"工业机械级"密封**（要求最高）；
> **民用产品的要求低得多，借用这些方法会很轻松。**
> **所以做民品时，本章是"过剩设计"的参考库。**

**② 药瓶封盖（p127，图 5-26）**
> 「药瓶，**内口用铝箔复合纸用高频热封方法粘合密封，瓶盖开设方便启闭口，用环状弹性结构密封**。」

> **★ 两种密封并存**：**一次性密封（铝箔热封）+ 可重复密封（弹性卡扣）**。
> 这是药品包装的典型要求：**开封后仍需密封**。

**③ 金属罐截门/喷雾罐（p127–p128）**

**左：打火机煤油罐**
> 「罐头部安装有**塑料制煤油释放截门，节门工作原理与水龙头类似**，
> 依靠**顶部的旋转头控制**，**旋转头转到一定角度，截门内部通道打开、接通**，可将煤油倾倒出来；
> **压下旋转头，则关闭截门。**」

**右：喷雾罐（图 5-27）**
> 「金属罐为**喷雾罐，装有压力的液体，头部装有喷射控制阀门，按下阀门，液体由阀门口喷出。**」

**★★★ 图 5-28 喷雾罐阀门结构（p128，13 件 + 全部尺寸）**

| # | 件名 | 作用 |
|---|---|---|
| 1 | **按钮喷孔** | 出料口 |
| 2 | **按钮** | 手动按压 |
| 3 | **固定杆** | 导向 |
| 4 | **阀杆** | 中心杆 |
| 5 | **阀杆喷孔** | 通道 |
| 6 | **阀杆** | 密封面载体 |
| 7 | **溶胶内衬** | **密封元件**（软胶） |
| 8 | **陷窝** | 定位 |
| 9 | **阀杆垫圈** | 二次密封 |
| 10 | **弹簧** | **复位 + 压紧** |
| 11 | **阀体** | 外壳 |
| 12 | **排气孔** | 泄压 |
| 13 | **阀体喷孔** | 进料口 |

**图 5-28 的全部尺寸标注（p128）**：
`11.6 / 9.91 / 13.6 / 11.4 / 5.94 / φ3.30 / 1.88 / 11.2 / 3.5 / 9.02 / 6.60 / φ9.39`

> **★★ 这条是本章唯一的"完整产品图纸"**：
> **13 个零件、全部关键尺寸都给全了**。
> **原文 p127 说「阀门闭合状态时，依靠弹簧压力闭合液体通道，
> 此时的密封元件为阀杆肩部软垫片」**——
> **密封靠"弹簧 + 软垫片"，不是靠加工精度**。
>
> **★ 这个设计的精妙处**：
> | 状态 | 弹簧 | 密封 |
> |---|---|---|
> | **闭合（未按）** | 弹起 | **弹簧压紧软垫片 → 密封** |
> | **开启（按下）** | 压缩 | 垫片离开 → **通道打开** |
> **一个弹簧同时实现"复位 + 密封"**。

## 5.6 密封方式选型树（我的提炼）

> 把全章的判据汇总成一棵决策树。**这是本章最实用的输出。**

```
密封需求
│
├─ 有相对运动吗？
│   │
│   ├─ 无（静密封）
│   │   ├─ 低压/大口径 ────────→ 平垫片（5.2.1）
│   │   ├─ 中压/需定位 ────────→ 凹凸面/榫槽面垫片
│   │   ├─ 螺纹接头 ──────────→ 生料带 / 组合垫
│   │   ├─ 液压/气动 ─────────→ O 形圈（静密封用）
│   │   ├─ 高压管道 ──────────→ 锥形金属垫（5-1e）
│   │   └─ 超高压容器 ────────→ 双锥环自紧（200MPa）
│   │
│   └─ 有（动密封）
│       │
│       ├─ 往复运动（活塞/杆）
│       │   ├─ 低压 ──────────→ O 形圈
│       │   └─ 中高压 ────────→ 成型圈 V/U/L/J（成组）
│       │
│       └─ 旋转运动（轴）
│           ├─ 低速 + 清洁 ───→ 毛毡（便宜）
│           ├─ 一般工况 ──────→ 唇形圈（有骨架+弹簧）
│           ├─ 多尘 ─────────→ 唇形圈双唇（防尘防油）
│           ├─ 高速 ─────────→ 非接触式
│           │   ├─ 液体 ──────→ 离心 / 螺旋密封
│           │   ├─ 气体 ──────→ 干气密封（2.5~5μm）
│           │   └─ 高真空 ────→ 铁磁流体密封（零摩擦）
│           └─ 不允许泄漏 ────→ 机械密封（动环+静环+弹簧）
```
