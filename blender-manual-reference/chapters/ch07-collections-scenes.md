# 第 7 章：集合与场景

> 出自《Blender 2.92 Manual》Scenes & Objects 区。

## 7.1 集合（Collections）

> **官方机制**：集合是**物体的分组容器**，可嵌套。**集合可整体隐藏/禁用/链接。**

| 操作 | 快捷键/路径 |
|---|---|
| 移入集合 | **M**（Move to Collection） |
| 链接到集合 | **Shift-M**（Link to Collection） |
| 新建集合并加入 | **Ctrl-G**（Create New Collection） |

## 7.2 集合的显示控制（官方表格摘）

| 操作 | 快捷键 |
|---|---|
| 切换 restriction 状态 | **Shift-LMB**（反转） |
| 隔离含选中物体的集合 | **Shift-Ctrl-LMB** |
| 禁用含选中物体的集合 | **Shift-Alt-LMB** |
| 复制/粘贴 restriction 状态 | **Ctrl-LMB** |

## 7.3 场景（Scenes）

> 一个 .blend 可有**多个场景**。适合**分件建模**或**分镜头渲染**。
