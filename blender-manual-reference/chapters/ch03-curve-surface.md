## 3.0 本章解决什么

> **原文（`modeling/curves/introduction.xhtml`）**：
> 「**曲线与曲面是 Blender 里特殊类型的物体。
> 它们由数学函数（插值）表达，而不是一系列点之间的线性插值。**
> **Blender 提供 Bézier 和 NURBS 两种。**」

**★★★★★ 一句话定位：曲线是"用数学函数定义的物体"，不是"点连成的线"。**

| 维度 | 网格（Mesh） | **曲线（Curve）** |
|---|---|---|
| **定义方式** | **点的线性插值** | **★ 数学函数插值** |
| **数据量** | 每个顶点都要存 | **★ 只要控制点** |
| **顶点级控制** | **★ 容易** | **★ 困难** |

> **★★★ 判据：想要"顶点级精修"→ 用网格；想要"沿路径挤出/少占内存"→ 用曲线。**
> **★ 这是本章的总纲（原文明确给出了这个权衡）。**

## 3.1 ★★★★★ 曲线 vs 网格：四个权衡（本章最重要的判断）

> **原文（`introduction.xhtml`，本节逐句）**：

**① 内存与存储**

> 「**使用曲线而不是多边形网格的主要优势是：曲线用更少的数据定义，
> 因此在建模时能用更少的内存和存储空间产生结果。**
> **然而，这种程序化的曲面方法会增加渲染时的需求。**」

| 阶段 | 曲线 | 网格 |
|---|---|---|
| **建模时** | **★ 省内存/存储** | 费 |
| **★ 渲染时** | **★ 更费** | 省 |

> **★★★ 判据：曲线是"建模省、渲染费"** ——
> **★ 因为它要在渲染时"算"出曲面，而不是"读"现成的面。**

**② 只有曲线能做的**

> 「**某些建模技术，例如沿路径挤出轮廓，只能使用曲线。**」

> **★★ 判据：「沿路径挤出轮廓」是曲线的独占能力** ——
> **★ 这与 ch08 的 Curve 修改器（缆绳/履带）完全对应。**

**③ 只有网格擅长的**

> 「**另一方面，使用曲线时，顶点级控制更困难，
> 如果需要精细控制，网格编辑可能是更好的建模选择。**」

> **★★ 判据：要"精修每个点"→ 用网格**（曲线做不到）。

**④ Bézier 与 NURBS 的选择**

> 「**Bézier 曲线通常更直观，因为它们从你设置的控制点开始和结束；
> 但当曲线有很多弯折时，NURBS 曲线对计算机计算更高效。**」

| 类型 | 优势 | 劣势 |
|---|---|---|
| **Bézier** | **★ 直观（起止于控制点）** | 弯折多时慢 |
| **NURBS** | **★ 弯折多时高效** | 不直观 |

> **★★ 原文还点出**：「**两者之间的选择往往更多是"背后如何计算"的问题，
> 而不是"建模者视角看起来如何"的问题。**」
> **★ 判据：Bézier 与 NURBS 的差别主要在算法，不在外观。**

## 3.3 ★★★★★ 曲线的结构（Structure & Splines）

> **原文（`modeling/curves/structure.xhtml`）**：
> **曲线由"控制点（control points）"定义"控制多边形（control polygon）"。**

**★★★★★ 三层结构**：

```
控制点（Control Points / Control Vertices）
   ↓ 连起来
控制多边形（Control Polygon）
   ↓ 插值
★ 实际曲线（用数学函数算出来）
```

> **★★ 判据：控制点是"手柄"，实际曲线是"算出来的"** ——
> **★ 所以"控制点不在曲线上"是正常的（Bézier 的中间控制点尤其如此）。**

**★★★★ Spline（样条）的概念**：
> **一条 Curve 物体可以包含多条 Spline** ——
> **★ 每条 Spline 有自己的控制点序列。**
> **★ 判据：Curve 是"容器"，Spline 是"其中一条线"。**

## 3.4 ★★★★★ 曲线编辑（Editing）

> **原文（`modeling/curves/editing/`）**：

### 3.4.1 ★★★★ 控制点的两种类型

> **原文（`control_points.xhtml`）**：

| 类型 | 作用 |
|---|---|
| **★ 控制点（Control Point）** | **★ 影响曲线走向（不一定是曲线上的点）** |
| **★ 手柄（Handle）** | **★ Bézier 专有，控制切线方向与长度** |

**★★★★ Bézier 手柄的两种模式（原文）**：

| 模式 | 行为 |
|---|---|
| **★ 自由（Free）** | **★ 两侧独立调整** |
| **★ 对齐（Aligned）** | **★ 两侧共线但长度可不同** |
| **★ 向量（Vector）** | **★ 指向下一个控制点** |
| **★ 自动（Auto）** | **★ 自动计算平滑** |

> **★★ 判据：手柄类型决定"曲线在该点的弯曲方式"** ——
> **★ 想"尖角"→ 用自由模式并让两侧不共线；想"平滑"→ 用对齐或自动。**

### 3.4.2 ★★★★★ 段（Segments）—— 曲线的"分辨率"

> **原文（`segments.xhtml`）**：

**★★★★★ 一段曲线由"多少个多边形面"近似** ——
> **★ 这是"曲线渲染质量 vs 性能"的开关。**

| 概念 | 作用 |
|---|---|
| **★ Resolution（U）** | **★ 沿曲线方向的分段数** |
| **★ Preview / Render U** | **★ 视口 / 渲染分别设** |

> **★★★ 判据：曲线转成曲面时的"光滑度"由 Resolution 决定** ——
> **★ 视口可以低（快），渲染必须高（光滑）。**

## 3.5 ★★★★★ 曲线属性（Properties，本节最实用）

> **原文（`modeling/curves/properties/`）分三组**：

### 3.5.1 ★★★★ Shape（形状）

> **原文（`shape.xhtml`）**：

| 参数 | 作用 |
|---|---|
| **★ Resolution U** | **★ 曲线方向分段** |
| **★ 2D / 3D** | **★ 2D 曲线是平的；3D 可在空间弯曲** |
| **★ Fill Mode** | **★ None / Front / Back / Full**（填充方式） |
| **★ Twist Method** | **★ 曲线的"扭转"算法** |
| **★ Radius** | **★ 曲线各点的半径（可做粗细变化）** |

**★★★★★ `Radius` 是"可变粗细"的关键**：
> **★★ 曲线的每个控制点有自己的 Radius** ——
> **★ 所以一条曲线可以"中间粗两头细"。**
> **★ 这与 ch08 的缆绳（均匀粗细）不同 —— 那里用 Array + Curve，不用 Radius。**

**★★ `2D / 3D` 的区别**：
> **★★ 2D 曲线"只在 XY 平面"，可以填充成面**；
> **★ 3D 曲线"可任意空间弯曲"，但不能填充。**

### 3.5.2 ★★★★★ Geometry（几何）

> **原文（`geometry.xhtml`，8,690 字符，本分区最大文件）**：

**★★★★★ 这一组决定"曲线如何变成可见的几何"**：

| 参数 | 作用 |
|---|---|
| **★ Extrude** | **★ 沿 Z 方向挤出（把线变成"带"）** |
| **★ Bevel Depth** | **★ 沿法向加厚（把线变成"管"）** |
| **★ Bevel Object** | **★ 用另一个曲线作为截面（自定义管形）** |
| **★ Bevel Resolution** | **★ 截面的细分数** |
| **★ Taper Object** | **★ 用曲线控制"粗细变化"** |
| **★ Offset** | **★ 偏移** |
| **★ Fill Caps** | **★ 给挤出的两端加封盖** |

**★★★★★ 这是"曲线建模"的完整工具箱**：

```
一条线
   ↓ Extrude      → ★ 变成"带"（有宽度）
   ↓ Bevel Depth  → ★ 变成"管"（有厚度/圆截面）
   ↓ Bevel Object → ★ 变成"任意截面形状的管"
   ↓ Taper Object → ★ 沿长度变化粗细
   ↓ Fill Caps    → ★ 两端封口
```

> **★★★ 判据：曲线到 3D 实体的四种途径是"Extrude / Bevel Depth / Bevel Object / Taper"。**
> **★ 这四个参数的组合，能覆盖从"扁平带"到"异形管"的所有需求。**

**★★★★ `Bevel Object` 是"自定义截面管"的关键**：
> **★★ 用一条"圆"曲线当截面 → 得到圆管；**
> **★ 用一条"方框"曲线当截面 → 得到方管。**
> **★ 这与 ch10 履带的"圆柱 + Curve 修改器"是不同路线：**
> **★★ 曲线自带 Bevel，不需要另建圆柱。**

### 3.5.3 ★★★★ Path Animation（路径动画）

| **★ Path Animation** | **★ 勾选后曲线可"沿自身运动"** |

## 3.6 ★★★★★ 曲面（Surfaces）

> **原文（`modeling/surfaces/`）**：

**★★★★ 曲面与曲线的关系（原文）**：
> **「Bézier 曲线和 NURBS 曲线与曲面，都是通过一组"控制点"来定义的。」**
> **★ 所以"曲面 = 曲线的二维版本"**（曲线有 1 个参数 U，曲面有 2 个参数 U/V）。

| 对象 | 参数 | 控制点 |
|---|---|---|
| **曲线** | **1 个（U）** | 一排 |
| **★ 曲面** | **★ 2 个（U/V）** | **★ 网格状一片** |

**★★★★★ 曲面 vs 网格的核心区别**：

> **★★ 曲面的控制点是"2D 阵列"，所以"改一个点会影响一小片"。**
> **★ 而网格是"每个顶点独立"。**
> **★ 这与硬表面的"Quad 拓扑"（`blender-hard-surface`）是两套思路。**

**★★ 曲面的用途**：
> **★★ Blender 的曲面主要用于"平滑过渡的有机形状/工业曲面"**；
> **★ 硬表面建模几乎不用 NURBS 曲面**（用 Subdivision 更多）。
