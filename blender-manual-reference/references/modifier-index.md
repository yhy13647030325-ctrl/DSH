# 修改器全索引（57 个）

> 出自《Blender 2.92 Manual》建模区。**这是本技能相对 `blender-hard-surface` 的最大增量**：
> 项目书只讲了 8 个修改器，**这里是全部 57 个**。
> 每个条目给：**官方定义 + 关键选项 + 规模**（规模 = 手册里该条的字符数，可判断详略）。

**添加路径（通用）**：右侧 **Modifier Properties 标签**（扳手图标）→ **Add Modifier** → 选类别。

---

## 一、硬表面建模主力（8 个，项目书也讲，此处补官方细节）

### Mirror Modifier（4,308 字符）

> 「**沿物体局部 X、Y 和/或 Z 轴，以物体原点为中心**镜像网格。也可以使用另一个物体作镜像中心。」

**关键选项**：

| 选项 | 官方说明 |
|---|---|
| **Axis（X/Y/Z）** | 沿哪个轴镜像，**可多选** |
| **Mirror Object** | 用另一个物体作镜像中心（不填则用自身原点） |
| **Bisect（X/Y/Z）** | **在镜像时同时切开**穿过镜像面的几何 |
| **Flip** | 配合 Bisect，反转保留哪一半 |
| **Use Clipping** | 防止顶点越过镜像面 |
| **Merge** | 合并镜像面上的顶点，阈值可调 |
| **Merge Threshold** | 合并距离阈值 |
| **Vertex Groups** | 镜像时是否保留顶点组权重 |
| **U/V** | 镜像 UV |

**★ Topology Mirror（手册专门展开）**：
> 「要让 Topology Mirror 生效，**三个 Mirror Axis 中至少要启用一个**。」
> 「用镜像轴处理镜像几何时，**被镜像的顶点必须精确放置**。如果它们没有精确位于镜像位置，
> **镜像轴就不会把这些顶点当作镜像顶点**。」
> 「**Topology Mirror 试图解决这个问题**：它不仅看顶点位置，**还看这些顶点与其他顶点的关系**，
> 看整体拓扑来判断哪些顶点会被当作镜像顶点。
> **效果是：镜像顶点可以是非对称的，却仍被当作镜像。」**
> 「**Topology Mirror 在更精细的网格上更可靠。如果几何很简单（如立方体或 UV 球），常常不生效。**」

### Array Modifier（4,589 字符）

> 「创建基础物体的阵列副本，**每个副本按多种可能方式中的任一种相对前一个偏移**。
> **相邻副本的顶点可以合并（若它们靠近），以便生成平滑的细分曲面框架**。」
> 「这个修改器**配合可平铺网格来快速搭建大场景**很有用，**也适合创建复杂的重复形状**。」
> 「**同一个物体可以同时激活多个 Array 修改器**（例如创建复杂的三维结构）。」

**Fit Type 三种（官方）**：

| 类型 | 说明 |
|---|---|
| **Fit Curve** | 按 **Curve** 中指定的曲线长度**生成足够多的副本** |
| **Fit Length** | 按 **Length** 给的固定长度生成足够多副本 |
| **Fixed Count** | 按 **Count** 指定的数量生成 |

> **★ 重要限制（官方 Note）**：
> 「**Fit Curve 与 Fit Length 都使用基础物体的局部坐标系尺寸，
> 这意味着在 Object Mode 下缩放基础物体会……**（不改变阵列结果）」

### Boolean Modifier（2,803 字符）

> 「对网格执行**用编辑网格手工难以用这么少步骤完成的复杂操作**。
> 它用**三种布尔操作之一**把两个网格物体合成一个网格。」

**★ 关键警告（官方 Warning，项目书没写）**：
> 「**只有流形（Manifold）网格才保证正确结果**。
> 其他情况（**尤其"开放的"网格、非流形但没有自相交的**）通常也工作良好，
> **但在某些情况下可能产生奇怪的故障与瑕疵**。」

**★ 官方 Tip**：
> 「如果你把物体设为显示边（**Properties ‣ Object Properties ‣ Viewport Display，启用 Wireframe**），
> **移动物体时就能看到边被创建的过程**。视网格拓扑，还可以启用 **X-Ray 和 Transparency**，
> **实时看到拓扑如何被创建**。」

**三种操作**：Intersect（相交）/ Union（并集）/ **Difference（差集，挖孔用这个）**。

### Solidify Modifier（6,691 字符）

> 「取任意网格的表面，**给它增加深度、厚度**。」

**关键选项**：Thickness / Offset / **Even Thickness（均匀厚度）** / Rim（边缘填充）/ Only Rim / 材质索引偏移。

### Subdivision Surface Modifier（6,328 字符）

> 「**把网格的面切分成更小的面**」（官方称 "Subdiv"）。

**关键选项**：Levels Viewport / Levels Render / **Type（Catmull-Clark 或 Simple）** / 质量。

### Shrinkwrap Modifier（4,554 字符）

> 「让一个物体**"收缩"到另一个物体的表面**。它移动该物体的每个顶点……」

**Wrap Method 五种（官方）**：**Nearest Surface Point** / **Project** / **Nearest Vertex** / **Target Normal Project** / ………

### Curve Modifier（1,991 字符）

> 「提供一种**简单而高效的方法，沿一条曲线物体变形一个网格**。」

**关键选项**：**Curve Object** / **Deform Axis**。

### Edge Split Modifier（1,752 字符）

> 「**分裂、复制网格内的边**，打断这些边周围面之间的"链接"」。

**关键选项**：**Edge Angle**（按角度）/ **Sharp Edges**（按手动标记的锐边）/ Split Angle。
