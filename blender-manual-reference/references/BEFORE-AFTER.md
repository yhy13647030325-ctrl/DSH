## 五、实测纠错记录（本轮最重要产出）

在 Blender **5.1.2** GUI 里读 keyconfig，纠正了**两处流传错误的键位**：

| 项 | 原有说法（错误） | **实测 5.1.2** | 影响 |
|---|---|---|---|
| **重算法线** | `Ctrl+N`（"新版"） | **`Shift+N`**（`mesh.normals_make_consistent`） | 改正 **12 处** |
| **合并顶点** | `Shift+W` | **`M` 菜单 → By Distance**（无快捷键）；`Shift+W` 是 **`transform.bend` 弯曲** | 改正 **12 处** |
| **Alt+S** | 沿法线缩放 | 编辑模式=沿法线缩放；**物体模式=清除缩放** | 补模式区分表 |

**这两处若不实测，会一直错在技能库里**——而且都是最高频操作。

**验证方法（可复跑）**：
```python
import bpy
kc = bpy.context.window_manager.keyconfigs.active
# 必须 GUI 运行！后台模式只有 12 条 keymap_items（实测）
print([(km.name, ("Ctrl+" if i.ctrl else "")+("Shift+" if i.shift else "")+i.type)
       for km in kc.keymaps for i in km.keymap_items
       if i.idname=="mesh.normals_make_consistent"])
```
