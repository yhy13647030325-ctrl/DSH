## 核心框架与心智模型

### 一、王受之的史论坐标系（本书方法论内核）

- **线性历史演进观（承自佩夫斯奈）**：把现代设计史讲成"莫里斯与工艺美术（19 世纪 60 年代）→ 新艺术（1890—1910）→ 现代主义"的更替式进步过程。
  - 何时用：需要一条讲得清的叙述骨架、向初学者解释"谁先谁后"时。
  - 必须一起用的限定：设计史"并不是一个单纯的线性发展模式，也并非总是后浪推前浪的进步，多元化、挫折性总是存在的"。遇到回潮、并行、失败的运动，不要硬套进步叙事。
- **横向交叉研究法**（作者自述的研究立场）：同时看**各设计门类之间的交叉关系**与**设计发展同社会发展的横向关系**。
  - 何时用：解释"某个运动为什么发生／转向"时，把经济、政治、文化演进与建筑、产品、平面、时尚并置，而不是按门类分科纵向叙述。
  - 判据：包豪斯同时是建筑、产品、平面、实验摄影与电影的中心；硬拆成"建筑现代主义教育／工业产品设计教育／平面设计教育"就丢掉了运动背景。
- **范围取舍原则**：本书以**工业产品设计为主导线索**，现代建筑与平面设计只作背景与交叉补充（第二版进一步压缩了建筑与平面篇幅）。查建筑史、平面设计史专题时，预期这里是背景级覆盖。
- **第二版修订的四条标准**：订正错误与不准确处；删除过于绝对的说法和结论；人名中译统一并附原文；纪年统一写"1980 年代"而非"80 年代"。

### 三、作者反复使用的分析判据（当检查清单用）

| 判据 | 用法 |
|---|---|
| 形式与功能 | 工业设计初期奉行"形式追随功能"；数码与电子时代"形式和功能已经无须存在固定的因果关系" |
| 装饰 vs 简洁 | 装饰艺术、后现代用装饰对抗现代主义的简洁；工艺美术运动则用装饰对抗机器产品的粗劣 |
| 手工艺 vs 批量生产 | 工艺美术运动的道德立场与其在市场中的失败是同一枚硬币 |
| 商业驱动 vs 意识形态驱动 | 美国（市场与消费主义）／德国（体制、乌尔姆、理性主义）／意大利（设计作为意识形态） |
| 设计师身份形态 | 独立设计师 → 驻厂设计部门 → 设计事务所 → 企业设计总监 |
| 知识产权 | 工业设计的发展与设计产权保护几乎同步 |
| 国家与教育体制 | 设计政策与设计学院（包豪斯、乌尔姆）对产业面貌的塑造 |

### 四、影响本书框架的学术谱系

佩夫斯奈（线性史观奠基）→ 胜见胜《设计运动一百年》与吉迪翁《空间、时间和建筑》（体系传播）→ 班翰《第一个机械时代的理论和设计》→ 库提斯《1900 年以来的现代建筑》、佛兰普敦《现代建筑，一本批评史》、詹克斯（后现代理论）→ 斯巴克《20 世纪设计与文化导论》（以产品为中心、设计与文化）→ 帕帕纳克《为真实世界的设计》（设计伦理学与设计批评）→ 萨卡拉《现代主义之后的设计》→ 伍德汉姆、菲尔兄弟（图册型综述）。

## 范围与限制

- 本技能只覆盖《世界现代设计史》（第二版）的内容，是**摘要与结构化提炼**，不是原书全文；不复制原书长段文字。
- 原书以工业产品设计为主导，建筑与平面设计为背景性覆盖；建筑史、平面设计史的专深问题请另找专著（作者另有《世界现代建筑史》《世界平面设计史》）。
- 原 EPUB 中夹带的盗版推广段落已剔除；书末「中译人名索引」与各章「参考书目」未纳入本技能。
- 章内保留作者原命名与年代表述；源为 EPUB，无页码对应，引用时以章节号为锚。
- **原书存在少量自相矛盾的表述**（已在章节摘要中取通行说法）：例如德意志"工作同盟"的成立年份，原书一处作 1904 年、另一处作 1907 年，摘要按 **1907 年**（穆特修斯、贝伦斯等人成立）处理；引用具体年份前建议核对其他资料。
- **其余年份张力（按各章语境保留，不作统一）**：一是"新艺术"运动的起止，前言作 **1890—1910**、第三章作 **1880s—1910s（高潮 1895—1904）**；二是"有计划废止制"在不同章节分属不同环节——第一、九章系于斯隆的 1924／1927 年，第六章记 **1932 年由伯纳德·伦敦正式提出、斯隆负责制度化**。理解时应视为一条**事件链**，而不是简单矛盾。
- 章节摘要基于**定点抽取**（每章约读取 15,000 字符的锚点区段），个别非锚点区段的次要人物或细分条目可能未收录；需要穷尽细节时应回到原书核对。
- 本文件与各章的「关联」节是**人工校验过的双向链接**（已修正三处章节号误标）；若新增章节文件，需同时更新「章节索引」与「因果边」表。

## 相关技能

- **`design-methodology-liuguanzong`**（柳冠中《设计方法论》）—— 当问题从"这段设计史是什么"转向"现在该怎么设计、怎么分析需求"时，用它承接：**事理学**（从造物到谋事）、内外因分析、目标系统构建、设计思维六步法。分工是：本技能提供**历史脉络与判据**（谁在什么时候为什么这么做），它提供**方法与流程**（面对新问题该怎么做）。
- **`book-to-skill`** —— 要把另一本书也拆成同类知识库时用它；本技能正是该流程的产物（EPUB → 定点抽取 → 章节摘要 + glossary/patterns/cheatsheet）。
