## 四、易混对比

| 对比 | 一行判据 |
|---|---|
| "工艺美术" vs "新艺术" | 前者的议题是设计标准与设计伦理、回到中世纪；后者是第一套被应用于大众产品的原创装饰语言，走向自然曲线（各国命名不同）。 |
| "装饰艺术" vs 现代主义 | 同期、形式相近而意识形态相反：是否强调装饰、为谁服务（富裕上层 vs 低收入大众）。 |
| 现代主义 vs "国际主义"风格 | 同一形式的性质变化：服务对象由大众／理想主义转为中产、政府与大企业；形式从"自然结果"升为"追求目的"。 |
| "国际主义" vs 后现代主义 | 前者以密斯"少就是多"为中心、反对装饰；后者以文丘里"少就是乏味"起手，折中抽取拼接历史符号。 |
| "高科技"派 vs 调侃"高科技"派 | 前者严肃反映第二机器时代、把结构当形式；后者对高科技结果感到不安并拿它开玩笑。 |
| "新现代主义" vs 后现代主义 | 前者维护现代主义基本理论、主张只能完善不能推翻；后者主张彻底决裂或折中推翻。 |
| 波普 vs 大众化 | 大众文化是大众的文化，波普文化是知识分子的文化，只借用大众文化的某些形式。 |
| 有计划废止制 vs 再设计 | 前者刻意让式样过时以制造换购；后者须因功能、审美、材料、款式之一真的失当才成立。 |
