## 一、钣金设计（第 8 章，p588–645）

### 1.1 三个折弯参数（p589–591）★ 必须先分清

**钣金定义（p588）**：
> 钣金是针对金属薄板（**通常厚度在 6mm 以下**）的综合冷加工工艺，包括剪、冲、切、复合、折、焊接、铆接、拼接、成型（如汽车车身）等。
> **显著特征：同一零件厚度一致。**

| 参数 | 定义（原文） | 公式 |
|---|---|---|
| **折弯系数（BA）** | 沿材料**中性轴**所测量的圆弧长度 | **Lt = A + B + BA** |
| **K因子** | **中性板相对于钣金零件厚度的位置的比率** | **BA = (R + K·T)·A/180** |
| **折弯扣除（BD）** | **回退量**，一种简单算法，用来描述钣金折弯过程 | **Lt = A + B − BD** |

**式中符号**：Lt = 总平展长度；A、B = 两侧直段长度；R = 内侧折弯半径；K = K因子；T = 厚度；A = 折弯角度（**经过折弯材料的角度**）。

> **三者只能选一个用**（都用来算展开长度 Lt）。
> - **折弯系数**：最直观——直接给一个圆弧长度数值
> - **K因子**：最通用——查材料表得到 K，再算 BA
> - **折弯扣除**：最简单——老工艺习惯，"直角边相加减去一个回退量"
> **注意公式里 A 的两种含义**：在 Lt 公式里 A 是**直段长度**；在 BA 公式里 A 是**折弯角度**。原文用同一个字母，容易混。

### 1.2 生成钣金的两个入口（p591）

> 生成钣金零件的方法有**两种**：
> 1. **利用钣金命令直接生成**
> 2. **将现有零件进行转换**

本章介绍第一种。

### 1.3 基体法兰（p591–595）★ 第一个特征

**判据（原文）**：
> **基体法兰是钣金零件的第一个特征。** 当基体法兰被添加到 SOLIDWORKS 零件后，系统会**将该零件标记为钣金零件**，并在特征管理器设计树中**显示特定的钣金特征**。

**属性三组**：

| 组 | 选项 | 说明 |
|---|---|---|
| **【钣金规格】** | **勾【使用规格表】** | 根据指定材料，**定义钣金的电子表格及数值** |
| **【钣金参数】** | 【厚度】 | 设置钣金厚度 |
| | **反向加厚复选框** | 以相反方向加厚 |
| | **【半径】** | **设置钣金折弯处的半径** |

> **"使用规格表"的意义**：把材料对应的厚度/折弯半径/折弯扣除做成表格，改材料即改全部参数。**这是钣金标准化的关键。**

### 1.4 边线法兰（p595 起）

> 可以在**一条或者多条边线**上添加边线法兰。

### 1.5 钣金展开与曲面技能的关系

`solidworks-surface-advanced` 第 1 章讲过：**可展曲面**（平面、圆柱面、圆锥面）是**钣金展开功能的几何基础**。
> 即：**钣金只能"展开"可展曲面**。如果钣金件上有非可展的自由曲面，展开会失败或失真。

### 1.6 与结构设计技能的对应

`product-structure-liubaoshun` 第一章 1.4"冲压壳体"给了两条**工艺层面**的判据，与钣金直接相关：
- **弯曲线要垂直于板料纤维方向**（平行会裂）
- **弯曲部位应设加强筋**
- **拉伸件形状应简单对称、法兰边宽度一致**

> 分工：那本讲"钣金件为什么会裂"，这本讲"在 SOLIDWORKS 里怎么建"。

## 二、焊件设计（第 9 章，p646–700）

### 2.1 焊件的本质（p647）

> 焊件（通常称为**型材**）是用铁或钢以及具有一定强度和韧性的材料，通过**轧制、挤出、铸造**等工艺制成的具有一定几何形状的物体。

**结构构件的七个属性（p647–648）★ 完整清单**：

1. 具有**统一的轮廓**，例如角铁、铝合金焊件等
2. 轮廓由**【标准】**、**【类型】**及**【大小】**等属性确定
3. **可以包含多个片段，但所有片段只能使用一个轮廓**
4. **具有不同轮廓的多个结构构件可以属于同一个焊接零件**
5. 生成的实体会出现在**【切割清单】文件夹下**
6. 可以生成**自定义的轮廓**，并添加到现有焊件轮廓库中
7. 可以在【切割清单】文件夹下**选择结构构件，并生成用于工程图中的切割清单**

> **第 3 与第 4 条合起来是一条重要判据**：
> **一个结构构件 = 一个轮廓 + 多个片段**；**不同轮廓 = 多个结构构件**。
> 所以"一次焊件里混两种型材"是允许的——**加第二个结构构件特征即可**。

### 2.2 结构构件属性（p649）

| 项 | 说明 |
|---|---|
| **【标准】** | 选先前定义的 **iso、ansi inch 或自定义** |
| **【Type: Configured Profile】** | 选择轮廓类型 |
| **【大小】** | 选择轮廓大小 |
| **【组】** | 在绘图区域选择**一组草图实体作为路径线段** |

> **【组】是焊件的组织单位**：同一组 = 同一根型材的连续路径。
> （这一点在 `solidworks-practice` 第 9 章有更细的分组规律：**平行线一组、圆弧单独成组**。）

### 2.3 剪裁/延伸：四种边角类型（p651–653）★ 本书独有的细化

**【边角类型】** 可设置：

| 类型 | 适用 |
|---|---|
| **终端剪裁** | 可选**一个或多个**要剪裁的实体 |
| **终端斜接** | 选**一个**要剪裁的实体 |
| **终端对接1** | 选**一个**要剪裁的实体 |
| **终端对接2** | 选**一个**要剪裁的实体 |

**【剪裁边界】** 可选：
- **【面/平面】**：使用平面作为剪裁边界

> **判据**：**只有"终端剪裁"能处理多个实体**；其余三种都是一对一对接。选错类型就做不出想要的接头。

### 2.4 焊件其余命令（章首列出）

| 命令 | 作用 |
|---|---|
| **圆角焊缝** | 在构件交接处生成焊缝 |
| **角撑板** | 加强连接（如两块板之间的斜撑） |
| **顶端盖** | 封住型材开口端 |
| **焊缝** | 具体焊缝特征 |
| **自定义焊件轮廓** | 建立自己的型材库 |
| **焊件工程图** | 出图（含切割清单） |

### 2.5 与结构设计技能的对应

`product-structure-liubaoshun` 第一章 1.3"焊接壳体"给了**焊缝位置四原则**：
1. 便于焊接操作
2. **避开最大应力区与应力集中部位**（尤其壳体拐角）
3. 避开或远离机械加工面
4. 考虑焊接变形

> **在 SOLIDWORKS 里加焊缝特征之前，先在结构上确认位置符合这四条。** 软件不会告诉你焊缝放错了地方。

## 三、动画模拟与仿真（第 10 章，p701–741；第 14 章 p863 互补）

### 3.1 运动算例的三类（p702–703）★ 与曲面/实体技能的三类一致

| 类型 | 可用范围 | 能力（原文） |
|---|---|---|
| **动画** | **核心 SOLIDWORKS 内** | 演示装配体运动。例如**添加马达**驱动一个或多个零件；**使用设定键码点**在不同时间规定零部件位置 |
| **基本运动** | **核心 SOLIDWORKS 内** | 在装配体上**模仿马达、弹簧、碰撞以及引力**作用。**计算运动时需考虑质量** |
| **运动分析** | **SOLIDWORKS Premium 的 Motion 插件** | 精确模拟运动效果（**包括力、弹簧、阻尼以及摩擦**）。使用**动力求解器**，计算时需**考虑材料属性、质量及惯性** |

> **这是"选错算例就白做"的三分法**：
> - 只想动起来看 → 动画
> - 要重力/碰撞/弹簧 → 基本运动
> - 要算力/摩擦/惯性 → 运动分析（需 Premium）

### 3.2 时间线与键码点（p703–705）★ 操作核心

**时间线定义（原文）**：
> 时间线是**动画的时间界面**，显示在**动画特征管理器设计树的右侧**。当更改时间栏、在绘图区域移动零部件、或更改视像属性时，**时间栏会使用键码点和更改栏显示这些操作**。

**刻度**：时间线被竖直网格线均分，对应时间的数字标记。**从 00:00:00 开始，间距取决于窗口大小**（可能每隔 1 秒、2 秒或 5 秒一个标记）。

**在时间线上单击任意位置**可显示对应点的零部件位置。

**右键菜单（时间线区域，p704）**：
- **【Move Time Bar】**：添加新键码点，并在指针位置添加**一组相关联的键码点**
- **【动画向导】**：调出【动画向导】对话框

**右键键码点（p704–705）**：
- **【剪切】【删除】** —— **注意：00:00:00 标记处的键码点不可用**
- **【替换键码】**：**更新所选键码点以反映模型的当前状态**

> **【替换键码】是很实用的功能**：摆好新姿态后，用它覆盖旧键码，不用删了重录。

### 3.3 五类动画（章首列出，p701）

| 动画类型 | 用途 |
|---|---|
| **装配体爆炸动画** | 演示拆装顺序 |
| **旋转动画** | 转盘式展示 |
| **视像属性动画** | 光源、相机、透明度等随时间变化 |
| **距离配合动画** | 用配合尺寸驱动运动 |
| **物理模拟动画** | 重力/碰撞等物理效果 |

> 与 `solidworks-practice` 第 10 章的分法（平移机构/吸盘/筛选球体/动态剖切/动画渲染）**角度不同**：
> 那本按"案例"分，本书按"动画类型"分。**两本合起来更完整。**

## 四、线路设计（第 12 章，p799–841）

### 4.1 这是什么（p799）

> 线路设计模块主要用于**规划和管理复杂的电缆和管道系统**。允许创建**三维线路模型**，模拟电缆和管道的路径，确保布局合理且符合设计规范。
> 支持对**线路长度、弯曲半径和固定点**等参数进行精确控制，以**优化空间利用和节约材料成本**。
> 有助于**减少安装时间**，提高系统可靠性和安全性，便于后续维护升级。

### 4.2 模块性质（p800）★ 关键概念

> 线路设计模块（**SOLIDWORKS Routing**）用来生成一种**特殊类型的子装配体**，以在零部件之间创建**管道、管筒或其他材料的路径**。

> **"特殊类型的子装配体"**——这一点很重要：**线路不是一个特征，而是一个子装配体**。所以它有自己的模板、自己的装配结构。

### 4.3 激活与模板（p800–802）

| 项 | 内容 |
|---|---|
| 激活 | 【工具】>【插件】→ 勾选 **【SOLIDWORKS Routing】** → 确定 |
| 步路模板 | **第一次创建装配体文件时自动生成**；使用与标准装配体模板相同的设置，也含步路相关的特殊模型数据 |
| 自动生成的模板名 | **route Assembly.asmdot** |
| 默认位置 | 默认模板文件夹（原文给的路径：`C:\Documents and Settings\All Users\Application Data\SOLIDWORKS\templates`） |

**自定义步路模板三步**：打开自动生成的模板 → 做更改 → 【文件】>【另存为】新名称，**必须用 .asmdot 扩展名**。

### 4.4 配合参考（p802）★ 比 SmartMates 更可靠

**判断（原文）**：
> 使用**配合参考**来放置零件**比使用智能装配（SmartMates）更可靠，并更具有预见性**。

**三条建议**：
1. **在一个设备上具有相同属性的配件，应用配合参考时应使用同样的名称**
2. 要确保线路设计零件的配合设置正确
3. 为放置配合参考，应遵守以下规则：
   - 给**线路配件**添加配合参考
   - 给**设备零件上的端口**添加配合参考，**每个端口添加一个**
   - 如果一台仪器有数个端口，**要么所有端口都添加配合参考，要么所有端口都不添加**

> 第 3 条的最后一句是"**全有或全无**"原则——部分添加会导致行为不一致，反而更不可预期。

### 4.5 两个核心概念（章首"重点与难点"）

| 概念 | 作用 |
|---|---|
| **线路点（Route Point）** | 线路在零件上的起点 |
| **连接点（Connection Point）** | 端口的连接位置与方向 |

> 这本书只把它们列为"重点"并做了概念说明，**具体操作细节以书中配套素材为准**（书中未展开到逐命令级）。

### 4.6 三类线路（p799 章首）

| 类型 | 内容 |
|---|---|
| **管筒线路** | 软管类 |
| **管道线路** | 硬管类 |
| **电力线路** | 电缆 |

## 五、仿真分析（第 14 章，p863–921）

### 5.1 五种工具全景（p863）★ 选哪个

| 工具 | 解决什么问题 |
|---|---|
| **公差分析（TolAnalyst）** | 公差与装配方法对**两个特征间尺寸**的影响 |
| **有限元分析（SimulationXpress）** | 强度/刚度等结构问题 |
| **流体分析（FloXpress）** | 流场评估 |
| **数据加工分析（DFMXpress）** | **可制造性**（数控加工） |
| **运动模拟** | 机械系统的**动态行为**预测与验证 |

> **共同目的（原文）**：「使用户可以在计算机中测试设计的合理性，**无须进行昂贵且费时的现场测试**，因此有助于**减少成本、缩短时间**。」

> **注意命名**：`SimulationXpress` / `FloXpress` / `DFMXpress` 都是 **Xpress 系列（简化版）**，不是完整版 Simulation/Flow Simulation/DFM。**能力有限，适合快速判断趋势。**

### 5.2 公差分析五步（p864–866）★ 本书独有的细化

**公差分析定义**：
> 一种仿真分析工具，用于研究**公差和装配体方法**对装配体的**两个特征间的尺寸**产生的影响。
> 每次研究的结果为：**最小公差、最大公差、基值特征和公差的列表**。

**五步（原文）**：

| 步 | 名称 | 要做什么 | 关键判据 |
|---|---|---|---|
| 1 | **准备模型** | 确保装配体与零件模型完整，**每个零件的尺寸都已正确标注公差** | 包括几何准确建模 + 工程图中赋予合适公差 + **检查模型完整性，确保没有遗漏或错误的尺寸与公差标注** |
| 2 | **测量** | 确定公差分析中要评估的**特定尺寸或空间关系** | 可选直线的距离、角度、点的位置等。**测量结果将直接影响结果**，因此需**基于装配体的功能要求**确定哪些尺寸是关键 |
| 3 | **设置装配体顺序** | **零件在装配体中的组合方式** | **零件的装配顺序可能会影响最终装配体的尺寸精度**；可通过模拟装配过程确定顺序 |
| 4 | **设置装配体约束** | **配合关系**（轴对轴、面接触等） | **约束决定零件位置和方向**，影响零件间相对位置，从而影响**累积误差** |
| 5 | **分析** | 用公差分析工具获取结果 | 结果**显示所选测量的潜在误差范围，包括最坏情况分析** |

> **第 3 步"装配顺序"是最容易被忽略的一步**：多数人以为公差只看尺寸与配合，**实际上"先装哪个"会改变累积误差的传递路径。**

### 5.3 与其他技能的关系

- **`solidworks-practice` 第 12 章**讲 Simulation **静力分析**（夹具、载荷、网格、结果、优化），是**完整版**的深入用法。
- **本章**讲的是**五种工具的分工**，偏"什么时候用哪个"。
> 两本合起来：**先在这里选工具，再到那本看具体做法。**

## 六、这四块与设计技能链的接口

```
product-structure-liubaoshun（结构设计）
   ├─ 冲压壳体（弯曲/纤维方向）──→ 本书 钣金
   ├─ 焊接壳体（焊缝四原则）────→ 本书 焊件
   ├─ 密封/安全结构 ───────────→ 本书 装配/工程图
   └─ 连续/间歇机构 ───────────→ 本书 动画模拟（验证运动）
                                       ↓
                              solidworks-practice（逐步操作）
                                       ↓
                              solidworks-surface-advanced（自由曲面）
```

**四个接口点**：
1. **钣金**：结构技能管"会不会裂"，本书管"怎么建"
2. **焊件**：结构技能管"焊缝放哪"，本书管"怎么建型材与切割清单"
3. **动画模拟**：结构技能第四章的机构，可以用 Motion 验证是否真的能动、会不会干涉
4. **仿真**：结构技能的"刚度强度准则"在这里落地为 SimulationXpress
