# 三本 SOLIDWORKS 技能统筹规范（solidworks-2025-mechanical 分册）

> **本文件是 `solidworks-practice/references/STANDARD.md` 的分册视图**。
> 三本 SOLIDWORKS 技能（practice / surface / 2025）共用一套规范，**总表与最终裁定以 practice 那份为准**。
> 本文件只保留与本技能（**2025 版全模块**）相关的部分。

---

## 一、三本分工（只看与本技能相关的部分）

| 技能 | 唯一职责 | 与本技能的关系 |
|---|---|---|
| `solidworks-practice` | 逐步操作 + 排错 + CSWA/CSWP | 提供**操作的细节与失败模式**；本技能的多数主题在那本有更细的案例 |
| `solidworks-surface-advanced` | 曲面原理与判据 | 其 **ch05** 与本技能 **ch05** 互补（原理 vs 参数） |
| **`solidworks-2025-mechanical`（本技能）** | **2025 版全模块 + 命令参数 + 四个独有模块** | 本技能主体 |

**一句话**：**"2025 版有什么、参数是什么、新模块怎么用"→ 本技能；"怎么一步步做"→ practice；"为什么/好不好"→ surface。**

---

## 二、本技能的四个独有模块（其他两本都没有）

| 章 | 模块 | 独有价值 |
|---|---|---|
| **ch08** | **钣金** | 折弯系数/K因子/折弯扣除**三公式**、基体法兰、边线法兰、展开 |
| **ch09** | **焊件** | **剪裁四类型**（只有终端剪裁能剪多个）、**切割清单**、角撑板/顶端盖/焊缝 |
| **ch12** | **线路设计** | **Routing 是特殊子装配体**、步路模板 `route Assembly.asmdot`、配合参考"全有或全无" |
| **ch14** | **仿真分析** | **五工具分工**（TolAnalyst/SimulationXpress/FloXpress/DFMXpress/运动）、**公差分析五步** |

> 另外 **ch13 配置项目完整清单**（零件 10 项 / 装配体 7 项）、**ch10 时间线右键菜单**、**ch11 完整标准清单**也是本技能增量。

## 三、统一操作规范（R1–R6，与 practice 完全一致）

| 编号 | 规范 |
|---|---|
| **R1** | 命令必须写全菜单路径：**【插入】/【钣金】/【基体法兰】** |
| **R2** | 对话框必须四列：**选项组 / 选项 / 默认值 / 本书取值** |
| **R3** | **默认值 = 软件默认**；**本书取值 = 原书该案例用的值** |
| **R4** | 原文依据可验证：每章标 **PDF 页码**；引用标 `（pXX）`；归纳标 **（提炼）** |
| **R5** | 步骤可复现：连续编号、每步带路径 |
| **R6** | 压缩冗余，保留**数值、判据、路径、陷阱** |

### 本技能的额外约定

| 约定 | 说明 |
|---|---|
| **原书"按图设参数"** | 本书大量写"按图 5-43 进行参数设置"而无文字数值 → 统一标 **（需对照原书图 N）**（本技能共 35 处） |
| **版本差异** | 与 practice（2014 前后）同名命令若选项名不同，**以 2025 版为准** |
| **Xpress 系列** | `SimulationXpress`/`FloXpress`/`DFMXpress` 是**简化版**，必须注明 |

| 情况 | 说明 |
