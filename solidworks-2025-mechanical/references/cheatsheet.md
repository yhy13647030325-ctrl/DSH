# 速查表（Cheatsheet）

## 一、钣金三参数

| 参数 | 定义 | 公式 |
|---|---|---|
| **折弯系数 BA** | 沿**中性轴**测量的圆弧长度 | **Lt = A + B + BA** |
| **K因子** | 中性板相对厚度的位置比率 | **BA = (R + K·T)·A/180** |
| **折弯扣除 BD** | 回退量（简单算法） | **Lt = A + B − BD** |

**符号**：Lt 总平展长度 / A、B 直段长度 / **R 内侧折弯半径** / K = K因子 / **T 厚度** / **A 折弯角度**（经折弯材料的角度）

> ⚠ 原文在 Lt 式与 BA 式里都用 A，但**含义不同**：一个是直段长，一个是折弯角度。

| 项 | 值/判据 |
|---|---|
| 钣金厚度范围 | **通常 6mm 以下** |
| 显著特征 | **同一零件厚度一致** |
| 第一个特征 | **基体法兰**（之后零件才被标记为钣金件） |
| 基体法兰三组参数 | 【钣金规格】（可勾使用规格表）/【厚度】+反向/【半径】 |
| 边线法兰 | 可在**一条或多条**边线上加 |

## 二、焊件

| 项 | 判据 |
|---|---|
| 一个结构构件 | **一个轮廓 + 可含多个片段**（所有片段只能用一个轮廓） |
| 多个结构构件 | **可属同一焊接零件**（不同轮廓 → 加第二个结构构件特征） |
| 生成实体位置 | **【切割清单】文件夹下** |
| 结构构件四属性 | 【标准】iso / ansi inch / 自定义；【Type: Configured Profile】；【大小】；【组】 |
| 【组】的含义 | 选**一组草图实体作为路径线段** |

## 三、Motion 三类算例

| 类型 | 可用范围 | 考虑质量 | 能力 |
|---|---|---|---|
| **动画** | 核心 SW | 否 | 加马达、设键码点 |
| **基本运动** | 核心 SW | **是** | 马达/弹簧/**碰撞**/引力 |
| **运动分析** | **Premium 的 Motion 插件** | **是**（含材料属性、惯性） | 力/弹簧/**阻尼**/**摩擦** |

### 五类动画

装配体爆炸动画 / 旋转动画 / 视像属性动画 / 距离配合动画 / 物理模拟动画

### 时间线要点

| 项 | 值 |
|---|---|
| 起点 | **00:00:00** |
| 刻度间距 | 取决于窗口（1/2/5 秒） |

## 四、线路设计（Routing）

| 项 | 判据 |
|---|---|
| 本质 | **特殊类型的子装配体**（不是特征） |
| 激活 | 【工具】>【插件】→ 勾 **SOLIDWORKS Routing** |
| 步路模板 | 首次建装配体时**自动生成**，名 **route Assembly.asmdot** |
| 自定义模板 | 另存为 **.asmdot** |
| 配合参考 vs 智能装配 | **配合参考更可靠、更有预见性** |
| 多端口规则 | 所有端口都加配合参考，**或都不加**（全有或全无） |
| 同名规则 | 相同属性的配件**用同样的名称**加配合参考 |
| 三类线路 | 管道 / 管筒 / 电力 |
| 两个核心概念 | **线路点**、**连接点** |

## 五、仿真分析五工具

| 工具 | 解决什么 |
|---|---|
| **公差分析（TolAnalyst）** | 公差与装配方法对**两特征间尺寸**的影响 |
| **SimulationXpress** | 有限元（结构） |
| **FloXpress** | 流体 |
| **DFMXpress** | 可制造性（数控加工） |
| **运动模拟** | 动态行为 |

> 四个 Xpress 都是**简化版**，用于快速判断趋势，不是完整求解。

### 公差分析五步

| 步 | 内容 | 关键 |
|---|---|---|
| 1 准备模型 | 尺寸都标好公差、模型完整 | 检查有无遗漏/错误标注 |
| 2 测量 | 选要评估的尺寸或空间关系 | **基于功能要求**选关键尺寸 |
| 3 设置装配顺序 | 零件怎么一步步装 | **顺序影响累积误差** |
| 4 设置装配体约束 | 配合关系 | 决定相对位置与误差传递 |
| 5 分析 | 出结果 | 含**最坏情况分析** |

**结果包含**：最小公差、最大公差、基值特征、公差的列表。

## 九、五个最容易记错的点

| # | 易错 | 正确 |
|---|---|---|
| 1 | 折弯系数 = 折弯扣除 | **不同**：BA 是中性轴弧长（加），BD 是回退量（减） |
| 2 | 一个结构构件可含不同轮廓 | **不能**，一个构件只能一个轮廓 |
| 3 | 动画算例能算碰撞 | **不能**，要【基本运动】以上 |
| 4 | 设计表默认链接 Excel | **默认嵌入、不链接** |
| 5 | 焊件剪裁四种类型都能剪多个 | **只有终端剪裁**可以 |
