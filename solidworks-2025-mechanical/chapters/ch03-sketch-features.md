# 第 3 章：基于草图的实体建模特征

> PDF p170–229（书内 p160–219）。
> **操作约定**：命令写全菜单路径；对话框列默认值。

## 本章范围（原文）

> **实体建模是 SOLIDWORKS 三大功能之一。实体建模命令分为两大类：**
> - **第一类：需要草图才能建立特征的命令**
> - **第二类：在现有特征的基础上进行特征编辑的命令**
>
> 本章介绍**第一类**：拉伸凸台/基体、旋转凸台/基体、扫描、放样、筋，以及螺丝刀与蜗杆建模实例。

**重点与难点**：拉伸 / 旋转 / 扫描 / 放样 / 筋

## 拉伸的定义（原文 p171）

> **拉伸凸台/基体特征是将 2D 草图沿着直线方向（常用的是 2D 草图的垂直方向）平移而形成实体的特征。**

> **关键词是"平移"**——这就是为什么拉伸只能做等截面。

## 五类草图特征（完整路径）

| 特征 | 菜单路径 | 关键选项（默认值） |
|---|---|---|
| **拉伸** | **【插入】/【凸台/基体】/【拉伸】** | 【终止条件】默认 **给定深度**；【深度】；【拔模开/关】默认**关**；【薄壁特征】默认**不勾**；**【所选轮廓】** 可限定多个封闭轮廓 |
| **旋转** | **【插入】/【凸台/基体】/【旋转】** | 【旋转轴】必选；**【旋转类型】默认【给定深度】**；【角度】默认 **360°** |
| **扫描** | **【插入】/【凸台/基体】/【扫描】** | 【轮廓】+【路径】（可加【引导线】）；**【方向/扭转控制】默认【随路径变化】**；实体扫描**轮廓必须闭合** |
| **放样** | **【插入】/【凸台/基体】/【放样】** | 【轮廓】≥2；**【起始/结束约束】默认【无】**（曲率 0）；【引导线】可选 |
| **筋** | **【插入】/【特征】/【筋】** | 【类型】默认**线性**；【厚度】；**【在草图基准面处】** |

## 两个实例（原书案例）

| 案例 | 涉及命令 | 说明 |
|---|---|---|
| **螺丝刀** | 拉伸 + 旋转 + 圆角 | 手柄用旋转，刀杆用拉伸 |
