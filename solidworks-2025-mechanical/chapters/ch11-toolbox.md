# 第 11 章：标准零件库

> PDF p742–798（书内 p732–788）。
> **操作约定**：命令写全菜单路径；对话框列默认值。
> **本章增量**：相对 `solidworks-practice` ch05，本章给出**完整标准清单、凸轮设计、凹槽设计、Toolbox 工作机制**。

## 本章范围（原文）

> **SOLIDWORKS Toolbox 插件包括标准零件库、凸轮设计和凹槽设计。**
> 利用 Toolbox 可以**选择具体的标准和想插入的零件类型，然后将零件拖曳到装配体中**。
> 另外**可自定义 Toolbox 零件库**。
> 内容包括：Toolbox 概述、凹槽、凸轮和标准件建模实例。

## ★ 2025 版支持的标准（完整清单，原文 p743）

> Toolbox 支持的**国际标准**包括 **ANSI、AS、BSI、CISC、DIN、GB、ISO、IS、JIS 和 KS**。

> 记忆：**ANSI（美）、BSI（英）、DIN（德）、GB（中）、ISO（国际）、JIS（日）、KS（韩）**，另有 AS、CISC、IS。

## Toolbox 的工作机制（原文）

> Toolbox 包含**所支持标准的主零件文件的文件夹**。使用新的零部件时，**Toolbox 会根据用户的参数设置、更新主零件文件以记录配置信息**。

> **即：Toolbox 不是"一堆现成零件"，而是"一个主零件 + 配置"。** 零件大小由配置生成，不是每尺寸一个文件。

## 三种能力

| 能力 | 说明 | 相对 practice 的增量 |
|---|---|---|
| **标准零件库** | 拖曳插入（轴承、螺栓、齿轮等） | practice 有智能扣件 |
| **凸轮设计** | 生成凸轮轮廓 | **本章独有** |
| **凹槽设计** | 生成凹槽 | **本章独有** |
| 自定义零件库 | 把自己的零件加入库 | practice 提及 |

## 命令路径（本章全部命令）

| 命令 | 菜单路径 |
|---|---|
| 启用 Toolbox | **【工具】/【插件】** → 勾 **SolidWorks Toolbox** + **SolidWorks ToolboxBrowser** |
| 打开设计库 | **任务窗格 →【设计库】** |
| 插入标准件 | 在 Toolbox 树中选**标准/类别/零件** → **拖到装配体** |
| 凸轮设计 | 设计库 → **Toolbox →【凸轮】** |
| 凹槽设计 | 设计库 → **Toolbox →【凹槽】** |
| 自定义零件库 | 设计库 → 右击 → **【添加文件位置】** |
| 配置 | **【工具】/【选项】/【系统选项】/【异型孔向导/Toolbox】** → **【配置】** |

### 补充：插入标准件的两种方式

| 方式 | 操作 |
|---|---|
| 拖拽插入 | **设计库 → Toolbox → 标准/类别/零件 → 拖到装配体** |
| 浏览插入 | **【插入】/【零部件】/【现有零件/装配体】** 指向 Toolbox 库中文件 |
| 自动加配合 | 拖到孔/圆柱面时**出现配合光标再松手** |

### 补充：Toolbox 配置与故障处理路径

| 场景 | 菜单路径 |
|---|---|

| Toolbox 配置 | **【工具】/【选项】/【系统选项】/【异型孔向导/Toolbox】→【配置】** |
| 标准件缺失 | **任务窗格【设计库】→ 右击 →【添加文件位置】** |
