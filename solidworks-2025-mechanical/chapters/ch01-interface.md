## 1.2 常用工具命令（五类工具栏，p26–36）

| 工具栏 | 菜单入口 | 常用命令 |
|---|---|---|
| **【标准】工具栏** | **【视图】/【工具栏】/【标准】** | 新建、打开、保存、打印、撤销、重建 |
| **【特征】工具栏** | **【视图】/【工具栏】/【特征】** | 拉伸、旋转、扫描、放样、圆角、倒角、抽壳、筋、阵列 |
| **【草图】工具栏** | **【视图】/【工具栏】/【草图】** | 直线、圆、圆弧、智能尺寸、剪裁、等距、镜像 |
| **【装配体】工具栏** | **【视图】/【工具栏】/【装配体】** | 插入零部件、配合、移动零部件、爆炸视图 |
| **【工程图】工具栏** | **【视图】/【工具栏】/【工程图】** | 模型视图、投影视图、剖面视图、注解 |

> **★ 工具栏调出（通用）**：**【视图】/【工具栏】** → 在列表中勾选需要的工具栏。默认只显示部分。

## 1.3 操作环境设置（p37 起）

### 两级设置的分界（与 `solidworks-practice` 一致）

| 级别 | 路径 | 影响范围 |
|---|---|---|
| **系统选项** | **【工具】/【选项】/【系统选项】** | **本机所有文档** |
| **文档属性** | **【工具】/【选项】/【文档属性】** | **仅当前文档**，随文件保存 |

> **判据**：跟机器走的改系统选项，跟文件走的改文档属性。

### 常用设置项

| 要设什么 | 路径 |
|---|---|
| 默认模板 | **【系统选项】/【默认模板】** |
| 文件位置 | **【系统选项】/【文件位置】** |
| 单位与小数位 | **【文档属性】/【单位】** |
| 图像品质 | **【文档属性】/【图像品质】**（注意是**文档属性**） |
| 颜色（开环边线等） | **【系统选项】/【颜色】** |
| 显示/选择 | **【系统选项】/【显示/选择】** |
| 性能（重建时验证） | **【系统选项】/【性能】** |

## 1.5 基准轴与基准面（p37 起）

### 基准面创建（对照 `solidworks-practice` 的 9 种方法）

| 方法 | 操作要点 |
|---|---|
| 偏移距离 | 选现有基准面/模型表面 → 输入距离 |
| 与面成角度 | 选一个表面 + 一条边/轴 → 输入角度 |
| 三点 | 分别选三个点 |
| 边线+点 | 选一条边线 + 一个点 |
| 面平行+点重合 | 选一个平面 + 一个点 |
| 两侧对称 | 选两个要对称的平面 |
| 垂直于曲线 | 选一条螺旋线 + 其一个端点 |
| 两面相切 | 选两个圆柱面 |
| 相切面+点 | 选一个曲面 + 草图点 |

**调用**：**【插入】/【参考几何体】/【基准面】**

### 基准轴创建（5 种）

| 方法 | 操作要点 |
|---|---|
| 临时轴 | 将临时轴转换为基准轴 |
| 两平面 | 选两相交基准面或两平面 |
| 两点 | 选两个草图点或模型顶点 |
| 圆柱/圆锥面 | 选一个圆柱面或圆锥面 |
| 点+面 | 生成轴穿过点并垂直于基准面 |

**调用**：**【插入】/【参考几何体】/【基准轴】**

## 1.6 阶梯轴建模实例（p50 起）

**这是本章唯一的完整案例**，串起：草图 → 旋转/拉伸 → 阵列 → 倒角。

| 步 | 操作 | 路径 / 参数 |
|---|---|---|
| **S01** | 新建零件 | **【文件】/【新建】** → **Part MM** 模板 |
| **S02** | 设单位 | **【工具】/【选项】/【文档属性】/【单位】** |
| **S03** | 画草图 | 选基准面 → **【插入】/【草图绘制】** → **【工具】/【草图实体】/【直线】** 画半剖轮廓 → **【工具】/【尺寸】/【智能尺寸】** 标尺寸 |
| **S04** | 加中心线 | **【工具】/【草图实体】/【中心线】** |
| **S05** | 旋转 | **【插入】/【凸台/基体】/【旋转】** → 【旋转轴】选中心线 → 【角度】默认 **360°** |
| **S06** | 倒角 | **【插入】/【特征】/【倒角】** |
| **S07** | 保存 | **【文件】/【保存】** |

> **（需对照原书图）**：本章案例的具体尺寸以书内图给出。
