## 2.4 尺寸标注

**调用**：**【工具】/【尺寸】/【智能尺寸】**

| 类型 | 操作要点 |
|---|---|
| 线性尺寸 | 自动按鼠标位置在水平/竖直/平行间切换 |
| 角度尺寸 | 两直线间；或直线与点 |
| 圆弧尺寸 | 半径（点圆弧）/弧长（先两端点再圆弧）/弦长 |
| 中心距 | 依次点两个圆后拖出 |
| 同心圆 | 点第一圆再点第二圆 |

## 2.5 几何关系

**调用**：**【工具】/【几何关系】/【添加】**（或 Ctrl 多选后属性框 / 右击关联工具栏）

**14 种关系**（表 2-2 全量）：

| 关系 | 施加对象 |
|---|---|
| 水平 / 竖直 | 一条或多条直线之间；两个或多个点之间 |
| 重合 | 端点和直线之间 |
| 合并 | 两个端点之间 |
| 中点 | 直线和端点之间 |
| 共线 / 平行 / 垂直 | 两条或多条直线之间 |
| 同心 | 两个或多个圆或圆弧之间 |
| 相切 | 两个圆或圆弧之间；一条直线与圆或圆弧之间 |
| 相等 | 两条或多条直线之间；两个或多个圆弧或圆之间 |
| 全等 | 两个或多个圆弧或圆之间 |

## 2.6 草图状态（三态）

| 状态 | 颜色 | 处置 |
|---|---|---|
| **欠定义** | **蓝** | 补尺寸/几何关系 |
| **完全定义** | **黑** | 目标状态 |
| **过定义** | **黄** | 多余尺寸改**从动**，或删冲突关系 |
