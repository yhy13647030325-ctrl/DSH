# 第 13 章：配置与零件设计表

> PDF p842–862（书内 p832–852）。
> **操作约定**：命令写全菜单路径；对话框列默认值。
> **本章增量**：相对 `solidworks-practice` ch08，本章给出**配置项目的完整两类清单**。

## 本章范围（原文）

> **配置是 SOLIDWORKS 的一大特色**，它提供简便的方法以**开发与管理一组有着不同尺寸的零部件或者其他参数的模型**，并可以**在一个文件中使零件或装配体产生多种设计变化**。
> 在 SOLIDWORKS 中，可以**使用零件设计表同时生成多个配置**。

## 13.1 配置项目（p843）★ 本章最有价值的部分

**定义（原文）**：
> **配置项目是指与特定配置相关联的一系列设置或项目。** 可以是**特定的视图、尺寸、注解、材料、焊接符号、表面粗糙度符号**等。

### 零件的配置项目（10 项完整清单）

| # | 配置项目 |
|---|---|
| 1 | 修改**特征尺寸和公差** |
| 2 | **压缩**特征、方程式和终止条件 |
| 3 | 指定**质量和引力中心** |
| 4 | 使用不同的**草图基准面、草图几何关系和外部草图几何关系** |
| 5 | 设置**单独的面颜色** |
| 6 | 控制**基体零件**的配置 |
| 7 | 控制**分割零件**的配置 |
| 8 | 控制草图尺寸的**驱动状态** |
| 9 | 生成**派生配置** |
| 10 | 定义**配置属性** |

**零件设计表可设置**：特征的**尺寸、压缩状态和主要配置属性**，包括**材料明细表中的零件编号、派生的配置、方程式、草图几何关系、备注，以及自定义属性**。

### 装配体的配置项目（7 项完整清单）

| # | 配置项目 |
|---|---|
| 1 | 改变零部件的**压缩状态** |
| 2 | 改变零部件的**参考配置** |
| 3 | 更改**显示状态** |
| 4 | 改变**距离或角度配合的尺寸**，或压缩不需要的配合 |
| 5 | 修改属于**装配体特征的尺寸、公差或其他参数** |
| 6 | 定义**配置特定的属性** |
| 7 | 生成**派生配置** |

## 13.2 设计表的存储方式（p845）★ 最容易误解

> **设计表保存在模型文件中，并且不会链接到原来的 Excel 文件**，在模型中所做的更改**不会影响原来的 Excel 文件**。
> **如果需要，也可以将模型文件链接到 Excel 文件。**

> **★ 默认是"嵌入"，不是"链接"**。很多人以为改了 Excel 模型就会变——**默认不会**。

## 配置操作步骤（推导版）

> **⚠ 标注说明**：本章原书以**功能讲解**为主、案例参数以图给出。下列步骤为**按命令语义推导的可执行顺序**，标 **（推导）**。
> **尺寸/角度等具体数值一律不填**，仍以 **（需对照原书图 N）** 为准——推导的是**操作路径与选项**，不是数值。

### 流程 A：手动建配置

| 步 | 操作 | 路径 / 默认值 |
|---|---|---|
| **S01** | 切到配置树 **（推导）** | **CommandManager →【配置】标签** |
| **S02** | 显示特征尺寸 **（推导）** | **右击设计树【注解】→【显示特征尺寸】**（需先开 **Instant3D**） |
| **S03** | 加配置 **（推导）** | **右击某个尺寸 →【配置尺寸】** → 在对话框里**双击"生成新配置"文字** → 输入名 → Enter |
| **S04** | 加更多尺寸列 **（推导）** | **双击模型上其他 "D1" 尺寸** → 自动加入 |
| **S05** | 填各配置的值 **（推导）** | 逐行改数值 |
| **S06** | 保存表格 **（推导）** | **【输入名称】** 填名（如"规格"）→ **【保存】** → **【确定】** |
| **S07** | 激活某配置 **（推导）** | **双击配置名** |

### 流程 B：用设计表

| 步 | 操作 | 路径 / 默认值 |
|---|---|---|
| **S08** | 插入设计表 **（推导）** | **【插入】/【表格】/【设计表】** → 选默认设置 → 确定 |
| **S09** | 选尺寸 **（推导）** | 弹**【尺寸】对话框** → **Ctrl 多选**要参数化的尺寸 → 确定 |
| **S10** | 编辑表格 **（推导）** | 图形区空白处单击退出 → **右击【系列零件设计表】→【在单独窗口中编辑表格】** |
| **S11** | **改单元格格式** **（推导）** | Excel 里**右击左上角 →【设置单元格格式】→【常规】**（默认可能是"文本"，必须改） |
| **S12** | 派生配置 **（推导）** | **右击配置名 →【派生配置】** |
