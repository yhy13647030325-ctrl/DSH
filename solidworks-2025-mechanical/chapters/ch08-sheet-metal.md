# 第 8 章：钣金设计

> PDF p588–645。本书独有模块之一。与 `product-structure-liubaoshun` 第一章 1.4"冲压壳体"互为表里：那本讲"会不会裂"，这本讲"怎么建"。

## 核心要点

**钣金定义（p588）**：
> 钣金是针对金属薄板（**通常厚度在 6mm 以下**）的一种**综合冷加工工艺**，包括剪、冲、切、复合、折、焊接、铆接、拼接、成型（如汽车车身）等。
> **显著特征：同一零件厚度一致。**

**两种生成方式（p591）**：
1. **利用钣金命令直接生成**
2. **将现有零件进行转换**

本章讲第一种。

## 8.1 三个折弯参数（p589–591）★ 必须先分清

钣金设计经常涉及三个术语。三者**都用来算展开长度**，选一个用即可。

### 8.1.1 折弯系数（BA）

> **折弯系数是沿材料中性轴所测量的圆弧长度。**

**公式**：
```
Lt = A + B + BA
```
- Lt = 总平展长度
- A、B = 两侧直段长度
- BA = 折弯系数

**用法**：生成折弯时，**可以给任何一个折弯输入数值以指定明确的折弯系数**。

### 8.1.2 K因子

> **K因子是中性板相对于钣金零件厚度的位置的比率。**

**公式**：
```
BA = (R + K·T)·A/180
```
- BA = 折弯系数
- **R = 内侧折弯半径**
- **K = K因子**
- **T = 钣金零件厚度**
- **A = 折弯角度（经过折弯材料的角度）**

> **注意字母冲突**：Lt 公式里的 A 是**直段长度**，BA 公式里的 A 是**折弯角度**。原文都用 A，容易混。

### 8.1.3 折弯扣除（BD）

> **折弯扣除通常是指回退量**，也是一种简单算法，用来描述钣金折弯的过程。

**公式**：
```
Lt = A + B − BD
```
- BD = 折弯扣除

**用法**：生成折弯时**可输入数值给任何折弯指定明确的折弯扣除**。

### 三者怎么选（提炼）

| 参数 | 直观程度 | 适用 |
|---|---|---|
| **折弯系数 BA** | 高（直接给弧长） | 已知中性轴弧长 |
| **K因子** | 中（查材料表） | **最通用**，换材料只换 K |
| **折弯扣除 BD** | 高（老工艺习惯） | 直角边相加减回退量，车间常用 |

> 实战建议：**同一套模、同一批材料，只用一种算法并全厂统一**，否则展开图对不上。

## 8.2 生成钣金特征

### 8.2.1 基体法兰（p591–595）★ 第一个特征

**关键判据（原文）**：
> **基体法兰是钣金零件的第一个特征。** 当基体法兰被添加到 SOLIDWORKS 零件后，系统会**将该零件标记为钣金零件**，并且在特征管理器设计树中**显示特定的钣金特征**。

**属性设置**：

| 组 | 选项 | 说明 |
|---|---|---|
| **【钣金规格】** | 勾**【使用规格表】** | **根据指定的材料，可以定义钣金的电子表格及数值** |
| **【钣金参数】** | **【厚度】** | 设置钣金厚度 |
| | **反向加厚复选框** | 以相反的方向加厚钣金 |
| | **【半径】** | **设置钣金折弯处的半径** |

**操作实例（p593）**：
1. 打开素材（第 8 章 > 基本功能 > 8.2.1）
2. **单击特征树中的【草图1】图标，使之处于被选择状态**
3. 【插入】>【钣金】>【基体法兰】→ 弹出属性管理器
4. 按图设参数 → 确定 → 完成

> **【使用规格表】的价值**：把"材料 → 厚度/折弯半径/折弯扣除"做成表，**改材料即改全部参数**。这是钣金标准化的核心机制。

### 8.2.2 边线法兰（p595 起）

> 可以在**一条或者多条边线**上添加边线法兰。

### 8.2.3 其他钣金命令（章首"本章介绍"列出）

编辑钣金特征主要包括：折弯、展开、折叠、切口等（**具体以配套素材为准**）。

## 8.3 钣金与可展曲面的关系

`solidworks-surface-advanced` 第 1 章指出：**可展曲面**（平面、圆柱面、圆锥面）是**直纹曲面的子集**，可在**未拉伸状态下自由展开**。

> **推论**：钣金只能展开**可展**的部分。件上如果有自由曲面（NURBS），展开会失败或失真。
> 所以**钣金件的形状天然限制在"平面 + 圆柱/圆锥面 + 折弯"这几类**。

## 8.4 与结构设计技能的对应

`product-structure-liubaoshun` 第一章 1.4"冲压壳体"给了三条工艺判据：

| 判据 | 在钣金中的意义 |
|---|---|
| **弯曲线应垂直于板料纤维方向** | 平行会**开裂**（这是钣金件报废的头号原因） |
| **弯曲部位设加强筋** | 补刚性 |
| **拉伸件形状简单对称、法兰边宽度一致** | 减少加工难度、省料 |

> **分工**：结构技能判断"这个设计会不会裂"；本技能负责"在软件里怎么建、展开长度算对"。

## 失败模式（F-M8）

| 编号 | 现象 | 根因 | 处置 |
|---|---|---|---|
| F-M8-01 | 展开长度与实际不符 | 三个折弯参数**选错或取值不对** | 三者选一，按材料与模具核对，用规格表统一 |
| F-M8-02 | 做出来不是钣金件 | **没用基体法兰**做第一个特征 | 基体法兰才标记为钣金件 |
| F-M8-03 | 每个件折弯半径不同 | 没用规格表 | 勾【使用规格表】 |
| F-M8-04 | 厚度方向反了 | 加厚方向 | 用**反向加厚**复选框 |
| F-M8-05 | 展开后外形严重失真 | 件上有**非可展曲面** | 钣金只能展开可展曲面 |
| F-M8-06 | 折弯处开裂 | **弯曲线平行纤维方向** | 调整排样 |
| F-M8-07 | 折弯处强度不足 | 没加加强筋 | 弯曲部位加筋 |
| F-M8-08 | 同一零件厚度不一致 | 违反钣金前提 | 钣金必须厚度一致 |
