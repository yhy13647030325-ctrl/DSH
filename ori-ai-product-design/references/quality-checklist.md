# 质量检查清单

> 每个关键里程碑执行一次，确保交付物达到演示级标准。

---

## 阶段一检查：需求锚定

```
□ 四要素（背景/角色/场景/模块）全部明确
□ 交付形态已确认（HTML原型 / 报告 / 看板 / PPT）
□ 设计风格已选定（配色方案 + 深浅色需求）
□ PM确认"理解正确，开始做"
```

## 阶段二检查：策略底座

```
□ 核心指标定义清晰（名称/计算公式/单位/量级）
□ 指标计算逻辑已验算（输入样本数据→输出结果合理）
□ 分类/标签体系阈值已量化（非主观判断）
□ 数据结构已定义（字段名/类型/来源）
□ PM确认指标体系和分类逻辑
```

## 阶段三检查：骨架首版

```
### 结构完整性
□ 所有页面路由已创建（含placeholder页）
□ 侧边栏导航完整，点击切换正常
□ Header功能就位（主题切换/数据源指示/用户信息）
□ DataStore数据层初始化完成
□ 至少一个核心页面完整可交互

### 设计系统
□ CSS变量体系已定义（色彩/间距/圆角/字体）
□ 深色模式基础适配
□ 玻璃拟态组件就位
□ SVG图标（非emoji）

### 数据
□ Demo数据量级合理
□ Demo数据覆盖正常值+边界值
□ 数据源切换逻辑就绪（API/Upload/Demo）
```

## 阶段四检查：迭代质量（每轮）

```
### AI执行质量
□ 只改了PM要求改的地方（无多余改动）
□ 改动前后其他模块未受影响
□ 深色模式下改动处显示正常
□ 回报了具体改了什么、在哪里

### PM反馈质量
□ 反馈针对单一改进点
□ 提供了截图或具体描述
□ 预期效果可验证
```

## 阶段五检查：终版交付

```
### 视觉一致性（逐页检查）
□ 所有页面配色统一（无硬编码颜色遗漏）
□ 深色模式逐页完整适配
□ 字体层级一致（标题/正文/辅助/数字）
□ 8px栅格对齐（间距无随意值）
□ SVG图标线宽/圆角/尺寸统一
□ 零emoji

### 交互完整性
□ 所有按钮/链接有hover状态
□ 所有表格排序正常工作
□ 所有筛选器联动正确（改一个→全局刷新）
□ 空状态有兜底展示（非空白）
□ 日期选择器/下拉框可用
□ 批量操作（全选/计数/执行）正常

### 数据科学性
□ 热度值与播放量级关系合理（不出现量级失配）
□ 环比/同比计算正确（公式 + 结果验算）
□ 百分比之和 = 100%
□ 排序后排名正确更新
□ 指标卡片数字与趋势图数据一致

### 响应式适配
□ 1440px+：标准三栏显示正常
□ 1024px：侧边栏隐藏，主内容全宽
□ 768px：控件纵排，卡片重排
□ 图表在各宽度下可读

### 代码健壮性
□ DOM操作均有null保护
□ 外部数据有类型校验和格式检查
□ localStorage读写有try-catch
□ Chart.js实例销毁/重建正确
□ 无console.error残留

### 老板演示测试
□ 打开即见完整数据（无需额外操作）
□ 点击任何导航有响应（无死链）
□ 核心数字经得起追问（有计算逻辑可解释）
□ 视觉质量达到"不像AI做的"水准
□ 10秒内能理解页面在说什么
```

## 常见问题快查

| 问题 | 检查点 | 修复方向 |
|------|--------|---------|
| 深色模式某处白底 | 检查是否有硬编码 `#fff` 或 `white` | 改为 `var(--bg-xxx)` |
| 数字不对齐 | 检查是否缺少 `font-variant-numeric: tabular-nums` | 添加到数字容器 |
| 筛选器改了但数据没变 | 检查 `syncAllViews()` 是否被调用 | 确保筛选操作触发全局刷新 |
| 图表溢出容器 | 检查 canvas 是否设了 `width:100%!important` | 添加强制尺寸 |
| 移动端侧边栏挡内容 | 检查 `@media(max-width:1024px)` 是否隐藏 sidebar | 添加 `display:none` |
| 排序点击无反应 | 检查 `onclick` 是否绑定到 `th`，函数名是否正确 | 修正绑定 |
| 表格hover在深色模式下不明显 | 检查 `--bg-card-hover` 在深色下的值 | 调高对比度 |
