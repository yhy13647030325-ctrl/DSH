# PM 输入模板

> 每次启动新产品设计时，PM 用此模板整理思路并提供给 AI。
> 不必严格填满每一项——核心四要素必填，其余按需补充。

---

## 模板A：快速启动版（最小可用输入）

```markdown

**需求背景**：
[为什么要做这个东西？解决什么痛点？业务上下文是什么？]

**目标角色**：
[谁用？谁看？谁决策？分别有什么诉求？]

**使用场景**：
[在什么情境下使用？使用频率？是日常工具还是一次性演示？]

**主体模块**：
[列出你脑中的核心模块/功能点，大致即可]
1. 
2. 
3. 

## 交付要求（可选）

- 交付形态：[HTML原型 / 报告 / 看板 / PPT / 其他]
- 设计风格偏好：[科技蓝 / 珊瑚 / 莫兰迪 / 无印 / 商务报告 / 随你]
- 是否需要深浅色切换：[是 / 否]
- 其他要求：[如"需要移动端适配"、"需要密码保护"等]
```

## 模板C：迭代反馈模板（日常使用频率最高）

```markdown
## 本轮改进

**改什么**：
[一句话描述你要改的点]

**当前问题**：
[截图 + 文字描述当前的问题]

**期望效果**：
[描述你期望改成什么样 / 截图参考]

**优先级**：[高-必须改 / 中-最好改 / 低-有空改]
```

---

## 使用建议

1. **首次启动**：用模板A或B，确保四要素完整
2. **每轮迭代**：用模板C，一次只提一个改进点
3. **注入外部材料**：用模板D，告诉AI怎么用这个材料
4. **截图是最高效的沟通方式**——尤其是UI和交互问题，一张截图胜过百字描述
