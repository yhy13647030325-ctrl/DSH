# 第 7 章：以用户为中心的设计

## Core Idea
把前六章的结论收束为**七条可执行原则**；其底层是通过**系统表象**让用户建立起与设计者一致的概念模型，且必要时**易用性原则可以反向应用**。

## Frameworks Introduced

- **将任务化繁为简的七个原则**（全书的总纲，作者明言"其实我在本书中已经提出了七个很明确的原则"）：
  1. **应用储存于外部世界和头脑中的知识。**
  2. **简化任务的结构。**
  3. **注重可视性，消除执行阶段和评估阶段的鸿沟。**
  4. **建立正确的匹配关系。**
  5. **利用自然和人为的限制性因素。**
  6. **考虑可能出现的人为差错。**
  7. **若无法做到以上各点，就采用标准化。**
  - When to use：任何可用性评审的检查清单；前六条做不到时，第 7 条是保底方案。
  - 第 1 条的补充说明：设计应当**容许用户把外界知识与头脑中的知识结合起来**，由用户视情况决定使用哪一种，必要时在外界知识与头脑知识之间**建立互补关系**。

- **三种概念模型（心理模型的三个方面，原书图 7-1）**：
  - **设计模型（design model）**：设计人员头脑中对系统（产品）的概念。
  - **用户模型（user's model）**：用户所认为的该系统操作方法。
  - **系统表象（system image）**：产品的实际呈现——外观、操作方法、对操作动作的反应，以及用户手册。
  - 核心论断：**在理想状态下，用户模型应与设计模型相吻合。但实际上，用户和设计人员之间的交流只能通过系统本身来进行**，因此**系统表象格外重要**。设计人员必须保证产品的各个方面都与正确的概念模型保持一致。
  - 一句话总结：**用户所获得的有关产品的全部知识都来自于系统表象。**

- **建立正确概念模型的三个条件**：
  1. **操作原理显而易见**；
  2. **所有的操作动作都符合概念模型**；
  3. **产品的可视部分应该按照概念模型反映出产品的目前状态**。
  - 补充：设计人员必须开发出**适合用户**的概念模型，该模型应包含产品的重要操作部位，且能够被用户理解。

- **故意增加操作难度（易用性原则的反向应用）**：
  - 问题来源：有些产品应用在**很敏感的领域**，需要严格控制用户身份；但"总不能为了达到让一般人也能够明白使用方法这一目标，就使产品的保密特性大打折扣"。
  - 结论：**有时必须忽视优秀设计的原则，否则那些用于保密的产品就会丧失其存在的价值**——"本书中阐述的易用性原则可以反过来应用，合理加大物品的操作难度。"
  - 典型案例：英国斯德波福德一所专为**残疾儿童**开办的学校的校门——**插销位于门的最顶部，既不容易看到，也不容易触摸到，但这是一个好的设计**，因为校方不愿让学生在没有大人陪同下擅自走出校门。
  - 判据：难度是**为谁、为什么目的**而设置的——阻碍"不该操作的人"，而不是阻碍"应该操作的人"。

## Key Concepts

- **标准化的定位**：不是首选方案，而是**前六条都做不到时的兜底**——它牺牲了自然匹配，换取跨场景的一致性。
- **系统表象的重要性**：设计者与用户之间没有直接沟通渠道，**产品本身就是唯一的信息通道**。
- **设计与社会**：工具不仅可以为工作提供便利，也能在很大程度上影响我们对自己、对社会、对整个世界的看法。
- **技术预测的不准确性**：电话刚发明时，绝大多数人怀疑"我们为何需要电话？"；有人预测飞机会像汽车一样成为私人交通工具、每家车库停一架直升机。**但技术预测不准并不说明人类不必对技术可能产生的后果作些准备。**
- **书写工具与写作风格（社会影响的实例）**：早期用鹅毛笔和墨水在羊皮纸上写作，**修改文章十分费力**，因此写作者"小心翼翼、落笔前字斟句酌"，句子**长且富含修饰，表现出古典文学优雅的风格**；随着工具改进、修改越来越容易，写作速度变快，**句子更加接近日常用语**。有人批评文学失去艺术美，也有人认为这样更真实、更通俗易懂。

## Mental Models

- **Use 七原则 when 评审任何界面或产品**：逐条过一遍，前六条都不满足时再谈标准化。
- **Think of 系统表象 as 唯一的沟通渠道**：设计者的意图如果没写进产品外观、操作方式、反应与手册，用户就收不到。
- **Use 三条判据 when 检查概念模型是否建立**：操作原理看得见吗？所有动作都符合这个模型吗？产品显示的状态反映了这个模型吗？
- **Use 难度反向应用 when 存在"不该操作的人"**：把易用性调低，是达成**访问控制**的正当手段（校门、敏感设备）。
- **Use 书写工具史 when 论证"工具改变人"**：工具的可修改性、可迭代性会反过来改变使用者的思考与表达方式。

## Anti-patterns

- **把"标准化"当第一选择**：标准化是七原则的最后一条、兜底方案；优先用它等于放弃了自然匹配与限制因素。
- **产品各部分与概念模型不一致**：只要外观、操作动作、状态显示三者中有一处违背模型，用户就会建立错误的模型。
- **只做保密不做区分**：故意增加难度必须**只挡住不该用的人**；若把应当使用者一并挡住，就是失败的设计。
- **以静态眼光看待技术的社会影响**：人类对技术的预测经常不准确，但这不是可以不做事前准备的理由。
- **用旧工具时代的流程硬套新工具**：书写工具改变后写作风格已随之变化，沿用旧流程会白白放弃新工具的收益。

## Worked Example

**为一所残疾儿童学校设计校门：把七原则反向使用**

任务：设计校门，既要保证**校内人员和获准的来访者能正常通行**，又要**防止儿童在没有成人陪同下擅自走出校门**。

1. **明确"谁不该操作"**：目标是挡住儿童，而不是挡住全体使用者——这是反向设计的前提判据。
2. **反向应用七原则**：
   - 原则 3（可视性）：**把插销放在门的最顶部**，使其"既不容易看到，也不容易触摸到"。
   - 原则 5（限制因素）：用**身高与臂展**这一物理限制天然筛选使用者。
   - 原则 4（匹配关系）：正常开启方式由成人掌握，儿童无法自行推导。
   - 原则 2（简化结构）：对**成人**一侧保持简单直接（"TO OPEN — PULL DOWN …"），避免给教师增加负担。
3. **代价与验收**：成年使用者需要伸高并做出规定动作，操作效率降低。作者对此的判定是——**"这是一个好的设计"**，因为降低的易用性正好换来了安全，而且**没有误伤应当使用者**。
4. **对照通用情形**：若同一款门装在普通办公楼，把插销放到顶部就变成纯粹的坏设计（违反可视性且无正当理由）。**同一结构，目的不同，评价相反。**

## Key Takeaways

1. 化繁为简的七条原则：外部/头脑知识、简化结构、可视性与消除两鸿沟、正确匹配、自然与人为限制、考虑人为差错、兜底用标准化。
2. **标准化是最后手段**，不是起点。
3. 用户与设计者之间**只能通过系统表象沟通**；用户关于产品的全部知识都来自系统表象。
4. 建立正确概念模型的三条件：操作原理显而易见、所有动作符合模型、可视部分反映当前状态。
5. **易用性原则可以反向应用**：为保密或安全，可合理加大操作难度（校门案例）。
6. 反向应用的判据是"**只挡住不该操作的人**"。
7. 工具会改变社会与人的表达方式（书写工具史），而人类对技术影响的预测经常不准——这不是不准备的理由。
