# 第 5 章：人非圣贤，孰能无过

## Core Idea
差错分两类：**失误（执行出错、目标没错、下意识）**与**错误（目标本身错了、意识行为）**；两者成因不同，对策也不同——失误靠**限制与强迫性功能**预防，错误靠**信息与教育**纠正。

## Frameworks Introduced

- **失误 vs 错误（用行动七阶段切分）**：
  - **失误（slips）**：**设立了一个正确的目标，但在执行过程中出了问题**。"失误大多是些小事：找错了行动对象、移错了物体、应该做的事没有去做。**只要稍加注意和观察，就能察觉出这些失误。**"
  - **错误（mistakes）**：**行动目标错了**。"错误可能是些非常严重的事，但又**很难被察觉，甚至不可能被察觉**，因为相对于目标来说，所执行的动作毕竟没有任何问题。"
  - 本质区别：**失误是下意识的行为，错误则产生于意识行为中**。
  - 意识行为的价值与风险：让我们具有创造力与洞察力，能从表面上毫不相关的事物中看出联系，并**根据部分正确甚至错误的证据迅速得出正确的结论**；但同一过程也可导致差错——**归纳太快**，把新情况误认为与旧情况相似，而"错误的归纳很难被发现，更不用说去消除了"。
  - When to use：拿到一个差错案例，先问"是目标错了，还是执行错了"。

- **失误的六类（原书分类）**：
  1. **撷取性失误（capture errors）**
  2. **描述性失误（description errors）**
  3. **数据干扰失误（data-driven errors）**
  4. **联想失误（associative activation errors）**
  5. **忘记动作目的造成的失误（loss-of-activation errors）**
  6. **功能状态失误（mode errors）**
  - 成因综述：由**动作之间的相似性**造成；有时是**外界发生的某件事自动引发了一个动作**；有时是**脑中所想的、手中所做的触发了原本无意去做的动作**。
  - 发生条件：**失误经常出现在你已习以为常的行为当中**，正在学习做某件事时则很少出现；部分原因是**注意力不集中**。人一次只能专注于一件事，但日常中常同时做几件事（边走边说、边开车边交谈），之所以能这样做，是因为**大部分动作是机械的、下意识的**。

- **与差错相关的设计原则（四条）**：
  1. **了解各种导致差错的因素，在设计中尽量减少这些因素。**
  2. **使操作者能够撤消以前的指令**，或是**增加那些不能逆转的操作的难度**。
  3. **使操作者能够比较容易地发现并纠正差错。**
  4. **改变对差错的态度**——要认为操作者不过是想完成某一任务、只是采取的措施不够完美，**不要认为操作者是在犯错误**。
  - 设计人员的真正错误在于：**没有把人的差错这一因素考虑在内**，设计出的产品容易造成操作失误，或使操作者难以发现差错，即使发现了也无法及时纠正。

## Key Concepts

- **强迫性功能（forcing function）**：把车钥匙锁在车里一度是常犯差错，为此有些汽车设计成"**只有用车钥匙才能把车门锁上**"，这就逼得你不得不把钥匙带在身上。这是用**物理机制防止失误**，而非提醒。
- **警报的局限性**：作者举出三条不被青睐的原因——**有时会出现故障**；**分辨不出哪些是错误的操作行为、哪些是故意的操作行为**（例如本就想开着车门交东西，警报声只会让人心烦）；**数量太多且声音相似**，操作人员习惯性忽略，而真出紧急情况时"所有的警报信号一齐响起来、音量一个比一个高，又会吵得工作人员难以集中精力处理问题"。
- **差错的可理解性**："人们在出现差错时，通常都能找到正当的理由。"属于错误范畴的，往往是因为**用户能得到的信息不够完整或产生了误导**；属于失误的，很可能是**设计上的弊端**或操作者精力不集中。
- **失误与注意力的关系**：注意力只需集中在高级层面（如演奏风格与技巧），具体动作由下意识控制；这既是熟练的标志，也是失误的温床。

## Mental Models

- **Use 七阶段 when 给差错定性**：目标错 → 错误；目标对而执行错 → 失误。
- **Think of 失误 as 熟练的副产品**：越熟练、越自动化，越容易犯失误；因此不要指望"更小心一点"能解决，要用设计手段。
- **Use 强迫性功能 when 某个差错的后果不可接受**：与其提醒用户，不如让错误**做不到**（不插钥匙就锁不上门）。
- **Use「可逆性」when 设计不可撤销的操作**：能撤消就给撤消；不能撤消的，**特意增加其操作难度**。
- **Treat 警报 as 低优先级手段**：警报会故障、会被忽略、会淹没彼此，不能作为防差错的主力。
- **Use「改变对差错的态度」when 做团队复盘**：把差错视为"措施不够完美"，而不是"人的过失"，否则差错会被隐瞒（呼应第 2 章秘书不汇报的例子）。

## Anti-patterns

- **把差错归因于操作者不认真**："人们常常认为应该尽量避免出错，或是认为只有那些不熟悉技术或不认真工作的人才会犯错误。其实**每个人都会出错**。"
- **不提供撤消，也不增加不可逆操作的难度**：使用户在一次误操作后无法挽回。
- **让差错难以被发现**：用户犯错了却无信号提示，只能付出更大代价才察觉。
- **用警报代替防错**：警报分辨不出故意与误操作，数量一多就被忽略，紧急时反而干扰处理。
- **惩罚或动怒于出错者**：作者明确要求"不要惩罚那些出错的人，也不要为此动怒"，但**更不能对差错置之不理**。
- **设计对差错零容忍却对使用场景零考虑**：作者举伦敦证券交易所的例子——"如果不是糟糕的设计，怎么可能会因为一个人犯了一个简单的错误，就导致如此大的损失"。

## Worked Example

**把车钥匙锁在车里：三种防错手段的层级对比**

问题：人下车时把钥匙留在点火开关上，车门却锁上了。

1. **提醒型（最弱）**：美国法规要求"若车钥匙还插在点火开关上，一打开车门警报器就会响"。
   - 失效原因：**警报分辨不出故意与误操作**。"你并不想让汽车熄火，打开车门只是为把东西交给某人"，警报只会让你心烦；久而久之用户学会忽略它。书中给的判据是：**警报信号并不总是能够有效地防止差错。**
2. **强制型（最强）——强迫性功能**：把设计改成"**只有用车钥匙才能把车门锁上**"，于是你**不得不**把钥匙带在身上。
   - 原理：不是提醒，而是让错误操作在物理上不可能完成；由**机制**而非**自觉**来保证正确行为。
3. **判据（用本章四条原则检验）**：
   - 原则 1（减少致错因素）：强制型把"钥匙留在车里"这一因素直接消除。
   - 原则 2（可撤消 / 增加不可逆操作的难度）：锁车是不易逆转的动作，因此应提高其门槛。
   - 原则 3（易于发现并纠正）：提醒型让用户听到，强制型让用户根本不会错。
   - 原则 4（改变态度）：两者都不惩罚用户。

**结论**：能用**强迫性功能**解决的差错，不要退回用**警报**解决。

## Key Takeaways

1. 失误 = 目标正确、执行出错、**下意识**；错误 = **目标本身错了**、意识行为。
2. 失误容易被察觉，错误很难甚至不可能被察觉——因此错误的代价通常更高。
3. 失误的六类：撷取性、描述性、数据干扰、联想、忘记动作目的、功能状态。
4. 失误多发于**已习以为常的动作**与**注意力分散**时，靠"更小心"无法根治。
5. 四条设计原则：减少致错因素 / 支持撤消或增加不可逆操作难度 / 便于发现并纠正差错 / 改变对差错的态度。
6. **强迫性功能**是防差错的最强手段：让错误行为做不到，而不是提醒用户别做。
7. 警报有三大局限（会故障、分不清故意与否、太多而被忽略），不可作为防错主力。
8. 不要惩罚出错的人，但**更不能对差错置之不理**。
