# 速查表（Cheatsheet）

## 决策规则

| 情形 | 决定 |
|---|---|
| 尺寸上下限都受约束 | Ⅰ型双限值 → P95 和 P5；涉及健康安全用 P99 和 P1 |
| 只受上限约束（净空、门高、通道） | ⅡA 型大尺寸 → P90；安全类 P99/P95 |
| 只受下限约束（可及、够到、抓握） | ⅡB 型小尺寸 → P10；安全类 P1/P5 |
| 一般产品、对个体差异不敏感 | Ⅲ型平均尺寸 → P50 |
| 男女通用产品 | 男 P99/P95/P90 定上限；女 P1/P5/P10 定下限 |
| 人体尺寸 → 图纸尺寸 | 加功能修正量；追求舒适再加心理修正量 |
| 无法固定唯一尺寸 | 给出**可调范围**，而非取平均 |
| 坐立必须二选一 | 通常选**坐姿**（ISO 6385） |
| 需要施力 | 避免静态施力；不可避免则 < 最大肌力 **15%** |
| 需要高精度动作 | 不要要求大肌力 |
| 键盘/工作面高度 | 上臂自然下垂、肘角 **70°~90°** |
| 固定显示器 | 上限高度与水平视线平齐；头部倾角 ≤**30°** |
| 坐姿监控控制台 | 台高低于坐姿视水平线；主面板斜度 **20°** |
| 坐姿岗位搬重物 | ≤ **4.5 kg**，否则改立姿 |
| 仪表刻度 | 大刻度间距 **L/50**；最小刻度不标数、最大刻度必须标数 |
| 仪表布置优先级 | 上限 > 右上限 > 左下限 > **右下限最差** |
| 环境达不到舒适 | 退允许区；守不住安全区就必须密封隔离 |
| 热环境基准 | **23 ℃／50%（40%~60%）／风速 ≤0.1 m/s** |
| 高温作业红线 | 深部体温 **38.5 ℃~38.8 ℃**，超则缩工时 + 防护 |
| 座垫设计 | 压力分布不均匀，接触边界 **2~8 kPa**；第一支承在第 **5、6 胸椎**之间 |
| 照明设计 | 六项要求（含"必须考虑成本"）；天花板青蓝色、壁面 V=8、C<3 |
| 危险信号 | 强度/形状/大小/对比度/显著性/信噪比都要保证 |
| 关键控制器 | 必须加防误动作保护装置 |
| 安全防护顺序 | 消除（双手按钮）→ 隔离（安全距离）→ 探测（感应+停机）→ 告警（颜色：黑/白/橙/红/黄） |
| 进入危险区 | 必须先断电 |
| 防护标准对象 | 以**初学者/不熟练使用者**为目标 |
| 智能系统决策 | 默认**人机共商**，而非机器独裁 |

## 决策树

```
该用哪个百分位？
├─ 上下限都受约束 → Ⅰ型：安全类 P99/P1（98%）｜一般类 P95/P5（90%）
├─ 只受上限约束   → ⅡA 型：安全类 P99/P95｜一般类 P90
├─ 只受下限约束   → ⅡB 型：安全类 P1/P5｜一般类 P10
└─ 一般产品       → Ⅲ型：P50

该选哪种作业岗位？
├─ 轻/中作业、不走动、搬动 ≤4.5 kg → 坐姿
├─ 需较大力量 / 需走动 / 空间大     → 立姿
└─ 复合作业、子任务分别适宜坐/立    → 坐、立姿交替

环境达标到哪一档？
舒适区 → 允许区 → 安全区 → （都达不到）密封隔离
```

## 阈值与默认值

| 量 | 值 |
|---|---|
| 短时记忆 / 注意广度 | 7±2 组块 / 约 7 个单位 |
| 暗适应 / 明适应 | 约 30 min / 约 1 min |
| 正常视力临界视角 | 1′ |
| 神经传导速度 | 约 100 m/s |
| 人脑突触数 / 每神经元 | 约 10¹⁴ / 10³~10⁴ |
| 静态施力上限 | 最大肌力的 15% |
| 背部肌肉力臂 / 背部受力 | 约 5 cm / 可达重物重力约 8 倍（≈3800 N） |
| 前臂重力（成年工人） | 约 16 N |
| 坐姿岗位搬动重物 | ≤ 4.5 kg |
| 大刻度最小间距 | L/50 |
| 座垫接触边界压力 | 2~8 kPa |
| 键盘倾斜 / 手腕休息区 | 5°~15° / 约 100 mm |
| 上臂与前臂夹角 / 头部倾角 | 70°~90° / ≤30° |
| 控制台面板斜度 | 20° |
| 舒适气候 | 23 ℃ / 50% / ≤0.1 m/s |
| 深部体温耐受 / 局部体温不舒适 | 38.5 ℃~38.8 ℃ / 38 ℃ |
| 无力防避比例 | 14% |
| 壁面明度 / 彩度 | V=8 / C<3 |

## 识别信号

- "长时间抓握""臂部上举""举手过顶" → 静态肌肉施力，须改设计或压到 15% 以内。
- "弯腰搬重物" → 背部受力已放大到重物重力约 8 倍。
- "食指反复扳扳机" → 扳机指风险，改拇指或指压板。
- "高个子撞头 / 小个子够不到" → 百分位用反了。
- "按'平均人'设计" → 除一般工业产品外都是错误默认。
- "只靠培训和告警保安全" → 缺装置层与防护层（14% 的人无力防避）。
- "从亮处直接进暗处作业" → 需 30 min 暗适应，应设照明过渡。
- "工作面有阴影或亮度突变" → 违背照度均匀、变化平缓。
- "关键信息放在右下视野" → 该区观察最差，移到上限区。
