# 第 1 章：人机工程学概论

## Core Idea
人机工程学研究人、机、环境三要素之间的相互作用规律，根本目的是**确保人-机-环境系统总体性能的最优化**；由此派生出两个核心思想——**以人为中心的设计理念**与**以人为本的管理思想**。

## Frameworks Introduced

- **人-机-环境系统三要素模型（七个研究分支）**：人-机-环境三条关系曲线交叉形成七个分支——①人的特性 ②机器特性 ③环境特性 ④人-机关系 ⑤人-环境关系 ⑥机-环境关系 ⑦人-机-环境系统性能。
  - When to use：分析任何一个人机系统问题时，先判断问题落在哪个分支上。
  - How：把问题拆成人/机/环境三要素及其两两关系与系统整体，逐个定位。

- **学科发展三阶段模型**（判断一个设计的成熟度／出发点）：
  1. **经验人机工程学**（泰罗科学管理 → 二战前）：研究者多为心理学家（代表 H.闵斯特泼格《心理学与工业效率》）；特点是**以选择和培训操作者为主，使人适应于机器**。
  2. **科学人机工程学**（二战期间 → 1950 年代末）：源于武器装备"忽视人的因素"导致操作失误的教训，认识到"主要的限制因素不是武器而是人"；特点**力求使机器适应于人**，学科名多称"工程心理学"。
  3. **现代人机工程学**（1960 年代至今）：引入控制论、信息论、系统论（"新三论"）进入系统研究阶段。
  - When to use：评估一个产品/系统停留在哪个层次——只训练使用者（阶段 1），还是改造机器（阶段 2），还是做人机环境系统优化（阶段 3）。

- **学科体系的"人体"比喻**：人体科学（人体解剖学、劳动生理学、人体测量学、人体力学、劳动心理学）+ 环境科学（环境保护学、环境医学、环境卫生学、环境心理学、环境监测学）为"两上肢"；管理科学、人文科学为"两下肢"；工程科学（工业设计、工业工程、安全工程、系统工程等）为"躯干"。
- **学科研究方法五法**：①观察分析法 ②实测法 ③实验法 ④模拟和模型试验法 ⑤计算机数值仿真法。
  - When to use：实测受限时用实验法；系统复杂、物理模型定型后难改时用计算机数值仿真法。
- **现代人机工程学五个新特点**：软件化、网络化、虚拟化、数字化、**智能化**（普通系统向智能化人机系统演化是必然趋势）。

## Key Concepts

- **人机工程学**：研究人、机械及其工作环境之间相互作用的综合性边缘学科。
- **Ergonomics**：源自希腊词根 *ergon*（工作、劳动）+ *nomoi*（规律、规则），本义为人的劳动规律；因词义中立、便于各国语言统一，成为国际上采用最多的命名。
- **IEA 定义（最权威）**：人机工程学研究人在某种工作环境中的解剖学、生理学和心理学等方面的各种因素，研究人和机器及环境的相互作用，研究在工作中、家庭生活中和休假时怎样统一考虑工作效率、人的健康、安全和舒适等问题的学科。
- **学科别名**：人类工程学（Human Engineering，美）、人的因素工程学（Human Factors Engineering，美）、人类工效学（Ergonomics，西欧）；国内常见人-机-环境系统工程、人体工程学、宜人学、人的因素等。
- **效能的广义含义**：不仅指工作短期内有效完成，还指长期内不存在对健康有害的影响，并使事故危险性缩小到最低限度。
- **C.C.伍德定义**：设备设计必须适合人的各方面因素，以便在操作上付出最小的代价而求得最高效率。
- **A.查帕尼斯定义**：人机工程学是在机械设计中，考虑如何使人获得操作简便而又准确的一门学科。

## Mental Models

- **Use「三要素+七分支」when 拿到任何一个设计问题**：先问"这是人的特性问题、机器特性问题、环境特性问题，还是它们之间的关系问题？"再决定查哪一类数据与方法。
- **Think of 人机分工 as 互补**：机器功率大、速度快、不会疲劳；人有智慧、多方面才能、适应能力强。人机配合的成效来自**取长补短**，因此"分工"与"信息交流"是系统的基本设计问题。
- **Treat「使机器适应人」as 成熟度标尺**：仍在要求使用者适应机器（靠选拔、培训、加警告）的设计，处于经验人机工程学阶段。
- **Use 效率的"长期账"when 评价设计**：只看短期产出的效率观是片面的；应把健康影响与事故风险一并计入。

## Anti-patterns

- **只重功能、忽视"人的因素"**：二战中片面注重新式武器的功能研究，导致误读仪表、误用操纵器、命中率低——这正是科学人机工程学诞生的代价。
- **把自己的研究视角当成学科边界**：各国按自身角度命名与定义（美国偏工程与人际关系、法国偏劳动生理学、苏联偏工程心理学、保加利亚偏人体测量），导致名称与定义不统一；设计中若只按单一学科视角组织，会漏掉要素。
- **把人的因素视为系统的次要限制**：在人与装备的关系中，主要限制因素往往不是装备而是人。

## Worked Example

**机床操作部位高度（人体尺度与设计的关系）**

同一个车床设计，操作部位的高度若与人的上肢舒适操作高度相比**过低或过高**，操作者就必须**弯腰或抬臂**。后果依次为：影响工作效率 → 人体过早产生疲劳 → 长期操作对健康带来不利影响。反过来，正确的做法是：一切操作装置都应设在人的肢体活动所能及的范围之内，其高低位置与人体相应部位相适应，并尽可能设在人操作方便、反应最灵活的范围之内。

这个例子演示了第 1 章埋下、第 2 章展开的核心逻辑：**设计中所有涉及人体尺度参数的确定都需要应用大量人体构造和功能尺寸的测量数据**。

## Key Takeaways

1. 一切人机工程设计问题的起点是"人-机-环境"三要素定位；终点是系统总体性能最优化。
2. 判断设计水平：还在要求人适应机器，就还没进入现代人机工程学。
3. IEA 的定义把范围从工作扩展到**家庭生活与休假**——统一考虑工作效率、健康、安全、舒适。
4. 五个研究方法按"实测 → 实验 → 模拟 → 数值仿真"逐级替代，仿真法是最现代的补充而非替代品。
5. 工业设计师的四项本职研究内容：人体特性研究；工作场所和信息传递装置设计；环境控制与安全保护设计；人机系统的总体设计。
6. 安全防护装置应在**设计阶段就视为机械的一部分**直接接入机器，而不是事后附加。
