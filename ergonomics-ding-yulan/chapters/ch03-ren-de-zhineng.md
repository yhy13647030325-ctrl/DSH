# 第 3 章：人的智能与人机智能

## Core Idea
人的智能有明确的物质基础（脑与神经系统），其运作可被拆成"感知—加工—决策—执行"的机能系统；理解这套机制，是人机系统走向**智能化**的前提。

## Frameworks Introduced

- **神经系统两分框架**：按位置与功能分为**中枢部**（颅腔内的脑 + 椎管内的脊髓）与**周围部**。
  - 周围部：与脑相连称脑神经，与脊髓相连称脊神经；按分布器官分为支配体表/骨/关节/骨骼肌的**躯体神经**与支配内脏/心血管/平滑肌/腺体的**内脏神经**。
  - How：把复杂的解剖结构简化为工程常见的**框图**（输入 → 中枢整合 → 输出效应器）来分析。
  - 机能链：感受器接受内外环境信息 → 周围神经传入脊髓和脑的各级中枢整合 → 经周围神经传出（或经内分泌腺）到达效应器 → 协调全身器官活动、维持内环境稳定。

- **大脑功能定位框架**：
  - 脑分为**大脑、间脑、小脑、脑干**四部分；大脑半球借外侧裂、中央沟及枕切迹至顶枕裂顶端的假想连线分为**五个脑叶**（额叶、顶叶、颞叶、枕叶、岛叶）。
  - **躯体感觉区**：身体各部分的精细代表区是**倒置**的，代表区大小取决于功能重要性。
  - **躯体运动区**：精细代表区基本上也是倒置的，但**头面部仍是正的**；运动愈精细的部位（手、舌、唇）代表区面积愈大。
  - **三个基本联络区**：第一区（调节紧张度/觉醒状态）｜第二区（接受、加工和储存信息）｜第三区（规划、调节和控制复杂活动，位于额叶）。
  - When to use：从"脑区损伤 → 功能丧失"反推某项设计要调动哪类认知机能（如第三区受损 → 行为失去主动性、不能规划行为）。

- **神经元与突触模型**：神经元基本构造为**细胞体、树突、轴突**三部分。
  - 细胞体：细胞膜厚 5~10 mm，膜内外电位差称**膜电位**，约 20~100 mV，随输入信号强弱变化。
  - 树突：长约 1 mm 的短突起，接受其他神经元传来的冲动。
  - 轴突：最长的一条神经纤维，末端分支称轴突末梢/神经末梢，其上有突触扣结。
  - **突触**：一个神经元的轴突末梢与另一神经元的树突或细胞体之间的微小间隙联结，直径 0.5~2 μm，分**兴奋型**与**抑制型**。
  - 规模：一个神经元有 10³~10⁴ 个突触；人脑约有 **10¹⁴ 个突触**。
  - 传导：电脉冲沿轴突以约 **100 m/s** 传到突触，末端释放化学物质改变突触后电位。

- **信息在人脑中的转化（二级层次模型）**：
  - 第一层次：外部信息的接收和转译结果，含原始拓扑结构及与之相适应的神经元冲动（**一一对应关系**）。
  - 第二层次：在第一层次基础上不断抽取、交联、组合，逐渐转化成统一整体，从整体中产生**概念**；概念进一步升华为**意识、情感**等高级智能因素。
  - 关键判断：人脑**不处理单个信息元素，而是处理整个信息集合的层次关系**（群处理过程）。

- **人的智能活动过程模型**：
  - 组成：感知器官（视/听/触/味觉）｜效应器官（手、腿、嘴等）｜传导神经｜思维器官（主要由中枢神经系统构成）。
  - 思维器官四机能：**计算**（感知信息预处理）、**认知**（信息→知识）、**决策**（据目标用知识生成方案）、**动机**（行为的内部动力）。
  - When to use：分析一个智能系统的"哪一环断了"——任何子过程失效都可导致整个过程失败。

- **人的智能形成过程模型（8 条建模基本假设）**：
  ①人是有"不断谋求更好生存与发展条件"目的之物种（目的是"看不见的手"）②感知系统灵敏、可选择性注意 ③传导神经系统把人体连成有机整体 ④思维器官具归纳/分析/演绎能力 ⑤记忆系统容量巨大 ⑥拥有本能知识 + 常识知识 ⑦有发达的行动器官 ⑧有语言能力可协作。
  - 流程：新信息 → 非认知预处理（排序、分类、过滤、去冗余、数值计算、简单逻辑处理）→ "旧信息" → 认知转换为知识 → 知识激活为智能策略 → 经神经系统传至效应器官 → 智能行为 → 求解问题、达到目标。

## Key Concepts

- **智能科学**：21 世纪国内外高度重视的前沿学科群，含脑科学、神经科学、认知科学、思维科学、人工智能。
- **认知科学（Cognitive Science）**：起源于 20 世纪 50 年代末，研究人脑的认知过程和机制（意识、感情、思维），是哲学、心理科学、计算机科学、神经科学、科学语言学等的交叉科学。
- **大脑皮层**：覆盖大脑半球表面的灰质，占中枢神经系统灰质的约 **90%**，是神经系统最高级中枢、意识活动的物质基础。
- **神经冲动传导速度**：沿轴突约 100 m/s。
- **人脑的可塑性**：长期进化使人脑具有庞大机能结构、很高的**可靠性、多余度和容错能力**——这使人在人机系统中成为最重要、主导的环节。
- **人机智能系统**：传统人机系统的发展方向，是人机工程学中的重要研究内容。

## Mental Models

- **Think of 神经系统 as 一个工程框图**：输入（感受器）→ 中枢整合 → 输出（效应器），便于把生理机制转译成设计语言。
- **Use 整体论 when 分析智能活动**：智能活动是完整而有机的过程，任何一个子系统的失效都可能使整个过程归于失败；但同时各子系统各有专司、缺一不可。
- **Use「群处理」when 推断人的信息加工方式**：人接收的是由拓扑结构与信息元素群组成的混合物，而非互相独立的元素——因此界面设计应保留信息的层次结构。
- **Treat 人 as 人机系统的主导环节**：因为脑具有极高可靠性与容错能力，而机器的优势在速度与功率。
- **在人机智能系统中强调人机协同而非全自主**：设计重点应落在"人机结合"的智能形态上。

## Anti-patterns

- **把人的智能简化为"逐元素处理"**：忽视人脑的层次化、群处理特性，会导致信息呈现方式与人脑加工方式相悖。
- **忽视"目的"在智能活动中的驱动作用**：目的是驾驭人类一切活动的"看不见的手"，抽掉它就无法解释选择性注意与动机。
- **假设智能系统中人可以被完全替代**：人的直觉、经验、应变与创造性（"只可意会、不可言传"）是计算机难以模拟的部分。

## Reference Tables

**神经机能系统速查**

| 系统 | 组成 | 主要作用 |
|---|---|---|
| 中枢部 | 脑（颅腔内）+ 脊髓（椎管内） | 接收、整合、发出指令 |
| 周围部 — 脑神经 | 与脑相连 | 头颈部等 |
| 周围部 — 脊神经 | 与脊髓相连 | 躯干四肢 |
| 躯体神经 | 支配体表、骨、关节、骨骼肌 | 躯体感觉与运动 |
| 内脏神经 | 支配内脏、心血管、平滑肌、腺体 | 内脏调节 |

**大脑联络区三区**

| 区 | 位置 | 机能 | 损伤后果 |
|---|---|---|---|
| 第一区 | 脑干网状结构、脑内侧皮层或边缘皮层 | 保证调节紧张度或觉醒状态 | 大脑皮层觉醒程度下降，选择性活动难以进行，记忆毫无组织 |
| 第二区 | 视觉区（枕叶）、听觉区（颞叶）、一般感觉区（顶叶） | 接受、加工和储存信息 | 严重破坏接受和加工信息的条件 |
| 第三区 | 额叶 | 规划、调节和控制复杂活动形式 | 行为失去主动性，难以形成意向，不能规划自己的行为 |

## Worked Example

**用"人的智能形成过程模型"走一遍一次作业决策**

情境：操作者面对"问题—环境—目标"（例：生产线出现异常）。

1. **感知**：感觉器官获得关于问题、环境、目标的信息 → 记为"新信息"。
2. **传递**：神经系统把新信息送到思维器官。
3. **非认知预处理**：排序、分类、过滤、去除冗余，必要时作数值计算与简单逻辑处理 → 变成有序、便于利用的"旧信息"。
4. **认知**：把信息转换为相应知识（结合记忆系统中既有的本能知识与常识知识）。
5. **决策**：把知识激活成能满足约束、解决问题、达到目标的**智能策略**。
6. **执行**：神经系统把智能策略送至效应器官，转换为**智能行为**，实现对问题的求解。

对照人机分工：步骤 1~3 与 6 可由机器承担（传感器、预处理算法、执行机构），步骤 4~5 是人不可替代的长处——这正是"人机协同"分工的依据。

## Key Takeaways

1. 人的智能可分解为感知/传导/思维（计算·认知·决策·动机）/效应四大机能，任何一环失效都会导致整体失败。
2. 人脑以"信息群 + 层次关系"方式处理信息，界面与信息呈现应保留层次结构。
3. 神经传导速度约 100 m/s、膜电位 20~100 mV、突触直径 0.5~2 μm、人脑约 10¹⁴ 个突触——这些量级决定了人的反应速度上限。
4. 大脑皮层占中枢神经系统灰质约 90%，是意识活动的物质基础。
5. 人机系统的智能化是发展方向，但设计重点应是**人机结合**，而非追求完全自主。
6. 人的直觉、经验与创造性是机器难以模拟的部分，也是人在系统中保持主导地位的理由。
