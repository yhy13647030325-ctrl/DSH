# 第 8 章：个体作业岗位与空间设计

## Core Idea
作业岗位的第一步是**按任务性质选姿势**（坐姿/立姿/坐立交替），第二步是围绕**人-椅、眼-视屏、手-键盘**三个界面确定尺寸，最后用"舒适—最大作业区域"校核空间布置。

## Frameworks Introduced

- **作业岗位选择框架**（依据工作任务的性质选择）：
  - **坐姿作业岗位**：为从事轻作业、中作业且不要求作业者在作业过程中走动的工作而组织。
    判断特征：①不需作业者施用较大力量（**搬动重物不得超过 4.5 kg**，否则应改立姿）；②要求操作位置分开、需要在不同岗位之间经常走动的情况则不适用；③操作位置相对固定。
  - **立姿作业岗位**：适合需要较大力量、需要走动或操作空间较大的作业。
  - **坐、立姿交替作业岗位**：因工作任务性质要求操作者在作业过程中采用不同姿势、而只有不同岗位才能满足时组织。
    判断要点：①不考虑人体可及范围和静负荷疲劳的特点，可取坐姿岗位；但考虑人的特性……②对于复合作业，有的最好取坐姿、有的适宜立姿，从优化人机系统考虑应取**坐、立姿交替岗位**。
  - When to use：选择哪一类岗位**必须依据工作任务的性质**来考虑；工业生产中常用的联合作业有推荐的最适用方案。

- **手工作业岗位设计框架**：
  - **布局原则**：①作业岗位的布局应保证作业者在上肢活动所能达到的区域内完成各动作；②应考虑操作动作的频繁程度；③还应考虑作业者的**群体构成**（全为男性或全为女性，或男女性混合时应取男女尺寸的综合指标）。
  - **生理特点原则**：必须考虑作业者动作的**习惯性、同时性、对称性、节奏性、规律性**等生理特点，以及**动作经济性原则**。
  - **合规原则**：作业岗位设计还应符合 GB 5083—1999 等有关标准和劳动安全规程。
  - **尺寸确定方法**（两类尺寸）：
    ①作业面高度 C 通常依据作业对象、工作面上相关配置件尺寸确定；
    ②工作台面厚度 K 在设计时应满足给定关系式。
  - **作业分类与 H₁、H₂**：Ⅰ类、Ⅱ类（使用臂力为主、对视力有一般要求的作业）、Ⅲ类（兼顾视力和臂力的作业），各类作业对应相应的 H₁、H₂ 尺寸。
  - 流水线特例：在生产流水线工作平面高度 A 必须统一的情况下，工作高度 H₂ 应按作业人员性别异同分两种情况确定。

- **视觉信息作业岗位的三个界面框架**（VDT 类岗位的核心）：
  - **人-椅界面**：
    ①首先要求作业者保持**正确坐姿**（头部不过度前倾等）；
    ②采用适当尺寸、结构和可以调节的座面。
  - **眼-视屏界面**：
    ①首先要求满足人的视觉特点，即从人体轴线至视屏中心的距离（视距）应符合要求；
    ②选用**可旋转和可移动的显示器**；若设置固定显示器，其**上限高度与水平视线平齐**，以避免头部上转。
  - **手-键盘界面**：
    ①上臂从肩关节自然下垂，**上臂与前臂的最适宜角度为 70°~90°**，以保证肘关节受力而不是上臂肌肉受力；
    ②保持手和前臂……（支撑）；
    ③为适应所有成年人的使用，可选择**高度固定的工作台**，但应选择**高度可调的平板**以放置键盘；键盘在平板上可前后移动，其**倾斜度在 5°~15° 范围内可调**；
    ④在腕关节和键盘间应留有 **100 mm 左右的手腕休息区**（腕垫），以避免手腕疲劳综合征。

- **作业空间设计框架**：
  - 需考虑：操作者的舒适性与安全性；便于使用、避免差错、提高效率；控制与显示的安排既紧凑又可区分；四肢分担的作业要均衡，避免身体……
  - 承认"不是最优的，但应最大限度地减少作业者的不便与不适"——作业空间设计应以"**人**"为中心，以**人体尺度**为重要依据。
  - **三维作业空间**：坐姿作业通常在作业面以上进行，其作业范围是一个三维空间，并受作业面的限制。
  - **水平作业面**：主要在坐姿或坐/站作业场合采用，必须位于作业者**舒适的手工作业空间**范围内。
    - **正常作业区域**：作业者应能在**小臂正常放置而上臂自然悬垂**状态下舒适地操作。
    - **最大作业区域**：应使在**臂部伸展**状态下能够操作，且这种作业状态**不宜持续很久**。
  - 应避免：伸臂过长的抓握、蹲身或屈曲、身体扭转、头部处于……

## Key Concepts

- **坐姿作业岗位**：轻/中作业、不要求走动、搬重物不超过 4.5 kg。
- **立姿作业岗位**：需较大力量或需要走动。
- **坐、立姿交替作业岗位**：复合作业的任务性质要求不同姿势时采用。
- **动作经济性原则**：手工作业岗位设计中必须遵循的生理特点原则之一。
- **作业面高度 C / 工作台面厚度 K / 工作高度 H₁、H₂**：手工作业岗位的核心尺寸量。
- **作业分类（Ⅰ/Ⅱ/Ⅲ类）**：按视力与臂力要求的侧重划分。
- **人-椅界面 / 眼-视屏界面 / 手-键盘界面**：视觉信息作业岗位的三个必备界面。
- **上臂与前臂最适宜角度**：70°~90°。
- **键盘倾斜度**：5°~15° 可调。
- **手腕休息区**：腕关节与键盘间约 100 mm，防手腕疲劳综合征。
- **显示器的上限高度**：固定显示器应与水平视线平齐，避免头部上转。
- **正常作业区域 / 最大作业区域**：水平作业面上的两级范围；后者不宜持续使用。
- **工作台面高度与头部倾角**：头部倾角不能超过 30°（否则需身体前屈）。

## Mental Models

- **Use「任务性质 → 姿势」作为岗位设计第一步**：先问"要施多大力？要不要走动？"，而不是先画台子。
- **Use 4.5 kg 作为坐姿岗位的力阈值**：超过该量级的搬动应改立姿。
- **Think of VDT 岗位 as 三个界面的联立方程**：人-椅、眼-视屏、手-键盘三者的尺寸必须同时满足，任一不配就会在颈、背、腕上体现为职业病。
- **Use 70°~90° 肘角 when 定键盘/工作面高度**：让肘关节受力而非上臂肌肉受力。
- **Use「正常区做常事、最大区做偶发事」when 布置工作面**：长时间操作必须落在正常作业区域内。
- **Treat「可调」优于「平均」**：面对人群差异，给出可调范围（键盘平板、座面）比取平均值更有效。
- **U形/半圆型布置的控制思想可迁移到作业空间布置**：把常用对象环绕在人的可及范围内。

## Anti-patterns

- **在坐姿岗位搬动超过 4.5 kg 的重物**：违背坐姿岗位的适用条件，应改为立姿。
- **把频繁操作放在最大作业区**：臂部伸展状态下操作不宜持续很久，长期如此必然导致疲劳与损伤。
- **键盘平板固定倾斜且无手腕休息区**：易致手腕疲劳综合征。
- **显示器位置过高要求头部上转**：固定显示器上限高度应与水平视线平齐。
- **只按单一性别尺寸设计混合性别岗位**：存在男女性别混合时应取男女尺寸的**综合指标**。
- **让作业者必须伸臂过长抓握、蹲身屈曲、身体扭转**：这些是应避免的作业空间形态。
- **忽视动作的习惯性、同时性、对称性、节奏性、规律性**：违背生理特点与动作经济性原则。
- **只为多数人设计而放弃可调手段**：应以可调范围覆盖个体差异。

| 界面 | 要求 | 关键数值 |
|---|---|---|

## Worked Example

**为一个打字与读屏为主的办公工位定尺寸**

1. **选姿势**：任务为轻作业、不需走动、不搬重物 → **坐姿作业岗位**。
2. **人-椅界面**：保证正确坐姿（头部不过度前倾）；选尺寸适当、结构合理且**可调节**的座面；腰部支承使腰弧曲线微微前凸（回引第 7 章）。
3. **眼-视屏界面**：视屏放在满足视觉特点的视距上；显示器选**可旋转可移动**式，或采用固定显示器但使其**上限高度与水平视线平齐**以防头部上转。
4. **手-键盘界面**：
   - 工作面选择**高度固定**的工作台（适应所有成年人），但键盘放在**高度可调的平板**上；
   - 调平板使上臂自然下垂、上臂与前臂夹角落在 **70°~90°**；
   - 键盘倾斜度调至 **5°~15°**，并留出约 **100 mm** 的手腕休息区（腕垫）。
5. **校核作业区域**：把高频操作（打字、常用按键、鼠标）保证落在**正常作业区域**（小臂正常放置、上臂自然悬垂）；只有偶发操作才允许伸到**最大作业区域**。
6. **复核合规**：对照 GB 5083—1999 等标准与劳动安全规程；若同一工位男女性混合使用，取男女尺寸的**综合指标**。

## Key Takeaways

1. 岗位类型由**任务性质**决定：坐姿（≤4.5 kg、不走动）/ 立姿 / 坐立交替。
2. 作业岗位布局三要素：上肢可及范围、动作频繁程度、作业者群体性别构成。
3. 必须遵循动作的习惯性、同时性、对称性、节奏性、规律性与动作经济性原则。
4. VDT 岗位必须同时解好三个界面：人-椅、眼-视屏、手-键盘。
5. 三个可直接引用的数值：肘角 70°~90°、键盘倾斜 5°~15°、手腕休息区约 100 mm。
6. 固定显示器上限高度与水平视线平齐；头部倾角不超过 30°。
7. 布置工作面时区分"正常作业区域"（长期用）与"最大作业区域"（偶发用）。
