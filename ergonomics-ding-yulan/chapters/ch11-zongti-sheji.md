# 第 11 章：人机系统总体设计

## Core Idea
总体设计的目标是让系统同时满足**安全、高效、舒适、健康、经济**五项指标；ISO 6385 给出的原则把这一目标翻译成工作空间、工作设备、信号显示、控制器、工作环境、工作过程六组可执行条款。

## Frameworks Introduced

- **总体设计五指标框架**：在人机系统设计时必须考虑系统的目标，即系统设计的目的所在。总体设计时要求满足 **①安全 ②高效 ③舒适 ④健康 ⑤经济** 五个指标。

- **ISO 6385—1981(E) 人机工程学原则框架**（工作系统设计的基本指导方针，可应用于对人的福利、安全和健康的最佳工作条件）：
  - **① 工作空间设计**：应考虑工作过程中对人身体尺寸所产生的……要求。工作空间应适合于操作者，设计时要特别注意下列各点：
    - a) 工作高度应适合于操作者的身体尺寸及所要完成的工作类型。座位、工作面和/或工作台应设计成能获得所期望的身体姿势，即**身体躯干挺直**……
    - b) ……（视野与可及范围）
    - c) 应为身体的活动，特别是头、手臂、腿和脚的活动提供**足够的空间**。
    - d) 各种操作器应布置在人的**功能可及范围**内。
    - e) 把手和手柄应适合**手的功能解剖学**要求。
  - **② 工作设备设计**：应避免肌肉、关节、韧带以及呼吸和循环系统必要和过度的应变；力的要求应在**生理上所期望的范围内**；身体动作应遵循**自然节奏**；身体姿势、力的使用以及身体的动作应互相协调。
    - 姿势与力的选择：a) 操作者应能**交替采用坐姿和立姿**；如果必须两者择一，则通常**坐姿优先**；b) 如果必须施用较大的肌力，应采取合适的身体姿势并提供适当……
  - **③ 身体姿势与疲劳**：a) 身体不应由于**长时间的静态肌肉紧张**而引起疲劳，应该可以变换身体……；b) 所涉及的肌肉群必须在肌力上能满足力的要求——如果力的要求过大……；c) 应该避免**同一肌肉保持长时间的静态紧张**。
  - **④ 身体动作**：a) 应在身体动作间保持良好的平衡，最好能选择长时间固定不变的动作；b) 动作的幅度、强度、速度和节拍应互相协调；c) **对精度要求较高的动作不应使用很大的肌力**。
  - **⑤ 信号与显示器**：应以适合人的**感受特性**的方式选择、设计……。①信号和显示器的种类和数量应符合信息的特性；②当显示器数量很多时，应以能清晰、迅速地识别信息的方式进行布置；③种类和设计应保证清晰易辨——这一点**对危险信号尤其重要**，应考虑到强度、形状、大小、对比度、显著性和信噪比等各个方面；④信号显示的变化速率和方向应与主信息源变化的速率和方向相一致；⑤在以**观察和监视为主的长时间工作**中，应通过信号和显示器的设计与……
  - **⑥ 控制器**：选择、设计和配置应与人体操作部分的特性（特别是动作）相适应，应考虑技能、准确性、速度和力的要求。①类型、设计和配置应适合于控制的任务；②**行程和操作阻力**应根据控制任务和**生物力学及人体测量数据**确定；③控制动作、设备的应答和显示信息应相互适应和协调；④各种控制器的功能应**易于辨认，避免混淆**；⑤控制器数量很多时，应以能确保**安全、明确、迅速**操作进行配置；⑥**关键的控制器应有防止误动作的保护装置**。
  - **⑦ 工作环境设计**：应保证环境中的物理、化学和生物学条件对人**不产生有害影响**，并保证健康、工作能力和便于工作。①工作场所的大小（总体布置、工作空间和通行有关的工作空间）应……；③应按当地气候条件调节工作场所的**热条件**；④**照明**应为所需活动提供最佳的视觉感受；⑤选择房间和设备颜色时应考虑其对亮度分布的影响；⑥**声学**环境应避免有害或扰人噪声（含外部噪声）；⑦传递给人的**振动和冲击**不应引起肉体损伤及生理/病理反应或感觉不适；⑧应避免工人暴露于**危险物质及有害辐射**环境中。
  - **⑧ 工作过程设计**：特别应避免工人**劳动超载和负载不足**，以保护工人的健康和……。改善方法包括：改变工作（例如在装配线上实行**自愿轮换工种**的方法）等。

## Key Concepts

- **总体设计五指标**：安全、高效、舒适、健康、经济。
- **人机关系随任务切换**：当系统正常时，人不受系统的约束；当系统出现异常时，机器由自动变为手动，人必须直接介入到系统之中——**人机结合从并联变为串联**，要求人迅速而正确地判断和操作。
- **身体躯干挺直**：工作空间设计追求的期望姿势。
- **功能可及范围**：操作器应布置在的范围内。
- **手的功能解剖学要求**：把手与手柄设计依据。
- **自然节奏**：身体动作应遵循的节律。
- **坐姿优先原则**：必须坐立择一时，通常坐姿优先。
- **静态肌肉紧张的时长约束**：不应长时间静态紧张，应可变换身体姿势。
- **精度与肌力的反向关系**：精度要求高的动作不应使用很大的肌力。
- **关键控制器防误动作**：应有保护装置。
- **劳动超载与负载不足**：工作过程设计的两个极端，都要避免。
- **岗位轮换**：改善工作过程的可用方法之一。

## Mental Models

- **Use 五指标清单 when 收尾评审任何系统设计**：安全、高效、舒适、健康、经济逐项核对，缺一即不完整。
- **Treat ISO 6385 as 六组可执行条款**：工作空间、工作设备、身体姿势、身体动作、信号显示、控制器、工作环境、工作过程——可直接当检查表用。
- **Use「坐姿优先」when 必须在坐立之间二选一**。
- **Think of 力的要求 as 生理可行域**：既不能超过（过度应变），也不能长期不变（静态紧张）。
- **Use 精度—肌力反比 when 分配动作**：需要高精度的动作不要要求大肌力。
- **Use 控制器数量规则 when 布置密集面板**：数量多时按"安全、明确、迅速"排序配置，关键控制器加倍防护。
- **Use「并联 → 串联」when 评估系统异常情景**：异常时人机结合由并联变串联，对人的判断与操作速度要求骤增。

## Anti-patterns

- **只优化功能而让身体姿势畸形**：工作空间应能获得躯干挺直等期望姿势。
- **让同一肌肉长期保持静态紧张**：违反 ISO 6385 的姿势与疲劳条款。
- **对高精度动作施加很大肌力**：违反"精度要求高不应使用大肌力"。
- **长时间监视类工作中显示设计不考虑负荷**：应通过信号与显示器设计减轻长时间观察的负担。
- **危险信号的清晰性与其他信号同等对待**：危险信号尤其要保证清晰易辨（强度、形状、大小、对比度、显著性、信噪比）。
- **关键控制器无防误动作保护**：必须设置保护装置。
- **控制器功能易混淆**：功能应易于辨认。
- **让工人长期超载或长期负载不足**：两者都是工作过程设计要避免的极端。
- **在人机关系由并联转串联时未考虑人的能力极限**：异常工况下要求人迅速正确判断与操作，需为此留出余量。

## Worked Example

**用 ISO 6385 定位一次自动化产线改造的人机问题**

1. **工作空间**：检查操作台高度是否匹配操作者身体尺寸与工作类型；是否让躯干挺直；头、手臂、腿、脚是否都有足够活动空间；操作器是否都在功能可及范围内；把手是否符合手的功能解剖学。
2. **工作设备与姿势**：力的要求是否在生理期望范围内；是否避免同一肌肉长时间静态紧张；是否允许变换姿势；若需大肌力，姿势是否合适。
3. **信号与控制器**：显示器数量是否按清晰、迅速识别来布置；危险信号是否在强度、对比度、显著性上突出；控制器行程与阻力是否按生物力学与人体测量数据设定；功能是否易辨认；关键控制器是否有防误动作保护。
4. **工作环境**：热条件、照明、色彩（反射与亮度分布）、声学（含外部噪声）、振动与冲击、危险物质与辐射逐项核查（对照第 9 章数值）。
5. **工作过程**：是否存在劳动超载或负载不足；如需改善，可采用改变工作内容、装配线自愿轮换工种等方式。
6. **异常情景**：模拟系统由自动切手动——此时人机结合由并联变串联，验证人是否来得及迅速正确地判断与操作；若来不及，回到第 3 步调整控制与显示设计。

## Key Takeaways

1. 总体设计的验收标准是五指标：安全、高效、舒适、健康、经济。
2. ISO 6385—1981(E) 把"以人为本"翻译成八组可执行条款，可直接当设计检查表使用。
3. 必须坐立择一时通常**坐姿优先**；力必须落在生理期望范围内且不能长期静态施加。
4. 精度要求高的动作不应要求大肌力；动作的幅度、强度、速度和节拍要协调。
5. 危险信号的清晰性要求高于一般信号（强度、形状、大小、对比度、显著性、信噪比）。
6. 关键控制器必须防误动作；控制器数量多时按"安全、明确、迅速"配置。
7. 人机关系在异常工况下由**并联变为串联**，设计必须为人的判断与操作速度留余量。
