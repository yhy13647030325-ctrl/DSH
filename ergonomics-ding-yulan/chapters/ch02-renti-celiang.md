# 第 2 章：人体测量与数据应用

## Core Idea
人体测量数据是把"以人为中心"落到尺寸上的量化依据；用的关键不是"有没有数据"，而是**先判定产品尺寸设计类型，再选对应百分位数，最后加上修正量**。

## Frameworks Introduced

- **产品尺寸设计分类（GB/T 12985—1991，表 2-8）**：先分类，再选百分位。
  - **Ⅰ型（双限值设计）**：需要**两个**人体尺寸百分位数分别作为尺寸上限值与下限值的依据。
  - **Ⅱ型（单限值设计）**：只需要**一个**百分位数。
    - **ⅡA 型（大尺寸设计）**：该百分位数作尺寸**上限值**依据。
    - **ⅡB 型（小尺寸设计）**：该百分位数作尺寸**下限值**依据。
  - **Ⅲ型（平均尺寸设计）**：只需要 **P50** 作为依据。
  - When to use：任何涉及人体尺寸的产品设计，第一步就应确认属于哪一类型。

- **百分位数选择模型（表 2-9）**：类型 × 产品重要程度 → 百分位 + 满足度。
  | 产品类型 | 重要程度 | 百分位选择 | 满足度 |
  |---|---|---|---|
  | Ⅰ型 | 涉及人的健康、安全 | **P99 和 P1** 作上、下限 | 98% |
  | Ⅰ型 | 一般工业产品 | **P95 和 P5** 作上、下限 | 90% |
  | ⅡA 型 | 涉及人的健康、安全 | **P99 和 P95** 作上限 | 99% 或 95% |
  | ⅡA 型 | 一般工业产品 | **P90** 作上限 | 90% |
  | ⅡB 型 | 涉及人的健康、安全 | **P1 和 P5** 作下限 | 99% 或 95% |
  | ⅡB 型 | 一般工业产品 | **P10** 作下限 | 90% |
  | Ⅲ型 | 一般工业产品 | **P50** | 通用 |
  | 成年男女通用产品 | 一般工业产品 | 男 P99/P95/P90 作**上限**；女 P1/P5/P10 作**下限** | 通用 |
  - **满足度**：所设计产品在尺寸上能满足多少人使用，以合适使用人数占使用者群体的百分比表示。满足度指标可另行确定——满足所有人技术上可行，但经济上往往不合理。

- **产品功能尺寸设定公式**：
  - **最小功能尺寸 = 人体尺寸百分位数 + 功能修正量**
  - **最佳功能尺寸 = 人体尺寸百分位数 + 功能修正量 + 心理修正量**
  - 功能修正量：补偿着装、姿势等实际差异（表 2-10）。
  - 心理修正量：为克服"空间压抑感""高度恐惧感"或满足"求美""求奇"而附加的增量，用被试主观评价表评分统计求得。

- **人体测量术语体系（GB 3975—1983）**：只有被测者姿势、测量基准面、测量方向、测点符合规定，测量数据才有效。
  - 姿势：**立姿**（挺胸直立、头部以眼耳平面定位、两足约呈 45° 夹角、体重均匀分布于两足）；**坐姿**（坐在调节到腓骨头高度的平面上、膝弯曲大致成直角、足平放地面）。
  - 基准面：矢状面、正中矢状面、冠状面、横断面、**眼耳平面（法兰克福平面）**。
  - 方向：头侧端／足侧端、内侧／外侧、近位／远位、桡侧／尺侧、胫侧／腓侧。

- **由身高推算各部分尺寸**：以站立平均身高为基数按正常人体结构比例关系推算；身高随生活水平提高而增长，用身高为基数能自动适应这种变化。

## Key Concepts

- **人体构造尺寸（静态尺寸）**：人体构造上的尺寸。
- **人体功能尺寸（动态尺寸）**：人在工作姿势下或某种操作活动状态下测量的尺寸。
- **百分位数 Pn**：表示大于和小于此人体尺寸的人各占一定比例；P50 代表"中"身材，P95 表示 95% 的人小于此值。
- **人体测高仪**：读数 1 mm，测量范围 0~1996 mm；加弯尺可组成圆杆弯脚规测宽度厚度。
- **人体测量用直脚规**：读数 1 mm 与 0.1 mm，范围 0~200 mm 与 0~250 mm；分Ⅰ型（无游标，又分ⅠA/ⅠB）与Ⅱ型（有游标）。
- **人体测量用弯脚规**：读数 1 mm，范围 0~300 mm；测肩宽、胸厚等不能直尺直接测量的两点距离。
- **主要数据标准**：GB 10000—1988《中国成年人人体尺寸》（七类共 47 项基础数据，男 18~60 岁、女 18~55 岁，按性别分列，分 7 个百分位）；GB/T 5703—2010《用于技术设计的人体测量基础项目》（81 个测量项目，统一测量方法）；GB/T 13547—1992（功能尺寸）；GB/T 5704—2008《人体测量仪器》。
- **GB 3975—1983 测点规模**：头部 16 个测点／12 项；躯干四肢 22 个测点／69 项（立姿 40、坐姿 22、手和足 6、体重 1）。

## Mental Models

- **Use 表 2-9 的"类型 × 安全等级"二维定位 when 选定百分位**：先问"这是单限值还是双限值？限制的是上限还是下限？"，再问"它涉及健康安全吗？"——两个答案直接给出百分位。
- **Think of 大尺寸设计 as 留余量、小尺寸设计 as 保可达**：ⅡA 型（上限）取高百分位（P90/P95/P99）保证高个子不被"卡住"；ⅡB 型（下限）取低百分位（P1/P5/P10）保证小个子能够到。
- **Treat 修正量 as 必加项，不是可选项**：着装、姿势、心理三类修正决定了图纸尺寸与真实使用体验的差距。
- **Use 身高 as 比例基准 when 无法逐一测量**：把设计对象归为典型类型，建立其高度与身高的比例关系查用。
- **活动空间用 P95 身高（1775 mm）作基准**：因为活动空间应尽可能适应绝大多数人，设计时以**高百分位**人体尺寸为依据。

## Anti-patterns

- **拿单个体尺寸当设计依据**：群体中个体差异存在，某一个体的测量尺寸不能作为设计依据。
- **把统计数据当设计常识、以数据代替设计分析**：只有熟悉数据测量定义、适用条件、百分位选择，才能正确应用；使用不当可能导致严重设计错误。
- **忽略着装修正量**：人体尺寸多为裸体或仅穿内衣测量（GB 3975 要求），直接套用会让实际使用尺寸偏小。
- **盲目追求 100% 满足度**：技术可行但经济不合理；满足度应按使用者差异与产品性质确定。
- **用 P50 通吃所有尺寸**：Ⅲ型平均尺寸设计只适用于一般工业产品中的特定情形，不是通例。
- **操作部位高度不匹配人体尺度**：过低或过高都会迫使操作者弯腰或抬臂，导致效率下降、过早疲劳、长期损害健康。

## Worked Example

**判定一个尺寸该用哪个百分位（走一遍表 2-9）**

设要设计三样东西：(a) 一扇通行门的高度；(b) 一个需双手操作的手柄抓握间距；(c) 一张通用办公椅的坐面高度。

1. **归类型**：
   - (a) 门高：需保证人**不撞头**——只受"上限"约束 → **ⅡA 型（大尺寸设计）**。
   - (b) 抓握间距：需保证人手**够得着**——只受"下限"约束 → **ⅡB 型（小尺寸设计）**。
   - (c) 通用椅坐面高：既怕高个子坐姿不适、又怕小个子脚不落地，需同时定上、下限 → **Ⅰ型（双限值设计）**。
2. **定等级并查表 2-9**：
   - (a) 门撞头**涉及人的健康、安全** → ⅡA 型安全类 → 取 **P99（或 P95）作上限**，满足度 99%／95%。实际设计时还需考虑"身高一般不穿鞋测量"这一注意事项与建筑规范，并加鞋高修正。
   - (b) 若为一般工业产品 → ⅡB 型一般类 → 取 **P10 作下限**，满足度 90%。
   - (c) 若为一般工业产品 → Ⅰ型一般类 → 取 **P95 与 P5**，满足度 90%；若追求可调，则做**可调性设计**覆盖 P5~P95 甚至更大范围。
3. **加修正量**：
   - 最小功能尺寸 = 人体尺寸百分位数 + 功能修正量
   - 最佳功能尺寸 = 人体尺寸百分位数 + 功能修正量 + 心理修正量
   - 例如站姿相关高度要加鞋高 25~38 mm、站姿眼高加 36 mm；肩宽加 13 mm、胸厚加 18 mm、腹厚加 23 mm 等。

## Key Takeaways

1. **先分类、后选值**：Ⅰ型（双限值）／ⅡA（大尺寸上限）／ⅡB（小尺寸下限）／Ⅲ（P50 平均）——类型错了，百分位再精确也是错的。
2. **安全等级决定百分位**：涉及健康安全用 P99／P1（满足度 98%~99%）；一般工业产品用 P95／P5（90%）或 P90／P10。
3. **大尺寸上限用高百分位，小尺寸下限用低百分位**——这是最容易记反的一步。
4. **功能尺寸 = 百分位数 + 功能修正量（+ 心理修正量）**；GB 3975 的数据是裸体或仅内衣状态下测得的，不加修正直接用会偏小。
5. **设计基准要说明**：本书活动空间尺度分析统一以我国成年男子 **P95 身高 1775 mm** 为基准。
6. **数据使用有门槛**：必须熟悉测量定义、适用条件、百分位选择，否则"数据正确、设计错误"。
7. **能测就测，不能测就按比例推**：以身高为基数按人体结构比例推算其他尺寸，可随身高增长自动适应。
