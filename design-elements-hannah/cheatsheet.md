# 速查表（Cheatsheet）

## 决策规则

| 情形 | 决定 |
|---|---|
| 开始任何三维造型 | 先用**三个直棱体**做抽象关系练习，不从产品形态入手 |
| 选体块 | 特征尽可能不同，**不能有两个相同大小的体块** |
| 判断体量 | 用**眼睛**评估，不要测量 |
| 组合多体块 | 先定**主导形体** → 加**次要形体**（使主导特征提升 **20%**）→ 加**附属形体**（增对比、补缺失，**不是加细节**） |
| 想让形体关系更强 | 让主导与次要形体的**轴线不平行** |
| 比例失控 | 分别检查**固有/相对/整体**三种比例；眯眼看整体轮廓 |
| 造型平淡 | 让一些形体在**水平**方向夸张，另一些在**垂直**方向夸张 |
| 形体在空间中位置不明 | 找穿过**最长维中心**、表达**最强动感**的轴线 |
| 想要立体感更强 | 引入**轴线的运动**（基础阶段则保持轴线相互垂直以求"不平淡"） |
| 决定形体怎样结合 | 用**相贯 / 楔入 / 支撑**，并让结合部位体现结构感 |
| 认为造型做完了 | 从**所有面、平视、顶部**检查；不允许有一个视角乏味 |
| 判断是否达到统一 | 检查是否"**任何细小的改变都会扰乱这种平衡和张力**" |
| 需要原创构思 | 用**主题联想**（电流、音乐、城市……）抓其暗含动感，再**抽象化** |
| 空间关系不够 | 在面与体之间建立**最大张力**，暗示凹体比例、建立主调 |
| 空间平面排布 | 平面相互弥补、沿 xyz 三轴运动、**悬挂不接触**、**第一大平面定调**、**忌对称分割**、两大平面分开 |
| 空间研究要不要做对照 | **做**：同尺寸两件，一件加工（设计模型），一件留原状（控制模型） |
| 判断空间改进程度 | 设计模型的**凹空间应看起来比控制模型更大** |
| 造型好不好说不清 | 试模型的"**温度**"（热/冷），与控制模型对照；允许局部温度不同 |
| 形体要不要表达功能 | 可以：凹面说明工具用途、体块姿态表现力量、扭曲平面联系声音 |
| 设计项目卡住 | 回到**主导关系、次要关系、从属关系**重新检查——"这是设计的要领所在" |
| 判断一致性 | **拿走一个部件，看作品是否解体** |
| 引入功能/工效/材料要求 | 应用它们，但**不让它们支配整个创造过程**（停留在"中间阶段"） |
| 形体该从哪来 | 从**材料与制造工艺的可能性**中得出（如塑模成型 vs 剪切焊接） |
| 能否跨品类迁移 | 能：产品、包装、家具、灯具、汽车、珠宝、室内、展览、雕塑同一套语言 |

## 决策树

```
组合多个形体时，关系做不出来，问题出在哪？
├─ 体块本身有问题
│   └─ 是否两个体块大小相同？→ 换成特征差异更大的体块
├─ 层次不清
│   ├─ 主导形体是否最大、最生动、位置显著？ → 调整
│   ├─ 次要形体加入后主导特征是否提升 20%？ → 否则继续实验
│   └─ 附属形体是否被孤立 / 被当成加细节？ → 改为"增加对比、弥补缺失"
├─ 比例单调
│   └─ 是否只做了整体水平比例？ → 让部分形体垂直夸张
└─ 动感不足
    ├─ 轴线是否都互相平行？ → 让主导/次要轴线不平行
    └─ 是否只用稳定轴线？ → 引入轴线运动（高级阶段）

空间研究做不出效果？
├─ 注意力是否被平面造型吸引走了？ → 回到"平面对凹体块的冲击"
├─ 平面是否彼此接触/相贯？ → 改为悬挂
├─ 是否把模型对称分割了？ → 取消对称
└─ 两个最大平面是否挨着？ → 分开它们，张力在"之间"而非"本身"
```

## 阈值与默认值

| 项 | 值／判据 |
|---|---|
| 基础课题形体数 | **3 个直棱体** |
| 次要形体的及格线 | 主导形体特征提升 **20%** |
| 草模放大倍数 | **1.5 倍或 2 倍** |
| 三种比例 | 固有 / 相对 / 整体 |
| 连结方法数 | 3（相贯、楔入、支撑） |
| 空间研究对照件 | **2 件同尺寸**（设计模型 + 控制模型） |
| 空间平面经验规则 | 10 条 |
| 第一种大空间关系的运动数 | **2~3 个** |
| 三类平面 | 静态平面、动态平面、曲面 |
| 三维轴 | x、y、z |
| 专业门类跨度 | 产品、包装、家具、灯具、汽车、珠宝、室内、展览、雕塑 |
| 石膏 | 高强度石膏水泥（比标准石膏更结实） |
| 判断"做完了"的视角数 | 所有面 + 平视 + 顶部 |

## 识别信号

- 两个体块**大小相同** → 对比不足，层次无从建立。
- 加了次要形体但主导形体**没变化** → 关系没建立起来，继续实验。
- 附属形体在做**细节装饰** → 用错职能了。
- 主导形体**固定在底部** → 学生的惯性做法，未必是最合适位置。
- **附属形体被孤立** → 常见错误，检查它与前两者的关系。
- 只做得**到整体水平比例**（"看起来更稳定"）→ 回避了垂直方向的对比。
- 造型只有**一个视角好** → 未通过多视角检验。
- 空间研究只关注**平面本身** → 偏离课题，应关注平面对凹体块的作用。
- 模型被**对称分割** → 体积感被限定，空间无法扩展。
- 反复强调"把凹体块做成最吸引人的形体很困难"→ 这正是难点的标志，坚持训练。
- 设计项目**停滞** → 立即回到主导/次要/从属关系检查。
- 拿走一个部件作品就**解体** → 一致性合格（反之不合格）。
- 功能/材料要求开始**接管全部决策** → 已越过"中间阶段"，创造过程失去主角。
