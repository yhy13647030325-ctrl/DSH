# 第 2 章（Ⅱ）：基础知识

## Core Idea
三维设计的基础不是造型技巧，而是**在简单形体上把"关系"做对**：用主导—次要—附属形体建立层次，用三种比例制造对比，用轴线定位动感，最终达到"任何细小改变都会扰乱这种完美平衡"的**统一性**。

## Frameworks Introduced

- **主导形体 / 次要形体 / 附属形体**（本章最核心的关系框架）：
  - **主导形体**：元素中**最大的一个**，最有趣的、最生动的，在各组成部分中**占主导位置**。
  - **次要形体**：在特征方面对主导形体进行**补充**。
    - 硬指标：**添加上次要形体后，如果主导形体的特征不能提高 20%，就需要进行更多的实验。**
    - 加强手法：主导与次要形体的关系"不仅仅是因为特征方面的对比，还因为位置的关系"；通常**如果它们的轴线不平行，这种关系就会被加强**。
    - 作者原话："主导形体与次要形体是一个很重要的关系。这些形体的首要作用是进行相互补充。它们必须是互利的——就像母鸡和鸡蛋一样。"
  - **附属形体**：引进**第三个可见元素和轴线**，使设计变得更有趣、更具三维感，弥补已存在的各个形体，**将实现设计的统一性**。
    - 与主体的区别：它"并不像主导形体和次要形体那样独立"。
    - 关键限定：它应当**增加对其他形体的对比感，而不是添加细节去增加精致感**；其设计思想是"弥补另外两个形体所缺少的部分"。
  - When to use：任何多体块组合的造型评审，先确定三者身份是否清晰。

- **三种比例**（必须同时管控的三层比例）：
  - **固有比例**：**一个形体内在**的各种比例——长、宽、高的比例。
  - **相对比例**：**一个形体与另一形体之间**的比例。（"想像一下，一个高瘦的人与一个矮胖的人的比较。"）
  - **整体比例**：**组合形体的特征或整体轮廓**的比例。（"如果你眯着眼看一个组合形体的外轮廓的各种比例，你看到它的则是整体比例。"）
  - 硬约束：**在特征方面，不允许有一个视角看起来是很乏味的。**
  - 常见错误：大多数学生做了整体的水平比例，"可能是因为它看起来更稳定，而从没有强调出立方体来"；正确做法是"从水平方面夸大一些形体，从垂直方面夸大另外一些形体"。

- **轴线（axis）**：一条**想像中的线**，它穿过形体**最长的那一维方向的中心**，显示了形体的**最强的动感（运动趋势）**。这个轴线确定了形体在空间中的位置。
  - 基础阶段：**保持形体的轴线稳定（相互垂直）**——"稳定的轴线是最简单的，会帮助你摆脱平淡的构成"。
  - 高级阶段：**尝试实现轴线的种种运动**；"如果要让你的设计更加具有立体感，你应该尽可能地使用大量的轴线的运动"。
  - 方法论提示：要"仔细定位各形体的轴线"；她反复强调轴线之间的抽象联系是控制设计的关键。

- **三种连结形体的方法**：**相贯、楔入、支撑**。
  - When to use：决定了形体之间是穿插、嵌入还是托举，直接影响结构感与立体感。

- **统一性（unity）**：意味着**视觉凝聚力**，"它把所有的东西联结在一起"。
  - 判据：设计中所有的视觉关系被组织成为一个**细腻的依赖关系**，所有元素**相互支持、相互加强**，**任何细小的改变都会扰乱这种完美的平衡和张力**——"这样，你就明白自己已经实现了统一性。"

## Key Concepts

- **制作三维草模（草模法）**：在基础系列和更高级的练习中，**所有的体验都始于三维草模的制作**。
  - 材料按具体问题选：黏土、纸、卡纸、优质纸板、电线、胶水……**然后快速制作**。
  - 目标：制作尽量多的**抽象关系**草模——"这些抽象关系表现了**局部与整体**的关系，而不是反映细节，更不是表现材料"。
  - 材料技巧：黏土制作的形体边缘应当尽可能清晰；黏土很容易补上一块或减去一块。
  - 态度：**不要让你的草模受到束缚**，然后"再给它们套上马鞍"。
- **体量判断**："学会用眼睛去评估一个设计元素的体量，而不是凭借测量。"
- **对比形状的特性**："你选择的直棱体在特征上要有尽可能多的变化，**不能有两个相同大小的体块**。"
- **连接方式**：相贯、楔入、支撑。
- **从所有方位构想**："通过在坚固的旋盘上工作，然后不停地转动草模，从而保证你能从各个角度观察。"
- **放大草模**：挑选最好的草模用石膏深化，**可能放大 1.5 倍或 2 倍**——"设计草模被扩大后，比例上的不同会变得更加明显"；**扩大并不是简单的拷贝**，需要你注意那些微妙的变化使之达到整体和谐。
- **石膏**："务必要使用高强度石膏水泥。这种混合物更结实，而且最终效果要比标准的石膏更好一些。"
- **精确性**："优美形体和普通形体之间的区别在于它们**比例的精确性**。精确性是一种无法触摸但又非常真实的特性。对于这种特性的领会是视觉艺术家的最具价值的财富之一。"

## Mental Models

- **Use「主导→次要→附属」when 组合任何多体块形态**：先立最大的、最生动的主导形体，再用次要形体补充它（提升 20% 才算够），最后用附属形体补缺并建立三维感。
- **Use「20% 提升」作为次要形体的及格线**：达不到就继续做实验，而不是凑合。
- **Think of 轴线 as 形体的"运动趋势"**：轴线不是几何中线，它表达动感；轴线不平行会加强主导—次要关系，轴线运动会增强立体感。
- **Use 眯眼看外轮廓 when 判断整体比例**。
- **Use「不许有一个视角乏味」when 验收体块组合**：造型必须在所有视角都成立。
- **Think of 统一性 as 精密到"任何细小改变都会打破它"**：达到这个敏感度才算成功。

## Anti-patterns

- **两个体块大小相同**：直接违反了对比形状特性的要求。
- **用测量代替眼睛判断体量**。
- **次要形体加完了而主导形体特征没有提升**：说明实验不够，关系没建立起来。
- **用附属形体增加细节以求精致**：附属形体的职能是**增加对比感、弥补缺失**，不是堆细节。
- **把主导形体一律放在底部**："学生喜欢把主导形体放在底部，这样主导形体看起来把其他物体抬高了，但这并不一定是主导形体最适合的位置。"
- **把附属形体孤立起来**：常见错误之一。
- **重复使用相同尺寸的形体**："有时学生有重复使用相同尺寸的趋势。"
- **只做整体水平比例**：因为"看起来更稳定"而回避垂直方向的对比，导致形体没有个性。
- **放大草模时简单拷贝**：放大不是拷贝，必须重新调和微妙变化。

## Worked Example

**"三个直棱体"课题的完整操作流程与自检**

**任务**：用三个直棱体黏土块组合成一个统一的整体，无参考图、不看成品样例。

**步骤**：
1. **选形体**：三个长方体在**特征上要有尽可能多的变化**，不允许有两个相同大小。用眼睛评估体量而非测量。
2. **定层次**：选出**主导形体**（最大、最生动）；再添**次要形体**补充它；添加后自问——主导形体的特征**是否提高了 20%**？否则继续实验。
3. **加附属形体**：引入第三个元素与轴线，使其弥补前两者所缺，**增加对比感**（而不是增加细节）。
4. **控比例**：同时检查三层比例——每个形体自身的长宽高（**固有比例**）、形体之间（**相对比例**）、整体外轮廓（眯眼看，**整体比例**）；刻意让一些形体在水平方向夸张、另一些在垂直方向夸张。
5. **定位轴线**：为每个形体找出穿过最长维中心、表达**最强动感**的轴线；基础阶段保持轴线**相互垂直**，以摆脱平淡构成。
6. **选连结方式**：在**相贯、楔入、支撑**中选定。
7. **多视角检验**：在旋盘上不停转动草模，从所有面、平视以及顶部观察。

**作者给出的自检问题清单**：
- 主导形体和次要形体之间**有没有对比**？
- 它们是不是互补的？在大小和形状上是不是**太相似**？
- 主导形体是否在**显著的位置**？
- 是否**把附属形体孤立起来**了？
- 从所有的面、从平视以及从顶部去看，设计是不是**都很好**？

**总结要点**（作者原话）：从设计主导形体开始，然后是次要形体，在它们的关系处理上花一点时间；先快速完成附属要素，使体块群组更有立体感，获得整体构成感；再开始细化设计；**每个草模里，要么突出垂直比例，要么突出水平比例**；所有结合部位都要体现一定的结构性；**各个方向力的平衡应当被建立起来**；从任何位置看都应当既有趣又有立体感。

## Key Takeaways

1. 三个直棱体课题包含四年设计训练的全部元素，是"简单载体 + 完整结构"的教学典范。
2. 主导形体=最大最生动；次要形体=补充主导（**须使其特征提升 20%**）；附属形体=补缺、增对比、建立三维感与统一性。
3. 三类比例必须同时管控：**固有比例 / 相对比例 / 整体比例**；不允许任何一个视角乏味。
4. **轴线**表达形体的最强动感；基础阶段保持垂直稳定，高级阶段追求轴线运动。
5. 形体连结三法：**相贯、楔入、支撑**。
6. **统一性**的判据是"任何细小的改变都会扰乱这种完美的平衡和张力"。
7. 一切体验都始于**快速制作的三维草模**；草模表现局部与整体关系，不表现细节与材料。
8. 优美与普通的区别在于**比例的精确性**——这是视觉艺术家最有价值的财富之一。
