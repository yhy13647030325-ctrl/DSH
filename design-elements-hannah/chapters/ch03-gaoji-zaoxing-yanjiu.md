# 第 3 章（Ⅲ）：高级造型研究

## Core Idea
从"三个直棱体"扩展到**多元素构成**：用抽象主题驱动构思，让线、面、体在空间中形成**方向力与张力的平衡**，并建立元素的统一性。

## Frameworks Introduced

- **构成（composition）作为抽象体验的基础**：
  - 定义："抽象体验是以构成为基础的，包括一些**对比形体的设计与组织**，一些用来创建**各种相关运动的群组形体**的新体验，还有对空间中一些**方向力和张力的平衡**更深一步的理解。"
  - 三个构成要素：①对比形体的设计与组织 ②相关运动的群组形体 ③方向力与张力的平衡。
  - When to use：当简单形体关系已经掌握，需要在多元素、多材料的条件下组织设计时。

- **抽象构思的触发法（联想→抽象→提炼）**：
  - 联想对象清单：**电流、交流、化学、结构化的设备、旅行（陆地的、水上的、空中的）、音乐、马戏、竞技表演、舞蹈、爵士乐、原子能、剧院、城市**。
  - 三步操作：①在大张纸上随意画二维草图，让构思流露出来；②联想对象本身与它所**暗含的动感**（如飞机上升和下降）；③**进一步抽象化**——"假如你联想到一架直升飞机，你可以在一个平面上制作一系列的螺旋线。提炼出它的抽象特性再进行探索研究。"
  - 产物："这些通过草模发现的构思应该是**对一个设计主题的情感反应和视觉反应**，这些是通过形体和运动来表现的。"

- **构成设计的工作序列**（六步）：
  1. **选材料**：金属、塑料、玻璃（不透明或透明）、金属线、细绳、荆条、金属片、木头、石头、熟石膏、玻璃纤维、纤维板及其他合成材料；**各种线、面和体元素可以被组合起来**。
  2. **二维草图**：在大张纸上随意画，使构思流露出来。
  3. **三维草模**：用硬纸板、金属线、黏土**快速**制作——"灵感在这里十分重要，要捕捉住它"。
  4. **探索最好的整体比例**：对三维草模做比例研究，为整体设计找到最好的比例。
  5. **制作空间草模**：在面与体之间（或每组面与每组体之间）建立**最大的张力**。
     - "这种张力关系强烈暗示着**凹体的各个比例**，并从每个位置建立**各个方向力的平衡**。它建立了**主调**，从而使各部分统一起来。"
  6. **处理材料**：按**体、面、线**的顺序组织，把各种材料元素"以一个比较舒服的关系组合在一起"。
     - 两个主要目的：**保持你构思的精神**；**学习如何将各种材料协调统一地结合在一起**。

- **元素层次在本章的表述**：确定出**主导元素、次要元素和从属元素**。
  - **主导元素**：在线条和比例上都应该很优美，应该具备**有趣的个性**，在**关键的位置**，应该表现出三维草模所要求的**动感**（即帮助构成表达出它的含义）。
  - **次要元素**：在线条和比例上也应该优美，并且应对主导元素起到**补充作用**。
  - 操作顺序：**在主导元素和次要元素之间建立第一种大空间关系**——"这是由两到三个令人兴奋的运动所组成的，这些运动表达了整体设计思想，并且暗示了凹体"。
  - 硬提醒：**要保证将平面放于二维内；不要将它们排成一条直线**——"空间关系是由一些运动动感构成的"。

## Key Concepts

- **结构（structure）**："结构是由各种材料的元素组成，这些材料可以用熔制、弯曲或用一些方法加工成型，然后组合在一起。"
  - 态度（引学生语）："一个设计不仅仅应该具有一定结构，还应该表现出其结构。你不得不识别结构，就像识别一个热炉子一样。"
- **精工制作阶段**：制作各个**体、面、线**，加强各元素间各种**空间关系和张力**。
  - 检查清单："检查你设计中所有的线条，包括那些由面形成的线。思考一下它们在空间和位置上是如何与其他元素相联系的。"
  - 表面过渡："各个表面之间的联系，即从**一个表面到另一个表面的过渡**是非常重要的。"
  - 目的："在制作一些表面时，你是在学习**如何使视线穿越形体和空间而运动**。"
- **建立统一性**："建立各个设计元素的统一性和各个力的统一性。对于各个元素的连接要特别敏锐。"
  - 两个层次：**各个元素间的视觉关系**；以及（元素连接本身的）结构关系。
- **抽象感觉的培养**：用联想的视觉感受来训练——"利用它们来培养自己的抽象感觉"。
- **比例上的探索**：为整体设计找到最好的比例，而不是沿用第一个想到的方案。

## Mental Models

- **Use「联想 → 动感 → 抽象化 → 草模」when 需要原创构思**：先借一个不相干的主题启动画面感，抓住它暗含的运动，再抽掉具体形象，留下纯粹的关系。
- **Think of 空间草模 as 主调的建立器**：它先定下"面与体之间的最大张力"，后面所有细节都要服从这个主调。
- **Use 体→面→线 作为材料组织的固定顺序**：先立体的体块，再组织面，最后处理线。
- **Treat「两到三个令人兴奋的运动」as 空间关系的最小完整表达**：少于这个数关系不成型，多于则散。
- **Use「表面过渡」when 检查视线动线**：看观看者的**视线能否穿越形体和空间而运动**。
- **Remember 两个目的 when 处理材料**：保持构思精神 + 材料协调统一。

## Anti-patterns

- **把平面排成一条直线**：直接破坏空间关系——"空间关系是由一些运动动感构成的"。
- **在构成中堆砌材料以求丰富**：材料组织存在固定顺序（体→面→线），乱序会失掉结构。
- **构思停在具体形象上不抽象化**：只画了飞机与螺旋桨，没有提炼出"螺旋线"这类抽象特性，就无法进入设计。
- **忽略表面之间的过渡**：过渡是"非常重要"的一环，视线动线正是靠它建立。
- **只做结构却不表现结构**：设计"不仅仅应该具有一定结构，还应该表现出其结构"。
- **让从属元素取得与主导元素同等的独立性**（第 2 章的同一原则在本章的延伸）。

## Worked Example

**从"航空运输"到一件抽象构成：完整走一遍构思链**

1. **选主题**：联想"旅行（陆地的、水上的、空中的）"中的**航空运输**。
2. **抓动感**：不只是看到飞机这个对象，还要抓住它**暗含的动感**——"飞机上升和下降"。
3. **抽象化**：改用直升机作为联想起点，**在一个平面上制作一系列的螺旋线**，提炼其抽象特性再探索。
4. **画二维草图**：在大张纸上"随意地画"，让构思流露出来（此阶段不做判断）。
5. **快速做三维草模**：用硬纸板、金属线、黏土快速成型；**捕捉灵感**，并让它在后续练习中继续发展。
6. **找整体比例**：对草模做比例研究，为整体设计确定最好的比例。
7. **做空间草模**：在面与体之间建立**最大张力**，暗示凹体比例，建立各方向力的平衡——**确立主调**。
8. **定元素层次**：确定主导元素（线条与比例优美、个性有趣、在关键位置表现出草模要求的动感）、次要元素（同样优美、补充主导）、从属元素。
9. **建第一种大空间关系**：在主导与次要元素之间用**两到三个令人兴奋的运动**表达整体设计思想，并暗示凹体；**平面保持在二维内，不排成直线**。
10. **处理材料与精工**：按体→面→线组织，检查所有线条（含由面形成的线）的空间与位置联系，重点处理**表面之间的过渡**。
11. **收口**：建立各元素与各力的统一性，特别敏锐地处理元素间的连接。

**关键判据**：整个过程中要反复自问"这是对主题的**情感反应和视觉反应**吗"——如果只是形状拼合而唤不起感受，就还没有完成抽象。

## Key Takeaways

1. 构成 = 对比形体的设计与组织 + 相关运动的群组形体 + 方向力与张力的平衡。
2. 抽象构思靠"联想 → 抓动感 → 抽象化 → 草模"这条链，而非凭空等灵感。
3. 工作序列固定：材料 → 二维草图 → 三维草模 → 整体比例 → 空间草模（最大张力/主调）→ 材料组织（体→面→线）。
4. 元素分**主导、次要、从属**；主导需在线条、比例、个性、关键位置的动感上全面达标。
5. 主导与次要之间要建立**第一种大空间关系**，由**两到三个令人兴奋的运动**构成。
6. **平面不要排成直线**；空间关系由运动动感构成。
7. 材料的处理有两个目的：保持构思精神、实现材料协调统一。
8. 统一性分两个层次：元素间的视觉关系 + 元素连接的结构关系。
