# 19 个设计技能：使用指南

> **这份文件回答一个问题：手上有个设计问题，该按什么顺序、查哪个技能、看哪一节、拿到什么产出。**
>
> 制定日期：2026-11-17｜适用：`design-router` 管辖的 19 个矩阵内技能
> 配套：`SKILL.md`（路由表本体）· `references/REPORT-5-ACTIONS.md`（能力边界与接口实证）

## 零、先记住这一条

**任何设计问题，先经 `design-router`，不要自己判断该查哪本。**

不是流程洁癖——19 个技能里有 **4 组"看起来该查 A、其实该查 B"** 的陷阱，凭直觉必错其中至少一组：

| 你的直觉 | 实际该查 | 为什么 |
|---|---|---|
| **选材 → SW 三本**（"材料"在 SW 里出现 278 次） | **`cmf-system`** | SW 那 278 次是"软件里怎么设材料属性"，不是"这个产品该用什么材料" |
| **作业环境 → 注塑**（482 次） | **`ergonomics-ding-yulan`** | 注塑讲车间温湿度对成型的影响；照明/噪声/振动在人机（237 次） |
| **轮廓 → 造型**（369 : 360，只差 9 次） | **看你要什么** | 建模里怎么定轮廓→`solidworks-surface-advanced`；审美上轮廓怎么读→`product-design-styling-dabbs` |
| **用户研究 → 诺曼**（21 次） | **`user-research-methods`** | 诺曼只有一节方法清单，没有样本量、筛选问卷、编码流程 |

## 一、三条主路

| 路 | 你要什么 | 特征 |
|---|---|---|
| **路 A** | **一个结论**（"这个设计对不对"） | 跨三层，顺序不能倒 |
| **路 B** | **一个产品**（从 0 到能造） | 沿链路推进，每环有交付物 |
| **路 C** | **一个证据**（别拿讨论代替测试） | 三个技能接力，缺一环结论不成立 |

## 二、路 A：要一个结论 —— 走三层

### 结构

```
原理层（为什么错）→ 方法层（应该多少）→ 工具层（怎么改）
```

### A-1 原理层：错在哪一类

| 你觉得 | 看谁 | 具体节 | 产出 |
|---|---|---|---|
| 用起来别扭、会按错 | `design-psychology-norman` | ch01（日常品的设计问题）、ch02（日常操作心理学）、**ch04（知道要做什么）**、ch05（失误与错误） | **失误类型判定**（六类失误中的哪一类）+ 七原则中违反了哪一条 |
| 形态不好看、组织不起来 | `design-elements-hannah` | ch02（基础知识）、ch03（高级造型研究）、ch04（空间研究） | **形体关系诊断**（主导/次要/附属哪个错位、三种比例哪个失配） |
| 看着别扭但说不清 | `visual-dynamics-industrial-design` | **ch01（发现视觉动力：F 假设与基准线对比）、ch02（什么是视觉动力：倒叙分析）**、ch03（图形受力与形变）、ch04（施力者与受力者） | **力感失衡的具体位置**（不是"不够协调"） |
| 说不清是什么风格/年代 | `world-modern-design-history` | ch01（现代设计概述）、各运动章 | 风格定位与年代锚点 |

> **★ 原理层的产出必须是一句可检验的判断**，例如：
> "用户在'执行阶段'就失败了，因为控制件与它在真实世界里控制的东西之间**没有可感知的匹配关系**（诺曼：匹配原则）"。
> 说"用户不会用"没有进入原理层。

### A-2 方法层：应该多少

| 你要的 | 看谁 | 具体节 | 产出 |
|---|---|---|---|
| 尺寸/百分位/作业空间 | `ergonomics-ding-yulan` | ch02（人体测量与百分位）、**ch08 §8.3b（表 8-1~8-8 全部数值 + 近身作业空间）** | 具体毫米数 + 覆盖到 P5 还是 P95 |
| 造型该往哪个方向 | `product-design-styling-dabbs` | ch01（视觉主题）、ch02（轮廓）、ch03（比例）、ch07（体积）、ch08（表面） | 造型方向 + 比例配置 |
| 用户会不会真的这么用 | `user-research-methods` | ch01 §1.2（方法谱系）、ch06 §6.5（样本量） | 研究设计（该找谁、几个） |
| 材料/工艺怎么定 | `cmf-system` | ch04 §4.4（选材四步）、ch06（15 种工艺量化表） | 材料牌号 + 七行表面规格 |
| 排除了多少人 | `inclusive-accessibility-design` | ch04 §4.2（四步评估）、§4.4（排除率） | 排除率百分比 |
| 这条要求是 A 还是 AA | `accessibility-standards` | ch01（WCAG 2.1 新增 17 条）、ch02（2.2 新增 9 条） | 条目号 + 级别 + 阈值 |

### A-3 工具层：怎么改成那样

| 场景 | 看谁 | 具体节 | 产出 |
|---|---|---|---|
| 改实体特征（圆角/壁厚/拔模） | `solidworks-practice` | 特征选型章、装配章 | 可执行的建模步骤 |
| 改曲面接顺 | `solidworks-surface-advanced` | 连续性判据章、剪裁缝合章 | 曲面修补方案 |
| 钣金/焊件 | `solidworks-2025-mechanical` | 钣金章、焊件章 | 折弯系数/K 因子/构件剪裁 |
| 硬表面细节 | `blender-hard-surface` | ch01（四步建模工作流）、各项目章 | 分件与细节方案 |
| 查某个修改器/节点的每个选项 | `blender-manual-reference` | 对应功能章 | 参数含义 |

### A-4 三层怎么衔接（这一步决定结论能不能用）

| 衔接 | 问自己 | 例子 |
|---|---|---|
| 原理 → 方法 | 这条原理**对应哪个可量化的量**？ | 匹配原则 → 控制件与受控物的**空间对应关系**（可画图判定） |
| 方法 → 工具 | 这个数值**在建模里怎么落地**？ | 握持直径 30–40 mm → 手柄草图直径约束 |
| 工具 → 回验 | 改完之后**原理层的问题解决了吗**？ | 改完再做一次原理层判定 + 一次可用性测试（走 C-1→C-2） |

> **★★★ 判据：三层都要给，顺序不能倒。**
> **只说"应该改成 R3 圆角"而说不出为什么不是 R1 → 没到方法层；**
> **只会建而说不出该多大 → 还停在工具层。**

**代价对照**：
- 直接跳工具层 → **建得出来但不知对错**（能把壁厚建成 2.0，不知道为什么不是 1.2）
- 只停原理层 → **说得对但做不出来**（知道该有拔模，不会建、不知度数与方向）

### 典型问法（可直接照抄）

> **"这个手柄用户说握着难受。别急着改模型——先说清三件事：按人机工程握持直径应该多少（P5–P95 覆盖到哪）、从视觉构成和力感上看问题出在哪、最后在 SOLIDWORKS 里怎么改形并接顺。三层都给，从'为什么错'开始。"**

命中：`ergonomics-ding-yulan`（ch08 §8.3b）→ `design-elements-hannah` / `visual-dynamics-industrial-design`（ch01–ch04）→ `solidworks-practice` / `solidworks-surface-advanced`

## 三、路 B：要一个产品 —— 沿链路推进

三条链路，按目标选。**共同点：每一环都有交付物，不能跳环。**

### B-1 塑料件：外观漂亮 + 能造（最常用的一条）

```
cmf-system → product-design-styling-dabbs → product-structure-liubaoshun → product-injection-defects
```

| 环 | 技能 | 具体节 | 产出（下一环的输入） |
|---|---|---|---|
| **1 定 CMF** | `cmf-system` | ch01（材料两个角色：技术/美学）、ch04 §4.4（选材四步）、§4.5（六张属性图）、ch05（20 对感知词）、ch06（15 种工艺五列量化表）、ch07 §7.5（四步流程） | **材料牌号 + 七行表面规格**（硬度/膜厚/温度/曲面/光泽/纹理/色号） |
| **2 定造型** | `product-design-styling-dabbs` | ch01（视觉主题与情绪板）、ch02（轮廓与设计指南）、ch03（比例与比例错觉）、ch07（体积分割）、ch08（表面三类型与光影）、ch10（色彩对比分区） | **视觉主题板 + 比例配置图 + 色彩分区** |
| **3 定结构** | `product-structure-liubaoshun` | ch01（壳体：壁厚均匀/拔模斜度/避免大面积薄壁）、ch02（连接：卡扣/螺纹/铆接）、ch05（密封）、ch06（安全四原理） | **壁厚/拔模/卡扣/密封的结构方案** |
| **4 过工艺** | `product-injection-defects` | ch01（五类参数：压力/速度/温度/位置/时间）、各案例章（现象→原因→对策）、结构端预防判据 | **缺陷风险清单 + 对策**（可直接用于模具评审） |

> **★ 顺序不能换**：先定材料再定造型，是因为**材料决定色彩与光泽的可实现区间**；
> 先定造型再定结构，是因为**结构约束会反过来削造型** —— 这个回流必须显式做（见 B-1 注）。

**B-1 注：两条回流路径（实际做起来一定会遇到）**

| 回流 | 触发 | 怎么处理 |
|---|---|---|
| 结构 → 造型 | 壁厚/拔模做不到造型的锐边 | 回 `product-design-styling-dabbs` ch02 改轮廓，不是硬压结构 |
| 缺陷 → CMF | 某个表面工艺在注塑下高风险（如高光面易缩痕） | 回 `cmf-system` ch06 换工艺档位，不是加修饰词 |

> **"做一个手持小家电外壳，要能注塑、要防摔，现在壁厚 1.2mm 摸着发软。帮我从选材料开始定方案，然后给结构改法，最后列一份开模前的缺陷风险清单——我要拿着这份去模具厂评审。"**

## 四、路 C：要一个证据 —— 验证链路

**路 C 的核心主张**：能不能用，**测出来**才算数；讨论出来的不算。

### C-0 为什么必须三个技能接力

| 只查一个 | 会缺什么 |
|---|---|
| 只查 `usability-testing` | 有测试流程，但**不知道该测谁**（普通用户？边界人群？） |
| 只查 `user-research-methods` | 知道该找几个用户，但**没有任务场景、主持禁语、严重度评级** |
| 只查 `inclusive-accessibility-design` | 知道排除了多少人，但**没有实测手段**，结论只能停在估算 |

**三环缺一，结论都不可用于决策。**

### C-1 第一环：选择层 —— 该不该测、测谁、几个

**技能**：`user-research-methods`

| 要看什么 | 具体节 | 拿到什么产出 |
|---|---|---|
| **该不该测** | ch01 §1.2 方法谱系五维、§1.3 设计五阶段 | 判断"这个问题属验证类还是探索类"，以及**当前处在哪一阶段**（阶段错了，方法再好也白做） |
| **测几个** | **ch06 §6.2（Goodman 样本量清单）、§6.3（UMoD 对照）、§6.5（没有数字时的四条替代判据）** | **具体人数**（含两书口径并列）+ 没有数字时的替代判据 |
| **测哪类人** | ch06 §6.4 矩阵设计（让每个格子都有人） | 被试矩阵（人群 × 熟练度） |
| **验证类方法的定位** | ch09 §9.3（**只写"什么时候选它"，不写怎么做**） | 决定"用可用性测试 / 木马法 / RITE / 并行原型 / 快速约会 / 启发式评估"中的哪一个 |
| **测完怎么分析** | ch07 §7.2 亲和图、§7.3 内容分析、§7.4 KJ 法、§7.5 主题网络、§7.6 三角验证 | 逐字稿 → 聚类 → 主题 → 三角验证后的发现 |

> **★ 为什么这一环必须排第一**：跳过它，最常见的后果是拿"**5 个被试够了**"当停止理由 ——
> 而 ch06 §6.5 给的是"**每人群格子 4–5 人**"，不是总数 5 人。

**产出**：一份**研究设计决定**
```
测不测 → 测什么类型（形成性/总结性/验证性/比较）
      → 测几轮（user-research-methods ch09 §9.4 RITE / §9.5 并行原型）
      → 每格几个被试（user-research-methods ch06 §6.5）
      → 人群矩阵（user-research-methods ch06 §6.4）
```

### C-2 第二环：执行层 —— 怎么测

**技能**：`usability-testing`

|---|---|---|

| **跨技能接口** | **ch05 §5.10 把诺曼七原则翻译成测试任务** | 预期缺陷清单 → 可观察场景（防止"任务里写了界面字面"） |

> **★ 严重度有两套口径（Rubin / Barnum），方向相反，引用必须标方向。** 见下方专节。

#### C-2 附：严重度怎么定 —— 两套口径方向相反，冲突怎么裁

**这是本技能最容易出错的一处。** 同一个数字在两套口径下含义完全颠倒。

##### 第一步：认清两套量表（原文对照）

| 项 | **Rubin & Chisnell**（ch08 §8.4） | **Barnum**（ch08 §8.5） |
|---|---|---|
| **量表点数** | **4 点** | **3 点**（Catastrophe/Serious/Cosmetic）或 **4 点**（catastrophe/major/minor/cosmetic） |
| **方向** | **4 = 最重**，1 = 最轻 | **1 = 最重**，4 = 最轻（**方向相反**） |
| **最重档的定义** | 「not able to **or will not want to** use」 | 「cannot complete task」／「expresses **extreme irritation**」／「needs assistance」 |
| **含"意愿"** | **显式**（will not want to use） | 未显式 |
| **含"需要协助"** | 未单列（分散在 3 分 "severely limited"） | **显式列入 1 分（最重）** |
| **优先级合成** | **Severity + Frequency（各 1–4）→ 2–8 分** | 无固定算式；三维度用于讨论 |
| **范围维度** | 无 | **有**（先分 global / local） |
| **呈现要求** | 汇总表含任务、成功率、均值、标准差 | 表格必含 **Number affected** |

**Rubin 的 4 分（§8.4.1）**：4 Unusable / 3 Severe / 2 Moderate / 1 Irritant
> 另有并存的一套：4 = Task failure（阻断该用户）、3 = Serious、2 = Minor、1 = No problem

**Barnum 的 3 分（§8.5.2）**：1 Catastrophe / 2 Serious problem / 3 Cosmetic problem
> 其 1 分含三种情形：**完不成** / **完成但极度恼火** / **需要协助**

##### 第二步：算优先级（只有 Rubin 给得出分数）

```
关键度 = 严重度(1–4) + 频率(1–4)   →  2–8 分
频率 = 受影响人群比例 × 该人群遇到的概率
例：0.10 × 0.5 = 5%
```

| 分数 | 含义 |
|---|---|
| **8** | **唯一最高分 = 4（Unusable）+ 4（≥90%）**，即"所有人都用不了" |
| **5** | 原文的对称案例：**"对所有人致命" 与 "对所有人小烦" 同得 5 分** |

> **★★★★★ 这条会挑战多数团队的本能排序**：关键度不是"越严重越优先"，而是**"总体损害"**。
> 把所有 4 分排最前、哪怕只影响 5% 的人 —— 这是最常见的错排。

**频率四档（§8.4.2）**：4 = ≥90% / 3 = 51–89% / 2 = 11–50% / 1 = ≤10%

##### 第三步：Barnum 多提供的一维 —— 持久性

| 维度 | Rubin | Barnum |
|---|---|---|
| 频率 | ✓ | ✓ |
| 影响 | ✓（即严重度） | ✓ |
| **持久性** | **无独立位置** | **✓**（被试第二次遇到还会不会栽） |
| 范围（全局/局部） | 无 | ✓ |

> **★★★★ 持久性的意义**：「第一次栽、第二次就会了」与「每次都栽」严重度不同 —— Rubin 体系里没这一维。

##### 第四步：本指南的裁决（可直接照用）

> **★★★ 冲突处理四条**
>
> **① 报告正文一律写"文字级别"，不裸写数字。**
> 例：严重（Rubin 4 分 / Barnum Level 2）。裸写"严重度 4"在 Barnum 口径下是"仅偏好/建议"，含义颠倒。
>
> **② 算优先级用 Rubin（两维可合成），做范围判断用 Barnum（有全局/局部）。**
> 两套不冲突，是**不同用途**：一个排修序，一个定修复面积。
>
> **③ 持久性作为调整项，不单独立维。**
> 持久性高 → 严重度**上调一档**，再进入 Rubin 的加法。
>
> **④ 必须先分 global / local 再评级（Barnum 的顺序，不可反）。**
> 理由：**一个 2 分的全局问题，总修复成本可能高于 4 分的局部问题。**
> 三个高发全局类型（几乎每次测试都出现，可作必查项）：
> **信息架构/导航**、**一致性/术语**、**反馈**。

> **★★★ 评级必须是团队共识，不是主持人独断。**
> Rubin：「you can develop your own hierarchy … based on your organization’s objectives」
> Barnum：「strengthened when it is a team effort, since consensus is needed」
> **落地**：评级会必须有开发/设计在场，且**评级标准的释义要先达成一致**。

##### 第五步：小样本的降级法

> **3 人以下的小测试**：可直接问被试"哪里最难"（Rubin §8.4.4）。
> **前提：多人一致才采信**，单人偏好不进优先级。

> **★ 阈值可自定义，但"两维分别评再合成"的结构不要动**（Rubin p301 明确允许自定义分档与权重）。
> 单维打分最容易把"罕见致命"和"常见小烦"混为一谈。


**产出**：一份**可交付的测试报告**
```
测试类型 → 计划（九节）→ 任务清单 + 任务场景 → 主持脚本
→ 筛选问卷 → 试点 → 发现清单 → 严重度评级 → 报告 → 迭代建议
```

## 五、路 C 之外的补充路径

前面只讲了三条主路。以下四类问题不属于任何一条主路，但实际很常遇到。

### 补充 1：只问一个数（单点查证）

**特征**：不要结论、不要流程，只要一个准确数值或条文号。

| 你要的 | 查谁 | 看哪节 |
|---|---|---|
| P5/P50/P95 的人体毫米数 | `ergonomics-ding-yulan` | ch02（人体尺寸数据，GB 10000—1988 原始表） |
| 作业面高度该多高 | `ergonomics-ding-yulan` | ch08 §8.3b（表 8-4 坐姿作业面高度）、§8.3b.1（肘下 5–10 cm） |
| 坐姿/站姿可及范围 | `ergonomics-ding-yulan` | ch08 §8.3b.1（坐姿抓握男 65/女 58 cm；站姿 110–165 cm、±46 cm） |
| 无障碍条文级别与阈值 | `accessibility-standards` | ch01（WCAG 2.1 新增 17 条）、ch02（2.2 新增 9 条）、ch04（EN 301 549 第 8 章硬件数值） |
| 对比度要求 | `web-accessibility-cn` | ch07（4.5:1 / 7:1 / 3:1 与灰度检验法） |
| 光泽等级与反射率 | `cmf-system` | ch05（光泽六级 0–100%） |
| 折弯系数 / K 因子 | `solidworks-2025-mechanical` | 钣金章 |

**典型问法**：
> **"别给我方法论。直接告诉我：操作台面高度按人机工程该多少，男性女性分别多少，出处哪一章。"**

### 补充 2：用标准做采购或验收（合规路径）

**特征**：要的是一份**可验收的规格**，不是设计建议。

```
accessibility-standards（条文与级别）→ web-accessibility-cn（中文落地与用户角色）→ inclusive-accessibility-design（覆盖多少人）
```

| 环节 | 看哪节 | 产出 |
|---|---|---|
| 条文与阈值 | `accessibility-standards` ch04（EN 301 549 第 8 章硬件尺寸与力值）、ch08（三版 87 条对照 + 20 行实体产品验收判据） | shall/should 之分 + 可采购条款 |
| 中文语境 | `web-accessibility-cn` ch01–ch02（8 个中文用户角色、可访问性方程） | 中文用户场景 |
| 覆盖人群 | `inclusive-accessibility-design` ch04 §4.4 | 排除率（用于论证投入必要性） |

**典型问法**：
> **"我要给一个自助终端写采购验收条款，无障碍部分必须能写进合同。给我 WCAG 与 EN 301 549 里适用于实体设备的强制项（shall 级别），并标出各自的条目号和阈值。"**

> **注意**：`accessibility-standards` 明确标注了 EN 17161、ISO 21542、GB/T 37668 正文与中国《无障碍环境建设法》条文的获取状态与留白 —— **引用前先看它的"已知空白"**。

### 补充 3：只做造型诊断（不进入制造）

**特征**：产品还没定，要先判断"这个形态对不对/好不好看"。

```
product-design-styling-dabbs（造型语言）→ visual-dynamics-industrial-design（力感诊断）→ design-elements-hannah（形体组织）
```

**反向用法（诊断为主）**：如果已经有形态、只要判断别扭在哪，直接 `visual-dynamics-industrial-design` ch01–ch02（F 假设、倒叙分析），再回 `design-elements-hannah` 查比例。

**典型问法**：
> **"这个模型我看着别扭但说不清哪里。用视觉动力的方法倒推：是力感失衡还是比例问题？给出具体位置，不要只说'不够协调'。"**

### 补充 4：跨书冲突裁决（两个技能给了不同数）

**特征**：同一个问题，两本书给的数字或口径不一致，你不知道该信哪个。

本项目已实证的冲突点及处理原则：

| 冲突 | 涉及 | 处理 |
|---|---|---|
| 严重度评级方向相反 | `usability-testing` ch08 §8.4（Rubin，4 = 最重）vs §8.5（Barnum） | **引用必须标方向**，不可混用 |
| 被试数口径 | `user-research-methods` ch06 §6.2（Goodman）vs §6.3（UMoD） | **两书并列给出**，取保守值用于正式测试 |

| 材料主力位 | `cmf-system`（选什么）vs SW（软件里怎么设） | 见本文§零陷阱表 |

**典型问法**：
> **"这两本书对严重度的评级方向不一样，我写报告该按哪套？如果要同时引用，怎么写才不混淆？"**
