## 核心原则（速记）

1. **六大原则**：平等、自愿、公平、诚信、公序良俗、绿色（第3-9条）
2. **行为能力三分**：<8岁无 / 8-18岁限制 / ≥18岁完全（第17-22条）
3. **诉讼时效**：普通3年，最长20年（第188条）
4. **物权公示**：不动产登记生效，动产交付生效（第209、224条）
5. **善意取得三要件**：善意 + 合理价格 + 已登记/交付（第311条）
6. **合同效力**：有效/无效/可撤销/效力待定四层体系（第143-154条）
7. **侵权归责**：过错责任为原则，无过错责任为例外（第1165-1166条）

## 限制

本技能基于成文法条整理，用于快速定位民法制度框架。不构成法律意见，具体案件请结合司法解释和专业律师意见。
