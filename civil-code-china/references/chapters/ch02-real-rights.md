# 第二章（编）：物权 — 第205-462条

## 核心要点
规范财产归属与利用关系，确立物权法定、公示公信原则，构建所有权、用益物权、担保物权三大支柱和占有制度。

## 基本原则
- **物权法定原则**（第116条）：物权的种类和内容由法律规定
- **公示公信原则**：不动产登记生效（第209条），动产交付生效（第224条）

## 第一分编：通则

### 不动产登记
- 不动产物权经依法登记发生效力；未经登记不发生效力（第209条）
- **更正登记**（第220条）：权利人、利害关系人认为登记簿记载错误可申请更正
- **异议登记**（第220条）：15日内不起诉的失效
- **预告登记**（第221条）：防止"一房二卖"

### 动产交付
- **现实交付**：直接移转占有（第224条）
- **简易交付**：受让人已先行占有（第226条）
- **指示交付**：返还请求权让与（第227条）
- **占有改定**：出让人继续占有（第228条）——不适用善意取得

## 第二分编：所有权

### 业主的建筑物区分所有权（第271-287条）
- **专有权**：对专有部分享有所有权
- **共有权**：对共有部分享有共有和共同管理权利
- **共同管理权**：共同决定重大事项
- 决议表决要求：双2/3参与，一般事项双过半，重大事项双3/4同意

### 共有
| 类型 | 处分规则 |
|------|---------|
| 按份共有 | 处分需占份额2/3以上同意；可随时请求分割 |
| 共同共有 | 共有关系存续期间不得分割；处分需全体同意 |

### 善意取得（第311条）——核心制度
**三要件缺一不可：**
1. 受让人受让时是**善意**的
2. 以**合理的价格**转让
3. 应登记的**已经登记**，不需登记的**已经交付**

**不适用善意取得**：遗失物（2年内可追回）、占有改定方式交付

## 第三分编：用益物权

| 用益物权类型 | 要点 |
|-------------|------|
| 土地承包经营权 | 耕地30年、草地30-50年、林地30-70年 |
| 建设用地使用权 | 出让/划拨；住宅到期自动续期（第359条） |
| 宅基地使用权 | 一户一宅 |
| **居住权**（新增） | 书面合同+登记设立；原则上无偿；不得转让继承 |
| 地役权 | 自合同生效时设立，登记对抗 |

## 第四分编：担保物权

### 抵押权
- 不动产抵押：登记设立（第402条）
- 动产抵押：合同生效设立，登记对抗（第403条）
- **禁止流押**（第401条）
- 浮动抵押（第396条）
- 最高额抵押权（第420-424条）

### 质权
- **动产质权**：交付质押财产时设立（第429条）
- **权利质权**：汇票/本票/支票、债券、存款单、仓单、提单、基金份额/股权、知识产权财产权、应收账款等（第440条）
- **禁止流质**（第428条）

### 留置权（第447-457条）
- 留置已经合法占有的债务人的动产
- 留置权优先于抵押权和质权（第456条）

### 担保物权竞和顺序
**留置权 > 已登记抵押权/质权（按时间先后）> 未登记抵押权**

## 关键要点
1. 不动产登记生效、动产交付生效是物权法的基石
2. 善意取得制度优先保护交易安全，三要件须同时满足
3. 居住权是民法典新增用益物权，需登记设立
4. 担保物权竞合：留置权最优先，已登记优先于未登记
