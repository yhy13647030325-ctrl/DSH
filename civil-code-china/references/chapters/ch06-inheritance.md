# 第六章（编）：继承 — 第1119-1163条

## 核心要点
规范自然人死亡后遗产的转移规则，确立法定继承、遗嘱继承、遗赠和遗赠扶养协议四种遗产转移方式。

## 第一章 一般规定

### 继承开始
- 继承从被继承人死亡时开始（第1121条）
- 相互有继承关系的数人在同一事件中死亡，推定没有其他继承人的人先死；辈份不同推定长辈先死；辈份相同推定同时死亡

### 继承的接受与放弃（第1124条）
- 继承人：没有表示的，**视为接受**继承
- 受遗赠人：知道受遗赠后**60日内**未表示的，**视为放弃**受遗赠

## 第二章 法定继承

### 继承顺序（第1127条）
**第一顺序**：配偶、子女、父母
**第二顺序**：兄弟姐妹、祖父母、外祖父母

### 代位继承（第1128条）——重大完善
- 被继承人的子女先于被继承人死亡 → 其直系晚辈血亲代位继承
- **被继承人的兄弟姐妹先于被继承人死亡 → 其子女（侄甥）代位继承**——新增

### 遗产分配原则（第1130条）
- 同一顺序一般均等
- 对生活有特殊困难又缺乏劳动能力的应予照顾
- 尽了主要扶养义务或共同生活的可以多分
- 有扶养能力和条件不尽扶养义务的应当不分或少分

## 第三章 遗嘱继承和遗赠

### 遗嘱形式（第1134-1139条）

| 形式 | 见证人 | 关键要求 |
|------|--------|---------|
| 自书 | 不需要 | 亲笔书写+签名+注明年月日 |
| 代书 | ≥2人 | 代书人+其他见证人+遗嘱人签名+日期 |
| **打印**（新增） | ≥2人 | 遗嘱人+见证人在**每一页**签名+日期 |
| **录音录像**（新增） | ≥2人 | 记录姓名/肖像+年月日 |
| 口头 | ≥2人 | 仅限危急情况；危急消除后能书面/录音的，口头无效 |
| 公证 | — | 公证机构办理；**不再优先**（重大变化！） |

### 遗嘱撤回与变更（第1142条）
- **立有数份遗嘱，内容相抵触的，以最后的遗嘱为准**——删除了原继承法"公证遗嘱效力优先"

### 遗赠扶养协议（第1158条）——效力最高
自然人与继承人以外的组织或个人签订，该组织或个人承担生养死葬义务，享有受遗赠权利。

**效力优先级**：遗赠扶养协议 > 遗嘱继承/遗赠 > 法定继承（第1123条）

## 第四章 遗产的处理

### 遗产管理人（第1145条）
遗嘱执行人 → 继承人推选 → 继承人共同担任 → 民政部门/村委会

### 限定继承原则（第1161条）
继承人以所得遗产实际价值为限清偿被继承人依法应当缴纳的税款和债务。超过部分自愿偿还不在此限。

## 关键要点
1. 法定继承两顺序：配偶/子女/父母 → 兄弟姐妹/祖父母/外祖父母
2. 代位继承扩大至侄甥
3. 新增打印遗嘱形式，删除公证遗嘱优先效力
4. 遗嘱效力优先级：遗赠扶养协议 > 遗嘱 > 法定继承
5. 受遗赠人60日内不表态视为放弃，与继承人"沉默视为接受"相反
