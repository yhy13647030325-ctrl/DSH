# 第五章（编）：婚姻家庭 — 第1040-1118条

## 核心要点
规范婚姻、家庭关系，包括结婚、夫妻关系、父母子女关系、离婚、收养等制度。

## 第二章 结婚

### 结婚条件
- 完全自愿；男≥22周岁，女≥20周岁；直系血亲或三代以内旁系血亲禁止结婚

### 无效婚姻（第1051条）
1. 重婚
2. 有禁止结婚的亲属关系
3. 未到法定婚龄

### 可撤销婚姻（第1052-1053条）
- 因胁迫结婚：自胁迫终止之日起1年内提出
- 婚前隐瞒重大疾病：自知道或应当知道之日起1年内提出

## 第三章 家庭关系

### 夫妻共同财产（第1062条）
1. 工资、奖金、劳务报酬
2. 生产、经营、投资的收益
3. 知识产权的收益
4. 继承或受赠的财产（遗嘱/赠与合同明确只归一方的除外）

### 夫妻个人财产（第1063条）
1. 一方的婚前财产
2. 一方因受到人身损害获得的赔偿或补偿
3. 遗嘱或赠与合同中确定只归一方的财产
4. 一方专用的生活用品

### 夫妻共同债务认定（第1064条）
- 共债共签或事后追认 → 共同债务
- 一方以个人名义为家庭日常生活需要所负 → 推定为共同债务
- 超出家庭日常生活需要 → 债权人举证用于共同生活/共同经营

## 第四章 离婚

### 离婚冷静期（第1077条）——新增
- 协议离婚登记申请后**30日内**，任何一方可撤回
- 期限届满后30日内双方亲自申请发给离婚证；未申请视为撤回

### 准予离婚的情形（第1079条）
1. 重婚或与他人同居
2. 实施家庭暴力或虐待、遗弃家庭成员
3. 有赌博、吸毒等恶习屡教不改
4. 因感情不和分居满2年
5. 经判决不准离婚后，双方又分居满1年，一方再次起诉 → 应当准予离婚

### 子女抚养（第1084条）
- 不满2周岁 → 原则上随母亲
- 2-8周岁 → 最有利于未成年子女原则
- 8周岁以上 → 尊重子女真实意愿

### 离婚损害赔偿（第1091条）
无过错方有权请求损害赔偿的情形：
1. 重婚
2. 与他人同居
3. 实施家庭暴力
4. 虐待、遗弃家庭成员
5. 有其他重大过错

## 第五章 收养

### 收养人条件（第1098条）
- 无子女或只有一名子女
- 有抚养、教育和保护被收养人的能力
- 年满30周岁
- **无配偶者收养异性子女**：年龄应当相差40周岁以上（第1102条）

### 收养效力（第1111条）
养父母与养子女间的权利义务关系，适用父母子女关系规定；养子女与生父母及其他近亲属间的权利义务关系，因收养成立而消除。

## 关键要点
1. 离婚冷静期30天仅适用于协议离婚
2. 夫妻共同债务"共债共签"原则
3. 离婚损害赔偿需对方有法定过错
4. 不满2周岁子女原则上随母，8周岁以上应尊重其意愿
5. 无配偶者收养异性需差40岁以上
