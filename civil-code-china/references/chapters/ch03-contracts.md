# 第三章（编）：合同 — 第463-988条

## 核心要点
民法典中条文最多、商事实践最常用的一编。规范合同从订立到终止的全生命周期，规定19种典型合同和准合同。

## 第一分编：通则

### 合同订立
- **要约**（第472条）：内容具体确定；经受要约人承诺即受约束
- **承诺**（第479条）：承诺生效时合同成立
- **格式条款**（第496条）：提供方应采取合理方式提示对方注意免除/减轻其责任等重大利害关系条款
  - 未尽提示说明义务 → 对方可主张该条款不成为合同内容
  - 格式条款无效：不合理免除/减轻提供方责任、加重对方责任、排除对方主要权利

### 合同效力
- 依法成立的合同，自成立时生效（第502条）
- 无权处分合同**不因无权处分而无效**（第597条）

### 合同保全
- **债权人代位权**（第535条）：债务人怠于行使其债权影响债权人实现，债权人可代位行使
- **债权人撤销权**（第538-539条）：债务人无偿处分财产权益，债权人可请求法院撤销
  - 行使期限：知道撤销事由起1年，行为发生起5年（第541条）

### 合同权利义务终止
- **法定解除权**（第563条）：
  1. 不可抗力致合同目的不能实现
  2. 预期违约（明确表示不履行主要债务）
  3. 迟延履行主要债务经催告后合理期限仍未履行
  4. 迟延履行/其他违约致合同目的不能实现
- 解除权行使期限：知道或应当知道解除事由起1年（第564条）

### 违约责任
- **赔偿损失**（第584条）：相当于因违约造成的损失，包括可得利益；不得超过违约方订立合同时预见到的损失
- **违约金**（第585条）：过分高于损失可请求减少；低于损失可请求增加
- **定金**（第586-587条）：不得超过主合同标的额20%；不履行时双倍返还或丧失
- **违约金与定金竞合**（第588条）：只能择一适用，不能并用

## 第二分编：典型合同（19种）

### 核心要点速查

| 合同类型 | 核心规则 |
|---------|---------|
| **买卖合同** | 所有权自交付时转移；风险自交付时转移（第604条） |
| **赠与合同** | 财产权利转移前可任意撤销；公证/公益道德性质的不可任意撤销（第658条） |
| **借款合同** | 禁止高利放贷；利息不得预先在本金中扣除（第670条） |
| **保证合同** | 约定不明推定为**一般保证**（重大变化！）；保证期间无约定为6个月（第686、692条） |
| **租赁合同** | 最长20年；买卖不破租赁（第725条）；承租人优先购买权（第726条） |
| **融资租赁** | 出租人购租赁物供承租人使用；期满归属依约定，无约定归出租人 |
| **建设工程合同** | 禁止转包违法分包；**工程价款优先受偿权**优先于抵押权（第807条） |
| **物业服务合同**（新增） | 物业不得停水停电催交物业费（第944条）；业主解聘提前60日通知（第946条） |
| **合伙合同** | 共享利益、共担风险；合伙人对合伙债务承担连带责任 |

## 第三分编：准合同

### 无因管理（第979-984条）
- 无法定或约定义务，为避免他人利益受损失而管理他人事务
- 管理人可请求偿还必要费用并适当补偿损失

### 不当得利（第985-988条）
- 没有法律根据取得不当利益，应返还
- **不适用情形**：履行道德义务的给付、债务到期前清偿、明知无给付义务的清偿
- 善意得利人以现存利益为限返还；恶意得利人应返还并赔偿损失

## 关键要点
1. 要约+承诺=合同成立；格式条款需提示说明
2. 债权人代位权和撤销权是合同保全两大工具
3. 违约责任以补偿性为主；违约金过高可调整
4. 买卖不破租赁、承租人优先购买权是租赁权物权化
5. 保证方式约定不明推定为一般保证（重大变化）
6. 建设工程价款优先受偿权优先于抵押权
