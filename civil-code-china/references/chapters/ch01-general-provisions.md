# 第一章（编）：总则 — 第1-204条

## 核心要点
民法典的"宪法性"编章，确立全部民事活动的基本原则、主体制度、法律行为效力规则和时效制度，是理解其余六编的基础。

## 六大基本原则（第3-9条）

| 原则 | 条文 | 核心含义 |
|------|------|---------|
| 平等 | 第4条 | 民事主体法律地位一律平等 |
| 自愿 | 第5条 | 意思自治，按自己意思设立变更终止法律关系 |
| 公平 | 第6条 | 合理确定权利义务 |
| 诚信 | 第7条 | 帝王条款，秉持诚实、恪守承诺 |
| 公序良俗 | 第8条 | 不违法、不违背公共秩序和善良风俗 |
| 绿色 | 第9条 | 节约资源、保护生态环境（中国首创） |

## 民事主体制度

### 自然人行为能力三分法
| 类型 | 年龄/状态 | 行为效力 |
|------|----------|---------|
| 完全行为能力 | ≥18岁；或16-18岁以自己劳动收入为主要生活来源 | 独立实施一切法律行为 |
| 限制行为能力 | 8-18岁；不能完全辨认自己行为的成年人 | 纯获利益或与其年龄/智力相适应的行为有效；其余需法定代理人同意/追认 |
| 无行为能力 | <8岁；不能辨认自己行为的成年人 | 法定代理人代理实施，独立实施的无效 |

### 监护制度
- **法定监护**：父母是未成年子女的监护人（第27条）；成年人监护人按顺序：配偶→父母子女→其他近亲属（第28条）
- **意定监护**：完全行为能力人可书面确定自己的监护人（第33条）
- **撤销监护资格**：实施严重损害被监护人身心健康行为等（第36条）

### 宣告失踪与宣告死亡
| 制度 | 条件 | 法律后果 |
|------|------|---------|
| 宣告失踪 | 下落不明满2年 | 设立财产代管人 |
| 宣告死亡 | 下落不明满4年；意外事件满2年；意外事件经有关机关证明不可能生存的不受时间限制 | 婚姻关系消灭、遗产开始继承 |

### 法人分类
- **营利法人**：有限责任公司、股份有限公司等
- **非营利法人**：事业单位、社会团体、基金会、社会服务机构
- **特别法人**：机关法人、农村集体经济组织法人、城镇农村的合作经济组织法人、基层群众性自治组织法人

## 民事法律行为效力体系

### 有效要件（第143条）
1. 行为人具有相应的民事行为能力
2. 意思表示真实
3. 不违反法律、行政法规的强制性规定，不违背公序良俗

### 无效情形（第144-154条）
- 无民事行为能力人实施的（第144条）
- 行为人与相对人以虚假的意思表示实施的（第146条）——阴阳合同中阳合同无效
- 违反法律、行政法规强制性规定的（第153条第1款）——仅"效力性强制性规定"才导致无效
- 违背公序良俗的（第153条第2款）
- 恶意串通，损害他人合法权益的（第154条）

### 可撤销情形（第147-151条）
| 情形 | 撤销权行使期限 |
|------|---------------|
| 重大误解 | 自知道或应当知道撤销事由之日起90日内 |
| 欺诈 | 自知道或应当知道撤销事由之日起1年内 |
| 胁迫 | 自胁迫行为终止之日起1年内 |
| 显失公平（乘人之危） | 自知道或应当知道撤销事由之日起1年内 |
| 行为发生之日起5年内未行使 | 撤销权消灭（第152条） |

### 效力待定
- 限制行为能力人超越能力实施的法律行为——法定代理人追认权（第145条），相对人催告权30日
- 无权代理——被代理人追认权（第171条），相对人催告权30日；善意相对人有撤销权

## 代理制度
- **委托代理 vs 法定代理**（第163条）
- **无权代理**：没有代理权、超越代理权、代理权终止后仍实施（第171条）
- **表见代理**（第172条）：相对人有理由相信行为人有代理权的，代理行为有效——保护交易安全
- **自己代理/双方代理**（第168条）：原则上禁止，经被代理人同意或追认除外

## 诉讼时效
- **普通时效**：3年（第188条）
- **最长保护期**：20年，特殊情况可申请延长（第188条）
- **中止**：最后6个月内因不可抗力等障碍（第194条）
- **中断**：权利人请求、义务人同意、起诉/仲裁——重新起算（第195条）
- **不适用时效的请求权**（第196条）：停止侵害/排除妨碍/消除危险；不动产物权和登记动产物权返还财产；抚养费/赡养费/扶养费

## 关键要点
1. 行为能力三分法是判断法律行为效力的起点
2. 诚信原则是"帝王条款"，可直接作为裁判依据
3. 诉讼时效3年为普通期间，20年为最长保护期
4. 表见代理制度优先保护交易安全
5. 绿色原则为民法典中国特色创新
