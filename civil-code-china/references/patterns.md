# 民法典典型规则与裁判模式

## 合同效力判断模式

### 规则：合同效力四步判断法
**When to use**：判断一份合同或民事法律行为是否有效
**How**：
1. 行为人是否具有相应民事行为能力？（无/限制/完全）
2. 意思表示是否真实？（有无欺诈、胁迫、重大误解、显失公平）
3. 是否违反法律、行政法规的**效力性**强制性规定？（管理性规定不导致无效）
4. 是否违背公序良俗？是否恶意串通损害他人？

## 善意取得适用模式

### 规则：善意取得三要件检验
**When to use**：无权处分人转让财产，原权利人追回财产时
**How**：
1. 受让人受让时是否善意？（不知道处分人无处分权）
2. 是否以合理价格转让？（明显低价排除善意）
3. 应登记的是否已登记？不需登记的是否已交付？
三要件全部满足 → 受让人取得所有权，原权利人只能向无权处分人索赔

## 诉讼时效计算模式

### 规则：诉讼时效起算与中断
**When to use**：判断请求权是否超过诉讼时效
**How**：
1. 普通时效3年，自知道或应当知道权利受损及义务人之日起算
2. 最长保护期20年，自权利受损之日起算（不发生中止中断）
3. 时效中断事由：权利人提出请求、义务人同意履行、起诉/仲裁 → 重新起算3年
4. 时效中止：最后6个月内因不可抗力等障碍 → 障碍消除后继续计算6个月

## 夫妻共同债务认定模式

### 规则：共债共签+家庭日常生活推定
**When to use**：判断婚姻关系存续期间一方所负债务是否为夫妻共同债务
**How**：
1. 共债共签或事后追认 → 共同债务
2. 一方以个人名义为家庭日常生活需要所负 → 推定为共同债务
3. 一方以个人名义超出家庭日常生活需要 → 债权人举证用于夫妻共同生活/共同经营/共同意思表示

## 离婚子女抚养权判断模式

### 规则：年龄分层+最有利于子女原则
**When to use**：离婚时确定子女直接抚养方
**How**：
1. 不满2周岁 → 原则上随母亲
2. 2-8周岁 → 法院按最有利于未成年子女原则判决
3. 8周岁以上 → 尊重子女真实意愿

## 侵权归责原则选择模式

### 规则：归责原则对照表
**When to use**：判断某类侵权应适用何种归责原则
**How**：
| 侵权类型 | 归责原则 | 举证责任 |
|---------|---------|---------|
| 一般侵权 | 过错责任 | 原告举证被告有过错 |
| 教育机构（无民事行为能力人受害） | 过错推定 | 学校举证自己无过错 |
| 动物园动物致害 | 过错推定 | 动物园举证尽到管理职责 |
| 建筑物脱落坠落 | 过错推定 | 所有人/管理人举证无过错 |
| 产品责任 | 无过错责任 | 受害人无需证明生产者过错 |
| 环境污染 | 无过错责任 | 加害人举证因果关系不存在 |
| 高度危险作业 | 无过错责任 | 受害人故意为唯一免责事由 |
| 饲养动物致害 | 无过错责任 | 受害人故意/重大过失可减免 |

## 担保物权竞合清偿模式

### 规则：担保物权优先顺位
**When to use**：同一财产上存在多个担保物权时确定清偿顺序
**How**：
1. 留置权最优先（法定担保物权 > 意定担保物权）
2. 已登记的抵押权和质权按登记/交付时间先后清偿
3. 未登记的抵押权不得对抗善意第三人，顺序最后

## 遗嘱效力判断模式

### 规则：遗嘱形式合法性检验
**When to use**：判断多份遗嘱中哪份有效
**How**：
1. 立遗嘱人立遗嘱时是否具有完全民事行为能力？
2. 遗嘱是否是真实意思表示（有无胁迫、伪造、篡改）？
3. 遗嘱形式是否符合法定要求（见证人人数、签名、日期等）？
4. 是否为缺乏劳动能力又无生活来源的继承人保留必要份额？
5. 数份遗嘱内容抵触 → 以最后合法有效遗嘱为准（公证遗嘱不再优先！）

## 高空抛物责任认定模式

### 规则：三层责任结构
**When to use**：高空抛物/坠物致人损害
**How**：
1. 能确定具体侵权人 → 该侵权人承担责任
2. 难以确定具体侵权人 → 可能加害的建筑物使用人给予补偿（能证明自己不是侵权人除外）
3. 物业服务企业未尽安全保障义务 → 承担相应侵权责任
4. 公安等机关应依法及时调查查清责任人

## 格式条款效力模式

### 规则：格式条款三层次审查
**When to use**：审查合同中格式条款的效力
**How**：
1. 提供方是否采取合理方式提示对方注意免除/减轻其责任等重大利害关系条款？
2. 未尽提示说明义务 → 对方可主张该条款不成为合同内容
3. 条款内容本身是否不合理地免除/减轻提供方责任、加重对方责任、排除对方主要权利？→ 是则条款无效

## 合同解除权行使模式

### 规则：法定解除事由与期限
**When to use**：判断一方是否有权解除合同
**How**：
1. 不可抗力致合同目的不能实现 → 双方均可解除
2. 预期违约（明确表示不履行主要债务）→ 非违约方可解除
3. 迟延履行主要债务经催告后合理期限仍未履行 → 非违约方可解除
4. 迟延履行/其他违约致合同目的不能实现（根本违约）→ 非违约方可直接解除
5. 解除权行使期限：知道或应当知道解除事由之日起1年（无约定时）
