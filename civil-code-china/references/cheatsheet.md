## 二、继承顺序速查

```
第一顺序：配偶 → 子女（婚生/非婚生/养/有扶养关系的继）→ 父母（生/养/有扶养关系的继）
第二顺序：兄弟姐妹（同父母/同父异母同母异父/养/有扶养关系的继）→ 祖父母 → 外祖父母

有第一顺序继承人时，第二顺序不继承。
代位继承：被继承人的子女先死 → 其直系晚辈血亲代位；
          被继承人的兄弟姐妹先死 → 其子女（侄甥）代位。
```

## 三、遗嘱效力优先级

```
遗赠扶养协议 > 遗嘱继承/遗赠 > 法定继承
```

## 四、遗嘱形式速查

| 形式 | 见证人 | 关键要求 |
|------|--------|---------|
| 自书 | 不需要 | 亲笔书写+签名+注明年月日 |
| 代书 | ≥2人 | 代书人+其他见证人+遗嘱人签名+日期 |
| 打印 | ≥2人 | 遗嘱人+见证人在**每一页**签名+日期 |
| 录音录像 | ≥2人 | 记录姓名/肖像+年月日 |
| 口头 | ≥2人 | 仅限危急情况；危急消除后能书面/录音的，口头无效 |
| 公证 | — | 公证机构办理；**不再优先** |

## 五、民事行为能力判断

```
< 8岁 → 无行为能力：所有法律行为需法定代理人代理
8-18岁 → 限制行为能力：纯获利益/相适应行为有效；其余需追认
≥18岁（或16+独立劳动收入）→ 完全行为能力：独立实施一切法律行为
不能辨认自己行为的成年人 → 无行为能力
不能完全辨认 → 限制行为能力
```

## 六、合同解除权情形

```
法定解除：
① 不可抗力致合同目的不能实现
② 预期违约（明确表示不履行主要债务）
③ 迟延履行主要债务，催告后合理期限仍未履行
④ 迟延履行/其他违约致合同目的不能实现（根本违约）

任意解除：
① 承揽合同：定作人可随时解除（赔偿损失）
② 委托合同：双方可随时解除
③ 不定期租赁：双方可随时解除（合理期限前通知）
④ 物业服务合同（不定期）：可随时解除（60日前通知）
```

## 七、离婚判断决策树

```
双方都同意离婚 + 财产/子女无争议
  → 协议离婚 → 30天冷静期 → 领证

一方不同意 / 财产或子女有争议
  → 诉讼离婚
  → 第一次起诉：法定情形（重婚/家暴/分居2年/恶习）判离；否则可能判不离
  → 判不离后分居满1年再起诉 → 应当判离
```

## 八、侵权归责原则速查

```
过错责任（一般）：原告证明被告有过错
  ↓
过错推定（法律推定被告有过错，被告反证）：
  · 无民事行为能力人在教育机构受害
  · 动物园动物致害
  · 建筑物脱落坠落
  · 堆放物倒塌
  · 林木折断
  · 地面施工未设标志

无过错责任（不管有无过错都要赔）：
  · 产品缺陷
  · 环境污染/生态破坏
  · 高度危险作业
  · 饲养动物致害（一般）
  · 禁止饲养的危险动物（绝对责任，无减免）
  · 机动车与非机动车/行人事故
```

## 九、夫妻财产速查

```
共同财产（婚内所得）：
  √ 工资奖金劳务报酬
  √ 生产经营投资收益
  √ 知识产权收益
  √ 继承/受赠财产（未明确只归一方的）

个人财产：
  √ 婚前财产
  √ 人身损害赔偿/补偿
  √ 遗嘱/赠与合同明确只归一方的
  √ 一方专用生活用品
```

## 十、不适用诉讼时效的请求权

```
① 停止侵害、排除妨碍、消除危险
② 不动产物权和登记的动产物权权利人请求返还财产
③ 支付抚养费、赡养费、扶养费
④ 人格权请求权（停止侵害、消除影响、恢复名誉等）
```

## 十一、保证方式速查（重要变化）

```
约定明确 → 按约定（一般保证 / 连带责任保证）
约定不明 → 推定为【一般保证】（原担保法推定为连带责任，民法典改了！）

一般保证：先诉抗辩权（先告债务人并强制执行无果后才能找保证人）
连带责任：债权人可直接找保证人，无需先找债务人
```

## 十二、担保物权优先顺序

```
留置权 > 已登记抵押权 ≈ 已交付质权（按时间先后）> 未登记抵押权
```

## 十三、高空抛物责任三层结构

```
第一层：找到具体侵权人 → 侵权人赔偿
第二层：找不到 → 可能加害的建筑物使用人【补偿】（能证明不是自己的除外）
第三层：物业未尽安全保障义务 → 承担相应责任
+ 公安等机关应当依法及时调查
```

## 十四、民法典中国特色创新点

```
① 人格权独立成编（世界首创）
② 绿色原则（节约资源、保护生态环境）
③ 居住权制度（为以房养老、离婚居住安排提供工具）
④ 违约精神损害赔偿
⑤ 离婚冷静期
⑥ 自助行为制度
⑦ 自甘风险规则
⑧ 保理合同、物业服务合同、合伙合同等典型合同新增
⑨ 代位继承扩大至侄甥
⑩ 打印遗嘱、录像遗嘱等新形式遗嘱
```
