## 1. 选方法：先问五个问题

| # | 问题 | 若答"是" | 若答"否" |
|---|---|---|---|
| 1 | 我要的是**行为**还是**态度**？ | 行为→观察/影子/行为地图 | 态度→访谈/问卷/焦点小组 |
| 2 | 我要**多少**还是**为什么**？ | 多少→问卷/A/B/调查 | 为什么→访谈/日记/情境访谈 |
| 3 | 我在**探索 / 生成 / 评价**？ | 探索→ch03-04；生成→ch09 并行原型；评价→ch09 | 先回 ch01 定阶段 |
| 4 | **用户能不能到现场**？ | 能→观察类 | 不能→日记/照片/探针 |
| 5 | 我有没有**东西可测**？ | 有→可用性测试/RITE/认知走查 | 没有→先做 ch02-04 |

**口诀**：专家评审（不需用户）→ 观察（要用户在场）→ 自报（可不在场）＝成本递增、真实性递减，**互补不互替**。

## 3. 各方法四问速查（何时用 / 何时不能用 / 样本 / 产出）

| 方法 | 何时用 | 何时**不**能用 | 样本 | 产出 |
|---|---|---|---|---|
| **深度访谈** | 要第一手叙述、要"为什么" | 要统计分布；用户说不出动机 | 两书未给 | 逐字稿、主题编码 |
| **情境访谈** | 要真实工作结构、要默会知识 | 现场进不去；无"日常"可看 | 两书未给；单场 **2~3 小时** | 工作模型、任务序列 |
| **师徒式** | 技能型任务、做得出说不出 | 一次性决策；不许旁观 | 两书未给 | 动作+缘由对照表 |
| **触石之旅** | 要理解"物/空间如何承载秩序" | 涉及隐私；环境已废弃 | 两书未给 | 导览稿、布局草图 |
| **观察（半结构）** | 进新领域、建基线 | 要量化比较 | 两书未给 | 笔记、照片、模式 |
| **观察（结构化）** | 元素已定义（先做试点） | 类别未定；样本太小 | 两书未给 | 编码表、频次 |
| **人种志** | 陌生领域、打共情底 | 要长期变迁；只有 2~3 天 | 两书未给 | 设计含义清单 |
| **参与式观察** | 要"同感"、理解亚文化 | 要代表性；需隐蔽身份 | 两书未给 | 共情叙述 |
| **影子跟踪** | routine 就是研究对象 | 高危职业；不同意贴身 | 两书未给（"several team members"是团队数） | 时间轴、决策点 |
| **飞墙观察** | 公共场所；被打断就变的工作 | 要动机（结构上拿不到） | 两书未给 | 行为记录、推断栏 |
| **行为地图** | 空间/动线是设计变量 | 行为不在固定空间；要动机 | 两书未给 | 动线图、停留热区 |
| **日记法** | 跨时间（1 天~1 月） | 要统计；跨度远超 1 月 | **约 10 + 2** | 日记本、条目、主题 |
| **经验取样** | 要"当下状态" | 需长时间不被打断 | 两书未给 | 即时条目、图文配对 |
| **照片研究** | 陌生领域；什么对用户重要 | 要精确频次；无法回访 | 两书未给 | 照片集 + 解释 |
| **文化探针** | 探索期要灵感与愿望 | 要可辩护的决策依据 | 两书未给 | 探针包、印象 |
| **焦点小组** | 生成假设、群体心智模型 | 敏感话题；组内有身份差；要外推 | **每组 6~8** | 假设清单、隐喻 |
| **问卷** | 大样本、要可统计 | 样本不够大；要"为什么" | 查表（见 §2） | 频次、交叉表 |
| **亲和图** | 材料要变主题、要可追溯 | 材料太少；团队未受训 | 每人 50~100 条 | 四层便签图 |
| **内容分析** | 大量文本/图像；要主题+频次 | 材料很少；要因果 | 两书未给 | 编码表、频次、形式分析 |
| **KJ 法** | 会议卡住、要平等表达 | 需要**用户证据** | 人数未给；**1~2 小时** | 团队版亲和图 |
| **主题网络** | 已有丰富文本、需分步法 | 材料很少；要统计 | 两书未给 | 三层主题 + 网络图 |
| **三角验证** | 结论要经得起质疑 | 时间只够一种方法 | 两书未给 | 汇聚/冲突对照表 |
| **人物画像** | 要长期参照、检查场景 | 只有人口统计；样本不足 | **3~5 个/项目** | 一页画像 |
| **用户旅程图** | 体验跨渠道/多时点 | 单点接触；无一画像 | 两书未给（案例 35 访→6 图） | 大幅旅程图 |
| **任务分析** | 流程有步骤可拆 | 任务边界模糊；要意义 | 两书未给 | HTA 树、错误清单 |
| **认知走查** | walk-up-and-use；无人指导 | 需培训的产品；探索型任务 | 两书未给（**不需用户**） | 四问评估表 |
| **木马** | 原型贵/未实现；测接受度 | 能便宜造原型；要真性能数据 | 两书未给 | 接受度、边界条件 |
| **可用性测试** | 有对象+任务；要定位失败 | 需求未定；要总体比例 | **每轮≥5，招募 6~10** | 问题清单（**执行详见 usability-testing**） |
| **RITE** | 早期、能几小时内改原型 | 需要稳定基线报告 | **连续 5 次成功** | 改进后的原型 |
| **并行原型** | 团队卡在一个方案 | 方案已定只待优化 | 两书未给 | 多原型 + 元素级反馈 |
| **快速约会** | 目标情境不可得 | 情境可直接进入 | 两书未给（案例：100+ 概念/27 变体/2 周） | 分镜、排序、误解清单 |
| **启发式评估** | 用户约不到；测前扫基线 | 要突破性机会；启发式未改写 | **3~5 评估者** | 问题-启发式对照表 |

## 4. 问卷设计七条铁律（源 A `p141`/`p173`）

1. **比较偏好别用单选** → 用排序或定额分配（100 分）
2. **李克特用五点**（strongly disagree ↔ strongly agree）
3. **leading / blaming 是硬禁**（原书唯一标"to be avoided"的两类）
4. **Neutral 是检查项**，不是题型
5. **Factual 可被观察验证；Hypothetical 只能拿意图**
6. **最后一题问"我漏了什么"**（Request for questions）
7. **外观决定应答率**（六因素里五个是形式）

## 5. 田野访问：六种要避免的角色（源 B `DOC 16 §103–§109`）

| 别当 | 症状 | 纠正 |
|---|---|---|
| 采访者 | 你在提示他说什么 | **深呼吸，给他时间做/说** |
| 专家 | 他反问你怎么办 | "你希望它怎么表现？" |
| 客服部 | 变成售后 | 只记问题，不解决 |
| 客人 | 寒暄占全场 | 头几分钟客气，随后请他继续工作 |
| 老大哥 | 他表演合规流程 | 明说"不是来评绩效"；**自己约人，别让管理层派单** |
| 间谍 | 未告知即观察 | **绝对不做**；未同意的越权汇报"always unethical" |

**应建立的两种关系**：师徒（他做+边做边讲，压住概括）｜伙伴（邀他退一步想缘由，会改变行为但信息关键）

## 6. 现场准备清单（源 B `DOC 16 §84–§89`）

- [ ] 物品清单（**首访前一周**开始，当天逐件划掉）
- [ ] 同意书按**两倍**准备
- [ ] 设备**装一遍→拆掉→再装一遍**（一两天前）
- [ ] 多孔插排、备用存储、多两本便签、多几支笔、**备用电池**
- [ ] 报酬装在一个可低调携带的容器
- [ ] 提前告知：目标 / 时长 / 设备 / 想看哪类活动
- [ ] **明确请对方"不要做任何准备"**（否则你看到的是一间收拾过的屋子）

## 7. 三条红线

1. **自报类不能单独用**（问卷/调查/焦点小组/照片/探针，五法五次表述零例外）→ 结论降级为"假设"
2. **不写书上没写的数字**（两书未给就写"未给"）
3. **不做隐蔽研究、不做越权汇报**

## 8. 交付物检查

| 交付物 | 必含 | 常见错误 |
|---|---|---|
| **人物画像** | 姓名 / **图库照片**（不用真实被试）/ 叙事（处境+目标+行为）/ 一页内 | 只差人口统计 ⇒ 那是市场细分 |
| **用户旅程图** | 画像名 / 范围界定 / 接触**前中后** / 正负中三态 / **含犹豫困惑挫败** | 只画顺畅路径 = 宣传册 |
| **任务分析** | purpose/cues/objects/method/options / HTA 树 / **走查校验** | 研究者自编流程未校验 |
| **认知走查** | 用户视角任务 / 逐步四问 / 失败步骤清单 | 用"系统视角"写任务 |
