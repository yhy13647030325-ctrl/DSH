## 三、WCAG 2.2 新增 9 条 + 废止 1 条

| 条目 | 名称 | 级别 | 一句话 |
|---|---|---|---|

## 四、尺寸：两档并存，不是一个取代另一个

```
2.5.8  Target Size (Minimum)     24 × 24 CSS px    AA    ← 2.2 新增
2.5.5  Target Size (Enhanced)    44 × 44 CSS px    AAA   ← 2.1 就有，2.2 改名
```

> **『2.2 把 44 降到 24』是错的。** 是在 AAA 之下**补了一个 AA 门槛**，两档同时有效。

**spacing 替代路径（2.5.8）**：小于 24px 的控件，只要以 24px 直径为圆、彼此不相交，也算通过。
> 这条比『必须做大』更容易落地 —— 小按键可以小，但**别挤**。

## 五、对比度：三个数，三种用途

| 用途 | 阈值 | 条目 | 级别 |
|---|---|---|---|
| 正文文字 | **≥4.5:1** | 1.4.3 Contrast (Minimum) | AA |
| 大字（≥18pt / 14pt bold） | **≥3:1** | 1.4.3 Large Text | AA |
| 文字（增强） | **≥7:1**；大字 ≥4.5:1 | 1.4.6 Contrast (Enhanced) | AAA |
| **非文字**（控件轮廓/状态/必需图形） | **≥3:1** | **1.4.11** | AA |
| **焦点指示** | **≥3:1**（同像素，聚焦前后） | **2.4.13** | AAA |

> **3:1 出现三次，用途各不相同** —— 别把『控件边框 3:1』当成『文字 3:1 就够了』。

## 七、EN 301 549 读法三条铁律

1. **`shall` 才是要求，`should` 只是推荐**
   第 14 章：「Those clauses containing the word "should" are recommendations and are not required for conformance.」
2. **测试只有四种结果**：`not applicable` / `pass` / `fail` / `not testable`
3. **条款是 self-scoping 的**：前置条件（`Where ICT ...`）不成 → 该条不适用，**不算未测**

## 八、EN 301 549 第 9 章 = WCAG 2.1 AA 的逐条转写

| 事实 | 数值/原文 |
|---|---|
| `WCAG 2.1` 在全文出现 | **423 次** |
| `WCAG 2.2` 在全文出现 | **0 次** |
| 锁定的 WCAG 版本 | **2.1（2018-06）** |
| 符合 WCAG 2.1 AA ≡ | 符合 **9.1 至 9.4 全部** + **9.6** |
| 符合 WCAG 2.0 AA ≡ | 符合 9.1.1 … 9.4.1.2 中**列出的那部分** + 9.6 |
| AAA 条目 | 单列 9.5 的 Table 9.1（**28 条**），仅「encouraged」 |
| 「Void」条款 | AA 层为对齐编号而留的空位（如 9.1.4.6–9.1.4.9） |

> **所以：符合 WCAG 2.0 AA ≠ 符合 EN 301 549 第 9 章**（前者不含 2.1 的新增条目）。

## 九、一致性模型（WCAG 第 5 章）

**『符合 AA』= 以下六条同时成立**：

1. 该版本全部 A 条目
2. 该版本全部 AA 条目
3. **整页**范围（含响应式的每个布局变体）
4. **流程内所有步骤**（一页不过则全流程不过）
5. 只依赖**可访问性支持**的用法
6. **非干扰四条目**对全页含第三方内容生效：`1.4.2` `2.1.2` `2.3.1` `2.2.2`

**AAA 不能当门槛**（W3C 与 EN 301 549 双重明文）：
> 「It is not recommended that Level AAA conformance be required as a general policy for entire sites because it is not possible to satisfy all Level AAA success criteria for some content.」

**部分符合只允许两种名义**：① 第三方内容（**2 个工作日内**监控修复）② 语言导致的可访问性支持缺失。

## 十三、五个『反直觉』提醒

1. **2.1 新增是 17 条，不是 15 条**（漏 1.3.6、2.3.3，都是 AAA）
2. **2.5.5（44/AAA）与 2.5.8（24/AA）并存**，不是前后替代
3. **4.1.1 废止 ≠ 不用测** —— 看你的合规声明引用哪一版
4. **800–1100 mm 是建议，1220 mm 是强制** —— 同一条款里两种约束力
5. **3.3.8 明文支持『允许粘贴密码』** —— 关掉粘贴才是不合规
