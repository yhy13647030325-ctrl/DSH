## 核心框架速查

### 一、WCAG 级别是包含关系

```
符合 A   = 全部 A 条目
符合 AA  = 全部 A + 全部 AA        （2.2 共 31 + 24 = 55 条，不含已废止的 4.1.1）
符合 AAA = 全部 A + 全部 AA + 全部 AAA
```

> **AAA 不得作为整站通用政策** —— W3C 与 EN 301 549 双重明文劝阻，理由是『某些内容逻辑上不可能满足全部 AAA』。

### 二、三个最容易记错的数

| 记错的说法 | 正确说法 |
|---|---|
| 『2.2 把触摸尺寸从 44 降到 24』 | **两档并存**：2.5.8 = 24×24 **AA**（2.2 新增）；2.5.5 = 44×44 **AAA**（2.1 就有，2.2 改名为 Enhanced） |
| 『2.1 新增 15 条』 | **17 条**（漏了 1.3.6、2.3.3） |
| 『4.1.1 废了就不用测』 | **看引用版本**：2.2 废止；**EN 301 549 v3.2.1 仍要求它**（锁 2.1） |

### 三、实体产品最该用的 8 个条文数值

| 项 | 数值 | 出处 | 约束力 |
|---|---|---|---|
| 触摸目标（AA） | **24×24 CSS px** 或 24px 圆不相交 | WCAG 2.2 **2.5.8** | AA |
| 触摸目标（AAA） | **44×44 CSS px** | WCAG 2.1/2.2 **2.5.5** | AAA |
| 非文字对比度 | **≥3:1** | WCAG 2.1 **1.4.11** | AA |
| 焦点指示 | **≥3:1** + ≥2 CSS px 周界 | WCAG 2.2 **2.4.13** | AAA |
| 操作件高度（强制） | **≤1220 mm**、**≥380 mm** | EN 301 549 **8.3.2** | **shall** |
| 屏幕可读点 | 从 **1015 mm** 处可读 | EN 301 549 **8.3.5** | **shall** |
| 机械操作力 | **>22.2 N 须替代** | EN 301 549 **8.4.2.2** | **shall** |
| 按键重复 | 延迟 **≥2 s**、重复率 **≤0.5 字符/秒** | EN 301 549 **5.7** | **shall** |

> **800–1100 mm（操作件）与 1200–1400 mm（屏幕）是 recommended，不是强制。**
> 强制的是 1220 / 380 / 1015。**四组数不能混用。**

### 四、EN 301 549 读法第一铁律

> **`shall` 才构成一致性要求；`should` 只是推荐。**
> 第 14 章原文：「Those clauses containing the word "should" are recommendations and are not required for conformance.」
> 测试结果只有四种：**not applicable / pass / fail / not testable**。

## 用法

- **不带参数** — 加载上面的核心框架速查
- **给一个条目号**（如「2.5.8」）— 我定位到章节并给出级别、阈值、原文、迁移判据
- **给一个主题**（如『触摸尺寸』『采购怎么写』）— 我按主题索引分派
- **给章号**（如 `ch04`）— 直接加载该章
- **问『有哪些章节』** — 显示完整索引
