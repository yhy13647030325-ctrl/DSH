# VoxLite — 一句话做成 Vox 风格科普短视频

> 当前版本 **1.0.12**。VoxLite 是一个 WorkBuddy 技能：把**一句话主题 / 一段文案**直接渲染成 **Vox 风格剪纸拼贴科普短视频**，全程自动、默认不打断确认。

## 特性

- **极速模式（默认）**：一句话 → 自动搜最新真实数据（实时检索，不编造，标注来源与检索日期）→ ImageGen 关键帧 → VideoGen 图生视频 → ffmpeg 拼接 → edge-tts 自然配音 + 抖音 9:16 安全区 ASS 字幕，直接出片。
- **引导模式**：指令含「确认 / review / 精修 / 先让我看分镜」时，先给你看分镜再渲染。
- **4 种画风 + 对比子集**：标准 Vox 4.0 / 美漫 / 纪念碑谷柔和几何 / 复古报纸。**默认每任务只出 1 种风格**；说「对比」可一次出多风格对比短片，且**可指定任意子集**（如「美漫+复古报纸」只出 2 条），不必出满 4 条（省积分）。
- **带情绪风格自然配音**：edge-tts 中文神经语音 + 按语义自动套情绪风格（疑问/揭示/转折/惋惜/安利/平述）+ 逐句调速 / 呼吸停顿 / 响度标准化，免 API Key，去平铺直叙。
- **去 AI 味爆款文案**：强制前 3 秒钩子（反常识 / 身份代入 / 数字 / 冲突对比），旁白用第二人称「你」、短句、口语情绪词，禁用「首先/其次/也就是说/众所周知」等 AI 过渡词，结尾留互动反转而非总结，更像真人博主而非讲解机器。
- **安全区字幕**：1080×1920 标准 9:16，白字黑描边 ASS 字幕，自动避开抖音顶部 / 底部禁区。
- **跨平台**：Windows / macOS / Linux，脚本自动定位中文字体。
- **任务目录隔离 + 自动清理**：每个任务新建独立文件夹（带时间戳，如 `voxlite-boba-sugar-260806-0430/`），临时文件互不串味；成片交付后用 `cleanup.py` 只清本任务文件夹，绝不误删其他未完成任务的文件。
- **省积分（关键帧复用 + 缓存）**：同场景多拍只出 1 张图、4 风格模式每风格仅 2 张图、纯数字揭示拍用 ffmpeg 直画免图；相同「风格+场景」的关键帧跨任务缓存复用（命中 0 积分）。单视频图片积分压到 2–3 张，4 风格约 8 张。
- **转场/揭示音效点缀（无 BGM，更干净）**：不加背景音乐，改为在镜头切换、大数字弹入、结尾等瞬间精确触发程序合成音效（whoosh/pop/ding 等，免版权、离线生成），音量低于人声、只负责"点睛"，视频更高级。

## 快速开始

在 WorkBuddy 直接说：

> 用 VoxLite 做一个「一杯珍珠奶茶到底藏了几块方糖」的科普短视频

指定画风或模式：

> 用 VoxLite 美漫风格做一条「中国高铁里程为何世界第一」的视频，先让我看分镜

## 依赖（首次使用）

技能通过 WorkBuddy 自带 Python 调用。如需在本地手动运行脚本：

```bash
pip install edge-tts imageio-ffmpeg
```

- Windows：自动从 `C:\Windows\Fonts\` 复制中文字体。
- macOS / Linux：请把任意中文字体（如思源黑体 `SourceHanSans`）放到工作目录，脚本会优先使用。

## 流水线概览

1. 解析主题 → 2. 搜最新真实数据（实时检索，不编造，标注来源与检索日期）→ 3. 拆 3–6 个叙事拍 → 4. 逐拍 ImageGen 关键帧（9:16 + 安全区 + 风格锚点句）→ VideoGen 图生视频（每段 ≤ 8s，默认 6s）→ 5. ffmpeg 拼接成单条 → 6. `tts_natural.py` 生成配音 + 字幕轴 → `finalize.py` 画幅归一 + ASS 字幕 + 混流 → 交付。

## 目录结构

```
voxlite/
├── SKILL.md              # 技能定义与执行流程
├── references/           # 视觉规范 / 调色板 / 风格预设
├── assets/sfx/           # 程序合成音效素材（首跑自动生成，免版权）
└── scripts/
    ├── tts_natural.py    # 自然化中文配音 + 对齐字幕轴
    ├── finalize.py       # 画幅归一 + 安全区 ASS 字幕 + 配音/音效混流
    ├── sfx_mix.py        # 按字幕时间轴铺音效，生成 sfx_track.wav
    ├── sfx_lib.py        # 纯 Python 音效合成库（whoosh/pop/ding/...）
    ├── gen_sfx.py        # 手动重生成音效素材
    └── cleanup.py        # 成片后清理本任务临时文件
```
